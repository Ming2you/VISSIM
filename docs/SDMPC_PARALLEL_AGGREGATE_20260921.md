## 병렬 미분

231개 Jacobian 열을8묶음으로 분할한다. 각 워커는 바이트로 고정한 같은 초기 상태,
수요, 제어 계획으로 전체450초를 계산하고 배정된 변수의 tangent만 전파한다.
모든 owner의 비용 및 NP/실제 합류 NUF에 대한 교차 영향을 유지한다.
시간 구간을 독립 실행하거나 제어값을 바꾸는 유한차분은 사용하지 않는다.

각 워커는 일반/미분 전체 상태 일치를 검사한다. 부모는 열의 중복/누락, 기준 비용/자원,
모델 소스, 행렬의 크기와 유한값을 검사한 뒤 합친다. 실패한 워커를0열로 채우지 않는다.
현재 일반 예측과 검산도 각 워커에서 반복한다. 따라서8배 가속이나150초 달성을 뜻하지 않는다.
`scalar_sec`/`tangent_sec`의 병렬 결과 최상위 값은 워커 합이고, 실제 경과 시간은
`parallel_derivatives.wall_sec` 및 `worker_times`를 사용한다.

## 집계형의 실제 범위

도시부 `native_input_routes`와 `native_input_prehead`의 이력이 다른 차량 조각을
경로/진행 단계/도착 예정 시각별 차량량으로 합산했다. 대기 차량은 단계별 차량량으로 보관하고,
이동 중 차량은 예측 길이에서 도출한 고정 크기 배열에 보관한다. 현재 망은 route stage2개,
prehead branch3개이며 각 모듈 안에서 서로 다른 집계 클래스가 같은 movement queue를 공유하지 않는다.

- 관측 초기 차량량과 회전확률을 그대로 사용한다. 소수 차량과 미분 성분을 버리지 않는다.
- 실제 queue receiving, 신호 시계, native 중간 gate, 첫/둘째 신호두 간 이동 지연과 통과량을 유지한다.
- 예측 종료 뒤에 도착할 차량은 별도 마지막 bin에 질량을 보존한다. 예측 안으로 조기 방출하지 않는다.
  이 상태를 더 긴 예측에 재사용하면 안 되며, 시간 범위를 넘긴 계산은 거부한다.
- 본선 차로군/램프 합류/국소 도시부 FIFO 동역학과 차량 관측 방식은 그대로다.
  전체 모델을 벡터화한 새로운 METANET이나 모든 Python 연산을 없앤 구현은 아니다.
- 같은 route/time bin 합산으로 순서가 바뀔 수 있으므로 모든 상태·망에서의 비트 동일성을 주장하지 않는다.
