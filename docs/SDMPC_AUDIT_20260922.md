# SDMPC 검증 기록 처리 추가 최적화

실행일은 2026-09-21이며, 디렉터리 이름은 앞선 성능 실험의 명명 규칙을 따른다.
작업 폴더는 `.worktrees/sdmpc-tangent-20260921`이다.

## 범위

기준은 `sdmpc_prediction_20260922/full_decision_v1`의 504.628초 전체 결정이다.
기존 900초 저장 상태, 450초 지평, 150초 제어 3개, 231개 미분 축,
1초 교통 적분, 같은 후보·반복·제약과 최대 8개 수치 워커를 유지한다.
이 실험은 저장 상태의 계산 시간과 결과 보존을 검증한다. VISSIM은 실행하지 않는다.
최신 망 조건이나 수요를 이 오래된 성능 비교 기준에 섞지 않았다.

## 변경

`adapter.sdmpc_compact_audit: true` 하나로 활성화한다. 명시적인
`sdmpc_primal_audit: true`가 필요하다. 기본 설정은 변경하지 않았다.

- 미분 검증용 격리 프로세스에서만 완료된 배분·상한 기록을 불변 숫자 열로 보관한다.
  모든 시간, 자원·출처 식별자, 입력 순서, 숫자를 보존하고 전체 열을 비교한다.
  정수 0과 부호 있는 0도 원래 형식으로 복원한다. 이전 pickle 기록과도 전체 비교한다.
- 원래 응답 형식으로 복원할 때 중간 리스트 생성을 줄였다.
  일반 후보 예측에는 기존 pickle 저장을 사용하여 불필요한 변환 비용을 피한다.
- 램프 보존 검사와 두 경로 재고 검사처럼 상태를 바꾸지 않는 세 검사에서만
  출력 미분에 연결되지 않는 계산 그래프를 생략한다. 숫자 계산 순서와 오류 검사는 유지한다.
  배분·교통 이동·비용·자원 미분이나 수치 적분식은 변경하지 않는다.
- 전체 미분의 각 숫자, 전체 저장 상태, 최종 제어 명령을 기존 결과와 비교한다.
  미세 오차나 불일치를 통과로 바꾸지 않는다.

## 중간 기록

  실패 로그를 보존하고 정수의 정확한 보존 처리를 추가했다.
- `compact_h3_v2`: 전체 미분 141.033초, 비용·자원·두 Jacobian 차이 모두 0.
- `compact_h3_v3`: 복원 경로 단순화 후 138.285초, 같은 네 비교 차이 모두 0.
- 최종 소스는 미분 검증 프로세스에만 열 저장을 적용한다.
  SDMPC 98개 회귀 검사와 정본 파라미터 검사가 통과했다.
  기존 calibration 경고는 해결됐다고 주장하지 않는다.

## 전체 결정 결과

`full_decision_v1`은 **474.518초(7분 54.5초)**에 완료했다.
이전 504.628초 대비 **30.110초, 5.97% 단축**이다.
전체 미분 두 번은 138.357 / 139.161초, 원 액추에이터 모델의 실제 교통 질의는
6회 / 185.529초다. 후보·반복 횟수와 NP-only 재사용은 이전과 같다.

`qualification_summary.json`의 19개 비교 조건이 모두 참이다.

- 두 Jacobian, 비용과 자원 차이가 모두 0이다. 전체 상태도 같으며 fallback은 없다.
- 최종 `ControlAction`, 물리 명령 행과 소유자별 명령 hash/vector가 정확히 같다.
  green, offset, 8개 metering, VSL의 원시값도 같다.
  provenance의 `context_fingerprint`만 현재 설정을 반영해 바뀌었다.
- 모든 후보의 결과와 최종 제약이 같다. 기준 비용은 402.31251168233456,
  선택 비용은 396.57370910204804 veh·h다. 실제 VISSIM 개선율로 해석하지 않는다.
- 상한 2400 / 743.75는 각각 두 단계 수락 후 `iteration_limit`,
  81.25는 기존과 같은 `linear_resource_qp_failed`다.
  선택 명령은 feasible이지만 최적화 수렴을 주장하지 않는다.
- 3개 제어 블록의 제약을 검사하고 블록 0만 적용하는 계약을 유지한다.
  실행 중 소스 변화는 없고 소유 워커는 모두 종료했다.
- 최종 소스의 SDMPC 98개 + 물리·회계 52개 검사 PASS, 파라미터 검사 PASS다.

이 PASS는 **바로 이전 504.628초 버전과 이번 변경의 동등성**이다.
이전 566.387초 버전과 504.628초 버전 사이의 녹색 0.001초 차이 및
`sdmpc_prediction_20260922/qualification_summary.json`의 FAIL을 취소하지 않는다.

**150초 전체 결정 목표에는 여전히 미달한다.** 한 번의 미분 139초와
전체 최적화 475초를 혼동하지 않는다. 남은 큰 비용은 미분용 교통 예측 약 117초와
직렬로 필요한 원 모델 후보 질의다. 역전파 병렬 커널 자체는 약 1초라서
그 워커 수를 늘리는 것만으로 큰 단축을 기대하기 어렵다.
추가로 큰 폭을 줄이려면 현재 동적 객체 중심의 교통 상태 갱신을 배열/컴파일 실행으로
옮기는 작업이 필요하다. 이번 변경은 물리 모델이나 적분 간격을 바꾸지 않는다.

현재 기록은 900초 고정 저장 상태의 오프라인 계산 검증이다.
다른 혼잡 상태·9000초 native 적용·모델 제어 이득 보정 완료를 보장하지 않는다.
직접 변경 파일과 SHA256은 `final_sources/`, `change_sources.json`에 보존했다.
