# SDMPC 추가 계산 경로 단축

후속 교통 예측 최적화는 `SDMPC_PREDICTION_20260922.md` 참조.
전체 결정504.628초이며,녹색 원시값0.001초 차이와 해당 시간대의 신호 상태 동등성을
구분해 기록했다. 아래566.387초 결과는 변경 전 증거로 유지한다.

작업 루트: `.worktrees/sdmpc-tangent-20260921`.
증거: `diagnostics/sdmpc_speed_20260922/` (실제 작업 시작은 2026-09-21).
기준은 `sdmpc_reverse_20260921/full_decision_v2`: 전체 결정849.376초,
미분2회419.740초, 기준/후보 질의13건423.073초다.
450초 지평,150초 제어3블록,231축,반복/탐색/QP/제약 허용오차는 유지한다.
VISSIM과9000초 런을 시작하는 작업이 아니다.

## 병목 계측

`profile_scalar_v1`은 고정900초 상태의 연속 예측을 cProfile로 계측했다.
프로파일 도구를 붙인232.869초는 실제 성능 기준으로 쓰지 않는다.
도구 내 누적 시간은 서로 중첩된다. 도시부450스텝145.7초,일반 deepcopy33.9초,
검증용 자원 배분 기록 약96만건33.2초,숫자 min/max 분기35.4초가 관찰됐다.
`profile.pstats`와 `profile.txt`를 보존한다.

## 구현

- `sdmpc_response_np_cache:true`: 결정 내부에서 NP 상한만 다른 궤적의 물리 응답을 재사용한다.
  NUF,실제 제어,모든 진단 필드와 미래 제어는 계속 정확한 키다.
  원본 응답 해시는 실제 계산한 명령을 계속 가리키며,다른 상한에는 별도의 명시적 binding을 붙인다.
  마지막 검증은 binding을 검사하고 요청한 NP/NUF 제약을 다시 계산한다.
  계산하지 않은 새 응답 해시나 새 실행 증거를 만들지 않는다.
- `sdmpc_fast_primitives:true`: 격리된 reverse AD 프로세스에서만 활성화한다.
  원 소스의 자원 배분/상태 상한 기록 함수를 그대로 컴파일해 불필요한 AD 형식 분기를 줄인다.
  기존 primal_audit가 이미 숫자로 분리한 검증값만 처리한다. 모든 오류 검사/기록/허용오차는 유지한다.
  기록 복사는 원본 알고리즘과 memo/격리를 유지하며,불변 AD scalar는 그대로 공유한다.
  두 피연산자의 min/max는 동일한 선택·동률·분기 기록을 유지하며 임시 리스트 생성을 줄인다.
  전체 상태 대조는 정본 스키마의 순수 숫자 검증 기록이 정확히 같을 때 컨테이너 동등성을 사용한다.
  다른 값·스키마·AD 값에는 원래의 전체 재귀 비교를 적용한다. NaN은 이 단축 경로에서 제외한다.

스위치가 없으면 종전 경로다. 후보 설정은 위 증거 폴더의 `config_candidate.json`.
물리식이나 vendor 파일을 바꾸지 않는다. 전체 예측의 시간축을8개로 나눈 것이 아니다.

## 전체 결정 결과

`full_decision_v1`이 exit0으로 **566.387초(9분26.4초)**에 완료됐다.
이전849.376초(14분9.4초)보다 **33.32%,282.989초** 줄었다.
185초는 미분1회 시간이고,566초가 최적화와 최종 명령 검증을 포함한 전체 결정 시간이다.

요청13건 중 NP만 다른7건의 중복 예측을 제거했다.
두 번째 상한743.75의 두 반복은 이전 물리 응답과 미분을 재사용하므로0.5초 이내에 끝났다.
후보별 비용/자원 제약과 선택 순서/반복 횟수는 유지했다.

`qualification_summary.json`의 모든 검사 PASS:

- 최종 ControlAction 전체와 제어 명령 행/owner별 해시가 정확히 같다.
- 최종 비용,전체 상한 후보 결과,최종 NP/NUF 제약이 정확히 같다.
- 전체 결정의 두 Jacobian도 각각 비용/자원/미분 행렬 모두 차이 0이다.
- 모든 231축의 전체 상태 대조 PASS, 유한차분 fallback 0, 제어 3블록 검사 및 블록 0만 적용하는 검증을 유지했다.
- 실제 모델 예측 TTT402.312512→396.573709veh·h는 이전과 같다.
  NP 562.245842 ≤ 2400, NUF 5142.757016 veh/h(목표 5144.214387, 기존 ±40 범위)이다.
- 두 유효 상한은 각 2회 반복 후 iteration_limit, 81.25는 linear_resource_qp_failed로 이전과 같다.
  수렴 인증은 하지 않는다. 새 소스/정책 때문에 명령 출처 기록의 context_fingerprint만 갱신됐다.
- 실행 중/이후 소스 변화 0, 소유한 워커 모두 종료. VISSIM을 시작하지 않았다.

**150초 전체 결정 목표에는 아직 미달한다.** 남은 큰 비용은 새로운 기준점마다 필요한
순차 교통 예측과 원 명령 검증이다. 역방향 미분 sweep은 약 2초라 추가 워커만으로 큰 단축이 되지 않는다.
교통 예측의 시간축을 독립 조각으로 분할하지 않았으며, 물리 모형을 단순화하거나 지평을 줄이지 않았다.
이 결과는 동일 900초 저장 상태 한 조건의 오프라인 시간 비교다. 혼잡 시점의 동일 시간이나 9000초 개선율을 뜻하지 않는다.
