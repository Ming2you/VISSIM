# SDMPC 예측 합산 재사용과 초기 계산 중첩

실제 작업일 2026-09-21, 작업 폴더 `.worktrees/sdmpc-tangent-20260921`.
기준은 `sdmpc_audit_20260922/full_decision_v1`의 전체 결정 474.518초다.
900초 저장 상태, 450초 예측, 150초 제어 3개, 231개 축, 1초 적분,
후보와 반복 설정을 유지한다. VISSIM은 실행하지 않는다.
이 성능 비교에 최신 실험의 다른 망·수요 조건을 섞지 않는다.

## 구현

1. `adapter.sdmpc_ramp_stock_cache: true`는 예측 내부의 램프 재고 합산을 재사용한다.
   기존 `sdmpc_prediction_cache: true`가 필요하다. 시간 전진·합류·head 통과·유입·
   차로 교환이 재고를 바꾸기 전에 해당 결과를 무효화한다. 원래 순서의 `fsum`을
   사용하며 누적 가감 합산으로 바꾸지 않는다. 캐시는 상태나 다른 후보로 전달하지 않는다.
   읽기 전용 검사에서 생성한 미분 없는 값을 물리 계산에 재사용하지 않도록 구분한다.
2. `adapter.sdmpc_initial_derivative_overlap: true`는 첫 Jacobian을 준비하는 동안
   NUF 초기화 후 명령의 독립 원 모델 검증을 실행한다. 원 모델 질의를 생략하거나
   다른 NUF 명령의 응답 토큰을 재사용하지 않는다. 최초 NP 후보가 최대 cap이라는
   기존 탐색 순서를 이용하며, 실제 사용 시 **전체 미분 요청의 SHA256 일치**를 확인한다.
   요청은 thread 시작 전에 별도 직렬화 사본으로 동결한다. 제약과 미분의 검사는 그대로다.
3. 초기 중첩은 시간 제한 없는 결정에서만 지원한다. 8워커 설정이면 중첩된 역전파는
   최대 7개 출력 워커, 일반 예측은 1개를 사용한다. 두 일반/미분 예측 단계는 각각
   한 수치 실행 흐름이며 scalar가 끝난 뒤 역전파를 수행한다. 다음 Jacobian은 기존대로
   8개 출력 워커를 쓴다. 종료·예외 경로 모두 소유 작업을 join한다.

기능이 없으면 기존 실행 경로를 사용한다. vendor, 교통 식, 보존 검사, 수요나
적분 간격을 바꾸지 않는다. 두 키가 켜진 실험 설정은
`diagnostics/sdmpc_flow_20260922/config_candidate.json`이다.

## 단계 검증

  기존 139.152초 대비 약 3초 단축이다. 일반 예측 50.897초,
  미분용 예측 114.124초, 비용·자원·두 Jacobian 차이는 모두 0이다.
  이 작은 단축을 큰 개선으로 해석하지 않는다.
- SDMPC 회귀 109개와 물리·회계 52개 검사 PASS.
- 파라미터 검사 PASS. 기존 calibration 경고는 그대로 유지한다.

## 최종 소스의 예측 대조

`flow_h3_v2`는 전체 미분 134.925초, 일반 예측 50.964초,
미분용 예측 112.571초, 전체 상태 대조 10.567초다.
비용·자원·비용 Jacobian·자원 Jacobian의 차이가 모두 0이다.
모든 231축을 계산했으며 역전파 8워커, fallback 없음이다.
역전파 커널은 0.969초, 그래프는 14,137,087개 노드 / 452,398,480bytes다.
일반/미분 예측을 동시에 실행하므로 이 구간들의 시간을 단순 합산하지 않는다.

`states_v1`은 두 옵션 모두 OFF/ON으로 별도 예측을 실행하여 전체 저장 상태를 대조했다.
상태·비용·자원 차이는 모두 0, 실행 중 소스 변화도 없다. 전체 대조 71.142초,
두 일반 예측은 OFF 51.762초 / ON 51.314초다. 초기 계산 중첩의 시간 효과는
한 번의 미분 호출에는 포함되지 않으며 전체 결정에서 따로 측정한다.
