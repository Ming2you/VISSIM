## 7. 규칙과 교훈

### 7.1 런 규칙

- **새 VISSIM 런은 최소로**: 보정·진단은 기존 FZP·결정 기록부터. 새 런은 망 변경·반응 측정·폐루프만. 망 변경은 모아서.
- **VISSIM 동시 상한 4**(5번째는 COM 생성 거부). 남의 VISSIM·codex 작업은 세기만 하고 건드리지 않음. 자리 나면 발사.
- **긴 런은 WMI `Win32_Process.Create` 로 세션과 분리해 발사**(`run_in_background` 발사는 세션 끝에 같이 죽음).
- **VISSIM COM 은 PowerShell 로**(한글 경로가 Git Bash 에서 깨짐).
- **옛 워치독 Kill-Vissim 은 PC 전체 VISSIM 을 죽임** → `-NoGlobalKill`, 자기 PID 만. codex 러너는 StallSec 3,600(D-K9-90).
- **무거운 일은 공용 잠금 LOCK 아래 하나씩**: 배타 생성, 내 토큰만 지움, 놓은 뒤 25 s 쉼. FZP·npz 스캔, plant 잡, 결정 재생이 무거운 일입니다.
- **실행 환경 고정**: `python -B`, `PYTHONHASHSEED=0`, `NUMBA_NUM_THREADS` 지움(K9-2 도구 꼴, D-K9-99). codex 런은 env_hsw(AVX-512 끔).
- 결정 실패 때는 예외만 직전 명령 유지(시한 유지 없음, D-K9-13). 유지 횟수는 보고만(D-K9-14).

### 7.2 사전 선언 규칙

- 규칙·도구·문턱·표본은 **데이터 전에 고정**하고 sha256 을 LOG 와 고정점 파일에 적습니다. 고정된 판으로만 관문·판정을 돌립니다.
- 데이터를 본 뒤 바꾼 것은 "데이터 뒤" 로 밝히고, 사용자 결정으로만 바꿉니다(예: D-K9-87 ④b 방법, D-K9-108 1e-9 허용).
- 관문이 거짓이면 그 자리에서 멈추고(STOP) 묻습니다. 뒤 단계는 돌리지 않습니다.
- 보고서는 독립 검증(새 도구, 작성자 도구 import 0)을 거쳐 r2 로 냅니다. r1 은 바이트 그대로 둡니다.

### 7.3 교훈

1. 증거·튜닝 파일에 경로 문자열을 넣지 마라. 어댑터가 경로를 따라가 고정 파일이 1,086개 → 1,708개, 결정당 +450–490 s 가 됐다. 이름 + sha 로 적는다(D-K9-42).
2. Windows 자식 프로세스에 긴 목록은 명령줄이 아니라 파일로 넘긴다(64,242자 > 32,767자, WinError 206; D-K9-52).
3. 프로세스별 임시 폴더 이름에 PID 만 쓰지 마라. Windows 는 PID 를 짧은 시간 안에 다시 쓴다(D-K9-65).
4. 봉인 폴더 이름에 시드 이름을 넣으면 경로 조각 판별기가 오인한다(D-K9-58).
5. 새 키가 결정 metadata 에 표지를 쓰면, 기록 대비 재생 관문(GB-7′)에 선언 차이가 필요하다(D-K9-71).
6. 사슬 재생 점검을 정의할 때, 어댑터가 직전 파일 경로·sha 를 출력에 적는지 먼저 본다(D-K9-62).
7. 벽시계 사분위 문턱 0.006 은 이 기계의 측정 잡음보다 작다. 중앙값만 판정한다(D-K9-47).

9. `subprocess(text=True)` 기본 디코딩은 cp949 다. git 출력에는 `encoding='utf-8'` 을 준다(D-K9-96).
10. **(새)** PowerShell `Add-Content` 는 다른 프로세스가 그 파일을 읽는 동안 실패한다(`FileShare.ReadWrite|Delete` 로 열어도). 돌고 있는 도구가 쓰는 상태 파일은 프로세스가 끝난 뒤에만 읽는다(FO_RUNS 04:10 사건).
11. **(새)** `response_token`(응답 요약 해시)은 작업 폴더 경로에 따라 바뀐다. 같은 폴더 두 번은 같고 다른 폴더 다섯 번은 매번 달랐다. 재굴림 대조에서는 "보고만" 칸으로 두고 물리 값으로 비트 같음을 본다(VERIFY_VP, D-K9-116 V1).
12. **(새)** 병렬 합산 순서 때문에 재생 목적값이 기록과 2 ULP(+1.137e-13 veh·h) 다를 수 있다. 목적값도 비용과 같은 |차| ≤ 1e-9 허용으로 본다(D-K9-108).
13. 판정·verdict 는 런 완료를 확인한 뒤에만 돌린다(10-01 사건). PowerShell 변수는 대소문자를 가리지 않는다.
14. ④b 짝 차는 첫 관측 차분으로 센다. 옛 재구성은 최대 35.5 veh·h(codex 꼴)·37.2 veh·h(우리 꼴) 달랐고 부호가 바뀐 칸도 있었다(D-K9-87).

16. 미터 명령의 `rate_vph` 는 방류가 아니라 쓰기 부호다. 방류는 FZP 머리 통과로 잰다.
