**Why:** 2026-09-05 아침 blindfix 단독은 9383(+1)로 중립이었다 — 평평한 체제(per_lane 207)에서는
모형이 q0 를 따르지 않으니 q0 가 틀려도 결과가 안 바뀐다. 곡률이 생기면 모형이 q0 를 그대로 따르므로
오귀속이 처음으로 실효한다. "중립" 판정은 **평평 체제 전용**이었다.

좋은 유역은 어떤 섭동에도 깨지는 특이점이고(9팔 전부 9050~9400), 나쁜 유역이 정상 결과다.

**기구 — 오귀속이 만드는 양의 되먹임 (t=2400 분해로 확정):**
SC5→SC101 링크(1220014203)는 물리적으로 SC101 의 E 접근로(SC101_E_SC5_to_* = SC101 **p3/p4**)인데,
canon 은 그 링크 차량을 SC5 의 **p2 진출 movement**(SC5_S_to_W_SC101 등, 이미 SC5 를 떠난 차) 큐로 센다.

```
SC5 p2 녹색 ↑ → 링크로 방류 ↑ → 링크 재차 ↑ → SC5 의 유령 p2 큐 ↑ → p2 녹색 ↑   (되먹임)
SC101 은 그 링크를 못 봄 → p3/p4 최소 → 안 비움 → 125~126 포화 고정(t=1500~)
→ SC5 의 출구 하나(SC101 방향)만 막힘(다른 출구 ≤31) → SC5 접근로 +695 = 손실의 96%
```
