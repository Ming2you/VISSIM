**0b 기각 (2026-09-09).** `capacity_drop_discharge_phi = 0.85` 단독 arm g1 = TTT **7625.4**,
분기점 f3 7496.6 대비 **+128.8** (시드 σ=50.7 의 2.5배). 무결성 정상(37/37, SKIPS=744, FAILED=0).
이유: φ 는 ρ>ρ_crit 에서만 걸리는데 **FW_E 는 t=1200 까지 임계를 안 넘는다**(실제 붕괴 개시 t≈1112).
잼이 이미 생긴 뒤에만 작동하고, 그 시점엔 벗어날 레버가 없어서 모형만 비관적으로 만든다.
게다가 FD·용량은 φ 없이 적합된 것이라 φ 를 얹으면 모형-plant 불일치가 새로 생긴다.

**δ_merge 는 값이 아니라 구조 문제다.**
* δ=0.3 은 `calibrate_metanet_ver2n21_20260907.py:299` 의 문헌제약 격자
  `[0.005, 0.0122, 0.05, 0.1, 0.3]` 의 **최댓값에 붙은 값**이다. 자유 격자(40까지)에서는 팔 전부가
  1.0~2.0 으로 갔다. 같은 스크립트 :294-296 이 "자유 적합이 문헌 밖으로 나가면 결과가 아니라
  **증상**이다 — 다른 오차를 그 축이 흡수하고 있다는" 이라고 적어 뒀다.
* **셀별 D-lit FD 가 이미 합류 감속을 먹었다.** 합류 4셀의 `v_free` 가 42셀 중 2·3·7·9위로 낮다
  (평균 85.66 대 나머지 112.49 = 26.8 km/h 흡수). δ 를 올리면 이중계상이다.
* 요구 δ 가 합류셀 관측 92개에서 0.04~420 (IQR 2.1~16.4) 로 흩어진다. δ 는 전역 스칼라이고
  셀별 표의 키(`adapter:8206-8207`)에 δ 가 없어 셀별로 못 준다. 스칼라 하나로 8배 IQR 은 못 맞춘다.
* 링크 스칼라 FD(120/27/1.6)로 재면 격차 44 km/h 지만 **셀별 표(FW_E_S9: v_free 91.31·rho_crit 25·a 2.0)로는 22.1 km/h**,
  합류 고유 잔차 9.4 km/h. 44 를 인용하지 마라.

**미터링의 정직한 장부** (t=900, R_F_E 완전 폐쇄): 본선 TTT 절감 0.0225 veh·h 대
