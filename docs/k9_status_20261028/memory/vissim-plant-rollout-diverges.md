(`nocontrolstep_20260826`, 컨트롤러가 루프에 없어 off-policy 오염 없음) 위에서
출발점 30개 × 6스텝 개루프 롤아웃, origin 단위 규칙불변 지표:

```
                    스텝1    스텝3(horizon)  스텝6(리더 끝)   총량6/실측
base                51.9%      71.6%          92.5%        1.261
+경계저류 39개        36.6%      62.1%          88.1%        1.457
+tau 물리길이 상한    33.0%      51.4%          70.3%        1.238
                                                            (실측 평평)
```

## 주범: tau 가 빈 공간을 거리로 쓰고 상한이 없다

```python
available   = 용량 - 점유          # 빈 공간
distance_km = available x 6m
tau         = distance / speed
```

빈 링크일수록 꼬리가 멀다는 설계 의도는 있으나 **상한이 없다**.
`SC5_to_SC6` 는 실제 1.232km / 자유주행 89초인데 모델 tau **740초(8.3배)**.
전체 합 자유주행 5,536초 대 모델 11,725초(2.1배). 차가 horizon 안에 정지선에
도착을 못 해 재고가 쌓인다.

물리 길이 상한을 걸면 tau 합 −44%, 최장 970→260초, 스텝3 −11pt.
**차로보정과 반드시 함께** 켠다 — 끄면 스텝6 오차가 102.5% 로 실측 총량을 넘는다.
스위치 `urban.tau.length_cap` (어댑터 `vissim_stackelberg_adapter_qbind_20260826.py`).
길이 정본은 `outputs/urban_storage_geometry_core17legs4f_20260826.json` (141개,
근거파일 80개를 비 1.0000 재현 = 그 origin 에 매핑된 **모든 링크 길이의 합**).

## 효과 0 으로 확정된 것 — 다시 시도하지 마라

| 후보 | 스텝3 효과 |
|---|---|
| **링크 속도 실시간 갱신(오라클)** | **0.0pt** |
| movement 방류상한 1400→3200 | 악화 |
| 유입 12.3% 보전 | **+5.3pt 악화** |
| 하류 수용공간 무한 | 0.000pt (binding 0회) |
| 램프 수요 배선 복구 | 0.000pt (비트동일) |
| `_out` 매 스텝 배출 | 총량 1.259→1.192 인데 오차 +0.3~2.7pt |

**속도 오라클이 0 인 것이 중요하다.** 모델은 `urban_link_speed_kph` 를 vendor 전체에서
**읽기 1회·쓰기 0회** 라 속도 동역학이 없고, 실측 속도는 150초에 15.4% 움직인다.
그런데 매 스텝 진짜 속도를 넣어줘도 0.0pt 다 — tau 가 5초 substep 정수라 15% 변동이
반올림에 흡수된다. "혼잡 생성/해소를 못 본다"는 기제는 맞지만 크기가 없다.

주의: 요약의 `urban_link_speed_kph` 는 **차로보정 전**(39.8 kph), 상태는 **후**(83.7,
2.10배)다. 그냥 덮으면 오라클이 아니라 '차로보정 제거'를 재게 되고 9pt 나빠지는 가짜가 나온다.

## 남은 벽: 통은 있는데 드나드는 경로가 없다

900초 동안 모델 재고 **+718**, 실측 **+0**. 통 별로:

```
스텝    _to_   in_   _out    큐   램프큐
0      1109   556    141   951    104
6      1624   556    325  1151      0
```

- **`_out` 은 싱크가 아니라 막다른 저장고** — movement 의 origin 123개 중 `_to_` 84 ·
  `in_` 39 · **`_out` 0개**. 들어간 차가 나갈 movement 가 없다. 141→325(+184).
- **`in_` 경계저류는 6스텝 내내 정확히 556 고정** — 초기값만 채우고 동역학이 없다.
  예측 −20pt 는 t=0 스냅샷을 맞춘 것이지 롤아웃 개선이 아니다.
- **램프큐 104 → 0 즉시 소멸**.

셋 다 파라미터가 아니라 **위상 구멍**이다. 그래서 용량·속도·유입을 아무리 만져도 안 움직였다.

  제어 여유가 얇다. "반응 없음"이 아니라 신호대잡음 문제다.
