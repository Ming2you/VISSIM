# 현시가격 항별 분해 (2026-09-06, g1 t=3600, `scratchpad/price_decomp_SC105.py`)

식: `price_i = [(ΔG_i) − (ΔL_i)] / δ × (n−1)/n`, δ=6 s, n=4 → 배율 0.75. 기준점 = **직전 결정 벡터**.
정련 목적 = `L_phased(vec) + w·Σ price_i·(g_i − ref_i)` (w=1). 오프라인 재현이 실런 가격과 소수점까지 일치.

**SC105 t=3600 (기준 46/28.7/40.7/22.7, 전역 기준 TTT 1036.681):**

| 현시 | ΔG/δ | −ΔL_phased/δ | price | live |
|---|---|---|---|---|
| p1 | **+0.00000** | +0.03454 | +0.02590 | +0.02590 |
| p2 | +0.00000 | −0.01351 | −0.01013 | −0.01013 |
| p3 | +0.00000 | +0.00795 | +0.00596 | +0.00596 |
| p4 | +0.00000 | −0.02811 | −0.02108 | −0.02108 |

**ΔG 가 네 방향 모두 정확히 0.0000** 이다(SC1002 는 ±0.013 로 겨우 살아 있다). 그래서
`price = −0.75·ΔL/δ` 이고, 큐가 있는 현시는 녹색을 더 주면 국소비용이 반드시 내려가(ΔL<0)
**부호가 구조적으로 양수**다. 부호 규약 자체는 맞다(가격은 국소 이중계상을 상쇄해
`L + price·Δg ≈ 전역 미분` 을 만드는 항). 문제는 그 전역 미분이 0 이라는 것.

**"일정 수준에서 내려가나?" — 내려간다. 다만 0 을 못 넘는다.** p1 기준을 바꿔 가며 재계산:

| p1 기준 | 28 | 34 | 46 | 58 | 70 |
|---|---|---|---|---|---|
| price_p1 | +0.0293 | +0.0259 | +0.0259 | +0.0060 | +0.0030 |
| 전역 G | 1036.681 | 1036.681 | 1036.681 | 1036.681 | 1036.681 |

큐가 다 빠지면 ΔL→0 이라 가격도 →0 으로 감쇠한다(포화형). 음수가 되려면 ΔG<0, 즉 그 현시를
줄였을 때 **지평(3×150 s) 안에 망을 빠져나가는 대수**가 늘어야 하는데 SC105 에서는 0 이다.

**그래서 정련이 하는 일 = 국소비용에서 자기 접선을 뺀 잔차(곡률)만 최소화** 하는 것이고,
그 지형은 울퉁불퉁해 **자기 목적함수의 최소도 못 찾는다**:
- pre_refine(GNE) 46/29/41/23 → 국소 12.356 + 가격 0 = 12.356
- 실제 채택 34/23/41/41 → 12.938 − 0.630 = **12.308**
- p1 58 → 11.772 + 0.367 = **12.139** (더 좋다)
- p1 70 → 11.331 + 0.766 = **12.097** (가장 좋다)
즉 6 s 쌍교환 좌표하강이 p1 을 **올리면** 자기 기준으로도 더 좋은데 내리는 쪽 국소최소에 갇혔다.

**정련이 얼어붙는 정확한 기구 (2026-09-06 21:1x, SC1002 t=3600, METER+SAT+QB 어댑터):** 기준 46/23/47/23, 국소 30.401.
p4 +6(p1 에서) 후보: 국소 30.194 (**−0.207, 국소는 원한다**) + 가격항 +0.332 = 30.526 → 기각. 가격항 = price_p4·6 − price_p1·(−6)
= 0.123 + 0.209 = 0.332 = **선형화한 국소 쌍교환 이득의 100%** ((−0.153 − 0.290)·0.75 = −0.332). (n−1)/n 은 방향미분→쌍교환 변환이라
정확히 상쇄한다. 남는 것 = L(vec) − L_lin(vec) = 곡률 잔차 ≥ 0(이득이 체감형이면 항상 불리) → ΔG≈0 인 신호에서 정련은 **한 걸음도 못 간다**.
GNE 출력(pre_refine)도 p4 를 직전 비율로 두므로 p4 는 어디서도 안 늘어난다. 큐(β)·용량(1764)을 고쳐도 마찬가지였다.
후보 처방 = 유의성 게이트: |ΔG_i| 가 |ΔL_i| 의 25%(또는 0.02 veh·h) 미만이면 그 현시 가격 0(외부효과가 측정 안 됐으면 세금도 없다). 가격을 끄는 것이 아니라
"전역 롤아웃이 못 본 것에 대한 −ΔL 세금" 만 제거한다. SC1002 는 p3 만(ΔG −0.031) 가격이 남고 p4 가 늘 수 있다.

**결정적 대조 (2026-09-06 22:xx, t=3600, 물리 수정 = METER+SAT+SAT2+QB):** 가격 ON → SC1002 **22/23/71/23**(p4 23), 가격 0(P0) → **22/23/41/53**(p4 53).
SC105 도 P0 에서 52/29/35/23(링크 420 서비스). 즉 램프·용량·큐 귀속을 고치고 나면 **남은 유일한 장벽이 현시가격**이다 — ΔG≈0 이라 −L_lin 세금이 국소 이득을 전부 상쇄.
PG(유의성 게이트)는 ΔG 가 거의 모든 현시에서 잡음이라 사실상 P0 와 같다.

**지평 9 스텝(H9, SAT2+QB, t=3600) 결과 — 지평을 늘려도 못 구한다.** ΔG 는 살아나지만(SC1002 p3 −0.53, p4 **+0.12**, p1 +0.25 per δ) 부호가
"좌회전(p4)을 늘리면 전역이 나빠진다" 다: 가격 롤아웃은 다른 신호(SC105)를 직전 계획에 **고정**한 편미분이라, 좌회전 차가 링크 420 으로 넘어가도
SC105 가 안 받아 주는 세계를 본다. 실제로 h4 에서 SC1002 가 p4 47 을 주자 420 이 263 대로 막혔다(SC105 p1 24~30). 즉 SC1002·SC105 가
**같이** 움직여야 하는 조정 문제인데 편미분 가격은 이를 못 푼다. 게다가 정련은 여전히 자기 목적의 최소를 못 찾는다(SC105: p1 70 = 12.562 가 선택 46/23/47/23 = 13.708 보다 1.15 좋음).
가격 ON 대안은 (a) 가격을 GNE 안에서 반복 재계산(in_gne, Jacobi 로 이웃 동시 이동) 또는 (b) 리더 수준 결합 결정. 단순 지평 연장·게이트·부호 조작은 답이 아니다.
**IG(in_gne 2라운드 + demand fix, SAT2+QB, t=3600) 오프라인: SC1002 40/23/53/23 (p4 여전히 23), SC105 46/23/41/29(=live), 미터 D_W 0·F_E 0 폐쇄, 진단 가격 전부 0.0000(in_gne 경로는 wu_phase_price_* 를 안 남김).** 현 구현의 in_gne 도 조정을 못 푼다. 오프라인 탐색은 여기까지 — 가격 채널은 설계 결정(사용자) 사안.

**옵션② own 항을 롤아웃 states 로 (OWN, 2026-09-06 22:5x 오프라인, 물리 전부 위):** ΔG≈0 인 채 ΔOwn 만 ±0.4~0.9/δ 로 커서 price = −0.75·ΔOwn/δ = +ΔOthers —
누적 불변 세계에서 "자기 큐를 줄이는 것 = 남에게 넘기는 것" 이라 큰 세금/보조가 되어 꼭짓점 결정: SC1002 58/35/23/23, **SC105 22/23/23/71(420 을 더 굶김)**, SC1001 77/20/21/20, SC1004 24/22/21/70. 오프라인 실패로 판정, 런 안 함. 누적 기반 G 에서는 own/others 분해로도 외부효과가 안 나온다.

**옵션① 2단 정련 (TS, 오프라인 t=3600, 물리 전부 위): plan A(가중 0) SC1002 22/23/65/29 · SC105 52/29/35/23 → 2단(plan A 기준 가격) SC1002 28/23/65/23 · SC105 52/29/35/23 · SC1001 23/74/21/20(?) · 이동 432 s · 결정 550 s(직렬).**
plan A 조차 p4 29 뿐(이 물리 스택에서 국소 최적이 p3 65 쪽), 2단이 p4 를 23 으로 되돌림. 가격이 plan A 에서도 −L_lin 성격이라 크게 움직인다. 유망하지 않으나 사용자 요청대로 h8 로 런.

**옵션③ 회랑 결합(JOINT, 오프라인 t=3600, 물리 전부 위): 결합 패스가 SC1002 12 s·SC105 48 s 이동 → SC1002 28/23/65/23(p4 23), SC105 52/41/23/23.** 결합 국소비용(L_A+L_B, 묶음 안 가격 0)도 좌회전을 안 늘린다.
주의: 물리 스택에 따라 국소 최적 자체가 흔들린다 — SAT2+QB+P0 는 SC1002 22/23/41/53(p4 53)인데 SAT3+CAP+QB 의 plan A 는 22/23/65/29. 전부 스택 + P0 를 다시 재는 중.

**How to apply:** 가격 부호를 뒤집거나 클리핑하는 식의 대증요법은 틀린 처방이다. 고칠 대상은
(1) ΔG≡0 — 전역 롤아웃이 지평 안 완료차량만 세어 망 내부 이동에 눈이 멀다(종단비용/역압으로
채워야 한다. h2 = 관측 역압 가격이 그 시도), (2) 정련 탐색이 자기 목적의 국소최소에 갇히는 것.
