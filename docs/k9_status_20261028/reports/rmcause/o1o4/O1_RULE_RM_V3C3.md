## 1. 줄임말

- RM = 램프 미터링(진입 램프 신호로 합류량 조절). ALINEA = 합류점 하류 점유율을 목표로 되먹임하는 미터 규칙.
- FW_E / FW_W = 동측 / 서측 고속도로. NC3 = 같은 시드 v3c3 무제어 런(`D:/VISSIM_runs/20261001_v3c3/s<S>_v3c3nc/run`).
- V-A = 묶음 B1 을 배포한 SDMPC(우리 예측 제어기) 폐루프 런(`D:/VISSIM_runs/20261023_sdmpc31_k92/sdmpc31_v3c3_k92va_s<S>`). 미터는 61결정 내내 녹색 10 이었습니다 [읽음 `rmcause/METER_CAUSE.md:18`].
- TTT = 총 통행시간(veh·h). Ω = 제어 영역 635 링크. ① = FW_E 본선 7링크. ② = 동측 국소 19링크. ③ = Ω TTT. ③u = Ω 안 도시. ④ = ④a 전체 1,236 링크 TTT + ④b 미삽입 지체. Ω 밖 (a) = ④ − ③, (b) = ④a − ③.
- 미삽입 = 입력에서 생겼지만 망에 못 들어간 차의 대기(재구성). UC = 이번 표의 미삽입 합집합(RM 2런 + V-A 3런 + NC3 3런에서 줄 선 입력 10개: 194, 282, 1064, 1085, 1086, 1087, 1093, 1098, 1099, 1102). 앵커는 그 시드 NC3 의 생성 대수입니다.
- 미터 대기 = 미터 커넥터 위 차 + 접근로에서 다음 링크가 미터 커넥터인 차(stage-1 `meterbound`). 램프 구역 = 미터 커넥터 + 접근로 전체(stage-1 `onramp:`).
- g = 10 s 주기 중 녹색 초. g10 = 늘 초록(열림).
- FZP = VISSIM 차량 궤적 기록(5 s 간격). KST = 한국 표준시.
