## 6. 읽는 법과 모름

### 6.1 읽는 법 [추론]

1. v3c3 에서 V-A 의 FW_E 차는 두 덩어리로 나뉩니다. (가) 셀 5–9(10643 진출 갈림점 근처)의 공통 몫: 무제어 런에만 늦게 생긴 진출 역류가 모든 처치 팔에서 같은 크기로 없습니다. (나) 나머지: 세 시드 모두 ±13 veh·h 안. 그래서 "V-A 가 FW_E 를 움직였다" 고 읽을 몫은 거의 남지 않습니다. 이것이 사용자가 짚은 "FW_E 가 안 움직인다" 의 숫자 모양입니다.
2. B 는 나머지 몫이 −37.5 / −114.7 / −76.0 이고, 그 자리가 B1·B2 두 합류 구역(10681·10484 합류 머리, `FD/R1_REPORT.md` §0 1번)이며, 같은 런에서 연결로 10639 재고가 늘었습니다. "미터로 연결로에 잡아 두고 합류 구역을 빠르게 한다" 는 그림과 맞습니다. 미터가 실제로 조였는지(GREEN 초)와 합류 유량은 R3 가 셉니다.
3. 64cf 는 같은 공통 몫(약 −70)이 있지만, 그것을 빼고도 joint 나머지가 −213.5 이고 거의 링크 2 의 B1·M(2,700–6,300 s)입니다. R1 에 따르면 64cf-s29 무제어는 B1 이 훨씬 깊고 길게 막힙니다(B1 평균 속도 47.3 대 v3c3 65.8–73.7 km/h, B1 번짐 62 분 대 0 / 0 / 2 분; `FD/R1_REPORT.md` §0 2번). 그래서 64cf 에서는 줄일 자리가 큽니다.
4. PRE §4.3 의 두 후보와 견주면: 후보 2("① 차의 일부가 진출 역류 몫")는 v3c3-s41·s43 에서 실제로 크지만, VSL 단독 팔(도시 native)에도 같은 크기로 나오므로 "도시 신호 제어의 몫" 으로는 이 자료에서 가를 수 없습니다. 후보 1("무제어가 덜 막혀 미터가 막을 번짐이 작다")은 v3c3 와 64cf 의 B1 깊이 차와 맞지만, B 가 v3c3 에서도 B1·B2 를 21–39 / 12–31 veh·h 줄였으므로 "자리가 없다" 는 아닙니다.
5. C1 을 볼 때: C1 − NC3 에는 이 공통 몫(무제어 사건)이 그대로 섞일 수 있습니다. C1 − V-A, C1 − B 처럼 처치 팔끼리 빼면 이 몫이 거의 지워집니다(B − V-A 의 셀 5–9 몫 ±0.3). C1 기준 줄의 C1 − V-A·C1 − B 칸이 FW_E 를 읽기에 덜 섞인 칸입니다.

### 6.2 모름

1. 공통 몫이 왜 모든 처치 팔에서 없어지는지 모릅니다. 같은 시드 무제어 런은 하나뿐이라, 작은 흔들림만으로도 그 사건이 사라지는지(궤적 갈림) 아니면 처치가 공통으로 바꾸는 무엇(예: 하류 진출·도시 쪽 흐름) 때문인지 이 자료로 가르지 못합니다. 새 런은 이 작업 범위 밖입니다.
2. v3c3 짝의 잡음 크기를 모릅니다(PRE §12-1). 64cf 의 A1 − joint(수치 경로만 다른 두 런)가 d① +32.5(M +27.2, 2,700–4,500 s)인 한 표본만 있습니다. v3c3 짝의 30 veh·h 아래 차는 이 크기와 나란히 읽어야 합니다.
3. 기구별 몫은 나누지 않았습니다(PRE §12-4). 이 문서는 링크·구역·셀·시간 칸만 냅니다. 기구 깃발(§6.1 표)은 종합 단계 몫입니다.
4. 진출 10643 의 감소가 VSL 단독 팔(s41 −31.0, s43 −26.9)에도 있으므로, 다른 팔의 10643 감소를 도시 제어 몫으로만 읽을 수 없습니다(PRE §12-3).
5. codex urban_only(d① +721.4)와 freeway_only(Ω701 +409.9 · ④ +1,275.7 · Ω 밖 (a) +865.8)의 풀이는 R4 몫입니다. 이 문서는 칸만 적습니다.
