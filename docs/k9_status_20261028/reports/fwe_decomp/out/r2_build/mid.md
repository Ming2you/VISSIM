## 5. 데이터 뒤: 셀 5–9 공통 몫 (멈춤 S-12 — 고정 문서에 없던 자르기; 깃발·C1 기준 줄에 쓰지 않음)

- 왜 이 자르기: R2-d 셀 표(T-d1)에서 셀 6–9 값이 같은 시드의 서로 다른 팔에서 거의 같게 보였습니다(예: v3c3-s41 셀 7 −29.2 · −29.1 · −21.9 · −29.2). 자르는 범위는 내가 고르지 않고, R1 이 무제어 쪽에서 이름 붙인 범위(셀 5–9, 2,631–4,543 m; `FD/R1_REPORT.md` §0 4번)를 그대로 썼습니다.
- 도구: `tools/fwe_r2_after.py`(`6bccb4c4…`), J 만 읽음(새로 센 것 없음, 셀 900 s 칸을 더하기만 함) → A.
- 읽는 법: "나머지" = d①(bin 꼴, 900 s–끝) − 셀 5–9 몫. 맨 오른쪽 칸은 셀 5–9 몫의 900 s 칸(900–1,800 s 부터).
- [계산] 같은 시드 B − V-A 의 셀 5–9 몫은 두 짝 몫의 차라 +0.3 / −0.3 / +0.1 veh·h 입니다(v3c3-s31 / s41 / s43). 처치 팔끼리 빼면 이 몫이 거의 지워집니다.
