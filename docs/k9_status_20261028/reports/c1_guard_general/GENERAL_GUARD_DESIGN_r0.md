### 2.3 (c) 머리 없는 공급 구간 → 서버 (사슬 이어짐)

- **차로 이음**: 구간 s 의 아래 끝에서 같은 차로로 이어지는 다음 구간. 같은 링크 안 다음 구간이거나, 그 차로에서 떠나는 커넥터의 착지 구간입니다(커넥터 차로 i: 출발 차로 first + i → 착지 차로 landing + i, CX USG:36-45 와 같은 읽기). 갈림이면 다음 구간이 둘 이상입니다.
- **서버** = 이음을 따라 처음 닿는 우리 현시 머리 또는 미터 머리. 이음이 정지선 없는 끝(sink), 우리 현시 밖 머리(native·미드블록), 차량 입력, 고속도로 본선에서 끝나면 서버가 없고 원천이 아닙니다.
- **귀속 규칙(권장, GG4)**: s 가 서버 X 에 귀속 ⇔ F_s 이고, s 아래부터 X 의 끝 구간(머리 차로 구간 또는 미터 머리 앞 구간)까지 이음 위의 짧지 않은 구간이 모두 F.
  - 뜻: "그 서버의 줄이 s 위 끝까지 끊김 없이 이어졌다" 를 관측으로 확인한 것입니다. 원인이 그 서버라는 근거가 됩니다. 중간 합류·양보·native 정지선 때문에 찬 공급 구간은 서버를 밀지 않습니다 [추론].
  - 귀속된 s 마다 max(1, n_s ÷ C_s) 를 X 에 더합니다. X 가 현시면 그 무게에, 미터면 미터 방아쇠와 근거 목록에 넣습니다. X 의 머리 차로 받는 쪽이 모두 넘었으면 0.
- **예 (129·10491, FW_W 감시)**: 10491 → 129 차로 1 [239.4, 300.0] → 갈림.
  - (a) 10490 → M:RM_C10490 → 미터 RM_C10490.
  - (b) 129 차로 1 [300.0, 301.9] → 10777(짧음, 지나감) → A:127:1 → SC1001 p3.
  - A:127:1 이 F 면 (b) 로, M:RM_C10490 이 F 면 (a) 로, 둘 다면 둘 다 귀속합니다. 129 가 127 넘침으로 찼는데 미터를 여는 일(r2 B 의 위험 줄)은 생기지 않습니다 [추론].
- **예 (FW_E 10643)**: F:10643 → 126 [150.2, 156.1](짧음) → 10641·10700 → A:71:*(SC1004 p3·p4). 71 차로가 F 일 때만 10643 이 귀속합니다.
- **짧은 머리 차로**(10개, F-G6): 그 머리 차로 자체는 원천이 아닙니다. 위 공급 구간이 짧은 구간을 지나 그 머리 차로까지 이어지므로, 짧은 머리 차로의 사슬 조건은 "판정 없이 지나감" 으로 둡니다. 곧 바로 위 짧지 않은 공급 구간이 F 이면 그 현시에 귀속합니다(예: SC101 1220016001 ← 커넥터 10502·10503(짧음) ← 링크 314).

### 2.6 (f) 한 신호에서 여러 요구 — 행 결합, 실현 가능성, 우선

**결합 (codex 꼴, CX USG:114-145)**

- 신호마다, 블록마다 행 하나: w̃ = (현시 무게 → 녹색 축 벡터) ÷ 최대 |무게|. 행 = w̃·z ≥ r_k, r_k = min(r, 0.5 × M_k), r = 2.0 s, M_k = 블록 k 의 기존 제약 아래 w̃·z 의 LP 최대. r_k < 0.01 이면 행 없음.
- 뜻: "무게를 곱한 현시 녹색 변화의 합 Σ_p w̃_p Δg_p ≥ r_k". 녹색 축이 {pX +1, 마지막 현시 −1} 이고 주기가 고정이라, 무게가 큰 현시 쪽으로 녹색을 옮기라는 요구가 됩니다.
  - 예: SC1001 에서 127 차로 1(p3) + L:10481 + 귀속 공급 구간 129 차로 1 = p3 무게 3, 북쪽 37(p1, Ω701 이 더한 접근) 무게 1 → 방향은 p3 쪽이 큼.
  - 모든 살아 있는 현시의 무게가 같으면 방향이 0 → 행 없음, 영수증 'no_green_redistribution_direction'. 줄 녹색이 없다는 뜻입니다.
  - −1 현시(받는 쪽이 다 참)는 녹색을 빼는 쪽으로 들어갑니다.
- 한 결정에서 강제되는 몫은 신호마다 required ≤ r = 2 (무게를 곱한 녹색 초)입니다. 블록 1·2 는 이동 한도가 커서 r 까지 요구하는 일이 많고, 실행되는 것은 블록 0 입니다 [읽음 r2 §2.1].

**실현 가능성**

1. 블록 하나 안에서는 늘 가능합니다: r_k ≤ 0.5 M_k [읽음 CX USG:117-140].
2. 신호 사이: 행마다 그 신호의 녹색 축만 씁니다(축이 겹치지 않음). 미터 하한은 미터 축만 씁니다. 그래서 블록 하나 안에서 함께 가능합니다 [읽음·추론].
3. 블록 사이(SEQ:145-153 의 이동 행 |z_k − z_{k−1}| ≤ 한도) [계산]:
   - 블록 k 의 가능 집합 S_k 는 이동 한도가 (k+1) 배이고 물리 한계 행은 같습니다. 직전 실행이 물리 한계 안이면(lo − a ≤ 0 ≤ hi − a) S_k ÷ (k+1) ⊆ S_0 이므로 M_k ≤ (k+1) M_0 입니다.
   - z_0 = z_1 = (S_0 의 최대점 z*) 로 두면 w̃·z = M_0 ≥ r_0, 그리고 r_1 ≤ 0.5 M_1 ≤ M_0.
   - z_2 = z* + (y − z*) ÷ 4 (y = S_2 의 최대점)로 두면, 이동 행 차는 (3 + 1) 한도 ÷ 4 = 한도 이내이고, w̃·z_2 = M_0 + (M_2 − M_0) ÷ 4 ≥ 0.5 M_2 ≥ r_2 입니다(M_2 ≤ 3 M_0 이므로).
   - 그래서 가드 행을 모두 더한 3블록 계는 비지 않습니다. 직전 명령이 물리 한계 밖이면 이 논거가 서지 않습니다. 그때는 codex seed 투영이 맡고, 투영이 실패하면 ValueError 입니다(아래).
4. 실제 기록: codex B 는 같은 함수로 3시드 × 61결정, 'constrained' 영수증 387 / 447 / 390 개에서 결정 실패 0, 유지 0 이었습니다(F-G24·F-G25).
5. 밀리초 반올림: r_k 가 1 ms 격자 위가 아닐 때(M_k < 4 s) 면 위 후보가 반올림 뒤 검사를 못 지날 수 있습니다. 선 탐색은 그 후보를 버립니다. seed 는 1.05 여유가 있습니다 [읽음 r2 §2.1 RV-G12]. 합성 시험 하나를 둡니다.

**우선 규칙**: 따로 두지 않습니다(권장, GG7). 무게(넘은 차로·구간 점수 합)가 곧 우선입니다. LP·QP 가 실패하면 codex 와 같은 ValueError → 결정 실패 → 탐침 멈춤 8 / S-C1-19 로 멈추고 묻습니다.
