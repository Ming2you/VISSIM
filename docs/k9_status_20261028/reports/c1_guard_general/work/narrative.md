## 줄임말 (처음 한 번)

- SC = 신호 제어기. SG = 신호 그룹. 머리(signal head) = 차로 위 정지선 신호등. 현시 p1–p4 = 우리 제어기가 녹색을 나누는 단위(계획 파일이 SG 를 현시에 묶음).
- 머리 차로 = 제어 SC 의 머리가 있는 차로 하나. 접근 묶음 = 같은 SC·같은 링크의 머리 차로들.
- 저장 용량(차로) = 그 차로 구간 길이 ÷ 정지 간격. 정지 간격(jam spacing) = 줄 선 차의 앞범퍼 사이 거리(차 길이 + 정지 틈).
- 공급 구간 = 머리가 없는 링크·커넥터 구간으로, 그 끝이 제어 접근·미터·고속도로 쪽으로 이어져 줄이 번질 수 있는 곳.
- 서버 = 그 구간의 차를 내보내는 정지선(우리 현시 또는 미터).
- USG = codex `urban_storage_guard.py`(도시 저장 보호, configure/constrain/operating_seed). M4 = C1 의 미터 저장 보호(머리 앞 점유 0.9 면 녹색 하한을 올림).
- Ω701 = codex 목적 영역(701 링크). FZP = VISSIM 차량 궤적 파일. V-A = 우리 배포 폐루프 런, B = codex 제어기 런, NC3 = 무제어 런(모두 v3c3 망).
- 결정 시각 관측 = 제어기가 150 s 마다 받는 상태 파일의 `/vehicle_records/records`(전체 차량 기록). 차로 프레임 = 같은 시각의 `lane_observations/frame_NNNNNN.json`(차 길이·경로 포함).
