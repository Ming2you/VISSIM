# 실제 기록 상태의 공통 차분·SPSA 비교

현재 sparse block SPSA는 기본 가격 계산으로 채택하지 않는다. 16쌍으로 늘려도 공통 방향 69개 중 24개의 외부 비용 부호가 틀렸고, 정확한 local 비용을 더한 제한된 후보 순위도 19개 owner 중 6개만 같은 최저 후보를 골랐다. 계산 횟수 감소만으로 선택의 신뢰성을 확보하지 못했다.

고속도로 70%·도시 30%의 저장 1050초 상태와 실제 900초 행동을 고정한 계산 검증이다. 도시 17개·고속도로 2개 owner, 기존 450초 예측과 고정 행동 box를 사용했다. 현재 선정한 80%·50% 시나리오의 교통 성능 시험이 아니다. 모든 입력 해시는 실행 전후 같았고, 근사 가격 적용·GNE 선택·명령 출력·VISSIM 실행은 하지 않았다.

|---|---:|---:|
| 추가 물리 응답 수 | 16 | 32 |
| 쌍별 시간 합계 [초] | 36.075 | 71.065 |
| 부호 일치 [전체 basis 가중] | 44/69 (63.77%) | 45/69 (65.22%) |
| 외부 비용 변화 MAE [veh·h] | 0.231485 | 0.149665 |
| 전체 L1 상대 오차 | 229.97% | 148.68% |
| 외부 비용 최저 후보 일치 | 8/19 | 10/19 |
| 정확 local+외부 비용 최저 후보 일치 | 4/19 | 6/19 |

부호 일치는 owner별 비율의 단순 평균이 아니라 일치한 basis 수/비교한 basis 수다. 정확 변화량의 절댓값을 가중치로 쓰면 77.75%→76.99%로, 16쌍에서 이 지표는 오히려 낮아졌다. 모든 69개 변화가 |Δexternal|>10⁻⁹ veh·h 조건을 충족했다.

MAE의 분모는 69개 방향이다. 전체 L1 상대 오차는 Σ|추정−정확|/Σ|정확|이며, 두 비교의 공통 분모는 6.9455932473 veh·h다. 분자는 8쌍 15.9724810808, 16쌍 10.3268788063 veh·h다. owner별 상대 오차의 평균을 전체 오차로 쓰지 않았다.

정확 차분은 기준 행동 1개+방향 69개의 응답을 사용했고 준비 전체는 118.488초였다. 이후 SPSA 16쌍(32개 응답)은 71.096초, 전체 진단은 195.038초였다. 표의 71.065초는 서로 겹치지 않는 쌍별 scope 합계이고 나머지는 checkpoint 집계 등이다. SPSA는 이미 만든 정확 basis와 초기화된 worker pool을 재사용했다. 따라서 118.488초와 표의 시간을 처음부터 실행한 두 제어기의 단축률로 계산하면 안 된다. 가격 준비까지 정확 응답을 재사용한 진단이며, 120초 전체 decision 예산 통과도 아니다.

각 owner에서 동일한 basis B1…Bn과 기준 유지 HOLD(비용 변화 0)를 함께 비교했다. 순위는 낮은 비용부터다. 아래 표는 최저 후보이며 전체 순위와 모든 변화량은 JSON에 있다. `정확 local+외부 비용`은 동일한 정확 local 변화에 정확 또는 SPSA 외부 변화를 계수 1로 더한 진단이다. 실제 follower의 채널 가중치·공유 제약·dual·다른 owner의 동시 행동은 포함하지 않으므로 새로운 GNE 행동으로 해석하지 않는다.

예를 들어 FW_W는 정확 local+외부 비용에서 HOLD가 최저인데, 8쌍·16쌍 모두 B2를 더 좋게 평가했다. 실제 정확 모델에서 B2는 HOLD보다 비용이 0.156136 veh·h 높다. SC101의 8쌍 최저 후보도 같은 제한된 후보 집합의 정확 최저보다 0.423494 veh·h 높았다. 전체 선택을 실행하지 않아도 현재 근사를 그대로 채택하기 어렵다는 근거다.

R_D_W·R_F_W·R_D_E·R_F_E의 네 미터 좌표는 현재 기준 행동/소스/허용 구간에 대한 해석적 proof에서 모두 실제 1800으로 고정됐다. 따라서 이 비교의 69개 측정 방향에는 미터 변화가 없다. 가격의 0 대표값은 미터 효과가 0이라는 추정치가 아니며, 실제 수요 근처 미터 탐색의 검증도 아니다. 이 표현 문제는 계산 가속과 별도로 남아 있다.

원인은 여러 owner의 변화가 한 쌍에 섞이는 유한 표본 잡음과 기준점 밖 상호작용 편향으로 설명 가능한 형태지만, 이 한 상태의 결과만으로 각각의 비중을 식별하지는 않았다. 현재는 정확 응답 재사용과 deadline 처리 개선을 유지하고, 이 SPSA 설정은 진단용으로 보존한다.
