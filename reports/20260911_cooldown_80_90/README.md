행의 차량 ID·시각 키 누락/추가는 없고, 최초에는 위치 0.10m·0.01m와 속도 0.69·0.06km/h 차이부터 시작한다. 이후 일부 행의 속도 차이는 최대 45.29·38.62km/h까지 벌어지므로 모든 차이를 단순 반올림 오차로 취급하지 않는다. 전체 0–5400초 Ω 차량 수·TTT·TTD·경계 사건 시계열은 정확히 같고, 본선의 모든 차량 행도 같다. **이것을 전체 궤적 동일성 통과로 대체하지 않는다.**

native LSA 1–5400초 event payload는 두 경우 모두 원래 런과 정확히 같다. 단, 기존과 마찬가지로 LSA에는 미터의 COM GREEN 전환이 기록되지 않아 적용·종료 readback의 확인 범위가 한계다.

원인은 아직 확정되지 않았다. 달라진 설정은 SimPeriod·평가 종료 시각이며, 추가 수요 검사는 읽기 전용이다. INPX의 단일 코어 설정, 96개 desired speed decision의 0–99999 적용시간, 관련 설치 매뉴얼을 조사했다. 종료 시각 접근이 차량 움직임을 바꾼다는 규칙은 확인하지 못했다. 종료 시각 때문이라고 단정하지 않았고, 시험을 통과시키려고 교통 조건을 바꾸지 않았다.

`strict_prefix_failure.json`과 `prefix_difference_diagnosis.json`, `prefix_changed_rows.csv`에 실패와 차이를 보존했다. `validation.json`의 상태는 `completed_native_runs_with_failed_prefix_equivalence`다. 그림은 이 실패를 표시한 상태에서 완료된 9000초 런 자체의 관측을 그렸다.
