# RM 명령 replay 충실도 시험 — 모형 vs native (완료)

방법: native RM 런이 실제로 쓴 ALINEA 녹색을 모형에 그대로 먹이고(replay), 같은 무제어
상태에서 hold 와 비교. native 쪽은 stocks.csv 의 rm - none 차이를 같은 창에서 적분.
도구 D:\VISSIM-merge\tools\rm_replay_fidelity.py (RM_CUTOFF 로 창 선택). VISSIM 미사용.

적분 검증: 900.1~끝 구간에서 FW_E -132.630 / FW_W +16.699 산출 —
공표값 -132.64 / +16.66 재현. 방법이 맞다.

native 두 런의 최초 차이 = 1980.1 초. ALINEA 최초 제한 결정 = 1950. 즉 1950.1 은
두 팔이 공유하는 상태다(비트 동일).

  RM_C10490 -0.600 / RM_C10484 -0.500 / RM_C10639 -0.086 / 나머지 5개 정확히 0

이 체제에서는 모형의 램프 물리가 틀렸다기보다 **미터가 원래 별 일을 안 하는 게 맞다**.

주의: native 의 -1.10 veh·h 는 1.2 대를 붙잡아 얻기에는 대당 55 분에 해당해 비현실적이다.
1980.1 이후 혼돈적 발산이 상당 부분을 차지할 수 있다. 단일 시드 450 초로는 판정 불가.

## 진단

1) 램프측 비용 / 본선 이득 비율

| 창 | 모형 | native |
|---|---:|---:|
| 2700.1 | 7.53/6.75 = **1.12** | - |
| 3450.1 | 9.92/9.17 = **1.08** | 6.59/15.68 = **0.42** |
| 9000초 전체 | - | 55.24/115.98 = **0.48** |

**모형의 램프 비용이 본선 이득 대비 약 2.6 배 과대하다.** 두 창과 전체 런에서 일관된다.
그 결과 모형의 순효과가 제한 깊이와 거의 무관하게 +1.2~+1.5 에 고정되는 반면
native 의 순효과는 +3.96 에서 -9.09 까지 움직인다. **모형이 평평해지는 원인이 램프항이다.**

2) 교차방향 실명
모형의 ΔFW_W 가 세 창 모두 **정확히 0.0000**. native 는 +1.49 / +2.16 으로 서쪽이 나빠진다.
모형에는 미터링이 반대 방향에 영향을 주는 기구가 아예 없다(도시망 미포함).

## 결론

"이득이 있는데 plant 가 못 잡는가" -> **그렇다, 구속 체제에서.**
- RM 은 모형에 보인다(D1 기각). 본선 이득의 부호와 대략적 크기도 잡는다.
- 그러나 램프 커넥터 재차 비용이 2.6 배 과대해 순효과를 상쇄해버린다.
- 그래서 3450.1 처럼 실제로 이득이 나는 구간에서 모형은 손해로 판정한다.
- 교차방향 효과는 전혀 못 본다.
