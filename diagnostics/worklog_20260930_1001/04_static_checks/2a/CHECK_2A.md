## 5. F10(가칭) 입구 경계 항목 제안 초안 (동결 규칙 OPEN에 따른 초안, 구현은 사용자 결정)

- **문제:** plant는 셀 0 유입이 net.v_free = 110 km/h로 들어온다고 가정합니다(AFA:365). VISSIM은 포화 삽입 중에 26–43 km/h로 넣고, 셀 0 전체가 가속 구간입니다(§4.2). 그 결과 셀 0 재고가 −24 ~ −28대, 속도가 +29 ~ +32 km/h 어긋납니다(§2.2). 셀 1 이후는 거의 맞습니다.
- **후보** (효과는 아직 시험하지 않았습니다)
  - (a) **관측 입구 속도 경계.** 셀 0의 `upstream_speed`를 인과적 관측값으로 둡니다. 예: 직전 150 s의 obs150 원점 검지(960278–960281) 평균 속도를 지평 동안 고정합니다. 새 config 키를 두고, 키가 없으면 비트 동일하게 합니다. 고치는 자리가 AFA:365 한 줄이라 가장 작은 변경입니다 [추론].
  - (b) **셀 0 전용 FD.** 셀별 FD(#11, 사용자 2026-09-30: 필요하면 가져다 씀)를 셀 0에만 적용합니다. 다만 정적 FD 하나로 두 체제(진입 26 대 43 km/h)를 동시에 나타내기는 어렵다고 봅니다 [추론]. (a)가 관문을 못 넘을 때의 대안입니다.
  - (c) **기존 상류 완충 셀 경로**(`freeway_buffer_segments`, AFA:178, :272, :365). 이 경로는 유입을 q_cap = 6,937 veh/h로 자릅니다(AFA:272). 관측 포화 삽입률(평균 약 7,650, p95 8,640–8,880)보다 낮아 수용 의미론이 바뀝니다. 그래서 권하지 않습니다 [읽음·추론].
- **판정 기준 제안** (사용자 확인 뒤, 결과를 보기 전에 동결)
  1. 키가 없으면 T5 비트 동일
  2. 같은 P-comp 하네스(fit 5시드, 같은 53개 절단점, s37 봉인 유지)에서 셀 0 \|bias\| < 15대가 ≥ 3/5 시드이고, 셀 0 MAE가 5/5 시드에서 줄어듦
  3. 셀 1·2의 \|bias\|가 시드마다 3대 넘게 늘지 않음
  4. history_forecast 모드에서도 2를 만족함
- **우선순위 의견 [추론]**
  - 셀 0 유입은 외생 입력(VISSIM 삽입)입니다. 그래서 재고 편향은 목적함수에서 대체로 준상수 오프셋이고, 결정을 직접 바꾸는 폭은 F1–F4보다 작을 수 있습니다.
