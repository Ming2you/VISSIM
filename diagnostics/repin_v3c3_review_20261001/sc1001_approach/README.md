# SC1001 접근로 구성요소 검증 — 2026-10-02

**상태: 구성요소 시험 통과, 전체 plant 연결·채택 전.** `SharedSignalApproach`를 기존 `evaluation/controllers/lane_offramp_runtime.py`에 추가했다. 기존 `LaneOfframpRuntime`의 AST는 변경되지 않았다. 따라서 현재 정본 예측의 배수 오차가 이미 수정됐다고 해석하면 안 된다.

## 근거와 변경

선택망의 10491 → 129/127 → SC1001 정지선은 서로 다른 물리 경계다. 기존 기록의 450초 배수는 실측 128대와 모델 27.365대, 종료 포트 재고는 2대와 38.582대였다. 상세 근거는 상위 `SC1001_BOUNDARY_DIAGNOSIS.md`와 반복 방문 집계를 바로잡은 `SC1001_ROUTE_AND_VISIT_UPDATE.md`에 있다.

새 구성요소는 세 차로의 유한 저장, 정지선까지의 이동 준비시간, FIFO 대기, 출처·목적지 표식, 차로별 공유 신호 서비스와 하류 수용 공간을 함께 계산한다. 적색 중에도 접근로에 공간이 있으면 진출 커넥터에서 받을 수 있고, 접근로가 차면 커넥터 배수를 제한한다. 같은 정지선 차로를 이용하는 도시 유입과 두 진출램프가 서비스율을 각각 중복 사용하지 않는다.

관측상 목적 차로에 아직 도달하지 못한 차량은 삭제하거나 목적 차로에 즉시 재배치하지 않는다. 옆 차로의 이전 단계 잔여 공간을 나눠 받아 한 차로씩 이동한다. 이것은 차로 단위 근사이며, 측면 이동 상한에 기존 차로 서비스율을 사용한 것은 아직 실측으로 보정된 gap acceptance 법칙이 아니다. VSL/RM 이득 보너스는 없다.

## 확인한 범위

- `diagnostics/test_shared_signal_approach.py`의 14개 시험 통과. 적색 수용·만차 차단·이동 지연·공유 서비스·막힌 회전류·하류 수용량 중복 방지·차량 보존·후보 상태 분리·인접 차로 이동을 검사했다.
- 자동미분은 합성 상태의 1초 신호 서비스·체류시간·재고를 독립 유한차분과 대조했다. 전체 450초 rollout이나 차로 변경 미분의 검증을 대신하지 않는다.
- 기존 seed47 2700초 관측에서 link127의 69대를 초기화했다. 적색 1초 후에도 총 69대, 정지선 방출 0대, 체류시간 69/3600 veh·h였다. 미래 차량이나 미래 경계를 입력하지 않았다.
- 알려진 S행 차량 2대가 각각 2·3차로에 있었다. 기존 nominal 서비스 1400 veh/h를 이용한 국소 시험에서 각각 0.388889대만 옆 차로로 이동했고, 차량 보존을 유지했다.
- 기존 7개 핵심 파일·망·expanded036 기준값의 SHA가 이전 검증과 같았다. `verification.json`, `tests.log`, 실행 소스 보관본 참조.

초기 목적지가 관측되지 않은 차량은 현재 차로의 직진/북행 연결로 근사했다. 이것은 숨겨진 실제 목적지를 복원한 것이 아니다. 서비스 1400 veh/h와 도시 자유속도 50 km/h도 기존 `parameters.py` 값으로 실시한 구조 시험이며, 새로 보정한 계수가 아니다.

## 연결 전에 남은 일

1. 기존 도시 소유 재고·이동 버퍼에서 127 접근로로 차량을 한 번만 옮기고, 129 및 두 포트의 서로 다른 진입 위치를 반영한다. 이미 정지선을 지난 10695 차량을 접근로 큐에 되넣지 않는다.
2. 도시 입력의 램프행과 정지선행을 보존하고, 상류 static route가 아직 유효한 차량에 하류 1117 선택률을 다시 적용하지 않는다. 원격 망과 관측 목적지 비율이 다르므로 원격 비율을 복사하지 않는다.
3. 실제 포트 배수와 공통 정지선 방출을 연결한다. Ω 내부 이동은 유출로 세지 않고, N_P의 진출램프 유입을 도시 경계 유입으로 다시 세지 않는다. 대기 비용은 기존 Ω TTT에 한 번만 포함한다.
4. 기존 RM 유지/완화와 VSL 기록의 소수 450초 상태, 독립 seed를 비교해 배수·재고·대기 비용·큰 손익 방향을 확인한 뒤 채택한다. 현재 결과만으로 포화율이나 회복 계수를 추가 탐색하지 않는다.

이번 구성요소 작업의 새 VISSIM 런·전체 망 예측·계수 보정·FZP 재스캔은 모두 0회다. 순이득 보정과 SDMPC 최종 검증은 미완료다.
