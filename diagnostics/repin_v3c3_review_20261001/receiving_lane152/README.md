## 같은 수용식도 실제 재고에서 반응이 나타난다

동결132의 실제 적용 FD로 셀21의 수용식을 계산했다. 차로당 최대 처리량2380.410대/h, 후방파 속도17.389km/h다. `min(Q,w*(rhojam-rho),잔여저장/dt)`를 변경하지 않았다. 실측5초 시작 상태를 넣은 적분과 양끝 사다리꼴 적분은 원인 분리 계산이며 자율 예측 입력이 아니다.
