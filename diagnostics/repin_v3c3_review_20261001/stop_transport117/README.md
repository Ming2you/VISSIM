# VSL 손익 보정 복귀: 정지 차량의 수송 가정 한 가지 검사

2026-10-03. 사용자 지시로 9000초 결과 분석을 중단했다(`../loss_onset116/README.md`). 기존 VSL 비교 자료와114의 정지·재출발 보조식에서 이어갔다. 새 VISSIM·FZP 추출·9000초 분석·계수 격자·push는 없다. **보정 후보는 불채택, 전체 목표는 ACTIVE / NOT_QUALIFIED**다.

## 무엇을 바꿔 시험했나

기존 보조식은 정지 차량도 모든 차량과 같은 비율 `B/N`로 다음 셀에 수송했다. 정지 재고의 지속·해소가 지나치게 빠른지 분리하려고, 발생/재출발 계수는114 값으로 고정하고 수송식만 바꿨다. 정본 물리 유량에는 아직 연결하지 않은 진단용 보조 상태다.

```
q_B = clip(q × (B/N) × v_B/max(v,v_B),
           max(0,q−N+B), min(q,B))
```

q는 이미 보존식을 만족한 전체 방출 대수, B는 재출발·정지 전이 직후의 정지 표지 재고다. 유출은 같은 비율로 내부/진출 경계에 배분하고 인접 셀로 보존 전달한다. 하한은 이동 차량만으로 전체 방출을 감당할 수 없을 때의 표지 회계 경계이며 추가 유량을 만들지 않는다. 표지 이동 속도 `v_B=1.95829km/h`는 **학습 seed29의 정지 표본 2,634개 평균**으로 한 번 계산했다. 새 발생/회복률 적합, 명령·시각·seed별 보너스는 없다.

이것은 두 집단의 속도 가중 수송 가설이다. Zhou 논문의 원식을 구현했다고 주장하지 않는다. 기존 문헌·Claude 검토를 재사용했고, Zhou 저자 연구실의 공개 목록에서도 재현 가능한 본문 수식을 추가로 확보하지 못했다. 앞선 단순 합류 속도 혼합·국소 회복 계수 후보의 실패도 다시 확인했으며 같은 격자는 재실행하지 않았다.

## 조건부 검사와 자율 검사의 구분

우선 기존29/43/67 캐시에서 다음 본선 표본을 찾을 수 있는 차량만 사용해 **수송 부분**을 분리했다. 이 단계는 실측 다음 상태의 정지 여부를 사용하므로 자율 예측 성능이 아니다. 끝 프레임을 못 찾은 차량은 검열하고, 정지·재출발로 임의 분류하지 않았다. 수송 L1 오차는43에서66.35%,67에서70.14% 감소했다. 이 근거로만 고정 계수의 자율450초 검사4회를 진행했다.

기존113의 `passive.py`를 그대로 읽어 정확히 한 수송 표현식만 메모리에서 바꿨다(`transport_candidate.patch`). 원 파일·runner·adapter를 복제하거나 변경하지 않았다. 예측 시작 시점의 실제 정지 재고만 초기화하고, 이후 미래 실측 상태를 입력하지 않았다. 평가43/67은 이전에 본 자료이며 blind 검증이 아니다.

| seed67, VSL90−110 | 실측 평균 정지 차량 차이 | 기존114 | 수송 수정 |
|---|---:|---:|---:|
| 150–300초 | −11.13대 | −1.59대 | −1.64대 |
| 300–450초 | −30.33대 | −5.29대 | −5.50대 |

큰 VSL 반응의 오차 감소는 각각 **0.55%, 0.83%**에 그쳤다. 43의 평균 정지 재고 RMSE는7.957→7.921대,67은8.093→8.257대로 변했다. 단순 수송 가정의 오류만으로 놓친 VSL 반응을 설명하지 못한다. 사전 기준인 두 큰 반응 오차20% 개선을 통과하지 못해 후보를 채택하지 않았다. 작은 절대 오차 개선을 이유로 계수를 더 탐색하지 않는다.

## TTT와 물리 검증

보조 상태를 물리 속도·유량에 되먹임하지 않았으므로 **이번 시험에서 TTT가 개선됐다고 말할 수 없다.** 이 결과를 SDMPC 비용 보너스나 강한 lane-drop으로 바꾸지도 않는다. 이득 예측 완료가 아니다.

- 4회450초 예측의 실제 물리 계산6.86초, 호출 전후 처리 포함8.26초.
- seed67의 cells/flows/ports/ramps가 기존111 기준 예측과 정확히 같았다.43의 세150초 거시 지표도 동일했다.
- 보조 표지 보존 오차 최대7.11e−15대. 음수나 실제 차량 재고를 넘는 값 없음.
- 초기 재고 일치, 생산9파일·이전 helper·기존 STOP 해시 보존 확인.

다음 보정에서 같은 수송 가정을 다시 훑지 않는다. 원래 과제인 **진출·합류 접근 교통이 만드는 정지 발생/해소와 실제150초 방출 변화**의 연결로 돌아간다. 실제로 나간 차량 수를 진출 희망 수요로 쓰거나, VSL 명령별 회복 보너스로 반응을 만들어내지 않는다. 속도 전부를 맞추는 대신 큰 ΔTTT·잔여 재고·제어 순위를 검증하는 기준을 유지한다.
