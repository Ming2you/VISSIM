# 현재 플랜트의 방출 제한과 VSL 반응 분해 — REVIEW104

완료된 seed67·73, 동일 초기상태의 RM 완화 + VSL110/90 예측을 재사용했다. 예측 시작은2700초, 길이는450초다. 새 예측·보정·VISSIM·FZP 재읽기는 없다. REVIEW103은 실제 보정 시험과 검증을 완료했으므로 이전 목표 작업은 PROGRESS다. 이번 작업도 기존 코드의 방출 제한 위치를 새로 검증한 PROGRESS다.

## 확인한 내용

- 진출 분기가 없는 셀16·17·19·21–25의 두 seed×두 조건×세 구간, 총96개 통과량은 기록된 `Σ rho(t) × v(t) × lanes / 3600`과 일치했다. 최대 차이는 1.02e-12대였다. 경로 송출·수용 제한은 이 잠재유량을 줄이는 구조이므로, 이 비교에서는 상한이 실제 통과량을 더 줄이지 않았다. 셀18·20은 진출 분기 때문에 이 동등성 검사에서 제외했다.
- 따라서 이 기록의 부족한 통과량을 하류 수용 상한만 높여 고칠 근거는 없다. 수용 모델이 다른 상태에서도 불필요하다는 뜻은 아니다.
- 18,000개 속도 갱신의 연속성이 정확히 일치했다. 120개 구간 속도 변화는 relaxation + convection + anticipation − lane-drop + clipping + 후처리의 합과 최대 2.06e-13km/h 이내로 일치했다. 현재 생산 코드와 동결 실행본은 수정하지 않았다.

## 다음 작업에서 제외할 것과 남은 문제

Claude의 S_STRUCTURE는 다른 기하의 off-ramp 배수 부족과 전체 단면 FIFO를 설명했다. 우리 망에서 그 원인이 똑같다고 가정하지 않고 현재 실행 유량으로 확인했다. 현재 검사의 셀21–25에는 그와 같은 추가 유량 억제가 없다.

REVIEW94는 계수 전달 오류를 배제했고, REVIEW103은 초기 도착시각 수정만으로 이득 부호를 회복하지 못했다. 연결 FD·회복 tau/nu·lane_joint67·lane_dn67·joint_lane_25·lane_rec 계열은 이미 검증 또는 기각되어 다시 격자 탐색하지 않는다. 현재 필요한 것은 셀18–20의 혼잡 형성과 목적지/차로별 방출 반응을 현재 모델에서 설명하는 것이며, 셀24·25만 빠르게 풀리도록 다시 맞추는 것은 우선순위에서 제외한다. 기존 lane 모델의 모멘트 수송도 이미 구현되어 있으므로 새 방법으로 간주해 반복하지 않는다.

이 진단은 새 모델 채택이나 제어 이득 검증 통과가 아니다. 본선·램프·도시 전체 대기와 ΔΩ TTT 검증, SDMPC 선택 검증,9000초 완료 비교는 여전히 남아 있다. 진행 중인 데이터9000 런을 이득 검증 대신 사용하지 않는다.

## 재현 및 한계

기존 helper `s67_policy_response81/assess_flow82.py --discharge104`에 진단을 추가했다. 기존15개 함수 AST, 생산 파일9개와 기존 STOP은 동일하다. 입력 해시와 검사는 `protocol.json`, `completion.json`에 남겼다. `flow_identities.json`, `flow_response.json`, `speed_terms.json`, `speed_response.json`이 계산 결과다.

실측 셀 통과량은 native 경계 사건과 셀 재고의 차량 보존식으로 재구성한 값이며, 모든 셀에 독립 계측기가 있는 것은 아니다. 이 분석은 확인한 두 상태·두 명령에 한정한다. 새로운 미래 실측 입력은 쓰지 않았다. 여러 항의 합은 상쇄되므로 항별 누적값을 제거 실험의 결과로 해석하지 않는다.
