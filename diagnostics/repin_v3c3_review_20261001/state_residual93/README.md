# 현재 상태에 따른 속도식 잔차 보정 — REVIEW93

2026-10-03. **셀19·20 후보 하나를 보정하고 자율450초 예측2회를 완료했으며, 손익 방향 악화로 기각했다.** 운용 plant는 변경하지 않았다. 새 VISSIM·FZP 읽기·push는 없다. 전체 목표 ACTIVE / NOT_QUALIFIED.

## 기존 검사와 이번 차이

REVIEW92의 차로·공간 요약변수 추가는 평균 상태 대비 개선이 작았다. 과거 `freeway_first/past_residual`의 직전30초 평균 오차를 일정하게 더하는 방식도 이미 실패했다. 이번에는 그 후보들을 반복하지 않고, 현재 평균 상태에 따라 달라지는 잔차를 무제어 자료에서만 학습했다.

셀19·20 각각에 ridge 회귀 하나를 사용했다. 입력은 현재 자기·상하류 밀도와 속도, 자기 밀도 제곱과 밀도×속도, 같은 상태에서 실제 FW_E 구성의110 기준 속도식이 주는1초 변화량이다. seed29 무제어 자료만 적합에 사용했다. 표준화·절편·ridge1을 고정했으며 seed43·67 결과를 보고 변수나 가중치를 다시 고르지 않았다. 시간·seed·RM/VSL 조건명·미래 경계는 입력에 없다.

학습 목표는 다음과 같다.

    R(x) ≈ [v_native(t+30) − v_native(t)] / 30 − F_nominal110(x)
    v_next = canonical_speed_update(x, actual_control) + dt_seconds × R(x)

이때 R은 현재 상태가 같으면 명령과 무관하게 같다. 기존 VSL 이력과 희망속도, 합류 감속, 동적 차로 감소와 진출부 방출 제약은 유지한다. 보정은 기존 속도식 다음, 기존 합류·진출 제약 적용 이전에 들어간다. 차량을 만들거나 제거하지 않고, 실제 accepted flow와 모든 램프·도시 대기를 그대로 계산한다. 속도 범위는 해당 셀의 기존 최소·자유속도로 제한한다.

**30초 평균 변화와 순간1초 변화는 다른 시간 연산자다.** 이 후보는 그 차이를 포함한 경험적 근사이며, 단기 회귀 성공만으로 동역학의 정확성을 주장하지 않는다. 실제450초 반복 적용 검사를 필수로 두었다.

## 자율450초 결과: 기각

기존 seed67의2700초 동일 초기 상태에서 RM완화·native 도시 신호를 유지하고 VSL110/90을 비교했다. 원래 명령3블록·네트워크·수요 예측·목적함수·관측 초기화를 그대로 재사용했다. 예측에는 실제 미래 자료를 넣지 않았다.

| VSL90−110 | 실제 | 기존 plant | 이번 보정 |
|---|---:|---:|---:|
| Ω TTT [대·시간] |−2.065|−0.0488|**+0.2576**|
| 동측 본선 종단 유출 [대] |+25|+3.8218|**−6.5424**|

음의 TTT는 개선이다. 보정 후 TTT 효과 오차가15.20%, 종단 유출 효과 오차가48.94% 커졌고 손익 방향까지 바뀌었다. 두 오차를 각각20% 이상 줄여야 한다는 사전 기준을 통과하지 못했다. 다른 계수·잔차 배율·창 크기를 훑지 않았고, 추가 seed/SDMPC/9000초 실행으로 확장하지 않았다.

각 실행에서450×2셀=900번, 두 실행 합계1,800번 속도가 실제로 변경됐다. 속도 projection은0회이며, 모든 입력은 각 학습 변수의 최소·최대 범위 안에 있었다. 이 범위 검사는 다변량 학습 분포 내부라는 보장은 아니다. 보정량은 평균−1.566/−1.438km/h/s였다. 단순히 보정이 전달되지 않았거나 속도 clipping에 가려진 결과는 아니다.

전체 재고 수지 최대 잔차는7.25e−9대 미만,8개 off-ramp 수지는8.18e−14대 미만이었다. 초기 상태·명령은 기존 비교와 정확히 같고, 액추에이터와 세 제어 구간 실행 검사를 통과했다. 각 상태에서 잔차가 원래 속도 갱신에 더해졌다는 산술 오차는3.56e−15km/h 미만이다. 두 실행의 동일 초기 상태에서는 잔차도 정확히 같았다.

## 진단 코드의 실패와 수정

첫 시도는 전체 망 설정과 도로별 물리 설정이 같은 Python 객체라는 잘못된 검사에서 멈췄다. 보정된 물리 갱신은0회였다. 두 번째 시도는 기존 회귀계수를 실제 도로별 구성에 재사용하려다 정상방정식 검사를 실패했다. 전체 망 구성과 실제 FW_E 구성에는 물리 계수 차이가 있었다. 이 두 시도의 단기 점수는 채택 근거로 쓰지 않는다.

세 번째 시도에서는 같은 사전 회귀 설계로 실제 FW_E 구성을 사용해 다시 적합했다. 전체 망 기준의 잘못된 적합2회와 유효 적합2회를 구분해 남겼다. `config_comparison.json`과 `nominal_equation_comparison.json`은 그 차이를 기록한다. 이것은 이번 새 진단의 참조 설정 오류이며, 기존 운영 런이 잘못된 계수를 사용했다는 증거로 일반화하지 않는다.

기존 속도식 관찰기의 원식 검사를 유지하기 위해 잔차 hook은 관찰기 바깥에 연결했다. 기존 식 자체와 추가 잔차를 각각 검증했다. 첫 두 실패 로그·출력은 보존했으며, 재시도 루프는 만들지 않았다. 실행 세션74234·19681은EXIT1, 실제 완료 세션61336은EXIT0이다. 정상 예측2회의 계산 시간 합계는52.14초다. 현재 이 작업의 소유 계산은 남아 있지 않다.

## 판단과 남은 일

현재 평균 상태로 다음30초 변화가 어느 정도 설명된다고 해서, 그 잔차를1초 속도식에 누적하면 제어 효과까지 재현되는 것은 아니었다. 이 제한된 잔차 후보를 운용 모델에 넣지 않는다. 모든 상태 의존 보정이나 학습 모델이 불가능하다는 결론도 아니다.

Claude의 다른 망에서 얻은 VSL 해석을 일반화하지 않는 원칙은 유지한다. 실제 VSL 이득67 RM완화, 손해67 선택 명령, 독립71의 순위 실패를 함께 보존한다. 이후 후보는 단기 속도 fitting만 통과해서는 안 되며, 결합된 재고·속도 전이와 방출 시각, 대기 비용, 큰 손익 방향을 자율 예측에서 설명해야 한다. 같은 단기 잔차·창·회귀 가중치 탐색은 반복하지 않는다.
