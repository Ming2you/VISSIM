# 공유 접근로의 잔량 감도 보존 — 2026-10-02

앞선 턴은 진행이었다. 독립 수치차분으로 녹색/offset의 차이를 구분했고, 기록 상태와 작은 사례에서 잔량 정리 중 감도 유실을 확인했다. 이번에는 그 잔량 처리 오류를 정본 SharedSignalApproach에서 수정했다.

## 변경

일반 숫자 차량 0대는 기존대로 생략한다. 활성 미분을 가진 0대/작은 잔량은 입구 수신과 큐 정리에서 보존하고, 이동 시간이 지난 뒤 유효한 녹색·하류 여유가 있을 때 같은 목적지로 방출한다. 0대 묶음은 다른 목적지의 실제 차량을 막지 않으며, 한 번 전송한 묶음은 제거하므로 0/0 배분이나 무한 반복을 만들지 않는다. 차로 이동 뒤에도 재고 감도를 보존한다.

변경은 기존 lane_offramp_runtime.py의 SharedSignalApproach 안에 있다. 새 adapter, 계수, 용량 보너스, 목적함수 또는 허용 명령 변경은 없다.

## 확인

- 수정 전: 20개 시험 중 새 4개 시험의 forward/reverse 8개 하위 사례가 실패했다.
- 수정 후: 관련 미분·접근로·영역 회계 시험 **87개 통과**.
- 일반 숫자 비교: 24조건×120초, **2,880개 스텝의 모든 접근로 상태와 방출 내역이 수정 전과 정확히 일치**했다. 적색·하류 막힘·공유 방출·차로 이동을 포함한다.
- 실제 seed47@2700의 450초 AD 한 번을 완료했다(62.19초). 수정 전 20개 비용·N_P·N_UF 값과 최대 차이 0이다.
- 이전에 포착한 접근로 재고/보존 감도 불일치가 이번 계측에서는 0개이고 기록 누락도 0이다. 원래 모든 내부 상태의 전체 감도를 인증했다는 의미는 아니다.

## 남은 오차와 다음 시험

**offset 전체 감도는 여전히 실패다.** Ω 합산 기울기는 변하지 않았지만 주체별 비용의 최대 오차는 정규화 좌표 기준 약3.58에서6.13으로 커졌다. N_UF 감도 차이 약45.68도 남았다. 정규화 좌표는 offset150초 척도이므로 초당 N_UF 차이는 약0.3045veh/h다. 질량 감도 보존 한 곳을 고친 것이 하류 전체 미분을 고친 것은 아니다. 이 결과를 감추거나 계수 보정으로 덮지 않았다.

계산을 완전한 미분 인증에만 묶어두지 않고, 기존 제한(PFO2/SDMPC2회)의 **오프라인 선택 한 번**을 별도 진단으로 진행한다. 후보를 실제 일반 수치 예측으로 재평가하는 기존 line search는 유지한다. 새 PFO 상한, 선택한 RM/VSL/도시 명령, 독립 canonical 재생의 비용·제약을 확인한다. offset 미통과와 물리 이득 검증 한계는 계속 표시하며, 이 선택은 native 적용 또는9000초 자격 판정이 아니다.
