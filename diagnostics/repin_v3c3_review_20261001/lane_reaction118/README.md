# VSL 반응 보정 — 차로 평균화의 영향 한 가지 검사

2026-10-03. **조건부 진단 완료, 후보 미채택. VSL 손익 보정은 미완료**다.
사용자 지시대로9000초 결과 분석은 재개하지 않았다. 기존 짧은29·43·67 비교 캐시만 사용했다. 새 VISSIM, FZP 추출, 계수 fitting, 자율 예측, push는 없다.

## 검토한 원인과 변경

Claude의 보관 worklog와 기존108 결과를 먼저 확인했다. 관측한10483 진출 집단은 이미 목적 차로에 정렬돼 있었고, 목적 차로 유지 후보도 VSL 반응을 개선하지 못했다. 따라서 같은 접근 정렬 후보를 다시 만들지 않았다.

이번에는 **셀 평균으로 정지·재출발을 계산하면, 막힌 차로와 흐르는 차로를 섞어서 반응을 놓치는지** 확인했다.114의 동일한 두 반응률 계수와 식을 그대로 사용하고, 입력을 셀 평균에서 차로별 밀도·속도·하류 정지 비율로 바꾸었다. 차로별 결과를 다시 합산한다. 수송 수정117, 계수 재탐색, VSL 전용 보상은 적용하지 않았다.

대상은31개 물리 셀의0기준19·20, 하류 참조는20·21이다. 이 경계들의 차로 번호는3차로로 연속이다.18→19의4차로→3차로 연결을 같은 번호로 잘못 대응하지 않도록 제외했다. 셀19에 포함된10613의 차로 번호는119와 대응하며, 목적 차로 판정에 사용했던108의 기하 확인을 재사용했다.

입력은 매5초의 **현재 실제 상태**이고, 다음5초의 정지/재출발을 비교했다. 다음 본선 관측이 있는 차량은 셀·차로를 옮겨도 포함했다. 관측이 사라진1.85–2.78%는 정지·재출발로 가정하지 않고 제외했다. 진출 차량의 라벨 누락이 포함되므로 이 전이 집계는 전체 차량의 완전한 대기 수지나 방출량이 아니다. 예측 중 미래 관측을 제공한 자율 모델 성능으로 해석하지 않는다.
