# Off-ramp 먼저 정합: 목적지 보존 후보와 8개 물리 출구

2026-10-02. **6회 예측 완료 / off-ramp 정합 미완료 / 전체 목표 ACTIVE·NOT_QUALIFIED.**

사용자 우선순위는 **8개 off-ramp 본선 진출·램프 배수·재고 정합 → 필요한 셀의 재보정 → 공통 초기 상태에서 NC/RM/VSL/둘 다 손익·순위 → 다른 상태·seed 확인**이다. 잘못된 출구 배분을 셀 속도 계수로 보상하지 않는다. 미래 진출 실측을 운영 예측의 경계로 고정하는 것도 아니다.

## 이번에 바꾼 범위

현재 SC105 후보에 기존의 pin된 목적지 재고 계약 한 개만 연결한 별도 검토 후보다. 초기 관측 경로는 보존하고 미래 선택은 망의 경로 비율을 사용한다. 미래 실측은 평가에만 사용했다. 현재 기본 후보·VISSIM 망·수요·물리 계수는 변경하지 않았다.

기존 진단 driver의 `probe_levers`에 8개 물리 포트의 초기/150/300/450초 재고·누적 진입·누적 배수와 매초 sending/receiving 자원 기록을 추가했다. 이전 집계에서 경로 이름에 합쳐져 구분하지 못했던 신호 분기 3개의 실제 모델 배수도 이제 분리했다. 별도 runner/adapter는 만들지 않았다.

seed47@2700 유지/도시 선택 2회와 seed43@2250 NC/RM/VSL/둘 다 4회, 각각 자율450초가 완료됐다. 계산시간 합155.878초이며 최적화 iteration은0이다. 새 VISSIM·FZP 재스캔·계수 fitting·push0회. 이전에 사용한 상태/seed 재검증이고 새 맹검은 아니다.

**모든6조건×8출구의 매초450 sending 기록에서 요청 진출량=수락 진출량이었다.** 따라서 이 예측들의 진출 부족은 추가 포트 receiving 절단에서 발생하지 않았다. 이는 실제 VISSIM에 차로/수용 제약이 없다는 뜻도, 다른 상태에서 저장 제약이 활성화되지 않는다는 뜻도 아니다.

서측10638은 독립적으로 봤던 seed43 NC에서도 실측100대 대 예측45.86대로 부족하다. 이 구간은 종료 포트 재고도 실측4대 대1.24대로 작다. 같은 seed43 서측 본선 입력은520대 대492대, 말단 유출은482대 대524.76대다. 입력 부족과 통과/진출 배분·이동시각 문제를 함께 분리해야 하며, 배수 상한을 올리거나 본선 모든 속도를 낮춰 출구량만 맞출 근거는 아니다.

10643은 seed47에서 배수94대 대67.47대, 종료재고15대 대25.81대로 배수가 느리다. 하지만 seed43 NC에서는 배수67대 대74.38대, 종료재고11대 대1.69대로 반대다. 일률적인 배수율 증가를 채택할 근거가 없다. 실제 신호 서비스·도착 시각·공유 접근로 재고를 상태별로 확인해야 한다.

## 검증 범위와 한계

- 6회 모두 동일 초기 물리 재고를 조건 간 유지했다. seed43 셀 상태·8포트 초기값, seed47 이전 static 명령표가 일치한다.
- 8포트 보존 최대2.27e−13대, 목적지별/물리 셀 재고 일치 최대2.12e−12대, 추출한 진출 sending/receiving 자원 초과0이다.
- seed47 진출량은 이전 검지기 위치 보정 결과를 재사용했고 배수는 재고 보존식으로 추론했다. 독립 출구 검지의 직접 관측으로 부르지 않는다.
- seed43은 기존30초 cache의2250.1–2700.1초 자료이고 모델은2250–2700초다. 미확인 사라짐0, 시간 위상0.1초 차이는 남긴다.
- 이번 trace의 `route_runtime=null/route_states=[]`는 진단 guard가 전체 cfg만 보고 per-road cfg를 보지 못한 기록 누락이다. 실제 활성화는 runtime.json의 enabled/source SHA/초기 경로 재고와 각 결과의6개 도로별 보존 검사로 확인했다. 세부 매초 목적지 구성을 이 trace에서 확인했다고 주장하지 않는다. 이 메타데이터만 채우려고6회 예측을 반복하지 않았다.
- 첫 사후검사는 selected 명령의 별도 validation schema를 처리하지 못해 KeyError로 중단했다. 보고 검사만 수정한 재실행은 통과했다. 두 로그를 보존했고 예측은 재실행하지 않았다.
