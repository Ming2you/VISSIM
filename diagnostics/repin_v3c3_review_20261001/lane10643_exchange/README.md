# 10643 자유 차로 이동: 한 계수 후보 평가 및 미채택

완료 상태: 2개 seed의 6조건 계산 완료. **후보 미채택**, 생산 코드는 시험 전 retained10638 버전으로 정확히 복원했다. 기존 경로 전달 수정은 유지했다. 현 목표는 ACTIVE/NOT_QUALIFIED다.

## 무엇을 시험했는가

- 학습: seed47 예측 시작 전 2550.1–2695.1초. 목적지가 확인된 10635행의 4↔5차로 이동만 사용했다. 관측 사건 3건 / 노출 635 veh·s = 0.0047244094/s, 공통 계수 1개. 5초 표본의 적은 사건이므로 추정 불확실성이 크다.
- 기존 유한 차로 이동 계산에 이 공통률을 명시적으로 연결했다. 필수 차로 변경·신호·FD·수요·경로·제어 명령·비용 정의는 유지했다. 미래 궤적을 자율 예측 입력으로 쓰지 않았다.
- 47 유지/도시 선택과 독립 seed43 NC/RM/VSL/둘 다, 동일 450초와 명령을 사용했다. 예측 시작 재고는 본선31셀·8off-ramp·국소차로 모두 이전과 정확히 같았다.
- 신규 계약 시험5개 및 기존 수용/차량보존 시험4개 통과. 실제 계산의 수용량 장부에서 4↔5차로 이동량을 확인했다. 설정이 켜졌다는 것만으로 실행 판정하지 않았다.
