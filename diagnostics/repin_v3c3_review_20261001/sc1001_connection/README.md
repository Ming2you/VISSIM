# SC1001 배수–접근로–공유 정지선 연결 시험

2026-10-02. **경계 연결 개선 확인 / 순이득 보정·생산 채택 미완료.** 이전 턴은 구성요소와 증거 보존의 진전이었고, 이번에는 기존 정본 초기화·도시 갱신·진출램프 갱신 경로에 연결한 후보를 실제 기록 상태로 예측했다.

## 무엇을 바꿨나

`urban.shared_sc1001_approach=boundary_only_v1`를 명시한 후보에서만 다음 연결을 사용한다. 기존 운영 설정과 METANET 계수는 변경하지 않았다. 새 adapter나 native runner는 만들지 않았다.

- 10491/10481 커넥터 배수는 하류 신호가 아니라 유한 접근로 공간과 기존 nominal 차로 서비스율을 받는다. 받은 차량은 이동 준비시간과 정지선 대기를 거쳐 배출된다. 미래 포트 유입은 예측된 본선 유량이며 실측 미래 유입을 넣지 않았다.
- 도시 차량과 두 포트의 차량이 127의 세 차로 서비스를 공유한다. 일반 movement 루프는 이 도시 신호를 다시 서비스하지 않는다.
- 현재 127/10777의 69대는 기존 큐·저류에서 공유 접근로로 한 번만 옮겼다. 10695에서 기존 도시 상류 저류에 섞였던 2대는 이미 정지선을 지난 하류 소유로 옮겼다. 기존 상류 저류에서 52대를 빼고 156대와 그 이동 예약을 보존했다.
- Ω 비용은 기존 storage 장부에서 한 번 계산한다. 포트→접근로 이동은 Ω 유출 사건이 아니다. 포트 배수는 기존 off-ramp movement 종류로 N_P에 한 번 계상하고, 그 차량이 나중에 공통 정지선을 지날 때는 내부 전이 키를 사용한다. 실제 17개 도시 주체의 집계 함수로 확인했다.

물리 경계 수정의 효과를 분리하기 위해 기존 상류 도시 이동시간과 미래 목적지 비율은 유지했다. 따라서 이전에 확인한 잘못된 미래 목적지 비율까지 수정한 최종 모델은 아니다. 접근로는 공간을 예약하는 차로별 이동·큐 모형으로, 129/127의 모든 실제 위치와 gap을 재현하는 모형도 아니다. 차로 서비스율 1400 veh/h와 속도 50 km/h는 기존 nominal 값이며 재보정하지 않았다.

## 아직 통과하지 못한 부분

공유 접근로 종료 재고는 모델95.62대와 실제127/10777의90대다. 그러나 기록이 충분한 2700–3140초 정지선 통과량은 실측5초 궤적의 **180–186대 구간**에 비해 모델 **130.28대**다. 따라서 최종 재고가 가까워도 도착·방출 오차가 상쇄됐을 수 있다. 다음 서비스 보정은 과거 관측의 실제 녹색/황색 노출과 준비 큐를 확인한 뒤 제한적으로 해야 하며, 이 결과 하나에 맞춰 서비스율을 임의로 키우지 않는다.

초기 69대 중 도시/포트 출처를 현재 모형 관측에서 구분하지 못한 차량이58대다. 이들은 기존 도시 유입 해석을 상한으로 유지하고 별도로 표시했다. N_P를 확정하려면 과거 출처 이력 또는 불확실성 처리가 필요하다. 미래 포트 차량의 이중 집계는 해결했지만 이 초기 출처 문제까지 해결됐다고 주장하지 않는다. 후보의 N_P 총량은 유지531.455 / 완화530.432대로 산출됐으며, 기존 목표에 대한 새로운 실행 가능성이나 SDMPC 선택은 아직 검증하지 않았다.

- 구조·장부·N_P 전이 시험16개 통과. 합성 1초 자동미분 확인은 유지했으나 전체 연결의 미분 검증은 아직 하지 않았다.
