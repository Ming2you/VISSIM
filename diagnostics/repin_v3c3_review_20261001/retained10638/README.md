# 경로 유지 수정과 off-ramp 우선 보정 — 2026-10-02

현재 상태: 경로 전달 오류 수정 및 6조건 검증 완료. **이득 예측 보정은 미완료**이며 운영 기본값이나 9000초 실행으로 승격하지 않았다. 이 문서는 완료된 계산을 정리하며 새 계산이나 VISSIM 실행을 뜻하지 않는다.

## 수정한 것

- 본선 목적지 재고의 활성 경로 표지를 실제 수락된 진출 차량량과 함께 off-ramp로 전달했다. 10638을 지나도 유효한 1133:2 경로와 이미 끝난 경로를 구분한다.
- 활성 경로를 1140 decision에서 다시 1/3씩 배분하던 처리를 고쳤다. 미배정 차량은 기존의 다음 ALL connector 규칙을 사용하며, 실제 하류 수락 전까지 기존 저장고를 차지한다.
- 기존 continuation 옵션만 이 진단 후보에서 활성화했다. 미래 실측, 추가 차량, 서비스·FD·METANET 계수 변경은 없다. 램프/도시 대기 비용과 유한 수용 공간을 유지했다.
- 기존 옵션이 꺼진 설정의 경로를 보존했다. 첫 초기화 실패는 run47.log와 원 출력 폴더에 남겼고, 실패한 시도는 완료 예측 수에 포함하지 않았다.

## 다음 작업 순서와 종료 기준

1. 8개 off-ramp별 진입·배수·재고와 누적 수지를 먼저 확인한다. 총 진출량 일치만으로 통과시키지 않는다. 10643의 하류 126/71 차로 활용과 경로별 공급을 우선 분리하고, 10682 등 독립 seed의 진입 오차도 유지한다.
2. 필요한 경우 실측 경계를 사용한 조건부 셀 진단으로 유량 오차의 전파와 셀 자체 속도·회복 오차를 분리한다. 이 결과는 자율 예측 성능으로 보고하지 않는다.
3. 경계 오류를 줄인 뒤 오차가 남는 셀/같은 성격의 짧은 구간에만 소수 계수를 재보정한다. 혼잡 발생·상류 전파·방출·회복과 차량 보존을 함께 확인하고, 개선 근거 없는 독립 셀 계수 격자는 반복하지 않는다.
4. 동일 초기 상태 NC/RM/VSL/둘 다에서 실제 합류량·방출량·전체 Ω TTT와 외부 대기 진단을 비교한다. 별도 상태/seed에서도 큰 손익과 순위가 맞아야 SDMPC 선택 검증으로 넘어간다.

완벽한 궤적 일치나 작은 이득의 부호까지 맞추는 것은 완료 기준이 아니다. 잘못된 경계유량을 셀 계수가 보상하지 않고, 중요한 제어 손익을 안정적으로 구분하는 것이 기준이다. 기존 9000초 STOP을 유지했다.
