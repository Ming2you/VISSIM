## 근거와 시험 범위

Lu et al., *METANET Model Improvement for Traffic Control*, IEEE ITSC2011, p.2151 식4.8/4.10을 저자 원문 PDF와 페이지 이미지로 확인했다.

원문: https://horowitz.me.berkeley.edu/Publications_files/All_papers_numbered/Lu_Metanet_improvement_TC_IEEE_ITSC_2011.pdf

기존 대류항 `T/L · v · (v_up−v)` 대신 아래 두 식만 검토했다. T는시간[h], L은거리[km], v는속도[km/h]다.

- 식4.8: `T/L · v · (sqrt(v_up*v)−v)`
- 식4.10: `T/L · v_up · (sqrt((v_up²+v²)/2)−v)`

원 논문의 전체 모형이나 현장 재보정을 재현한 시험은 아니다. 우리 모델의 FD·이완·anticipation·합류 감속·기존 속도 상한은 유지하고, **대류항의 수식만** 바꿨다. 원 논문은 대류항 대안을 제시하고 현장 자료로 보정하지만, 우리 망의 VSL 이득을 보증하지 않는다.

기존133의 실제 허용 유량 기반 모멘트 수송 실패,162의 상류 속도와 하류 밀도 결합 오차,163/164의 결과, Claude P_PLANT의 상류 경계 속도 주의, 완료된 native_distribution_split의 평균/분포 형태 실험을 먼저 확인했다. 분포 폭 축소를 무조건 이득으로 만드는 항이나 새 capacity 보너스는 없다.
