# 링크66 큐·도착 정합 시험 — REVIEW59

2026-10-02. **초기 배정 오류는 수정 후보에서 바로잡혔지만, 방출 및 제어 이득 개선은 미검증이다.** 기존 운영 설정에는 적용하지 않았다. 코드의 선택적 기능과 실행한 후보 설정은 다음 결합 검증을 위해 보존한다. 새 VISSIM, FZP 재스캔, 계수 fitting, push는 없었다.

## 수정 후보와 범위

기존 `observation_projection.initialize_kinematic_arrivals`에 선택적 초기화, `runtime_setup`에 호출, 기존 도시 도착 처리에 원점별 이동 시간을 연결했다. 활성화 키는 `urban.arrival.kinematic_contract`이며 `candidate_config.json`에만 추가했다. 망, 수요, 신호 명령, 서비스 상한, METANET 계수는 그대로다.

- 동일한 연속 정지선 큐 정의로 차량을 식별한 뒤 현재 차로와 connector 분기 위치에 따라 배정한다.
- 현재 위치·속도로 나머지 차량의 ETA를 정한다. 현재 속도/링크 평균속도/선언된 20km/h 바닥값을 사용한 근사이며, 실제 미래 도착 시각을 사용하지 않는다.
- 원래 재고와 arrival/release 예약을 함께 보존한다. 지평 밖에 도착할 차량도 남긴다.
- 이미 다른 물리 모델이 소유한 재고, 중복 태그, 불완전 관측, 망·movement 불일치는 거부한다.
- 이동 중 미확정 목적지는 현재 차로의 접근 가능 movement 안에서 기존 비율로 나눈다. 실제 미래 경로를 재현했다고 주장하지 않는다.

seed47@2700초의 현재 링크66 차량은 175대다. 연속 큐 49대와 잔차 126대는 전후 동일하다.

## 결과: 남은 방출 상한이 더 직접적이다

450초 예측 8회(기준47 두 조건 + 후보47 두 조건 + 후보43 네 조건), 계산 합계 230.53초. 단위 시험 11개 통과. 물리 자원 초과 최대치는 약 1.78e-15로 수치 오차 수준이다. 시험 예산은 소진했으며 추가 계수 탐색을 하지 않았다.

| seed47 RM 유지, 2700–3150초 | native | 이전 | 수정 후보 |
|---|---:|---:|---:|
| N 방출 [대] | 62 | 23.751 | 23.751 |
| W 방출 [대] | 38 | 36 | 36 |
| 종료 링크66/모델 접근 재고 [대] | 160 | 233.677 | 235.583 |

native 방출은 정지선 head, 모델은 connector transfer다. 경계 사이 수 m 오프셋이 있고, E의 정지선 이전 분기 방출은 이 head 자료에 없다. 모델 접근 재고는 원점 저장·movement 큐·게이트 이동을 합한 값이다. 별도 connector 초기 재고도 있으므로 이 표를 정확한 차량별 장부 일치 또는 큐 RMSE로 해석하지 않는다.

N의 기존 서비스 상한은 3차로 합계 **619.5918367대/h**다. 450초 동안 녹색 138초를 곱하면 **23.7510204대**로, 전후 예측 방출과 정확히 같다. 이는 이 조건의 방출 제한이 도착 부족보다 서비스 상한에 걸린다는 직접 증거다. 실측 62대는 달성된 방출이지 포화용량 추정값은 아니다.

현재 `vissim_stackelberg_adapter`의 `_LG_KINDS` 기본값은 `internal`이다. `boundary_in`인 N/E가 제외되고, `signal_head_observation.install`은 대상 movement가 없으면 해당 head 그룹을 건너뛴다. W는 기존 `66|p2 → 10633` 물리 서비스 계약을 통해 따로 보정된다. N에는 현재 `66|p1` 관측이 있어도 연결되지 않는다. Claude가 지적했던 결함이 현재 링크66에서도 확인됐다.

## 제어 판단은 아직 개선되지 않았다

seed47 Ω TTT의 선택 명령−RM 유지 차이는 이전 −7.57373에서 후보 −7.57221 veh·h로 사실상 그대로다. 후보의 RM 유지 Ω TTT 자체는 약0.222 veh·h 낮아졌지만 외부 비용은 약0.223 늘었다. 전체 비용 개선으로 평가하지 않는다.

별도 seed43의 동일 초기 상태, 2250–2700초 비교:

| 조건−무제어 Ω TTT [veh·h] | native | 수정 후보 |
|---|---:|---:|
| RM | −1.54722 | −0.09590 |
| VSL | +0.77708 | −0.38201 |
| RM+VSL | −1.45347 | −0.46448 |

RM 이득 크기 부족과 VSL 부호·후보 순위 오류가 남는다. 기존 `seed43_fullplant_20260929/analysis_v2/observation_reuse.json`의 공통 제어 전 prefix 검증과 실행 검증을 재사용했다. 다른 정책으로 장시간 운행한 뒤의 상태 차이를 공통 초기 상태 효과로 사용한 것이 아니다. 이 시험은 계수 보정이 아니라 초기화·도착 후보 비교다.

## 남은 일과 채택 상태

1. Claude U4/U5와 현재 물리 head 서비스 구현을 먼저 대조하고, `66|p1 → 10631`의 실제 차로·head 소유권과 공유 예산을 확인한다. 단순히 모든 경계 용량을 높이지 않는다.
2. 10632는 정지선보다 앞에서 갈라지고 자체 head가 없다. 현재의 signal phase 귀속이 맞는지 별도로 확인한다. 이 시험에서는 바꾸지 않았다.
3. 합리적인 서비스 연결 수정과 U7 후보를 함께 검증한 뒤 채택 여부를 판단한다. 71번 도로의 차로·목적지 전파 오차는 별도 미해결 문제다.

현재 후보는 **opt-in 보존 / 운영 기본값 미채택 / 이득 미검증**이다. 전체 AD·worker·SDMPC 선택 경로, 관측 요약과 모델 초기화 복사본의 일관성은 아직 확인하지 않았다. `assessment.json`, `completion.json`에 출처·해시와 미검증 범위를 기록했다. 이전 실패 로그도 보존했다.
