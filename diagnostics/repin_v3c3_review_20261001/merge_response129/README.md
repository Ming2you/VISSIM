# REVIEW129 — 합류 계수와 진출 인접 셀의 공동 재보정

2026-10-04. **450초 조건부 물리 예측88회, 제한된 네 변수 공동 보정1회 완료. 정본 미채택, 전체 목표 ACTIVE / NOT_QUALIFIED.** 소유 세션93625 EXIT0, 계산250.838초. SDMPC 최적화 반복은0이다. 새 VISSIM·FZP 읽기·9000초 결과 분석·push는 없다. 직전128은 합류/진출 기구의 상호작용을 확인한 PROGRESS였고 이번에는 실제 계수를 함께 재보정했다.

## 왜 이전 보정과 구분했는가

128에서 셀21·23의 명시적 합류 감속을 제거하면 RM 유지의 이득을 잃었다. 반면127 공동 보정에서는 이 두 합류 계수를 고정한 채 임계밀도·이완·anticipation만 조정했다. 기존 `freeway_first/lane_fit29`는21의 합류계수 절반과19–21 FD 형상1.5배만 비교했고, 다른 조합이었다. 따라서 이번에는 기존 공유 차로124 구조를 유지하며 아래 네 공통 배율을 함께 식별했다.

1. 셀21 합류 감속계수
2. 셀23 합류 감속계수
3. 셀19–21 가속 이완시간
4. 셀19–21 임계밀도

anticipation·셀22–25 회복 계수·차로 교환율·동적 off 저장/배수·물리 수용·명령·수요 설정은 유지했다. 전 셀에 새 계수를 추가하지 않았다. 실제 합류량을 사용하며, 제어·seed·시각별 보너스는 없다.

Claude 기록에 있었던 비활성 항 검증 문제와128의 실제 항 작동 기록을 재사용했다. 다른 망의 수치·계수는 옮기지 않았다. 기존94의 정본 계수 전달 검사를 전체 공유 차로 후보의 신규 검증이라고 부르지 않고, 이번 factory에서 각 셀의 실효 FD·상태 반응 계수를 다시 대조했다.

## 식별과 자율 검증의 분리

학습은 이전에 사용한 seed29·67 후기, 각각 RM 유지/완화 × VSL110/90이다. seed67은 이미 학습 자료이며 독립 검증이 아니다. **물리 식별 중에는 관측30초 본선 진입량을 같은 구간에 균등하게 넣었다.** 미래 합류·진출·속도·차단 상태는 넣지 않았다. 모델이 받은 본선 차량 수와 이 관측 입력을 매 예측 대조했다.

이는 알려진 경계 입력에 대한 조건부 식별이며, 운영 예측의 미래 입력을 바꾸는 구현이 아니다. 통과 후보가 나오면 원래 captured 유입 예보를 쓰는 자율 학습상태8회와 다른 상태(seed43 초기4조건·seed29 초기NC)5회를 먼저 확인하도록 구현했다. 그러나 아래 학습 관문을 통과한 후보가 없어 **그13회는 시작하지 않았다.** 새로운 seed73 및 전체 Ω/SDMPC 평가는 하지 않았다.

평가 TTT는 동측31셀+4진입·4진출 커넥터의30초 재고 적분이다. 전체 Ω TTT가 아니다. `exits`는 본선→off 진입+본선 말단이며 Ω TTD나 이 TTT 영역의 외부 유출과 혼동하지 않는다.

## 정한 계산 예산과 결과

각 배율은0.7–1.3, 중앙 차분±0.1이다. 기준과8개 중앙 차분으로 Jacobian을 만든 뒤, bounded ridge 최소제곱 방향의 전체/반 단계만 평가했다. **11개 벡터×8조건=88회**다. 선형 문제의81개 경계면 계산은 교통 예측81회가 아니며, KKT 조건을 확인했다. 비선형 최적화 수렴이나 계수의 전역 최적해를 주장하지 않는다. 추가 Jacobian·범위 확대는 하지 않았다.

기존450초 및 세150초의 재고·체류·합류·방출 오차와 모든 명령쌍의 차이에 더해, 세150초의 **셀19→20, 셀20→21, 셀20→10483 방출 차이**를 평가했다. RM 차이와 VSL 차이를 모두 포함한다. 목적함수 Ω TTT 자체를 바꾼 것은 아니다.

## 다음 작업의 범위

같은 네 배율의 범위만 계속 확대하지 않는다. 다음은 기존 기록에서 **셀20 진출 요청·진출부 수용/배수·같은 차로 통과 제한 중 어느 단계가 두 VSL 조건을 거의 같게 만드는지** 직접 확인한다. 통과 회복만 개선하고 진출 반응이 남은 결과를 재사용한다. 이전108에서 실제 진출 차량의 차로 정렬을 이미 확인했고, 단순 목적지 정렬 후보는 실패했다. 이를 새 발견이나 같은 정렬 시험의 재실행으로 바꾸지 않는다. 합류 계수 공동 보정의 가능성은 남기되, 방출을 결정하는 단계의 근거 없이 또 다른 계수 탐색을 시작하지 않는다.
