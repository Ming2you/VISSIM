## 가설과 변경 범위

기존 모델의 동측 셀19·20만 다음과 같이 바꿨다.

- 초기2700초 차량의 현재 위치·현재 경로로 남은 거리를 설정한다. 미래 실현 경로·속도·유량은 읽지 않는다.
