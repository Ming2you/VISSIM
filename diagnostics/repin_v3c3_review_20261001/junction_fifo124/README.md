## 확인한 연결과 변경

기존 `RouteLaneRegion`은 진출 수용량이 부족하면 같은 차로의 직진도 줄인다. 반대로 하류 직진 수용량이 부족할 때는 진출을 먼저 독립 배분한다. 따라서10483 진출과10490 합류가 같은1차로에서2.814m 떨어진 구간에서, 직진 대기가 진출을 가로막는 상호작용은 직접 표현하지 못한다.

기존 Claude `FWW_STRUCT_PROPOSAL`의 차로별 FIFO 구분과 기존107의 실패를 확인했다. Claude 문서는 다른 망의 서측 진출·도시 배수 문제이므로 수치나 판정을 가져오지 않았다. 과거107은 셀19→20 수용 제한이었다. 이번에는 합류10490이 있는 **셀21의 수용량과 셀20의 분기 배분**을 연결했다. 셀 번호는0기준이다.

기존 `entry10682/audit.py`의 차로 시험에 선택 옵션을 추가했다. 정본 runner/adapter를 복제하지 않았다. 기존19–25 차로×목적지 재고,29에서 추정한 차로 교환율, 초기 관측, VSL 노출 이력, 동적 진출 저장·배수, 램프 대기·명령·수요·속도 계수는 유지했다. 실제 프로세스 내부 함수만 바꾸고 종료 시 복구했다.

1. **합류 셀 수용만:** 셀21 각 차로에 기존 FD의 명목 처리량 `Q=rho_crit*v_free*exp(-1/a)`와 `w=Q/(rho_jam-rho_crit)`를 사용해 `R=min(Q,w*(rho_jam-rho),물리적 여유/dt)`를 적용했다. 합류 차량도 동일 R을 사용하고, 남은 몫을 본선이 사용한다. 명령별 용량 보너스는 없다.
2. **공유 차로 연결:**10483이 연결된 셀20 1차로에만 진출과 직진의 공동 배분을 적용했다. `f=min(1,진출수용/진출요청,합류후잔여수용/직진요청)`으로 같은 차로의 두 요청을 함께 줄인다. 요청0은 해당 비율 제한을 만들지 않는다. 다른 차로는 독립이다.

완전한 같은 차로 FIFO는 구조 가설이다.2.814m 간격과 몸체 차단 관측이 이 결합을 검토할 근거는 되지만, 매순간 차량 순서·국소 차로변경까지 정확히 표현한다고 가정하지 않는다. 셀 평균 차로 상태·고정 교환율의 한계도 남아 있다.
