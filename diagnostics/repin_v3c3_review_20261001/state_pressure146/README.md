# 셀22 상태별 anticipation 보정: 조건부 개선, 자율 손익 실패

2026-10-04. **조건부 적합1회와450초 예측9회를 완료했고 후보는 기각했다.** 정본에 채택하지 않았다. 직전 목표 턴은 설명만 한 NO_PROGRESS였으며, 이번은 새 상태별 근거·후보 실행·반증까지 완료한 PROGRESS다. 목표는 ACTIVE / NOT_QUALIFIED다. 새 VISSIM, FZP 재추출,9000초 분석,push는0이다.

## 확인한 상태 차이

기존137의 실측 상태 장부와138의 `1초 속도식×5회` 결과를 재사용했다. 매5초 실제 자기·이웃 상태를 넣고 그5초 동안 밀도·이웃 속도를 고정하는 **조건부 국소 계산**이다. 차량의 유입·이탈을 갱신하는 자율 교통 예측이 아니다. 미래 평균속도는 채점에만 썼다.

셀22의 실효 임계밀도는38.439대/km/차로, 하류23은40.905다. 저장된 기본 rhoCrit와 실효 값을 섞지 않았다. 자기22는 임계 이하인데 하류23은 임계 초과이고 하류 밀도가 더 높은 상태에서 과감속이 특히 컸다.

공간 평균속도의 변화율이며 개별 운전자 가속도라고 해석하지 않는다. 셀22 자체도 혼잡한 상태와 나머지 밀도 구간의 속도식은 이번 후보에서 정확히 유지했다. 기존137의 전체 negative-gradient 계수 축소,139의 속도차 상한,145의4계수 공동 적합 실패를 읽고 같은 시험을 반복하지 않았다. Claude `03_codex_review/REVIEW_CHECK.md`의 설치·셀 인덱스 주의도 확인했다. 해당 기록에서 이번 상태 법칙을 이미 해결한 구현은 확인되지 않았다.

## 한 번만 제한해서 바꾼 부분

```
active = rho22 <= rhoCrit22
         and rho23 > rhoCrit23
         and rho23 > rho22
anticipation22 = z * original_anticipation22 if active else original_anticipation22
```

실제 rollout의 active는 **매1초 현재 예측 상태**로 판단한다. 명령·seed·절대 시각으로 보정 여부를 정하지 않는다. 압력항만 바꾸며 유량에 보너스를 더하지 않는다. 이 상태 구분은 관측에서 세운 가설이지 입증된 운전자 법칙이 아니다.

seed67 RM 완화·110만 사용해45개30초 블록·267표본의5초 변화율 오차를 적합했다. 영향받는 표본은55개다. z∈[0.1,1]의 단일 유계 적합으로 **z=0.1**, 허용 하한을 골랐다. 활성 상태에서만 ν20.1309→2.01309다. 하한을 넓히거나 자율 결과를 보고 두 번째 값을 고르지 않았다. 다른 seed29는 이미 검토했던 다른 상태 점검이며 맹검이라고 부르지 않는다.

물리 모델은144의 셀19 독립 공간 재고·속도와132의 동결 계수다. 앞서 실패한145 계수는 채택하지 않았다. 합류 감속,21수용,20진출 공유 FIFO,동적 off-ramp 저장·배수,램프 대기,원 수요 예보,VSL 노출 이력은 그대로다. 기존 helper에 시험 선택기만 추가했고 생산 모델/adapter를 복제하지 않았다.

## 실측 상태에서 맞아도 자율 상태에서는 다른 구간에 보정이 걸린다

실측과 예측의 같은5초 시각·3차로 상태를 대조했다. seed67 RM 완화·110의270개 표본 중 실제 활성 상태는55개였다. 기존144는9개, 후보146은91개로 예측했다. 후보의91개 중69개는 실제로 해당 상태가 아니었다.

특히 중간150초에서는 실제 활성 표본5/90에 비해 후보는30/90이었다. **후보의30개 모두 실제 활성 상태와 겹치지 않았다.** VSL90 조건도 중간150초18개 활성 표본 모두 실측 구분과 어긋났다. 실측 상태를 대입한 적합도가 좋아졌다는 이유로 예측 상태에서도 적절한 보정이 된다고 볼 수 없다.

이 불일치는 예측 상태가 보정 구간에 머무르며 과도한 회복을 만들 수 있다는 단서다. 임계밀도 판별만이 유일한 원인이라고 확정하거나 모든 상태별 보정을 부정하지 않는다. 현재 모델이 만드는 재고·속도 경로와 보정항이 함께 작동한 결과다. `regime_samples.json`에 원 시각별 밀도와 활성 여부를 보존했다.
