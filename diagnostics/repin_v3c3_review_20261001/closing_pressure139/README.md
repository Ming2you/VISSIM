# 셀22 하류 속도차로 anticipation 감속을 제한한 후보

2026-10-04. **9회 예측 정상 완료, 제어 손익 검증 실패로 후보 기각. 정본에 채택하지 않았다.** 이전 사용자 답변은 설명만 했으므로 NO_PROGRESS였고, 이번에는 준비된 후보의 실행·대조·결과 보존을 완료했다. 목표는 ACTIVE / NOT_QUALIFIED다.

## 변경한 것과 유지한 것

137의 단일 계수 감소는 상태 오차를 줄이는 대신 RM의 예방 효과까지 지나치게 약화했다.138에서는 정본1초 식을5회 계산해도 셀22의 과감속이 남았다. 이번에는 동결132의 모든 계수를 그대로 두고 셀22의 **음의 anticipation 항만** 다음처럼 제한했다.

`pressure_new = max(pressure_old, -max(0, v_local - v_downstream))`

속도는 현재 예측 상태이며 적분은 기존1초다. 양의 anticipation, 이완·대류·합류 감속, 실제 합류·수용량, 차로·목적지 재고, 동적 진출부 저장·배수, 램프 대기, VSL 이력은 그대로다. 하류가 정지해 있고 기존 pressure가 속도차보다 작으면 기존 감속을 유지한다. 이는 pressure 한 항의 제한이며, 모든 항을 더한 최종 감속의 상한은 아니다.

이 식은 논문식을 그대로 옮긴 것이 아닌 **하류가 이동 중일 때의 과도한 밀도 압력을 구분하려는 가설**이다. 문헌 탐색의 출처는 [Fang·Ye·Easa2019](https://onlinelibrary.wiley.com/doi/10.1155/2019/8151582)와 [Zhao 등의 Bounded-METANET](https://arxiv.org/html/2503.17680v1)이다. 문헌이 이 제한식을 검증했다고 주장하지 않는다. 과거 `freeway_first/bounded_recovery`와 `center_distance`의 실패는 보존하고 재실행하지 않았다. Claude의 기존 검토 기록에서 망과 계수 차이도 확인했으며 다른 망의 계수를 복사하지 않았다.

사전 예산은 기준 동등성1회+seed29·67의 RM 유지/완화×VSL110/90 총8회, 모두450초다. 추가 계수 적합이나 임계값 탐색은0이다. 두 상태는 이미 검토한 자료로 독립 맹검이 아니다. 원래 캡처의 미래 수요 예측을 유지했고 미래 실측 상태·유량은 모델에 넣지 않았다.
