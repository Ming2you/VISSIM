# 셀19 내부 위치를 유지한 VSL 손익 예측

2026-10-03. **450초 예측3회 완료, 후보 기각. 이득 보정은 미완료**다. 이전118은 차로별 정지 전이 근사의 평가 자료 간 불일치를 확인한 진전이었다. 이번에는 실제 TTT·방출 반응을 다시 직접 검사했다. 사용자가 중단한9000초 결과 분석은 재개하지 않았다.

## 검토 근거와 작은 변경

Claude의 보관 REVIEW_CHECK/K1K6 및 기존62·94·106·108을 확인했다. 다른 망의 계수는 가져오지 않았다. 현재 계수가 실행에 전달되지 않은 오류나, 수용 상한을 무조건 높일 근거는 이전 검사에서 확인되지 않았다.106의 셀19에서는 VSL로 셀 내부 이동량이 줄어도 하류 경계 방출이 늘었다. 셀 내부 위치 분포의 변화가 남아 있기 때문이다. 위치를 관측 시점에서 고정해 외삽한91, 수동 VSL 태그 수송85, 회복 셀24/25의 조건부 공간 분할과 이번 동적 물리 유량 검사를 구분한다.

셀19(약200m, 중간 진출·합류 없음)만 길이가 같은 앞·뒤 구획으로 나눴다.31개 물리 셀의 외부 상태·속도식·FD·램프·진출 모델·명령·목적함수는 유지했다. 초기 차량의 실제 위치로 경로별 재고를 두 구획에 나누고, 이후에는 예측 속도와 수락된 유량만 사용했다. 두 구획에는 같은 기존 셀 평균속도를 사용했다.

```
U_next = U + accepted_in - H
D_next = D + H - accepted_out
H = min(2*v*U/L, U/dt, free_D/dt) * dt
out = min(2*v*D/L, D/dt, 기존 하류 수용량)
```

상류 수용은 앞 구획의 여유 공간도 지킨다. 뒤 구획의 실제 경로 조성으로 방출하고, 앞 구획 재고를 즉시 방출하지 않는다. 두 구획 합계가 기존 셀 재고이며 추가 차량이 아니다. 기존 활성 sending cap도 유지한다. 새로운 capacity 계수·VSL 보너스·fitting은 없다.

이것은 **수송의 공간 혼합 근사 한 가지**다. 독립적인 두 속도 상태를 가진 세분 METANET이나 차로별 정지 대열 모형을 구현한 것은 아니다. 운용 파일은 수정하지 않고 기존 canonical 함수 두 곳에 진단 프로세스 안에서만 연결했다. 원래 초기 경로 분할·차량 보존·rollout을 재사용했고 종료 시 연결을 복구했다.
