# 국소 계수 재보정과 구조 비교 — REVIEW125

2026-10-03. **고정/재보정 × 기존/새 구조 비교 완료. 이득 보정은 미완료.** 이전124는8회 자율 예측을 완료한 PROGRESS였고, 이번에는 학습·다른 상태 검증까지 진행했다. 새 VISSIM·FZP 스캔·9000초 결과 분석·push는 없다. 정본 모델은 변경하지 않았다.

## 범위와 보정

사용자가 지적한 “기존 계수를 고정한 새 동역학 시험으로 재보정 후 설명력까지 제한하지 말라”는 점을 반영했다. 단순히 차단 계수만 더 강하게 주는 시험과 구분한다. 기존 Claude 진출·공유 차로 기록 및 이전 `lane_fit29`의 FD형상/합류계수3후보 시험은124와 이번 준비에서 확인했다. 이전 후보를 그대로 반복하지 않았다.

- **기존 구조:** 현재 retained10638/expanded036 거시31셀 METANET.
- **새 구조:**124의19–25 차로×목적지 재고, 셀21 차로 수용,10483 진출/직진 공동 방출. 프로세스 내부에서124의 실행 함수를 재사용했다.
- **공통 보정변수3개:** 셀19–21 임계밀도 배율0.8–1.2; 셀19–21 가속 이완시간 배율0.65–1.35; 셀22–25 가속 이완시간 배율0.65–1.35. 각 셀의 기존 계수 차이는 유지하며 그룹별 공통 배율만 사용했다.
- 감속 이완시간, anticipation 계수, 합류계수, 차로 교환율, 저장 공간, 수요, 명령, VSL 이력은 고정했다. 가속 분기는 현재 예측의 희망속도와 속도로 선택한다. τ 변경은 기존 METANET의 이완과 anticipation 분모에 함께 작용한다. 특정 제어·시각에 붙는 보너스가 아니다. 임계밀도는 FD와 노드 수용에 일관되게 전달했다.

각 구조에 기준+6개 축 후보+유리한 축 조합+중간값, **9벡터씩** 같은 예산을 줬다. 학습은seed29 후기2670.1초의 RM유지/완화×VSL110/90 네 조건450초다. 학습 점수는 절대 TTT·램프 대기·잔여·유출·합류 오차, 국소 N/v/q, 모든 쌍의 손익 오차를 함께 포함했다. 제어기의 Ω TTT 목적함수는 변경하지 않았다.

학습 후 값을 고정하고seed43 초기 네 조건,seed67 후기 네 조건,seed29 초기 무제어1조건을 평가했다.29후기·43초기·67후기의 각4조건에서 **모델 초기 상태와 실측 초기 셀별 N/v가 각각 정확히 동일**함을 확인했다. 그동안 이미 살펴본 자료이므로 새 미공개 holdout으로 표현하지 않는다.

## 남겨 둔 후보와 해석

기존 구조의 **[1,0.65,1]**, 즉 셀19–21 가속 이완시간만 줄인 후보는 학습 가중 점수1.3090→1.2273, 손익 오차0.2165→0.2000으로 두 학습 조건을 함께 통과했다. 가중 점수 최소값 후보와 달라 이번 검증 대상에 포함되지 않았다. 이 후보까지 실패했다고 판정하지 않는다. `assessment.json/training_admissible_candidates`에 미검증으로 남겼다. 새 구조의 이번9벡터에는 두 학습 조건을 함께 통과한 후보가 없다.

다음의 우선 행동은 새 grid를 늘리기보다, 이 **이미 계산된 학습 적격 후보 한 개**를 별도의 작은 검증 예산으로 확인하는 것이다. 선택 기준은 기존 학습 자료에만 고정하며, 검증 결과로 새 계수 값을 만들지 않는다.

이번 결과는 **시험한3배율 범위와 두 구조의 결과**다. 동역학에 맞는 보정의 가능성 전체를 부정하지 않는다. 반대로 학습의 절대 상태 개선을 근거로 VSL 이득을 맞췄다고도 할 수 없다. 만약 남은 후보도 실패하면 현재 차로별 분포·회복의 구조와 작은 이득 목적 오차 사이의 연결을 다시 좁혀야 한다.
