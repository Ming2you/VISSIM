# 10682 접근부 차로·목적지 전달 시험 — 기각

2026-10-02 / REVIEW48. **실제 접속 기하를 반영한 6개 450초 예측을 완료했지만 채택하지 않았다.** seed43의 10682 유량만 개선하고 seed47 회복과 10643 진출을 악화했다. 이번 변경 7개 파일은 작업 전 바이트로 복원했고 REVIEW47의 선택적 차로 초기화만 남아 있다. 전체 목표 ACTIVE / NOT_QUALIFIED.

사용자 우선순위는 **8개 off-ramp 진입·배수·저장 → 필요한 셀 보정 → 공통 초기 제어 손익**이다. 이번 결과는 경계 유량을 먼저 고쳐야 한다는 방향을 유지하되, 단순 차로 분할 자체도 검증 없이 해결책으로 삼을 수 없음을 보여준다.

## 시험한 내용

과거 `freeway_first/joint_lane_fifo`에서 보존 검사를 통과했던 국소 차로 allocator를 기존 `physical_lane_groups.py`에 재사용하고 현재 목적지 재고·off-ramp 도시부 전달에 연결했다. 과거 셀19–21 계수나 기각된 성능 결론을 그대로 채택하지 않았다.

- 동측 셀9–12의 네 물리 차로만 구분했다. 나머지 셀과 서측, FD·속도 계수, 수요·경로 선택 확률, 신호·미터 명령, 목적함수는 그대로다.
- 차로별 재고는 기존 셀별 목적지 재고의 분할이다. 수락한 종방향·횡방향·합류·진출량과 도시부로 전달하는 경로별 차량 수가 일치해야 한다.
- 기존 동적 off 저장·배수·유효 차로 감소를 유지했다. 셀9의 초기 유효 차로3.90672를4로 되돌리지 않았다. 감소한 운영 수용량은 접근 가능한 차로에 나누되 물리적 저장 차량은 삭제하지 않았다.
- 실제 선택망 XML에서10643 진출은2차로,10682 진출은1차로,10639 합류는1차로,10681 합류는2차로임을 확인했다. 코드에 이 실제 접속 차로 수와의 일치 검사도 넣었다.
- 동일한 이미 수락된 합류량을 가능한 접속 차로의 빈 공간에 비례해 나누었다. 실제 차로별 합류량 관측을 재현했다고 주장하지 않는다. off-ramp 수용 상한도 기존 공유 총량을 유지했다.
- 횡방향 교환률은 독립 학습 자료인seed29 NC의 기존2220.1–2670.1초5초 캐시에서 인접 차로 끝점 변화/차량·초로 한 세트만 계산했다. 정확한 차로 변경 사건 수가 아니며, 목적지별 의무 차로 변경을 분리하지 못한다.43/47의 미래 실측은 예측 입력으로 넣지 않았다.
- 구간 유입의 목적지별 차로 분배는 현재 상류 셀8의 관측으로 고정하고 해당 목적지 표본이 없으면 균등 분배했다. 이것이 아래 실패의 중요한 원인이 됐다.

## 후보가 잘못 남긴 진출 차량

현재 셀8에는 두 상태 모두10643행 표본이0대였다. 해당 목적지의 차로 분배가25%씩으로 대체되고, 목적지와 무관한 평균 교환률을 사용하면서 진출할 수 없는3·4차로에10643행을 남겼다.

- seed43 종료: 후보28.57대, 실제 현재 경로 관측0대.
- seed47 종료: 후보29.10대, 실제 현재 경로 관측0대.

이것은 **이번 후보가 만든 가짜 차로 접근 대기**에 대한 증거다. 기존 aggregate 모델에 이미 이 동일한 가짜 재고가 있었다는 뜻은 아니다. 또 이것 하나로 속도 오차 전체가 설명된다고 단정하지 않는다. 상세는 `class_blockage.json`.

따라서 다음에는 현재 짧은 셀 한 곳의 빈 표본을 미래 전체의 균등 차로 분배로 바꾸는 가정과, 진출 의도를 무시한 교환률을 먼저 검증해야 한다. 현재/과거 자료로 목적지별 접근 차로와 필요한 차로 이동을 식별할 수 있는 범위를 정한 뒤, 이 보존 코드를 다시 사용할 수 있다. 이 가짜 재고에 맞춰FD·회복 계수를 낮추거나 같은 교환률 격자를 반복하지 않는다.
