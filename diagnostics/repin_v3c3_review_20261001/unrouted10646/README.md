## 기존 코드가 빠뜨린 이동

선택망64cf5…에서 경로1135:2는10646에서 본선120으로 합류하고 **1m 뒤에 끝난다**. 합류점은120의2340.148m, 경로 끝2341.148m,10638 분기는2402.481m다.1133 routing decision은424.229m에 있어 이미 뒤에 있다.

기존 `_future_distribution`은 이후 static decision이 없으면 무조건 terminal100%로 분류했다. 그러나 경로가 끝났다는 것은 이후에도 본선을 통과하라는 명령이 아니다.10638은 Direction=ALL connector다. 공식 COM 설명에는 경로·희망 방향이 없는 차량이 다음 ALL connector를 이용한다고 명시돼 있다. [PTV ILink Direction](https://cgi.ptvgroup.com/vision-help/VISSIM_2026_COM-Help/VISSIMLIB~ILink_attributes.html). 이는2026 문서이며 설치된2020에서의 실제 동작은 아래 차량별 자료로 별도 확인했다. 경로가 목적지 단면에서 끝나고 이후 routing decision의 적용 대상이 된다는 설명은 [PTV Vissim2020 routing 문서](https://cgi.ptvgroup.com/vision-help/VISSIM_2020_ENG/Content/5_Netzbearbeiten/Fzgverkehr_Routen_RoutenEntsch_mod.htm)를 참고했다.

- **seed43 NC2250.1–2700.1:** 10646 실제 합류53대 중52대가 같은 창에서10638에 도착했고, 마지막1대는2705.1초에 도착했다. 기존5초 궤적에서 만든 차량번호별 port event를 재사용했다. 관측시각 차이는0또는5초이므로 실제 이동시간을0초라고 해석하지 않는다.
- **seed47 유지2700–3150:** 10638 진출93대 중44대가 초기10646 재고 또는 이후10646 진입 차량과 연결됐다. 별도 재고수지로 얻은10646 합류도44대다. 도시 선택은 진출92대 중43대가 같은 방식으로 연결됐다(합류44대). MER는 램프 진입·off 진입 검지이므로 정확한 합류 시각의 직접 관측이라고 부르지 않는다.
- 같은 구조가10480→10491에도 있다. seed43 합류32대 중28대의 후속10491 도착을 확인했고4대는 미확인으로 남겼다. 이를100% 관측 성공이나 삭제로 간주하지 않았다. 차로 접근·기간 내 관측 한계는 남는다.

10638 실측100대 중52대의 우회 진출을 모델에서 빠뜨렸다는 사실은 기존 예측45.86대와의 약54대 차이를 설명한다. 미래 실현 차량을 예측에 넣거나53/53로 경험 확률을 피팅하지 않았다.

## 기존 compiler의 제한적 수정

`evaluation/controllers/offramp_routing.py`의 `compile_inventory`와 `_future_distribution`만 바꿨다. 별도 교통모델·adapter·runner는 없다.

새 후보의 pin된 route 계약에 `route_free_policy=next_all_connector`를 명시했다. 경로가 없거나 현재 경로가 종료된 이후, 다음 static decision과 다음 ALL 진출 connector의 실제 위치를 비교한다. decision이 먼저면 기존 확률 선택, connector가 먼저면 해당 진출 대상이다. **아직 유효한 본선 통과 경로는 그대로 유지**한다. 관측된 missed-target 검열 처리·차량 보존·현재 수락 유량 수송·동적 off 저장/배수도 유지한다.

망의 본선→외부 connector가 검토된8개 출구인지 검사하며 미검토 출구와 모호한 동위치 분기는 거부한다. 해당 옵션이 없는 기존 계약의 compiled runtime과 대표 위치별 분포는 수정 전과 정확히 같았다.

새 후보의 input분포와 다른6개 on-ramp 분포는 그대로이고,10480→10491 및10646→10638의 두 합류 후 연결이 달라졌다. 초기 null-route 차량도 현재 위치 이후의 같은 규칙을 적용한다. cell aggregate 근사라 실제 차로 접근·미진출을 완벽히 재현하는 것은 아니다.

계수,망,수요,명령,Ω 목적함수는 변경하지 않았다. 과거 후보 파일은 보존했고, 다음 off-ramp 조사에서는 이 후보를 구조 수정 기준으로 사용한다. 전체 제어 이득을 검증하기 전 운영 기본 활성화·9000초 실행을 하지 않는다.
