# REVIEW126 — 고정한 제한적 보정 후보의 검증

2026-10-03. 이 기록은 이미 시작한 짧은 예측 검증의 종료 보고다. 새로운 셀 재보정, native 실행, FZP 재추출, 9000초 결과 분석, push를 수행하지 않았다.

## 해석 원칙

사용자 지적대로, **진출부 동역학을 바꾸고 기존 셀 계수를 그대로 적용한 결과는 그 조합의 성능만 보여 준다. 동역학에 맞게 셀을 재보정한 모델이 이득의 크기를 설명할 수 없다는 근거가 아니다.** 이전 계수가 누락된 동역학을 일부 흡수했을 가능성과 새 동역학 도입 뒤 중복 설명 가능성은 검토할 가설이며, 아직 입증된 원인이 아니다.

이번 후보도 전체 셀의 충분한 재보정 결과가 아니다. REVIEW125의 작은 공통 계수 탐색에서 학습 기준을 통과한 한 후보를 고정한 검증이다. 후보의 실패를 METANET 또는 셀 재보정 전체의 성능 한계로 일반화하지 않는다. 반대로 재보정만 하면 해결된다고 보장하지도 않는다. 사용자의 이번 설명은 즉시 추가 fitting을 시작하라는 요청이 아니다.

## 고정 후보와 예산

- REVIEW125 학습 자료에서 선택한 aggregate 후보 `[1, 0.65, 1]`을 그대로 사용했다.
- 셀 19–21의 가속 이완시간 배율만 0.65. 임계밀도와 셀 22–25 회복 계수 배율은 1이다. 셀 번호는 0기준이다.
- component 검증: 기준 재현 1회 + 후보 9회 = 450초 예측 10회, 19.209초.
- seed73 전체 Ω 검증: 기준 2회 + 후보 2회 = 450초 예측 4회, 148.876초.
- 추가 계수 탐색 0회, 새 VISSIM 0회. 위 시간은 최적화나 SDMPC iteration 시간이 아니다.

## 완료 결과

Component 범위는 동측 31셀과 진입/진출 커넥터 각각 4개다. 전체 Ω TTT 또는 Ω 정상 유출과 혼동하지 않는다.

| 검증 | 실측 ΔTTT [veh·h] | 기존 예측 | 후보 예측 |
|---|---:|---:|---:|
| seed67 RM 완화 상태에서 VSL110→90, component | -1.633333 | -0.028241 | -0.095405 |
| seed73 RM 완화 상태에서 VSL110→90, 전체 Ω | -0.559389 | +0.936212 | +0.890666 |

Component 종합 반응 손실은 0.403414→0.360562로 약 10.6% 감소했고, 두 검증 상태에서 최저 비용 후보 순위는 맞았다. 그러나 의미 있는 모든 손익 부호 검증은 통과하지 못했다. seed73 전체 Ω에서도 VSL 이득을 손해로 예측한다. 이 후보는 정본에 채택하지 않는다.

seed43의 450초 전체 실측 비교에는 후반 본선 유입 차이가 있다. 이를 전부 내부 동역학의 VSL 반응 오차로 귀속하지 않는다. 기존 `source_realization_onset_20261001/prefix_response.json`에서 동일 유입 구간의 진단은 별도로 보존돼 있다. seed73은 본선 유입 총량이 양쪽 모두 918대로 같지만, 총량 일치만으로 도착 시각까지 동일함을 주장하지 않는다. 이 자료들은 이미 검토한 seed이며 새 맹검 검증이라고 부르지 않는다.

## 실행 및 보존 확인

- component 기준의 cells/flows/ports/ramps가 기존 저장 결과와 정확히 일치했다 (`parity.json`).
- seed73의 기준 두 조건이 기존 REVIEW95의 물리 결과와 정확히 일치했다 (`full73/baseline_parity.json`).
- 각 단계에서 생산 코드 9개, 입력 pin, 기존 STOP의 SHA를 보존했다 (`preservation.json`, `full73/preservation.json`).
- 실행 세션 73914는 exit 0으로 종료 확인했다. 새 후속 계산은 시작하지 않았다.

## 이후 판단에 남길 구분

후속 보정의 가치를 판단할 때 기존/새 동역학과 기존/동역학에 맞춰 보정한 계수를 구분해야 한다. 동일 학습 자료·작은 예산으로 비교하고, 별도 상태에서 150초 방출·잔여 재고 및 큰 ΔTTT 손익과 순위를 확인하는 원칙을 유지한다. 이번의 제한적 후보 결과를 이유로 그 가능성을 미리 닫지 않는다.

전체 이득 보정·SDMPC 선택·9000초 목표는 미완료다. 사용자가 중단한 9000초 결과 분석은 계속 중단 상태다.
