# 회복 셀 공간 분할 검사 — 2026-10-02

**같은 계수로 셀24·25를 둘로 나누는 단독 변경은 채택하지 않는다.** 셀25의 국소 속도변화 오차는 세 자료 모두 줄었지만 셀24는 모두 커졌다. 원격 bd39205의 구조 진단을 참고하는 과정에서, 회복 편향이 셀 평균화만으로 설명되는지 한 가지 고정된 분할로 확인했다.

## 범위와 방법

- 기존 seed67 RM 완화(2670.1–3120.1초), seed29/43 무제어(2670.1–2970.1초)의 완료된 5초 차량 위치 캐시만 사용했다. 모두 명목110 조건이며 VSL90 차량군을 평균110으로 대체하지 않았다.
- 세 자료에 같은 동결 expanded036 계수를 적용했다. 이미 검토한 자료이므로 새 맹검 검증이라고 부르지 않는다.
- 31셀 중 셀24(164.26m), 셀25(492.79m)를 각각 같은 길이의 두 절반으로 동시에 나눴다. 상류 셀23과 하류 셀26은 원래 관측 상태를 유지했다. 계수·차로 수를 바꾸거나 fitting하지 않았다.
- 각 절반의 차량 수와 평균속도를 현재 차량 위치에서 계산했다. 이 둘을 다시 합쳐 원래 차량 수와 속도 모멘트가 보존되는지 검사했다.
- 정본 METANET 속도식의 이완·대류·anticipation 항을 사용했다. 유량은 이 국소 검사에 한해 `q=n*v/(3600*L)`로 계산했다. 수용·저장 제한을 적용한 실행 유량이 아니다.
- 평균속도의 미분은 속도 미분의 단순 가중평균에 더해, 차량 수 변화에 따른 가중치 변화까지 포함했다: `dV/dt = Σ[n_j*dv_j/dt + (v_j−V)*dn_j/dt]/N`. 내부 유량은 차량 수 수지에서 상쇄된다.

**현재 실측 상태에서의 조건부 식 검사**다. 미래 5초 표본은 평가 정답으로만 사용했다. 자율450초 예측, 제어 순위, ΔTTT, SDMPC 성능 검증이 아니다. 순간 모델 미분과 실제5초 평균 변화는 시간 연산자도 다르다.

셀24의 뒤 절반은 앞 절반보다 평균10.3–13.0km/h 빠르고 밀도는 낮았다. 공간 이질성은 실제로 존재한다. 그러나 같은 계수를 쓴 분할에서는 대류 감속이 더 커져 전체 저속 편향이 남았다. 셀25도 개선 후 평균 예측 변화율은 −1.12~−1.32km/h/s인 반면 실측은 −0.048~+0.007로, 편향이 해결되지 않았다.

사전에 정한 여섯 seed·셀 조합 모두의 RMSE10% 이상 개선 및 절대 평균 편향 감소 조건은 실패했다. 단순히 변화율을0으로 놓은 비교값이 여섯 조합에서 모두 더 작지만, 이것을 새 동역학으로 채택하지 않는다. 실제 순간/단기 집단 변화와 장기 자율예측의 차이 때문이다.

이 결과는 **공간 분할 단독 수정이 충분하지 않음**을 뜻한다. 재보정한 분할 모델까지 불가능하다는 증거, METANET 전체의 불가능 증명, 또는 VSL/RM 이득이 없다는 증거는 아니다. 여기서 더 잘게 나누거나 계수를 반복 탐색하지 않는다. 큰 제어 손익을 설명하려면 기존에 확인한 합류·진출 유량과 유한 대기 연결의 검증을 함께 유지해야 한다.
