# 링크66 직진 head 관측 연결 — REVIEW60

2026-10-02. 이전 REVIEW59는 초기 투영 수정과 방출 상한 원인 확인으로 진전이 있었다. 이번에는 그 상한을 기존 과거 관측 처리에 실제 연결하고, 기록 상태 2개에서 450초 예측 6회를 마쳤다. **국소 방출량 오차는 줄었지만 제어 반응·이득 검증은 통과하지 못했다.** 운영 기본 설정은 바꾸지 않고 선택적 후보를 보존한다.

## Claude 기록을 먼저 확인한 내용

bd39205 보존본 `U7.md`, `STAGE4.md`, `STAGE5.md`, `S_STRUCTURE.md`, `FWW_STRUCT_PROPOSAL.md`를 재사용했다. U7은 도착·구성을 고치는 하네스였고, U4는 정규화 용량 문제, U5는 중복된 공유 차로 서비스 문제를 다뤘다. 현재 링크66에서도 `boundary_in` 직진이 `internal` 전용 head 보정에서 제외되는 것을 확인했다. Claude의 전체 C3 패키지나 1,850대/h/차로 상수를 가져오지는 않았다.

## 실제 변경

기존 `head_service_resources.py`에서 선택적 v9 계약에 10631을 추가했다. 현재 망의 66번 도로 1–3차로, SG1004-8, 정지선 후 유일한 직진 connector10631을 검증한다. 기존 과거 관측의 4개 녹색 노출 창 및 carried support를 그대로 사용한다. 새 포화용량 보너스·METANET 계수·신호·수요 변경은 없다.

우회전10632는 같은 1차로를 쓰지만 정지선 전에 갈라진다. 직진 head의 관측률을 우회전에 배분하지 않는다. 초기화 전에 남아 있는 두 우회전 목적지 별칭은 기존 route-choice 계약이 같은 물리 분기로 합치는 경우에만 제외한다. 다른 임의의 경쟁 movement는 거부한다.

처음 단위 시험 14개는 통과했지만 실제 초기화는 우회전 별칭 `SC1004_S_to_E_SC107`를 발견해 거부했다. 시험 fixture에 실제 초기 단계의 별칭·소유자를 추가하고, 기존 corridor 증거에 결속한 뒤 **15개 시험과 실제 초기화가 통과**했다. 최초 실패와 준비 단계 receiver 불일치 기록은 남겼다.

이전 검토의 불확실성도 하나 해소됐다. 10632는 movement에 phase 이름이 남아 있어도 `route_choice_corridor.intended_departure`에서 `signal_controlled=false`에 따라 이미 녹색 비율1로 처리된다. 별도의 신호 수정은 필요하지 않다.

seed47 직진 상한은 619.592→1,486.957대/h, seed43은 619.592→1,565.217대/h다. 다른 movement 상한·기존 head 자원률·초기 재고·도착 태그·게이트 지연·실행 명령은 보존했다. 이 값은 **과거에 달성한 방출률의 하한**이며 식별된 포화용량이 아니다.

## 같은 명령에서의 450초 방출

| 상태·명령 | native 직진 방출 | U7만 | U7+관측 연결 |
|---|---:|---:|---:|
| seed47@2700, RM 유지 | 62 | 23.751 | 57.000 |
| seed47@2700, 기존 선택 명령 | 70 | 20.653 | 49.565 |
| seed43@2250, 무제어 | 76 | 23.751 | 60.000 |

native는 head 통과, 모델은 인접 connector transfer이므로 수 m의 경계 차이는 남는다. 이전과 동일한 native 기록을 사용했고 FZP를 다시 읽지 않았다.

종료 접근 재고는 seed47 유지 235.583→202.334대(native 링크66 160대)로 줄었다. 그러나 도시 명령을 바꾸면 실측 직진 방출은 +8대인데 모델은 −7.435대다. 절대 오차가 줄어든 것과 제어에 대한 반응을 맞춘 것은 다르다.

기존 native head 이벤트를 초기 링크66 차량 번호와 대조했다. 초기 차량의 직진 방출은 두 명령 모두 총45대지만, 150초별로 유지 20/21/4대, 선택 28/17/0대다. 이후 진입한 차량의 직진 방출은17→25대다. 즉 선택 명령에서는 초기 차량이 더 일찍 빠지고 새로운 차량도 더 통과했다. 이것은 사후 평가 증거이며 예측 입력으로 쓰지 않았다. 서비스 상한 하나를 더 높이는 것으로 이 시간 관계까지 해결된다고 단정할 수 없다.

## 이득 예측과 제약

독립 seed43의 조건−무제어 Ω TTT [veh·h]:

| 조건 | native | 연결 후 모델 |
|---|---:|---:|
| RM | −1.54722 | −0.09590 |
| VSL | +0.77708 | −0.38201 |
| RM+VSL | −1.45347 | −0.46448 |

이 차이들은 연결 전 U7 후보와 수치 오차 이내로 같다. 따라서 이번 오류는 **이 상태들의 RM/VSL 손익 예측 실패를 설명하지 못한다.** native 공통 초기 prefix 검증은 이전 결과를 재사용했다.

seed47 선택−유지 Ω TTT 예측은 −7.5722→−8.5683 veh·h로 변했지만 native는 −1.0883이다. 전체 추적 비용 차이는 모델 −0.4700으로 그대로다. Ω로 더 일찍 이동한 재고에 따른 외부 비용 변화가 있으므로 Ω 절대 TTT의 변화를 새 성능 개선으로 보고하지 않는다. native 전체 시간에는 미삽입 대기를 포함하며, 모델의 추적 외부 비용과 완전히 같은 범위라고 주장하지 않는다.

또한 재사용한 두 seed47 명령은 현재 모델의 고정 N_P cap473.589대를 모두 넘는다. 연결 전에도 위반했고 연결 후 유지607.489/선택587.522대로 나타난다. N_UF cap은 통과한다. **이번 비교는 기존 실행 명령에 조건을 둔 물리 반응 시험이며, 새 모델에서 실행 가능한 SDMPC 선택을 얻었다는 뜻이 아니다.** 제약을 임의 완화하지 않았다. seed43 기존 four-arm exporter에는 같은 quantity 제약 판정이 없어 미검증으로 남긴다.

## 검증과 다음 단계

- 15개 단위/회귀 시험. 후보 예측6회, 계산 합계156.119초. 계수 fitting·새 VISSIM·FZP 재스캔·push 0회.
- 여섯 조건 모두 링크66의 초기 재고+실제 입출력−종료 재고 오차 약1.1e−12대 이하. 기록된 물리 자원 초과 약4.7e−15대 이하.
- seed47 전체 saved-stock witness 두 개 통과. 기존 seed43 exporter는 그 witness를 내보내지 않으므로 국소 보존 검사로 전체 보존 검증을 대체했다고 주장하지 않는다.
- 모든 비교 명령은 이전 결과와 정확히 같음. 기존 STOP 및 운영 설정 보존. 전체 AD/worker/SDMPC 선택 경로는 이번에 검증하지 않음.

다음에는 Claude의 실제 포화 서비스 식별과 현재의 관측 하한 추정을 대조해, 공급이 충분한 녹색 구간의 처리율과 도착·offset에 따른 방출 시각을 구분한다. 동시에 이번 수정에서 RM/VSL 차이가 그대로였다는 결과를 유지해야 한다. 해당 이득을 설명하려고 링크66 계수를 더 반복 조정하지 않는다. 기존 71번 도로의 목적지·차로 전파 오차와 고속도로 제어 반응은 별도의 미해결 항목이다.

실행 소스·출처 해시는 `completion.json`, 수치 및 제약은 `assessment.json`, 초기화 불변 검사는 `initialization_check.json`에 있다. 새로운9000초 실행으로 미해결 검증을 대신하지 않았다.
