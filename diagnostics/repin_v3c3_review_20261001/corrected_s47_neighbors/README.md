# 선택 이후 RM·VSL 유한 변경 — 2026-10-02

직전 목표 턴은 선택·정본 재생 완료 증거를 확정한 진행이었다. 이번에는 미분 또는 반올림 때문에 큰 실행 가능 이득을 놓쳤는지 검사했다. 새 계수·목적함수·도시 명령·제약은 만들지 않았다.

seed47@2700의 완료된 SC1001 후보 SDMPC 선택을 기준으로 첫150초 명령만 바꿨다. 그 뒤300초는 원래 선택 명령으로 돌아온다. 도시 green/offset, 과거 관측, N_P/N_UF cap은 고정했다. 후보5개+선택 기준1개를 각각 근사·실행 규약 모델로 계산했다(총12회450초,최적화0회). 세션55468은exit0이며 재계산 대기 작업은 없다.

현재 상태에서는 미터를 더 강하게 제한할 때 본선의 작은 절감보다 램프 비용이 크다. g7 완화의 작은 이득0.0495는 탐색이 놓친 후보이지만, 전체 이득 문제를 설명하는 큰 차이는 아니다. 10681은 g9→g7로 내려도 전체 합류 변화가0.00042대 정도여서 현재450초에서는 반응이 매우 작다. 초기 램프 재고의 존재만으로 이 후보가 큰 방출 차이를 만든다고 가정하지 않는다.

정본 `meter_activation_axes`는 완전 개방10초이고 모든 비용/제약 감도가0인 축만 검사한다. 현재5·9초의 유한 이웃 검사는 그 기능의 범위 밖이다. 이번 결과로 보완의 범위를 확인했지만,0.05 차량·시간을 얻기 위한 전역 후보 탐색이나 계수 수정은 하지 않았다. 모든 VSL값·구간·명령 시퀀스 또는 다른 시각에서 이득이 없다는 뜻도 아니다.

## 다음 실행과 한계

기존 SDMPC 선택을 그대로2700–3150초에 적용하는 native 검증1회를 준비했다. 미세한 사후 최선으로 바꾸지 않는다. 이전 완료된 RM 유지 런을 비교 기준으로 재사용하며,2700초 이전 FZP prefix와 실제 명령 기록까지 맞는지 확인한다. 도시 이득 과대예측과 본선 반응 오차를 실제 결과로 점검하기 위한 실행이며, 물리 이득 자격을 통과한9000초 실행이 아니다. 기존9000 STOP은 유지한다.

변경은 기존 진단 함수 `probe_selected_meter`와CLI만이다. 코어·계수·제어기·입력 SHA는 불변이다. 원본/실행 driver,12회 예산의protocol,모든후보·실패로그를 보존했다. 새native 준비·실행 상태는 별도protocol을 따르며, 이 비교 자체는native0회다.
