# 거시적 정지·회복 보조식: 작은 보정과 자율 예측 검사

2026-10-03 / REVIEW113. 이전112는 PROGRESS. 이번에도 진단은 완료했으나 제어 이득 보정은 **ACTIVE / NOT_QUALIFIED**다. 정밀 속도 궤적 일치를 채택 기준으로 삼지 않았다. 진행 중인 DATA9000 동결본·설정·프로세스는 변경하지 않았다.

## 판단

사용자가 제안한 ‘진출하려는 비율과 접근 시간으로 차로변경 방해를 거시적으로 표현’하는 방향에는 문헌 근거가 있다. 하지만 **실제로 나간 차량 수를 정지 발생의 원인으로 바로 쓰면 안 된다**. 심한 차단으로 나가지 못하는 상태에서 진출 희망 수요를 작게 추정하게 된다. 현재 목적지별 재고/예측 도착, 차로 접근 가능성, 남은 접근 시간이 더 적절한 설명 변수다. 정지 차량 수도 모든 원인이 급한 차로변경이라고 확인된 값은 아니다.

아주 작은 보정을 실제로 시험했다. 두 공통 계수로 정지 발생과 재출발을 표현하면 관측 상태를 넣은 조건부 설명력은 개선됐다. 그러나 같은 식을 현재 plant 상태로450초 전진시키면 VSL의 큰 정지 감소를 충분히 설명하지 못했고 다른 상태에서는 과장했다. **계수를 더 늘리거나 방출에 연결하지 않고 이 후보는 보류한다.** 단순 모델 전체가 불가능하다는 결론은 아니다.

## 문헌과 실제로 구현한 것의 구분

- [Jin2010, A kinematic wave theory of lane-changing traffic flow](https://arxiv.org/html/math/0503036), 식5–12: `rho_eff=rho*(1+epsilon)`, `q=rho*V(rho_eff)`, 균일 교통에서 `epsilon=alpha*p_LC*t_LC/T_traverse`. 차로변경 비율과 통과시간을 연결한다. 실제 보존량은rho다. 논문도 이 강도식을 일반 비정상 교통의 보편식으로 제시하지 않는다. T가 늘 때 t_LC도 같이 늘 수 있어, VSL 저하가 항상 이득이라는 결론은 없다.
- [Zhou et al.2022, Hybrid modeling of lane changes near freeway diverges](https://doi.org/10.1016/j.trb.2022.09.002): 필수 차로변경 차량이 틈을 기다리며 정지해 상류 대기와 하류 공백을 만든다는 모형이다. 출판사 초록/본문 발췌는 두 확률 과정, 이동 병목 입자, 진출부 평균속도에 따른 간결한 대기시간 모형을 설명한다. **전체 원문 수식은 확보하지 못했으며 이번 식은 이 논문의 구현 재현이 아니다.**
- Jin의 간단한 METANET 적용은 이미 REVIEW111에서 완료했다. 같은9조합을450초의 세150초 구간으로 평가했고 학습 손실은23.27% 감소했지만 seed67 큰 VSL 이득을 손해로 예측했다. 해당 후보는 기각·원복됐으므로 반복하지 않았다. 자세한 결과는 `../jin_macro111/README.md`.

## 이번 보정식과 자료

진단용 보조 상태는 B=5km/h 미만 차량 수다. 물리적 전체 차량 수N과 별도로 가산하지 않는다.

`B_next = B + 정지 발생 - 재출발 + 정지 상태 유입 - 정지 상태 유출`.

기존 두 계수의 발생/회복률을 모든 시험 셀·정책·seed에 공통 적용했다. VSL 명령 자체, 시각, seed별 보너스는 없다.

```
X_stop = (rho/rho_crit) * (B_down/N_down + max(v-v_down,0)/v_free + rho_down/rho_max)
X_release = max(v_down,0)/v_free_down * max(1-rho_down/rho_max,0)
a = theta_stop * X_stop
b = theta_release * X_release
p01 = a/(a+b) * [1-exp(-(a+b)*dt)]
p10 = b/(a+b) * [1-exp(-(a+b)*dt)]
```

이는 별도 가설인 **현재/하류 상태 기반 최소 통계식**이다. 진출 접근시간이나 목적지별 비율을 새로 구현한 것은 아니다. 정지 원인의 정답이나 인과적 capacity 손실식을 뜻하지 않는다.

기존 캐시6개만 읽었다. 학습 seed29 무제어/VSL, 평가43 무제어/VSL과67 RM완화/VSL90.43은2220.1초 시작,67은2670.1초 시작이다. 다른110/112의2700.1초 시작 그림과 섞지 않는다. 셀은31개 물리 셀의0기준16–23. 평가seed는 이미 검토한 자료여서 blind holdout이 아니다. 학습 목적함수에는29만 사용했다.

## 조건부 보정 결과

첫 적합은5초 정지/재출발 확률의 이항 우도였다. 이후 변수·범위·지역을 그대로 유지하면서 사용자 목적에 가까운150초 발생/재출발/순발생의 가중제곱오차로 한 번만 수정했다. 상수율 기준 모델도 같은 목적함수로 재적합했다. 총3개의 작은 적합이며 이후 탐색을 늘리지 않았다.

최종 공통 계수: `theta_stop=0.04031688816`, `theta_release=0.92899254665` [1/s]. 비교 상수율은 `[0.0129361081, 0.1764053537]`이다.

|평가seed|150초 가중제곱오차 감소|150초 순발생 RMSE 감소|
|---|---:|---:|
|43|49.15%|23.32%|
|67|45.96%|25.63%|

앞의46–49%는 **가중제곱오차** 감소이지 RMSE나 차량 수 오차가 같은 비율로 줄었다는 뜻이 아니다. 절대 순발생 RMSE도62.40/156.33회로 남아 있다. 발생/재출발은 반복 사건 수이며 고유 차량 수가 아니다.

미래 시점의 관측 상태와 같은 셀에 남은 차량의 노출량을 사용하는 조건부 검사다.6240개의5초 관측 재고 항등식을 확인했지만, 이것만으로 자율 예측이나 TTT 개선을 주장하지 않는다.

## 고정 계수 자율 검사4회

43 두 조건,67 두 조건에 각450초를 기존 plant로 실행했다. 관측은 초기 정지 차량 수에만 사용했다. 이후에는 plant가 예측한N·속도와 보조 상태B만으로 발생/회복을 계산했다. 두 식을 같은 물리 rollout 안에서 수동 표지로 동시 전진시켜 계산을 줄였다. 전체4회 계산8.13초이며 **SDMPC 최적화 시간은 아니다.**

실제 수락된 기존 경계유량으로 B 표지를 비례 수송하고 새 본선·램프 유입은 이동 상태로 두었다. 이는 검증 대상인 단순 수송 가정이다. 정지 차량과 이동 차량의 이탈 확률이 같다는 근사, 영역 밖에서 새 정지를 만들지 않는 제한이 있다. 어떤 B 값도 물리 속도·유량·목적함수에 되먹임하지 않았다.

|seed67, 예측 시작 후 구간|무VSL 실측 B|VSL90 실측 B|무VSL 예측 B|VSL90 예측 B|
|---|---:|---:|---:|---:|
|0–150s|8.70|8.70|10.47|10.53|
|150–300s|19.03|7.90|19.57|17.35|
|300–450s|41.00|10.67|46.51|39.07|

B는 해당150초 평균 대수다. 마지막 구간 VSL 효과는 실측−30.33대, 공통식−7.45대다. 반면43 마지막 구간은 실측−3.30대인데−15.84대로 과장했다. 150초 평균B RMSE는 상수율 대비43에서4.59→8.72대,67에서10.77→12.47대로 악화했다. 사전 기준을 통과하지 못했다.

이 검사는 **정지 상태의 예측**이며, TTT나 방출 이득의 개선 결과가 아니다. 물리 plant를 바꾸지 않았으므로 TTT가 변했다고 주장할 수 없다.67의 cells/flows/ports/ramps 네 표는 기존111 결과와 정확히 같고43의 세150초 블록 지표도 정확히 같다.3600개 모델별1초 표지 보존 검사 최대 잔차1.43e−14대, 초기 실측/모델 차량 수 일치, 음수/초과 재고 없음.9개 정본 소스 해시가 유지됐다.

## 다음 방향과 중단 기준

1. 이번49% 조건부 수치를 근거로 이 식을 생산 plant에 연결하지 않는다. 같은 계수 grid, 문턱, 셀별 계수 확대를 반복하지 않는다.
2. 다음 최소 후보에서 구분할 것은 ‘진출하려는 차량의 도착’과 ‘그 차량이 실제로 기다리고 빠져나가는 서비스’다. 전체 하류 평균속도와 비례 수송만으로 두 과정을 대신하면 위와 같은 조건부/자율 차이가 생길 수 있다. 이번 결과만으로 어느 요인이 원인인지 확정하지 않는다.
3. 문헌을 더 따라간다면 Zhou의 진출 차로 대기시간/서비스 관계 원식을 확보해 좁은 영역의 상태1개·소수 공통 계수로 검토하는 쪽이 타당하다. 정지차량 수에 임의 용량감소 배율을 붙여 ‘VSL은 항상 이득’으로 만들지 않는다. 우선 기존 Claude 기록과 거절된 후보를 확인한다.
4. 기준은150초 실제 방출·잔여와450초 큰 제어 손익/순위다. 현재 결과에는 RM 유지/완화 전체 검증, Ω 비용, AD, SDMPC 선택 성공이 포함돼 있지 않다. 작은 속도 오차나 작은 손익 부호를 계속 쫓을 필요는 없다.
