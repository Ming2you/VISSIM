# 관측 차로 이동을 준 조건부 원인 분리

2026-10-04. 기준 재현1회와 조건부450초 예측2회를 완료했다. **미래 관측을 사용하는 진단으로, 자율 이득 예측 통과가 아니다.** 정본 채택·새 계수 보정·VISSIM·FZP 재읽기·9000초 결과 분석·push는0이다. 목표 ACTIVE / NOT_QUALIFIED.

166에서 회복 구간의 차로 이동 반응 누락을 확인했다. 같은148 모델의 셀20–25 차로 이동만 관측된5초 전이로 대체해, 이것이 방출과 재고 반응에 영향을 주는지 검사했다. 셀19 반셀 교환, METANET/FD 계수, 실제 합류와 대기, 수요 예측, 동적 off 저장·배수·공유 수용, VSL 이력은 그대로 유지했다.

각5초 구간의 같은 셀 내 g→k 관측 전이 대수를 그 구간 시작의 실제 g차로 차량 수와5초로 나눈다. 이 분율에 매초 **모델의 현재 donor 재고**를 곱한다. 기존 수용 차로 저장 여유 제한·목적지별 차량 보존·속도 모멘트 전달은 유지한다. 관측 재고를 모델 재고에 직접 덮어쓰지 않는다.

이 분율은5초 끝점에서 보이는 부분 전이이며 전체 미시적 차로 변경률이 아니다. 경계 이동과 차로 변경이 겹친 표본은 포함하지 않는다. 실제 미래 차로 이동을 조건별로 주므로, 이를 명령에 따른 자율 반응이나 실현 가능한 MPC 입력으로 사용할 수 없다. 낙관적 성능 상한도 아니다.
