# 셀10–11의 실행 속도항과 셀 내부 상태 — REVIEW174

2026-10-04. **진단 완료, 모델 채택·이득 보정 완료 아님.** 직전 목표 턴은 172–173 인계의 커밋·원격 확인을 완료한 PROGRESS였다. 이번 턴에는 실제 실행 항과 관측 차량 구성의 영향을 분리했고, 다음 후보의 범위를 좁혔다.

## 같은 초기값인데 어디서 갈라졌나

173의 seed67 RM 완화110/90 두450초 예측을 소스·계수·수요·명령 그대로 재생했다. 셀10–11의 실제 속도 호출7,200개를 계측했고, 네 결과 표(cells/flows/ports/ramps)가 기존 저장본과 정확히 일치했다. 직접 재구성한 속도 갱신 오차는 최대1.42e−14km/h다. 모든 차로 호출에 해당 셀 계수와 길이가 전달됐다. 148의 문맥 소비 오류가 재발한 것은 아니다.

110 조건의 셀10·1차로는 같은 초기8대·53.565km/h에서 시작했지만, 첫5초 뒤 실측7대·24.814km/h, 모델6.551대·60.573km/h로 갈라졌다.

첫1초 모델의 속도 변화[km/h]는 다음과 같다.

|항|속도 변화|
|---|---:|
|차로 이동의 속도 혼합|−0.129|
|이완|+2.573|
|대류|+3.926|
|anticipation|+5.258|
|기존 유효 차로 감소|−0.135|
|실제 받아들인 합류에 따른 감속|0.000|
|합계|+11.493|

이때 목표 차로 밀도41.226대/km에 비해 다음 셀 밀도는12.674대/km다. 현 식은 이를 열린 하류로 해석해 가속한다. 반면 초기 관측 차량은 같은 셀 안에서 상류108/100km/h부터 하류18/21km/h까지 공간적으로 다르고, 상당수가 제동 중이다. **차로 평균을 분리한 것만으로 셀 내부의 감속 전선을 표현하지 못한다는 단서**다. 이것만으로 전체 오차의 유일한 원인을 확정하지 않는다.

## 차량 구성 변화만으로 설명되지는 않는다

5초 간 같은 차로·셀에 남은 차량과 진입·이탈한 차량을 따로 대조했다. 관측 평균속도 차이는 다음 항등식으로 정확히 나뉜다.

`Δv = [Σ_stay(v1−v0) + Σ_enter(v1−v̄0) − Σ_leave(v0−v̄0)] / N1`

첫5초 셀10·1차로의 초당 기여[km/h/s]는 남은 차량의 속도 변화−7.047, 진입 차량−1.122, 이탈 차량+2.418, 합계−5.750이다. 실제로 남은 차량들이 강하게 제동했다. 느린 차량이 유입되어 평균만 낮아진 경우가 아니다. 이 값은 독립 인과 기여율이 아니라 관측 끝점의 회계 분해다. 내부에서 여러 번 차로를 바꾼 이력까지 식별하지는 못한다.

1,426개 유효5초 셀·차로 구간에서 항등식을 검산했다. 제동/회복을 평균속도만으로 차량 가속도라고 해석하지 않는다.

## 공간 분할을 바로 채택하지 않고 먼저 검사했다

기존 물리 셀10은4542.539–4736.591m, 실제10639 합류는4698.745m다. 합류 전156.206m와 후37.847m를 현재 차량 위치로 구분했다. 초기1차로 차량은 각각5대와3대이며, 평균속도는70.492와25.353km/h다.

두 표현에 동일한153 계수와 기존173의 예측 합류량을 사용하고, 현재 밀도·이웃 상태·차량 구성을 고정한 채 속도만5×1초 갱신했다. 현재173의 동적 lane-drop 계수는 고정해 물리적 하류 경계에만 적용했다. 관측 미래는 채점용이며, 미래 실측 합류량이나 제동 상태를 입력하지 않았다.

**이 계산은 차량 수지를 갱신하지 않는 조건부 국소 ODE 진단이다.** 450초 자율 예측, 분할 셀의 보존 수송, 실제 합류·방출·대기·TTT 검증이 아니다. 두 구획 중 관측 차량이 없는 구간은 제외했고, 같은 표본끼리 비교했다.

## 다음 작업

먼저 148의 계수 문맥 전달 및149의 실제 합류 위치 처리 코드를 재사용할 수 있는지 확인한다. 셀10 내부의 위치별 목적지 재고·속도를 보존하며, 합류 차량은 실제 후단 구획에만 들어가고 두 구획/본선/램프가 수용 공간을 공유하도록 작은 후보 하나를 검토한다. 짧은37.8m 구획의1초 수송·속도 안정성, 유량과 속도 간 연결을 먼저 검증한다. 내부 적분 간격을 임의로 줄이거나 속도만 별도로 낮추지 않는다.

이후 동일 초기 RM 유지/완화·VSL 조건과 seed61 회복 등 기존 반례에서 합류·진출·전체 대기·큰 손익을 확인한다. 이번 조건부 이득을 이유로 계수 격자를 확대하거나 기존19–25 후보와 즉시 합치지 않는다. 필요하면 구조 정합 뒤에 국소 계수를 제한적으로 보정한다.

Claude의 F1/F2 검토는 수용-속도 연결과1/L 민감성의 참고다. 해당 문서도 F1이 TTT를 악화했다고 기록했고 망·계수가 다르므로 수치나 채택 판정을 옮기지 않았다. 48/50/51/52의 가짜 대기·회복 실패도 유지한다.
