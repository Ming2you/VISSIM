# REVIEW55 — 10643 하류 방출과 분할 차량 FIFO

이전 목표 턴은 REVIEW54의 차로별 합류 연결 검증과 복원을 완료한 진척이었다. 이번에는 기존 자료와 기존 국소 재생에 관측만 추가하여, METANET 셀 계수보다 먼저 확인할 하류 대기열 표현의 문제를 좁혔다. 생산 모델 수정이나 이득 보정 완료가 아니다.

## 먼저 재사용한 근거

`../entry10643/README.md`에서 seed47의 진입 부족 일부는 후속 목적지 구성 차이임을 이미 확인했다. 실제 확인된10643행90대와 모델 기대77.75대의 차이를 FD로 맞추지 않는다. 별도로 남는 배수·저장 오차를 검토했다.

`../urban10643_conditional`의 실제 도착·신호를 사용하는2700.1–3145.1초 재생을 재사용했다. 미래 실측 입력은 원인 분리용이며, 자율 예측·제어 이득 검증이 아니다. 첫 관측 재생 후 잔여 조각 크기가 필요해 같은 재생에 그 관측을 추가했다. 두 결과 모두 경과시간을 제외한 모든 기존 출력이 저장 결과와 정확히 같다. 국소 방출은 모델163.943대, 실측 보존식212대다. 삭제2대는 정상 방출에서 제외한다.

## 새로 확인한 막힘

71번 도로3차로는 녹색135초 중55초에10635행 세 차량의 차로 접근 때문에 방출하지 못했다. 해당55초의 횡방향 이동 합은0.0311대여서, 이때의 무방출을 횡방향 이동이 sending 예산을 모두 사용한 탓으로 설명할 수 없다. 반복되는 미사용 sending 합은24.15이며, 이를 고유 차량24대나 복구 가능한 추가 방출량으로 부르지 않는다.

12046은 모델에서0.999637708대가71의4차로 상류 셀에 있고,0.000362292대만3차로 정지선 셀에 있다. 그 작은 조각에 완전 FIFO 규칙을 적용해 뒤 차량이17초간 모두 막힌다. 질량 보존은 맞지만 한 차량의 물리적 위치·차로 변경과 같은 의미로 해석할 수 없는 분산이다.

## 합성 상태로 확인한 구조적 민감도

동일한3차로 총재고2대와 녹색, 만차인4차로 적색을 고정한6개의1초 상태를 시험했다. 앞의 진로 불일치 질량이1대,0.1대,0.01대,0.000362대,0.000001대일 때 모두 직진 방출0이다. 그 질량이0인 경우에만0.439579대가 방출된다. 각 상태는 모든 질량을 보존하며, 수지 오차는 최대4.44e-16대다.

이것은 수용량 개선안이나 앞 차량을 추월하도록 허용하는 실행 후보가 아니다. 연속적인 차량 질량 계산과 개별 차량식 완전 FIFO의 결합에 불연속 민감도가 있음을 확인한 진단이다. 조각을 삭제하거나 EPS를 키우는 수정은 하지 않았다. 이 원인이 전체 약48대 방출 부족을 모두 설명한다고도 주장하지 않는다.

## 다음 작업의 기준

셀 계수나 고정 배수율을 바꾸기 전에 분할된 차량 재고와 차로 변경·FIFO 적용의 일관성을 바로잡아야 한다. 대안은 차량/목적지 질량과 차로 수용 공간을 보존해야 하며, 순간이동·사후 실측 차로 강제·작은 조각 삭제로 해결해서는 안 된다. 기존 조건부 재생으로 원인을 분리한 뒤, 두 상태의 자율 배수·잔여·제어 반응에서 검증한다. 이 진단만으로 완전 FIFO를 없애거나 자유 추월 모델을 채택하지 않는다.

모든 생산 소스와9000STOP 해시는 기존과 동일하다. 새 VISSIM/FZP스캔/계수 보정/450초 전체망 예측/push는0회다. 전체 목표 ACTIVE/NOT_QUALIFIED이며, 새 실행을 시작할 근거로 사용하지 않는다.

근거: `assessment.json`, `assessment_prefix.json`, `prefix_evidence.json`. `audit.py`는 두 번째 관측 형태이며 각 실행 로그를 따로 보존한다. `prefix_sensitivity.py`는6개 합성 상태와 실제 차량 표본을 기록한다.
