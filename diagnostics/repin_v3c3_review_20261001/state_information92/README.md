# 추가 공간·차로 상태의 설명력 검사 — REVIEW92

2026-10-03. **기존 캐시 분석·제한된 통계 적합4회 완료. 새 plant 후보는 채택하지 않았다.** 새 VISSIM, FZP 읽기, 자율 예측, 운용 계수 변경, push는 없다. 전체 목표 ACTIVE / NOT_QUALIFIED.

## 질문

REVIEW91에서 현재 위치와 남은 이동거리를 넣어도 셀19·20의 VSL 이득을 재현하지 못했다. 같은 평균 밀도·속도 아래에 서로 다른 차로별 혼잡이나 차량 분포가 숨어 있는지 확인하기 위해, 추가 상태를 구현하기 전에 그 정보가 다음30초 속도 변화 예측에 얼마나 도움이 되는지 검사했다.

이 검사는 **방출량·TTT 예측이나 제어 효과의 검증이 아니다.** 같은 완전한 모델 상태에서 결과가 달라진다는 증명도 아니다. 비슷한 국소 평균 상태라도 경계·수요·인접 교통 이력이 다를 수 있다. 이번 결과로 METANET 평균 상태가 충분하거나 부족하다고 확정하지 않는다.

## 사전에 고정한 방법

- 기존 native5초 캐시의 동측 셀19·20, 총1,488개 cell/time 표본을 사용했다. seed29의576개를 적합에만, seed43의576개와67의336개를 평가에만 썼다.43·67은 이전에 본 자료로 완전한 신규 blind seed가 아니다.71은 읽지 않았다.
- 29·43 자료는2220.1–2970.1초,67 자료는기존 후기2670.1–3120.1초다.67은 REVIEW90의 새2700초 시작 실행이 아니라 앞서 검증한 후기 캐시다.
- 입력은 현재 자기·상하류 밀도와 평균속도, 자기 밀도 제곱·밀도×속도, 직전5초 자기 밀도/속도 변화다. 예측 대상은 `v(t+30)−v(t)`다.
- 추가 입력은 현재 셀의 속도 표준편차, 차로별 밀도 불균형, 차로 평균속도 차이, 셀 앞/뒤 절반 속도 차이, 차량 위치 중심,20km/h 미만·5km/h 미만 차량 비율의7개다.
- 셀별 기준/추가모형의 ridge 회귀4개를 한 번씩 적합했다. 학습 표준화, 비규제 절편, ridge1을 고정했으며 변수·가중치 탐색은 없다. 시간·seed·제어 조건명은 입력에 넣지 않았다. 실제 미래 관측은 평가/학습 정답에만 사용했다.
- 현재 속도 유지도 비교했다. 겹치는30초 표본은 상관되므로 표본 수를 독립적인 반복 실험 수로 해석하거나 유의확률을 제시하지 않는다.

기준 회귀는 **현재 METANET 자체가 아니다.** 현재 정보의 설명력을 검사하는 보조 도구다. 이 회귀가 잘 맞는다고450초 예측이나 VSL 효과가 맞는 것은 아니다.

## 판단

현재·과거의 평균 상태 자체에도 다음30초 변화에 대한 정보는 있었다. 그러나 차로별 불균형·속도 분산을 단순한 선형 추가식으로 넣는 개선은 제한적이었다. 이 근거로 새로운 분산 상태나 VSL 전용 속도 평준화 보너스를 운용 plant에 추가하지 않는다.

반대로 비선형 차로 상호작용, headway, 개별 가속 또는 충분한 공간 상태가 모두 불필요하다는 결론도 아니다. 이번 후보 집합과 회귀 형태에 한정된 결과다. 관측 정보를 추가하기만 하면450초 이득이 살아난다는 가정 대신, **기존 상태에서 혼잡이 발생·해소되는 전이식과 자율 예측의 반응**을 계속 구분해야 한다. 새 전이식 후보가 생기면 실제 유량·보존·대기 비용과 VSL 이득/손해 조건을 함께 통과해야 한다.

## 문헌과 적용 한계

[Fang 등(2019)](https://onlinelibrary.wiley.com/doi/10.1155/2019/8151582)은 차량 간격·개별 가속 정보를 METANET의 속도 조정 거리 항에 넣고 VISSIM 기반 MPC를 시험했다. 따라서 미시 관측을 보완 정보로 검토할 근거는 있다. 이번7개 요약변수 회귀는 그 논문 식을 구현하거나 검증한 것이 아니다. 미래의 차량 간격·가속도를 자율적으로 어떻게 예측할지도 해결해야 하므로 논문의 실측 입력을 미래 정답으로 주입하지 않는다.

[Frejo 등(2019)](https://www.sciencedirect.com/science/article/pii/S0968090X18303310)은 네덜란드 A12 자료에서120→90km/h 제한 시 용량 감소와 임계밀도 증가를 관측하고 VSL 모델을 비교했다. 해당 망의 결과를 우리 망의 용량 증가/감소 법칙으로 그대로 이식하지 않는다. Claude의 다른 망 해석도 같은 원칙으로 다룬다.
