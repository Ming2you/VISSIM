2026-10-03, REVIEW70. 동일 현재 상태에서450초 예측6회(기준43 두 조건, 후보43 두 조건, 후보47 두 조건)를 완료했다. 계산시간 합182.616초이며 준비/후처리 전체 경과시간은 아니다. 파라미터 fitting·새 VISSIM·FZP 재읽기는0회다. 후보를 채택하지 않았다.

## 앞선 사전 검사와 이번 검사 구분

REVIEW68의 현재 밀도 RMSE 검사는 네 조건에서4–7% 개선으로 사전10% 기준을 실패했고, 당시에는 자율 예측하지 않기로 했다. 그 실패 기록은 유지한다. 이번 결과를 보기 **전에** protocol.json에 절차 변경을 명시했다. 사용자 요구인 큰 손익 방향과 제어 순위는 공간 밀도 RMSE와 다르므로, proxy 기준만으로 동역학적 효과가 없다고 단정하지 않고 한 후보를 제한적으로 예측했다. 이전 기준을 통과했다고 재해석하거나 계수/구간을 추가 탐색하지 않았다.

Claude bd39205의 REVIEW 및 FWW P_PLANT를 먼저 대조했고, 다른 망의 계수나 배수 상한은 사용하지 않았다. 기존 경계 속도/minmod, 중심간 거리, 통과 밀도 후보 실패도 유지한다.

후보는 현재 예측된 셀 평균과 실제 셀 길이로 다음 셀 상류 절반 밀도를 minmod로 추정해 FW_E 셀16–20의 anticipation 입력에만 사용했다. 질량·유량 장부, 원래 길이와 다른 속도식 항, 실제 RM1초 녹색/적색 파형, 도시부, 동적 off-ramp, VSL 명령 이력, 물리 계수는 유지했다. 이는 진짜 운전자 인지 밀도를 식별한 결과가 아니며, anticipation의 유효 기울기 크기도 바뀌는 근사다.
