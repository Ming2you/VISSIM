# REVIEW77 — 현재 seed67 상태의 SDMPC 선택과 VSL 후보

2026-10-03. 직전 사용자 답변은 현황 설명으로 새 검증이 없었다(NO_PROGRESS). 이번에는 현재 U7/service66 플랜트로 **SDMPC 한 주기, 정확 실행 모델 재생, VSL100·90 두 후보**를 실제 계산했다. 물리 계수·수요·망·목적함수·실행 중인 DATA9000은 변경하지 않았다. 전체 목표는 ACTIVE / NOT_QUALIFIED다.

## 이번에 새로 구분한 것

REVIEW76의 실측 VSL 이득은 **동측 RM들을 4→6→8초 등으로 완화한 두 실행**에서 나온 조건 간 차이다. SDMPC의 이번 상한은 PFO 예측 달성량에 기존 여유를 더해 N_P=676.985대, N_UF=6019.608대/h로 정해졌다. 상한을 결과에 맞춰 바꾸지 않았다.

이전 고정 명령의 예측 N_UF는 release=6585.952, release+VSL90=6586.247대/h다. 따라서 두 명령은 **이번 상한 아래에서는 각각566.344·566.639대/h, 450초로70.793·70.830대 초과**한다. 실행 가능한 신호/미터 명령이라는 사실과 현재 공유 상한을 만족한다는 것은 별개다. 이전 실측 비교를 무효로 만들거나, 실제 VSL 이득이 없다는 뜻이 아니다.

반면 선택안 위에 VSL100·90만 넣은 아래 두 후보는 모두 N_P·N_UF를 통과한다. **VSL 자체가 제약 때문에 꺼진다는 설명과 강한 RM 완화가 상한을 넘는 문제를 섞으면 안 된다.**

## 실제 선택

- 10490 미터는 첫 블록 녹색5→6초, 다음 두 블록5초. 다른 미터는 직전 실제 녹색 유지.

## VSL 미선택은 두 후보의 손익 판단과 일치

최종 선택의 RM·도시 명령을 고정하고, 동측 S13만 세 블록 모두100 또는90으로 낮췄다. 진입부110과 다른 VSL 구역은 유지한다. 기존 정본 neighbor 도구로 연속 근사3회+정확 모델3회를 실행했고, 포함된 선택안 재생은 기존 결과와 정확히 일치했다.

| 선택안 대비 | 정확 ΔΩ TTT [대·시간] | N_UF [대/h] | 고정 N_P·N_UF |
|---|---:|---:|---|
| VSL110 유지 | 0 | 5886.730 | 통과 |
| VSL100 | +0.1145 | 5886.871 | 통과 |
| VSL90 | +0.5576 | 5887.337 | 통과 |

최적화 내부에서도110→100의 실행 가능한 유한 변화량을 평가했다. S13 세 블록×두 반복의6개 기록은 `executable_secant_fallback`이며, 그 단계에서 제한을 거는 방향의 비용이 늘었다. 따라서 **0미분 때문에 VSL 후보를 전혀 보지 않았다거나, 시험한100·90의 유리한 후보를 놓쳤다고 판단할 근거는 없다.** 모든 속도·구역·시간 조합을 탐색한 것은 아니다.

이 결과와 REVIEW76의 RM완화 조건 VSL 예측−0.0488은 서로 다른 RM·도시 명령이다. 이번의 손해 예측이 실제로 맞는지는 해당 명령의 native 비교가 필요하다. REVIEW76의 실제−2.065/예측−0.0488, off-ramp 도착·본선 회복 오차는 여전히 미해결이다.

## 보정 및 다음 판단

Claude REVIEW_CHECK의 VSL 설치/계수 해석과 기존10682 진입·차로 후보, 국소 E 시험, 공통 초기 차량/유입 분해를 먼저 확인했다. 과거 기각된 계수 격자와 미래 경계 주입 실험은 반복하지 않았다. 10682를 맞추려고 배수율을 일괄 낮추거나, VSL에 이득 보너스를 더하지 않았다. 이 작업은 새로운 동역학 보정의 채택이 아니다.
