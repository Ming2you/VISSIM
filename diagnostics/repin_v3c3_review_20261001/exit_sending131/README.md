2026-10-04. **기존 캐시 진단 완료, 모델 채택·보정 완료 아님. 목표 ACTIVE / NOT_QUALIFIED.** 직전 답변은 완료된128/130을 설명했으므로 NO_PROGRESS였다. 이번에는 실제 기록으로 새 가설을 검사했다. 권위 있는 결과는 `attempt2/`다. 새 VISSIM·FZP 읽기·물리 rollout·계수 fitting·9000초 결과 분석·push는 모두0이다.

## 구분한 질문

130에서는 시험 중인 공유 차로 모델의 셀20 진출 요청 `N_exit × v_lane / L`가 두 VSL 조건에서 거의 같았다. 이것이 **같은 차로의 진출행·통과행 속도를 섞었기 때문인지**, 아니면 식에 들어가는 **차로 재고·속도 예측 자체가 틀리기 때문인지**를 구분했다. 정지 차량을 합류/진출 원인으로 분류하는 검사는 아니다.

Claude의 `upstream_worklog/07_fww_sc1001eb/fww-struct/FWW_STRUCT_CHECK.md`를 읽었다. 비활성 수용 상한이나 정상상태 분기 항등식만으로 원인을 판정하지 않는다는 주의를 적용했다. 다른 서측 망의 수치·계수를 옮기지 않았다.91의 평균속도 이동거리 후보,108의 목적 차로 유지 후보,119의 두 구획 수송 실패와106의 위치 모멘트 장부를 재사용했다. 그 물리 후보들을 재실행하지 않았다.

## 자료와 계산

seed67 RM 완화 고정의 VSL110/90 기존5초 차량 캐시와 MER 사건,128/130의 기존 예측 기록만 읽었다. 실측 분석은2700.1–3120.1초,120+150+150초의 겹치지 않는 세 구간이다. 예측 기록은2670.1초에서 시작한 기존450초 계산의 해당 부분이며,2700.1초에서 실측으로 재초기화하지 않았다.

진출행 특징은 각 시점의 `NEXTLINK\\NO=10483`으로 구분했다. 나중에 실제 진출한 차량을 거슬러 입력 집단으로 고르지 않았다. 이 기간의 셀20 진출행 관측은 모두 실제 출구 차로인119의1차로에 있었다. 미래 위치·MER 사건은 방출 정답과 수지 검증에만 사용했다.

- 기존 요청식: `Q_lane = Σ N_exit(t) × mean(v_lane(t)) × 5/(3.6 L_m)`.
- 목적지별 속도식: `Q_class = Σ Σ_exit v_vehicle(t) × 5/(3.6 L_m)`.
- 두 식 모두 **매5초 실측 상태를 넣은 조건부 계산**이다. plant rollout이나 MPC가 사용할 수 있는 미래 입력이 아니다.
- 모델 셀 길이199.96815m를 두 식에 똑같이 사용했다. 실제 진출 경계는 셀 끝보다1.4073m 앞이므로, 위치 수지는 실제 접근 길이198.56085m로 따로 계산했다.
- 5초 시작점 적분과 사다리꼴 적분을 함께 계산했다. 평균속도와 평균재고를 먼저 구해 곱하지 않았다.

### 같은 요청식에 들어가는 상태가 다르다

가운데150초의 접근1차로 진출행 재고 평균은 **실측7.467/6.867대, 모델13.445/13.449대**다. 요청식에 대응하도록 진출행 재고로 가중한 차로 속도는 **실측21.440/29.851km/h, 모델8.452/8.485km/h**다. 실제 진출행 차량 속도 평균21.423/30.502와도 가깝다.

이는 속도계수 하나만 키우라는 결론이 아니다. 모델의 과도한 재고를 유지한 채 속도만 실측으로 대체하면 요청이142.28/110.99대로 오히려 커지고 제어 반응 방향도 틀린다. 재고만 대체해도9.85/11.74대로 부족하다. **N·v의 시간별 결합과 혼잡·회복의 변화를 함께 맞춰야 한다.** 이 교체는 이미 저장된 숫자에 대한 조건부 대수 계산이며 새 물리 예측이 아니다.

단순 시간평균 속도는 이 구간에서54.79/40.15km/h라 방향마저 다르다. 차량이 적은 자유류 시각에 큰 가중치를 주기 때문이다. 전체 차로 차량 표본 가중 속도는26.57/33.07km/h다. 서로 다른 평균 정의를 섞어 회복 방향을 판단하지 않는다. `interpretation.json`에 각 가중 정의를 구분했다.

기존 속도 추적에서도 모델의 가운데150초 셀20·1차로는 두 명령 모두95초에 진출 연동 속도 상한이 작동했고63초에최저속도5km/h에 닿았다. 그러나128에서 그 추가 연결만 제거하는 후보가 실패한 사실도 유지한다. 상한을 제거하거나 계수를 키우기만 하면 해결된다는 증거는 아니다.

## 위치 수지와 검지기 경계 검증

현재 진출행 차량의 셀 내부 위치 합 `M=Σ(x−x_start)/L_exit`를 이용해, 각5초에서 `진출 = 내부 이동거리/L_exit − ΔM`을 검증했다. 현재·다음 관측 사이의 진입/진출 차량 및 한 구간에 통과한 차량을 포함했다.168개 구간의 질량 수지 통과, 위치 수지 최대 오차1.33e−15대다. 미래 위치로 검증한 항등식이지 자율 방출 예측식이 아니다.

가운데150초의 진출 증가14대는 `내부 이동거리/L 증가10.9094 − 위치 모멘트 변화 차이(−3.0906)`로 닫힌다.131에서만 얻은 인과 기여율로 해석하지 않는다. 현재 상태 요청식과 실제 경계 방출의 나머지 차이에 비정상 위치 분포가 관계한다는 근거다.

MER의1m 검지기만 동일 시간 경계로 자르면28/43대가 나왔다. 차량22175는2970.1초에 이미10483의0.84m에 있었고 검지기 사건은2970.12초였다. 이 경계 사이 재고1대를 보정하면 실제 connector 진입29/43과 일치하며, 다음150초는46/45가45/45로 바뀐다. 사건 시각을 임의로 당기거나 기존 자료를 덮어쓰지 않았다. 해당 차량·프레임을 `boundary_witnesses.json`에 보존했다.
