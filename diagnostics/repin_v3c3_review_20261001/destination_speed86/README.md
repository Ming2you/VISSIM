# 진출행과 통과행의 속도 차이 — REVIEW86

2026-10-03. **진단 완료, 운용 모델 미변경, 이득 보정 미완료.** 이전 목표 턴은 해석 설명뿐인 NO_PROGRESS였다. 이번에는 기존 자료로352개 조건부 5초 창과 동일 실행의 실제 관측8개를 검사했다. 새 VISSIM·FZP 재스캔·예측·계수 보정·push는0회다. 기존 실패9000과 STOP을 유지했다.

## 새로 구분한 질문

현재 `offramp_routing.sending_requests`는 동일 셀의 총 sending을 목적지 재고 비율로 나눈다. 이는 그 셀의 진출행과 통과행이 같은 평균 방출 속도를 갖는 근사다. Claude REVIEW_CHECK K3/K4/K5와 기존 경로 재고·진입 구성·차로 유입 보정 기록을 먼저 확인했다. 기존 lane10682_inlet_flux의 **경계 유입 차로 배분**과 이번 **현재 셀에서 목적지별 방출 배분**은 다른 검사다. 이미 실패한 passive VSL 전달 순서 후보를 재실행하지 않았다.

## 조건부 검사: 속도만 반영해도 일반적으로 맞지는 않는다

기존 seed29/43 초기, seed67 후기의 NC/VSL 또는 RM완화/VSL 비교 캐시6개를 사용했다. 시작 때 실제 관측된 STATIC 경로만 추적했다. 경로가 끝나거나 차량이 본선 기록에서 처음 사라지면 그 경로를 더 이상 붙이지 않는다. 새로 들어온 차량과 미정 경로에 미래 실제 목적지를 부여하지 않았다.

진출행과 통과행이 함께 남아 있는352개 5초 창에서, **해당 관측 집단의 실제 총 셀 이탈 수**를 고정하고 두 방법으로 집단별 이탈을 나눴다.

- 재고 비율: `N_exit / (N_exit + N_through)`
- 속도 가중 비율: `sum(v_exit) / sum(v_all_known)`

이는 미래 총 이탈 수를 사용하는 조건부 표현 검사이며 자율 예측이 아니다. 본선 기록에서의 소실은 미분류로 남겼고 정상 진출·삭제·Ω TTD라고 판정하지 않았다. 합계 이탈량은 두 방법 모두 정확히 보존한다.

목적지별 5초 이탈 배분의 평균 절대오차 감소율:

|29 NC / VSL|71.8% /71.8%|−15.9% /−11.0%|
|43 NC / VSL|54.4% /50.0%|17.7% /16.9%|
|67 RM완화 /RM완화+VSL|42.6% /42.6%|18.3% /19.6%|

음수는 악화다. 두 하류 출구·각 상태에서20% 이상 개선한다는 사전 진단 관문을 통과하지 못했다. **단순 속도 가중 분기식을 운용 모델에 넣지 않는다.** 특히10483의 seed29 악화가 있어 특정 상태에서의 개선만으로 정당화하지 않는다.

창은 서로 독립 표본이 아니다. 초기 차량이 빨리 빠져나가는 출구에서는 관측 대부분이 VSL 영향 전이다. 따라서 이 표를6개의 독립 VSL 효과 검증이나 후반 재정체의 검증으로 부르지 않는다. 이 한계 때문에 다음 실제 현재 상태 검사를 별도로 수행했다.

## 동일 실행의 후반 현재 상태에서도 속도 분리가 확인됨

REVIEW76에서 Ω VSL 이득−2.065veh·h를 확인한 **동일한 두 native 실행**의2700/2850/3000/3150초 전체 COM 관측을 읽었다. 옛 FZP 캐시와 새 실행의 차량을 섞지 않았다. 네 동측 출구의 source cell과 바로 상류 셀, 총64개 분할을 검사했다. 실제 run ID·시각·전체 차량 수가 일치하고 각 분할에서 진출행+통과행+미정=전체 재고가 성립했다. 두 조건2700초의 대상 분할·차량 ID·속도는 정확히 같다.

이 두 분할에는 미정 경로가0대다. 같은 전체 `N·v/L`를 재고 비율로 나누면 진출행의 공간 유량을 진출행 자체 `N_exit·v_exit/L`보다 각각2.10배/1.25배로 계산한다. **실제 출구 처리량이 그 배율로 틀렸다는 뜻은 아니다.** 공간 유량과 경계 통과량은 다르며, 방출 위치·기간·차로 접근·수용 제한이 남아 있다.

2850초에는 같은 셀의 RM완화 진출행/통과행이87.61/89.19km/h로 거의 같지만, VSL90 상태는35.20/67.62km/h다.3150초에는 두 조건 모두 다시 비슷해진다. 따라서 한 출구의 고정 분기 보정값이나 항상 일정한 속도 비율로 설명하기 어렵다. 이 시점들의 국소 상태가 서로 다르므로 순수 VSL 인과 계수로 해석하지 않는다.

## 판단과 다음 범위

목적지별 속도 차이가 실제로 있으며 제어 후 상태에 따라 달라진다는 근거를 확보했다. 그러나 **속도 가중치 하나만 추가하면 VSL 이득이 재현된다**는 가설은 지지되지 않았다. 현재 모델의 전체10682 진입 과대와, 조건부 초기 차량의 진출 배분 과소가 동시에 존재하므로 분기율·배수 상한의 일괄 수정으로 덮지 않는다.
