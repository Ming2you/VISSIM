# 진출 목적지별 접근 차로 확인 — REVIEW49

2026-10-02. 기존 저장 궤적과 현재·과거 관측만 확인했다. 모델 계수나 실행 설정을 바꾸지 않았고 새 예측·VISSIM·FZP 재스캔·push는 없다. **이득 예측 보정은 미완료**다.

사용자 우선순위는 8개 off-ramp의 본선 진출·도시 배수·저장을 먼저 맞춘 뒤, 남는 셀 동역학 오차와 제어 손익을 검증하는 것이다. 전체 진출량 하나나 속도 오차 하나를 맞추는 작업으로 대체하지 않는다.

## 이번에 확인한 것

seed29와43의 2220.1초 초기 관측과 기존 5초 궤적 캐시의 차량 ID·셀·차로·위치·속도가 정확히 일치했다. 초기 관측에서 목적지를 아는 차량을 추적하고, 처음 본선 기록에서 사라지면 추적을 종료했다. 재진입 차량에 이전 목적지를 다시 붙이지 않았다. 목적지 미정 차량은 별도로 남겼다.

셀9 시작 경계(4,286.333m)를 건너는 것으로 관측된 초기 차량 집단:

| 자료 | 10643행: 차로1·2·3·4 [대] | 10682행: 차로1·2·3·4 [대] |
|---|---|---|
| seed29 NC, 학습 후보 자료 | 6·15·0·0 | 56·0·0·0 |
| seed43 NC, 독립 seed | 11·11·0·0 | 52·0·0·0 |

이 집단에서는 10643행43대 모두 실제 진출 연결 차로1·2, 10682행108대 모두 실제 연결 차로1에 진입했다. 이 통과 표본은 **모든 차량의 진출량이나 수요가 아니다.** 경계 앞뒤5초 끝점이 같은 차로인 것은 확인했지만 그 사이의 정확한 차로 이동 시각을 알 수는 없다.

현재 시점만 사용해도 접근 차로 정보가 있다. seed43 2250초와 seed47 2700초 모두 짧은 셀8에는10643행이0대였지만, 경계 앞500m에는 각각 차로1·2에1대씩 있었다.10682행은 각5대 모두1차로였다. 현재 앞1000m의10643행은43에서1·3·0·0대,47에서3·2·0·0대다. 표본이 작으므로 이를 미래 유입의 정확한 차로 비율로 고정할 근거는 부족하다.

## 직전 후보 실패에 주는 의미

REVIEW48의 시험 후보는 현재 셀8에 특정 목적지 표본이 없으면 네 차로에 균등 배분하고, 진출행에도 통과 차량과 같은 횡방향 교환률을 적용했다. 그 결과10643에 접근할 수 없는3·4차로에 약29대의 진출행 재고가 생겼다. 이번 관측은 그 가정이 실제 접근 차로 분포와 맞지 않음을 뒷받침한다. **이는 기각한 시험 후보의 오류이며, 현재 복원된 집계 모델에도 똑같은 가짜 재고가 있다고 단정하지 않는다.**

다음 연결 후보에서는 실제 기하와 현재·과거의 목적지별 접근 차로를 이용해야 한다. 균등 분배로 만든 가짜 대기를 FD·이완시간으로 보상하지 않는다. 이미 잘못된 차로에 있는 실제 초기 차량을 순간이동시키거나, 접근할 수 없는 차량을 즉시 진출시키거나, 차로별 수용 공간·공유 유량 상한을 늘려서는 안 된다.

10643행은 진입 경계와 출구 사이가 약100m여서5초 기록에서 바로 본선을 떠나는 차량이 많다. 구간 내부 노출량이 잡히지 않았다는 이유로 의무 차로 변경률을0으로 보정할 수 없다. 현재 자료는 접근 차로의 제한을 지지하지만, 모든 목적지의 상태별 횡방향 교환 계수를 식별하지 못한다.

## 독립 검증으로 세지 않은 자료

NC와 VSL 캐시는 각 seed에서151프레임 중144프레임이 달라 서로 복제된 파일은 아니다. 그러나 이번 초기 집단의 접근 경계 통과와 차로 변경 기록은 두 조건에서 같았다. 따라서 NC/VSL을 합쳐 표본을 두 배로 세거나, VSL 반응의 정확성을 검증했다고 하지 않는다. 새로 들어온 차량의 목적지는 이번 초기 집단 표지로 추정하지 않았다. 미래 궤적은 관측 분석에만 썼고 예측 입력으로 사용하지 않았다.
