입력 차량 구성이 바뀌어 공간 평균속도가 달라질 수 있다. 기존134의 동일 차량/유출입 구성 장부를 연결했으며, 그 한계를 지우지 않았다. VSL90의 노출 이력을 nominal90 하나로 대체하지 않기 위해 식 비교는110에 한정했다.
