# REVIEW128 — 합류 감속과 진출 차단의 분리 시험

2026-10-04. 기존 짧은 기록으로 450초 예측 16회를 완료했다. 계산 49.857초이며 SDMPC 최적화 반복 시간은 아니다. **모델 기구 진단 완료, 정본 채택 없음, 전체 목표 ACTIVE / NOT_QUALIFIED.** 새 VISSIM·FZP 읽기·9000초 결과 분석·계수 적합·push는 없다. 직전 사용자 설명 턴은 새 검증을 만들지 않은 NO_PROGRESS였고, 이번 턴은 아래 증거를 추가한 PROGRESS다.

## 조건과 해석 범위

seed67의 동일 2670.1초 초기 상태, RM 유지/완화 × VSL110/90 네 명령에 대해, REVIEW124 공유 차로 구조와 REVIEW127 eval_00의 고정 계수를 사용했다. 127에서 탈락한 재보정 계수를 채택한 것이 아니다. 자료의 미래 30초 본선 진입량을 각 30초 안에 균등하게 넣어 입력 오차를 분리했다. **따라서 자율 예측도, 운영 가능한 제어기 검증도 아니다.** 미래 실측 합류·차단·속도는 입력하지 않았다. 조건별 본선 진입량이 다르므로 실측 비용 차이 전체를 내부 동역학의 인과 효과로 부르지 않는다.

네 모델 설정은 다음과 같다.

- `both`: 기존 공유 차로 시험 모델.
- `no_merge_penalty`: 셀19–25 중 합류 셀21·23의 명시적 METANET 합류 속도 감속만 제거. 상류 합류 셀10·12, 실제 합류 배분·수용·재고·램프 대기는 유지.
- `no_exit_feedback`: 셀19–25의 추가 같은 차로 진출→직진 제한,10483 직진→진출 제한, 진출 차단에 따른 속도 상한을 제거. 진출 요청·유한 저장·배수·실제 진출 차량 보존, 기존 저장 점유율에 따른 유효 차로 감소, 셀21 수용 제약·기하는 유지. **off-ramp 동역학 전체를 제거한 시험이 아니다.**
- `neither`: 위 두 부분만 함께 제거.

항 제거는 원인 분리용 극단 설정이다. 허용 제어 명령이나 채택 후보로 간주하지 않는다. 물리 규칙을 유지해도 속도 변화로 실제 수용·합류량은 내생적으로 달라질 수 있으며, `rows.json`에 램프별 실제 예측 합류량을 함께 기록했다.

TTT는 이 진단의 **동측31셀+4진입·4진출 커넥터**에 대한 30초 재고 사다리꼴 적분[veh·h]이다. 전체 Ω TTT와 다르다. 기존 `exits` 필드는 본선→off-ramp 진입과 본선 말단 유출의 합으로, Ω TTD도 이 TTT 영역의 정상 외부 유출도 아니다. 둘의 구분은 `discharge_windows.json`에 추가했다.

## 확인된 효과

매초 차로별 속도 갱신을 기록했다. 기존 설정에서 명시적 합류 감속은 셀21·23, 추가 진출 차단 속도 상한은 셀20에서 작동했다. 16회 전체에서 두 명시적 감속이 **동일 셀·차로·동일 갱신에 함께 적용된 횟수는 0**이었다. 이는 두 항의 직접 중복 차감이 관측되지 않았다는 뜻이며, 기존 anticipation·유효 차로 감소·보정 계수와의 중복 설명까지 배제한 것은 아니다.

합류 감속을 끄면 진출 차단도 줄었다. RM 완화/VSL110에서10483 공동 수용 제한 작동 시간은 **260→97초**, VSL90에서는 **265→98초**였다. 합류 감속이 하류 수용과 상류 진출 대기에 영향을 주는 모델 내 간접 연결이 실제로 작동한다.

RM 완화/VSL110에서 두 기구의 TTT 상호작용 `both−no_merge−no_exit+neither`는 +2.161 veh·h였다. 이 값은 모델의 비선형 상호작용이며, VISSIM에서 실제 중복 손실이 2.161이라는 뜻은 아니다.
