# 셀19 분할 속도식의 계수·길이 전달 오류 수정

2026-10-04. 구현 오류 수정과 8조건 재검증 완료. **제어 이득 보정은 미완료이며 정본 채택하지 않았다.**

144의 셀19 두 구획 모델은 여섯 차로·구획 속도 갱신 전에 `segment_vsl`을 한 번만 호출했다. 이 호출이 설정하는 셀별 계수 문맥은 첫 속도 갱신에서 소비된다. 따라서 첫 계산은 셀19 계수와 전체 셀 길이를, 나머지 다섯 계산은 공통 계수를 사용했다. `physical_length_km`을 명시하고 매 계산마다 문맥을 다시 설정하도록 기존 진단 helper를 수정했다. 이 문제는 공간 분할이 없는132의 실행을 무효화하지 않는다.

12회 식 검산에서 기존 실행의 문맥 활성은 `[true,false,false,false,false,false]`였다. 수정 후 여섯 계산 모두 해당 셀 계수·99.984m 길이를 사용하며 직접 계산한 FD/상태 반응/METANET 값과 오차0이다. 다른 물리 메서드9개와 기타 실행 소스는 그대로다.
