## 단 하나의 변경

정상148의 모든 실제 수송·합류·저장·배수·공유 차로 FIFO·하류 수용·VSL 이력과132 계수는 유지했다. 기존 허용 이동률 기반 속도 `v_cap=(q_through+q_off)L/(T*N)`를 속도 갱신 후 평균속도에 즉시 적용하는 대신,동일 조건에서 METANET 목표속도 `V_target=min(V_target,max(v_min,v_cap))`에 적용했다. 이완시간·대류·anticipation·합류 감속은 기존 값 그대로다. 새 반응시간·용량·제어 보너스는 없다.

이것은 관측에서 지지되는지 검사할 유한 반응 가설이다. 문헌의 검증된 완성 모형이라고 주장하지 않는다. 평균속도가 현재 경계 처리량과 즉시 같아야 한다는 근사를 완화하지만,정확한 대열 선두 위치나 미시적 정지·재출발을 구현한 것은 아니다.135의 제약 삭제와 달리 제약은 기존 목표속도 이완에 남아 있다.
