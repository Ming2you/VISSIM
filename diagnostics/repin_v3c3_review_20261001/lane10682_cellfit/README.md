# REVIEW51: 새 동역학 위의 제한적 셀 보정과 남은 연결 오류

이번에는 REVIEW50의 차로·목적지별 보존 동역학을 그대로 두고 **0기준 셀11의 세 계수만 실제로 재보정**했다. 전체 셀별 보정을 완료한 결과가 아니다. 동역학을 먼저 확인하고, 남는 국소 오차를 계수로 보정한 뒤, 공통 초기 상태에서 제어 손익을 확인한다는 순서는 유지한다.

## 실행 범위

- seed29 무제어 2220.1–2970.1초 관측으로 임계밀도와 밀도차 부호별 anticipation 두 계수를 추정했다. 최대 20회 함수평가/100회 잔차 호출 중 실제 잔차 호출은 28회였다.
- 유효 임계밀도 44.908→27.817, anticipation 15.519→7.759 및 21.550→10.775. 두 anticipation 계수는 사전 설정한 하한에 도달했다. 다른 셀, 이완시간, FD 모양, 합류·수용, 도시 신호·목적함수는 유지했다.
- seed43 네 조건과 seed47 두 조건, 총 여섯 번의 450초 자율 예측을 완료했다. 계산시간 합 193.595초이며 병렬 실행의 전체 경과시간과 다르다.
- seed47 두 조건은 RM 유지와 도시 신호 선택 명령이다. RM 유지/완화의 별도 검증을 완료했다고 해석하면 안 된다. 명령은 주어진 것을 재생했으며 새 SDMPC 선택을 실행하지 않았다.
- 실행 코드 7개는 REVIEW50과 바이트 단위로 같아 기존 22개 엔지니어링 검사를 재사용했다. 이번에 새로 확인한 것은 실제 실행 속도식 1,800행의 재구성(최대 오차 1.42e-14), 세 설정 필드 변경 및 자율 예측이다.

## 계수보다 먼저 확인할 연결 문제

저장된 실제 계산 항에서 셀9의 직접적인 속도 후처리 제한은 두 상태 모두 0이었다. 따라서 이 예측의 저속을 직접 off-ramp 속도 제한 하나로 설명할 수 없다. 수용 제약이 유량을 통해 간접 영향을 주는 가능성까지 배제한 것은 아니다.

현재 유입 추정은 통과 차량에 대해 짧은 셀8의 차로 비율을 450초 동안 고정한다. seed47에서는 통과 차량 **3대**로 2차로 66.7%, 3차로 33.3%, 4차로 0%를 정했다. 같은 현재 시점의 상류500m에는 37대가 있고, 속도 가중 분포는 2·3·4차로 36.1/32.9/31.0%다. 넓은 구간의 분포가 정확한 미래 경계 유량이라는 뜻은 아니지만, 작은 표본을 고정하는 연결 가정은 먼저 검증할 필요가 있다. 초기 차량 자체를 다른 차로로 옮기는 수정은 허용하지 않는다.

다음은 이 인과적 유입 배분을 하나의 제한된 후보로 검증하는 것이다. 이번 보정 예산을 늘려 셀 계수를 계속 탐색하지 않는다. 상류 유입과 off-ramp 진입·배수·저장 연결을 확인한 뒤, 남는 셀 계수를 보정하고 독립 상태의 큰 제어 손익과 순위를 검증한다. 새 유입 후보는 아직 구현·검증하지 않았다.
