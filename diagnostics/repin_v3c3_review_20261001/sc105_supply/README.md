# SC105 공급 오차와 선택망 경로 비율 연결 수정

2026-10-02. **PROGRESS / 전체 목표 ACTIVE·NOT_QUALIFIED.** 직전 목표 턴은 기존 검토 결과 재확인이어서 no progress로 분류했다. 이번에는 상류 공급의 장부를 추출하고, 선택망과 다른 두 목적지 비율을 실제 코드 경로에 연결해 다른 seed까지 확인했다.

## 확인하고 바꾼 것

10565는 이미 무신호 서비스로 처리된다. 원래 서비스 상한936대/h도 설치되어 있다. 그런데 seed47 유지 예측의 뒤 두150초 창에서 준비 큐가 거의 비고, SC105 북측의 연결도로행 공급도 창당9.96대뿐이었다. 신호 연결이나 서비스 상한을 올려 해결할 증거가 아니다.

선택망64cf에 저장된 native 경로와 현재 플랜트의0824 비율표를 대조해 다음 불일치를 확인했다.

| SC105 접근로 | native 결정 | SC1005 연결도로행 기존 비율 | 올바른 native 설정 |
|---|---|---:|---:|
| 북측 N_SC1002 |1043|0.629400|602/797 = 0.755332|
| 서측 W_SC1003 |1041|0.234923|78/249 = 0.313253|

다른 목적지도 같은 결정의 전체 상대유량으로 함께 정합했다. 원점별 합은1이며 차량 입력량·VISSIM 경로·망·명령은 그대로다. 실측 통과 비율을 피팅하지 않았다. 동측1042의 해당 비율은 이미 정합하므로 추가하지 않았다.

기존 `configure_native_choice_groups`를 사용했다. 북측1043은420→10659/10660→1220007200처럼 동일한 두 도로 사이에서 병렬 connector를 사용한다. 기존 검사는 이를 서로 다른 접근로로 거부했다. 도로 경로가 같고 모든 연결이 연속된 경우만 인정하도록 수정했다. 중간 차량 입력·다른 경로 재선택·다른 수신 저장고는 계속 거부하며, 최초 decision 이후의 추가 진입도 거부한다. 임의의 복잡한 회랑을 허용하는 변경이 아니다.

현재 후보는 [candidate_config.json](candidate_config.json)이다. 기존 SC1001 후보에서 경로 증거 파일 참조 한 곳만 바뀌고, 증거에는 위 두 그룹만 추가됐다. 과거 실험 설정 파일은 보존했다. 미래 목적지 prior 정합이며, 이미 경로를 선택한 초기 차량의 위치·차로·도착시간 문제가 모두 해결됐다는 뜻은 아니다. beta를 사용하는 기존 서비스 배분의 파생값도 바뀔 수 있으나, 새로운 서비스율이나 물리 계수를 피팅하지 않았다.

## seed43의 기존4조건으로 확인

10681 무제어의 도착은123.77→127.22대, 합류는113.10→113.23대, 종료 재고는63.66→66.99대다(실측 도착137·합류133·종료56). 늘어난 도착 대부분이 대기로 남는다. 전체32개 램프×조건의 도착/합류/종료재고 MAE는8.17/6.97/4.54→7.59/6.93/4.87대로, 재고 오차는 악화했다. 작은 절대 TTT 감소만으로 채택 성공이라 하지 않는다.

이전 seed43 예측은 기존 저장 결과를 재사용했다. 그 이후 일반 숫자 동등성이 검증된 미분 보존 수정들이 있었으므로, 이번 비교를 두 소스 버전의 완전한 재실행 비교라고 표현하지 않는다. 새 후보의 실제 명령표·원본 초기 상태 SHA는 기존과 같다.

## 검증·작업 범위

- 변경 함수는 진단 driver의 `probe_levers`와 기존 경로 연결의 `configure_native_choice_groups` 두 개다. 새 runner/adapter는 없다.
- 진단2회450초는 앞선 출력·추적 전체와 벽시계 및 새 진단 필드를 제외하고 정확히 같다. 물리 결과를 바꾸지 않고 원래 장부를 추가 저장했다.
- 후보6회450초 완료: seed47 유지/선택2회, seed43 4조건. 전체8회 예측189.75초. 소유 세션35405·86994·10012 모두exit0. 기존 초기화89473/audit.json은 재사용했다.
- native 경로·비율·보존과 잘못된 중간 입력/경로/수신 거부 시험5개 통과. 수정 전 native 병렬 경로 거부 실패를 보존했다. 실제 두 초기화에서 기존4개와 새2개 그룹이 설치됐다.
- 8램프 보존 잔차 최대4.98e−13대. seed47의 정본 물리 재고·자원 한도 검사 통과. 명령표와 이전 결과 파일·생산 계수·선택망 SHA 유지.
- 새 VISSIM·FZP 재스캔·계수 fitting·최적화·push는0회. 기존9000 STOP 유지. 실제 proof 범위는 `assessment.json`과 `protocol.json`을 따른다.

## 다음 작업의 범위

이번 근거로 SC105의 비율이나 서비스율을 더 맞추는 탐색을 반복하지 않는다. **10681에서 추가 도착이 실제 합류로 이어지지 않는 단계**를 기존 큐·차로·head 서비스·본선 수용 장부로 분리한다. 초기/과거 관측에서 알 수 있는 원인만 운영 예측에 반영하며, 필요한 실측 미래 경계 조건부 진단은 원인 분리용으로만 명시한다.

전체 목표에는 독립 상태의 RM/VSL/결합 손익·선택 순위, SDMPC 선택과 감도·실행, 최종9000초 및 matched NC가 여전히 남아 있다. 이번 연결 정합으로 그 자격을 대신하지 않는다.
