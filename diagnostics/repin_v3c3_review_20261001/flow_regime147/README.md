## 셀 내부 합류 위치가 유량 근사에 미치는 부분

선택망의 실제10484 합류점은7,603.745m다. 셀23은7,498.791–7,663.052m이며 합류점은 **상류에서104.955m(63.895%)**, 하류 끝까지59.307m인 위치다.31셀 소속은 맞지만 합류 차량이 셀 전체164.262m를 통과하는 것은 아니다.

현재 `offramp_routing.py`는 실제 합류점으로 셀 번호를 검증한 후 merge runtime에 freeway/cell/route weights를 남긴다. 해당 셀 내부 좌표는 이 재고 수송 경로에 보존하지 않는다. 공유 차로 모델은 허용된 합류 차량을 그 셀 차로 재고에 더하고 같은 공간 평균속도의 요청 계산에 포함한다. 차량 누락이나 잘못된 셀 매핑이 아니라 **셀 내부 위치를 평균화하는 근사**다.

5초 차량 ID·본선 좌표와 실제 램프 이탈 사건으로 다음 위치 수지를 검증했다.

```
하류 통과 = 셀 내부 종방향 이동 대용량/L
           + 합류 위치 비율 × 실제 합류 대수
           − 셀 내부 정규화 위치합의 변화
```

여기서 이동 대용량은 두 관측 끝점과 경계·합류 위치로 구성한 본선 좌표 이동이다. native 연속 주행거리나 전체Ω 주행거리와 같다고 주장하지 않는다. 미래 위치와 실제 합류량은 이 장부 검증의 정답이며 운영 예측 입력이 아니다.

RM 완화·110의 **중간150초**는 `238.259 + 19.807 − (−1.934) = 260대`로 정확히 닫힌다. 같은 창에서 실측 상태의 `ΣN*v/L` 요청은239.841대다. 위치 수지의 합류항 규모가 그 차이와 비슷하지만, 이를 오차의 독립 인과 기여율로 해석하지 않는다.

VSL90 조건은 `249.494 + 21.085 − (−1.420) = 272대`다. 실제 추가 방출12대의 수지는 이동 대용량 차이11.236, 합류 위치항 차이1.278, 위치합 변화 차이−0.513으로 닫힌다. 합류 위치항 하나만이 VSL 이득을 만드는 구조가 아니다.

**0.639×합류량을 방출량에 그냥 더하는 수정은 하지 않았다.** 자율 모델에서는 그 차량의 이동·위치 재고·하류 수용을 함께 갱신해야 하며, 미래 위치합 변화를 답으로 넣어서는 안 된다. 이 수지가 정확하다는 사실도 자율 예측 검증을 대신하지 않는다.
