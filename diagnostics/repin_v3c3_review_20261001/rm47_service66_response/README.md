# 최신 U7·정지선 후보의 큰 RM 반응 및 SDMPC 연결

2026-10-02. 전체 목표는 ACTIVE / NOT_QUALIFIED다. 이전 REVIEW60은 실제 수정·예측 검증을 완료한 진척이었다. 이번에는 그 후보가 큰 RM 반응을 보존하는지와 실제 제어 계산 경로를 검증한다. 소스 계수·망·수요·목적함수는 바꾸지 않는다.

## 먼저 재사용한 Claude 및 기존 증거

- Claude `upstream_worklog/02_urban_b2/impl/STAGE3.md`의 U4는 공급이 충분한 구간의 포화 서비스 식별이다. 현재 온라인의 녹색 전체 평균 통과율 하한과 같은 추정량이 아니다.
- `upstream_worklog/07_fww_sc1001eb/fww-struct/S_STRUCTURE.md`는 관측 통과율을 진출 용량으로 쓰는 한계를 이미 지적한다. 다른 망의 계수나 관측 미래 유량을 가져오지 않았다.
- 우리 `sc1001_route_inventory_s43`에 seed43 네 조건의 유량 수지 분해가 이미 있다. 이 계산을 새로 만들지 않고 재사용했다. RM 동측 ΔTTT −1.2792 중 본선 진입량 차이의 수지 기여가 −1.7292 차량·시간이므로, 이를 전부 회복 계수의 목표로 삼지 않는다. 이 수지 분해는 인과 분해가 아니다.
- 동일 prefix가 검증된 seed47 2700초 RM 유지/완화 쌍과 기존 native 분석을 재사용했다. 신호와 VSL110은 같고, 10484만 녹색2초 유지 대4→6→8초 완화다. 다른 미터까지 모두 해제한 조건이 아니다.

## 큰 RM 이득 방향은 보존

최근 link66 도착·목적지 초기화와 공유 head 서비스 후보를 그대로 사용해 두 명령을450초씩 재생했다. 미래 실측값은 평가에만 사용했다. 원래 실행된 세 블록 명령과 정확히 같고, 두 예측의 초기 전체 물리 재고도 같다.

| 완화−유지 | native | 현재 모델 |
|---|---:|---:|
| 동측 본선 진입 [대] | +1 | 0 |
| 동측 합류 [대] | +50 | +40.77 |
| 동측 진출 [대] | −18 | −11.44 |

10484 합류 예측은45.31→86.01대다. 램프 대기를 줄여도 본선 방출 감소에 따른 비용이 더 커져 유지가 유리하다고 예측한다. 기존 목적지 재고 결합 후보의 Ω 차이+1.2053과 거의 같아, 최근 link66 수정으로 새로운 RM 이득을 만든 것은 아니다. 예측 크기의 오차는 남지만 이 사례에서 RM 이득을 전혀 보지 못한다는 설명은 맞지 않는다.

현재/150/300/450초 정본 stock witness와 전체 transfer 수지를 확인했다. 최대450초 재고 수지 잔차1.30e−8대 미만, 물리 자원 초과7.78e−16대 미만이다. 두 예측 계산 합50.519초이며 초기화·후처리를 포함한 벽시계 시간은 아니다.

native Ω 값은5초 기록에 마지막4.9초 재고 유지를 포함한다. 기존 삭제·미해명 disappearance 제한은 원래 분석에 남아 있다. 모델 외부 추적 체류 차이−0.000002와 native 외부 체류−0.4986은 측정 범위가 같다는 보장이 없고, 미삽입 대기를 포함한 native 전체 비용으로 대체하지 않는다.

## 실제 SDMPC 미분 경로

현 후보로 정본 controller worker의 AD1회와 독립 scalar11회를 실행했다. 같은 AD 출력을 scalar 정답으로 재사용하지 않았다. 20개 비용 분할과 N_P·N_UF 두 값의 기준 출력 차이는 각각2.85e−14,1.14e−13 이하였고, 아래 세 축의 비용·자원 미분은 선언한 허용오차 안에서 모두 통과했다.

| 첫 블록 축 | AD Ω 미분 | 독립 중앙차분 |
|---|---:|---:|
| 10484 녹색 [1초당 차량·시간] | −0.0747580184 | −0.0747580171 / −0.0747580182 |
| SC1004 p1 녹색 교환 [1초당 차량·시간] | +0.0468772166 | +0.0468772173 / +0.0468772168 |
| 동측 VSL 구간13,110km/h [1km/h당 차량·시간] | 0 | 0 |

SC1004 p1 축은 주기 합을 보존하는 기존 green 좌표이며 p1 증가만 단독으로 더하는 명령이 아니다. 이 미분은 연속 근사 모델의 국소 미분이다. 10484 첫 블록 미세 완화가 유리한 것과 세 블록4→6→8 완화가 손해인 것은 다른 후보에 대한 판단이다. 유한 명령은 정본 비용·제약으로 다시 확인해야 한다. VSL110의 국소0은 허용 범위 전체에서 VSL 효과가 없다는 뜻이 아니다.

미분 시험 경과172.334초. 전체 상태 궤적의 AD/scalar 동일성이나 모든237축을 검증한 것은 아니다. 기존10490 녹색5초의 비매끄러운 미분 차이도 이번 세 축 통과로 해결했다고 하지 않는다.

## 제약·선택 구분

두 고정 명령은 writer·블록 간 실행 제한을 통과했다. 이 시험 자체에는 새로운 PFO/N_P/N_UF 예산 선택이 없다. 과거473.589대 상한을 새 모델의 현재 선택 상한이라고 해석하면 안 된다. 현재 `sdmpc.solve`는 매 주기 PFO를 실행하고 `sdmpc_budget.initialize`에서 현재 예측 달성량+명시된 여유로 상한을 새로 정한다. 기존 고정 상한을 수정하거나 위반 후보를 통과시키지 않았다.

같은 후보의 새 SDMPC 한 주기 계산과 선택 명령의 정본 재생을 완료했다. 새 PFO 달성량 N_P595.388대/N_UF5841.045대/h에 각각 기존 설정 여유100을 더해 상한695.388/5941.045를 만들었다. 과거473.589 상한은 사용하지 않았다.

- 첫 블록10484 녹색2→3초, 다음 두 블록은2초다. 나머지 미터는 실제 직전 명령을 유지한다. VSL은 모든 블록110을 유지했다. 도시green/offset도 변경했다.
- PFO2회 중1회 수락 후, S-DMPC는1회 평가에서 `no_executable_step`으로 추가 개선 없이 PFO 후보를 선택했다. 수렴·전역 최적해를 주장하지 않는다.
- 내부 예측29회(AD5+scalar24), controller 경과337.753초. 별도 전체 decision budget 기록344.443초에는 로딩·출력 등의 범위 차이가 있다.
- 연속 근사 ΔΩ TTT−6.20284, 정확 실행 시간 규약 재생−6.20186 차량·시간. 두 정본 재생은 writer binding·전체 stock witness·물리 자원·현재 고정 N_P/N_UF 상한을 통과했다.
- 정확 재생의 선택 N_P596.142/N_UF5844.532, 유지607.489/5739.801이다. 둘 다 이번 상한을 통과한다. 상한을 결과에 맞춰 다시 넓히지 않았다.

선택안의 정확 비용 차이는 동측+0.72827,서측+0.09998,8램프+0.08265,Ω전체−6.20186이다. 추적된 외부 체류는+5.21933 늘어 추적 전체 비용 차이는−0.98253이다. 따라서 Ω 감소 전체를 본선/RM 이득이라고 해석하면 안 된다. native의 같은 크기 개선은 아직 검증하지 않았다.

## 선택안에서 RM과 도시 명령을 분리

기존 component 검사로 선택안·도시만·RM만 세 후보를 같은 고정 상한에서 각각 연속 근사/정본으로 비교했다(3+3회). 선택안 재생이 직전 계산을 재현했고, 모든 후보의 정본 N_P/N_UF 제약을 통과했다. 새 최적화나 보정은 없다.

| 후보 | 정본 예측 ΔΩ TTT, 실제 유지 대비 [차량·시간] |
|---|---:|
| 선택 도시+RM | −6.20186 |
| 선택 도시만, RM 유지 | −6.18033 |
| 선택 RM만, 도시 유지 | −0.02167 |

도시 명령 위에서 RM 변경의 추가 예측 이득은0.02153 차량·시간으로 매우 작다. RM이 물리적으로 움직이지 않은 것도, 이번 후보가 제약 때문에 탈락한 것도 아니다. 현재 모델이 보는 이 한 단계 완화의 순이득이 작다. 이 작은 수치를 맞추려고 추가 계수 격자를 반복하지 않는다. 강한4→6→8 완화가 손해라는 앞의 결과와도 모순되지 않는다. VSL의24개 유한 후보 평가는 실행됐지만, 모든 VSL 조합의 최적성이나 실제 VSL 이득 부재를 뜻하지 않는다.

수치는 `selection_assessment.json`과 원본 solver/정본/component 결과를 참조한다. 이 데이터는 새 선택 명령의 실제 VISSIM 검증이 아니다.

## 남은 범위

seed43 VSL 손익 방향, 다른 상태의 도시부 방출 반응, 전체237축의 독립 미분과 native 실행 검증은 미완료다. 이번 한 상태의 선택·RM 반응·세 축 시험을9000초 자격으로 대신하지 않는다. 이미 확인한 입구 실현 차이 이전의 VSL 셀16–20 방출 반응 및 link71 도시 방출 오차를 다음 판단에 사용한다. 같은 목적의 계수 격자나 이 작은 RM 선택 차이의 부호 맞추기를 반복하지 않는다. 기존 STOP·운영 기본값·사용자 프로세스를 보존했고, 새 VISSIM·FZP 재스캔·보정 fitting·push는 없다.

초기 helper 보관 바이트 재구성 검사 실패와 상세 trace 옵션 사전검사 실패는 예측 시작 전이었다. 이전 실행 helper 원본과 `run.log`를 보존했고, trace 옵션만 제외한 `run_v2.log`에서 두 예측이 완료됐다. 상세 수치와 출처 해시는 `assessment.json`, `derivative_assessment.json`, 실행 선언은 `protocol.json`을 따른다.
