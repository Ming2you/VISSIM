- 직전 셀에 해당 목적지 표본이 없으면 **현재 관측의 경계 상류500m**에서 목적지별 차로 분포를 사용한다. 표본이 있으면 실제 관측을 유지한다. 진출행 표본이 전혀 없을 때만 실제 출구 연결 차로에 균등한 기하 사전분포를 둔다. 미래 차량을 관측한 것처럼 취급하지 않는다.

- 수락된 차량 이동과 속도 모멘트를 전달하고, 목적지별 교환이 공유 수용 공간을 나누도록 했다. 통과량 보너스·capacity 증가·FD/이완/anticipation 보정·목적함수 변경은 없다.
