# 공유 차로의 진출·통과 방출 연결 — REVIEW123

2026-10-03. **조건부450초2회 완료, 자율 이득 보정은 미완료.** REVIEW122의 사용자 보완을 유지한다. 이번 결과는 기존 셀 계수를 고정한 진단이며, 동역학 변경 후 셀 재보정의 설명력 한계가 아니다.9000초 분석·새 VISSIM·FZP 재읽기·fitting·push는 하지 않았다.

## 바꾼 연결

기존121 진단 경로에 `--shared-lane` 옵션을 추가했다. 새 runner/adapter는 만들지 않았다.121의 실행 당시 스크립트는 `probe.before_shared_option.py.txt`에 보존했다. 먼저 확인했던 Claude의 FWW_STRUCT 기록은 다른 망의 차로별/전체 FIFO 구분에 참고했고, 그 계수는 이전하지 않았다.

동측10483 진출과10490 합류는 모두link119의1차로를 사용한다. 진출은392.291m, 셀20/21 경계는393.698m, 합류는395.105m다. **셀 경계는 두 접속점 사이**다.121의 `after_merge_face` 열은 합류1.407m 앞 단면이므로 이름을 정정하고 원 수치는 보존했다.

같은 초기seed67, RM완화 고정·VSL110/90의2700–3150초를 비교했다. 미래 관측에서 진출점을 저속 차량 몸체가 걸치는 시각을 알려주는 조건부 진단이다. 기존 진출 수용량0에 더해, 같은 차로에 있는 통과 차량의 몫을 본선 sending에서 제한했다.

`S_through,new = (1 − b × w) S_through,old`

- b: 관측된 진출점 차단 여부. 매5초 표본을5초간 유지한다.
- w: 해당 시각 셀20의 통과행 차량 중1차로 차량 비율. 현재 NEXTLINK=10702로 분류한다.
- 다른 차로·다른 셀의 요청은 변경하지 않고, 원 수용 제한으로 실제 유량을 정한다. 경로별 보존·속도 갱신·동적 off-ramp 저장/배수·램프와 도시 대기 비용을 유지한다.
- 램프 방출 계산의 본선 요청과 실제 본선 갱신에 같은 제한을 전달했다.9초/10초 서비스 표나 RM 명령을 바꾸지 않았다.

w는 현재 재고 비율을 서비스 비율로 근사한 것이다. 실제 순간 유량 비율이나 새 용량 계수로 확인된 값이 아니다. **미래 b와 w를 알고 있는 조건부 시험**이므로 자율 예측으로 채택하지 않는다. 실제 방출량을 예측값으로 직접 넣지는 않았다.
