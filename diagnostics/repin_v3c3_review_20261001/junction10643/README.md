## 가설과 변경

실제10643은126의150.209m에 합류하며,126→10641 접속점은152.456m다. 기존 모델은133.399m에서 시작하는 마지막126 셀에 off-ramp 차량을 넣어, 실제 합류보다16.810m 상류의 수용 공간·FIFO와 경쟁시켰다. 이 근사가 과도한 배수 억제의 주원인인지 시험했다.

후보는 계산상의126/10641 경계를 실제 합류점으로 옮겼다. 남은126의2.248m는10641 첫 셀에 포함했다.2.248m 셀을 별도로 만들면1초 CFL 조건을 어기므로 같은2차로의 연속 구간을 묶은 것이다. 전체 길이·차로별 총 저장공간·FD·wave speed·신호·수요·명령·본선 계수는 유지했다. 합류 두 흐름은 같은 하류 수용 예산을 공유한다.

초기 차량의 경로 표지·질량을 유지하고, 짧은126 말단의 계산상 소유가10641로 옮겨지는 것은 provenance에 기록했다. 거리 계산도 각 계산 셀을 원래126/10641 구간으로 되돌려 적분하도록 했다. 실제 VISSIM 차량이나 망을 이동·수정하지 않았다. 개별 셀 내부 초기 위치의 유한 체적 투영은 달라질 수 있으며, 이를 동일 궤적이라고 주장하지 않았다.

## 채택 판단과 다음 범위

추가 구현·AD 경로를 유지할 만큼 큰 개선 근거가 없어 **후보를 정본에 남기지 않았다.** 생산4파일은 시험 전 byte로 복원했고 기존7개 core SHA·9000 STOP SHA도 일치한다. 후보 소스와 시험은 `*.executed.txt`, 기준 소스는 `*.before`로 보존했다. `candidate_config.json`은 과거 실행 증거이며 현재 소스에서 후보가 재현되는 운영 설정이 아니다.

같은 위치·FD·차로 이동률 격자를 더 돌리지 않는다. 다음 원인 분리는71에 도착하는 집단의 공급·목적지 순서와 셀 내부 FIFO/차로 접근 반응이다. 기존 native 캐시를 이용해 실제 도착 조건을 준 국소 재생이 필요하면 **미래 경계를 사용하는 조건부 진단**으로 한정한다. 그것을 자율 제어 이득 검증에 섞지 않는다.8개 off-ramp 경계 정합 → 필요한 본선 셀 보정 → 공통 초기 제어 손익이라는 순서는 유지한다.

새 VISSIM·FZP 재스캔·계수 fitting·push는 없다. 후처리에서 packet을 사전 대신 쌍으로 읽은 오류, 외부 유입 자원 key를 내부 셀 key로 읽은 오류가 각각 있었다. 두 실패 로그를 보존하고 집계만 고쳐 완료된6예측을 재사용했다. 예측 재시도는 없었다.
