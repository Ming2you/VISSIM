# SC1001 과거 관측의 공유 정지선 연결

2026-10-02. **관측 연결 개선 / 전체 이득 보정 미완료.** 앞선 경계 연결은 진행된 작업이며 이번에는 그 후보가 기존 head·차량 출처 이력을 빠뜨리는 부분을 수정했다. 운영 기본 설정은 바꾸지 않았다.

## 원인과 변경

새 공유 접근로는 SC1001 링크127의 과거 head 방출 기록을 사용하지 않고 차로당 nominal1400대/h만 설치했다. 2550–2700초만 해도 1·2차로는 녹색45초 중26·24대, 3차로는 녹색24초 중12대가 확인된다. 이 기록은 포화 교통류율의 식별은 아니지만,1400대/h보다 높은 실제 녹색 방출이 가능하다는 증거다.

기존 `signal_head_observation`의 provenance 검증 뒤 공유 접근로에도 관측을 연결했다. 연속150초 창4개를 서로 겹치지 않는300초 두 묶음으로 나누고, 기존 최소 녹색 노출30초·최소 통과5대를 각각 만족할 때 작은 쪽의 녹색당 실현율을 사용한다. 짧은 SG5 녹색도 묶음의48초 노출로 검증한다. 유효 이력의 서비스 하한을 유지하되 관측 누락·run 변경 시 이력을 버린다. 황색 통과를 녹색 방출에 보태지 않았으며, 임의 capacity 보너스나 계수 탐색도 없다.

2700초 설치값은 1·2·3차로 각각 **2000·1920·1725대/h**다. 이미 과거에 실현한 서비스의 하한이며, 충분한 큐와 하류 여유를 확인해 식별한 포화율이라고 부르지 않는다. 실제 예측 방출은 준비 재고·차로 접근·신호·공유 하류 여유로 다시 제한된다.

현재·이전150초 frame의 출처 표지를 다음 관측으로 이어 보존했다. 짧은 off-ramp를 관측 사이에 건너는 차량은 본선의 이미 지정된1131/1132 경로를 함께 사용한다. 해당 접근로·관련 경로 밖으로 떠난 ID는 제거하여 다음 방문에 옛 출처를 붙이지 않는다. 이전 run/미래 frame/관측 간격 단절을 이어 쓰지 않는다.

## 출처와 N_P

현재 초기 차량은 off39·city23·불명7대로 분류됐다. 확인한62대는 cutoff 이전5초 지역 궤적 캐시의 출처와 모두 일치했다. 나머지7대도 사후 감사에서는 off-ramp 출신이지만,150초 운영 관측으로는 확정하지 못하므로 미래·고밀도 궤적의 정답을 후보에 주입하지 않았다.

불명7대는 도시 유입으로 보는 기존 보수적 상한 해석을 유지한다. 초기 출처 불확실성만으로 생기는 N_P 과대계상은 최대7대 범위다. 따라서 이후 상한 제약 검증에서는 이 범위를 표시하고, 상한 해석에서도 통과한 후보와 불확실성 때문에 판정이 갈리는 후보를 구분할 수 있다. 미래 off-ramp 배수는 N_P에 한 번만 들어가며 공통 head에서 다시 들어가지 않는 검사를 유지했다. 현재17개 주체 N_P 합은 유지501.397 / 완화500.394대이며 새 SDMPC 후보 선택을 수행한 값이 아니다.
