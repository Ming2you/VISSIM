# 셀19 공간별 재고와 속도의 자율 예측

2026-10-04. **계수 고정 후보8조건450초 실행 완료. 현 후보 미채택, 이득 검증 미완료.** 권위 있는 완료 결과는 `audit_repair/`다. 직전143은 조건부 경계·공간 장부를 확인한 PROGRESS였고, 이번에는 별도 속도 상태를 가진 물리 후보를 구현하고 자율 제어 손익을 검증했다. 목표 ACTIVE / NOT_QUALIFIED.

## 변경한 것

143에서 셀19의 대열 해소 중 상류·하류 속도가 달랐다. 기존119는 두 재고 구획에 같은 속도를 사용해 반응을 거의 개선하지 못했다. 이번에는 **셀19의 세 차로를 각각 동일 길이의 두 구획으로 나누고, 구획마다 경로별 재고와 METANET 속도를 따로 갱신**했다. 셀19에는 중간 진출·합류가 없음을 실제 routing 계약으로 검사한다.

- 현재 관측 위치·차로·경로·속도로 초기 분할한다. 이후 미래 실측 상태나 차량 통과량을 입력하지 않는다.
- 상류 수락 유입은 앞 구획에, 내부 수락 이동은 뒤 구획에, 본선 방출은 뒤 구획의 경로별 재고에서 차감한다. 각 구획의 실제 저장 여유와 donor 재고를 지킨다.
- 두 구획에 같은 기존 셀19 FD·relaxation·anticipation 계수를 사용하지만, 각 구획의 예측 밀도·속도와 이웃 상태로 반응을 계산한다. 길이는 실제 셀 길이의 절반이며1초 적분은 유지한다.
- 기존 차로 교환률을 각 구획의 재고·저장 여유에 적용한다. 목적지를 바꾸지 않는다. 구획 합계는 기존31셀 경로 재고의 분할이며 추가 차량이 아니다.
- 상류 셀18의 anticipation 경계는 앞 구획 평균밀도, 하류 셀20의 convection 경계는 뒤 구획 차로 속도를 사용한다. 셀19의 외부 출력은 두 구획의 차량 수·속도 모멘트를 합친다.
- 실제 합류, 셀21 수용, 셀20 진출10483 공유 FIFO, 동적 off-ramp 저장·배수, 램프 대기, 기존 수요 예보·명령·계수를 유지한다. 기각된141/142의 초기 비율 변경을 결합하지 않았다.

이는 셀19 내부의 최소2구획 후보 한 개다. 모든 셀을 재분할하지 않았고 별도 정본 adapter를 만들지 않았다. 기존 진단 helper가 보관된124 함수에 프로세스 내부에서 연결하고 종료 후 복원한다. VSL 노출 이력은 보존하지만 두 구획 모두 기존 물리 셀의 cohort 비율을 사용한다는 근사가 남아 있다. 이 비율은 이전 차로 모델에서도 공유하던 값이다. 명령별 용량·가속 보너스는 없다.
