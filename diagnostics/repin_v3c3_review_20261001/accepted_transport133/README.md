# 실제 이동량에 맞춘 속도 전달 후보 — 미채택

2026-10-04. 기준 재현1회와 자율450초 예측8회를 완료했다. 모든 물리 계산은 정상 종료했지만 **VSL 손익 검증은 실패했다.** 정본 채택·새 VISSIM·FZP 읽기·9000초 분석·push는 하지 않았다.

## 무엇을 검토했나

132는 차량 수·이동량 오차를 줄였지만 VSL에 따른 방출 반응을 놓쳤다. 이전 `merge_population`, `merge_speed_audit`, `lane_terms25`, `joint_lane_rec`과 Claude의 `upstream_worklog/07_fww_sc1001eb/fww-struct/P_PLANT.md`를 확인했다. 고정 램프 속도 혼합과 회복 계수 확대는 이미 실패한 시험이므로 반복하지 않았다. Claude의 다른 망 계수를 가져오지 않았다.

이번 후보 하나는 셀19–25 차로별 **실제 허용된 본선 이동량**으로 속도 모멘트를 전달한다. 모든 차량을 동일한 차로 평균속도로 나타내는 근사는 남긴다.

한 차로의 기존 재고가 n, 본선·진출 방출이 o/e, 본선 유입이 f, 실제 램프 합류가 m이면, 차로변경 전 재고는 `n' = n − o − e + f + m`이다. 전달 속도는 다음과 같다.

`v_transport = [(n − o − e + m) v_local + f v_upstream] / n'`

그 뒤 기존 차로 간 이동은 이 전달 속도 모멘트를 함께 운반한다. 기존 이완·anticipation은 전달된 속도를 입력으로 쓰며, 별도의 표준 대류항은 0으로 두어 이중 적용을 피한다. 따라서 기존 METANET 원식을 그대로 쓴 후보가 아니라 **수송과 나머지 속도식을 분리한 국소 변경**이다. 가속·감속까지 포함한 속도 모멘트 보존을 요구한 것은 아니다.

램프 속도는 새 고정값이나 미래 실측을 넣지 않고 기존 국소 속도 대용값을 유지했다. 명시적 합류 감속·실제 합류량·램프 대기·진출 저장과 배수·공유 수용 제약·VSL 노출 이력은 유지했다. 132의 네 보정계수도 동결했다. 새 보정·계수 격자는 없다.
