## 시험한 것은 하나

`N_e, N_t`를 현재 **모델**의 진출행·통과행 재고, `r`을 제공한 속도비, `Q`를 기존 총 sending이라고 하면, 진출 요청은 `Q × N_e r / (N_e r + N_t)`다. 두 집단의 현재 재고로 상하한을 제한하고 나머지는 통과 요청에 배분한다. 같은 상태에서 총 sending은 그대로이며, 막힌 차량의 목적지를 바꾸거나 실제 유출을 강제로 맞추지 않는다. 실제 receiving·accepted flow·진출 저장/배수·램프 대기는 기존 계산을 따른다.

실측 비율은2700/2850/3000초 값을150초씩 유지했다.2700초 이후 값은 **미래 관측**이다. 따라서 이것은 원인 분리용 조건부 계산이며 자율 예측·보정된 plant·SDMPC 검증으로 사용하지 않는다. 각 결과와 모든150초 구간 기록에 `future_observation_inputs=true`와 조건부 설명을 저장 전부터 표시했다. 미래 실제 차량 재고·속도 상태·유량으로 모델 상태를 덮어쓰지는 않았다.
