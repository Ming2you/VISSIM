# 초기 상태가 같아도 다른 방출로 진행하는 이유: 현재 상태 요청과 공간 축적

2026-10-04. **기존 캐시의 1,080개 5초 차로 전이 검사 완료. 모델 채택·이득 보정 완료 아님.** 직전 목표 턴은 기존 결과 설명만 했으므로 NO_PROGRESS다. 이번에는 새로운 조건부 경계 검사와 보존 검증으로 다음 수정 범위를 바꿨다. 새 VISSIM·FZP 스캔·450초 예측·계수 적합·9000초 결과 분석·push는 모두0이다. 목표 ACTIVE / NOT_QUALIFIED.

## 이전 설명에 추가해야 하는 점

131에서는 셀20→10483 진출에 실측 재고·속도를 매5초 넣으면 실제 진출 반응을 상당 부분 설명했다. 그러나 이를 **모든 본선 경계의 요청식도 실측 상태에서는 맞는다**로 일반화할 수 없다. 140의 셀18→19 초기 과유입을 매 시점 실측 상태로 다시 계산하자, 그 경계에서도 오차가 컸다.

따라서 두 문제가 함께 있다.

1. 자율 예측의 차로 재고·속도가 실측에서 일찍 벗어난다.
2. 실측 평균 재고·속도가 정확하더라도, 셀 내부에서 움직인 양과 셀 끝을 넘어간 양은 대열 형성·회복 중에 다를 수 있다.

초기 관측을 계속 주는 조건부 진단은 운영 가능한 예측이 아니다. 이번 자료로 실제 미래 상태를 controller 입력에 추가하지 않았다.

## 검사 범위와 계산

seed67 RM 완화/VSL110 및 같은 RM 완화/VSL90의 기존 5초 차량 캐시만 사용했다. 2670.1–2700.1, 2700.1–2820.1, 2820.1–2970.1, 2970.1–3120.1초를 겹치지 않게 나눴다. 실제 물리 셀18의2·3·4차로와 셀19의1·2·3차로를 추적했다. 셀18 길이175.4293m, 셀19 길이199.96815m를 선택망31셀 mapping에서 읽었다.

현재 상태 요청은 `Σ_t Σ_vehicle v(t) × 5/(3.6L)`이다. 매5초 시작값과 사다리꼴 적분을 둘 다 계산했다. 평균 재고와 평균 속도를 따로 구해 곱하지 않았다. 실제 방출은 같은 차량 ID가 다음 기록에서 하류 셀에 있는지로 센다. 5초 안에 차로 변경과 경계 통과가 모두 있으면 통과 순간의 차로는 확정하지 않고 별도 표시한다. 표의 실측은 **마지막 상류 관측 차로 기준**이다. 따라서 기존140의 하류 도착 차로별 수와 일부 다르다. 초기 셀18·2차로 및 셀19·1차로에는 이 모호성이0건이었다.

미래 프레임은 정답과 전이 수지에만 사용했다. 현재 상태 요청에 다음 시각의 차량·목적지를 소급해 넣지 않았다. 반 셀 통계는 동일 길이2분할 한 개만 사용하며 분할 위치/개수를 최적화하지 않았다.

## 위치 장부 검증의 의미와 한계

각 차로의 `M=Σ(x−x_start)/L`에 대해 다음 관측 구성의 정확한 항등식을 확인했다.

`방출 = 종방향 끝점 이동 대용량 + 차로 이동 위치항 − ΔM`

종방향 대용량은 잔류 차량의 위치 차이, 경계 유입 차량의 관측 위치, 방출 차량의 남은 길이를 합친 값이다. 차로 변경 순간·위치가5초 사이에 있으므로 이를 연속 실측 주행거리나 인과 기여율로 부르지 않는다. 이 대용량은 속도 적분 요청과도 같지 않다. 예를 들어 셀18 초기30초는 `9.356 + 0.286 − 6.642 = 3`으로 닫힌다. 셀19 초기30초는 `8.567 − 0.031 − (−3.464) = 12`다.

1,080개5초 전이의 차량 수 보존과 위치 항등식을 통과했고 위치 잔차 최대1.78e−15대다. 대상 차로에서 미관측 진입·이탈0건을 확인했다. 수지가 맞는 것은 분해 계산의 검증이지 미래 방출 예측의 검증이 아니다.

## 다음 모델 작업에 반영할 판단

- 141·142의 고정 초기 차로/목적지 비율을 다시 조정하지 않는다. 동적 상류 차로 재고만 추가하고 동일 평균 속도 요청식을 유지하면 초기 오류를 그대로 남길 수 있다.

- 미래 위치 모멘트 변화나 실측 통과량을 보정 입력으로 쓰지 않는다. 현시점 초기 공간 분포 이후에는 모델의 수송·속도 동역학만으로 진행해야 한다.
