## 변경과 근거

148의 공유 차로 모델은 목적지별 차로 재고로 실제 수송을 계산하지만, 합류 gap 입력은 여전히 전체 셀 평균 밀도·속도와 과거 진출 비율을 사용했다. 기존 정본의 routed_ramp_conflict 수정과 Claude P_PLANT를 확인한 뒤, 현재 진단 경로의10490/10484에 상류 목표 차로의 현재 통과행 Nv/L 요청을 연결했다. 같은 셀에서 빠지는 진출행 재고를 제외한다. gap 공식·계수, 신호 서비스, 수용량, 차량 보존, 모든 METANET/FD 계수는 유지했다. 153의 계수는 섞지 않았다.

이것은 실제 통과 유량이나 미시적 gap 관측이 아닌 **상류 차로의 수송 요청 기반 근사**다. 더 큰 gap 상한이 실제 합류나 제어 이득을 늘린다고 가정하지 않았다. 동측4램프 중 명시 차로 영역에 들어가는 두 램프만 연결했다.
