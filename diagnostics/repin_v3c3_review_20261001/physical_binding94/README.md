## 확인한 내용

고정된 calibration reference를 정본 factory로 읽은 도로별 설정과 실제 coupled plant의 실행 설정을 비교했다. Deepcopy·pickle 이후에도 같았다. 기존 seed67 2700초 상태에서 RM 완화 조건의 VSL110/90 두 자율450초 예측을 그대로 실행하며 동·서측 62개 셀의 속도 갱신 55,800회와 도로 설정 전달 1,800회를 확인했다. 실제 계수와 상태별 선택이 reference와 일치했고, 독립적으로 재구성한 스칼라 속도식의 최대 차이는 1.42e-14 km/h였다.

두 예측의 Ω TTT·영역별 비용·외부 추적 체류·제어영역·램프·명령·셀 상태는 기존 결과와 정확히 일치했다. 예측 계산시간 합계는49.645초였다. Ω TTT는 VSL110 497.399301, VSL90 497.350487대·시간이며 차이는−0.048814다. 보정 계수가 실제 물리 계산에 전달되지 않았다는 증거는 이 검사에서 발견되지 않았다.

전체 망 기본 설정과 도로별 물리 설정이 다른 것은 calibrated component가 도로별 설정을 만드는 현재 구조와 일치한다. REVIEW93 초기 진단의 잘못된 설정 참조를 운영 모델의 전달 오류로 일반화하지 않는다. 전체 기본값을 물리 설정에 덮어쓰지 않는다.

## VSL 판단에 주는 의미

Claude의 HYBRID_DESIGN은 다른 망의 S4 제어·S5(6,733.2m)110 고정과80–110 범위를 논의한다. 선택망의 이번 비교는 DSD63–66(6,341.743m)의110 대90이다. Claude의 제한된 제어 권한 해석을 우리 망 전체의 VSL 무효 판정으로 옮기지 않는다.

완료 자료의 동일 초기 상태 비교에서 seed67 native 도시 신호·RM 완화 조건은 VSL 추가의 실제 ΔΩ TTT−2.065대·시간, 예측−0.048814였다. 같은 초기 상태의 다른 도시/RM 명령에서는 실제+0.6657, 예측+0.5576이었다. 독립 seed71은 RM에 VSL을 추가하면 실제+1.4477 손해인데 예측은 약−0.2240 이득이었다. 따라서 모델은 이득 크기를 놓치는 경우와 손익 방향을 틀리는 경우가 모두 남아 있다.

REVIEW90의 동일 초기·동일10483 진출84대는 VSL 조건에서 평균21.011초 빨리 진출했고, 셀19·20 통과시간 차이가 약−16.51초였다. 이는 결과를 보고 고른 집단이며 전체 Ω의 인과효과나 차로변경 개선을 입증하지 않는다. 원점 삽입·차량 구성 차이도 남는다. 임의 capacity 보너스나 명령별 보정항의 근거로 사용하지 않는다.
