각 인접 프레임에 대해 다음 재고식을 적용했다.

```
B_next = B + 새로 저속에 들어온 차량 - 다시 움직인 차량
           + 저속으로 구역에 들어온 차량 - 저속으로 구역을 벗어난 차량
```

B는기존 차량 중 속도 문턱 미만인 부분집합이다. 차량을 새로 더한 재고가 아니다. 경계 유입·유출을 별도로 세어 차량이 관측 구역을 떠난 것을 재출발로 세지 않았다.4개 구간·2개 속도 문턱·2조건·89구간의**1,424개 관측 재고식**이 정확히 성립했다. 현재 저장된 캐시에서 명시한 구역의 모든 차량을 사용했다.
