##142의 수정

원래 총 본선 요청량은 그대로 둔 채 목적지 클래스별 재고에 그 목적지의 **초기 평균속도**를 곱해 상대 요청량을 만든다.

`weight_c = current_predicted_N_c * observed_initial_v_target(c)`

클래스별 배분은 현재 해당 클래스 재고를 넘지 못한다. 빠른 클래스 재고가 먼저 소진되면 남은 요청 예산을 나머지 클래스에 다시 분배한다. 가중치가 모두0이면 재고 비율로 복귀하고, 초기 미관측 목적지는 관측 전체 평균속도를 쓴다. 이어서 기존 차로 배분·실제 수용 제약을 적용한다. 수락된 물량은 기존 보존 장부로 같은 목적지의 상류 재고에서 차감하고 하류에 더한다.
