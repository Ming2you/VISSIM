## 검증·기록

6개 모두 명령과 초기 본선·국소·off 재고가 기준과 같고,8램프 수지 최대4.76e−13대,8off 수지4.65e−13대,경로 재고2.09e−12대,국소 공유 자원 초과1.33e−15대였다. 생산7개SHA·STOP은 이전과 정확히 같다. 계수 차이는 reference의 셀11ρcrit 하나이며 나머지는 후보 manifest 연결과 qualification 설명뿐이다. 후보 파일은 진단 증거로 남기고 운영 설정은 바꾸지 않았다.

`fit.json`은 보정, `assessment.json`은6개 연결 결과, `native_lane_check.json`은 차량별 위치, `completion.json`은 종료·미채택·수지 증거다. `protocol.json`의 예정 상태보다 completion이 실제 완료 상태의 근거다.

준비 실패도 보존했다. scipy 읽기 권한은 승인된 실행 환경으로 해결했다. 최초 기하 검사는 피팅과 무관한 말단셀30의 좌표 초과(29:21건,43:32건)로 멈춰, 실제 사용하는10–12셀에 검사 범위를 한정했다. 셀11 보정 완료 후 `lane_plant`가 문자열인 설정을 사전처럼 취급한 포장 오류가 있었고, 이미 저장한 계수를 재사용해 수정했다. 최적화 횟수 nfev는 실패 전에 저장되지 않아 정확한 횟수는 미확인(최대25); 최적화는 반복하지 않았다. 첫 후처리는43작업 종료 전에 summary를 읽어 실패했고, 소유 세션 정상 종료 확인 후 완료 결과를 읽었다. 어떤 실패도 VISSIM/예측 재시작으로 처리하지 않았다.
