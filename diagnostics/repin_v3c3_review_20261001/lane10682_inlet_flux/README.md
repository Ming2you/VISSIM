# REVIEW52 — 짧은 셀 표본으로 고정한 유입 차로 비율 검증

기존 500m 범위를 모든 목적지에 적용하고, 현재 차량 수×속도로 유입 차로 비율을 추정했다. 전부 정지한 목적지는 현재 차량 수 비율로, 출구행 표본이 없으면 기존 기하 사전분포로 처리한다. 이는 미래 경계 유량 관측이 아니라 현재 상태의 근사다. 초기 차량 위치·총 목적지 수요·진출/배수·명령은 바꾸지 않았다. REVIEW51의 셀11 계수도 고정했다. 새 계수 탐색은 없다.

26개 검사와 같은 초기 상태의 450초 예측 6개를 완료했다. 계산시간 합193.147초; seed43 네 조건, seed47 RM유지/도시명령 두 조건이다. 후자는 RM 유지/완화나 새 SDMPC 선택 비교가 아니다. 미래 실측은 사후 평가에만 사용했다.

직전 시험에서 생긴 인위적인 상류 대기를 크게 줄였다. 그러나 **원래 aggregate 기준의 seed47 셀9·10도84.1/81.0km/h였으므로, 이 회복을 기존 기준보다 새롭게 좋아진 결과라고 표현하지 않는다.** 이번 비교가 입증한 것은 차로 모델의 작은 표본 고정이 추가 오류를 만들었다는 점이다. 원래 기준과 전체 출구·비용 비교는 `original_comparison.json`에 남겼다.

seed43 RM/VSL/둘다 ΔΩTTT는 −0.132/−0.354/−0.468veh·h이며, 실측 −1.547/+0.777/−1.453과 여전히 다르다. 작은 VSL 부호 하나가 미채택 이유는 아니다. 두 상태 모두 셀11·12의 실제 2차로 혼잡을 놓치며10643 배수 오차가 크다. 따라서 전체 후보는 아직 채택하지 않는다.

## 남은 오차 위치와 반증한 가설

- seed43 종료 셀11 2차로: 실측17대/10.4km/h, 예측4.56대/54.3km/h. 셀12는 실측14대/14.9, 예측10.09대/35.5.
- seed47 종료 셀11 2차로: 실측15대/6.7km/h, 예측4.69대/57.6km/h. 셀12는 실측16대/11.4, 예측9.88대/38.5.
- 셀12는 모델에서 높은 회복 anticipation과 합류 감속이 동시에 작동한다. 마지막150초 seed47 2차로 평균은 relaxation−3.22, convection+1.22, anticipation+4.50, 후처리−2.52km/h/step이다. 이것만으로 어느 계수가 틀렸다고 단정할 수 없다.
- 기존 완전 차량 스냅샷에서 셀13 2차로도 실제로 덜 혼잡했다. seed47 종료 셀12/13 밀도86.84/32.57veh/km/lane, 속도11.40/65.36km/h. seed43도 같은 밀도차 부호다. 따라서 하류를 평균 밀도로 둔 것만 고치면 국소 합류 정체를 설명한다는 가설은 충분하지 않다. 미래 실측 밀도를 예측 입력으로 넣지 않았다.

다음에는 저장된 자료로10681 실제 합류량 및 어느 차로로 합류하는지와 셀12 국소 방출을 분리한다. 현재 차로 후보는 합류 총량을 연결된 두 차로의 남은 공간에 비례 배분하는 근사다. 그 배분의 타당성부터 확인하고, 필요한 경우에만 국소 계수를 다시 보정한다. 근거 없이 영역을 넓히거나 anticipation 격자를 반복하지 않는다.

## 상태와 재현

`candidate_config.json`은 REVIEW51 설정에 `inlet_estimator=current_window_flux` 한 항목만 추가했다. 실행한7파일은 `executed_sources/`와 해시에 보존했다. 코드 변경은 REVIEW50 대비 `physical_lane_groups.py`의 선택적 유입 추정뿐이다. `assessment.json`, `localization.json`, `boundary_check.json`에 원본 경로·해시를 남겼다. 경계 검사에는 완전 스냅샷의 차량수·시각 검증을 적용했다. 첫 대화형 조회의 `route_states` 최상위 키 오류는 경로를 확인해 수정했고, 예측을 재실행하지 않았다.
