## 무엇을 비교했나

172에서 확인한 10639 합류와 10682 진출의 공유 목표 차로를 기존 코드로 표현했다. 기존 `state_lateral168/run.py`에 `--merge173` 진단 모드만 추가했다. 기존 `main()`의 AST와 운용 소스는 그대로다.

- 두 비교군 모두 153 계수와 171 신호 앞 저장공간 수정을 사용한다.
- 기준은 집계 모델, 후보는 물리 셀10–11의 4개 차로·목적지별 재고를 명시한다. 두 군 모두 19–25 차로 영역은 포함하지 않는다. 따라서 이 시험은 171 전체 모델에 대한 추가 개선 시험이 아니라 첫 합류 구간을 분리한 비교다.
- 10639 합류와 본선 차량이 같은 FD 기반 차로 수용 예산을 공유한다. 기존 ramp-first 배분 규약을 유지했으며, VISSIM 미시 우선권을 재현했다고 주장하지 않는다.
- 상류 500m의 현재 목적지별 속도 가중 차로 분포를 유입 근사로 고정했다. 횡방향 이동률은 seed29 NC 2220.1–2670.1의 기존 5초 캐시에서 한 번 산정했다. 끝점 관측이 놓치는 중간 이동의 한계가 있다.
- 목적지 재고·동적 off-ramp 진입/배수/저장·VSL 이력·신호 pulse timing·램프 대기를 보존했다. 예측 중 미래 관측을 공급하지 않았다.
- **차로별 METANET 속도계수는 이번에 재보정하지 않았다.** 이번 실패가 국소 재보정의 한계를 입증하는 것은 아니다.

seed29/67의 RM 유지·완화 및 각 VSL90 조합 8조건, seed61 유지·완화 2조건을 각각 두 모델로 예측했다. 기존 비활성 경로 재현 1회를 합쳐 21회다. 새 VISSIM 런, FZP 재스캔, 9000초 결과 분석은 하지 않았다.
