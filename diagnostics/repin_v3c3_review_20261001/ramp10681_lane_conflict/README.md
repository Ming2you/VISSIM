# REVIEW54 — 계수 보정 전 합류 간섭 유량 연결 검증

사용자가 확인한 순서는 **off-ramp 진입·배수·저장과 합류·셀 간 전달 동역학 → 필요한 셀의 계수 보정 → 공통 초기 상태의 제어 손익 검증**이다. 전체 31셀 재보정을 완료했는데 실패한 상황이 아니다. REVIEW51은 셀11의 세 계수만 추정한 제한된 시험이며, 상류 회복을 악화시켜 채택하지 않았다. 이번 시험도 그 실험 계수를 고정하여 연결 변경의 효과만 분리했다. 해당 계수가 검증된 정본이라는 의미가 아니다.

이 표현은 과거 셀별 보정을 하지 않았다는 뜻이 아니다. `expanded_joint/README.md`에 따르면 expanded036에서는 31셀의 계수와 합류 계수 총159값을 유지하며 12개 결합 방향으로 450초 예측의 상태·제어 반응 손실을 실제 보정했다. 학습 반응 손실은39.9% 감소했으나 seed43 확인 개선은0.67%였고 중요한 RM·결합 이득 방향은 실패했다. 최근 REVIEW51의 셀11 시험은 이와 다른 작업으로, 실측 주변 상태를 넣은 국소 속도 변화율 잔차를 맞춘 것이다(`lane10682_cellfit/fit.py:105`). 둘을 같은 의미의 '셀별 보정 완료'로 설명해서는 안 된다.

## 변경 하나와 검증 범위

10681의 기하상 수신 차로는 본선 1·2차로다. 이전 후보는 차로별 방출을 보존했지만 gap 수용 계산에는 본선 전체 차로 평균 유량을 공통 적용했다. 이번에는 현재 예측된 상류 1·2차로의 통과 목적 차량 재고와 속도로 각각의 간섭 유량을 계산한다. 상류에서 진출할 목적 차량은 제외하며, 한 적분 단계의 재고보다 많이 보낼 수 없도록 제한한다. 기존 gap 계수·물리 공간·다른 7개 램프·셀 계수·수요·명령·목적함수는 유지했다.

이 값은 합류 147.51m 상류 경계의 sending 추정이며, 합류점에서 즉시 관측한 실제 통과량과 같다고 가정하지 않는다. 미래 실측 유량은 예측에 넣지 않았다. 이미 검토한 seed43/47 상태를 재사용했으므로 새로운 맹검 검증도 아니다.

33검사 PASS. 처음 실패한 한 검사는 '없는 상류 셀'로 실제 존재하는 셀을 지정한 fixture 오류였다. 셀1..3인 fixture에서 합류 셀1의 상류0으로 수정했으며 `tests.json`, `tests.log`의 실패 기록과 `tests_corrected.json`, `tests_corrected.log`의 통과 기록을 함께 보존했다. 예측 코드 완화로 통과시킨 것이 아니다.

기존 runner로 450초 자율 예측 6회 완료(43 네 조건, 47 두 조건), 계산시간 합 180.176초. 47 비교는 RM 유지와 도시 신호 변경이며 RM 유지/완화 비교가 아니다. 새 SDMPC 선택·VISSIM·FZP 재스캔·계수 탐색은 하지 않았다.
