# 완전 개방 RM의 유한 명령 검사 — REVIEW66

현재 U7/service66 모델과 seed43의 검증된 무제어2250초 상태에서450초를 예측했다. 유지 명령과 동측4램프 각각의 첫 블록8초/후속10·10초를 비교했다. **이번 네 후보에서는 큰 이득을 탐색이 놓친다는 근거가 없다.** 이 결론은 다른 상태·조합·지속 제한 전체에 적용되지 않는다. 전체 목표는 ACTIVE / NOT_QUALIFIED다.

## 먼저 확인한 기존 작업

- Claude `upstream_worklog/03_codex_review/REVIEW.md`의 서비스 평탄 구간과 계수 이식 주의를 확인했다. 그쪽의 다른 망 서비스표를 가져오지 않았다.
- 로컬 `rm_nonselection_live_20260929/METER_ACTIVATION_RESULT.md`에 이미 완전 개방 RM 유한 단계 보완과3600초 비교가 있다. 당시44개 추가 secant를 계산해도 최종 선택은 바뀌지 않아 기본 비활성으로 남겨뒀다. 같은 실험을 반복하지 않았다.
- 실제 `sdmpc.py`의 `meter_activation_axes`와 `sdmpc_sequence.py`는 옵션을 켜면 기존2초 차분으로g8에 도달한다. 별도 보완을 새로 만들 필요가 없다. 현재 동결9000초의 첫900초 정책에는 이 옵션이 없고 VSL 보완만 켜져 있다.
- `finite_neighbor_audit_performed=false`는 전체 유한 이웃 감사를 하지 않았다는 뜻이다. 모든 유한 명령 평가나 실제 writer 검증을 안 했다는 뜻으로 해석하지 않는다.

## 현재 모델의 제한된 비교

망·수요·초기 재고·과거 head/VSL 이력·도시green/offset·VSL110을 고정했다. 기존 실행 모델과 시퀀스 decoder로 한 램프의 첫150초만10→8초, 나머지300초는10초를 적용했다. 총5회이며 새 계수·최적화·native 런·FZP 읽기는 없다. 임의의 개선 보상도 없다.

TTT 단위는 차량·시간이고 음수는 유지 대비 개선이다. Ω에는 다른 도시부 비용도 들어가므로 본선과 램프 두 열만 더한 값과 다를 수 있다. 외부 추적 체류 변화는 모두절댓값4.3e−7차량·시간 미만이다. 미삽입을 포함한 native 전체 비용 검증은 아니다.

누적 합류가 같아도 지평 내부 합류 시점과 재고가 다르면 TTT는 달라질 수 있다. 따라서 ‘RM의 물리 효과가 전혀 없다’고 판정하지 않는다. 이 결과 파일은150초별 합류 누계를 별도로 보존하지 않았으므로 순간 합류 차이가 없다고도 주장하지 않는다.

실효1차로 서비스표는g8=1440,g9=g10=1512대/h이며2차로10681은두 배다. g10→g8의 주기 평균 상한 차이는1차로에서150초당3대다. 이는 **상한 차이**이지 실제 합류 감소량이 아니다. 초기 재고53대도 각 순간 차로 접근·수용·유입이 포화 서비스 공급을 보장하지 않는다.

## 검증과 판단

- 유지안은 이전 REVIEW60의 비용 분할·관측 초기화 이후 셀 상태·실제 명령·램프 결과와 정확히 같았다.
- 네 후보는 실제 명령 기준 첫 블록−2초/다음+2초 제한을 통과했고, 그 외 독립 좌표는 바뀌지 않았다.
- Ω 체류 비용 합,8램프 보존식을 검사했다. 최대 램프 수지 잔차4.13e−13대, 물리 자원 초과4.67e−15대 미만이다. 전체 망 모든 상태의 보존 증명으로 확장하지 않는다.
- 비교 전 정한 큰 손익 기준0.5차량·시간보다 모두 작다. 작은 부호를 맞추는 보정을 추가하지 않는다.
- 이번 후보의N_P/N_UF 상한 선택·제약 검사는 수행하지 않았다. **큰 실행 가능 해를 놓치지 않는다는 일반 증명이나 native 이득 검증이 아니다.**
- 계산156.43초는5회 예측 함수 시간 합이며 로딩·사후 분석 포함 전체 벽시계 시간과 구분한다. 낮은 프로세스 우선순위로 실행했다. 세션64778은EXIT0다.

운용 RM 보완을 켜거나 새로운 탐색을 추가하지 않는다. 현재 모델에서 큰 반응이 검증된47 RM 유지/완화 자료를 회귀 기준으로 유지하고, 미해결 VSL2250의 자율 상태 전파·방출 오차를 먼저 다룬다. 큰 RM 후보가 있는 상태에서만 실제SDMPC 선택 검증을 확대한다. 이 네 후보의 미미한 이득이나 약한 반응을 해결하려 같은 격자·최적화를 반복하지 않는다.
