## 계산 범위

완료된 seed47@2700 유지/도시선택450초의 기존 trace를 사용했다. 실제 실행과 동일한 CumulativeLane을 초기 위치·재고·속도 프로파일로 초기화하고, 기존의 유한 저장·이동 지연·sending/receiving 식을 그대로 호출했다.

조건별 세 가지, 총6개 부품 재생을2.123초에 완료했다.

1. **기존 예측 재생:** 기존 진입과 하류 수용 기록. 원래450개 step의 배수와150초별 재고·진입·배수가 모두1e-8대 이내로 일치해야 다음 진단을 허용했다.
2. **실측 진입 + 잔여 수용 공간:** native MER의1m 단면 진입 시각·차로를 사용하되, 기존 예측에서 다른 차량이 수락된 공간을 빼고 남은 수용량만 사용했다.
3. **실측 진입 + 기존 전체 수용 공간:** 다른 차량에게 배정됐던 공간도10643에 제공했다. 이것은 공간 경쟁에 대한 낙관적 민감도 진단이며, 다른 교통을 보존하는 실행 가능한 제어가 아니다.

2·3은 미래 실제 진입을 사용하는 **조건부 진단**이다. 하류 재고·수용량 이력을 원 예측에 고정했으므로 전체망 자기일관성이 없으며, 그 값을 전체 허용 제어의 용량 한계나 자율 예측 성능으로 해석하지 않는다. 1초의 점 차량 진입이 fluid 수용량을 넘으면 외부 backlog에 남겼다. 두 조건 모두 최종 backlog는0이고, 차량 수지는 유지됐다.
