# 수용량의 중복 합류 절단 — 2026-10-02

이미 수용한 합류량은 누적 전에 비음수 검증을 통과한다. 그 값을 본선 잔여 수용량에서 다시 max(0,q)로 절단하면, q=0인 경계의 제어 미분이 사라진다. 실제 정본 식을 추출한 합성 시험은 수정 전 forward/reverse 두 경우에서 예산 미분 보존을 실패했다. 안쪽 절단만 제거했으며 바깥쪽 비음수 본선 수용 제한은 유지했다.

76개 회귀시험과 일반 숫자 수용량42쌍의 동등성 검사를 통과했다. 실제 seed47@2700 같은450초 AD는62.596초에 완료됐고, 기준 출력 및 전체 RM10490 기울기는 이전과 정확히 같았다. 이 지점에서는 해당 수용 제한이 최종 기울기 오차의 원인이 아니었다. 고친 예산 항등식과 실제 원인 판정을 구분한다.

읽기 전용 branch observer가 비교 연산 wrapper를 한 단계 더 건너뛰게 해, 실제 `METANET` 합류 감속 조건에서 활성 미분을 가진0대 유량이 생략되는2710/2736초 두 사건을 확인했다. 출력 연결성만으로 원인 기여도를 계산한 것은 아니다. 이후 merge_speed 시험으로 이 가설을 분리 검증했다.
