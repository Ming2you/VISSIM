# 합류량 경계의 미분 보존 — 2026-10-02

상태: 보존 결함 수정 확인 / 전체 SDMPC 미분·이득은 미검증.

이미 수용한 램프 합류량을 urban → freeway로 넘길 때 0값의 활성 미분이 사라지는 경계를 수정했다. 기존 장부에 `complete_source` 계약을 추가해, 한 단계에서 전부 소비하는 `merge_pending` 묶음의 Ω 내부·외부 구성을 그대로 전달한다. 빈 일반 저장고에 임의의 내부 비율을 부여하지 않는다. accepted flow에 다시 적용하던 두 경계의 max(0,flow)는 물리 합류 경로에서만 비음수 검증으로 대체했다. 일반 경로는 유지한다.

수정 전 새 시험은 실패했다. 수정 후 tangent/Ω/freeway 관련 전체 74개 시험이 통과했고, 일반 숫자 장부 30쌍의 전체 상태·사건·TTT·TTD가 수정 전후 정확히 같다. 최초 수정 후 시험의 clock 누락 2오류는 시험 입력을 바로잡았으며 실패 로그도 보존했다.
