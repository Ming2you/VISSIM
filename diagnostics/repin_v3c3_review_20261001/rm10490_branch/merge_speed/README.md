# METANET 합류 감속의 0유량 미분 — 2026-10-02

계수나 식을 바꾸지 않고, 기존 `delta*q_merge*v/(L*lanes*(rho+kappa))` 항에 활성 미분을 가진0대 합류도 전달했다. 일반 숫자0은 이전과 같이 생략한다. 기존 램프의 `_has_transfer` 판정을 재사용했으며 별도 모델이나 어댑터를 만들지 않았다.

정본 합류 감속 블록의 새 시험은 수정 전 forward/reverse 두 경우에서 미분0을 잘못 반환했다. 수정 후 전체77개 시험과 일반 숫자 합류 감속72조건의 정확한 동등성을 통과했다.
