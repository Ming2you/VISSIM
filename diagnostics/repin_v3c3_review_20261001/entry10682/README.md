# 10682 진입 과대 예측의 목적지·잔여 차량 분해

2026-10-02. 기존 native MER/COM frame과 완료된 예측만 사용했다. 새 VISSIM 런·FZP 스캔·예측·계수 보정은 없다. 생산 코드 7개 SHA와 기존 9000초 STOP은 그대로다. 전체 목표는 ACTIVE / NOT_QUALIFIED.

사용자 순서는 **8개 off-ramp 진입·배수·재고 정합 → 필요한 셀 보정 → 같은 초기 상태의 NC/RM/VSL/both 손익**이다. 이번 결과는 첫 단계에서 잘못된 배수율 보정을 피하고, 접근부 동역학 검토 범위를 정한다.

## 현재 기준 모델의 경계 장부

각각 독립된 450초 상태이며 서로 같은 교통 상태가 아니다. 수치는 차량 수, `실제 / 예측`이다.

| 조건 | 본선→10682 진입 | 10682→도시 배수 | 종료 off-ramp 재고 |
|---|---:|---:|---:|
| seed43 NC, 2250–2700초 | 113 / 140.416 | 119 / 143.748 | 1 / 3.669 |
| seed47 RM 유지, 2700–3150초 | 147 / 146.696 | 148 / 148.947 | 5 / 3.749 |

초기 off 재고는 각각 7대·6대이며 장부가 보존된다. seed43 배수 과대 24.748대는 진입 과대 27.416대에서 종료 재고 과대 2.669대를 뺀 값이다. 여기서 배수율만 낮추면 잘못 들어온 차량이 더 쌓인다. seed47에는 같은 일괄 감소를 적용할 근거도 없다.

## 어떤 차량을 너무 일찍 진출시키는가

목적지가 초기부터 정해진 차량은 실제로 두 상태 모두 450초 안에 전부 진출했다(43:56대, 47:62대). 각 150초 끝의 미관측·실종 차량은 없었다. seed43 첫 150초에는 실제 27대/예측 34.465대로 초기 이동 시점도 차이가 있지만, 최종 오차의 대부분은 이후 유입 차량에 있다.

| 이후 본선 유입의 10682행 | seed43 실제 / 예측 | seed47 실제 / 예측 |
|---|---:|---:|
| 확인된 목적지 차량 수¹ | 144 / 149.000 | 147 / 155.500 |
| 기간 안에 10682로 진입 | 56 / 82.294 | 82 / 82.741 |
| 종료 시 본선에 잔류 | 88 / 66.706 | 65 / 72.759 |

¹ 실제는 진출한 차량 + 종료 시 목적지가 확인된 본선 차량이다. 아직 경로가 미정인 신규 차량 12대/11대와 관측되지 않은 손실 가능성이 있어, 모집단의 정확한 분기 확률 추정치가 아니다. 신규 진출 차량 전부가 본선 입력 검지기에서 확인됐다. 10639 진입램프 검지 기록과 중복되는 신규 진출 차량은 없었다. seed47 잔류 차량 한 대는 입력 검지기 40m보다 앞인 36.987m에 있었다. source MER tail은 그대로 별도 기록했다.

seed43 신규 진출 차이 `실제−모델 = −26.294`는 확인된 목적지 인구 차이 `−5.000`과 잔류 차이 `+21.294`로 분해된다. 실제 분기비율을 사후에 낮춰 맞추기보다 **접근부 체류·도착 시점**을 조사할 근거다. 다만 집계 대수의 항등식만으로 속도식의 원인을 확정하지 않는다.

seed43 목적지별 예측 스냅샷은 이미 기각된 compatible71 후보의 완료 기록을 재사용했다. 해당 후보의 10682 총 진입은 140.440대이며 현 기준 140.416대와 0.024대 차이다. 이를 현재 기준의 정확한 클래스별 예측이라고 부르지 않는다. seed47 클래스는 현재 retained10638 기준의 관측 추가본이다. 아래 속도는 두 경우 모두 **현재 기준**의 저장 예측이다.

## 셀별 위치: 일정한 감속 계수로는 두 상태를 동시에 설명하지 못함

31개 물리 셀의 0기준 번호, 종료 순간 차량 평균속도[km/h], `실제 / 현재 기준 예측`.

| 셀 | seed43, 2700초 | seed47, 3150초 |
|---|---:|---:|
| 8 | 102.7 / 91.2 | 83.9 / 82.0 |
| 9 | 51.3 / 86.6 | 99.9 / 84.1 |
| 10 | 22.7 / 81.0 | 96.6 / 81.0 |
| 11 | 30.0 / 68.3 | 35.0 / 70.2 |
| 12 | 35.8 / 45.3 | 37.6 / 44.3 |

두 초기 시각의 셀8–12 속도는 native frame과 예측 초기값이 일치한다. seed43 셀10은 2400초 실제47.1/예측81.3, 2550초25.7/79.8, 2700초22.7/81.0으로 악화 과정을 놓친다. 반면 seed47 셀10은 실제96.6으로 회복한 상태다. **셀10을 항상 느리게 만드는 보정은 seed47을 훼손할 수 있다.** 셀11의 저속을 두 상태에서 놓치는 현상과 셀9·10으로 전파되는 조건을 함께 확인해야 한다.

seed43 종료 신규 10682행 차량 중 셀9·10에 실제 30대가 남는다. compatible71 저장 예측의 해당 두 셀 잔류는 약6.48대다. 이후의 셀 보정은 이 위치·시간 차이를 다뤄야 하며 목적지별 대수를 바꾸는 보정으로 대신하면 안 된다.

## 다음 범위와 채택 기준

1. 10643의 도시부 수용·배수 반응 문제는 여전히 미완료로 유지한다. 절대 방출 개선만으로 채택했던 것은 없다. 같은 교환률 격자를 반복하지 않는다.
2. 10682의 경계 수지·현재 분기 계약·배수 상한을 유지하고, 셀9–12에서 합류, 속도식, 진출 접근 및 수용 제한이 만드는 도착 오차를 제한적으로 분리한다. 그 결과에 맞는 항만 보정한다. 실제 미래 경계를 쓸 경우 원인 분리용으로만 표시한다.
3. 셀 계수 보정은 자유 상태와 혼잡 상태를 함께 통과해야 한다. seed43의 저속만 맞추려고 seed47의 회복을 망가뜨리면 채택하지 않는다. 8개 off-ramp의 누적 진입·배수·종료 재고도 재확인한다.
4. 그 뒤 동일 초기 NC/RM/VSL/both의 Ω TTT·램프/도시 대기·정상 유출·큰 손익과 순위를 독립 상태에서 검증한다. 경계 유량이 정확해졌다는 것만으로 제어이득 보정 완료를 선언하지 않는다.

기록: `assessment.json`, `spatial.json`, `verification.json`. `audit.py`, `spatial.py`는 기존 기록만 읽는 일회성 진단이며 실행 runner/adapter를 추가하지 않는다. 첫 탐색에서 오래된 seed47 summary의 `physical_cell_states` 누락으로 KeyError가 났고, 해당 사실을 verification에 보존했다. 기존 trace의 동일 상태 기록으로 읽는 위치만 정정했으며 예측을 다시 돌리지 않았다.
