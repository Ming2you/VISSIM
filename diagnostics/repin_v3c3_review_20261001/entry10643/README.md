# 10643 진입 오차: 초기 경로와 후속 유입 집단 분리

2026-10-02. 원인 분리 완료, 이득 예측 보정은 미완료다. 사용자가 정한 **8개 off-ramp 진입·배수·재고 → 필요한 셀 재보정 → 동일 초기 상태의 제어 손익** 순서를 유지한다.

## 확인한 것

기존 진단 driver가 상위 설정의 route-inventory 유무를 검사해, 실제 refined freeway kernel에서 활성화된 목적지 재고를 출력하지 못했다. 실제 실행 kernel을 참조하도록 관측 부분만 수정했다. 생산 물리 코드·계수·경로 비율·수요·명령은 바꾸지 않았다.

seed47 유지/도시선택 두 450초 예측을 다시 실행했다. 두 결과의 wall_sec 이외 모든 기존 결과 필드, 모든 기존 response trace가 retained10638 결과와 정확히 같았다. 추가로 목적지별 재고 네 시점만 내보냈다. 계산 합계63.609초, 세션29638 정상 종료. 새로운 VISSIM, FZP 스캔, 계수 추정, 최적화, push는0회다.

## 초기 경로의 차량을 놓친 현상은 아니다

seed47,2700–3150초. 시작 시 이미10643행 경로1130:1이 있는35대는 실측에서 모두 진출했다. 모델도34.986대가 진출했다. 2850초 누적은 실측25대/모델23.596대,3000초는35대/34.240대였다. 초기 목적지 분류가 대규모로 사라진 것이 현재 약16대 진입 부족의 원인은 아니다.

native 유지의 총 진입96대는 초기 경로 확정35대, 초기 미확정 경로1대, 초기 본선에 없던 후속 차량60대다. 도시선택은35+1+59=95대다. 후속 진출 차량 모두 native 본선 입구 검지기의 실제 통과를 확인했다.

## 후속 유입 집단의 목적지 구성은 기대값과 다르다

현재 autonomous source forecast933대와 설정된1130 상대유량1:9:2에 따라, 모델의 새10643행 생성 기대량은933/12=77.75대다. 예측값933은 현재 관측 이력 기반 source forecast이며, XML의 명목 vehicle-input 수요 자체와 혼동하지 않는다.

실측은 미래 기록에서 확인된 후속10643행만 세어도90대였다. 유지에서는60대 진출+30대 본선 잔여,도시선택에서는59+31대다. 아직 경로가 확인되지 않은 차량이 있어90을 전체 잠재 목적지 인원의 완전한 관측이라고 부르지 않는다.

후속 집단의 진입 부족은 유지15.790대,선택14.570대다. 회계상 각각 `12.25 - (-3.540)`와 `12.25 - (-2.320)`으로 나뉜다. 이는 목적지 인원 차이와 잔여 차이의 분해이며, 잔여 차이를 순수한 이동시간 오차로 단정하지 않는다. 도착 시각과 구성, 유량·속도 반응도 함께 영향을 준다.

본선 입구 MER에는 마지막1초 사건의 미상세 기록이 유지2건/선택1건 남아 있다. 기존 카운터와 잔여 차량을 함께 사용한 새 생성 하한은914/917대다. 이 하한을 정확한 전체 생성량이라고 쓰지 않는다. `assessment_source_tail_failure.log`에는 처음 모든 tail이0이라고 가정한 검사 실패를 보존했다. tail을 명시한 뒤 기존 예측을 재사용해 평가했으며 재예측하지 않았다.

## 독립 seed에서는 차이가 작다

기존 seed43의2250–2700초 raw frame와 MER만 읽었다. 시작 시 확정된29대는 모두 진출했다. 후속10643행은46대 진출+31대 잔여=77대가 확인됐고, 모델 source894대에 설정 비율을 적용한 기대량은74.5대다. 이 seed의 전체 native10643 진입은76대다.

따라서 seed47의 실현90대에 맞춰 경로 비율이나 FD를 조정할 근거는 없다. 두 seed만으로 모든 차이가 확률적 선택 때문이라고 입증한 것도 아니다. 미래 native 목적지 수·진입을 autonomous 입력으로 사용하지 않았다.

## 배수·저장 오차는 별도로 남아 있다

현재 유지 모델의10643 진입80.194대/배수61.039대/잔여32.155대에 대해 실측은96/94/15대다. 동일 초기 재고에서 배수 부족32.961대는 진입 부족15.806대와 잔여 과대17.155대의 합이다. 진입 구성 차이를 인정해도 하류 배수·저장 동역학을 계속 검증할 이유가 남는다.

도시선택은 모델 진입80.416대/배수75.351대/잔여18.065대,실측95/84/24대다. 여기서는 잔여 과소가 진입 부족을 일부 상쇄한다. 한 조건의 배수 총량만 맞춰 통과시키지 않는다.

다음은 기존 배수 재생 진단을 필요한 범위에서 재사용해 실제 진입 시각을 조건으로 한 배수·저장 반응과 autonomous 예측을 구분한다. 조건부 미래 경계를 쓰더라도 원인 분리용으로만 표기하고 이득 예측 성능으로 보고하지 않는다. 그 뒤 경계 오류로 설명되지 않는 셀의 발생·전파·회복만 제한적으로 재보정한다.
