## 바꾼 것

119의 보존형 앞·뒤 구획과 경로별 재고를 재사용했다. 이번에는 각 구획의 **현재 관측 평균속도도 별도로 초기화**하고, 기존 셀19의 METANET 계수로 각 속도를 갱신했다. 물리 길이는 각 약100m이며 이완·대류·anticipation 및 기존 상태별 계수를 그대로 사용한다. 내부 이동은 앞 구획 속도, 셀19 하류 방출은 뒤 구획 속도로 계산한다.

셀18은 셀19 앞 구획의 밀도를 하류 상태로 받고, 셀20은 뒤 구획의 속도를 상류 상태로 받는다. 두 구획의 차량 수로 가중한 속도를31셀의 셀19 출력에 기록한다. 초기 및 모든 갱신에서 차량 수·속도 모멘트를 확인했다. 물리적 capacity 증가나 VSL별 가속 보너스는 없다.

부모 셀의 FD·계수를 고정했고 새 속도 상태만 추가했다. 두 구획은 여전히 기존 셀 단위 VSL 노출 혼합을 공유한다. 차로별 미시 행동이나 모든 셀을 세분한 모델을 구현한 것은 아니다. 기존119 스크립트를 해시 확인 후 진단 프로세스 안에서만 변환했다. 원 스크립트와 생산 코드는 수정하지 않았다.
