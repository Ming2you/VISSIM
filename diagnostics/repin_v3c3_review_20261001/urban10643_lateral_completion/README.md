# REVIEW56 — 차로 변경 완료와 분할 재고의 전진 일관성

한 가지 동역학 후보를 기존 코드에 구현하고 시험했다. **10643 배수 부족 일부는 줄었지만 제어 반응 방향은 해결되지 않았다.** 계수 보정·새 VISSIM·push는 하지 않았다. 기존 소스로 복원한 실제 증거는 `completion.json`이다.

## 변경과 가정

필수 차로 변경이 실제 수락되면, 같은 셀의 해당 목적지/집단 잔여량은 원래 차로에서 먼저 전진하지 않고 차로 변경을 마치도록 했다. 여러 차로를 건너는 중간 차로에서도 같은 규칙을 적용한다. 수락되지 않은 요청만으로 차량을 묶지 않는다. 수용 공간과 종·횡방향 sending 예산·목적지·질량은 그대로이며, 작은 조각을 삭제하거나 EPS를 늘리거나 뒤 차량의 임의 추월을 허용하지 않았다.

이는 셀 안에서 차로 변경 완료를 근사하는 보수적인 가정이다. 실제 차로 변경 중의 연속적인 전진 궤적을 재현한 것은 아니다. 미래 예측 집단은 여러 차량을 같은 label로 나타내기도 하므로 그 영향도 자율 예측에서 확인했다.

참고한 [Wright 등의 partial-FIFO 연구](https://arxiv.org/abs/1601.01054)는 차로 기하에 따른 여러 이동의 상호 차단을 다룬다. 현재의 단일 차로 내부 잔여 조각을 무시하는 근거로 그대로 사용하지 않았다. 이번 후보가 그 논문의 식을 구현했다는 뜻도 아니다.

## 발견·수정한 구현 실패

최초7검사 통과 뒤 추가한 순서 검사가 실패했다. 기존 FIFO 압축은 같은 목적지 차량을 같은 동작으로 보았지만 새 완료 대기 상태는 서로 다른 동작이었다. 서로 다른 완료 상태를 압축하지 않도록 수정한 뒤8검사가 통과했다. 비활성 모드는 기존 소스와120step 전이·재고·방출이 정확히 같다. 전체 차량이 길을 막는 경우, 거절된 차로 변경, 중간 차로, 질량 및 compiled/AD 미검증 경로의 명시적 거부도 확인했다.

최초6개450초 예측은 실패 구현으로 보존했다. 수정 후 같은6개를 한 번 더 검증했다. 총12예측이며 유효한 최종 비교는 수정본6개이다. 최초/수정본의 이번6조건 결과 장부는 정확히 같았지만 합성 상태에서 확인된 순서 오류를 허용하지 않았다. 기존 분석기를 재사용하면서 남은 `fit` 이름 때문에 생긴 사후 처리 실패도 로그로 보존했고, 그 오류를 고칠 때 예측을 재실행하지 않았다.

계산시간 합은 최초189.194초, 수정본181.723초다. 병렬 실행의 전체 경과시간이나 VISSIM 시간과 다르다. 실제 도착을 넣은 국소 재생은 첫 버전2회·수정본2회로 따로 기록한다.

## 판단과 다음 검증

이 후보를 운영 정본·이득 보정 완료로 승격하지 않는다. 차량 조각의 전진을 일관되게 처리하면 배수 부족 일부가 줄지만, 국소 병목을 상류로 옮기는 효과와 미사용 차로가 함께 남는다. 같은 완료 규칙의 강도를 바꾸거나 FD 계수로 이 오차를 흡수하는 탐색은 반복하지 않는다.

다음에는 이미 확보한47 유지/도시 선택 자료에서 도착 구성·신호 시계·차로별 실제 방출을 함께 대조해, 반대인 배수 응답의 원인을 분리한다. 특히 한 조건의 총량 일치만으로 다른 상태의 대기·제어 반응까지 맞았다고 판정하지 않는다. 이후 정리된 동역학 위에서 필요한 셀 계수를 연속 예측 기준으로 보정한다.
