# 셀18 lane-drop 계수 식별 검사 — REVIEW105

2026-10-03. **국소 조건부 적합은 개선됐지만 정본에 채택하지 않는다.** REVIEW104는 완료된 PROGRESS였고, 이번에는 기존 수용 한계가 아닌 속도식의 차로 감소 계수에 대한 신규1회 식별 검사를 했다. 새 자율 예측·VISSIM·FZP 재읽기·push는 없다.

## 질문과 사전 범위

셀18의 명목4→3 차로 전환에 대해 감속계수 phi를 더 크게 하면 실제 혼잡 발생을 맞출 근거가 있는지 검사했다. 현재 선택망과 retained10638/expanded036의 나머지 물리 계수를 유지했다. 계수 식별은 seed29 무제어2220.1–2970.1초 저장 상태만 사용했다. seed43 같은 시간대 및 seed67 RM완화2670.1–3120.1초는 적합에 쓰지 않았다. 세 자료 모두 이미 검토한 자료여서 새 맹검이라고 하지 않는다.

실측 현재 셀17/18/19 차량 수·속도로 정본 속도식의 relaxation, convection, anticipation과 nominal lane-drop을 계산했다. 다음5초 평균속도 변화는 평가 정답으로만 읽었다. 식은 `dv/dt = base − phi × unit_drop`이다. phi 하나만 닫힌 형태의 최소제곱으로 적합하고0–6 범위에 제한했다. 시간·seed·RM/VSL 조건별 보너스는 없다. 사전 예산은 적합1회·예측0회다.

## 결과

제약 전 최적계수는−2.0205, 비음수 제한을 적용하면 **phi=0**이다. 기존 값은3이다. 음수 계수는 차로 감소가 가속을 준다는 잘못된 해석이 될 수 있으므로 사용하지 않는다. 이 결과는 감속을 더 강하게 할 근거가 아니다.

## 왜 채택하지 않는가

기존 `freeway_first/exit_lane_drop`에서 셀18의 명목 진출1차로에 해당하는 추가 감속을 없애고 동적 추가 손실을 보존한 자율750초 후보는 이미 실패했다. 앞선450초 손실0.72498→0.80182, 후반300초4.48642→5.13503이었다. 당시 첫150초 셀18 통과량은 늘었지만 하류21·23 방출이 감소했다. 별도 `drop_recovery`의 동측 phi3→1.5/1도 실패했다.

이번 검사와 과거 자율시험은 동일한 검증이 아니다. 이번에는 관측 상태를 매번 주고 명목 차로만 사용했고, 과거에는 예측 재고·속도·진출 저장이 스스로 변했다. 따라서 이번 국소 개선을 기존 장기 실패의 해결로 표현하지 않는다. 동적 spillback까지 제거하는 phi0 운영 설정도 만들지 않는다.

현재 증거는 **셀18의 추가 감속이 국소 속도 편향을 키우지만, 다른 구간의 동역학 오차를 상쇄하고 있을 가능성**과 양립한다. 인과적으로 확정된 계수 오차는 아니다. 차량 구성 변화·하류 상태 오차·순간식과5초 관측의 차이를 phi 하나가 흡수할 수 있다. 이 상태에서 큰 phi로 혼잡을 강제하거나 음수 phi로 가속을 추가하지 않는다.

다음은 이 후보를 재실행하는 것이 아니라, 이미 완료된 감속 제거 시험의 상류 방출 증가가 하류21/23의 어떤 상태·합류·배수 조건에서 손실로 바뀌었는지를 현재 모델과 구분해 재사용하는 것이다. 과거 연결FD·tau/nu·lane-joint 탐색은 반복하지 않는다. 전체 Ω TTT·외부 대기와 제어 순위 검증은 계속 필요하며 목표는 ACTIVE / NOT_QUALIFIED다.
