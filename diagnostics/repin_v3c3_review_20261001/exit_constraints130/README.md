# REVIEW130 — 진출 요청·저장·공유 수용의 실제 실행 추적

2026-10-04. **`attempt2/`의 네 계측 예측과 검사 완료. 전체 목표 ACTIVE / NOT_QUALIFIED, 정본 변경 없음.** 앞선129의 공동 보정은 완료·기각된 PROGRESS였다. 이번에는 그 물리 결과를 바꾸지 않고 제한이 작동하는 단계를 관찰했다.

## 조건과 실행 범위

seed67,2670.1초 공통 초기 상태, RM 완화 고정, VSL110/90의450초를 사용했다. 모델은129의 기준 `eval_00`과 미채택 공동 조정 `eval_09` 두 개다. 기준선과 보정본 모두 정확히 이전129의 본선 cells/flows, off ports, ramp 기록과 같았다.

129와 같은 관측30초 본선 진입량을 알려준 **조건부 진단**이다. 미래 내부 상태·합류·진출은 입력하지 않았다. 운영 가능한 자율 예측이나 VISSIM의 원인별 인과 분해가 아니다. 이번에 보정 계수를 다시 맞추지 않았고 새 VISSIM·FZP·9000초 결과 분석·push는 없다.

기존 `RouteLaneRegion.plan`을 그대로 실행한 뒤 그 내부 재고·속도·수용량으로 다음 단계를 독립 재구성했다.

1. 접근 가능한 차로의 진출 요청: `N_exit,lane1 × min(1,v_lane1 × dt/L)`.
2. 진출부 저장 수용 적용: `min(요청,branch_capacity × dt)`.
3. 같은 차로 직진의 셀21 수용 여유 적용: `min(2단계,요청 × min(1,직진수용/직진요청))`.
4. 실제 진출량과 off 저장고에 들어간 차량 수, 실제 직진 배분을 대조.

모든1초에서 계산된 요청·단계별 수용·진출/직진 배분이 실제 실행과1e−9대 이내 일치했다. 추가 감속이나 유량 변경은 없다.

기준의 VSL90−110 반응은 **요청+0.1025 − 공유 제한 증가0.0950 = 진출+0.0075대**다. 공동 보정도 **요청+0.1520 − 공유 제한 증가0.2148 = 진출−0.0628대**다. 실측+14대에 못 미치는 문제가 최종 저장 수용 이전의 요청 단계에도 이미 있다.

네 예측 전체1,800초에서 저장 수용이 요청을 줄인 횟수는0이다. 가운데150초 off 저장고 평균 재고는 기준 약1.34대, 공동 보정 약1.71대다. 공유 제한은 기준 두 조건 모두95초, 공동 보정110/90은76/73초 작동했다. 따라서 **이 시험 모델에서 off 저장·배수 상한을 더 높이는 것으로는 현재 요청 부족을 해결할 수 없다.** 실제 VISSIM에서 도시 신호·배수가 중요하지 않다는 일반론은 아니다.

모델 접근1차로의 평균 속도는 기준110/90 **8.781/8.814km/h**, 공동 보정 **9.957/10.192km/h**였다. 같은 차로의 진출행 재고는 기준13.445/13.449대다. `N_exit × v/L`가 두 조건에서 거의 같기 때문에 요청도 거의 같았다. 이 평균값들만으로 실제 정지의 원인을 합류/진출로 분류하지 않는다.

## 다음에 검토할 대상

저장 상한이나 합류 감속을 임의로 바꾸는 대신, **본선 진출 접근의 차로·목적지 재고에서 방출 가능한 차량을 만드는 식**을 검토할 근거가 생겼다. 현재 차로 속도를 진출행 모든 차량에 동일하게 적용하는 표현이 대기열 선두의 방출과 얼마나 다른지 확인해야 한다. 이는 새 용량 보너스를 넣자는 결론이나 특정 대안의 채택이 아니다.

같은 구간에 진출행 차량을 다른 차로로 수송하는 근사도 남아 있다(기준 가운데150초 다른 차로의 진출행 재고 평균 약8.49대). 다만108에서 관측 차로 정렬과 단순 정렬 후보 실패를 이미 확인했고91·119의 공간 수송 시험도 있었다. 이를 새로운 발견으로 포장하거나 같은 고정계수 시험을 반복하지 않는다. 수정은 이전 결과를 재사용해 현재 요청 생성·공유 수용과의 연결을 검증해야 한다.129의 제한된 공동 보정 실패가 모든 동역학 일관 보정의 설명력 상한을 뜻하지도 않는다.
