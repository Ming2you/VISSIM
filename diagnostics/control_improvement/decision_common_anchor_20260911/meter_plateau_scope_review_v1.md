# Meter plateau: finite held-action scope review

현재 V3 native 실행 중 수행한 읽기 전용 코드 검토다. 실제 plateau는 미확정이며, held-action의 평균 predicted merge가 g8 서비스 상한보다 작다는 사실만으로 g10과 g8의 전체 예측 응답·payoff가 같다고 판정할 수 없다.

- **Follower의 중립 이동은 없다.** incumbent를 첫 최선 후보로 두고 `result.cost < best_cost`일 때만 교체하며, 실제 채택에는 `gap > improvement_tolerance`가 필요하다(현재 1e-7). 따라서 평가된 feasible 이웃이 모두 동률이거나 나쁘다면 g10을 유지한다. 시간/평가 예산으로 미방문인 후보는 동률 또는 무효로 해석할 수 없다. [엄격한 최선·채택](<C:/Users/alsrj/Desktop/학술/찐찐막/Codex/VISSIM/.worktrees/control-full-review/evaluation/controllers/joint_owner_game.py:781>)
- **고정 actual-action ±2초 box다.** 실제 g10 anchor에서는 g8·g9·g10이 가능하고 g6은 같은 결정의 반복 sweep으로 열리지 않는다. 실제 g8이 적용·기록되어 다음 결정의 anchor가 8이 되어야 g6이 가능하다. 상태·수요 예측·가격이 다음 결정에 달라져 g8이 엄격히 개선될 수 있으므로 영구 고정을 뜻하지 않는다. [물리 meter 후보 범위](<C:/Users/alsrj/Desktop/학술/찐찐막/Codex/VISSIM/.worktrees/control-full-review/evaluation/controllers/joint_owner_neighbors.py:1032>)
- **450초 held-action 평가다.** 현재 horizon은 3 × 150초이며 canonical endpoint 호출은 빈 schedule과 `box_walk=False`를 사용한다. 따라서 g8을 450초 유지한 효과를 평가하고 미래의 g10→g8→g6 연속 이동을 미리 채점하지 않는다. 이 범위는 유한한 owner-coordinate held-action neighborhood이며 temporal-sequence/global 최적성 주장이 아니다. [canonical held endpoint](<C:/Users/alsrj/Desktop/학술/찐찐막/Codex/VISSIM/.worktrees/control-full-review/evaluation/controllers/area_follower_objective.py:501>)
- **모형의 meter는 평균 서비스 상한이다.** `service_by_green_veh_h = lane_count × per_lane_veh_per_cycle[g] × 3600 / 10`으로 변환한다. 1차로 기준 g10=1512, g9=1328.4, g8=1166.4, g6=842.4 veh/h이며 2차로 미터는 두 배다. 각 `T_f`에서 재고·램프용량·본선 수용력·이 상한의 최소값을 구하고 `T_u`별 실제 재고로 방출을 제한한다. 서비스표는 녹색 길이의 총 서비스 차이를 반영하지만 모형 meter 동역학에 정확한 10초 RG 위상 펄스를 직접 넣지는 않는다. Native는 `simSec mod 10`으로 RG를 실제 적용한다. **Outer seed/결합 후보 예외:** outer leader는 양쪽 freeway의 물리 meter seed들을 교차하고, follower에는 VSL×meter 결합 후보도 있다. 따라서 단독 meter 이웃의 own-payoff 동률만으로 전체 제어기가 반드시 OPEN을 유지한다고 결론낼 수 없다. 다른 NP/복원/결합 레버를 포함한 feasible 결과가 선택될 수 있다. 다만 outer 순위도 전역 objective의 엄격한 감소로 갱신하므로 같은 objective의 후보는 앞서 선택된 feasible 결과를 대체하지 않는다. 실제 후보별 방문·feasibility·전체 payoff 비교 없이 이번 실행의 미변경 원인을 plateau로 확정할 수 없다.
