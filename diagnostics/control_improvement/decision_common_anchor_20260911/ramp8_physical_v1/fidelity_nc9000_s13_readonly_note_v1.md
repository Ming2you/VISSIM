## 미삽입·경고·비교 자격

`unfinished_inputs=[]`는 ERR에서 분류된 미완료 입력 경고가 없다는 뜻이며 전체 희망수요 삽입 완료의 증명은 아니다. 고립 source link에서 첫 관측된 삽입은 input 1098/1100/1101 각각 8,895/715/1,159대다(4,500–9,000초에는 3,222/264/401대). input 1099의 link 26은 상류 유입도 있어 제외되고, 1초 사이에 짧은 source를 통과하면 누락될 수 있다. 따라서 이 수를 전체 요구수요로 쓰거나 미삽입을 0대로 확정하지 않는다.
