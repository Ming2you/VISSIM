## 해석 범위

- conditioned_diagnostic은 미래 실제 경계 유량을 사용하는 물리식 진단이다. 실시간 예측 성능과 분리한다.
- baseline은 기존 정본 계수, calibrated는 훈련 초기 자유류 속도 갱신과 방향별6개 계수 보정이다. 형상·수요·제어 정책은 같다.
- off-ramp 수용량은 외부 방출률 대리값, forecast에서는 과거값이다. 도시 신호·출구 배수의 완전한 폐루프 예측이 아니다.
- TTT 수치는 고속도로 구성요소만 포함한다. Ω 전체 TTT나 제어 개선율로 해석하지 않는다.
- 5초 궤적 사이 경계 통과는 구간 단위 추정이며, 단일 연결이 확인되는 connector 생략만 인정한다. 삭제와 미확인 이동은 정상 방출에 넣지 않는다.
- 생산 기본값은 변경하지 않았다. 개별 혼잡 위치·발생/해소 오류와 실패를 summary.json, validation.json에 함께 남겼다.


## 최종 판단

**예측 오차는 개선됐지만, 정본 채택은 보류한다.** 방향별122개 후보(450초 훈련 예측1,098회)를 비교하고 계수를 고정한 뒤296회 검증했다. 차량 보존·음수 밀도·최대 밀도 관련 평가 실패는0회였다. 이는 속도 예측이나 제어 이득까지 검증됐다는 뜻이 아니다.

새 FW80%·도시100% 조건의 과거 관측 기반 예측에서 속도 RMSE는 동측35.62→29.55km/h, 서측28.03→14.82km/h다. 동측 유량 RMSE는2707.8→1188.7veh/h로 줄었다. 보정에 쓰지 않은 다른 수요 조건에서도 평균 오차가 줄었다.

남은 문제는 구체적이다.

- 동측에는 아직 약30km/h의 속도 오차가 남는다. FW80%·도시100%에서120초 이상 지속되는30km/h 미만 정체를 놓친 셀·예측창은1→15개, 잘못 예측한 셀·예측창은93→3개였다. 과도한 정체 예측은 줄었지만 일부 실제 전파도 놓친다. 이는 서로 다른 셀·예측창의 수이며 독립적인 혼잡 사건 수가 아니다.
- 기존 본선 진입 상한6937veh/h가 실제 진입 유량을 다시 제한한다. 훈련 자료의30초 유량 환산 최댓값은 동측9120, 서측7200veh/h다. 이 관측 최댓값을 곧바로 지속 가능한 용량으로 간주하지는 않는다. 모든 검증 창에서 모델의 외부 대기는 이 고정 상한만으로 계산한 대기와3.1e-12대 이내로 같았다. FW80%·도시100% 동측 예측 유입의7.33%가 상한에 막혔고,100%·90%에서는12.41%·11.40%였다. 보정 전후 상한은 같다.
- 동측 임계밀도 배율1.4는 탐색 상한, 서측 τ=12s·κ=5·merge계수0은 탐색 하한이다. 특히 merge계수0을 실제 합류 손실이나 RM 이득이 없다는 뜻으로 해석하면 안 된다.
- 속도 상·하한 처리 횟수도 별도로 남겼다. 이 진단값은 최저속도와 경계 속도 상한 처리를 합산하므로, 그 횟수만으로 수치 발산이라 판정하지 않는다.

다음 단계는 본선 진입과 말단의 수용량 설정을 각각 현재 기하·관측과 정합시키고, 동측 램프 주변의 혼잡 전파·회복 잔차를 분리하는 것이다. 전역 용량을 임의로 올려 제어 이득을 만드는 방식은 사용하지 않는다. 현재 계수는 비교용 후보이며, 같은 망의 RM/VSL 실제 반응과 다른seed 검증 전에 생산 기본값으로 승격하지 않았다.
