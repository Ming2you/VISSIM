# 동측 본선 입력0.8 조건: 종료 오류 감사

`east080_v1/native9000`의 종료ERR 두 파일을 기존parser로 읽었다. 준비망 폴더의동일ERR복사본은중복계산하지않았다. FZP·COM·새런·기존설정변경없음.

## 미삽입 잔여

|Input|기준 native|east080|차이|
|---|---:|---:|---:|
|282|39|30|-9|
|1086|28|29|+1|
|1087|4|4|+0|
|1093|64|59|-5|
|1098|13,742|8,152|-5,590|
|1099|18,928|18,992|+64|
|합계|32,805|27,266|-5,539|

각 입력은 종료 잔여 메시지1개뿐이다. 구간별 증분으로 보거나 여러 복사본을 더하지 않았다.

1098의설정생성기대량은27,126→21,700.8대(−5,425.2대)로줄었다. 미삽입감소5,539대전체를처리성능개선으로판정할수없다. 다른입력의설정수요가같아도확률적생성과교통상호작용에따른실현량은같다고가정하지않는다. 설정기대량−종료잔여를정확한삽입량으로계산하지않았다.
