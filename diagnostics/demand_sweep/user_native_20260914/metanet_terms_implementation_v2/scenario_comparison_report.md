# 현재 수정망은 제어실험에 나아졌는가

**동측 램프에 실제로 도착해 합류하는 차량과 대기 재고가 늘어, 이전 rule100 시험보다 RM 반응을 시험할 대상은 뚜렷해졌다. 그러나 본선 과포화가 해소됐거나 제어 편익을 얻기 쉬워졌다는 결론은 아직 아니다.** 현재 망은 장시간 잔여 대기와 원점 미삽입이 상당하며, 현재 망의 같은 초기상태·수요에서 실제 RM A/B 반응은 아직 확인하지 않았다.

이번 검토는 기존 CSV/JSON 집계를 읽은 분석이다. VISSIM·프로세스·원시 FZP를 사용하지 않았고, 소스·설정·동결 자료를 바꾸지 않았다. 생성한 수치와 입력 CSV의 SHA는 `scenario_comparison_metrics.json`, 보충 맥락은 `scenario_comparison_context.json`에 있다.

## 비교 조건과 66대 주장의 범위

과거 rule100은 고속도로80%·도시50%, seed13, 초기 VSL100km/h, 기존 도시 신호, 900초 제어 시작, 3000초 종료다. 무제어는 `rule100_none3000_s13_v1`, RM은 `rule100_rm3000_s13_v2`이다. 현재는 사용자가 수정한 망과 저장된 native 수요·경로·신호·희망속도를 유지하면서 입력1098만 사용자 원본의0.8배로 둔 seed13/17,9000초 런이다. **현재의 도시·램프 수요를 과거의 도시50% 조건과 같다고 두지 않는다.**

`diagnostics/rule_baseline_20260914/REVIEW_20260914.md:45`의 **66대는 RM_C10639 한 램프의900–3000초 실제 본선 합류량**이다. 무제어·VSL·RM·병용 네 조건에서 모두66대였고, 모든 램프 합계나 램프행 희망수요가 아니다. 과거 RM에서는 이 미터만 g9에서 g2까지 줄였지만 누적 합류는 변하지 않았다. 다른7개는 대부분 g10이었으므로 다른 램프까지 '미터링이 효과없었다'고 일반화할 수 없다.

## 동측0.8이 실제 본선 여유를 만들었는가

같은 사용자 수정망의 원래 수요와 동측0.8을 비교한 기존9000초 집계에서도 이 점은 구분해야 한다. source74 첫 등장 차량은 **13,327→13,326대**로 거의 같다. 입력1098 미삽입 잔여는13,742→8,152대로 줄었지만, 실제 본선 진입량은 사실상 줄지 않았다. 입력1099 잔여도18,928→18,992대로 계속 크다. 현재seed13 총 미삽입은27,266대다.

따라서 '동측 희망수요20% 감소'와 '실제 본선 유입20% 감소'는 다르다. 이번0.8은 원점 밖의 대기량을 줄였으나,9000초 안에 실제 본선 유입을 충분히 낮춰 회복시키는 조건으로 확인되지는 않았다. 이 비교의 원래수요 망과 현재0.8 망은 과거 도시50% rule100과도 구분한다.

## 제어실험 적합성 판단

현 망을 버리거나 'RM 여지가 없다'고 결론낼 이유는 없다. 특히10490·10681·10639는 실제 통과량과 커넥터 재고가 이전보다 커져, **같은 상태에서 녹색을 낮췄을 때 서비스·합류·본선 반응이 달라지는지 확인할 후보**가 생겼다.10482도 합류량이 크게 늘었다. 반대로10646과10644에는 같은 이유를 그대로 적용할 수 없다.

확인하지 못한 것은 그 재고가 서비스 상한 때문에 쌓였는지 본선 수용량 때문에 쌓였는지, 현 trust region의 g10→g8만으로450초 누적 합류가 바뀌는지, 줄인 합류가 도시·램프 대기를 포함한 비용을 낮추는지다. 현재의 무제어 집계만으로 RM의 실제 조절 가능량이나 최적 녹색을 확정하지 않는다. **현재는 더 풍부한 램프 반응 시험 시나리오이며, 원점·말기 과부하가 해소된 최종 성능평가 시나리오는 아직 아니다.**
