# 2026-09-16 물리 기하·램프 경계·실제 제어 반응 검증

네트워크는 사용자가 수정한 east080 seed13 원본(SHA 3795b346d7eafbbdf47ede0673050c12a4dcea2e40bca7abc085abf71381d65c)을 그대로 사용했다. 동측 본선 input1098만 0.8로 준비했던 망이며, 과거 전역 80/50 수요 조건과 다르다. 새 제어 실험은 망·수요·경로·seed를 바꾸지 않았다.

## 먼저 내릴 수 있는 판단

현재 망은 과거보다 RM의 물리적 반응을 식별하기에 낫다. 같은900–3000초 8개 램프 실제 합류는 과거1,824대에서 현재 seed13/17의3,760/3,757대로 늘었다. 10639의 과거66대는 그 램프 하나의 합류량이며 전체 수요가 아니다. 다만 현재9000초 종료 동측 재고1,081/1,123대·정지108/78대가 남는다. 과거80/50 NC의 회복보다 좋다는 뜻은 아니다. 자세한 대조는 scenario_comparison_report.md에 있다.

이번 실험에서는 RM이 실제로 합류를 줄였지만 Ω 전체 TTT 개선은 관측되지 않았다. 이는 이 단일 seed·고정 명령의 결과이며 최적 제어 가능성이나 통계적으로 확정된 우열이 아니다.

## 완료한 작업

- 실제 차로 변화 위치와21개 모델 셀을 정렬했다. 동측4→3차로 위치는6,841.743m이며, 종전 셀 경계는 약166m 상류였다. 재고·밀도·속도 방정식·수용 공간에 같은 물리 길이를 사용한다.
- 진출 커넥터의 본선 진입, 하류 배수, 이동 중 재고와 대기 재고를 분리했다. 예측 중 관측 재고를 재설정하지 않는다. history 모드의 배수는 직전150초 관측을 유지한 외생 근사이며, 도시 신호의 완전한 미래 예측은 아니다.
- seed13으로 계수를 보정하고 seed13/17에서 총576개 방향별450초 예측 결과를 평가했다. seed17은 이전 작업에서 이미 본 개발 검증 자료이므로 새 독립 holdout이라고 부르지 않는다.
- 실제 무제어/VSL/RM/동시 적용2250초 런을 모두 완료했다. 네 조건의 개입 전1350초 FZP가 정확히 일치한다. 무제어는 기존9000초 런의2250초까지8,152,944 데이터 행과 기록된144SG 신호가 일치한다.
- 짧게 실행하려고 SimPeriod 자체를2251로 줄였던 v2는2231초부터 궤적이 달라졌다. 해당 실패 자료는 보존했다. v3는 원래SimPeriod9001을 유지하고 SimBreak2250으로 중단하여 전체 prefix 일치를 확인했다.
- 제어 실행은 적용 시 readback과 native LDP로 확인했다. LSA를 COM 제어의 충분한 증거로 사용하지 않았다. 기록이 없는 나머지 SG는 초기·최종 소유/상태 점검 범위이며 연속 검증이라고 주장하지 않는다.

## 실제 명령과 범위

1350초부터 DSD59–62의 기존 희망속도 분포 ID120을100,1500초80,1800초100,1950초120으로 바꿨다. 숫자는 VISSIM 분포 ID이며 모든 차량의 실제 속도를 고정하는 값이 아니다. 물리 적용 범위는5,386.554–6,733.193m이다. 모델의 근사 셀은0기반10–12, 범위5,262.879–6,841.743m다. 기존 구역 묶음이 하류13–14셀까지 제한을 퍼뜨리지 않도록 명시적 경계를 추가했다.

RM은10490/SC9107·SG1만 변경했다.10초 RG 주기에서1350/1500/1650/1800/1950/2100초의 녹색은8/6/4/6/8/10초이며 황색은 없다. 이전 native 무제어 상태는OFF로 보존했다. 모델의OFF 서비스 상한에 기존g10 표를 사용하는 것은 검증 대상 근사이지 두 상태가 동일하다는 증명이 아니다.

이 처방 실험은 물리 응답 진단이다. N_UF 고정 목표 및17개 도시 주체의 follower game 실행 가능성을 인증하는 시험은 아니다. 특히 단독 RM으로450초 합류가17대 줄어드는 후보는 다른 램프의 보상 없이 기존±5대 합류 허용오차를 만족하지 않는다.

## 계수 보정의 한계

같은 새 기하·같은 동역학에서 seed17 history 속도 RMSE는 동측19.62→19.11km/h, 서측21.80→20.00km/h다. 그러나 TTT 평균절대오차는 동측3.890→4.241veh·h, 서측3.902→4.878veh·h로 악화했다. 동측 지속저속이 관측된7개 예측 창은 여전히 모두 놓친다. 계수 보정을 성공으로 채택하지 않는다.

동측 δ=1·차로감소φ=6, 양측τ=12초 등 여러 값이 탐색 경계에 도달했다. 이는 고유한 물리 식별 결과가 아니다. 기존 FD 계열을 유지했으며 새 capacity-drop 보상이나 레버를 움직이게 하는 목적함수 항은 넣지 않았다.

## 동결한 첫 제어 반응 예측

native_response_v1은 계수 재보정 없이16개 예측을 저장하고 실행 소스를 ZIP으로 보존했다.1350초 history에서 무제어 합류105.33대(실측93), RM92.83대(실측76)를 예측했다. RM의 합류 감소 방향은 맞지만, 공통 영역 TTT 증가는0.007veh·h만 예측했고 관측30초 적분값은1.200veh·h 증가했다.

이 버전은 정지선 뒤6.43m에 새로 방출된 차량을 다음10초까지 남기는 근사 때문에 모델 재고가무제어4.2대/RM3.24대로 누적됐다. 관측1초 peak는2대이고 명목 길이/평균차량간격은1.071대다. 순간적인 native2대를 불가능하다고 판정하지는 않지만 모델의 지속적인 적색 비영향 재고는 실행 반응 해석을 제한한다. v1은 실패 진단으로 보존하며, 물리 응답 검증 통과나 GNE용 정본으로 승격하지 않았다.

## 마지막 검증 완료: 램프 내부1초 계산

METANET10초·계수·서비스 표는 고정하고 램프 경계 내부만1초로 처리했다. 본선 수용 예산은10초 시작에 한 번 계산하며, 초당 사용 상한을 지킨다. 정지선 이후 공간이 찼을 때 신규 정지선 통과를 제한하고, 이미 통과한 차량은 적색에도 이동한다. 관측 초기 재고는 삭제하지 않는다. 명목 공간은 미시적인 차량 앞부분 위치의 정확한 수용 법칙이 아닌 보수적인 유체 근사다.

신규10개·기존14개 검사가 통과했다. 무옵션/명시적10초의 전체 JSON은 동결v1과 정확히 일치한다.45회의 본선 갱신·수용 조회와450회의 램프 내부 계산, 합류량 전달·보존, 기존 서측 궤적 불변을 확인했다. DEFAULT_CONFIG의 verify_parameters도PASS이며, 기존 보정파일의 값 일부가 정본/tuning 우선순위로 폐기되는 WARN은 보존했다. 이 컴포넌트 시험에서는 보정 계수를 구성 뒤 명시적으로 적용하며, 그 WARN을 무시하고 기존 보정이 자동 적용됐다고 주장하지 않는다.

native_response_v2의16개 예측을 완료했다. 정지선 뒤 공간 감사는16개 모두 통과했으나, 이는 예측 정확도 통과가 아니다. 모델 peak는0.405–1.0대였고 실제 짧은 구간의1초 front-position peak2대를 물리 불가능으로 판정하지 않았다. 계수와 실제VISSIM 결과는 재조정하지 않았다.

기존30초 cohort를 이용한 추가 분석에서는 램프 전체에 정지 차량이 있어도 정지선 직전30m에 정지 차량이 없는 표본이 존재했다. 반면RM g4 구간은5/5 표본에서 정지선 가까운 대기가 있었고15주기22대 통과(1.47대/주기)로 표의1.44와 가까웠다. 이 표본은 신호 주기 끝 시각에 치우쳐 있으므로 지속 포화나 새로운 서비스율 보정 근거로 그대로 쓰지 않는다. 전체 큐를 head-ready queue로 간주하거나 서비스 표를 일률적으로 줄이지 않는다.

## 채택·보류 및 다음 판단

1. 실제 기하와 보존식 정합, 진출의 진입/배수/저장 분리, 짧은 램프 이동의 시간 처리 수정은 유지한다. 보정 계수와 서비스율의 정확성 인증은 별개다.
2. 현재 새 계수는 후보로 보존한다. 속도 RMSE 감소만으로 정본 승격하거나 추가계수·capacity drop을 넣어 제어 이득을 만들지 않는다.
3. 다음 보정의 우선 대상은10490의 **목적지 도착 → 정지선 준비 → 실제 head 방출 → 본선 수용/합류** 연결이다. 실제 head 준비가 있는 구간에서 공유 병목 처리량과 본선·램프 우선권이 제한을 어떻게 만드는지 확인해야 한다. 기존 모든1800대/h 수용 조회가 현실을 설명하는지 검토한다.
4. VSL은 분포 ID에서 유효 희망속도로 이어지는 관계와 실제 제어 적용 구간 근사를 검증한다. 이번 모델의135개 활성 셀-step 중 실제 속도 상한이 제한한 경우는 v2 history18개뿐이었다. 명령이 들어간 것과 그 명령이 물리적으로 구속하는 것은 다르다.
5. Ω 삭제·경로 경고를 정리하고 추가seed로 확인하기 전, 약0.1–0.35%의 이번 비용 차이를 최종 성능 우열로 인증하지 않는다. 최적화/GNE로 넘어갈 때에는 N_UF 실행 가능성과 도시부 대기 비용까지 다시 포함한다.

이번 요청의 기하→동역학→보정→실제레버반응 검증은 완료했다. 결론은 'RM이 무효'가 아니라 **실제 국소 효과는 관측되지만 현재 모델이 대기 비용·후속 반응을 충분히 예측하지 못하며, 이번 처방은 Ω 편익을 만들지 않았다**는 것이다.
