# 2026-09-19 램프만 보정한 결과

**후속 정정:** [비용 집계 수정 보고서](../merge_drain_response_20260919/REPORT.md)를 먼저 읽는다. 아래 표는30초 재고 표본의 역사적 결과다.1초 native 회계와 모델 내부 체류량으로 재평가하니 seed33 RM의 실제 ΔTTT는−0.1622,10484 후보의 모델 ΔTTT는−0.0154veh·h였다. 따라서 아래의seed33 부호0/3은2/3으로 정정된다. 이 재표본화 비용이 단독 MPC 선택에도 사용돼 수정했다. 본문·원본 결과는 과거 판단 근거로 보존한다.

본선 FD·METANET 계수를 고정한 채 램프 이동 시간, 정지선 이후 합류 수용, 도착 시간 분포를 보정·비교했다. **10484의 조건부 재현은 개선됐지만, 실제로 사용할 수 있는 450초 예측의 RM/VSL 순비용 방향은 해결되지 않았다.** 따라서 이번 후보를 controller 기본값으로 승격하지 않는다. 기존 VISSIM 기록을 재사용했으며 새 native 런은 시작하지 않았다.

## 실제로 변경·시험한 것

- 기존 `physical_ramp_boundary.py`에 정지선 전후 이동 속도를 분리하는 선택 설정과1초별 도착량 입력을 추가했다. 도착량 합 보존·음수/비유한 값·길이를 검사하고, 차로별 재고에도 동일 원칙을 적용한다. 별도 adapter는 만들지 않았다.
- 기존 `canonical_harness.py`와 `evaluate_response.py`에서 명시된 config만 적용한다. 옵션이 없으면 이전 예측을 그대로 재현한다.
- 10490·10484의 합류 수용에는 이미 구현된 gap 모형을 사용했다. 후보는 임계 gap2.5–6초, 추종시간1.5–2.5초 및 수용 제한 없는 기존 방식이다. 시간 간격은 평균 본선 유량으로 산출하는 모형의 유효 계수이며, 운전자 gap을 직접 측정한 값이 아니다.
- seed13의8개 무제어450초 창과1650초 RM 짝으로 국소 보정했다. 손실은 정지선 전후 체류·정지선 통과·합류·끝 재고의 오차다. RM을 유리하게 만드는 보상항은 넣지 않았다.
- 이 국소 보정에서는 원인 분리를 위해 **미래의 실제 도착과 실제 본선 상태**를 입력했다. 온라인 예측 정확도로 제시하지 않는다. 이후 과거150초 정보만 쓰는 별도의450초 결합 예측으로 후보를 평가했다.
- 본선 계수·FD·기하·수요·명령·서비스 곡선·목적함수는 고정했다. 진출 모델은 앞선 구간 내 배수 시간 수정본을 유지했다. 이번에 도시 신호 배수를 새로 보정했다고 주장하지 않는다.

## 이 결과가 제시하는 다음 범위

램프 보정부터 시작한 것은 유효했다. 다만 **10490 방출률만 보정하는 접근은 지지되지 않는다.** 다음에는10484 합류 지점의 접속 차로 유량·속도·platoon 간격과 정지선 이후 체류를 연결하고,10483·10682의 도시 하류 배수 변화가 어느 경계 입력에서 사라지는지 분리해야 한다. 평균 본선 유량 하나로 gap을 계산하는 현재 근사는 그 후보 중 하나다.

이때도 이번에 고정한 본선 계수를 먼저 다시 탐색하지 않는다. 국소 경계 반응을 확인한 뒤 같은450초 짝 비교를 통과시켜야 한다. 다만 seed23은 본선 ΔTTT 자체를−0.950에 대해−0.248로 예측하므로, **모든 상태의 문제를 램프만으로 해결할 수 있다고 확정할 수 없다.** 현재 후보는 제어 반응 검증을 통과하지 못했으므로 새 장시간 폐루프 실험을 시작할 단계가 아니다.
