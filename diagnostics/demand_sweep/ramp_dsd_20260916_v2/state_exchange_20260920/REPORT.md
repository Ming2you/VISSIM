**이득 예측 보정은 아직 NOT_QUALIFIED다.** 현재 속도·밀도에 따라 차로 교환률을 갱신하는 후보를 구현했지만, seed23의 실제 RM/VSL 이득을 여전히 손해로 예측했다. 이를 기본 plant로 채택하지 않았다.

## 1. 실제로 수정한 모델

`evaluation/controllers/physical_lane_groups.py`에 `StateDependentExchange`를 추가하고 기존 `canonical_harness.py`에 연결했다. `freeway.physical_lane_exchange_model` 설정이 있을 때만 켜진다. 이 후보는 기존 차로군 기능도 필요하다. 제어기 어댑터 사본은 만들지 않았다.

인접 차로군 g→h의 초당 이동률을 다음과 같이 계산한다.

`r(i,g,h) = min(r_max, exp(a(i,g,h) + beta · standardize(x(i,g,h))))`

`x = [현재 g 속도, 현재 h−g 속도차, 현재 g 밀도, 현재 h 밀도]`.

입력은 학습 관측 범위로 제한하고 제한 횟수를 기록한다. 이동량은 기존 재고·수용 공간·목적지 보존 제약을 거친다. 실제4→3차로 연결과 진출 대기, 램프 비용도 유지했다. 미래 상태·미래 차로 이동률을 rollout에 넣지 않았고, VSL/RM 명령에 직접 붙는 보상이나 capacity drop은 추가하지 않았다.

보정 자료는 무제어 seed13/23,900–4500초뿐이다.900–3000초로 적합하고3000–4500초로 ridge를 고른 뒤 두 seed의 무제어 전체로 다시 적합했다. 제어 자료와 seed33은 적합·ridge 선택에 사용하지 않았다. seed33은 이전 작업에서 이미 본 개발 검증 자료라서 완전히 새로운 holdout이라고 부르지 않는다.

- 설명변수4개, 인접 주소별 절편40개, 최종 학습27,933행.
- 시간 분리 검증 Poisson deviance: 상수 교환률18,635.47 → 상태 기반12,569.62(32.55% 감소).
- 같은 검증의 실제 이동9,942건 대비 예측11,369.84건: 총량은 여전히14.36% 과대.
- 이는 **현재 실측 상태와 미래10초의 실측 exposure로 평가한 이동률 적합도**다.450초 자율 예측 향상과 구분한다.

## 6. 다음 보정 방향과 채택 기준

1. **DSD 전달과 동역학을 분리해 연결한다.** 이미 검증한 분위수 보존 변환을 이용해 현재 차량군의 희망속도 평균·분산이 하류로 전달되는 상태를 검토한다. 기존 속도 상한만 변경하는 모형에는 이 정보가 없다. 다만 이번 진단만으로 분산 감소→용량 증가 함수를 정하지 않는다.
2. **국소 모형의 비용 범위를 유지하고 하류까지 검증한다.** 출구10643 주변 개선,10490/10484의 서로 다른 반응,link24 하류 손익을 함께 설명해야 한다. 필요한 경우에만lanes3/4와 목적지 접근 상태를 분리한다. 모든 차로를 무조건 세분화하는 작업으로 확대하지 않는다.
3. **RM은 수용 반응과 비용 크기를 별도로 고친다.** seed23에서는 램프 대기를 지웠을 때만 이득이 나오는 문제가 아니라 본선 회복량을 과소예측하는 것이 확인됐다. 실제 합류량·접속 차로 재고·하류 방출의 연결을 검증한다.
4. **동일한 미사용 제어 자료에서 반응 부호·구성 비용·후보 순위를 통과해야 채택한다.** 더 좋은10초 적합도, 미래 관측을 넣은 oracle, 한 seed의 좋은 결과만으로 승격하지 않는다. seed33 분산 축소의 손해도 이후 모델이 맞춰야 할 반례로 고정한다.

현재 기본 진단 모델은 이전 `merge_drain_response_20260919/decisions_v1/internal_cost/` 그대로다. 정본 파라미터·목적함수·운영 후보 범위·full GNE를 바꾸지 않았다. 새 상태 교환 후보, 새 CDF 진단 모두 실험용이며 실제 controller 순이득 개선 완료가 아니다.
