# 2026-09-19 램프 경계 반응과 MPC 비용 집계 수정

**중요한 원인 하나를 수정했다. 새 기하용 단독 MPC가30초 재고 표본으로 TTT를 다시 계산하면서 작은 후보 차이의 부호와 선택을 바꾸고 있었다.** 본선 물리·수요·명령을 그대로 두고 모델 내부 체류시간을 사용하자 seed33의2400초 선택이10484 제한에서10490 제한으로 바뀌었다. 이10490 명령은 이미 완료된 VISSIM 짝 실험의 첫450초와 일치한다.

진출램프 진입 속도·가속 시간도 구현하고 검증했다. 실제 진입 속도를 준 국소 검증은 개선됐지만,450초 결합 예측은 일관되게 좋아지지 않아 이 물리 후보는 채택하지 않는다. 이번에 검증한 것은 비용 집계 수정이며 RM/VSL 전체 성능 보정의 완료가 아니다.

## 이전 부호 진단을 정정한다

기존 `state_response_20260919/study.py:direction_parts`와 `evaluate_response.py:component`는 시작점부터30초 간격의 재고를 사다리꼴로 적분했다. 그러나 램프 미터는10초 주기로 움직이고, 램프 내부는1초·본선은10초로 계산한다.30초 재표본화는 이런 비용 변화를 충분히 보존하지 못한다. 이 함수가 단순 보고서뿐 아니라 `mpc_choice`의 후보 비용에도 쓰이고 있었다.

seed33,2400–2850초,10490 RM−무제어를 같은 물리 예측으로 비교했다.

| 동측 본선+4진입+4진출 connector ΔTTT [veh·h] | 종전30초 표본 | 각 자료의 원래 계산 시간 간격 |
|---|---:|---:|
| VISSIM | −0.266667 | −0.162222 |
| 모델:10484 수용 후보, 새 진출 가속 보정 없음 | +0.010392 | **−0.015433** |

**따라서 이전의 “seed33도 세 제어 모두 순이득 방향 실패”라는 결론은 정정한다.** 모델 내부 비용으로 보면 RM과동시 제어의 부호가 맞고 VSL은 여전히 틀린다(2/3). 크기는 여전히 크게 과소예측한다. seed23은0/3으로 남는다. 이는 새 물리 계수로 성능이 개선됐다는 결과가 아니라, 기존 예측을 잘못 집계한 부분을 바로잡은 결과다.

새 실제 값은 native1초 끝 재고를 합했다. 램프 진입·유출 사건으로 매초 재고를 재구성해 모든30초 원시 snapshot에 맞는지 검사했고, 진입램프는 head 재고와 매초 대조했다. 모델 값은 이미 계산하던 본선10초·진입램프1초 체류와 새로 감사한 진출램프 사건별 연속 유출 적분을 쓴다. 이산 모델과 native 사이의 시간 해상도 차이가 완전히 사라졌다는 뜻은 아니다. Ω 전체 기존 회계는 별개이며 아래에 따로 쓴다.

## 비용 집계 구현과 실제 선택

기존 `canonical_harness.DelayedPort.release`에 이동 중 재고와 실제 유출을 포함한 체류 적분을 추가했다. 서비스가 없는 동안에도 차량은 비용을 발생시키고, 도착 전의 남는 서비스를 저장하지 않는다. 부분 유출은 시간에 따라 실제 감소한 재고만 적분한다.

`freeway.physical_component_residence=true`인 모델은 기존 `simulate`와 `component`를 통해 그 체류량을 MPC 비용으로 사용한다. 체류량 정보가 누락되거나30초 실제 관측을 정밀 회계로 쓰려 하면 실패 처리한다. 목적함수 가중치·후보·제어 주기·writer·본선 물리는 그대로다. 옵션이 없는 과거 설정은 전체 예측이 정확히 같다. 새 adapter나 별도 selector는 만들지 않았다.

세 seed의 개입 시점과3600초, 세 설정으로 **기존 MPC 선택 함수18회**를 실행했다. 모든 초기 후보를 평가했으며 예산 초과로 일부 후보를 생략한 비교가 아니다.

| 기록 상태 | 종전30초 비용 | 물리는 그대로, 내부 체류 비용 |
|---|---|---|
| seed13,1650초 | 10490 제한 | 10484 제한 |
| seed33,2400초 | 10484 제한 | **10490 제한** |

다른 네 상태도 비용과 명령을 모두 저장했다. 단독 MPC의 후보 순위를 확인한 결과이며, 이전 full GNE가 정지했던 원인이 모두 이 문제라고 소급하지 않는다. 기존 full GNE의 새 기하 지원도 이번에 완성한 것이 아니다.

비용 수정만 켠 실행 가능한 진단 모델은 [decisions_v1/internal_cost/config.json](decisions_v1/internal_cost/config.json)이다. 진출 가속 후보까지 켠 `entry_and_cost`와 구분한다. 후속 단독 MPC 비교는 먼저 `internal_cost`를 사용한다.

근거: [18개 결정](decisions_v1/summary.json), [후보 평가 완전성](decisions_v1/completeness.json), [seed33 전 후보](decisions_v1/s33_internal_cost/mpc_candidates_2400.json).

## 10484: 평균 유량만으로는 놓치는 상태

seed13 무제어와seed23/33 무제어·RM의 FZP를 각각 한 번씩 읽었다. 실제10484 접속점은link24의165.698m,1차로다. 그 지점 전후100m씩 총200m를 같은 범위로 집계했다.

seed33,2400–2850초:

| 접속1차로 | 무제어 | RM10490 |
|---|---:|---:|
| 본선 통과 유량 [veh/h] | 976 | 1000 |
| 구역 내 평균 속도 [km/h] | 25.70 | 28.43 |
| 평균 재고 [veh/200m] | 10.94 | 10.28 |
| 5km/h 미만 평균 재고 [veh] | 1.72 | 1.36 |
| 평균 유량만 넣은 기존 gap 수용 상한 [veh/h] | 1006.71 | 997.41 |

실제 접속 차로는 RM 조건에서 속도가 높고 저속 재고가 줄지만, 평균 유량만 쓰는 gap 상한은 오히려 조금 낮아진다. 실제 본선 유량은 회복 상태에서 늘 수도 있어 낮은 유량을 곧 유리한 합류 조건으로 해석하면 안 된다. 같은 구간3차로 속도는 무제어48.28km/h로1차로와도 크게 다르다. 본선 전체 평균과 실제 접속 차로의 상태를 동일시할 수 없다.

이는 현재 수용 모형의 누락 후보를 좁히는 관측 근거다. 차로 재고·국소 속도·차량 간격 중 어떤 상태가 최소로 필요한지는 아직 구분하지 못했다. 이 표에 맞춰 임의의 capacity drop이나 제어 보상을 추가하지 않았다.

## 10483·10682: 진입 속도 보정은 국소 개선, 결합 예측은 보류

두 진출 connector의30초 표본에서는 장시간 정지 재고가 거의 없었지만 완주 통과시간은 달라졌다. 기존 모델은900초 이전에 정한 일정 이동 속도를 계속 썼고 초기 차량의 관측 속도도 이동 지연에 반영하지 않았다.

단일 차로용 선택 설정 `freeway.physical_offramp_entry_speed`를 기존 저장고에 연결했다. 관측 초기 속도와 예측된 본선 진입 속도에서 시작해 일정 가속도로 기존 순항 속도까지 가속하는 통과시간이다. 차량 보존·유한 저장·하류 서비스는 유지하며, 뒤 차량이 앞 차량을 통과하지 않도록 도착 시각에 FIFO를 적용한다. 새 차량에는 해당 시점의 모델 속도만 사용한다.

seed13 무제어의 완주 기록으로 유효 가속도를 보정했고 두 connector 모두0.75m/s²가 선택됐다. 이 값은 차량의 실제 가속 능력을 직접 추정했다는 뜻이 아니다. 실제 진입 속도로 조건화한 첫450초 무제어 검증의 통과시간 MAE는 다음과 같다.

| connector·seed | 일정 속도 [s] | 진입 속도 반영 [s] |
|---|---:|---:|
| 10483·23 | 2.357 | 2.037 |
| 10483·33 | 6.427 | 4.356 |
| 10682·23 | 5.884 | 3.688 |
| 10682·33 | 2.738 | 1.898 |

그러나 미래 실제 진입 속도를 주지 않은 결합450초 예측에서는10483 체류 MAE가seed23에서0.0550→0.1203,seed33에서0.0354→0.1001veh·h로 악화됐다(네 조건 평균).10682도seed23에서는 개선되지만seed33에서는 악화됐다. 모델이 내놓는 진입 상태·도착 분포와 남아 있는 하류 경계 오차를 함께 봐야 한다. **이 물리 옵션은 실험 후보로만 보존하며 후속 기본 실험에 켜지 않는다.**

근거: [보정·검증](transit_fit_v1/evaluation.json), [보정 절차](transit_fit_v1/protocol.json), [미래 실측 없이 계산한 결과](causal_v1/results.json).

## 검증과 다음 범위

- 56개 검사 PASS. 통과시간·FIFO·도착 전 서비스 금지·보존·시간 분할에 무관한 체류 적분·누락 기록 실패를 확인했다.
- 기본 설정의 과거12개 예측이 전체 JSON 기준으로 일치한다.
- 비용 옵션만 바꾼12개 비교의 셀·유량·진입 및 진출 저장고 기록이 정확히 같다. 비용 차이가 교통 상태 변경에서 온 것이 아님을 확인했다.
- 미래 관측을 삭제한 창과 예측도 일치한다. parameter 검사 PASS이며 과거 calibration/기하 경고는 유지한다.
- 최종 [검증](verification_v1/validation.json)과 [소스 동결](verification_v1/freeze.json). `causal_v1/freeze.json`은 비용 연결 이전 단계의 역사적 소스 pin이다. 최종 실행 근거는 결정별 model pin과 최종 검증 pin을 따른다.

지금 유지할 변경은 **단독 MPC의 내부 체류시간 비용 집계**다. 진출 가속 후보는 보류한다. 다음 물리 검토는10484 접속 차로의 재고·속도와 본선 평균 상태 사이의 관계를 최소 상태로 연결하는 데 좁힌다. 비용 집계 오차가 섞인 종전 부호 점수를 목표로 추가 보정하지 않는다. VSL의 낮은 반응,seed23 RM 이득 과소예측,Ω 전체·장기간 회복은 여전히 남은 문제다.
