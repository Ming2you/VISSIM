# 새 기하 제어 응답: 중간 기록

사용자가 4500초 재검증을 요청하여, 최종 판단은 `../rules_4500_v1/REPORT.md`의 장기 룰 비교 이후로 미뤘다. 이 문서는 초기 결과를 보존하는 기록이며 full controller 완료 보고가 아니다.

## 완료

- 새 망의 실제 셀 길이/차로 수 및 8개 램프 head·merge 주소로 geometry profile을 재생성했다. 기존 4개 룰 실험의 FZP에서 보존식이 닫히는 42셀·16개 on/off port 관측을 추출했다.
- 동일 1650초 상태에서 RM g8 유지, RM g8→6→4, DSD59–62 VSL100→80, 동시 제어를 새로2250초까지 실행했다. 기존 무제어를 대조군으로 재사용했다. 전체 초기 FZP 데이터 행, native LDP, 적용readback 검증을 통과했다. 자료는 `../response_pairs_v1`.
- 기존 METANET·기존 1초 램프 계산을 재사용하여, 8개 램프의 이동·head service·본선 수용·대기를 함께 예측했다. 450초 예측 중 관측 상태 재설정은 없다. 실제 DSD의 공간 범위를 셀 중심으로 투영하고 각 셀 명령을 기록했다.
- 새 망 무제어의900초 이전 관측만으로 connector 이동속도와 셀 자유속도를 갱신했다. 42셀 중40셀은 저밀도 표본으로 갱신했고2셀은 표본 부족을 표시했다. 동측 cell14 자유속도는 이전78.1에서117.34km/h로 달라졌다. 혼잡 해소/제어 이득을 강제하는 capacity drop은 추가하지 않았다.
- 제한된 계수 후보를 기존 룰 실험으로 비교했다. `model_v1`은 merge 계수만, `model_v2`는 새 자유속도와 동측 임계밀도/merge 계수를 점검했다. 새 동일 상태 비교의 결과를 보기 전에 후보 예측을 저장했다. 정본 파라미터로 채택하지 않았다.

## 초기 응답 검사 결과

1650–2100초10490의 무제어/단계적RM 실제 합류는96/84대. `model_v2` 예측은81.63/77.15대였다. 동일 부분 영역(본선42셀+8on connector+8off connector) TTT는 실제159.058→159.475veh·h 증가했지만 예측은 약0.002veh·h 감소였다. 이 부분 영역을 Ω 전체로 부르지 않는다.

도착량을 직전150초 평균으로 고정하는 예측, head에서 실제 출발 가능한 차량, 본선 병목 반응을 분리할 필요가 남는다. 2250초까지의 작은 차이만으로 혼잡 이후 정책 우열을 결정하지 않는다.

추가로2차로10482의 component merge 상한이 이전 그룹의1800veh/h를 물려받은 것을 확인했다. 450초 실제 합류265대는 이 상한이 허용하는225대를 넘는다. `canonical_harness.py`에 명시적8개 `freeway.physical_ramp_capacity_vph` 옵션과 입력 검증을 추가했다. 옵션이 없을 때 기존 출력의 완전 동일성을 유지한다. 실제 본선 수용량을 이 상한으로 대체하거나 OFF=g10을 입증했다고 주장하지 않는다. 새 상한 값의 적용/반응 검증은 후속 작업이다.

## 진행 상태와 제한

- 사용자 요청으로 기존 ALINEA/규칙VSL4조건을4500초까지 재실행한다. `rules_4500_v1`은 네트워크 bytes·정책·수요·seed13·SimPeriod9001이 기존3000초 조건과 같고 SimBreak만 연장한다. 검지 위치도 중간에 바꾸지 않는다.
- 전체 follower의 가변 셀 길이 경로와 최신 native 망의 공유 재고/수요 authority 이행은 아직 완료되지 않았다. 명시적 실행 차단을 제거하지 않았다.
- 새로운 교통 결과·예측 비교가 통과하기 전에는 작은 비용차를 근거로 정본 controller에 계수를 채택하지 않는다. 작은 중앙집중 후보 비교조차 Ω 전체 모델이라고 주장하지 않는다.
- full GNE 폐루프 검증은 미완료. 위의 VISSIM 실험은 룰 제어 또는 고정 명령의 실제 실행 검증이다.
