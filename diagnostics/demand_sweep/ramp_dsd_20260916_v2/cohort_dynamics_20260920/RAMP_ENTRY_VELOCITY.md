# 합류 차량 속도 수송 검증 — 보정 미완료

직전 goal turn은 전달 작업을 완료한 progress다(`56fcfac` 원격 확인). 이번에는 기존 차로군 함수에 선택적 합류 속도 입력을 연결하고 기록 상태의450초 비교를 완료했다. **세 후보 모두 순이득 보정 실패이며 기본 채택하지 않는다.** 새 옵션은 진단 호출에서만 사용하고 기존 실행의 기본 동작은 유지한다. full Ω/full GNE 검증이 아니다.

## 최소 변경과 발견한 구현 오류

기존 모델은 새 합류 차량을 수용 차로 속도로 취급했다. `PhysicalLaneGroups.advance(..., ramp_entry_speed_kmh=...)`는 실제 수용량만으로 차량 수×속도의 혼합을 계산한다. 공간 분리 셀에서는 합류 뒤 재고에만 해당 속도를 전달하고, 기존 차량의 속도·수송을 중복 이동시키지 않는다. 명시적 입력이 없으면 기존 경로다. 실제 액추에이터·흐름 보존·본선/램프/진출 비용 규약은 그대로다.

첫 진단은 `_label` 관측기에서 바꾼 속도가 이후 `carrier_v=oldv`에 덮였다. 분리 셀에만 반영된 이12개 결과는 `ramp_entry_velocity_work_v1/adjudication.json`에서 **INVALID_PARTIAL_APPLICATION**으로 제외했다. 소스와 결과를 보존했다. 수정은 기존 함수 내부에서 혼합 속도를 횡방향 이동까지 전달하는 작은 변경이며 adapter 복제는 없다.

## 인과적 입력과 완료 결과

기준seed23의2250초 초과~2400초 합류 직전 속도만 평균해 고정했다.10490은66.530km/h(37대),10484는30.463km/h(27대),10639는54.790km/h(25대),10681은19.958km/h(40대)다.2400초 뒤의 관측은 예측 입력에 없다. 이 상수 예측이 RM/VSL 이후 가속·간격을 정확히 설명한다고 가정하지 않는다.

두 기본 후보는 기존 merge 감속항 δ1을 유지하거나 δ0으로 대체했다. 세 번째는 기존10483 분기 전후 공간 분리를 함께 켜 합류 뒤 약91m 길이를 반영했다. 계수를 이득에 적합하지 않았다.

## 검증과 적용 범위

- 관련47개 검사 PASS. 새 검사는 합류 속도가 횡이동 뒤에도 남는지, 분리 셀의 후방 공간에 한 번만 들어가는지, 차량 수·속도 모멘트가 보존되는지 확인한다. 이후 완전한 키 집합의NaN/음수/bool 거부도4개 검사 재실행으로 확인했다.
- 기능 비활성4개 전체 JSON 기존 기록과 정확 일치. 후보12개 서측 불변·보존·비음수·jam 한계 PASS.
-33,712개 혼합 모멘트 등식,19,800개 실제 ODE 진입 시 모멘트 유지,16개 소스 pin 확인. `ramp_entry_velocity_validation_v1.json`.
- config 파라미터 검사 PASS. 기존 calibration 경고는 그대로이며 full GNE 통과를 의미하지 않는다.
- 다중 초기 상태 보호·자유류 선택·미사용 seed는 이번 실패 후보에 대해 수행하지 않았다. 계수나 평균 속도 입력을 추가 조정해 성공으로 포장하지 않는다.

## 다음 식별

고정 과거 평균 속도 혼합과 이 공간 분리 조합이 충분하지 않음을 확인했다. 이는 모든 합류 가속/속도 모델이 무효라는 증명은 아니다. 다음 대상은 합류 시점의 실제 추종 대상·제동 상태·차로 변경과 그 반응 지속시간이다. 기존 RM9열에는 이 필드가 없었으므로 기하상 앞차를 native 추종 대상으로 동일시하지 않는다.

같은 RM 명령(seed23, g8→6→4)의 관측 열만 추가한3000초 재현이 정상 완료됐다. 기존 runner의 LDP/readback 검증은 통과했고, 원래9개 FZP 열11,790,482행이 기존 런의3000초까지 정확히 같았다. 초기 전역5,189대와2400–2460초61개 프레임을 보존했다. `route_state_native_v1/rm_ramp_s23/analysis_v2`가 유효한 분석 결과다. 첫 parser는 마지막 빈 interaction target을 잘못 제거해 실패했으며 `analysis/failure.json`과 수정 전 소스를 별도 보존했다. native 런 자체는 재실행하지 않았다.

차량17532는 NC에서2418초에 합류 차량18665를 대상으로 `Brake AX`와97.57km/h를 기록했지만 RM에서는 다른 차량을 대상으로 `Free`,109.92km/h였다. RM에서도2420초부터 다른 차량을 대상으로 제동하므로 지속적 이득이나450초 순이득의 원인으로 단정하지 않는다. native interaction은 직전 simulation step의 기록이고, 길이만으로 차종을 추정하지 않는다. `analysis_v2/paired_focus.json`에 두 궤적을 보존했다. 이번 관측 반복은 새로운 독립 성능 표본이 아니다.

다음은 같은 초기 차량군의 실제 추종 대상·제동 지속시간·차로 변경을 이용해 반응 누락을 구분하는 것이다. 넓은 평균속도/계수 sweep을 반복하지 않는다. 미사용 seed·450초 구성 비용·순위·무제어 보호와 정본 통합 요건은 그대로 남는다. 이후 Ω·도시 대기·TTD와 full GNE는 별도다.
