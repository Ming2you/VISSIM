## 이번 검사의 범위

seed23의 현재 실제 상태를 매초 새로 받아 해당 차량의 다음1/5/10초 속도 변화를 예측했다. 학습은900–2090초 시작 상태와2100초까지의 결과다. 시간 검증은2100–2390초 시작 상태, 제어 후 진단은2400–2840초 시작 상태다. 모든 예측은 해당 시작 시각 이전/현재 정보만 사용한다.

**450초 시작점에서 미래인 상태들을 매초 실제 값으로 다시 받은 조건부 검사다.** 따라서 이것을2400초부터450초를 자체 예측한 결과, plant 오차 개선, TTT 이득 예측 성공이라고 해석하지 않는다. 단일 이미 본 seed이며 수십만 차량·초는 독립 실험 횟수가 아니다.

대상은 완전하게 관측되는cell14–20다. 현재 기하상 동일 차로의 앞차와 간격을 사용했다. 미래 native interaction target이나 미래 차로 변경을 입력으로 넣지 않았다. 현재 간격이 음수인 차로 투영 겹침, 앞차 미관측, 대상 밖으로 나간 미래 라벨은 명시적으로 제외/집계했다.5/10초 라벨은 말단 유출로 중도 절단될 수 있다.

비교식은 같은 학습 자료의 조건부 평균표다. 속도·밀도 구간만 쓴 식을 기준으로, 다음 정보를 추가했다.

- 간격: 실제 앞차 뒷면까지의 거리 / 기존 CC0+CC1×현재 속도. CC 값은 native 설정에서 읽었다. 이 비율의 진단 구간은 물리적 폐쇄 법칙이 아니다.
- 상대속도: 현재 자기 속도−현재 앞차 속도.
- 순서 변경: 현재 기하상 앞차가 직전 초와 달라졌는지.
- 가감속 이력: 현재 속도−직전 초 속도. 직전 기록이 없으면 unknown으로 둔다.

표의 최소 지원30행과 분류 경계는 고정된 진단 설정이다. 제어 결과로 후보 경계를 탐색하거나 차량 비용 보너스를 넣지 않았다. **이 비교의 기준은 정본 METANET 자체가 아니다.** 어떤 정보가 평균 속도·밀도에 더 필요한지 구분하기 위한 제한된 식별 검사다.

## 대조 집단을 수정한 이유
