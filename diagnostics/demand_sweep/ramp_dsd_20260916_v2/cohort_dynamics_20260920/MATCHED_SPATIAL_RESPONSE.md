# 두 2550초 상태에서 RM 응답을 비교한 후속 기록

판정은 **NOT_QUALIFIED**다. 기존 선택적 모델 기능으로 두 개발 상태의 RM 선택 순위는 맞췄지만, 순이득 크기와 본선·램프·진출 비용을 충분히 설명하지 못했다. 실패 후보를 기본 활성화하지 않았다. 이 단계에서 모델 본체·수요·기준망 수정이나 새 VISSIM 실행은 없었다.

## 비교 조건과 결과

사용자 가속거리 수정 + 램프 DSD120, 동측 본선 입력1098만 0.8배인 망이다. 같은 seed의 2550초 상태에서 3000초까지 예측한다. RM_C10490만 변경하며 10초 RED/GREEN 주기, 실제 녹색 변경 한도2초를 유지한다. 기준은 g8 유지이며 **무제어가 아니다**. 평가 영역은 동측 본선 + 진입4개 + 진출4개 connector이며 **Ω 전체가 아니다**.

마지막 후보의 순위는 실제와 같다: seed23에서는 g8→g6→강한 RM, seed33에서는 강한 RM→g6→g8 순이다. 그러나 seed33 강한 RM의 이득 크기는 실제의 약8%만 예측한다. seed23 강한 RM의 본선 ΔTTT도 실제 +0.401389에 대해 −0.476172로 반대다. 총비용의 부호가 맞는 것만으로 보정 성공이라고 할 수 없다.

1. `matched_resolution_response_v1`: 10초/1초 적분 12개 예측. 이전10초 예측6개 전체 JSON 정확 일치, 1초 명령구간2700개 동일. 시간 해상도만으로 문제가 해결되지는 않았다.
2. `matched_lane_response_v1`: 현재 차로군 재고·속도, 과거150초 교환률, 기존 모멘텀 수송·진출 차로 옵션의 18개 예측. 서측 기록18개 동일. 순이득 보정 실패.
3. `matched_port_timing_response_v2`: 실제 이동거리·현재 위치·합류 출신 재고 및 기존 분기 전후 상태의 18개 유효 예측. 이 중6개는 실패한 v1의 완료 예측을 설정·입력 일치 확인 후 재사용했다. 서측18개 동일, 램프 차로 인터페이스16,200개 확인. 계수를 새로 적합하지 않았다.

총48개의 유효 예측 사례다. 10481의 분기 분리를 추가한 최초 시도는 차로가 끝나는 기하를 지원하지 않아 중단됐다. `matched_port_timing_response_v1/failure.log`와 수정 전 소스를 보존했고, 보호 조건을 우회하지 않았다. v2에서는 그 미지원 옵션을 제외했다.
