# 누적 경계 수정과 실제 하류 차로 접근 실패

2026-09-20. **방출 지연의 중복을 제거하는 누적 경계 후보는 수치 검사를 통과했으나 RM/VSL 이득 예측은 여전히 NOT_QUALIFIED다.** 추가 원인 분리에서 기존 하류 배수 예측식은 실제 미래 상태까지 주어도 VSL의 방출 증가 방향을 틀렸다. 기존 native 궤적을 더 읽어, 녹색 중 목적 차로 접근 실패가 배수를 막는 구체적 사례를 확인했다. 새 VISSIM 실행·원본 망/수요·정본 core/기본 config 변경·commit/push는 없다.

## 입구와 출구에 같은 누적 보존식을 적용했다

`off_spatial_transport.py --cumulative`는 이전 `ReceivingEnvelope`의 초기 공간 분포와 삼각형 FD를 재사용하되, 이번에는 출구 sending도 같은 초기조건/누적 유입으로 계산한다. 출구 방출은 `min(sending, 외부 서비스×dt)`로 한 번 제한하며, 부분 차량을 소진한 뒤 다시 추종 지연을 더하지 않는다. 초기 재고 n0, 누적 유입 A, 누적 유출 D에 대해 항상 `n=n0+A−D`다.

초기 위치로 만든 upstream 누적 차량 함수의 부호를 바꾼 것을 N0(x), 자유속도를 v, 기존 파속을 w, 임계밀도를 kc, 용량을 Q라 하면 초기조건에서 허용하는 누적 유출의 상한은 다음과 같다.

`D_initial(t) = n0 + Q t − kc L + min[N0(x) + kc x]`

최소화 범위는 `max(0,L−v t) ≤ x ≤ L`다. `t≥L/v`이면 상류 이력 `n0+A(t−L/v)`도 함께 제한한다. 입구는 기존 초기조건/지연된 D에 따른 receiving 상한을 사용한다. 이는 누적 경계·초기조건을 함께 처리한다는 문헌 구조를 따른 진단 구현이며, 해당 문헌이 이 망의 보정을 검증했다는 뜻은 아니다. [Van der Gun 등, 초기조건을 포함한 LTM](https://research.tudelft.nl/files/46631109/2018_Van_der_Gun_Pel_Van_Arem_The_link_transmission_model_with_variable_fundamental_diagrams_and_initial_conditions.pdf).

파속은 기존 NC13 측정값 3.25573m/s, 저장 용량·평균 정지 간격·자유 이동속도는 기존 값이다. 새로운 이득 적합은 없다. 현재 위치는 기존 유한 간격 투영을 거치며 최대 이동 오차는 1/2차로 각각 0.11/3.71m다. 이 후보는 현재 개별 속도·길이를 새로운 상태로 보존하지 않는 연속체 근사다. 기존 공간 패킷 모델과 같다고 해석하지 않는다.

추가 7개 검사와 이전 6개 검사를 통과했다. 충분한 대기에서 입력 서비스 360/900대/h를 그대로 유지하고, 적색 중 0방출·녹색 복귀·자유주행 이전 유출 금지·미사용 서비스 비축 금지·상류 공간의 유한 전파·부분 유입 보존을 확인했다. 외부 서비스가 FD 고유 용량보다 높으면 그 용량으로 제한한다. 이전 합성 시험의 1800대/h도 새 FD 용량을 넘으면 그대로 재현할 대상으로 두지 않는다. 낮은 서비스까지 직렬 지연으로 축소하는 결함과 실제 고유 용량 제한을 구분한다.

시간 적분은 1초 내부 구간의 균일 방출 근사이고, 본선에서의 유입은 기존 10초 구간 끝 순서를 유지한다. 정본 액추에이터·수요·목적함수는 바꾸지 않았다. 과거 교환률 0인 seed23 시작 상태만 시험했으므로 일반 차로 변경 동역학은 아직 없다.

현재 상태+신호 후보의 NC 1차로 방출은 이전 지연 패킷의 49.21→62.33대로 늘었지만 실제 84대에 못 미친다. 예측 유입도 48.68대 대 실제 76대로 낮다. 2차로 방출은 NC/VSL 모두 28.51대로, 실제 23→30대 반응을 못 맞춘다. 따라서 낮은 1차로 방출의 일부 인터페이스 결함을 고쳤지만 전체 물리 반응을 설명한 것은 아니다.

## 실제 미래 상태를 주어도 기존 배수식은 방향을 틀린다

`urban_service_response_decomposition.py`는 기존 NC13 배수식의 계수·40초 신호 지연을 그대로 두었다. 예측 시작점 이후 상태를 선택적으로 실제 값으로 교체한 것은 **원인 분리용 미래 정답 입력**이며 운영 예측에 사용할 수 없다. 현재 초기 상태와 신호는 비교 조건 간 정확히 같다.

|2차로 450초 방출 변화[대]|seed23 VSL−NC|seed33 분산만 축소−NC|
|---|---:|---:|
|실제|+7|+1|
|현재 상태 고정, 신호만 진행|0|0|
|실제 미래 진출 head 상태만|+0.59|−0.69|
|실제 미래 도시 재고만|−1.01|+0.08|
|실제 미래 상태·배수 이력 모두|−0.35|−0.59|

따라서 도시 상태를 갱신하기만 하면 기존 선형 배수식이 제어 반응을 해결할 것이라는 가설도 지지되지 않는다. seed33 분산 변경은 이전 전체 비용이 악화된 반례이며, 작은 +1대만으로 좋은 제어라고 판정하지 않는다. 두 조건 모두 삭제가 없는 짝 10초 구간은 각각 35/45개이고, seed23 그 구간에서도 실제 2차로 방출 증가는 +7대다. 이 제한은 이전 삭제의 간접 영향을 제거하지는 않는다. 이 진단의 회귀 계수는 인과적 병목 계수가 아니다.

## 녹색 중 실제 목적 차로 접근 실패

기존 seed23 NC/VSL FZP에서 2400–2850초의 10643·126·10641·10700·71 위치를 다시 추출했다. 각 조건 451개 프레임을 기존 재고와 3,600건씩 대조해 모두 일치했다. 원래 native 파일의 크기/mtime도 추출 전후 일치한다. 신호는 기존 LDP 대조를 통과한 자료다.

71의 3차로가 연결되는 SG2 녹색은 두 조건 모두 45초다. 그런데 정지선 통과량은 다음과 같이 크게 달라진다.

|동일 녹색 구간|NC 3차로 통과|VSL 3차로 통과|NC/VSL 큐 존재 시간[초]|
|---|---:|---:|---:|
|2474–2519|17|22|10 / 4|
|2624–2669|4|2|36 / 43|
|2774–2819|1|3|43 / 40|

두 번째 녹색의 선두 정지를 궤적과 오류 기록으로 확인했다.

- NC 차량 13038: 71의 3차로, 위치 73.39m에서 선두 정지. 해당 녹색 중 선두로 정지한 시간이 31초다. 2682초 오류에 45초 차로 변경 대기 후 삭제가 기록되고 2683초 FZP에서 사라진다.
- VSL 차량 13942: 같은 차로·위치에서 녹색 중 선두 정지 37초. 2676초에 같은 종류의 삭제 오류, 2677초 FZP 소실을 확인했다.

둘 다 2400초에는 10643의 2차로에 있었다. 오류에 기록된 static route 1126–1을 실제 run의 망에서 확인하면 `126→10641→71→10635→47`이다. 10641은 71의 2·3차로에 들어오지만, 10635는 71의 4·5차로에서 시작한다. **녹색만 충분하면 정상 방출되는 대기가 아니라, 목적 connector에 맞는 차로로 이동하지 못해 앞을 막는 상태**다. 위 두 삭제는 두 번째 녹색 종료 후에 발생한다. 따라서 해당 녹색의 낮은 방출을 삭제 사건 자체로 설명할 수는 없으며, 이후 삭제로 생긴 공간은 별도로 경계해야 한다.

이 사례만으로 VSL의 모든 이득이나 그 차량들의 경로 선택이 VSL 때문에 바뀌었다고 주장하지 않는다. 또한 오류에서 얻은 미래 route label을 2400초 예측 입력에 넣으면 안 된다. 이는 필요한 상태를 찾는 진단 근거다.

71의 3차로 접속점 앞 6m 안에 저속 차량이 있다는 단순 표식도 공급 0과 같지 않았다. 그 표식이 있는 초에도 10643 정상 유출이 관측됐다. 차량 전면 거리는 후미 여유가 아니며, 짧은 연결부 중간의 공간과 이동 시간을 생략한 이진 폐쇄로 사용하지 않는다.

## 다음 결정

새 누적 경계는 서비스 중복을 제거한 진단 후보로 보존하되 기본 채택하지 않는다. 다음은 **현재/과거 자료에서 확인 가능한 차로별 목적지 구성·선두의 목적 차로 접근 가능성·인접 차로 여유**를 확인하는 것이다. 현재 자료에 목적지 정보가 없으면 먼저 그 관측 공백을 명시하고, 필요한 최소 기록만 기존 native 실행 경로에서 확보한다. 미래 삭제 경고나 나중의 경로를 현재 상태로 소급해 넣지 않는다.

이 상태를 확보한 뒤에만 `71 차로별 방출→126/10643 수용→본선 부분 차단`을 차량 보존으로 연결한다. 보상/용량을 이득에 맞춰 더하거나 무조건 차로를 닫는 방식은 쓰지 않는다. 10681/10484 합류 타이밍과 램프 대기 비용의 남은 오차도 별도 유지한다. 최종 기준은 인과적 구성 비용·손익/순위·NC 보호·자유류 해제·미사용 검증·정본 채택 전체이며, 보정 목표는 active다.

근거: `off_spatial_transport_cumulative*_v1/`, `off_spatial_transport_cumulative_validation_v1.json`, `urban_service_response_decomposition_v1.json`, `off_urban_entrance_state_v1/review.json`. 이전 진단 소스는 `source_before_cumulative`, `source_before_validation`, `source_before_review`에 원본 바이트로 보존했다. 모든 이번 계산은 종료했고 실행 중인 소유 프로세스는 없다.
