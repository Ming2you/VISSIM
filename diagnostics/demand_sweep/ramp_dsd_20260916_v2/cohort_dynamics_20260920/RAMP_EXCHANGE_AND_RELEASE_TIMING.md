# 램프 차로 이동 수정과 남은 방출 시각 오차

2026-09-20. **목표active, 보정NOT_QUALIFIED.** 직전 차로 전달/차로 이동 진단은 실제 코드 수정과 원인 분리를 낳은 progress였다. 이번에는 기존 물리 buffer에 차로 이동을 추가하고123개 검사 및450초 응답을 검증했다. 이득 검증은 실패했으므로 기본 모델에 채택하지 않는다. 이번 native 런은0회이며 소유 실행 세션은 모두 종료됐다.

## 구현과 검증

기존 `physical_ramp_boundary.py`의1초 진행 루프를 공유하는 generator로 정리했다. 기본 단일 차로 경로는 즉시 끝까지 소비하고, 차로 이동이 켜지면 모든 차로가 같은 시각에서 한 번씩 움직인다. 별도 서비스/주행 모형이나 adapter를 복제하지 않았다.

선택 설정은 `freeway.physical_ramp_lane_exchange`이며 이번에는10681만 적용한다. 앞선 물리 차로→본선group 매핑이 있어야 한다. 신호두 전/후에 독립적인2×2 차로 이동률을 받는다.1초 이동 요청은 `n_i (1-exp(-sum_j rate_ij))`를 목적 차로별 비율로 나누고, 받는 차로의 해당 단계와 전체 차로 빈 공간으로 제한한다.

- 이동 차량은 신호두 전/후 단계를 넘지 않고, cohort의 남은 도착시각ETA를 유지한다. 즉시 도착·합류하는 지름길을 만들지 않는다.
- 현재 공간만 예약하고 같은 초에 빠져나갈 것으로 기대하는 공간을 빌리지 않는다. 여러 출발 차로/단계가 같은 공간을 중복 사용하지 않는다.
- 차로간 입장·퇴장 ledger를 별도로 기록한다. 차량 생성, 외부 유입, 신호두 통과 또는 본선 합류로 중복 계상하지 않는다. 총TTT는 모든 차로의 실제 재고 시간 적분이다.
- 선택적으로 차로별1초 도착 프로필도 받을 수 있다. 전체/매초 요청 합과 일치해야 한다. 이는 원인 분리에서 기록된 도착을 제공하기 위한 입력으로, 운영 경로에서 미래값을 읽지 않는다.

차로 이동은 단계 내 동질적인 비례 이동, 공간은 단계 합계라는 근사다. 개별 위치에서의 미시적 차로 변경 gap을 검증한 모델이 아니다. 미래의 실제 이동량을 강제로 만들거나 재고를 매초 덮어쓰지 않는다. 기존 class 설명의 독립 lane 가정은 기본 경로를 뜻하며, 활성 상태와 이동률은 runtime metadata에 별도로 표시한다.

`ramp_exchange_v1/validation.json`:123개 단위/회귀 검사PASS, Python `-O`에서도 신규10검사PASS, parameter검사PASS다. generator 진행을assert의 부수효과에 의존하지 않도록 확인했다. 원래 기본12개 전체 forecast JSON과 활성12개 전체 JSON을 최종 코드로 정확히 재현했다.28개 forecast의 보존/비음수/저장,2520개 차로 보존식,1080개 램프→본선 전달 대조도 통과했다. 이 검사는 물리 구현 검사이며 이득 qualification은 아니다.

## 오차를 더 좁힌 원인 분리

같은 초기 상태에서10681만다음정보를추가했다. 다른 램프와본선 입력은원래과거 기반 예측을 유지했다. 미래도착은유한저장규칙을통해수용하고, 미래차로변경은관측출발재고당이동비율을모델의예측재고에곱한다. 실제재고·합류량을강제로대입하지않는다.

1. **실제1초 차로별 도착만 제공:** seed33의원래도착예측153대가실제124대보다많고1/2차로비율도다른점을분리했다. 과거진단의미래총도착+고정차로비율과구분한다.
2. **실제 차로 이동비율도 제공:** seed33 NC1차로합류예측이약5.01대로실제4대에가까워졌다. VSL도7.82대/실제7대다. 하지만대기가집중된2차로는NC106.18/실제127대,VSL105.97/실제126대로과소예측했다.
3. **합류대상 본선차로의 실제 평균 유량도 gap 계산에 제공:** 미래본선재고/속도를대입해plant상태를덮지않고,cell9 각차로의 `n*v/L`만10681 gap 기회계산에썼다. 예측빈공간·총합상한·실제수락flow는유지했다. 그럼에도2차로합류는seed33 NC108.67/VSL105.26대로실제127/126대를놓친다. 이때native상충유량은약1312/1369대h,기존예측도약1314/1316대h다. 평균유량오차만으로부족한방출을설명할수없다.
