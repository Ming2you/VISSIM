# 수용 공간 비교와 제어 반응 전달 검증

**판정: NOT_QUALIFIED.** 무제어 방출 오차 일부는 줄었지만 VSL/동시 제어의 이득 방향은 여전히 틀렸다. production 설정·core·망·수요는 바꾸지 않았고 신규 VISSIM 런은 없다. 이전 목적지별 분리 시험은 `LANE_BLOCKING_DECISION.md`에 보존한다.

## 구현·실행한 변경

기존 `urban_route_transport.py`의 진단 경로에 `prefer_more_receiving_space`를 추가했다. 강제 변경이 필요한 차량이 현재 차로에서 다음 셀로 진행할 수 있고, 그 전방 수용량이 인접 목적 차로의 수용량보다 클 때만 조기 변경을 미룬다. 양쪽 모두 열려 수용량이 같으면 기존 변경을 허용한다. connector 접근 한계에서는 계속 직진하지 못하며, 차로별 공간·FIFO·신호·차량/목적지 보존은 유지한다. 새로운 속도·간격 계수나 목적지별 이득 보상은 없다. 셀 수용량을 실제 차체 간격으로 간주하는 검증된 법칙은 아니다.

먼저 혼잡한 목적 차로로0.0625대가 조기 이동하는 반례 검사를 만들고 실패를 확인했다. 변경 후27계약이 통과했다. 목적지별 지연이나 기존 일괄 지연과 동시에 켜지지 않도록 검증한다. 기본 비활성이다.

실행:

```powershell
python -B -X utf8 diagnostics/demand_sweep/ramp_dsd_20260916_v2/cohort_dynamics_20260920/urban_route_transport.py --probe --lateral-access --prefer-receiving --nc-only
python -B -X utf8 diagnostics/demand_sweep/ramp_dsd_20260916_v2/cohort_dynamics_20260920/urban_route_transport.py --probe --lateral-access --prefer-receiving
python -B -X utf8 diagnostics/demand_sweep/ramp_dsd_20260916_v2/cohort_dynamics_20260920/urban_route_transport.py --local-recovery --prefer-receiving
```

출력은 각각 `urban_route_transport_space_v1_nc`, `urban_route_transport_space_v1`, `urban_local_recovery_space_v1`이다. 이미 완료된 폴더를 재실행해 덮어쓰지 않는다.

## 무제어 개선과 이득 실패를 구분

seed23의 동일2400초 초기 상태에서450초 예측했다.10643 2차로 정상 방출은 기존30.819대에서27.590대로 실제23대에 가까워졌다. 그러나 VSL 예측은27.590186대로 무제어와 거의 같고, 실제는23→30대다. 무제어를 맞추기만 하면 제어 반응도 맞는다는 가설은 이번에도 성립하지 않는다.

## 하류 수정이 본선에 전달되지 않는 코드 결함인가?

수용량 조건을 바꾸자 하류 방출은2408초부터 달라지고, 본선에 넘기는10643 진입 상한도2500초부터 달라진다. 따라서 callback이 끊겨 있다는 증거는 없다. 다만 이번NC 비교에서 본선 `cells`, `flows`, `lane_groups` 및 `ramps` 전체 기록은 기존 후보와 정확히 같다. 상한을 이 정도 바꾸어도 실제 본선 유량은 달라지지 않은 것이다.

전체 score 사전은 off-ramp 체류 진단까지 포함하므로 동일하지 않다. 이것과 본선 물리 궤적의 정확한 일치를 구분했다. 이 국소 조건을 계속 조절해 본선 이득까지 보정할 수 있다고 가정하지 않는다.

현재 기록된 로컬 링크의2250–2400초 모든 프레임은 NC/VSL이 동일하다. 이후 최초 차이는 차량19204에서 관측된다:

VSL의126은 짧은 링크여서1초 프레임에 잡히지 않는다. 차량이 없어졌다는 뜻이 아니다. 진입할 때 관측 속도는52.50 대63.74km/h다. 늦게 진입한 차량이 먼저 하류에 도착하므로 진입 누적 대수뿐 아니라 주행 지연과 합류 순서가 함께 바뀐다. 로컬 영역에서 처음 관측되는 차이라는 뜻이며 전체 망 최초 반응이라고 주장하지 않는다.

10643 내부의 실제 차로 번호 변경은 VSL2555초, NC2595초부터 발생했다. 모두2400초 초기 로컬 재고 밖의 차량이다. 이미 진행 중인 변경은 차로 번호 변경보다 이를 수 있으므로 번호 전이 시점을 변경 시작으로 오해하지 않는다. 이 순서만으로 인과관계를 확정하지 않지만, 나중의10643 차로 교환만을 초기 도시부 차이의 원인으로 삼을 수는 없다.

`control_influence_audit.json`은 미래 궤적을 검증 자료로만 사용한다. 예측에 미래19204 궤적이나 차로 교환을 주입하지 않았다. 이전 실제 경계 유입 oracle도 배수 차이를 충분히 설명하지 못했으므로 같은 실험을 그대로 반복하지 않는다.
