# 차로별 전달 수정과 램프 차로 이동 검증

2026-09-20. **보정 NOT_QUALIFIED, 목표 active.** 이번 체크포인트의 계산은 모두 완료했다. 차로별/off-ramp 차단 요청을 이어 기존 궤적과450초 모델 응답을 검증했다. 새 VISSIM 런은 없으며 원본 망·수요·신호·production 기본 config는 유지했다. 기존 물리 모듈과 canonical harness에 선택적 차로 전달만 추가했다. 사본 어댑터는 만들지 않았다.

## 무엇을 고쳤고 무엇은 아직 틀리는가

10681은2차로 connector이며 본선1·2차로에 연결된다. 이전 모델은 램프 차로별 실제 수락 합류량을 계산하고도 본선으로 전달할 때 합계를 다시50:50으로 나눴다. 출처별 본선 재고에도 이 고정 비율이 적용됐다. 새 `freeway.physical_ramp_lane_coupling: {"RM_C10681": [0,1]}`은 다음을 바꾼다.

- 물리 램프 차로별로 접근 가능한 본선 group의 빈 공간과 상충 유량을 조회한다. 기존 canonical 총합 상한의 차로별 몫, 실제 빈 공간, 기존 gap 법칙의 상한을 교차 적용한다. 동일 group을 공유하면 공간을 중복 사용하지 않는다.
- 각 램프 차로에서 **실제로 수락된** 합류량을 해당 본선 group에 전달한다. 그 차로의 본선 재고·출처 재고·ledger가 같은 수량을 받는다. 합계는 기존 램프 방출과 정확히 같다.
- 이 선택 설정이 없으면 이전 동작을 유지한다. 계수·목적함수·신호·meter 서비스는 바꾸지 않았다. 이 수정만으로 램프 내부 차로 이동을 구현한 것은 아니다.

`ramp_lane_coupling_v1/evaluation/`의12개450초 예측에서1,080개 차로 인터페이스 대조와 차량 보존·서측 불변·비음수·저장 검사가 통과했다. 기본 비활성12개 전체 JSON도 이전 결과와 같다.113개 단위/회귀 검사와 parameter 검사가 통과했다. 이후 새 기능의 metadata가 기본 equal-share 설명으로 남는 문제를 바로잡았고,12개 전체 JSON을 다시 계산해 **그 metadata만** 달라졌음을 확인했다. 이전 소스 hash는 snapshot으로 보존했다.

## off-ramp 차단은 따로 유지해야 한다

기존 `LANE_BLOCKING_AND_OFFRAMP.md`의 결과는 여전히 유효하다.10643 진출램프2차로와 연결된 본선2차로 정지 대기를 관측했으며, 같은 시각3·4차로는 계속 통과한다. 진출 차단은 공유하는 차로의 통과/수용에 적용하되 그 차로의 차량·길이·저장·대기비용을 없애지 않는다. 모든 진출 접근 차로를 함께 폐쇄하거나10초 내내0으로 두는 규칙은 맞지 않았다.

현재 진출의 partial FIFO 제한은 저장고 총빈자리를 충분하다고 판단해 실제 차단이 생기는 조건에서 작동하지 않는다. 미래 관측 차단을 대입한 원인 분리도 국소 속도만 개선했고 순이득은 실패했다. 따라서 이번 램프 전달 수정 또는 차로별 속도 개선으로 이 문제가 해결됐다고 주장하지 않는다.

## 함께 끝낸 원인 분리

`port_arrival_response_v1/`은 진입 connector TTT를 초기재고·입장시각·합류시각의 시간 가중 합으로 정확히 분해했다.1초 끝 재고 기준으로 사건t의 가중치는(2851−t)/3600이다.15,360개 native 재고 대조가 통과했다. seed23 VSL의10484 체류 감소−0.11417은 입장시각 항−0.14472와 합류시각 항−0.03056의 차이다. 이를 합류 서비스 향상 하나로 설명하면 틀린다.

하지만 각 조건의 실제 미래 진입량을 모두 준 진단도 이득을 해결하지 못했다. seed23 VSL은여전히+0.11833이고,10681의 대기비용 변화도 실제−0.08806 대비+0.17790이었다. 미래 도착은 원인 분리용이며 운영 입력이 아니다. 모델의 미래 도착 요청은 이 시험에서 모두 수용됐다. 입력 거절 때문이라고 설명할 수 없다.

## 다음 작업의 좁힌 범위

1. 기존 램프 buffer에 필요한 것은 합류 서비스 감소 상수가 아니라, 현재 위치·신호두 전후 단계·차로별 이동을 보존하는 전달이다. 이동 후 남은 주행시간과 수용 공간을 유지해야 하고 이동을 입장·합류로 중복 계상하지 않는다. 우선10681의1/2차로 비용과 합류 수량을 동시에 검증한다. 미래 실제 이동을 준 진단과 과거 관측/현재 상태로 예측하는 후보를 분리한다.
2.10643→본선 차단은 별도 목표로 남긴다. 현재 진출 차로의 입구 대기/하류 방출로 차단과 회복을 예측하고, 열린 본선 차로까지 함께 닫지 않는다. 단순 미래 차단 대입·FD25 대입·배수 위상 변경의 기존 실패를 되풀이하지 않는다.
3. 후보가 해당 국소 수량·시각·대기 비용을 개선할 때만 기존450초 gain/state suite, 손해 반례(seed33 직접10484·분산축소), 자유류 해제, 이후 동결한 미사용 조건으로 확대한다. 지금 후보로 새native4조건을 반복하지 않는다.
