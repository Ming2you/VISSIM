## 다음 최소 실험

1. 이 결과를 근거로 global FD/ν/τ sweep이나 단순 density-to-closure 함수를 추가하지 않는다. 기존 off-ramp10643의 실제 연결 대기와 이번 link24의 이동하는 국소 정지를 같은 정적 차단 규칙으로 합치지 않는다.
2. cell16과20에서 정지 후 방출을 시작하는 차량·앞차 간격·차로 변경 종료·가속을 시간순으로 확인한다. 기존 native target 기록은 NC에 있으므로 우선 NC에서 시작/해제의 상태 변수를 식별하고, RM은 현재 보유한 위치·속도·차로 전이로 대조한다. 개입 후 새로 생성된 같은 ID를 동일 차량으로 취급하지 않는다.
3. 작은 국소 수송 검사에서 **현재 정지/이동 재고와 실제 위치·간격을 유지한 상태**가 평균 n/v만 쓸 때보다 다음 방출과 회복을 설명하는지 확인한다. 보존되는 대기/이동 상태가 필요한 근거를 확보한 뒤 기존 transition에 최소한으로 연결한다. 미래 정지표식으로450초 gain을 맞추는 방식은 운영 후보로 삼지 않는다.
4. 후보의 구성 비용·RM/VSL/동시 순위와 무제어 상태 보호를 통과한 뒤 미사용 검증으로 간다. 현재는 그 조건을 충족하지 않는다. fullΩ/fullGNE도 미완료다.
