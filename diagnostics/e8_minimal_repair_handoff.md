# E8 recovery error: bounded intervention and one next model change

The next defensible change is a **localized, conserved diverge/merge interface that retains physical branch order and lane/route-specific queue access around 10639→10682**. A positive-anticipation multiplier or generic acceleration ceiling is not ready for production. The controlled experiment below identifies the positive anticipation term as the dominant immediate error in the deeply congested state, but almost no remedy for the initial breakdown state. This is a proposal for the smallest new physical state needed, not a claim that a numerical node capacity or a complete lane-change model has been identified.

No production file, runtime input, configuration, FD fit, capacity, lane-loss coefficient or VISSIM run was changed by this task. The earlier speed-term/lane evidence remains unmodified. New diagnostic files execute the currently installed canonical endpoint with private inputs and an exception-safe temporary wrapper.

The paired experiment seeds pure n7's actual t1200/t3300 state, previous action, and held current action into `diagnostics/area_candidate_configs/n7_area_beta0.json`. Each endpoint runs three 150-second intervals with same-snapshot demand forecasting. The only intervention multiplies **positive** anticipation by zero at every freeway cell; negative anticipation and every other equation retain their original functions and parameters. Zero is an identification limit, not a proposed or fitted value. All four control vectors are identical between arms and all 45 substeps; recorded, prepared and finalized vectors are equal in these two cases. Both final area stock closures pass, original cfg/state/action/demand hashes are unchanged, and the 234 pinned input/source hashes remain unchanged during each pair. Each pair took about19 seconds. The decisive physical evidence is the **structure of the downstream state**. A partial-FIFO node is an appropriate structural reference, because blocked turn access need not block every through lane equally. Its restriction intervals still require physical/behavioral evidence; the literature is not a numeric calibration for this site. In particular, an empty downstream connector would not trigger a conventional receiving-supply-only FIFO restriction, whereas mandatory lane-change failure can already obstruct this diverge. That is why a scalar downstream-capacity multiplier or simply dividing E9 into lane-average densities would not complete the repair. [Wright et al., author-hosted primary paper](https://www.me.berkeley.edu/~horowitz/Publications_files/All_papers_numbered/Wright_node_models_transportation_networks_Transportation_research_B_2017.pdf).

What is identified now: node positions, lane attachments, branch support, physical signal/meter command paths, observed counts and selected route cohorts. What is **not** identified: a reliable mandatory lane-change acceptance law, a time-varying lane restriction interval, connector saturated discharge capacity, or candidate-dependent branch receipt split after present group aggregation. The immediate implementation stage should expose and conservatively update those existing physical observations/receipts behind one flag, reject missing route allocation, and test partition/closure/candidate isolation. It should not create a queue by adding vehicles or infer a physical branch's future receipt by dividing a group using a stale observed percentage. The subsequent node law must be tested against held-out free-flow/recovery as well as queued intervals, with physical branch stock, crossing time and lane-specific through/direct flow errors. A model that matches only cell8 speed is insufficient.

This preserves the causal role of all four levers: green and offset alter urban release timing and queues downstream of off-ramps; meters alter actual lane-specific merge receipts; VSL can meter upstream arrivals and change interactions before the node. None receives an invented equilibrium-capacity reward.
