## 아직 해결되지 않은 문제와 다음 방향에 대한 제안

**첫째, 실제 native 신호와 제어기 초기 행동이 충분히 정렬돼 있지 않습니다.** 확인한 SC1·SC1004는 워밍업 action에 균등 녹색34.5초·offset0으로 나타나지만 실제 native 녹색, offset, phase 순서가 다릅니다. native offset 숫자만 복사해도 같아지지 않습니다. 첫 제어 전환이 원래 신호보다 나빠지는지, green·offset의 작은 탐색으로 회복할 수 있는 출발점인지 먼저 확인할 가치가 있습니다. 아직 수정하지 않았습니다.

**둘째, 예측 방출의 오차가 의사결정을 바꿀 수준입니다.** 기존 동일 명령 비교에서 모델 TTD는약233, 실제는368이었으며, 고속도로 말단은133.617 대 실제134로 가까웠습니다. 차이 대부분은 non-terminal 경계 방출에 있었습니다. SC1004 수정으로 일부 차이를 줄였지만 전부 설명하지 못했습니다. SC107에도 신호 정지선을 지나지 않는 경로를 녹색으로 제한한 의심이 있으며 아직 고치지 않았습니다.

**셋째, NP가 음수인 후보를 시작할 적절한 행동을 찾지 못합니다.** 최신 NP−250 후보는 초기 행동의 실제 NP가+247.285여서 이웃 탐색 전에 탈락합니다. 이는 해당 후보 영역 전체가 불가능하다는 증거가 아닙니다. 목표를 바꾸거나 위반을 숨기는 방식 대신 같은 목표에서 실행 가능한 초기 행동을 찾는 절차가 필요합니다. 현재 gap 인증 미완료도 그대로 남아 있습니다.

**넷째, 수요와 기준망의 선택은 재검토할 여지가 있습니다.** 도시30%는 첫 비교용으로 유지했으나 삭제·경로 오류가 남았습니다. 더 높은 도시 수요 조건과 비교해 제어할 만한 혼잡이 어디에 얼마나 있는지, 정상 방출로 회복되는지를 다시 판단할 수 있습니다. 다만 수요를 바꾼 결과를 현재10% 목표의 개선으로 섞지 않아야 합니다.

## 재현 자료와 판정 기준

Ω는 고속도로와 도시 protected network의 합집합입니다. TTT는 Ω 내부 체류시간, TTD는 살아서 밖으로 이동한 관측 사건과 정상 말단 유출 추론의 합입니다. 내부 이동·삭제·미확인 소실·종료 잔여 차량은 TTD에서 제외합니다. 같은 차량이 재진입 후 다시 나갈 수 있으므로 TTD는 고유 차량 수가 아닌 사건 수입니다. 서로 다른 수요의 총 TTT를 제어 성능 순위로 비교하지 않습니다.

수치의 기준 파일과 작업 이력은 별첨 `EVIDENCE_INDEX.md`에 연결했습니다. 오래된 상태 문서에는 당시의 LIVE·pending 표현이 남아 있지만 이 보고서와 최신 완료 receipt가 현재 상태입니다. 신규 실험은 보류했으며, 완료된 자료를 지우거나 실패 판정을 성공으로 바꾸지 않았습니다.
