# 예측 재고가 VSL 반응을 바꾸는지 확인

2026-10-01. 기존 expanded036 예측과 native 캐시를 재사용한 진단이다. 새로운 계수·보상항을 만들지 않았다. 이전 목표 턴은 속도/유량 계측을 완료한 PROGRESS, 이번 턴도 아래 새 근거를 확보한 PROGRESS다. 전체 목표는 ACTIVE / NOT_QUALIFIED다.

## 1. 같은 식도 잘못된 재고에서 명령 반응이 달라진다

현재 Carlson A=0.5/E=2를 그대로 사용해, 각 저장 상태의 같은 밀도에서 `V(90)−V(110)`만 계산했다. 양수는90의 **평형 목표속도**가 높다는 뜻이지, 전체 TTT에서90이 유리하다는 뜻이 아니다. 명령을 실제 차량 전체에 즉시 적용한 자율 예측도 아니다.

31셀 전체465개 시점/셀×6개 조건을 읽었다. 아래 집계는 실제 VSL 노출 셀16–25의15개30초 표본, 조건당150개다. 초기29·43의 NC/VSL과 후기29의 RM유지/VSL 추가를 포함한다. 모두 이미 검토한 자료이며 미사용 holdout은 아니다.

|비교 상태의 기준 명령|예측 상태에서 V90>V110|실측 상태에서 V90>V110|방향이 다른 표본|
|---|---:|---:|---:|
|seed29 초기 NC|97/150|70/150|51/150|
|seed43 초기 NC|27/150|59/150|62/150|
|seed29 후기 RM 유지|30/150|20/150|22/150|

예측 셀 재고만 실측 재고로 치환하고 모델의 유효차로를 고정해도 이 세 경우의 방향 불일치 개수는 같다. 따라서 단순한 정적 차로수/유효차로수의 표시 차이만으로 설명되는 결과가 아니다. 실제 미래 재고는 이 원인 분리 계산에만 썼고 예측 입력에는 쓰지 않았다.

**셀24의 오류가 두 초기 seed에서 반복됐다.**

|셀24, 기준 명령의450초 표본 평균|예측 재고 / 실측 재고 [대]|예측 밀도에서 V90−V110|실측 밀도에서 V90−V110|
|---|---:|---:|---:|
|seed29 초기|21.05 / 15.33|+0.97km/h|−0.83km/h|
|seed43 초기|20.82 / 14.60|+0.94km/h|−1.48km/h|

두 경우 모두 예측 셀24에서는15개 표본 모두90의 목표속도가 높지만, 실제 재고를 사용하면4개뿐이다. 반대로 셀25는 양쪽 밀도에서 모두110 목표속도가 높다. 셀24와25를 같은 VSL 반응 오류라고 묶거나 전역 E 상향으로 처리할 근거가 부족하다. seed43의 셀16–23은 오히려 재고를 적게 예측하는 부분도 있어, 전체 밀도를 일률적으로 줄이는 방법도 맞지 않는다.

이 결과는 **FD 명령 반응만 다시 fitting하기 전에 자율 예측이 어떤 밀도 상태로 이동하는지 함께 검증해야 한다**는 근거다. 실측 재고를 주면 전체 제어 순위가 맞는다고 확인한 것은 아니다. 이전의 관측 상태 속도식 진단에서도 과도한 감속이 남았으므로, 단지 초기화나 상태 관측의 문제라고 좁히지도 않는다.

## 2. 기존 이득 모델과 전체망 모델의 차이를 재확인

본선 부분모델의 route036은 현재 차량의 목적지 경로 재고와 실제 native 미래 선택 확률을 보존하며, 물리 진출부 저장·배수로 방출을 제한한다. 그 모델은 seed29의750초 VSL 본선 ΔTTT를 약−3.04대·시간으로 예측한 기존 결과가 있다(실측30초 집계−3.57). 그러나 seed43에서는 실제 손해를 이득으로 예측한 기록도 있다. 이득을 전혀 못 보는 모델이라고 일반화하지 않는다.

이전9000의 c4ab 전체망 설정에는 이 목적지 재고 옵션이 없다. 이는 새로 발견한 소스 연결 누락이 아니라 **이미9월30일에 전체망 연결을 시험하고 기본 채택을 보류한 차이**다. `route_coupled_20260930/README.md`에서 seed43 실제 VSL Ω손해+0.777에 후보가−0.384를 예측했다. 해당 실패를 보존하고 같은 시험을 반복하지 않는다.

이번에는 새로운 onset2250 seed29 유지/해제 상태에서 기존 옵션만 켠 두450초 예측으로 범위를 한정했다. 원래 config와의 차이는 `freeway.offramp_route_inventory` 한 키다. 현재 관측된 목적지를 유지하고, 기존 전체망 진출부 수용·배수는 그대로 둔다. 부분모델의 경계와 전체망 경계까지 동일해졌다고 주장하지 않는다. 소스 물리식·계수·수요·writer·Ω 목적함수는 변경하지 않는다.

두 예측을 완료했다. 초기 동측1038대·서측670대의 목적지 분할이 실제 재고와 같고, 놓친 출구를 가진 초기 차량은 없었다. 두 방향의150/300/450초 셀 분할 최대잔차는2.14e−12대다. 기존 두 명령표와 초기 물리 상태가 정확히 같고8램프 보존도 통과했다.

|2250–2700초, 해제−유지|실제|기존 전체망|경로 재고 연결|
|---|---:|---:|---:|
|Ω ΔTTT [대·시간]|−1.25072|+0.01288|+0.03328|
|10481 이후 본선 통과 Δ [대]|+24|−5.170|−5.460|
|본선 말단 방출 Δ [대]|+19|+0.580|+0.215|
|2700초 동측 재고 Δ [대]|−21|+0.826|+1.267|

유지 조건 Ω TTT 자체는485.218→481.009로 실제465.518에 조금 가까워졌다.10481 이후 통과도660.16→694.22대로 실제715대에 가까워졌다. 그러나 **명령 변경에 따른 비용·방출 차이는 개선되지 않았다.** 절대 예측 개선을 제어 효과 검증으로 바꾸지 않고 후보 채택을 보류한다. 이번에도 내부 본선 수용 상한 clipping은0회다.

계수 그대로450초2회, 예측 계산48.158초/초기화·저장 포함63.267초, 최적화 iteration0이다. 실행14833은종료코드0, 남은 이 작업의 계산은 없다. `vsl_route_inventory_trace/{protocol,completion,comparison,assessment,results_location}.json`과 매초 계측을 보존했다.

따라서 이번 증거로 배제할 수 있는 설명은 ‘목적지 재고 옵션을 빠뜨린 것만 고치면 이번 VSL 방출 차이가 복원된다’다. 옵션의 일반적 무효를 증명한 것은 아니다. 이미 수행한 seed43 연결 시험,24·25 임계밀도 일괄 상향, E4 복원, 국소 이류 후보를 다시 탐색하지 않는다. 다음 수정의 근거는 동일한 물리 상태에서의 반응 불균형과 그 상태를 만들어내는 흐름이어야 하며, 작은 순이득 부호만을 맞추는 보정은 계속 제외한다.

## 검증·재현

- `assess_fd_regime.py`, `fd_regime_comparison/{summary.json,states.csv}`: 새 forecast0, fitting0. 기존 검증 장부의 native/예측 파일SHA12개 일치. 모든 셀의 관측 재고·물리 밀도 및 모델 재고·유효차로 밀도 관계 확인.
- 실제 실행 trace의 nominal FD에서 자유속도를 대수적으로 복원해 매초 값이 동일함을 확인했다(최대4.3e−14km/h). 재적합한 값이 아니다.
- 첫 진단은 CSV의 `rho_veh_per_km_lane`를 모델 상태 밀도로 취급한 가정에서 중단됐다. 이 필드는 물리 lane-km 기준이며 모델식에는 `rho_canonical`이 들어간다. 두 정의를 각각 재고/면적으로 확인하고 올바른 필드로 수정했다. 원문과 실패 로그는 남겼다.
- 변경한 진단 wrapper/assessor의 이전 실행 원문은 `vsl_response_trace/*_source_executed.py.txt`에 보존했다. 이전 계측 결과와 원래 raw-prefix 실패를 덮어쓰지 않았다.

새 VISSIM/FZP 스캔/실행 중인 CTG 조회/계수 보정/push는 없다. 새9000 실행이나 정본 채택을 이번 국소 진단으로 대신하지 않는다.
