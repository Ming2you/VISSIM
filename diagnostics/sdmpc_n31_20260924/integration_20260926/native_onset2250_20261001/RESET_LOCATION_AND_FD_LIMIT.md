# VSL 복귀 위치와 회복부 FD의 설명 한계

2026-10-01. 이전 턴은 완료 보고서의 재확인·요약으로 새 근거를 추가하지 않은 NO_PROGRESS였다. 이번 턴은 기존 실제 기록의 복귀 위치 검사, 동일 초기 상태 450초 예측 두 회, 저장된 국소 속도식 180개에 대한 FD 한계 계산을 완료한 PROGRESS다. 전체 목표는 ACTIVE / NOT_QUALIFIED다. 정본 물리식·계수·망·목적함수는 바꾸지 않았다.

## 1. 복귀 위치 근사는 있지만, 이번 반응 오차의 충분한 설명은 아니다

실제 DSD67–69는 동측 누적8090.751m, 셀25 안에 있다. 기존 모델은 다음 경계8320.100m에서110으로 복귀시킨다. 약229.35m 늦은 기존 명시적 근사이며, 새로 발견한 명령 연결 오류라고 부르지 않는다.

기존 seed29 초기/후기 차량 캐시만 재사용했다. 두 조건의 공통 초기 차량 중 같은 시각에 모두 실제 복귀 표지 뒤·셀25 안에 있던 표본에서는, 희망속도가 0.02km/h 이내로 같은 경우가 초기713/715, 후기969/969였다. 실제 복귀 표지와 셀26 경계 통과 사이의5초 표본 시각 차이는 중앙값10초였다(838/891개 차량). 정확한 이벤트 시각이나 독립적인 가속 이득을 측정한 값은 아니다.

위치 영향 시험은 **예측에서만** 복귀를 셀25 시작7827.314m로 앞당겼다. 실제보다263.44m 이르므로 정확한 위치 수정본이 아니다. 두 셀 경계 근사의 민감도를 보는 실험이며 실제 TTT가 두 결과 사이에 있다는 수학적 보장도 없다.

2250초의 물리 상태·과거 명령 cohort·도시/RM/VSL 명령표를 동일하게 유지했다. 이미 셀25 안에 있는 차량을 즉시110으로 바꾸지 않고, 이후 셀25로 들어오는 실제 허용 본선 유량만110으로 태깅했다. 원래110인 램프 차량, 차량 보존·수용량·FD 계수·동적 off-ramp는 그대로다. writer나 native sign을 이동하지 않았다.

## 2. 셀24는 임계밀도·FD 형상만으로 감속을 보상하기 어렵다

기존 `freeway_first/merge_population`의 seed67 RM 완화·VSL110 조건을 재사용했다. 현재 실측 본인·인접 상태와 해당5초 실제 합류량으로 이미 계산된 국소 식이다. 두 셀에 직접 합류는 없으며 다른 항을 고정했다. 미래 실측을 자율 예측에 넣은 결과가 아니다.

현재 식의 속도 변화를

`dv = (V_FD − v)/tau + convection + anticipation`

로 쓰면, 순간적인 평균속도 감소를 멈추는 데 필요한 목표는

`V_required = v − tau*(convection + anticipation)`

이다. 자유속도를 고정한 현재 지수형 FD는 양의 임계밀도·형상에서 항상 `V_FD <= v_free`이므로, `V_required > v_free`인 표본은 임계밀도/형상만 바꿔 그 국소 균형을 만들 수 없다.

|450초의90개5초 상태 평균|셀24|셀25|
|---|---:|---:|
|현재 실측 평균속도 [km/h]|74.11|92.68|
|현재 FD 목표 [km/h]|56.75|80.32|
|현재 FD 자유속도 [km/h]|108.16|108.16|
|영(0) 변화에 필요한 목표 [km/h]|127.18|104.25|
|필요 목표가 현재 자유속도를 넘는 표본|60/90|35/90|

셀24에서 FD 목표를 모든 표본에서 낙관적으로108.16까지 올려도 평균 모델 변화는−1.217km/h/초다. 관측된 다음5초 공간 평균 변화율은+0.023이다. 이는1초 연산자와5초 차분의 비교이며 개별 차량 가속도 오차로 해석하지 않는다. 시점별 상태 변동도 크므로 모든 표본에 같은127km/h가 필요하다는 뜻은 아니다.

**108.16은 현재 보정된 FD 상한이지 도로의 물리적 최고속도나 제한속도110 자체가 아니다.** 이 결과는 다른 항·상태·자유속도를 고정한 FD-only 설명 범위의 한계다. 모든 파라미터 조합이나 METANET 전체의 불가능 판정이 아니다. 자유속도를127 이상으로 올려 다른 항의 오류를 억지로 상쇄하는 계수도 선택하지 않았다.

## 3. 다음 작업에 적용할 판단

이미 기각한 임계밀도 상향·회복 anticipation 배율·이류 보조항을 새 후보처럼 다시 시험하지 않는다. 현재 결과는 복귀 위치와 FD 곡선 하나로 문제를 좁힐 근거가 부족하다는 뜻이다. 국소 평균 상태와 상류에서 들어오는 차량 집단의 속도 전달, 회복 반응이 함께 만드는 균형을 대상으로 해야 한다. 회복부 속도만 올려 상류 재고·실제 방출·RM 손익을 악화시키는 후보는 계속 제외한다.

기존 큰 RM 유지/완화 반응 검증과 seed29에서 VSL 이득을 일부 포착한 결과는 보존한다. 이번 국소 반응 실패를 모든 RM/VSL의 일반적인 무효로 확대하지 않는다. 아직 큰 제어 손익의 안정적인 구분과 SDMPC 연결을 통과한 새 모델이 없으므로 추가9000초 실행으로 검증을 대신하지 않았다.
