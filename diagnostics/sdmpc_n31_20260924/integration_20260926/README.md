## 기준망 선택 대기 및 완료 감사

선택 질문은 최초 목표 턴부터 세 목표 턴에 걸쳐 답변 대기다. 그동안 공통 실행기와 관측/VSL 이력/셀 연결 검증을 완료했다. 이제 다음 실질 단계인 물리 반응 보정·동일 조건 순이득 검증·full SDMPC 재생·새 native 실행은 기준망 선택에 의존한다. 어느 쪽으로든 자동 전환하지 않는다.

|목표|현재 증거와 남은 작업|
|---|---|
|1 기준 정합|두 망의 상세 차이/핀/물리 주소 감사 완료. 최종 선택 미완료|
|2 물리 반응 보정|공통 관측 이력과 합류 주소 수정 검증. 대상망 계수·자율 방출/회복 보정 미완료|
|3 순이득 및 독립 검증|기존 기각 결과 보존. 선택망의 NC/RM/VSL/both 및 독립 seed 이득 검증 미완료|
|4 SDMPC 연결|단위·기계적 미분·worker 연결 통과. 선택망의 실제 한 주기/연속 결정과 제약 검증 미완료|

유효한 기존 결과는 보존되어 있으며 새로 실행 중인 작업은 없다. 사용자 선택은 (A) 기존 이득 확인망 유지+최신 코드 연결, 또는 (B) 최신v3b로 이전+이득 재검증이다. A를 권장했으며 선택이 오면 선택망의 source/manifest/config를 먼저 일치시킨 뒤2단계부터 계속한다. 목표를 완료로 표시하지 않는다.
