# 미래 gate 이동·외부 대기·차로 수 — 2026-09-26

목표 ACTIVE. 이득 보정 **NOT_QUALIFIED**, 정본 설정 비활성. 이번에는150초 예측3개와
450초 고정 명령 예측1개를 완료했다. 초기화 실패2개는 별도로 보존했다.
VISSIM·최적화·새 seed·push는 실행하지 않았다.

## 변경한 정본 코드

`physical_ramp_branches.py`와 기존 `urban_flow_accounting.py`에 연결했다.
어댑터나 native 실행 경로를 복제하지 않았다. 수요·신호·미터·VSL 명령·계수·목적함수는 유지했다.

- `urban.ramp.native_gate_travel`: 앞서 검증한 초기 목적지 보존을 전제로1102의 미래 차량을 native1136의6:1:2 비율로 한 번만 분기한다.
- 같은468m/34초를 쓰던 입력 지연을 실제 connector 접속점까지의 목적지별 이동 시간으로 바꾼다. 현재 링크별 평균속도와 기존 속도 하한을 사용하며 지평 중 고정한다.
-1200초에서는10482까지1028.621m/158초,10490까지1330.644m/183초,도시 정지선까지261초다. 현재·과거 자료만 입력했다.
- 기존 `urban_inflow_transit_buffer`를 유일한 미래 주행 재고로 사용한다. 태그는 목적지 정보이며 차량 재고를 복제하지 않는다.
- 접근로의 기존 저장 재고·movement 큐·진입 후 이동 재고가 공간을 함께 쓴다. 못 들어간 수요는 별도 outside 대기 버퍼에 남고, 수요=삽입+미삽입 대기 및 삽입=도착+이동 재고를 검사한다.
- 외부 대기는 Ω TTT와 TTD에 포함하지 않는다. 입장 후에만 Ω 재고가 되며, 전체 비용 보고용 외부 재고는 보존한다. 초기 미삽입 대기량을 관측해 복원한 것은 아니므로 **이번 지평에서 새로 생긴 대기**의 장부다.
- `gate_entry_capacity_per_lane_veh_h=1800`을 명시한 별도 비교는 실제 차로 수를 곱한다.10482는3600,10490은1800대/h. 기존1차로 명목값을 사용했고 실제 처리량에 재적합하지 않았다. 미터의 녹색별 서비스 표와 본선 합류 수용량은 변경하지 않았다.

새 차량이10490에 너무 빨리 도착하던 오류는 제거됐다. 실제 새 차량 도착0대와 같지만,
전체 도착 오차는 여전히 크다. 앞선 새 차량의 과대예측이 초기 차량의 지연 오차를 상쇄하고 있었다.
10482에서는 새 차량 실제6대도 이번158초 고정 이동시간으로는 놓친다.

현재1136 경로가 확정된 차량의 ID를 실제 MER 진입과 대조했다.

-10490: 실제 초기 차량34대 중8대는 모델 준비 시각이1350초 뒤다. 나머지3대는 시작 때29·124에 있어 현재 gate 초기 저장소 밖이다.
-10482: 현재 경로가 확정된 실측 초기 차량78대 중11대를 늦게 예측한다. 반대로3대는 일찍 준비시키지만 실제 진입은 이 구간에 없다. 준비와 진입은 서로 다른 경계이므로 이3대를 무조건 잘못된 방출로 판정하지 않는다.
-예:10490행10171 차량은 현재21.79km/h를 남은1250m 전체에 고정해1407초 준비를 예측했지만 실제1m 검지기 통과는1333.14초다.
-32번 도로의 현재 속도는 위치·차로에 따라 다르다. 입구 부근은 대략15–26km/h, 끝부분은29–40km/h다. 초기 차량 속도를 남은 전체 경로에 고정하는 근사가 회복·가속을 놓친다. 실제 미래 속도를 예측 입력으로 사용하지 않았다.

## 450초 연결 확인

1200초에서 직전 실제1050초 명령을 유지한 **단일 예측**을 끝냈다. 도시 명령도 유지했다.
앞의150초 비교는 실제1200초 명령이므로 두 예측의 TTT를 제어 효과로 비교하지 않는다.

-지평 중 희망·삽입449.8875대, 목적지 큐 도착274.93125대, 나머지174.95625대는 이동 중이다. 이 조건에서 새 outside 대기는0대다.
-8개 램프 보존 잔차 최대4.41e−13대. 원 초기 상태는 후보 계산 중 변하지 않았다.
-예측 Ω TTT427.4858veh·h, 기존 모델 전체의 outside 체류199.7899veh·h. 후자는 새 gate 대기가 아니라 주로 기존 다른 outside 재고이므로 이번 기능의 효과로 돌리지 않는다.
-계산21.30초는450초 예측1회 시간이다. SDMPC 최적화 iteration=0, 후보 수락·수렴 및 실제450초 이득 검증이 아니다.
