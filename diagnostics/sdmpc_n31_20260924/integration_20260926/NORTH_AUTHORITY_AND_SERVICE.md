# 10625 비신호 연결과 과거 서비스 관측 — 2026-09-26

목표 ACTIVE. 물리 이득은 NOT_QUALIFIED이며 새 VISSIM·9000초·push는 없다.
이번에는 정본의 신호 연결 코드 한 곳을 수정하고, 같은 1200초 기록에서 두 개의 150초 예측을 완료했다.
누적 완료 오프라인 예측 조건은 39개다. 기존 결과와 선택망의 생산 config는 유지했다.

## 206.53대/h의 출처

`install_movement_capacity_by_lanes`의 내부 movement 184개 × 평균 330대/h를
차로 가중치 합 294로 나눈 값이 206.530612대/h다. 10625에 대응하는
`SC1004_N_SC1003_to_W`는 perimeter 차로 자료에 없어서 같은 회전의 대표 차로 수로 채워졌다.
이 값은 10625에서 측정한 포화 교통류율이 아니다. runtime 메타데이터와 설치 순서를 확인했다.

기존 R3 seed29 FZP를 1200초까지만 읽었다. 실제 마지막 표본은 1195.1초이며
1350초의 미래 결과는 예측에 사용하지 않았다. source46→10625 직접 전이 또는
source46→68의 유일한 직접 연결을 통과한 차량만 센 보수적인 하한은 다음과 같다.

|관측 구간|확실한 통과 차량|150초 전체로 나눈 달성 유량 하한|
|---|---:|---:|
|750–900초|10|240대/h|
|900–1050초|15|360대/h|
|1050–1200초|10|240대/h|

5초 표본 사이에서 connector가 생략된 사례는 이전 표본의 native NEXTLINK가
10625였는지도 추가 확인했다. 생략 전이 15개 모두 일치했다. 창 경계에 걸친 사건이나
source를 보지 못한 사건은 확정 계수에 더하지 않았다. 원본 크기·mtime·읽은 prefix SHA를 남겼다.
용량 식별이 아니라 기존 206.53 상한보다 실제 통과한 유량이 높았다는 증거다.

근거: `north_past_crossings1200.json`, `north_past_crossings1200_verified.json`.
후자는 기존 prefix를 재검사하여 NEXTLINK 증거를 덧붙인 별도 파일이다.
예측에 사용한 원래 증거 파일은 당시 SHA와 정확히 같게 보존했다.

## 정본 신호 연결 수정

46번 도로의 10625 분기는 949.208m이고 같은 차로 SG4 head는 953.160m다.
모든 source head가 분기 뒤에 있으며 10625·68에는 head가 없다. native1125:1 경로도 확인했다.

기존 `physical_movement_routes.configure_phase_authority`에서 검토한 이 분기를
추가로 받을 수 있게 했다. 망·신호 계획 hash, 연결 위치/차로, 모든 source head,
연결로/도착 링크의 head 부재, native 경로 및 예상 movement 의미가 모두 맞아야 적용한다.
정본의 `unsignalized=True`를 초기화 전에 설정하고 topology cache를 무효화한다.
현시 이름, beta, 수용 공간, 서비스 용량과 현재 차량 재고는 유지한다.
증거는 `physical_phase_authority_10625.json`; 아직 선택 생산 config에는 승격하지 않았다.

직전 `--north-bypass-only` 진단은 초기화 뒤 현시 문자열만 비운 시험이었다.
빈 현시는 기존 monitor 신호 처리로 넘어갈 수 있고 movement cache도 이미 만들어져 있다.
따라서 그 결과를 **신호 제약을 완전히 제거한 정본 예측으로 해석하면 안 된다**.
이번에는 기존 비신호 처리와 초기화 순서를 사용했다.

## 검사와 한계

- 선택망 연결 검사 4개, 세부 사례9개 통과 (`north_authority_final.log/xml`).
  같은 SG의 직진은 적색에 계속 제한되고, 비신호 분기만 허용된다.
  잘못된 위치·경로·head·수용 링크를 거절하고, 실패 전후 상태 불변과 기존 캐시 갱신도 확인했다.

  이를 통과나 skip으로 바꾸지 않았다 (`north_authority_tests.log/xml`). 선택망 검사와 구분한다.
- 과거 하한 예측의 첫 시도는 Windows261자 경로에서 실패했다.
  결과 폴더 이름만 줄여 실행했고 원래 로그/폴더를 보존했다 (`north_pastfloor1200_path_failure.log`).
- 모든 계산은 종료됐다. 차량 보존과 소규모 연결 검사는 전체 AD·SDMPC 선택·native 검증을 대체하지 않는다.
