# Gate 결합 후보의 SDMPC 선택·실행 모델 검증

2026-09-29. seed47의 실제2700초 저장 상태에서 기존 SDMPC 한 주기를 완료했다. **도시 녹색·offset 변경은 선택했지만, 8개 RM과 VSL은450초의3블록 모두 직전 실제 명령을 유지했다.** 현재 상태에서 RM은 이미 일부 제한 중이다. ‘RM이 꺼짐’ 또는 ‘metering은 무효’라는 뜻이 아니다.

## 선택과 실행 모델의 일치

|Ω TTT [대·시간]|직전 명령 유지|선택|선택−유지|
|---|---:|---:|---:|
|최적화 근사 모델|497.488728|487.218783|−10.269945|
|정본 실행 모델|497.546094|487.259970|−10.286124|
|실행 모델+추적된 외부 재고|727.760628|725.904028|−1.856600|

모두 예측이다. 외부 항은 모델에 포함된 도로·이동 중 재고이며 native 전체 미삽입 비용을 포함한 값이 아니다. 기존 SC109 후보의 완료 native 결과와 이번 gate 결합 후보를 혼합하지 않는다. 이번 선택의 native 실행은 아직 없다.

실행 모델의 도시만 변경 결과는 선택 전체와 정확히 같다. RM만 변경한 비교는 명령 자체가 유지 명령과 같아 ΔTTT=0이다.8개 RM 녹색은 `[10,10,10,10,2,9,5,2]`초(10480,10482,10646,10644,10639,10681,10490,10484 순), VSL은110km/h다. 이 결과를 ‘새 RM 이득0’ 이상의 일반론으로 확대하지 않는다.

## 제약과 계산 범위

- 실제 SDMPC 호출 전체360.874초. PFO 최대2회/실행2회/수락2회, SDMPC 최대2회/실행2회/수락2회, 두 단계 모두 반복 상한에 도달했으며 **미수렴**이다. Nash 해로 판정하지 않는다.
- 최적화 내부 근사예측33회(일반26+자동미분7).237개 좌표의 도함수를 계산했으나 이 사실만으로 독립 미분 검증을 통과했다고 하지 않는다.
- 별도 정본 실행 모델의 유지/선택2회와 요소분해3회에서 writer·150초 블록 변경폭·8램프 보존·물리 자원 및 N_P/N_UF 제약을 확인했다. 선택의 N_P417.911≤528.722대, N_UF5895.260≤6043.727대/h. 수용 자원 최대 초과8.89e−16대이며 검사 누락0이다.
- 유효 config의 정본 파라미터 검사 PASS. 기존 calibration/parameter 우선순위 경고는 기록된 기존 경고이며 새 후보에서 묵시적으로 계수를 바꾸지 않았다.

## VSL을 선택하지 않은 이유의 제한된 확인

선택된 도시·RM과 현 주기 PFO 예산을 고정하고, 램프 사이 구간 `FW_E__seg13`의110 유지/100/90km/h를 각각450초 평가했다. 기존 허용집합·변경폭·진입부110은 유지했다.

|선택된110 대비|근사모델 ΔΩTTT|실행모델 ΔΩTTT|NP/NUF·물리 제약|
|---|---:|---:|---|
|100km/h|+0.060094|+0.059113|통과|
|90km/h|+0.325095|+0.322931|통과|

두 후보에서는 제약에 막힌 것도, 근사 모델만 이득을 놓친 것도 아니다. **현재 모델이 해당 VSL 제한을 손해로 평가한다.** 이 작은 차이가 실제 VISSIM 손해와 일치한다는 증거는 없으며, 다른 구간·명령 조합 전체의 최적성을 증명하지 않는다. 이 결과만으로 새 VSL 계수를 다시 탐색하지 않는다.

이번 선택 후 검증은 정본450초8회(선택검사2+요소분해3+VSL후보3), 추가 근사6회이며 optimizer 재실행0, 새 native0이다. 앞선 기하/이동시간12회와 구분한다.

## 다른 저장 상태의 미분 검사 — 일부 차분 불일치 유지

seed29 4500초의 기존 실제 상태·과거 관측·직전 명령을 사용했다. 기존 계획 그대로10484 g8/6/4의 실행 가능한 기준점에서 RM 세 번째블록, VSL13 첫블록의 두 열만 비교했다. AD1회+독립 일반9회,100.85초이며 최적화0회·native0회다.

- 기준점 owner/passive 비용 최대 차이1.42e−14대·시간, N_P/N_UF 차이0. 초기 응답은 일치한다.
- RM의±0.001/±0.0005초 차분은 둘 다 통과한다. 정규화 좌표 Ω 미분은 AD0.000272938로 독립 차분과 일치한다.
- VSL±0.005km/h는 비용·자원 미분 모두 통과한다(Ω AD−1.793853510 / 차분−1.793853517). **±0.01km/h는 실패**한다(Ω 차분−1.806754774, 최대 owner비용 미분차0.06119, 자원 미분차6.83353). 큰 폭 차분의 좌·우 N_UF 기울기는6.7863/20.4533으로 다르다.

이전 셀23 후보에서는 두 차분 폭 모두 통과했다. 이번 기하·이동시간 결합 상태에서 이산 이동 사건 또는 활성 제약이 작은 구간 안에서 바뀌었을 가능성이 있지만, 이 검사만으로 특정 사건을 원인으로 확정하지 않는다. **원본 `all_checked_gradients_match=false`를 유지했다.** 작은 폭이 통과했다는 이유로 전체 미분 인증을 부여하지 않는다. 반대로 이 작은 진단 불일치를 이유로 물리 계수를 다시 무한 탐색하지 않는다. 실제10km/h 후보를 직접 평가한 위 유한 응답 검증과 구분한다.

현재 모든 소유 오프라인 계산은 종료됐다. 이번 두 열 검사는 전체 궤적·모든 열의 미분 검증, 독립 seed의 실제 제어 이득 검증을 대체하지 않는다.
