# 제어 반응과 본선 유입 실현 차이 분리 — 2026-09-29

**seed43의 RM 비용차 오차를 전부 METANET의 합류·회복 오차로 보고 맞추면 안 된다.** 제어 이후 실제 본선 유입량이 조건마다 달랐고, 이 유입량만 바꾼 조건부 예측에서 비용차의 상당 부분이 설명됐다. 반면 독립된 seed47의 큰 RM 완화에서는 미래 자료 없이도 합류 증가와 비용 악화 방향을 예측했다. 이번 단계는 물리 계수 보정을 하지 않았다.

## 실제 유입과 TTT

선택된 동일 망, seed43,2250초 공통 상태,450초의 고정 명령4조건이다. 아래 Δ는 각 조건−무제어이며 Ω TTT 단위는 대·시간이다.

|---|---:|---:|---:|---:|---:|
|NC|916|0|0|0|0|
|RM|901|−1.547|−0.016|−0.016|−1.431|
|VSL|955|+0.777|+0.202|+0.202|+1.142|
|RM+VSL|911|−1.453|+0.189|+0.188|−0.690|

같은 seed·입력 설정·제어 이전 이력이 **제어 이후의 동일한 실현 유입**을 보장하지 않았다는 것이 이번 자료에서 확인됐다. 이것을 모두 난수 때문이라고 확정하지 않는다. 확률적 생성과 실제 삽입 가능성의 변화가 각각 얼마나 작용했는지는 아직 분리하지 않았다. 제어로 삽입량 자체가 달라졌다면 그것도 교통 반응의 일부다.

모든 조건에 NC의 미래 유입을 동일하게 넣으면 원래 제어 비용차가 거의 유지된다. 조건별 미래 유입을 넣었을 때만 RM 예측이−1.431로 변했다. 따라서 단순히 baseline 유입 수준을 보정한 효과와, 조건별 실현 유입 차이의 효과를 구분했다. **이 수치는 모델 안에서의 입력 민감도이며 VISSIM 제어 효과의 인과적 기여율이 아니다.** 병용은 여전히−0.764대·시간의 차이가 남는다. 다른 입력·램프 도착·경로·본선 반응까지 모두 설명했다고 주장하지 않는다.

## 공간상 단서

기존30초 셀 재고를 적분한 동측 본선 TTT에서 RM의 변화는−1.279대·시간이다. 이 중 첫 램프 이전 셀0–7은−0.767, 합류·회복 셀21–25는 오히려+0.571이다. VSL의 동측 변화+1.096 중 셀0–7은+0.812다 (`native_location.json`).

이것은 이 상태의 이득을 전부 셀23–25 회복 개선으로 설명할 수 없다는 단서다.30초 성분 적분과5초 Ω 적분을 섞어 잔차를 정확한 도시부 비용이라고 부르지 않는다. 인근 셀의 평균속도 또는 재고 차이만으로 특정 동역학 항의 원인을 확정하지 않는다.

## 구현·검증 범위

- 기존 `probe_selected_arrival_path.py`에 명시적 `--diagnostic-sources`만 추가했다. 현재2250초 고정4조건의 원인 분리 모드로 제한하며 optimizer/선택·native 준비와 조합하면 거부한다. 실제 controller, adapter,물리 계수,실행망은 이 단계에서 변경하지 않았다.
- 일반 경로는 과거 관측만 사용한다. 조건부8회는 `future_observation_inputs=true`, `autonomous_prediction=false`로 저장한다. 결과를 controller의 예측 성능이나 계수 적합 자료로 승격하지 않는다.
- FW_E의150초 평균 본선 유입만 바꿨다. 도시·램프·서측 수요 예측,초기 상태,제어 명령,차량 보존과수용 제약은 유지했다.8회 모두 실제 모델 진입이 공급한 관측 합계와 일치하고 원점 잔여 큐는0이었다. 두 모드의 NC 비시간 출력은 정확히 일치했다.
- 별도의 입력 복사·미래 자료 표시·잘못된 계약 거부7검사 통과. 초기 시도는 인자 검사 순서 오류로 예측 전에 실패했고 `common.log`에 보존했다. 수정 후 조건부8회·일반 RM2회 완료. FZP 재스캔과 새 VISSIM 실행은0회다.
- 실제 최신 SDMPC 선택은 이 조건부 모드와 분리해 일반 입력으로 실행한다. 결과는 `selection_review.json` 및 후속 보고에 정리한다.

## 실제 SDMPC 한 주기 선택 완료

동일 seed47 상태에서 미래 관측 없이 실제 solver를 실행했다. PFO 이후 고정된 상한은 N_P506.53대,N_UF5890.36대/h이며, 이번 최신 SDMPC 설정은 등식 띠가 아닌 **상한 제약**이다.2회 반복에서2개 개선 단계를 수락했다. 총363.4초,AD6회·scalar26회다. 실행 가능한 후보를 찾았으나 반복 한도로 종료돼 수렴이나 Nash 해를 주장하지 않는다.

- 선택은 도시 green/offset 변경과 **첫150초 FW_E 셀13·14의 VSL110→100**이다. 이후 두 블록은110을 유지하고8개 미터는 세 블록 모두 실제 직전 명령을 유지한다.
- 근사 모델의 Ω 개선 예측9.753대·시간을 정본 실행 모델의 두450초 재계산으로 확인했다. 실제 선택 명령의 정본 예측은 **9.738 감소**,추적 외부 재고까지 포함하면 **1.441 감소**다. 이는 모델 결과이며 이 새 명령의 native 이득은 아직 없다. VSL 단독 기여도 아직 분리하지 않았다.
- 선택 모델의 N_P410.13,N_UF5735.36으로 두 상한을 만족한다. 정본 실행 모델의 N_UF는5731.40으로 상한 안이다. 이 두 정본 재계산에서 N_P는 별도 저장하지 않았으므로 그것까지 독립적으로 재확인했다고 표현하지 않는다.
- 물리 제어 파일213행과 평가한 명령의 결합 검사가 통과했다. 적용 가능한첫 블록만 writer에 기록됐으며 native 실행 증명은 아니다.
- 앞선 도시 명령을 고정한 큰 RM 완화는 비용도+0.473 나쁘고 N_UF6099.25로 이번 상한을208.89대/h 초과한다. 따라서 이 강한 후보를 안 골랐다는 것만으로 탐색 실패라고 할 수 없다.
- 다만 RM10484의 **첫 블록 국소 미분은 완화에 유리한 방향**이고, 뒤 블록은 불리한 방향이다. 모든 허용 이산 이웃은 검사하지 않았다. 큰3블록 완화의 손해와 첫 블록만1~2초 완화의 손익은 다르다. 다음에는 선택된 도시/VSL과 상한을 고정해 이 작은 이웃을 직접 평가한다.
