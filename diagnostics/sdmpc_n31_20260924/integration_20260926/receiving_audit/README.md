# 합류 수용량 계측 — 2026-09-27

기존2670.1초 공통 상태의 유지/미터 해제 두450초 예측만 계측했다. 계수·물리식·수요·명령 변경 없음. 각 예측의 cells/flows/ports/ramps는 기존 자료와 정확히 일치했다. 1초 계측으로 복원한 본선 유입과 램프 합류 적분도 원래30초 유량 장부와1e-7대 이내 일치했다.

네 합류 셀 모두 두 조건에서 저장공간 수용 제약은450회 중0회 걸렸다. 기존 배분은 먼저 수용된 램프 합류량을 저장 여유에서 빼고 본선에 잔여를 배정하므로 같은 저장공간을 두 번 사용한 오류는 아니다. 하지만 이 상태에서 지속 가능한 공통 처리 유량 상한이 활성화되어 있는 것도 아니다. 램프별 서비스·gap acceptance와 METANET 속도 피드백은 별도로 작동한다.

단위는 대/h,450초 평균이다. 합산 유입은 해당 셀의 상류 본선 통과+실제 램프 합류다. FD 최대값은 기존 셀별 v_free·rho_crit·shape와 차로수의 평형값이며, 비평형 상태의 실제 유량 상한으로 검증된 값이 아니다. 현재 METANET은 q=rho*v*lanes이므로 일시적으로 평형 FD 최대값을 넘을 수 있다. 따라서 이 표만으로 FD 오류를 확정하지 않으며, 이 값을 새 hard cap으로 바로 사용하는 것도 거절한다. 특히10681에서는 실제 통과량부터 그 상한을 넘는다.

10484에서는 실제 미터 해제 후 본선 진입872→754대, 합류45→89대인데 모델은815.05→804.22대,45.31→93.16대다. 모델은 추가 합류를 표현하지만 본선 통과 감소는 작게 표현한다. 공통 용량을 임의로 낮추어 이 부호를 맞추지 않는다. 유효한 포화 상태의 용량 근거 없이 새로운 receiving/capacity-drop 식을 승격하지 않았다.

별도의 `../lane_drop_response/summary.json`에서는 물리4→3차로수는 유지하고 추가 감속 phi3만0으로 한 후보를 평가했다(기본 일치 확인2회+개발16명령). 네 상태의 선택이 모두 기존과 같아 채택하지 않았다. 차량 보존 잔차는 검사했지만 이 기각 후보를 독립 검증·native 이득 증거로 사용하지 않는다.
