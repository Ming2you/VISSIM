# VSL 노출 전달 시차와 방출 반응 분리

2026-10-01 완료. 이전 목표 턴은 자료 반영 범위 설명으로 NO_PROGRESS, 이번 턴은 기존 예측의 정확 재실행2회와 조건부 원인 분리4회로 PROGRESS다. 전체 목표는 ACTIVE / NOT_QUALIFIED다.

## 판단

VSL 적용 차량의 전달이 모델에서 늦어지는 부분은 있지만, 그 차이를 실측에 가깝게 바꾸는 것만으로 셀16–20의 방출 반응 오류가 해결되지 않았다. VSL 노출의 전달 속도나 복원 표지판 위치를 다시 계수 탐색하는 것을 다음 우선순위로 두지 않는다. 이번 자료로 METANET의 특정 항이 원인이라고 확정한 것도 아니다.

기존 route036 component의 seed29/43 공통2220.1초 초기 상태,2250초 VSL90 개입을 사용했다. 미래 관측 없이450초 예측2회를 실행하며 passive command cohort만 관측했다. 두 실행 모두 저장된750초 예측의 첫450초 cells/flows/ports/ramps와 정확히 같았다. 현재 full SDMPC의 새로운 선택이나 검증이 아니라, 이미 동결한 본선 component의 내부 원인 분리다.

## 노출 차량 비율 확인

새 FZP 읽기 없이 기존5초 차량 위치 캐시를 사용했다. 초기/신규 원점/램프 차량은110,6341.743m 표지판 통과 뒤90,8090.751m 복원 표지판 통과 뒤110으로 추적했다. 실제 표지판은 셀16 내부에 있으며, 셀25 내부 복원을 모델이 셀26 경계로 근사하는 것은 기존에 알려진 차이다. 셀16–20의 이전 표본 없이 새로 나타난 차량은 두 seed 모두0대였다.

이 태그는 명령 분포를 가리키며 차량의 DESSPEED 숫자를90과 직접 비교한 분류가 아니다. seed29의 독립 DESSPEED 캐시에서 초기 전환시각이 불확실한 사건을 제외한807회 활성 표지판 통과 중785회는 같은 표본에 희망속도가 달라졌다.20회는 다음5초 표본에 달라졌고, 마지막2회는 다음 표본이 없어 미확인이다. 따라서 첫 위치 통과 표본부터 모두 새 명령이라고 단정하지 않고, 조건부 시험에서는 그 표본의 이전/신규 명령 가능성을 모두 허용했다.2250초 활성화 시각을 걸친 통과도 불확실하게 남겼다. seed43은 위치로 추론한 노출이며 DESSPEED를 새로 읽지 않았다.

## 미래 노출만 교체한 조건부 시험

새 예측4회 한도로 seed29/43 각각 노출 비율 하한/상한 경로를 사용했다. 현재 예측 밀도에서 기존110/90 FD 목표속도를 계산하고, 그 둘을 해당 비율로 섞는 부분만 바꿨다. N/v/유량·합류·수용·도시 배수는 실측 미래로 교체하지 않았다. 기존 source/ramp 수요 전망, 실제 수용 계산, 차량 보존, 램프 대기, 동적 off-ramp 저장·배수는 유지했다. 물리적 차량·명령 cohort의 보존식은 그대로 실행했다.

**미래 노출 자료를 넣었으므로 자율 예측도, 채택 가능한 제어 모델도 아니다.** 5초 노출 비율 사이를 선형 보간한 원인 분리다. 비율의 두 경계 경로를 각각 평가했으며, 비선형 예측 결과 전체의 수학적 상하한이라는 뜻은 아니다. 결과 파일에도 future_observation_inputs=true, autonomous_prediction=false를 명시했다.

비교 창은 이전 source 검사에서 정한 입구 유입 동일 구간 그대로다:29는2220.1–2640.1(420초),43은2220.1–2490.1(270초). 이번 비용 결과를 보고 창을 다시 선택하지 않았다. VSL−NC의 차이이며, 통과량은 해당 셀의 하류 본선 통과량이다.
