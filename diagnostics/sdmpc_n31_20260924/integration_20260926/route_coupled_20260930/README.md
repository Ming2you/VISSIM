# 전체 망 목적지 재고 연결: 후보 검증

2026-09-30. expanded036 계수는 그대로 두고, 기존 목적지별 재고를 전체 망의 두 방향 고속도로에 연결했다. SDMPC 후보별 상태의 같은 차량을 분할하며 새 차량 재고를 추가하지 않는다. 진출부 수용·이동·배수와 본선 유입 예측은 기존 runtime이 담당한다.

8개450초 예측(후보4+비활성 회귀4), 초기화2회, 관련 시험9개를 완료했다. 새 계수 보정·VISSIM·FZP 스캔은 없다. 기존 무제어/RM/VSL/결합 명령과 seed43@2250 상태를 재사용했다. 이미 검토한 상태이며 독립 검증은 아니다.
