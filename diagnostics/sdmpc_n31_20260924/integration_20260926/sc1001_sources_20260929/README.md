## 확인한 원인과 수정

- 실제 `29 → 10119 → 31`은 29의 2·3차로와 SC1001 SG6의 두 헤드를 사용한다. 기존 plant 서비스 상한은 **413.06대/h**여서 450초 중 녹색135초에 정확히 **15.49대**만 방출했다. 실측은37대였다.
- 같은 모델 현시에 들어 있는 우회전 `29 → 10122 → 38`은 1차로의 별도 이동이다. native route1118:3, connector 차로 범위, 목적 링크의 기존 권역 매핑을 검증해10119의 관측을 이 이동에 중복 배분하지 않는다. 해당 우회전의 기존 동역학은 바꾸지 않았다.
- 이미 사용 중인 **과거4구간의 녹색 방출 관측 하한**을10119에 연결했다. seed43에서는1000대/h, seed47에서는1080대/h가 적용됐다. 미래 방출량으로 맞춘 상수나 새로운 포화율은 없다.
- MER 검지 차량과 완료된 FZP의 connector 진입을 ID로 대조했다. 과거49대와 후속37대 **총86대 모두10119 진입을 확인**했다. 미래37대는 원인 검증에만 사용하고 예측 입력으로 쓰지 않았다 (`native_join_checks.json`).
