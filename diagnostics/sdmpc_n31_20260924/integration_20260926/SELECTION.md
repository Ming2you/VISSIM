## 최신 코드에 연결하며 재현·수정한 문제

1. 31셀의 anticipation 보정 인덱스를 분할 이전 21셀에 검증해 `Invalid response cell index: 21`로 종료했다. 물리 분할 뒤 검증하도록 기존 수정 사항을 옮겼다.
2. 기존 `physical_cell_fd`를 최신 구성요소 코드가 적용하지 않았다. 명시된 셀에만 FD를 적용하며, 잘못된 인덱스/계수는 거부한다. FD·VSL·램프 보정 선언을 실제로 설치했는지 검사한다.
3. 램프 녹색별 실측 방출표가 구성요소의 고정 명령 예측에서도 쓰이도록 연결했다. RED는 방출0을 유지하고 명령 자체는 바꾸지 않는다. 이 연결은 방출표의 모든 상황 정확도를 입증한 것이 아니다.
4. 실제 기록 상태 초기화가 다른 PC의 SIG 경로에서 실패했다. 선택한 INPX가 지정한 SIG를 읽어 17개 신호의 활성 프로그램·현시·녹색·오프셋이 기존 명세와 같은지 확인한다. 실제 로딩한 망의 SIG SHA도 대조한다. 원본 신호 계획과 SIG는 수정하지 않았다.
