# 혼잡 형성·회복 이력만으로 방출 보정항을 추가할 수 있는가

2026-10-01 완료. 이전 목표 턴은 VSL 노출 진단으로 PROGRESS, 이번 턴도 기존 자료에서 새로운 상태 대응·보존식 검사를 완료해 PROGRESS다. 전체 목표는 ACTIVE / NOT_QUALIFIED다.

결론: **과거60초 밀도 감소를 회복으로 분류하고 방출능력·가속도 보너스를 주는 보정은 이번 자료로 정당화되지 않는다.** 밀도만 같게 보면 속도 차이가 나타나지만, METANET이 이미 가진 현재 속도·하류 상태를 함께 맞추면 일부 차이는 사라진다. 남는 방출 차이에는 이후 유입 차이가 크게 동반된다. 이는 모든 이력 효과가 없거나 특정 셀 보정이 불필요하다는 결론은 아니다.

## 자료·방법

원래 기준 실험의 seed29/43 무제어 캐시를 사용했다. 동측0기준 셀16–25,300.1–8850.1초,30초 상태 기록이다. 제어 정책에 따른 효과를 학습한 것이 아니다. 각 시각의 지난60초 밀도 변화가+2veh/km/lane 이상이면 형성,−2 이하이면 감소로 분류했다. 이 명칭은 밀도 추세 라벨이며 지속적인 실제 혼잡 회복을 판정한 것은 아니다.

같은 seed·같은 셀에서 두 상태를120초 이상 떨어지게 짝지었다. 세 방법은 밀도만, 밀도+현재 속도, 여기에 하류 밀도/속도·과거 유입/합류·off-ramp 재고까지 맞추는 방법이다. 허용 차이와 최소12쌍/seed/셀 기준은 결과를 보기 전에 protocol.json에 고정했다. 현재 상태 차이가 작은 순서로 선택했고, 미래 결과로 짝을 고르지 않았다. 방법별로 표본을 중복 사용하지 않았지만 서로 다른 방법 사이에는 같은 관측이 사용될 수 있다. 시간적 상관도 있으므로2582쌍을 독립 실험2582회로 해석하지 않는다.

N<5, 속도 누락, 과거/미래 균형 창의 미확인 유입·소실·삭제 또는 보존 잔차가 있는 상태는 제외했다. 남은 상태는29에서2191개,43에서2163개다. 미래60초의 실제 총방출(본선 통과+off 진출+말단)을 결과 변수로 사용했다. 미래 자료는 결과 분석에만 사용했으며 어떤 예측기에도 입력하지 않았다.

## 결과

밀도만 맞춘 전체 대응쌍에서 밀도 감소 쪽의 현재 속도는29에서 평균4.3km/h,43에서5.4km/h 더 느렸다. 그러나 다음60초 방출은 오히려 각각238.4,224.2veh/h 더 많았다. 정적 FD 그림에서 보이는 낮은 속도를 그대로 지속되는 방출 상한 감소로 바꾸면 서로 다른 시점의 관계를 혼동할 수 있다.

현재 속도·하류 상태 등까지 맞춘 결과를 아래에 보인다. 수치는 **밀도 감소 상태−증가 상태**, 방출과 유입은 모두 다음60초 평균veh/h다. `재고 변화 기여`는 보존식의 음의 재고 증가율 차이로, 독립적인 인과 기여도가 아니다.

셀24는 현재 속도·주변 상태를 맞춘 뒤 일관된 별도 방출 차이가 거의 남지 않았다. 이것은 현재 METANET이 셀24를 정확히 예측한다는 뜻이 아니다. 기존 모델의 현재 상태 자체가 느리게 예측되는 오류와, 같은 상태에서 추가적인 이력별 용량이 필요한지는 다른 문제다.

셀16·17에 남는 높은 미래 방출에는 더 높은 미래 유입이 동반된다. 예를 들어43·17의+1121.54는 유입+1283.08와 재고 증가 차이−161.54의 합으로 정확히 닫힌다. 단순 회복 가속의 증거로 사용할 수 없다. 이 대응쌍의 밀도 감소 쪽이 이후60초 속도를 더 많이 회복한 것도 아니었다: 셀16·17의 속도 변화 차이는 두 seed에서−0.90∼−3.43km/h다. 과거60초 추세 라벨만으로 다음60초의 회복 상태를 식별하지 못한다.

합류 셀21은 충분히 비슷한 상태가29에서1쌍,43에서2쌍뿐이었다. 셀20·22·23도 한쪽 seed에서 최소12쌍 기준에 못 미쳤다. 이 구간들의 이력 계수를 추정할 근거로 승격하지 않는다. 본선 상류 정지차량 존재와 하류속도60km/h 이상을 동시에 만족하는 대응쌍도 엄격한 상태 비교에서 전체356쌍 중1쌍뿐이었다. 이 자료를 공급·수용이 통제된 병목 용량 측정이라고 부를 수 없다.

## 모델에 반영한 판단

- 새 capacity-drop 배율이나 밀도 감소에 따른 회복 보너스를 추가하지 않았다. 이 관측 분석은 그 구조를 지지하기에 부족하다.
- 현재 N/v, 상·하류 파동, 실제 합류·유입과 off-ramp 저장·배수를 구분하는 기존 보정 기준을 유지한다. 현재 속도를 빼고 정적 밀도 관계만 맞추는 방향으로 단순화하지 않는다.
- 원래 ALINEA/RM/VSL 네 조건의 이득과 SDMPC 선택 검증을 대체하지 않는다. 이번 결과는 NC 자료의 상태 식별 한계를 좁힌 것이며 자율 예측·제어 이득 검증이 아니다.
- 같은 과거60초 밀도 부호에 가속 보너스를 붙이거나, 동일 자료의 추세 창·허용폭을 반복 탐색하지 않는다. 남은 물리 반응 검증과 실행 가능한 제어 경로의 비교가 필요하다.

## 검증과 보존

캐시 geometry.json은 옛 기준 파일 해시401b6558을 갖고 있어 선택망 해시64cf5f55와의 단순 동일성 검사에서 한 번 중단됐다. 메타데이터를 고치지 않았다. 선택망 원본SHA를 확인하고, 두 seed 캐시의31셀 경계가 선택망 compiled 자료와 정확히 같은지,8개 램프 귀속 셀과 진출 연결 셀·위치가 같은지 대조했다.29 캐시 자체 manifest의 파일SHA와 두 NC 원본 FZP 출처를 확인했다. 이는 물리 관측 투영의 정합이며 서로 다른 .inpx 파일의 바이트 동일성 주장이 아니다.
