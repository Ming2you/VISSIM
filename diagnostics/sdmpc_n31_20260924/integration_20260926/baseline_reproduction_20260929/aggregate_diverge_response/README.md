# 집계 METANET의 진출 분기 밀도 연결 시험

2026-09-29. **12개450초 제어 예측 + 기본설정450초 재현1회 완료. 계수 적합0, 새 VISSIM0, push0. 정본 채택 없음.**

## 확인한 연결 차이

현재 정본 집계 경로 `area_freeway_accounting._freeway_substep_events`는 진출부의 anticipation에도 다음 본선 셀 밀도만 사용한다.
다중 출구의 METANET 가상 하류 밀도 함수 `junction_downstream_density`는 존재하지만, 차로 그룹 경로에서만 사용하고 있었다.
현재 선택망 예측은 차로 그룹을 사용하지 않으므로 이 함수가 진출 압력에 적용되지 않는다. 동적 off-ramp 저장·배수·spillback 자체가 빠졌다는 뜻은 아니다.

[Hegyi 학위논문 §3.2, 식(3.9)](https://www.hegyi.info/thesis/dep_hegyi_20040203.pdf)의 가상 출구 밀도는 다음과 같다.

`rho_virtual = sum(rho_outlet**2) / sum(rho_outlet)`

검색 색인의 해당 원문 수식은 확인했으나 PDF 직접 열기는502오류였다. 기존 함수 및 이전 문헌 구현과 식이 일치한다.
이 식은 본선과 진출부의 밀도에 따라 anticipation 압력을 바꾸는 연결식이며, 제어에 용량 이득을 부여하는 보너스가 아니다.

## 시험 범위

기존 집계 함수와 canonical_harness에 선택적 연결만 추가했다. 매1초 시작 시점의 **예측 off-ramp 재고 / 실제 connector 차로·길이**로 진출부 밀도를 계산했다.
그 시점 배수·진입보다 먼저 재고를 읽었고 미래 실제 재고·유량은 넣지 않았다. 기존 동적 저장·배수·실제 합류·대기는 유지했다.
진출 connector 전체를 한 개의 출구 셀로 보는 근사이므로, connector 내부 큐의 선두 위치까지 표현하지는 않는다.

계수를 새로 맞추지 않고 현재 값 그대로 한 후보를 동결했다. 공통2220.1초의 seed29/43 NC·VSL·RM·결합 및2670.1초의 seed29 RM 유지·완화±VSL을 비교했다.
이미 여러 번 확인한 상태이므로 독립 미사용 검증이라고 부르지 않는다.

## 발화·기하·검증 근거

- 총5400번의 집계 substep에서 진출4곳씩, **21,600회** 실제 가상 밀도 연결이 적용됐다. 각 정책 시작 밀도는 공통 초기 차량 cohort 수/차로·길이와 일치했다. 동적 밀도 범위는 `verification.json`에 저장했다.
- 초기seed29에서10481의 예측 밀도는0–0.70대/km/차로에 불과하다. 따라서 이 분기의 가상 밀도는 본선 값과 거의 같고, 셀18의 큰 과도 감속을 해소할 정도로 바뀌지 않는다. 다른 진출부의 밀도 효과까지0이라는 뜻은 아니다.
- 정적 연결은 본선2의2–4차로가10613을 통해119의1–3차로로 이어진다.10481은2의1차로부터 시작하는2차로 진출 connector다. 물리4→3 차로 수 감소가 곧 모든 통과 차량의 강제 합류를 뜻하지는 않는다. 다만 이 기하만으로 lane-drop 항을 없애거나 올바른 보정 크기를 확정하지 않는다. 이전 phi제거 시험도 재현에 실패했다.
- 기본 비활성 설정의450초 cells/flows/ports/ramps가 저장된 기준 배열과 정확히 일치했다.
- 12개 후보의 수치·보존 검사 통과. 최대 램프/포트 잔차1.13e−12대. 기존 공식 단위시험5개와 잘못된 밀도 입력4개 거부 검사 통과.
- 전체 과거 차로 테스트 실행은 역사적 `controller_response_s23_v1/none/cells_30s.csv` 부재로2개 클래스의 setup이 실패했다. 이 테스트 전체 통과를 주장하지 않는다. 이번 집계 모델의12개 실자료 replay와 기본 회귀 검사는 별개로 통과했다.

## 채택과 다음 판단

**후보는 미채택.** 실행 소스를 `executed_sources/`에 보존하고 수정한3파일을 `before_sources/`의 정확한SHA로 복원했다. 이전 미커밋 작업은 유지했다.
현재 정본에는 시험 전과 같은 물리가 실행된다. 후보manifest를 재현하려면 보존된 실행 소스를 함께 사용해야 한다.

저밀도 감속과 가상 출구 밀도를 각각 확인했지만, 초기 VSL·RM의 큰 방출 이득을 설명하지 못했다.
따라서 다음 판단의 대상은 이 두 항의 세밀한 계수 탐색이 아니라 **혼잡한 본선 구간의 방출·회복 반응**이다.
새 구조 또는 보정식의 근거가 확인되기 전에는 이번 실패를 임의의 capacity 증가나 추가9000초 런으로 덮지 않는다.
