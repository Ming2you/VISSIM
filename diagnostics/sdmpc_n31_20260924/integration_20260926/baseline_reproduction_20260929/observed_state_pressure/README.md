# 실측 상태의 속도식과 실제 이동 차량 속도 진단

2026-09-29. **진단 완료 / plant 보정·제어 이득 검증은 미완료.**
기존 정본 물리·계수·수요·제어·목적함수는 바꾸지 않았다. 기존 진단 helper만 확장했다.
새 VISSIM 및 새450초 자율예측은0회다.56개의 조건부1초 계산과 완료된4개FZP의 지정 구간 재읽기를 수행했다.

## 1. 실측 상태를 넣어도 큰 감속이 남는다

seed29/43 NC의2220.1–2670.1초 창에서30초마다14개 상태를 사용했다.
각 시점의 실측 본선N/v와 저장된 자율예측의N/v를 각각 현재 상태로 놓고, **양쪽에 동일한 현재 실측off 재고와 직전30초 평균 source/merge 유량**을 공급했다.
110 명령과 기존 split·물리 길이·동적 유효차로·FD·lane-drop·합류 감속을 사용했다. 해당1초의 off 진입 상한은 현재 빈 저장 공간이며 배수 이전 값이다.

미래 상태를 예측 지평에 넣어 성공으로 판정하는 실험이 아니다. 이후 시점의 실측 초기상태를 사용하는 **원인 분리용 조건부 진단**이다.
직전30초 평균 유량은 다음1초의 실제 유량과 다르며, 다음5초의 셀 평균속도 변화에는 차량 교체·이동도 포함된다. 개별 차량 가속도나 정확한 순간 미분으로 간주하지 않는다.

|---|---:|---:|---|

반대로 저장된 모델 상태를 같은 조건으로 대입하면 셀18/24의 모델 속도 변화는 약−0.06/−0.02까지 작아진다.
**잘못된 상태가 전달되는 것뿐 아니라, 실측 상태에서 평가한 반응식 자체에도 큰 불균형이 남는다**는 단서다.
모델이 관측보다 느린 상태 주변에서 균형을 이루는 것과 일관되지만, 단일 계수의 오류나 확정된 원인 하나를 입증한 것은 아니다.

56개 조건부 계산의 차량 보존 최대잔차1.84e−13대, 밀도 projection0.
기존 관측 wrapper에서 relaxation/convection/anticipation/lane-drop 재구성이 실제 정본 속도함수와 일치했다.
독립적으로 보관된5초 순간 통계와30초 실측N/v를868개 셀·시각에서 대조했다.

## 2. 넘어오는 차량은 상류 평균보다 빠르다

기존FZP의2220.1–2670.1초만 분석했다. seed29/43의NC/VSL4개 파일을 각각 한 번 읽었고,2670.1초까지의 데이터prefix SHA가 기존manifest와 모두 일치했다.
총364개5초 프레임,1,875,235개 창 내 원시행을 처리했다. 관심 셀17–25의N/속도합3276개가 기존캐시와 일치했다.

셀24로 다음5초 동안 이동한 차량은 **이동 전 표본 시점**에도 상류 셀23 평균보다 빨랐다.

|조건|이동 차량의 출발 표본속도−당시 상류 셀 평균|이동 차량 표본 수|
|---|---:|---:|
|seed29 NC|+11.20km/h|838|
|seed29 VSL|+10.75km/h|860|
|seed43 NC|+16.06km/h|836|
|seed43 VSL|+12.84km/h|848|

따라서 상류 셀의 평균속도를 그대로 이동 차량 대표속도로 쓰면 실제로 전진하는 집단을 느리게 표현할 수 있다.
다만5초 뒤 도착속도에는 경계 통과 후 가속도 섞이므로, 이를 정확한 경계 순간속도로 바꾸어 부르지 않았다.

매5초 셀 평균속도 변화를 아래 세 항으로 **정확하게** 분해했다.

```text
mean(v1)-mean(v0)
 = sum_stayers(v1-v0)/N1
 + sum_entries(v1-mean(v0))/N1
 - sum_exits(v0-mean(v0))/N1
```

셀24에서는 남아 있던 차량의 가속과 유입·유출 집단 변화가 서로 상쇄되어 평균속도가 거의 일정했다.
이 회계식의 각 항을 METANET의 force/convection에 일대일 대응시킨 것은 아니다. 표본 사이 두 셀 이상 이동, 경계 통과 후 가감속, 차로별 분포 등이 남아 있다.

## 3. 작은 분산 보정의 설명력은 있지만 자율 모델은 아직 아니다

국소 위치 분포가 균일하고 속도가 짧은 시간 고정된다면, 유량으로 가중한 속도는
`E[v²]/E[v] = mean(v) + variance(v)/mean(v)`가 된다.
이 관계가 실제 전진 집단의 빠른 속도를 설명하는지 아래 한 계수 식으로 검사했다.

`advancing_speed - spatial_mean_speed = beta * current_variance/current_mean`

절편·seed·시각·제어 보너스를 넣지 않았다. seed29 NC만으로 차량 표본 수 가중 최소제곱을 적용해 beta=0.70055를 얻었고, 그 값을 고정했다.
이 회귀는 plant 계수 보정이 아니라 **관측된 속도 선택 편향의 설명용 검사**다. 다른 상태도 과거 열람한 자료라 pristine holdout으로 부르지 않는다.

이동 전 차량속도−상류 평균속도 차이의 RMSE[km/h]:

|자료|보정0|이론계수1|고정 beta=.70055|
|---|---:|---:|---:|
|학습29 NC|9.57|7.96|7.56|
|확인29 VSL|9.00|7.32|6.98|
|확인43 NC|10.69|7.07|6.93|
|확인43 VSL|10.15|7.20|6.96|

RMSE는 줄었지만 beta=.70055가 모든MAE에서도 이론계수1보다 좋지는 않다. 이 계수를 정본으로 선택하지 않았다.
사용한 분산은 **현재 실측값**이다. 미래 분산을 자율적으로 생성·유지하는 법칙과 실제 이득은 아직 검증되지 않았다.

## 4. 다음 작업의 조건

이전 `MOMENT_AND_LANE_BINDING_20260925.md`에서는 실제 허용 유량으로 평균속도 모멘트를 운반하는 후보와, 분산을 상태로 추가한 후보를 이미 시험했다.
분산이 실제보다 지나치게 빨리 소멸했고, 재보정 후에도 VSL 손익 방향을 통과하지 못했다. 단순한 평균 이송 후보를 새 아이디어처럼 반복하지 않는다.

이번에 추가한 근거는 **실제로 다음 셀로 이동한 집단의 속도 선택 편향**이다.
작은 보정으로 연결하려면 현재 예측 상태에서 이 분산/이송 모멘트를 예측할 수 있어야 하며, 빠른 차량의 유출이 출발 셀에 미치는 반작용까지 계산해야 한다.
유입 속도만 올리거나 미래 실측 분산을 주입하면 회복을 인위적으로 만들 수 있으므로 채택하지 않는다.
새 차로 상태를 전수 확장하기보다 기존 평균·모멘트 전달 부분에서 이 조건을 충족하는 작은 관계가 가능한지 먼저 판정한다.
그 후에도 동일 초기 상태 RM/VSL/결합, 손해 상태, 램프·도시 대기 포함 비용 및 SDMPC 선택 검증이 남는다.
