## 비교 방법과 제한

실제 다음5초 속도 변화는 저장된 native5초 moment를 사용했다. 별도 차량 ID 집계의 잔류 차량 가감속·진입 집단 구성·이탈 집단 구성의 항등식과 재대조했다. 각 항은 집단 평균 변화에 대한 기여이며 각각을 METANET의 특정 힘과 동일시하지 않는다. 잔류 기여도 전체 개별차량의 평균 가속도를 뜻하지 않는다.

기준 첫1초의504개 셀 기록이 기존 진단과1e-8 이내로 일치했다. Native N/v868건 재구성, 본선+origin 경계 보존 최대잔차1.90e-13대, density projection0. 해석을 위한5초 비교에29/43 모두의 관측 상태를 썼으며 독립 검증이나 새450초 gain 검증으로 세지 않는다.

## 셀 길이와 문헌

geometry_distance_audit.json에서 실제31셀 길이와 중심 간 거리를 비교했다. 중심 간 거리로 anticipation 분모를 바꾼다면 현재 대비 셀18은0.9346배,21은0.7223배,24는0.5배다. 셀24에서는 양의 anticipation도 약해지므로 회복 개선을 보장하지 않는다. 변경하거나 새 예측하지 않았다.

[Frejo et al., Macroscopic Modeling of Variable Speed Limits on Freeways, 식1–3](https://www.dcsc.tudelft.nl/~bdeschutter/pub/rep/19_022.pdf)은 서로 다른 segment 길이와 셀별 τ·μ 보정을 허용하면서 자체 길이Li를 쓴다. 따라서 비균일 길이만으로 현재 분모가 구현 오류라고 판정하지 않는다.

추가로 [Zhao et al., Bounded-METANET, 2025 preprint](https://arxiv.org/html/2503.17680v1)의 식13–17을 확인했다. 이류를 제거하고 anticipation·merge·lane-drop을 유효 밀도와 이완에 포함한다. SUMO/실측 자료 검증은 있지만 이 논문을 우리 RM+VSL MPC의 이득 검증으로 사용할 수는 없다. 이번에는 읽기만 했고 구현·보정하지 않았다. 현재 망에서의 대안 검토 시 실제 accepted merge, VSL 노출 이력, off-ramp·차량 보존은 유지해야 하며 기존 계수를 그대로 복사하거나 lane-drop/merge 감속을 중복 적용하면 안 된다.

다음 판단은 동일 계수 격자를 더 반복하는 것이 아니다. 순간항의 개선을 자율 예측 개선으로 취급하지 않고, 현재 모델이 서로 상쇄하는 큰 감속·가속 항으로 상태를 유지하는 방식과 이득 민감도의 관계를 확인한다. 새로운 속도식 검토가 필요하더라도 현 플랜트의 실제 유량·재고·램프 비용 및 동일 조건 제어 순위와 함께 한정된 비교로 판단한다.9000초 실행 gate는 아직 통과하지 않았다.
