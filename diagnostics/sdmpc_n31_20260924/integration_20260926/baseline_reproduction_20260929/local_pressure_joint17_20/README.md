## 기존 두 감속항의 공동 보정

이전159계수 보정은 lane-drop phi를 고정했으며, 국소 anticipation 시험 역시 lane-drop을 유지했다. 이번에는 기존 식의 **셀17–20에만** anticipation 두 분기와 lane-drop을 동시에 조정했다. 보조 가속도·용량·제어 보너스를 새로 넣지 않았다.

기존 observed_state_pressure의 seed29 NC14시각×4셀에서 다음 식의 세 배율을0–2 범위 제한 최소제곱으로 구했다.

    observed_next5s_mean_speed_trend
      ≈ relaxation + convection + post_equation
        + a_ge * anticipation_ge + a_lt * anticipation_lt
        − b * lane_drop

선형항 재구성은 기존 실제 모델1초 변화와1e-14 이내로 일치했다. **다음5초 셀 평균 변화에는 차량 교체도 포함되므로 개별 가속도나 정확한 순간 미분이 아니다.** 이 적합은 초기값 후보 생성이며 이득 검증이 아니다. 탐색적 설명 계산을 먼저 보았다는 사실을 protocol에 명시한 뒤 자율 실험 예산을 고정했다.

배율은 a_ge=0.215232816, a_lt=0, b=0.235401438(기존phi3→0.706204313). FD·τ·합류항·비대상 셀·수요·명령·내부1초·램프 대기·동적off-ramp는 유지했다. 감속/회복 분기는 현재 예측 밀도차로 판정한다.

설명용 실측상태 추세RMSE는 seed29 5.22→1.78, seed43 5.55→2.08km/h/s로 작아졌다. seed43 값으로 계수를 다시 고르지 않았다. 이후 모든450초 예측은 현재/과거 관측만 사용했다.
