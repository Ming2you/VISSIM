## 사전 범위

- 형상 계수는 모든 후보에서1보다 컸다. 임계밀도는 정체밀도보다 작았다. `v_free`, τ/ν/κ/φ/merge, 셀23 상태 보정, 나머지 셀의 FD는 유지했다.
- 임계밀도는 기존 lane-drop 감속 분모에도 들어간다. 그 연결을 유지했으므로 순수 평형속도 효과 하나만 바꾼 시험이라고 주장하지 않는다. 새 hard capacity 상한/보너스는 없다.
