# 원래 ALINEA 자료의 10681 신호 통과·합류 오차

2026-10-01 완료. 기존 관측 캐시만 사용했다. 12회 조건부 버퍼 재생, 4회 단일 가설 재생, seed53의 기존 모델 동등성 1회와 후보 4회(450초)를 확인했다. 새 VISSIM, FZP 재스캔, 계수 적합, 실행 중인 native 런 조회는 하지 않았다. 후보는 채택하지 않았다.

## 원인 분리

원래 네 정책 중 NC2700, RM2700, RM4500, 결합4500의 150초를 사용했다. 기존 모델 재생은 저장된 기준 결과와 동일했다. 실제 미래 차로별 도착량, 다음으로 실제 합류 사건을 수용 예산으로 공급해 보아도 신호 뒤 재고 오차가 약 +4~14대 남았다. 이는 원인 분리용 조건부 시험이며 자율 예측 또는 보정 성능이 아니다. 실제 합류량을 강제로 생성하지 않고 해당 시간의 상한으로만 사용했다.

따라서 오차를 본선 합류 상한 하나로 설명할 수 없다. RM4500에서 실제/예측 합류량은 1차로 4/16.56대, 2차로 35/33.09대다. 전체 상한을 낮추면 이미 가까운 2차로까지 바뀐다. 실제 전후 재고와 입출 경계로 추정한 1→2차로 순이동은 7대지만, 이 자료로 이동 위치·시각 또는 차로별 신호 통과량을 확정하지 않았다. 전체 신호 통과량은 차량 보존으로 계산했다.

## 시험한 수정과 범위

기존 모델은 신호 뒤 공간의 잔여 저장량을 검사하지만, 신호 뒤 밀도가 올라갈 때 통과 유량을 점진적으로 줄이는 수용식은 없다. 10681에만 다음 가설을 메모리에서 시험했다. 기존 포화 서비스, 이동속도, 차량 간격을 그대로 사용했다.

- 차로당 녹색 중 최대 서비스 Q = max_g(service[g]/g/차로 수) = 0.5대/초.
- 자유 이동속도 v = 39.3765/3.6m/s, 정체밀도 kj = 1/6대/m.
- w = Q/(kj−Q/v) = 4.1338m/s.
- 현재 예측 신호 뒤 재고 N, 길이 L에 대해 수용량 R = max(0,min(Q,w(kj−N/L))).
- 기존 녹색 서비스에 R·dt 상한을 추가하고 기존 대기·공간 검사와 적분 순서를 유지했다.

이는 기존 값으로 만든 수용 가설이다. 실측 충격파 속도나 실제 차로별 이동을 식별한 모델이라고 주장하지 않는다. 메모리 훅은 실행 후 복원했고 운영 코어·설정은 바꾸지 않았다.

## seed53의 동일 초기 상태 450초 확인

RM 유지/완화와 VSL90 유무 네 조건을 확인했다. seed53은 이전에 검사한 자료지만 이번 가설을 만들거나 계수를 맞추는 데 사용하지 않았다. 기존 모델 1회 재생에서 모든 셀·유량·off-ramp·램프 기록이 저장 결과와 정확히 같아 나머지 기준 결과를 재사용했다. 후보 4회에서는 본선 상태·유량·off-ramp 기록이 기준과 정확히 같고, 10681 합류량도 같다. 램프의 종료 재고 약 7~8대가 신호 뒤에서 앞으로 이동했을 뿐이다. 따라서 이번 후보는 이득 예측 오차를 해결하지 못했다.
