# 저밀도 anticipation 보정: 작은 후보 2개, 채택하지 않음

2026-09-29. 문헌 검토 후 기존 상태 의존 속도식에 한 가지 작은 보정을 시험했다.
**8개 학습450초 예측 + 기본설정450초 재현1회 완료. 추가 검증0회, 새 VISSIM0회, push 없음.**
단위는 차량·시간이며 평가 범위는 동측31셀+진입/진출 connector8개다. Ω 전체나9000초 정책 성능이 아니다.

## 가설과 사전 기준

셀17–25가 공통 계수 beta를 사용한다. 하류가 더 조밀한 감속 방향에서만 기존 anticipation의 분모를
`rho+kappa`에서 `max(rho,beta*rho_crit)+kappa`로 바꿨다. beta=.5와1을 비교했다.
현재 예측 상태로만 작동한다. 회복 방향·임계 이상 밀도·FD·lane-drop·합류 상한·램프 대기·동적off-ramp·차량 보존은 유지했다.
이는 Fang 등의 상태 의존 반응이라는 발상에 참고한 **우리의 시험식**으로, 논문 공식을 그대로 구현한 것이 아니다.

후보를 보기 전에 `protocol.json`에 예산과 점수를 고정했다. seed29,2220.1초 공통 상태에서450초간 none/VSL/RM/both를 비교했다.
학습 점수는 제어쌍의 ΔTTT, 진출+말단 누적 유출 차이, 실제 합류 차이 오차를 합쳤다. 속도RMSE만으로 고르지 않았다.
점수20% 이상 개선과 재고·유량RMSE 악화10% 이내를 모두 요구했다. 두 후보 모두 이 기준에 실패했다.

beta=.5는 결과가 그대로였다. beta=1의 반응 오차 점수는2.358624→2.352786으로 약0.25%만 줄었다.
VSL의 실제 진출+말단 유출 증가는32대지만 예측은−0.00885→+0.02609대에 그쳤다.
평균 속도RMSE18.56→18.48km/h의 작은 개선을 이득 재현으로 판정하지 않았다.

기존 첫150초의 실행 항 기록을 재사용해 조건의 발화를 확인했다. beta=.5 조건에 해당하는 셀17–25 샘플은0개였다.
beta=1 조건은 셀17·18에서86·33회에 해당하지만, 셀19·20·22·23은 이미 임계밀도 이상이었다.
따라서 이 시험은 **저밀도 감속만 완화하는 국소 보정으로 현재 이득 오차를 해결하지 못했다**는 결과다.
모든 anticipation 보정이나 모든 작은 보조 항이 불가능하다는 증거는 아니다.
발화 횟수는 기존 기준 궤적의 설명용 검사이며 후보 자체의 발화 횟수로 주장하지 않는다.

## 검증·정리

- 새 보정과 기존 분기·격리 테스트14개 통과. 기본설정450초의 cell/flow/port/ramp 배열은 기존 결과와 정확히 같았다.
- 8개 후보 예측의 수치 유효성 검사 통과, 최대 램프/포트 보존 잔차9.10e−13대.
- 학습 기준 미달로 seed43와 늦은 상태의 추가8개 검증은 실행하지 않았다. 독립 검증 통과를 주장하지 않는다.
- 실패한 보정은 정본에 남기지 않았다. 실행 소스는 `executed_sources/`에 보존하고, 수정한6파일을 `before_sources/`의 정확한 SHA로 복원했다. 원래 존재하던 미커밋 수정은 유지했다.
- 실험 재현 시 실행 소스와 후보manifest를 함께 사용해야 한다. 현재 정본에는 이 시험용 설정 키가 없다.
- 실행 중인 타 프로젝트 Python 프로세스는 건드리지 않았다. 새 native 실행 및 FZP 재스캔도 없었다.
