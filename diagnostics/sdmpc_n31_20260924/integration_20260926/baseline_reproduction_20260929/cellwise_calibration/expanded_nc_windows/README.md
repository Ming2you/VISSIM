# 추가 시간대에서 셀별 보정의 일반화 확인

기존159계수 후보를 재보정하지 않고, 기존 학습 두 초기 시점 밖의 무제어 상태7개에 적용했다. 기존 모델과의 **14개450초 예측**이 완료됐다. 이어서 셀24·25 계수만 이전 값으로 돌린 후보를13개 상태/조건에서 비교했다. 이번 작업은 총27개 새 오프라인 예측이며 새 VISSIM·계수 최적화·push는 없다.

## 자료와 예측 입력

seed29의1200.1/1800.1/3600.1/5400.1/7200.1초, seed43의1800.1/7200.1초를 사용했다. 각450초의 동측 본선·8connector 장부에 미해명 손실·native 삭제 기록이 없는 창이다. seed43의 다른 세 창은 기존 손실 기록 때문에 제외했다. 도시부 전체·외부 대기까지 무손실이라고 주장하지 않는다.

선택망64cf5f… 원본과 실행망을 확인했다. seed43은 randSeed만 다르고, 준비된 실행 INPX는 해당 원본과 XML 트리가 같다. geometry가 참조하는401b65… 기반망과는 DSD·검지기 항목만 다르며 links 기하는 같다. 예측의 DSD 바인딩은 실제 선택망에서 생성해 본선110을 확인했다. 도시/램프의 다른 DSD를110으로 강제하지 않았다. 두 native 실행은 기존 기록에서9000초 완료, 무제어 명령 이벤트0, 실행 검증 exit0을 확인했다. FZP 재스캔은 하지 않았다.

기존 forecast/make_window를 사용하고 rollout 직전에 입력만 저장했다. 각 상태에서 미래 관측을 제거한 입력과 완전히 동일함을 확인했다. 추가 미래 경계·재고를 예측에 주지 않았다. 표준 관측·과거 도착 이력·동적 port 상태와1초 내부 적분을 유지했다.
