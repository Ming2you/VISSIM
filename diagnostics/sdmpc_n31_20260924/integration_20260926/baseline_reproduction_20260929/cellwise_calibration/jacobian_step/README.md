# 31셀 공동 보정: 직접 민감도 기반 1회 갱신

**완료·정본 미채택. [결과](RESULT.md)** 최초 실행 기록:  기존 SciPy 폴더 접근 제한으로 최초 시작은 rollout 전에 실패했다. 기존 설치에 대한 접근을 확인한 뒤 동일 코드·예산으로 다시 시작했고, 실패 로그를 first_import_failure.log에 보존했다. 기존 반응 포함 보정의 학습 최선에서 시작한다. 스칼라 손실과 잔차벡터 제곱합의 일치를 매 평가에서 확인한다. 159개0.2% 상대 섭동, 큰 목적 기울기6개에 절반 간격 확인, prior를 제외한 민감도 행렬을 기록한다. 관측 없는 자유도를 prior가 식별한 것으로 취급하지 않는다.

새 Jacobian은1회만 계산한다. 계수 상대 변화±5/15/30% 범위의 선형화 최선3개를 실제 연결망450초로 평가한다. 학습 손실로 최종 후보를 고정하고 seed43 네 조건을 확인한다. 최대1356개 예측,4개수치 worker. 새 VISSIM/push/production 수정 없음. 기존 native HOLD와9000STOP 유지.

이전 scalar calibration 실행 helper의 해시는 상위 helper_before_fit.py.txt에 보존돼 있다. 이번에는 기존 helper에 진단 명령을 추가했으므로 이전 실행 시점의 helper 해시와 현재 파일 해시는 다르다.


최종: 159열+6절반간격+3실제갱신, 총1356개450초 예측. 학습 반응오차17.9% 감소, seed43는1.8% 증가하고 RM/both 손익 부호 실패. 계산57091은 exit0 종료했다. 기존 native HOLD/9000STOP 유지, 목표ACTIVE/NOT_QUALIFIED.
