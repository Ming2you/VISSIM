# 추가 시간대와 제어 반응의 공동 보정

**학습 반응 오차는39.9% 줄었지만, seed43의 RM·결합 이득 방향은 여전히 실패했다. 정본에 채택하지 않았다.** 기존 두 시점만 반복하지 않고, 추가 시간대를 실제 보정에 편입한 유한 시험이다.

새450초 예측은 총502개다: 학습494, 기존 결과와 정확한 일치 확인2, 고정된 후보의 별도 확인6. 새 VISSIM·push는 없다. 보정/후속 확인 경과시간은 약512초이며 초기 자료 읽기·SVD·두 동일성 확인 시간은 제외한다. SDMPC 최적화 시간이나 native simulation 시간이 아니다.

## 방법과 범위

학습은 seed29의 공통2220.1초 NC/RM/VSL/결합4조건,2670.1초 RM 유지/완화±VSL4조건, 추가NC1200.1/1800.1/3600.1/5400.1/7200.1초5조건이다. 제어쌍의 초기 상태·명령·경계 입력 계약은 이전 검증을 재사용했다. 실제 미래 유입을 예측 입력으로 주지 않았다.

31셀의 임계밀도·FD형상·이완시간·두 anticipation 계수와4합류 계수, 총159값의 이질성은 유지했다. 이전 학습 Jacobian의 prior 행을 제외한 데이터 민감도에서12개 결합 방향을 고정해 증분 보정했다. 각 계수의 변경은 이전 원점 척도 대비±15% 및 기존 물리 범위 안으로 제한했다. 따라서 독립159차원 전체의 새로운 최적화나 충분한 식별을 완료한 것이 아니다. FD/속도/실제 수용·보존식에 새 항을 붙이지 않았다.

같은 상태 손실+제어쌍 반응 손실×2+상대계수 prior×0.1을 사용했다. 추가NC는 상태 손실에 참여하며, 제어 반응은 기존 동일 초기 상태 쌍에서만 계산했다. 이는 보정 목적이고 controller의 Ω TTT 목적은 바꾸지 않았다.

12방향의 절대 유한차분 간격0.1로 Jacobian을 다시 평가했다. solver nfev=3, njev=3, 예산 소진으로 success=False이며 수렴 주장은 하지 않는다. 39개 고유 계수 평가(그중 초기 평가의13예측은 기존 결과 재사용) 중 학습 목적값이 가장 작은36번을 선택한 뒤 고정했다. 방향별 probe도 실제 학습 점수로 비교한 후보에 포함된다. 확인 자료에서 계수를 다시 선택하지 않았다.

## 남은 RM 오차의 장부 분해

새 후보의 예측 유량과 실측 유량을 동일30초 보존식으로 대조했다. 미래 실측은 채점 장부로만 읽었고 예측 입력에 넣지 않았다. 합계는 각 본선 ΔTTT와 수치 오차 범위에서 일치한다.

- seed29 RM: 실제 본선 TTT는−1.0000veh·h, 새 후보는−0.2287이다. 진출+말단 방출 변화의 시간 가중 기여는 실제−0.6833, 예측−0.0565다. 합류 감소를 대기로 옮기는 효과를 넘어선 본선 방출 반응이 여전히 작다. 실제 source 기여는+0.0708이므로 이 상태의 이득을 단순한 입력 감소로 설명할 수 없다.
- seed43 RM: 실제 본선 TTT−1.2000 중 source 시각·통과량 차이의 장부 기여가−1.5917이다. 모델의 source 차이는0이다. 이 자료의 이득 전부를 합류 감속 계수로 맞추면 다른 원인의 차이를 흡수할 위험이 있다. 다만 이는 보존식의 회계적 분해이며 입력 차이가 내생적 교통효과인지 난수 변동인지 확정한 것은 아니다.

4개 합류 계수도 실제로 바뀌었다(셀10:3.711→3.530,12:4.858→5.089,21:4.500→4.212,23:2.169→2.211). 이번12방향 공간에서 합류 계수가 완전히 고정됐던 것은 아니다. 그럼에도 이것만으로 전체 가능한 계수 범위에서 RM 이득을 만들 수 없다고 판단하지 않는다.

## 검증과 다음 판단

159개 유효 계수가 저장값과 일치하고 물리 범위 안임을 확인했다. 서측 및 다른 freeway 설정은 유지했다. 후보들의 물리 검사는 모두 통과했고 port/ramp 최대 보존 잔차는1.21e−12대였다. 기존 두 예측의 cells/flows/ports/ramps는 정확히 일치했다. source/관측 해시와9000 STOP을 유지했다. Session7604는 exit0을 직접 확인했다.

이제 추가 시간대를 포함한 보정 자체는 실행했다. 다음은 같은 계수 탐색을 더 오래 반복하기보다, seed29의 실제 합류 이후 방출 반응과 seed43의 source 변동을 구분해 어느 부분을 예측 모델이 설명해야 하는지 좁히는 것이다. 새 후보는 개선·실패 근거와 함께 보존하되, 전체Ω·SDMPC 선택·native 성공으로 대신하지 않는다. 전체 목표는 ACTIVE / NOT_QUALIFIED다.

실행: 기존 sole plant를 호출하는 ../expanded_joint_fit.py. protocol.json, selection.json, summary.json, effective_coefficients.json, control_flow_decomposition.json, verification.json에 입력·예산·수치·유효값 근거가 있다. 실패나 완료된 폴더를 자동 덮어쓰거나 재실행하지 않는다.
