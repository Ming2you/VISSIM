# 本선 합류 경계의 원인 분리

2026-09-29. 고속도로를 먼저 보정한다는 우선순위에 따라, 동결된 expanded_joint/eval_036의 seed29 초기 네 조건을 비교했다. 새로운 계수 선택·도시 신호 최적화·VISSIM 실행·push는 없다.

## 시험과 검증

- 같은 2220.1초 초기 상태에서 450초, NC/RM/VSL/결합 네 명령을 유지했다.
- 먼저 모델이 원래 예측한 1초별 실제 합류량을 기존 external boundary 입력으로 재생했다. 네 조건 모두 본선 cells, flows, 동적 off-ramp ports 전체가 저장 결과와 **정확히 같았다**.
- 이후 합류 경계만 FZP에서 추출된 실측 connector departure로 치환했다. 기록은5초이므로 각5초 구간 안에 균일하게 배분했다. 본선 입력 예측·VSL 노출 이력·FD/속도식·off-ramp 진입/저장/배수는 그대로다.
- 램프의 도착·신호·대기·gap 계산은 이 조건부 구성요소 밖에 있다. 본선 진입량을 강제한 원인 분리이며, 실행 가능한 제어 또는 전체Ω 순이득 예측이 아니다. 미래 실측 입력을 자율 모델에 채택하지 않는다.
- 실측 진출 합류 사건은 각30초 본선 보존 장부와 대조했다. 세 종류×네 조건의 본선 장부 최대 잔차1.42e−13대, 음수·jam초과0. 소스/모델/기존9000 STOP 등29개 pin을 재확인했다.

## 결과

음수는 NC 대비 본선 TTT 감소, 단위veh·h/450초.

|조건|실측|기존 자율 예측|실측 합류를 넣은 조건부 예측|
|---|---:|---:|---:|
|RM|−1.0000|−0.2287|−0.4277|
|VSL|−0.3750|−0.3702|−0.2502|
|결합|−1.1000|−0.6056|−1.1109|

**RM 단독의 방출 증가 부족은 합류 입력을 정확히 줘도 남는다.** 진출+말단 누적 방출 증가는 실측22대, 기존2.097대, 조건부1.139대다. RM의 조건부 TTT가 나아진 것은 주로 합류량의 시간 분포를 맞춘 영향이며, 방출 반응이 복구된 결과가 아니다.

같은30초 재고 적분의 보존식 분해에서 RM의 합류 항은 실측−0.3875, 기존−0.1722, 조건부−0.3875veh·h다. 방출 관련 항은 실측−0.6833, 기존−0.0565, 조건부−0.0402다. 이는 회계적 항등식이며 독립적인 인과 기여율로 해석하지 않는다.

결합의 총TTT가 가까워져도 방출 증가는 실측30대/조건부18.731대이며, source 통과의 시각 차이도 남는다. 합계 일치만으로 역학 보정 성공을 선언하지 않는다. VSL 조건부 결과가 기존보다 나빠진 것도 보존한다.

## 남은 위치

RM−NC의 누적 하류 통과 증가:

|0기준 셀|실측|기존|실측 합류 조건부|
|---|---:|---:|---:|
|18|27|5.175|6.243|
|19|25|5.970|6.307|
|23|20|2.685|0.093|
|24|20|2.470|0.257|

따라서 '램프의 합류량만 보정하면 된다'는 설명은 이 상태에서 충분하지 않다. 다음 본선 검토는18–19 및23–24에서 합류 변화가 방출·전파·회복으로 연결되는 반응이다. 이 결과만으로 특정 METANET 항이나 전체 구조가 원인이라고 확정하지 않는다. 본선 입력/분기 예측과 미시적인 합류 순서의 불확실성도 남아 있다.

강제한5초 실측 합류는 예측 상태의 평균 gap/수용 envelope를 넘는 구간이 있다. NC에서 네 램프 각각90/75/57/70초다. 해당 값을 잘라서 맞추지 않았고 모두 summary.json에 기록했다. 평균 유량 모델의 envelope 초과는 VISSIM의 실제 물리 위반이나 그 계수 오류의 증명이 아니다. 이 구성은 본선 조건부 진단에 한정된다.

## 실행 기록과 결정

유효 결과8개(동일성4+실측 경계4), 수치 rollout 실행9회다. 첫 실행은 동일성4개 완료 후 램프 인덱스 참조에서 중단됐다. 첫 재개는 조건부NC 계산 완료 후 Windows 경로 길이로 저장에 실패했다. 로그·실행 당시 소스를 merge_boundary_source에 남겼고, 완료된 동일성4개를 재사용하면서 저장 실패한NC만 한 번 다시 계산했다. 결과와 실패를 합쳐 성공으로 처리하지 않았다.

기존 정본 식·설정은 변경하지 않았다. 기존 진단 helper에 명시적 명령 하나와 실패 지점 재개 경로만 추가했다. 기존 함수의 AST는 유지했다. 예측 성공/전체 이득 보정 완료가 아니며, 계수 채택·새9000초 실행도 없다. 전체 목표는 ACTIVE/NOT_QUALIFIED다.

근거: summary.json(조건별 원시 지표·pin), spatial.json(시간가중 보존식과 셀별 시계열), summarize.py(저장 자료 재집계). 기존9천초 STOP은 유지했다.
