# 직전 속도식 잔차를 쓰는 보조항 사전 검사

2026-10-01. 기존 검증된 계산 장부를 재사용해 1,464개 시점에서 검사했다. 후보 한 개를 시험했고, 새 계수 적합·자율 예측·VISSIM·FZP 재읽기는 없다. 보조항을 플랜트에 채택하지 않았다. 전체 목표는 ACTIVE / NOT_QUALIFIED다.

## 질문과 고정한 검사

앞선 실제 SDMPC 선택에서는 VSL 미분을 수정해 동측의 허용 단계 후보가 평가되었지만 선택 명령은 그대로였다. 실제 VSL 방출·회복 오차를 해결하기 위해, 반복한 FD/merge/회복 계수 탐색 대신 최근 모델 편향을 작은 관측 보정항으로 유지할 수 있는지 검사했다.

시각t에서 이미 끝난 여섯5초 구간의 잔차만 평균했다.

    b(t) = mean[실제 공간평균 속도변화율 − 조건부 모델 속도증가량], 구간 [t−30,t)
    보정 변화율(t) = 기존 모델 변화율(t) + b(t)

30초 창과 계수1은 검사 전에 고정했으며 여러 창이나 배율을 탐색하지 않았다. 현재/미래 정답은 점수에만 사용했다. 비교 기준은 기존 식, 현재 속도 유지(변화율0), 직전 완료5초의 변화율 유지다. 단순 유지보다도 못하는 후보를 큰 플랜트 수정으로 연결하지 않기 위해, 사례별로 기존 식과 변화율0 대비 모두 RMSE10% 개선 및 셀75% 이상에서 변화율0 대비 비악화를 사전 기준으로 두었다.

평균 signed bias는 각각 −1.753→+0.336, −2.512→+0.155, −1.377→−0.033으로 줄었다. 하지만 변화율0보다 나쁘지 않은 셀은 각각0/5,0/5,0/11이었다. 과거 평균 편향을 제거하는 것과 순간 상태 변화의 오차를 예측하는 것은 달랐다. 세 사례 모두 사전 검사를 실패했다.

이 결과는 일정한 추가 가속항으로 저속 편향을 상쇄하면 제어 반응까지 좋아진다는 근거를 주지 않는다. 창·배율을 더 훑거나 조건별 보너스를 넣지 않는다. 변화율0 기준이 좋다고 METANET의 속도 갱신을0으로 바꾸는 것도 아니다. 그것은 제어·혼잡 전파의 반응을 제거하므로 대체 플랜트로 시험하거나 채택하지 않았다.

## 해석 범위

- seed29/43 자료는 이전 연결FD 후보의 조건부 장부, seed67은 expanded036 장부다. 하나의 계수 모델처럼 합쳐 fitting하지 않았고, 각각 별도로 비교했다.
- 현재 식은 실측 현재/인접 상태와 일부 실제5초 합류·유효 차로를 사용한다. 보정항의 과거 사용은 인과적이지만, 이 전체 검사는 여전히 조건부 원인 진단이다. 미래 관측 없이 움직이는450초 MPC 시험으로 보고하지 않는다.
- 모든 조건의 VSL은110인 원래 진단이다. VSL90의 cohort 노출을110으로 바꾸어 비교하지 않았다. 이 검사로 제어 효과나 후보 순위를 통과했다고 주장하지 않는다.
- 실제 속도 표본 사이의 차량 구성 변화와 모델 시간 연산자 차이가 포함된다. 일반적인 offset-free MPC 또는 모든 외란 추정이 불가능하다는 결론이 아니라, 이 구체적인30초 평균 보조항을 지금 추가할 근거가 없다는 판정이다.

## 보존·재현

기존 replay_congested_component.py에 순수 장부 검사 함수 하나와 CLI 항목만 추가했다. 기존104개 함수 AST가 동일하며, 이전 helper 바이트는 helper_before.txt에 보존했다. 운영 core·계수·설정·목적함수·STOP은 변경하지 않았다.

seed67 두 기존 장부의 겹치는180개 조건부 값이1e−8 이내로 같고,1464개 모든 보정에서 마지막 사용 관측의 종료시각이 현재t 이하임을 확인했다. 입력/core/source pins 불변을 확인했다. 검사는 exit0로 끝났다. 과거 완료 결과나 실행 중인 프로세스는 변경하지 않았고 push는 없다.

프로토콜과 결과: protocol.json, summary.json, samples.json, cells.json, verification.json. 재실행 명령은 기존 helper의 audit-past-speed-residual이며, 같은 출력 폴더의 protocol이 있으면 덮어쓰지 않는다.

다음 판단에서는 이 평균 편향 보조항이나 이미 기각된 지역 계수 후보를 반복하지 않는다. 현재까지의 물리 근거는 단순 유량 변환보다 셀15–22의 혼잡 형성·회복·재정체 상태 변화가 문제라는 쪽이다. 변경 후보가 생기면 기존 ALINEA/VSL 공통 초기 상태에서 실제 합류·방출·대기 비용과 큰 손익 방향으로 검증해야 한다. 전체 망·9000초 목표는 미완료다.
