# 본선 국소 속도식 비교 — Bounded-METANET 방식

2026-09-30. **시험한 후보 기각·핵심 소스 원복 완료.** 목표 ACTIVE / NOT_QUALIFIED.

본선 동역학을 먼저 맞춘다는 우선순위에 따라, 전체 망·SDMPC 최적화 대신 동측 셀15–20의 속도식 한 대안을 실제로 구현하고 재보정했다. 기존 ALINEA/VSL 효과의 존재를 부정하는 실험이 아니다.

## 변경 범위

[Zhao et al., Bounded-METANET, 2025 preprint, 식13·14·16](https://arxiv.org/html/2503.17680v1)의 유효 밀도와 이완 방식을 사용했다. 선택 셀에서는 원래 convection·anticipation·lane-drop 속도항을 다시 더하지 않는다. 계수는 논문 실험값을 복사하지 않고 현재 무제어 자료에 적합했다.

이것은 해당 식을 여섯 셀에 적용한 **국소 혼합 모델**이다. 논문 전체 모델이나 RM/VSL MPC를 재현한 것은 아니다. 해당 셀에는 on-ramp가 없음을 검사했다. 다른 셀의 합류 감속과 실제 합류량 계산은 그대로다. 실제 유량·재고 보존, 물리 차로 수, 동적 off-ramp 저장·배수·경로별 재고, 기존 수용 제약과 VSL 명령 노출 이력은 유지했다. 가상의 용량 또는 제어 보상을 추가하지 않았다. 기존 최소속도 5km/h 및 진출 수용에 따른 속도 상한도 유지했다.

## 보정 방법과 종료 기준

- seed29 무제어의 같은 2220.1초 상태에서 750초 자율 예측. 미래 관측 입력 없음.
- 셀15–20 공통 네 계수: tau, eta, kappa, phi. 다른 셀과 기존 FD는 고정했다.
- N/10대, 속도/20km/h, 30초 하류 통과량/(1000대/h에 해당하는 대수)의 제곱오차를 함께 줄였다. TTT 이득을 보정 목적에 넣지 않았다.
- 사전 예산: optimizer nfev 최대3, 유한차분 포함 최대15개 보정 롤아웃. 기준 동일성1회 및 조건부 후속검증11회를 합쳐 최대27회.
- 통과 기준: 마지막300초 국소 손실 10% 이상 개선, 앞선450초 손실 증가 10% 이내, 전체 속도 RMSE 증가 2km/h 이내.

실행은 기준1+보정15=**16회**에서 끝났다. optimizer는 nfev3/njev3 **예산 종료이며 수렴하지 않았다**. 시험한 범위에서 가장 낮은 손실의 e12도 기준을 통과하지 못했다. 따라서 RM/VSL·다른 seed 후속검증은0회다. 이것으로 더 넓은 보정이나 Bounded-METANET 전체가 불가능하다고 결론내리지 않는다.

e12 공통 계수: tau=11.7050초, eta=0.56225, kappa=137.1746대/km/차로, phi=0.80916.

## 끝 속도만 보면 잘못 채택할 수 있다

일부 초기·마지막 속도는 좋아졌지만, 그 사이 혼잡의 시작과 저장량이 크게 틀렸다. 아래는 실측/기존/대안 순서다.

| 시각·셀 | 속도 [km/h] | 재고 [대] |
|---|---|---|
| 2250.1초 셀18 | 77.7 / 54.8 / 84.2 | 16 / 20.1 / 15.4 |
| 2370.1초 셀18 | 29.4 / 51.3 / 96.5 | 26 / 23.3 / 13.2 |
| 2670.1초 셀18 | 26.8 / 23.6 / 5.0 | 37 / 38.7 / 78.2 |
| 2670.1초 셀19 | 37.7 / 26.7 / 6.7 | 27 / 37.1 / 78.9 |
| 2970.1초 셀19 | 82.6 / 26.2 / 88.0 | 18 / 37.5 / 15.8 |
| 2970.1초 셀20 | 43.5 / 22.1 / 82.8 | 34 / 44.5 / 15.9 |

대안은 셀18에서 초반 혼잡을 지나치게 늦게 예측한 뒤 과도하게 축적하고, 나중에는 셀20까지 너무 빨리 회복시켰다. 셀19 마지막 속도가 26→88km/h로 좋아진 것만으로 성공이라고 하면 이 문제를 놓친다. 큰 opposing speed terms를 제거하는 것만으로 발생·전파·회복이 함께 맞지는 않았다.

## 검증·보존

- 비활성 기준의 cells/flows/ports/ramps 전체 배열은 기존750초와 정확히 같다.
- 수식·물리 범위 예제30개 통과. 16회 모두 invalid=false, 차량 보존 최대잔차 4.84e−13대 미만.
- 실험 직전 핵심3파일과 실행 원문을 before/executed에 각각 보존했다. 종료 후 현재 소스가 실행 원문과 같음을 확인하고 세 파일을 **시험 직전 바이트 그대로** 복원했다. 기존 dirty 수정은 보존했다.
- 기존 helper의61개 함수는 변경하지 않았고 이 유한 실험 함수와 CLI 항목만 추가했다. 현재 정본 핵심 소스에는 이 후보가 남아 있지 않다. 재현하려면 executed의 원문과 기록된 설정을 함께 사용해야 하며 helper 단독으로 후보를 켤 수 있다고 가정하면 안 된다.
- 처음 두 호출은 SciPy import/읽기 권한 때문에 예측 전에 종료됐다. 로그를 별도 보존했으며 기존 설치 경로로 권한을 확보해 완료했다. 새 패키지를 설치하지 않았다.
- 새 VISSIM·FZP 재스캔·push 없음. 기존9000초 STOP 해시 유지. 완료 세션15241 exit0, 이 계산의 대기 작업 없음.

## 다음 판단

이 후보의 계수 범위를 곧바로 넓히지 않는다. 기존 모델의 큰 후기 RM 손해 구분을 보존하면서, 기존 저장 자료의 회복 시기에서 경계를 통과하는 차량 집단과 셀 평균의 변화가 어떻게 다른지 확인한다. 앞선 속도 모멘트 검사는 주로2220–2670초였으므로, 이후 회복 구간의 자료가 이미 캐시되어 있는지 먼저 확인한다. 새 상태를 늘리거나 전체 도시부 계수를 맞추기 전에 필요한 최소 원인을 좁힌다.
