## 수용량 상한보다 상태 예측의 문제

셀21–25의 저장된 1초 속도식을 분해했다. 합류 감속으로부터 실제로 모델에 들어간 합류율을 복원했고, 80개 30초 합류량과 일치했다. `min(보내는 유량, 하류 잔여 수용량)`으로 200개 30초 본선 통과량도 복원했다. 최대 오차는 각각 6.22e−15대, 2.14e−14대다.

네 자료 × 300초 × 5셀 = 6,000셀·초에서 하류 수용량 상한이 본선 방출을 제한한 경우는 **0회**다. 여기서 낮은 방출은 모델의 낮은 `rho*v*lanes`에 따른 것이다. 다른 구간·혼잡 상태에서도 수용 제약이 무의미하다는 뜻은 아니다. 셀20에는 실제 진출 분기10483이 있으므로 순수 본선 연속구간 검사는21–25로 한정했다.

## 합류량과 속도식의 균형을 구분

29 NC 셀21 후반300초 실제/예측 합류는66/70대, 본선 통과는523/410.15대다. 모델 평균속도는 약20.34km/h에 머문다. 1초 속도식의 평균 기여[km/h]는 relaxation −0.488, convection +0.099, anticipation +1.226, 합류 감속 −0.838로 거의 상쇄된다. 셀23·24도 유사하게 낮은 속도 주변에 머문다.

같은 시각의 자기 N/v·상류 속도·하류 밀도를 각각 실측으로 바꾸는 500회 스칼라 검사를 추가했다. 전부 모델 상태인100개 경우는 저장값을 최대7.11e−15km/h 오차로 재현했다. 실측 하류만 넣으면 셀21이 강하게 가속하지만, 모든 현재 상태를 실측으로 넣으면 다시 큰 감속이 생긴다. 잘못 전달된 밀도와 현재 상태에서의 식 균형을 모두 점검해야 한다.

이 혼합 상태들은 연속 궤적이나 자율 예측이 아니다. 합류율은 공통으로 저장된 순간 예측값을 사용했다. 비교용 다음30초 평균속도 변화는 개별 차량 가속도가 아니므로, 이 차이 자체를 계수 적합 목표로 사용하지 않았다.

## 제한된 후속 시험

다른 계수는 그대로 두고 셀21의 합류 감속만 절반으로 줄인 [자율750초 시험](../merge21_half/README.md)을 완료했다. 회복은 오히려 악화되어 채택하지 않았다. 특정 감속항 하나보다 연결된21–25 구간의 상태 균형이 중요하다.
