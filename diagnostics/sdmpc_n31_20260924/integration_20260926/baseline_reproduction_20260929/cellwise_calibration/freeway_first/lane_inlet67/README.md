# 재정체 누락의 유입·방출 분리 — 조건부 진단

2026-09-30. 이전 셀19–21 차로 후보가 재정체를 놓친 이유를 저장된 기록으로 분리했다. **상류 총 유입량만 맞춰도 문제가 해결되지는 않았다. 차로 비율만 따로 맞추는 방식도 목적지와 차로의 관계를 유지하지 못해 완전한 경계 정합 시험이 되지 못했다.** 이 결과를 계수 채택이나 자율 예측 통과로 사용하지 않는다.

## 실제 재고 축적은 언제 달라졌나

`../lane_accumulation67/summary.json`은 native5초 endpoint와 기각된 후보의1초 실제 수락 유량을 비교한다. 공간은 셀19, 세 차로다. native 차량 ID의 출입과 같은 셀 내 순 차로 이동을 구분했다. 링크2→10613의 차로2/3/4→1/2/3 재매핑을 적용했다. 공간 경계를 지나는 동안 차로도 바뀐 경우는 별도 불확실성으로 남겼다.5초 사이 복수 차로 변경 총량을 관측했다고 주장하지 않는다.

같은 창의 모든 차로 유입은 실측304대, 후보278.87대이고,1차로 비율은34.21%와29.82%다. 따라서 총유량과 차로 분배가 모두 어긋나 있었다. VSL90 상태에서는 실측1차로 재고가6→21대인데 후보는8.36→9.33대로 두 조건을 모두 평탄하게 예측했다.

3,240개 native/model lane-step와36개150초 집계의 재고식이 닫혔다. 셀19의 native 미해명 출입은 없었다. 모델의 순 차로 이동은 보존된 재고와 수락된 종방향 유량의 잔차로 계산했으며 독립 실측 횟수와 혼동하지 않는다.

## 실제로 실행한 조건부 계산

기각된 `joint_lane_fifo` 소스를 일시 복원해 아래4개450초 예측과1개 기준 재현을 실행했다. 기존 계수·이동률·RM/VSL 명령을 바꾸지 않았다. 완료 후 core4개는 다시 원래 바이트로 복원했다.

1. **총 유량만 정합:** 실제 셀18→19 통과량을5초 창별로 공급하고, 한 창의 양을 다섯1초 step에 균등 배분한다. 목적지별 차로 비율은 기존 후보의 현재 상태 기반 비율을 유지한다.
2. **총 유량+endpoint 차로 비율:** 같은 총량에 실제 도착 endpoint 차로 비율도 사용한다. 다만 미래의 목적지별 차로 공동 분포를 관측한 것이 아니므로, 모든 예측 목적지 class에 같은 차로 비율을 적용한다. 이 불완전한 조건부 가정은 결과 해석에 명시적으로 제한을 둔다.

이것은 **미래 실측 경계를 쓰는 원인 분리**다. 자율 예측, 제어기 입력, 전체 Ω 손익 검증 또는 실제 VSL의 인과 효과 추정이 아니다. 예측 상태·속도를 미래 관측으로 리셋하지 않았다. 차량·경로 보존과 차로 수용공간은 유지했고, 수용하지 못한 차량은 상류에 남는다.

공동 분포를 유지하지 않고 모든 목적지 class를 같은 차로 비율로 넣으면, 진출행이 접근 불가능한 차로에 쌓이는 등 원래 후보와 다른 경계 혼합이 발생한다. 이 문제와 실제 속도식 오차를 이번 둘째 조건만으로 분리할 수 없다. 저장공간 제한을 해제하거나 차량을 삭제해 입력을 강제로 맞추지 않았다.

## 다음 판단의 범위

이번 결과는 계수를 더 크게 조정할 근거가 아니다. 필요한 다음 구분은 **목적지×차로별 유입과 방출의 공동 동역학**이다. 총유량 또는 차로별 주변 비율만 각각 맞추면 충분하다고 가정하지 않는다. 기존 native 사건·현재 경로 재고에서 공동 분포를 얼마나 식별할 수 있는지 확인한 뒤, 제한적으로 지역 모델을 수정할지 단순한 집계 모델을 유지할지 판단해야 한다.

셀18의 종료 차로가 모든 혼잡의 원인이라고 확정하지도 않는다. 현재 seed67 초기 관측에서 셀18 1차로는 비어 있었고, 마지막150초 해당 차로의 평균 재고는 두 조건 모두0.7대였다. 주된 속도 차이는 통과 가능한2차로와 그 하류 셀19 1차로에 나타났다. 기하에 lane drop이 있다는 사실만으로 임의의 추가 용량 손실을 넣지 않는다.

전체 망·도시부 계수, 목적함수, SDMPC는 이번에 바꾸지 않았다. 실제9000초 런의 자격 검증은 여전히 미완료다.
