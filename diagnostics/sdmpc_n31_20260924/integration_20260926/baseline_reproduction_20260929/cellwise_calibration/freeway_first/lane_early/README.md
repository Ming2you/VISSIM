# 초기 VSL 반응에서 기존 차로 후보 재검증

2026-09-30. **두 후보 모두 기각, 현재 코어 복원.** 이번에는 새 계수를 맞추지 않고, 이미 만든 차로19–25 후보와 그 후보에 회복부24·25 공통 보정을 붙인 모델을 확인했다. seed29·43 NC/VSL을 각각750초 예측했고, 비활성 기준 재현1회를 포함해9회 완료했다. 새 FZP 읽기와 VISSIM 실행은 없다.

사용자가 요청한 expanded036 seed29 SDMPC9000은 별도 동결본에서 실행 중이다. 이 진단은 현재 작업본에 보존된 후보만 사용했으며 실행 중인 모델을 변경하지 않았다.

## 제어 반응

VSL−NC의 동측 본선31셀 ΔTTT[veh·h], 음수는 감소. 전체 본선은 기존30초 집계, 초기 차량 집단은5초 집계다. 두 집계의 절대값을 직접 차감하지 않는다.

seed43의 전체 손해 방향은 맞췄지만, seed29의 확인된 이득을 손해로 뒤집었다. 신규 입력량 차이를 제거한 공통 초기 차량 집단에서도 같은 문제가 남는다. 초기 차량은 첫 본선 유출까지 세고 재진입은 신규 램프 집단으로 분류했다. 미래 차량 분류는 평가에만 썼으며 자율 예측 입력에 넣지 않았다.

## 무제어 상태도 나빠졌다

- seed29 속도:19.37→25.44→24.49km/h; 재고:11.99→20.32→19.40대; 유량:1179.65→2062.44→1963.05대/h.

따라서 작은 부호 하나 때문에 탈락시킨 것이 아니다. 확인된 큰 이득을 잃고 기본 혼잡/방출 예측까지 악화했다. 단순히 차로 상태를 더 자세히 나누거나24·25만 회복 보정하는 것이 이번 모델의 해결책은 아니었다. 이 결과가 차로 영향 자체가 없다는 증거는 아니다. 기존 집계 모델의 계수와 고정 차로 이동률을 사용한 이 두 구체적인 후보가 실패한 것이다.

## 검증과 다음 판단

기존 네 코어를 임시 복원해 후보를 실행한 뒤 원래 바이트로 되돌렸다. verification.json에서6,200개 셀 보존식과1,400개 차로→셀 재고/속도 합산을 독립 대조했다. 최대 잔차는 각각2.665e−13대와1.756e−12이다. 비활성 기준의 cells/flows/ports/ramps는 저장 결과와 정확히 같다. 실패 후보를 정본이나 실행 중인 SDMPC에 적용하지 않았다.

새 후보 격자나 추가 RM 사례를 이 실패 모델에 붙이지 않는다. 다음 작업에서는 현재 expanded036의 보존된 이득 반응을 유지하면서, 초기 상태·경계 유입·실제 합류와 병목 방출 오차를 구분한다. 특히 큰 순비용 차이에 신규 유입 집단이 크게 기여한다는 cohort_early 결과를 보정 목표에 반영한다. 실행 중인9000초 런의 결과는 종료와 native 기록 검증 뒤 판단한다. 전체 목표는 ACTIVE/NOT_QUALIFIED다.
