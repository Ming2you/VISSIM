# 차로 모델의 제한적 지역 계수 재보정 — 채택하지 않음

2026-09-30.19회450초 계산 완료, 약72.7초. 기존 관측·완료 런만 사용했다. 정본 소스는 원래 바이트로 복원했다.

시험 전에 후보를 세 개로 고정했다: 셀19–21 FD 형상계수×1.5, 셀21 합류 감속계수×0.5, 둘의 조합. 임계밀도·이완·anticipation·차로 이동률·수요·실행 명령은 유지했다. 제어별 보너스나 미래 관측은 없다. FD 형상 변화는 모든 명령에 동일하게 적용되며 유량 변화도 평가했다.

seed29 후기4조건에서 국소 N/속도/유량과 mainline/component ΔTTT 오차를 함께 평가하고 합류계수 절반 후보를 선정했다. 그 뒤에 값을 고정해 seed67 네 조건과 seed29 초기NC를 평가했다. 두 자료 모두 앞서 보았으므로 미공개 holdout으로 주장하지 않는다.

- 지역 상태 제곱오차 점수는 seed29 **7.8%**, seed67 **11.0%** 줄었다. 이것은 TTT 성능 개선율이 아니다.
- seed67 RM 완화 손실은 동측 본선 실측+8.629 차량·시간 /예측+7.724로 방향을 유지했다.
- 중요한 VSL 추가 효과는 실측 **−1.492**, 예측 **+0.0647**로 여전히 실패했다. 램프·진출 connector를 포함해도 실측−1.633 /예측+0.0682였다.
- 초기NC에서 지역 N·속도·유량 RMSE는 모두 약3–4% 악화했다. 형상 변경 두 후보는 학습 상태 점수부터 악화했다.

따라서 속도/재고 오차 일부 개선을 제어이득 재현으로 인정하지 않는다. 선언한 response 비악화 조건도 통과하지 않았다. grid나 셀별 자유도를 늘리지 않았다. 모델의 구조적 경계 문제를 별도 진단했다(../lane_dn67/README.md).

verification.json: 셀 보존8,835건, 차로 합산855건, config 실효값과 저장된 기준의 네 물리 표 정확 일치 확인. 초기 verifier의 .json.gz 이름 처리 오류는 예측과 무관했고 suffix 처리만 수정해 재검증했다. summary/selection/bindings/protocol과 config·manifest는 미채택 실험 자료다. 전체 Ω와 SDMPC/9000 검증은 미완료.
