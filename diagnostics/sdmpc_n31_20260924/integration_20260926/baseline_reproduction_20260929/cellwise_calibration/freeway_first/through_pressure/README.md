# 통과 경로 밀도와 합류 감속의 결합 시험 — 두 후보 기각

2026-09-30. 셀18의 진출 전용 차로 사용이 적고 셀21의 국소 감속이 강하다는 관측을 바탕으로, 자율 예측 후보 두 개를 실행했다. **둘 다 사전 기준을 통과하지 못해 정본에 반영하지 않았다.** 새 VISSIM·FZP 읽기·push는 없다.

## 무엇을 바꿨나

기준은 route036 + 현재 목적 경로 재고·동적 off-ramp 저장/배수다. seed29 무제어의 같은2220.1초 초기 상태에서750초를 예측했다. 운영 MPC 지평이나 수요를 변경한 실험이 아니다.

1. **pressure18:** 매1초 셀18의 기존 경로 재고에서10481로 나갈 차량을 뺀 나머지 재고로 통과 밀도를 계산했다. 통과 차로 수는 `min(3,현재 유효 차로 수)`다. anticipation의 밀도차와 분모에 이 통과 밀도를 사용하도록 기존 속도식의 가상 하류 밀도만 변환했다. 실제 보존 밀도·FD 목표·유량 계산·기하·lane-drop 감속·램프 방출·대기는 유지했다.
2. **pressure18_merge21_23:** 위 후보에 셀21·23의 기존 merge 감속계수를 같은 비율로 낮췄다. 나머지 셀과 계수는 유지했다.

첫 후보의 변환은 다음 국소 가설이다. 논문의 공식이라고 주장하지 않는다.

`rho_through = N_continuing / (L × lambda_continuing)`

`rho_virtual = max(0, rho + (rho_down − rho_through) × (rho + kappa)/(rho_through + kappa))`

관측된 미래 차로 점유를 넣지 않는다. 현재 예측 경로 재고만 사용한다. 다만 경로가 차로를 완전히 결정하지는 않으며2차로는 본선과 진출이 공유하므로, 이 균질 통과 밀도 근사 자체가 검증 대상이다. 기존 anticipation 분기는 가상 밀도의 부호 관계를 사용한다. 실제 차량 수나 수용량을 추가하지 않는다.

## 합류 계수 적합의 한계

seed29 무제어2670.1–2970.1초의 캐시를 사용했다. 실측 현재 N·속도·상하류 상태와 실제5초 합류량에서 셀21·23의 식을 계산하고, 30초 평균 변화율20개에 공통 계수1개를 적합했다. 허용 배율은0.25–1, 기존값1에 대한 이차 사전항은 데이터 제곱합의10%였다. 제어 이득이나 seed67을 적합 목표로 쓰지 않았다.

그러나 무제약 적합값은 **−0.934**였다. 실제로 음의 감속을 사용하지는 않았으며 하한0.25를 적용했다. 이것을 물리 계수가0.25로 식별됐다고 해석하면 안 된다. 나머지 항의 잔차, 상태·공간 평균 근사 및 시간 연산자 차이를 merge 계수 하나로 설명하려는 적합의 한계다. 조건부 RMSE도8.605→6.803km/h/초로 일부 감소할 뿐이었다.

## 자율 예측 결과

사전 기준은 셀15–25의 N·속도·30초 방출 정규화 손실에 대해 후반300초10% 이상 개선, 앞선450초 악화10% 이내, 전체 속도 RMSE 악화2km/h 이내였다. 통과할 때만 제어·다른 상태 검증을 추가하기로 했다.

| 후보 | 앞선450초 손실 | 후반300초 손실 | 본선 TTT [veh·h] | 진출+말단 유출 [대] |
|---|---:|---:|---:|---:|
| 기준 | 0.7720 | 3.1102 | 223.262 | 1902.21 |
| 통과 밀도만 | 0.9694 | 4.0904 | 226.602 | 1853.24 |
| 통과 밀도+합류 계수 | 1.2608 | 2.1653 | 208.728 | 2062.24 |
| 실측 | — | — | 212.046 | 2106 |

통과 밀도만 바꾸면 초반 셀18이 빨라지지만, 하류21·23이 더 막혀 후기 방출이 나빠졌다. 결합 후보는 후기 손실을 약30.4% 줄이고 총 유출도 실측에 가까워졌으나, 초반 손실이 약63.3% 증가했다. 총 TTT가 가까워진 것만으로 채택하지 않았다.

따라서 추가 RM/VSL·다른 seed 검증은 실행하지 않았다. 후보의 제어 이득 재현 여부는 **미검증**이다. 이번 결과는 진출 차로 문제나 merge 반응이 중요하지 않다는 증명도 아니다. 이 두 국소 근사만으로 연결된 본선 동역학을 해결하지 못했다는 결과다.

## 실행·보존

- 고유 자율 예측3회: 기준1회, 후보2회. 최대14회 예산은 기준 단계에서 종료했다.
- 기준의 저장된 cells/flows/ports/ramps는 기존750초 결과와 정확히 같다.
- 최초 비교는 메모리 객체와 JSON 표현을 직접 비교해 중단됐다. 저장 배열이 모두 같은 것을 확인하고 기준을 재실행하지 않은 채 재사용했다. 실패와 두 실행 소스를 보존했다.
- 후보의 압력 hook은 각각750개 실제1초 갱신에 적용됐고 가상 밀도 하한 clipping은0회였다.
- 본선 및 램프·진출 보존, 음수 밀도·jam 초과 검사를 통과했다. 기존 core 파일은 편집하지 않았고 모든 임시 관측/후보 hook은 종료 시 복원했다.
- 기존9000STOP과 입력 pin을 유지했다. 운영 설정·목적함수는 변경하지 않았다.

`fit.json`, `selection.json`, `summary.json`, `spatial_response.json`, `verification.json` 및 실행 helper가 근거다. 같은 phi·nu·delta 크기 탐색을 반복하지 않는다. 다음 구조 검토는 길이가 다른 셀 사이의 속도·밀도 경사 거리이며, 기존 거리 감사는 있었지만 중심 간 거리로 바꾼 예측은 아직 검증하지 않았다. 이것도 현재 확정된 버그나 해결책은 아니다. 전체 Ω 및 SDMPC9000 목표는 미완료다.
