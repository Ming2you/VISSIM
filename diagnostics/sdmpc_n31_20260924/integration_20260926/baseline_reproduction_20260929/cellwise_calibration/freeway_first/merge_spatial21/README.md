# 10490 합류 감속의 공간 배분 후보 — 미채택

2026-10-01. 새 계수 적합 없이 고정 후보 하나를 7회 자율 예측으로 확인했다. 기본 동등성1회 + 비교6회, 순 예측 10.271초. 새 VISSIM·FZP 재스캔은 없고, 추가8조건 확인은 첫 비교에서 개선 기준을 통과하지 않아 실행하지 않았다.

## 변경한 내용

10490의 실제 합류 위치7243.086m와 셀20/21 중심7141.695/7288.104m로 선형 공간 가중치를 정했다. 기존 합류 감속의 원천량 δ·Δt·실제 합류유량·합류셀 속도를 셀20에30.748%, 셀21에69.252% 배분하고 각 셀의 L·차로수·(밀도+κ)로 나눴다. source 원천량은 clip 전 보존된다. 이는 기하에 따른 하나의 근사 후보이며 문헌의 필수 식이나 실제 운동량 보존 법칙이라고 주장하지 않는다.

차량 주입은 실제 합류 셀21에 유지했다. 감속 계수·FD·수용 유량·다른7개 램프·신호·VSL 명령은 바꾸지 않았다. 기존 동적 off-ramp 저장/배수와 경로별 재고, 램프 대기 및 실제 합류 장부도 유지했다. native 미래 관측은 점수 계산에만 사용했다.

## 실행 검증과 복원

공간 배분을 끈750초 예측은 저장된 기준 cells/flows/ports/ramps와 정확히 같았다. 단위 검사에서 identity 배분, 합류0일 때 감속0, 원천량 보존 및7개 잘못된 가중치 거부를 확인했다. 자율 예측의 on/off 저장 보존 잔차 최대는8.53e-13대였다.

area_freeway_accounting.py와 replay_congested_component.py의 이번 변경은 검증 후 이전 바이트로 정확히 복원했다. 기존 dirty worktree의 이전 수정은 보존했다. 실행한 코드와 결과는core_executed.py.txt/helper_executed.py.txt 및 각json.gz에 남겼다. 실행 전 출처 핀을 확인했고, 복원 시 외부 수정이 없다는 byte 비교를 먼저 통과했다. 운영 코드에 미채택 옵션이나 새 adapter를 남기지 않았다.

원래 ALINEA+VSL 네 조건을 물리 반응 기준으로 유지한다. 이 본선 부분모델 결과는 전체 도시부·외부 대기·SDMPC 선택 검증이 아니므로 9000초 이득 검증 통과로 바꾸지 않는다. Goal ACTIVE / NOT_QUALIFIED, 기존 STOP·원격 저장소·다른 프로세스는 변경하지 않았다.
