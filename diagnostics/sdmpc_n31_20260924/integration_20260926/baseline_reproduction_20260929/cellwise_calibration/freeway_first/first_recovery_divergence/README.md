# 본선 회복 오차의 시작과 VSL 방출 반응 분리

2026-09-30. **회복 셀24·25에는 국소 오차가 있으나, 그 속도 오차만 없애도 VSL 방출 이득은 복원되지 않았다.** 정본 계수·동역학은 변경하지 않았다. 본선 우선 목표는 ACTIVE / NOT_QUALIFIED다.

## 저장된 예측 14개를 먼저 재사용

직전 face 후보/기존 모델의 seed29 여섯 조건씩 12개와 seed67 RM 완화±VSL의 조건부 결과 2개를 분석했다. 새 예측 없이 셀15–26의 매30초 유입·유출과 재고 오차를 대조했다. 모든 경우 초기 재고가 같은지 확인한 뒤, 다음 식으로 오차를 분해했다.

`재고 오차 = 초기 재고 오차 + 누적 유입 오차 − 누적 유출 오차`

초기 재고 168개, 이후 재고 장부 3,000개를 확인했다. 최대 항등식 잔차는 `1.933e-12`대였다. 이 범위에서 설명되지 않은 진입·차량 삭제는 없었다. native 전체망 셀30의 기존 미확인 소실 2건은 이 분석 구간 밖이며 정상 종료로 다시 분류하지 않았다.

24·25의 저속 편향은 첫30초부터 나타나지만, 23에서 10km/h 이상 저속 편향이 두 표본 연속 나타나는 시점은270초다. 이 기준은 발생 시점 정리를 위한 진단 기준이며 새 보정 합격 기준이 아니다. 30초보다 짧은 시간의 인과 순서는 확정하지 않는다.

seed67의 저장된 첫 속도 갱신도 셀24에서 FD 목표58.60km/h가 현재72.98km/h보다 낮아 relaxation이 감속을 만들고, convection도 감속을 만든다. 셀25 목표77.63km/h 역시 현재101.10km/h보다 낮다. 기존 connected-FD 보정은 이 절대 오차를 줄였지만 제어 반응 검증을 통과하지 못했으므로, 같은 임계밀도 그리드를 바로 반복하지 않았다.

## 셀24·25 속도 오차만 제거하는 조건부 진단

결과는 `../recovery_speed67/`에 저장했다. 기존 원인 분리 helper를 확장해 parity1회와 조건부2회, 총3개의450초 계산만 실행했다. 새 VISSIM이나 FZP 읽기는 없었다.

- seed67 RM 완화와 RM 완화+VSL90, 같은2670.1초 초기 상태.
- 기존 `b67`과 동일하게 실제 미래30초 source admissions 및5초 실제 합류량을 각 bin 안에 균등 배분했다. 미래 입력을 사용하는 원인 분리 조건이다.
- 추가로 셀24·25의 갱신 후 평균속도만 native5초 평균속도의 선형 보간값으로 바꿨다. 재고 N은 바꾸지 않았고 저장 유량은 `rho*v*lanes`로 일치시켰다.
- 경로별 재고, 동적 off-ramp 저장·배수·수용, VSL 노출 이력은 그대로 계산했다.
- 외부에서 속도 정보를 주입하므로 이는 구현할 모델이나 물리적으로 실행 가능한 제어가 아니다. **자율 예측·MPC 검증·이득 보정 성공에 포함하지 않는다.** 램프 도착·미터 대기 계산은 원래 조건부 경계 모드 밖이므로 Ω/전체 대기 포함 순이득도 주장하지 않는다.

## 다음 보정 범위에 미치는 영향

1. 회복부24·25의 절대 속도 편향은 실재하지만, 그 구간만 계속 빠르게 만들어 VSL 이득을 맞추는 접근은 근거가 부족하다.
2. VSL이 작용하는 앞쪽 병목의17–19 방출 반응과 합류·회복21–25를 연결해서 평가해야 한다. native는 VSL 적용 시18·19 통과량이 늘지만 모델은 반대로 본다.
3. 후속 후보는 이미 실패한 FD·anticipation·merge 공통 배율을 반복하기 전에, 병목의 제어별 유량·재고·속도 변화가 어떤 상태 표현에서 어긋나는지 기존 캐시로 구분해야 한다. 현재 자료를 본 뒤 같은 seed를 새 blind holdout으로 부르지 않는다.
4. 도시부 보정과 전체 SDMPC9000은 본선의 큰 손익·방출 반응 검증 후에 연결한다. 작은 속도 오차까지 완벽히 맞추는 것은 요구하지 않는다.

## 검증 및 보존

- 과거 source pin90개 및 핵심 소스5개 해시가 그대로다. `verification.json` 참조.
- 진단을 끈 경로의 cells/flows/ports는 저장된 자율 RM 완화 결과와 정확히 같다.
