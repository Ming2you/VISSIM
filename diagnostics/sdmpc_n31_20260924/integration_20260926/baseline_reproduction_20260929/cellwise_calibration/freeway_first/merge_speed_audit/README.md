# 합류 속도 출처 검증 — 고정 이동속도 연결만으로 해결되지 않음

2026-09-30. 기존 seed67 4조건에서8개 램프의3,170건 방출 사건을 확인했다. 미래 실측은 진단·채점에만 사용했고 새 VISSIM·FZP 읽기·예측·보정은 없다. **고정 posthead/connector 평균 이동속도는 혼잡한 램프의 합류 속도를 잘 대표하지 못했다.** 다만 현재 이 속도 혼합 기능은 OFF여서, 고정값의 오류가 현재 자율 예측의 직접 원인이라고 주장하지 않는다.

## 관측 정의를 먼저 확인

`PortObserver`의 departure.speed_kmh는 이전 프레임에서 본 램프 속도다. 사건 시각은 (t−5,t]이며 순간 합류 속도가 아니다. 별도 캐시에서 같은 차량ID의 첫 본선 관측을 짝지었다. 두 속도 사이에도 가감속·합류 상호작용이 들어가므로 실제 경계 속도의 엄밀한 상하한으로 쓰지 않는다.

seed67의 RM 완화 및 완화+VSL 두 조건에서 동측818대 전부 첫 본선 관측을 찾았다. 10484의 RM 완화 사건은 마지막 램프 관측이 출구에서 평균15.7m 전, 첫 본선 관측은 합류점에서 평균18.6m 후다. 정밀한 순간 속도로 보간하거나 기록이 없는 값을 생성하지 않았다.

2670.1–3120.1초 seed67, 단위km/h. '모델 고정값'은 기존 혼합 옵션을 켰을 때 사용하는 이동속도이며 현재 OFF다.

## 기존 식에 고정값을 단순 연결하면 생기는 문제

기존 식은 실제 허용 유량을 사용해 가상 상류속도를 `u=(q_main*v_up+r*v_ramp)/(q_main+r)`로 만든다. 이를 현재 관측 상태에 조건부로 대입해 기존 convection에 추가되는 양만 비교했다. 5초 유량은 프레임 경계 통과로 재구성했고120개30초 mainline 유량과 정확히 대조했다.

아래는 RM 완화450초90표본 평균의 **1초 속도식 기여[km/h]**다. 차량의 실제 가속도를 측정한 표가 아니다. 합류 손실은 현재 δ와 물리 차로 수, 실제5초 합류를 사용했다.

| 셀/램프 | 고정값 연결의 추가 convection | 마지막 램프 속도 사용 | 첫 본선 속도 사용 | 현재 명시적 merge 감속 |
|---|---:|---:|---:|---:|
|21 /10490|+0.123|−0.189|−0.162|−3.024|
|23 /10484|+0.171|−0.089|−0.073|−0.567|

고정값은 두 셀에서 가속을 추가하지만 실측 양끝 속도를 사용하면 감속이 추가된다. 따라서 고정값으로 기능을 켜서 평균속도가 높아졌다는 이유로 물리 보정에 성공했다고 판정할 수 없다. 반대로 실측 속도의 추가 감속 규모만으로 현재 셀21의 강한 감속과 회복 오차가 해결된다는 근거도 없다. 실제 경계 속도와 공간 평균속도·허용 유량을 혼용하지 않아야 한다.

이번은 국소 조건부 진단이다. 실측 속도·미래 합류량을 자율 예측 입력에 넣지 않았고, δ를0으로 바꾸거나 합류 감속을 혼합식으로 임의 대체하지 않았다. RM/VSL 이득 재현 통과로 세지 않는다.

## 결론과 다음 범위

1. 기존 속도 가중식은 이미 존재하며 이전 모델에서18회 시험 후 미채택됐다. 현재 계수로 같은 고정속도 시험을 반복하지 않는다.
2. 여행시간용 자유 이동속도와 혼잡 중 본선으로 들어오는 속도를 구분해야 한다. 모든 램프 이동속도를25km/h로 낮추는 보정은 유지 조건과 대기 비용을 망가뜨릴 수 있어 하지 않는다.
3. 다음에는 기존 속도 모멘트/차로 관측을 재사용해 합류 차량 유입에 따른 평균속도 변화와 본선 잔류 차량의 가감속·차로별 구성 변화를 분리한다. 이미 했던 평균 가속도·전체 모멘트 검사를 반복하지 않고, 명시적 merge 감속이 대신 설명하고 있는 잔차의 위치를 좁힌다. 관측 전후 구성이 달라지는 효과를 모두 합류 마찰의 인과 효과로 해석하지 않는다.
4. 자율적으로 계산할 수 있는 상태·항의 근거가 확보된 뒤 소수 후보만 검토한다. 전체 망 보정이나9000초 실행으로 건너뛰지 않는다.
