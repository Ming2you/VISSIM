# 목적지×차로 유입 진단

2026-09-30. 이전에 완료한2개450초 예측의 계측을 검증했다. 차량을 재분류하거나 제어·물리를 바꾸지 않은 계측이며, 저장된 후보의 cells/flows/ports/ramps가 정확히 일치한다.

첫300초 셀19 유입에서 이후10483 진출이 확인된 차량은 모두1차로였다. 원래 후보도 그 목적지–차로 관계를 유지했다. 따라서 앞선 모든 목적지에 동일한 주변 차로 비율을 주입한 lane_inlet67의 total_and_lanes 시험은 이 결합관계를 깨뜨린 진단이었다. 이를 완전한 경계 정합이나 속도계수의 잘못으로 해석하지 않는다.

전체450초는 release761대 중48대, VSL800대 중56대의 향후 경로가 미확정이다. 첫300초는 전부 확인되어 그 범위만 후속 조건부 실험에 사용했다. 진출 확인과 하류 통과 확인의 관측 종료시각이 달라 전체450초 비율을 희망 목적지 수요로 쓰지 않는다. 사후 목적지 라벨은 실제 경계 진단용이며 MPC 입력이나 자율예측에 쓰지 않았다.

summary.json, native.json, 두 trace.json, verification.json과 helper_executed.txt가 근거다. 정본 core 복원 및 기존9000 STOP 해시 확인. 이득 검증 완료 아님.
