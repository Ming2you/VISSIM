# 본선 회복부의 가속·평균속도 조건부 진단

2026-09-30. 기존 검증된5초 차량 캐시만 재사용했다. 새VISSIM/FZP재읽기 없음. seed29·43 무제어2670.1–2970.1초, 셀21–25를600회 조건부 계산했다. 동결된 connected-FD가 기준이며, 자율 예측 검증과 구분한다.

## 확인된 오차

아래는 각60개 표본의 평균이며 단위는km/h/s다. `공간 평균 변화`는5초 차분, `차량 가속`은 해당 시점 셀 안 차량의 기록 가속도 평균이다. 서로 같은 물리량이 아니다. 모델은 매 표본에서 관측한 현재 셀·인접 셀 상태와 해당30초의 실제 합류량을 넣은1초 속도 갱신이다. 따라서 실제 미래 경계를 사용한 **원인 분리용 진단**이며 MPC 예측 결과가 아니다.

| seed / 셀 | 실제 공간 평균 변화 | 기록된 차량 가속 | 모델 공간 평균 변화 |
|---|---:|---:|---:|
|29 /21|−0.224|−0.299|−6.861|
|43 /21|−0.073|+1.388|−6.709|
|29 /24|+0.029|+2.914|−3.101|
|43 /24|−0.015|+2.812|−2.916|
|29 /25|+0.007|+0.522|−1.012|
|43 /25|−0.048|+0.464|−1.163|

셀24·25는 실제 인접 상태를 주어도 감속 편향이 남는다. 따라서 자율 예측의 상류 오차 전달만으로 설명되지 않는다. 셀21도 큰 국소 오차가 남으며, 이번24·25 후보로 이 합류 오차까지 해결했다고 주장하지 않는다.

셀24에서는 개별 차량이 가속하는 동안 느린 차량의 유입으로 평균속도가 거의 일정하게 유지된다. 모델의 convection와 나머지 항을 각각 실제 집단 교체·개별 가속과 동일시해 보정하지 않았다. 예를 들어29의 시작 차량 전체를5초 후까지 추적하면 평균 속도 변화율은+2.438, 집단 교체 효과는−2.410이다. 이 전자는 이미 다음 셀에 들어간 이후의 가속도 포함하므로 셀24 내부 가속의 직접 측정값은 아니다.

600개 표본 모두 시작 차량 전체가 다음 본선 프레임에서 관측됐다. 잔류·진입·이탈 평균속도 항등식 및 시작 차량 집단을 사용하는 별도 분해를 확인했다.100개 기존30초 N/v 대조와300개 기존 자율예측 속도식 복원이 통과했고, 복원 최대오차는0이다. 코어·STOP 불변은후속 `../recovery_pair/verification.json`에서 함께 확인한다.

## 기존 계수 한 개의 제한된 지역 보정

셀24·25의 `downstream_lt_local` anticipation에 같은 배율을 적용했다. 다른 방향 anticipation·FD·합류항·수용 유량·램프 대기·off-ramp 동역학은 그대로다. seed29의20개 셀×30초 평균 속도 변화 잔차만으로 닫힌 형태의 최소제곱 해를 구했다. 배율은 **2.859774049618318**이다. seed43은 적합에 쓰지 않았으나 이전에 관찰한 상태이므로 완전히 새로운 blind holdout은 아니다.
