# 실측 현재 상태에서도 남는 본선 속도식 오차

2026-09-30. 이전 `flow67`은 실측 N·v/L에도 VSL 방출 증가 방향이 나타나지만 예측 상태에서는 사라지는 것을 확인했다. 이번에는 자기 셀과 이웃 상태를 따로 바꾸어, 전달된 오차와 국소 식의 반응을 구분했다.

## 범위와 검증

- seed67 RM 완화·VSL110 조건, 2670.1–3120.1초, 셀15–22.
- 90개 5초 시점×8셀×4조합 = 2,880회 스칼라 속도 갱신. 조합은 전부 예측 상태, 자기 N/v만 실측, 이웃 상태만 실측, 자기·이웃 모두 실측이다.
- 이웃 상태는 상류 속도와 하류 N이다. 상태를 바꿀 때 FD 목표속도와 anticipation 분기도 다시 계산한다.
- 같은 시각의 예측 유효 차로 수·lane-drop 상태 및 실측 5초 합류량을 모든 조합에 공통으로 썼다. 현재 off-ramp 재고를 실측으로 바꾸거나 전체 동역학을 다시 진행한 실험은 아니다.
- 예측 상태만 사용하는 720개 계산은 저장된 canonical 식의 최종 속도와 FD 목표를 최대 1.43e-14km/h 오차로 재현한다.
- 검증된 5초 캐시만 읽었다. 새 FZP 읽기·VISSIM·전체 rollout·계수 보정은 각각 0회다. 입력 및 core pin 20개가 불변이다.

VSL90 조건에서는 실제 차량별 과거 명령 노출과 예측 cohort가 다를 수 있다. 그 비율을 추정해 섞지 않기 위해 이번 국소 진단은 모든 명령이110인 조건에 한정했다.

## 실측 상태를 써도 셀18·21의 감속 편향이 남는다

아래 모델 수치는 90개 시점에서 계산한 **1초 속도 증가량의 평균**이다. 실측 비교 수치는 다음5초 **공간 평균속도 변화/5**다. 서로 다른 시간 연산자이며 개별 차량의 가속도 오차로 부르면 안 된다.

셀18의 항 평균은 relaxation +2.573, convection −0.529, anticipation −4.042, lane-drop −2.665km/h/초다. 셀21은 실제 합류를 넣을 때 합류 감속 약−3.024km/h/초가 큰 부분을 차지한다. 모든 항을 합친 최종 속도는 하한 clipping 없이 계산됐다.

실측 상태로 바꾸면 무조건 좋아지는 것은 아니다. 예측 상태는 이미 모델의 강한 감속에 맞춰 낮은 속도·다른 밀도 분포로 움직이며, 그래서 그 상태에서 평균 순변화가 작다고 해서 식이 맞다는 뜻은 아니다. 반대로 이 관측만으로 merge 계수를 줄여도 된다는 결론 역시 나오지 않는다. 주어진 합류량의 시간 분배와 모델의 유효 차로 상태를 공통으로 고정한 조건부 진단이다.

## 셀18의 밀도 평균에 차로 사용 차이가 섞여 있다

선택망 XML을 재확인했다. 본선 link2의2·3·4차로는10613을 통해 본선으로 이어지고, 진출10481은1·2차로에서 접근한다. 즉 **2차로는 공유이며, 1차로만 본선으로 이어지지 않는다.** 처음에 진출 연결이1차로뿐이라고 가정한 검사는 실패했다. 실제 XML에 맞게 바로잡았고 `lane_geometry_check.json`에 남겼다. 실행망이나 기존 결과를 바꾸지는 않았다.

셀18의 해당90개 프레임에서:

- 본선으로 이어지지 않는1차로의 재고 비율: **2.203%**.
- 전체4차로로 나눈 평균 밀도: **38.10대/km/차로**.
- 본선으로 이어지는2·3·4차로의 실제 차량만으로 계산한 밀도: **49.68대/km/차로**.
- 하류 셀19의 평균 밀도: **53.86대/km/차로**.

전체 평균끼리 비교한 차이는 약15.76이지만, 연속 차로끼리 비교하면 약4.18이다. 따라서 lane-drop 경계의 anticipation에 서로 다른 차로 사용을 평균낸 밀도가 들어가는 영향은 검토할 가치가 있다. 이것은 **보정식이 확정됐다는 뜻이 아니다.** 측정 차로 재고와 목적 경로 재고는 다르며, 공유2차로와 상류 차로 변경도 남아 있다.

표준 METANET 설명은 밀도차에 대한 anticipation과 합류·차로 감소 추가 감속을 구분한다. 다만 그 설명만으로 이 망의 전용 진출·공유 차로에 사용할 압력 보정식을 정당화할 수는 없다. [TU Delft 교재, 15장](https://ocw.tudelft.nl/wp-content/uploads/Reader_ct4821.pdf), [Zegeye 박사학위논문, 2장](https://web.dcsc.tudelft.nl/~bdeschutter/research/phd_theses/phd_zegeye_2011.pdf).

## 채택 판단과 다음 범위

이번에도 정본 계수는 바꾸지 않았다. 전체 phi를 낮추거나 셀18의 명목 lane-drop 감속만 없앤 이전 시험은 하류21·23의 방출을 악화시켰으므로 반복하지 않는다.

다음 후보를 만들기 전에, 현재 예측 경로 재고와 실제 연결 차로로 계산 가능한 본선 압력 표현을 검토해야 한다. 미래의 측정 차로 점유를 사용하거나 VSL/RM 명령에 보너스를 붙이면 안 된다. 셀18만 빨라진 뒤21에서 다시 막히는지 합류·회복 반응도 함께 보아야 한다. 새 보정이 필요하면 기존 학습29/43 자료에서 작은 공통 계수로 제한하고, 이미 검토한67을 새 후보의 미사용 독립 검증으로 부르지 않는다.

이 결과는 자율 예측·전체 Ω 이득·SDMPC 선택 검증이 아니다. 실제 목적함수, 램프 대기, off-ramp 저장·배수, 기존9000STOP은 유지했다. `rows.json`, `summary.json`, `verification.json`, `lane_density.json`과 실행 소스를 보존했다. 전체 목표는 미완료다.
