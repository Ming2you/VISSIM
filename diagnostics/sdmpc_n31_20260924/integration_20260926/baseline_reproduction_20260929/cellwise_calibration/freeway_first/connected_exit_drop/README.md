# 하류 FD 보정과 진출부 차로 감속의 결합 시험 — 2026-09-30

판정: **기각, 정본 미반영**. 완료된 오프라인 예측 7개를 정리했다. 새 VISSIM 실행·FZP 재읽기·추가 계수 적합·push는 없다.

## 시험 범위

`../connected_fd/review/candidate_manifest.json`의 동결된 FD 후보에, 셀18 진출부의 명목 1개 차로 감소에 따른 추가 속도 감속만 제거했다. 이 FD 후보 자체도 이전 제어 반응 검증을 통과하지 못했으므로 이번 조합은 진단용이다. 물리 차로 수, 보존식, 실제 수용 계산, 동적 off-ramp 저장 및 추가 차로 손실은 유지했다. 셀15–25의 회복과 연결된 방출을 평가했다.

7개 예측은 비활성 기준 1개, seed29·43 NC/VSL 각 750초, seed61 RM 유지/완화 각 450초다. seed43·61은 이번 시험에 적합하지 않았지만 이전에 검토한 자료이며, 처음 보는 검증 자료라고 부르지 않는다. NC 검증 실패 후 다른 조건도 원인 비교 목적으로만 확인했다.

## 결과

본선 ΔTTT 단위는 veh·h이며 음수는 기준 대비 감소다. VSL은 같은 seed의 NC 대비, RM 완화는 같은 seed의 유지 대비다.

| 비교 | 실제 본선 ΔTTT | 후보 예측 |
| --- | ---: | ---: |
| seed29 VSL, 750초 | -3.567 | -2.324 |
| seed43 VSL, 750초 | +3.704 | -2.927 |
| seed61 RM 완화, 450초 | +7.967 | +9.703 |

NC의 초기·후반 구간 검증 모두 실패했다(`selection.json`). seed43의 VSL 손익 방향이 여전히 반대이고, 셀19 누적 방출 변화도 실측 +6대에 비해 예측 +36.224대로 크다. seed61 RM 완화의 누적 출구 유출 감소는 실측 -51대에 비해 예측 -116.013대로 과대하다. 단순히 진출부 감속을 제거하는 조합으로 회복과 제어 반응을 함께 해결하지 못했다. 이것만으로 기존 명목 차로 감속이 물리적으로 옳다고 확정하지 않는다.

`paired.json`의 `ttt`는 동측 본선+4개 on-ramp+4개 off-ramp connector의 부분망 비용이다. 전체 Ω 비용이나 SDMPC의 최종 성능으로 해석하지 않는다.

## 보존과 재현

비활성 후보는 cells/flows/ports/ramps 배열이 기존 기준과 정확히 일치했다. 실행 당시 소스는 `executed/`, 이전 소스는 `before/`에 보존했다. 시험용 두 core 파일은 이전 바이트로 정확히 복원했다. `verification.json`에 소스 해시, 67개 기존 helper 함수의 AST 동일성, 기존 9000초 STOP 유지 및 종료 코드가 있다. 현재 helper만 실행해서 당시 core를 쓴 시험을 재현했다고 판단하면 안 된다.

## 다음 작업의 우선순위

사용자 지시에 따라 freeway 동역학 검증을 먼저 마친다. 도시부 전체 보정과 SDMPC 재탐색으로 범위를 넓히지 않는다.

1. 동측 31셀의 합류량 → 병목 방출·재고 → 혼잡 전파·회복을 NC/RM/VSL/both로 비교한다. 셀18–19의 VSL 방출 과대반응과 셀21–25의 연결된 회복을 구분한다.
2. 원인 분리 단계에서는 실제 경계 유량을 조건으로 줄 수 있지만, 미래 실측을 쓰는 결과는 조건부 진단으로만 표시한다. 채택 여부는 현재 상태·과거 관측으로 시작한 자율 예측에서 확인한다.
3. 큰 본선 손익과 후보 순위가 안정되면 freeway 계수를 동결한다. 램프 대기·off-ramp 저장/배수는 계속 보존하며, 다음 단계에서 도시부 도착·신호와 연결해 전체 Ω TTT를 검증한다.
4. 미세한 속도 오차나 작은 손익 부호를 모두 맞추기 위한 동일 계수 탐색은 반복하지 않는다. 본선 이득 재현과 전체망 순이득 검증은 별도 단계다.

현재 목표는 ACTIVE / NOT_QUALIFIED이며, 이 실패 시험을 근거로 9000초 SDMPC 실행으로 넘어가지 않는다.
