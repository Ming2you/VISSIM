# 셀23 회복 anticipation 시험 및 단일 계수 재보정

2026-09-30. **새 정본 후보를 채택하지 않았다.** 이번에51개 오프라인 예측을 완료했다: 고정 후보15개, 제한된 재보정36개. 기존 양 끝값의 학습 조건12개는 재사용했다. 새 VISSIM/FZP 추출/push는 없다. 네 core 파일과 기존9000초 STOP은 그대로다.

## 왜 이 계수를 확인했나

이전 source 교차 및 하류 밀도 전달 진단은 셀21의 잘못된 밀도가 상류 회복을 오래 막을 수 있음을 보여줬다. 기존 실행의 셀23은 후반300초 내내 하류 밀도가 더 낮았는데, 회복 방향 anticipation 계수는4.644838, 같은 셀의 반대 방향은18.375였다. 인접 회복 계수는 약15.7–23.7이었다. 기존 속도식 항의 상쇄를 확인하고, 새로운 보상항 대신 이 기존 계수 하나를 시험했다.

모델 속도식이 relaxation·convection·anticipation을 별도 항으로 표현한다는 문헌 구조도 다시 확인했다([Frejo 등의 논문, 식2](https://www.dcsc.tudelft.nl/~bdeschutter/pub/rep/19_022.pdf)). 이 구조 자체가 이번 계수의 수치나 제어 이득을 보장하지는 않는다.

기준은 동결된 `../connected_fd/review/candidate_manifest.json`이다. 이 FD 후보는 이전 반응 검증 실패 상태이며, 이번 시험이 그 실패를 자동 해제하지 않는다. cell23의 `anticipation.downstream_lt_local`만 바꾸고 FD·합류 감속·유량·재고·경계 입력·VSL 이력·off-ramp 저장/배수·대기 비용은 유지했다. 모든 rollout 입력은 현재/과거 정보에서 왔다.

## 1. 회복 계수를18.375로 맞춘 고정 후보

무제어750초 셀21–25 N/v/유량 오차는 처음450초0.51616→0.47349, 이후300초1.09145→0.56679로 줄었다. NC 기준을 통과했기 때문에 미리 정한 다른 상태·제어까지 계산했다. 비활성 기준의 cells/flows/ports/ramps는 기존 결과와 정확히 같다.

하지만 제어 반응은 통과하지 못했다. 아래 비용 단위는veh·h이며, 초기 VSL은 NC 대비750초, 후기 RM 완화는 유지 대비450초다.

## 2. 두 값 사이를 제한적으로 재보정

동일한 기존 보정 손실을 유지했다. 셀21–25와 전체31셀의 N/v/유량 상태 오차, 제어에 따른 N·누적유량·본선 ΔTTT 오차를 함께 평가했다. seed29 초기 NC/VSL750초, RM/both450초, 후기 유지/완화450초의6조건만 학습에 썼다. seed43·61로 계수를 맞추지 않았다.

- 탐색 변수는 셀23 회복 계수 하나, 범위4.644838–18.375.
- 양 끝값12개 예측은 재사용하고, 내부6개 값×6조건=36회만 새로 계산했다.
- SciPy bounded scalar의 nfev6 예산 종료다. 수렴했다고 주장하지 않는다.
- cached 기존 계수의 전체 손실이 이전 connected-FD 결과와1e-10 이내로 일치했다.
- 상태만 개선하고 제어 반응을 악화하는 후보를 채택하지 않도록, 기존 기준과 보정 전 expanded036 반응 손실 기준을 함께 유지했다.

| 후보 | 상태 손실 | 제어 반응 손실 | 합계 |
| --- | ---: | ---: | ---: |
| 기존4.644838 | 0.66787 | 0.52532 | 1.19318 |
| 내부 최저5.409994 | 0.59829 | 0.67050 | 1.26878 |
| 강한 회복18.375 | 0.63761 | 2.86177 | 3.49937 |

새 내부값 중 가장 나은5.409994도 종합 손실이 기존보다 약6.34% 컸다. 최선은 기존 계수 그대로였고, 새로운5% 개선 기준을 충족하지 못했다. 기존 FD 후보가 실패한 보정 전 반응 기준도 여전히 실패했다. 따라서 추가 독립 검증은0회이며, 범위를 넓혀 같은 단일 계수 탐색을 반복하지 않는다.

## 해석과 남은 일

이번 자료는 **회복을 일률적으로 강화하면 무제어 속도·재고는 개선할 수 있지만 RM/VSL의 이득 구조까지 함께 맞아지지는 않는다**는 제한된 결론을 준다. 특정 셀 보정 자체가 불가능하다거나 anticipation 수정 전체가 무효라는 뜻은 아니다.

다음에는21–25에서 실제 차량의 가속·유입/유출에 의한 구성 변화와 모델의 공간 평균속도 갱신을 구분해야 한다. 기존5초 차량·가속도 캐시를 우선 재사용한다. 같은 단일 nu/merge/phi 그리드를 더 촘촘히 탐색하거나, 도시부 계수로 본선 오차를 상쇄하지 않는다. 임의 VSL/RM 보상·용량 보너스·미래 관측 주입은 채택하지 않는다.

실행9426·5848 모두 종료코드0.51개 새 예측의 invalid·차량보존 검사, 소스/STOP 불변, 기존68개 다른 helper 함수 AST 불변을 확인했다. 당시 helper는 `executed/helper.txt` 및 `../recovery23_fit/helper_executed.txt`에 보존했다. `verification.json`, `../recovery23_fit/comparison.json` 참조. 목표 ACTIVE / NOT_QUALIFIED; fullΩ·SDMPC9000 검증은 아직 남아 있다.
