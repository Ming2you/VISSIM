# 현재 경로 재고를 사용한 초기 상태 검증 — 2026-09-30

판정: 일부 물리 정합은 개선됐지만 채택·전체 망 이득 검증은 미완료다. 사용자 우선순위는 **freeway 역학 검증 → 램프·도시부 비용 결합 → SDMPC 선택 검증**이다. 정확한 속도 궤적보다 큰 손익 방향과 제어 후보 순위를 우선한다.

## 완료 범위

- 기존 완료 VISSIM 자료의 현재 2220.1초 스냅샷을 사용한 450초 예측. seed29는 기준 재현 1회+경로 재고 후보 4회, seed43은 기준 재현 1회+고정 분기 저장 모델 4회+경로 재고 후보 4회로 총 14회.
- 새 native 런 0회, 재보정 0회, 미래 실측 입력 없음. expanded_joint/eval_036 계수 고정. 미래 합류·분기량을 입력하는 조건부 진단과 구분한다.
- 기존 canonical_harness의 명시적 offramp_inventory 입력과 unchanged offramp_routing을 사용했다. 새 adapter 없음. helper의 기존 run_route_inventory_response만 case를 받도록 일반화했으며 다른 함수와 모델 코어는 이번 초기 상태 검증에서 변경하지 않았다.
- 실행 .inpx는 선택망과 seed만 다름을 바이트 정규화로 확인했다. 재사용 관측 캐시의 과거 geometry network SHA는 실행망 증거로 사용하지 않았다.
- 초기 동측 31셀 N/v가 네 명령의 저장 입력과 일치했다. 알려진 목적지와 현재 경로가 없는 차량을 구분하고, 미래 차량 기록을 초기값에 남기지 않았다.
- seed43은 이번 후보 계수 학습에 쓰지 않았지만 이전에 검토한 개발·검증 자료이므로 독립적인 블라인드 검증이라고 부르지 않는다. seed61은 재보정·선정에 사용하지 않았다.

## 본선 ΔTTT

단위 대·시간, 같은 초기 상태의 NC 대비. 동측 31셀 본선 범위이며 전체 Ω 이득과 구분한다.

| seed29 초기 | RM | -1.0000 | -0.2492 |
| seed29 초기 | 둘 다 | -1.1000 | -0.6708 |
| seed43 초기 | VSL | +0.7625 | -0.2922 |

기존 late29까지 3상태에서 실측 비용 차이 절댓값 0.5대·시간 이상인 후보쌍 14개 중 11개의 방향을 맞췄다. 본선 및 본선+8개 connector 비용 모두 같은 3쌍을 틀렸다. 초기29 RM 대 VSL 순위, 초기43 NC 대 VSL 손익, 초기43 RM 대 VSL 순위다.

네 후보를 모두 허용했을 때 최선 선택은 초기29 both, 초기43 both, late29 hold였다. 초기43 본선 실측 최선은 RM이며 선택 후회는 0.0667대·시간, connector 포함 최선은 both였다. 그러나 RM과 VSL 사이의 유의한 순위 오류가 남으므로 이것만으로 검증 통과라고 판단하지 않는다. 제약으로 both를 선택할 수 없으면 잘못된 단독 레버를 고를 수 있다.

## 경계 유량과 TTT의 관계

30초 유량과 잔여 지평 가중치로 계산한 차량 보존 항등식은 ΔTTT와 일치한다. **인과 효과 분해나 동일 유입 반사실 실험은 아니다.**

- 초기29 RM: 실측 source +0.0708, merge -0.3875, off -0.4208, terminal -0.2625 = -1.0000. 예측은 source 0, merge -0.1746, off -0.0396, terminal -0.0350 = -0.2492. 실제 합류 감소뿐 아니라 방출 반응도 작게 예측한다. 누적 정상 유출 증가 실측 +22대 대비 예측 +2.79대다.
- 초기43 RM: 실측 source -1.5917, merge +0.0667, off +0.0875, terminal +0.2375 = -1.2000. 본선 진입량 감소 항이 지배하므로 전부 방출 개선으로 보정하면 안 된다. source 차이가 확률적 생성 때문인지 상류 동역학 때문인지는 미분리다.
- 초기43 VSL: 실측 source +0.5000을 포함한 총 +0.7625 대비 예측 -0.2922. 실측 source 항을 단순 차감한 값을 제어 인과 효과로 간주하지 않는다.

## 검증·한계

- 기준 재현은 cells/flows/ports/ramps 전체 일치. 소스 고정 확인 통과. 본선 보존 오차 최대 2.85e-14, 목적지 분할 오차 1.14e-12, connector 보존 오차 1.11e-12 이내.
- 초기29 속도 projection 0회/명령, 초기43 2회/명령. projection 횟수만으로 수치 실패라고 단정하지 않는다. 실제 기록은 각 completion.json에 보존했다.
- 경로 재고+관측 유입 proxy 후보는 이전 late29에서 악화했다. 현재 결과는 경로 재고+동적 저장 후보이며, 정본·SDMPC에 채택하지 않았다. 서측 경로 동역학은 검증하지 않았다.
- 기존 9000초 STOP 유지, push 없음. 이번 두 작업은 완료됐고 진행 중인 계산은 없다.

## 다음 순서

1. 본선 source, 실제 합류, off-ramp 저장·배수 경계를 명확히 유지하며 초기29의 합류 이후 방출 반응 부족과 초기43의 경계 차이를 분리한다. 현재 결과만으로 다음 대규모 계수 탐색을 시작하지 않는다.
2. 이미 확인한 큰 RM 손익 방향을 보존하고, 기존 자료의 혼잡 발생·전파·회복과 RM/VSL 순위를 함께 검증한다. 특히 회복 셀의 속도만 맞추는 보정은 채택하지 않는다.
3. 실측 미래 경계 고정은 원인 분리용으로만 사용한다. 채택 판정은 자율 예측과 미사용 상태·seed에서 수행한다.
4. 본선 판단이 안정되면 램프 및 도시부 대기와 연결해 Ω TTT로 검증하고, 그다음 SDMPC가 실행 가능한 유리한 후보를 선택하는지 확인한다. 대기는 모델에서 삭제하지 않으며 목적함수를 바꾸지 않는다.
