# 본선 상태 오차와 공간 평균 유량 근사의 분리

2026-09-30. 직전 `b67` 추적은 셀14–25에서 모델의 본선·진출 수용 상한이 450초 동안 직접 작동하지 않았음을 확인했다. 이번에는 완료된 seed67 RM 완화 / RM 완화+VSL90의 FZP를 읽어, 실제 상태로 계산한 공간 평균 유량에서도 VSL 반응이 나타나는지 확인했다. 새 VISSIM, 전체 예측, 계수 보정은 모두 0회다.

## 자료와 계산

2670.1–3120.1초, 조건별 5초 프레임 91개. 각 차량의 셀, 속도, 본선 좌표, 차로, 가속도, 희망속도를 작은 gzip 캐시로 남겼다. 이후 같은 창을 분석할 때 FZP를 다시 읽을 필요가 없다.

각 셀에서 `q_spatial = sum(vehicle speed) / cell length = N*v/L`을 계산하고 5초 사다리꼴 적분을 했다. 비교 대상은 같은 30초의 실제 하류 통과+off-ramp 진출량이다. 모델은 이전 관측 hook의 1초 q_spatial 및 실제 allocator 방출 기록을 재사용했다. 본선 하류 통과와 진출이 있는 셀에서는 두 유출을 반드시 합쳐 비교한다.

공간 평균 유량은 과도 상태에서 하류 경계 유량과 같을 필요가 없다. 따라서 적분값을 가상의 실제 방출이나 교정 목표로 대체하지 않는다. 셀의 앞쪽 절반만 사용한 값도 참고용으로 계산했으나 별도 유량 보정식으로 채택하지 않았다.

셀18의 실제 본선 하류 통과는 +39대이고 진출은 −1대이므로 표의 총 유출은 +38대다. 마지막150초에는 실제 총 유출 +47대, 실측 공간 평균 적분 약 +39.19대, 모델 약 +3.11대다. 실측 공간 평균과 경계 유량 간 차이는 남지만, 실측 상태에는 나타나는 방출 증가 방향 자체가 모델 상태에서 사라진다.

따라서 **공간 평균을 경계 유량으로 쓰는 근사만으로 현재 VSL 오차를 설명하기 어렵다.** 본선 속도·밀도 상태의 형성, 일시 회복, 재정체 반응을 먼저 확인하는 것이 타당하다. 숫자의 차이를 나눠 원인 기여율로 해석하거나, 이 결과만으로 특정 계수의 잘못을 확정하지 않았다.

## 검증과 실패 기록

- 두 파일의 과거 2700초 전 전체 데이터 행 해시가 기존 native 증거와 정확히 일치한다.
- 기존 30초 집계와 31셀×16시점×2조건 = 992개 N·평균속도 기록이 일치한다.
- 각 파일을 읽는 동안 크기·수정시각은 불변이다. 분석 입력 pin도 불변이다.
- 첫 파일의 첫 시도에서 운영 초기화용 엄격한 `_position` 검사가 마지막 셀 경계 밖 기록을 거부해 중단됐다. 완료된 추출은 없었고 실패와 당시 helper를 보존했다. 이는 성공한 2회 읽기 외에 부분 읽기 1회다.
- 좌표를 확인하니 맨 끝 셀30 경계를 최대 1.879m / 2.529m 넘는 기록이 각각 7행 / 13행 있었다. 기존 native 집계의 마지막 셀 포함 규칙으로 재현해 992개 집계를 검증했다. 대상 셀14–25의 결과에는 영향을 주지 않는다. 운영 모델의 좌표 검사나 기하를 바꾸지는 않았다. 전체 망 연결 전 종단 좌표 정합은 별도 확인할 항목으로 남긴다.

원시 FZP 파일 2개에 대해 실패 후 완전 읽기 각1회, 새 런 0회다. 실패는 `failure.json`, 원 실행/수정 실행 소스는 `helper_executed.txt` / `helper_resumed.txt`, 검증은 `verification.json`에 있다. 정상 완료 자료는 `summary.json`, `blocks.json`, 두 `*_frames.json.gz`다.

## 다음 범위

현재 정본 계수를 유지한다. 캐시에 있는 실제 현재 셀·상하류 상태에서 속도식의 국소 반응을 검사해, 셀15–22의 오차가 전달된 상태 때문인지 그 상태에서도 회복식이 틀리는지 구분한다. 근거가 생기면 기존 학습 상태에서 소수의 지역 공통 계수를 보정하고 자율 제어 반응을 검증한다. 이미 검토한 seed67은 새 후보의 미사용 독립 검증으로 부르지 않는다.

단순한 전체 phi 감소와 셀24·25 anticipation 증대는 앞선 비교에서 실패했다. 같은 탐색을 반복하거나 실제 VSL 이득에 맞춘 보상·capacity 보너스를 넣지 않는다. 동적 off-ramp 저장·배수, 램프 대기, 원래 Ω 목적함수는 유지하며 전체 망 보정·SDMPC9000은 아직 진행하지 않았다. 기존 STOP과 no-push를 유지한다.
