## 이전 보정과 다른 점

학습은 seed29 초기 NC/VSL750초·RM/both450초, 후기 RM유지/완화450초의6조건이다. 미래 실측을 예측 입력으로 사용하지 않았다. 초기750초 결과와450초 RM 비교는 동일450초 부분끼리 비용 차이를 계산했다. 비용은 동일한 동측31셀+4on/4off connector 장부로 보존하며, 본선 우선 보정의 손실에는 N/v/유량과 제어에 따른 N/누적유량/본선TTT 차이를 썼다. 이 보정 손실은 controller의 Ω 목적함수를 변경하지 않는다. 램프·진출 대기 비용은 모든 결과에 별도로 남겼다.

## FD와 실제 통과량의 정합성

현재 셀24의 균일 정상상태 FD 최대유량 `lambda*rho_crit*v_free*exp(-1/a)`는5,022대/h다. 실측 NC의2670.1–2970.1초 평균 통과량은 seed29에서6,876, seed43에서6,816대/h이며 각10개30초 구간 모두 이 FD 기준보다 높았다. 후보는 그 FD 기준을6,612대/h로 올린다.

이는 실제 수용 용량에 보너스를 더한 것이 아니라 기존 희망속도 FD의 임계밀도·형상을 보정한 결과다. 반대로 균일 정상상태 FD 최대값을 비정상·비균일 METANET 유량의 엄밀한 상한이나 실측 용량으로 해석해서도 안 된다. 그럼에도 회복부 FD가 너무 낮은 목표속도를 만드는 단서로 볼 수 있다. `fd_flow_audit.json`에 조건·계수·출처를 남겼다.

## 동결한 후보의 다른 상태 검토

후보를 기존 config 필드10개와 manifest로 저장해 같은 물리 예측이 나오는지 확인했다. 수치 차이는 최대3.42e−12로, 곱셈 순서의 부동소수 차이 범위다. `scripts/verify_parameters.py`는 PASS였다. 기존의 사용되지 않는 전역 calibration 값 경고는 남아 있으나, 이번10개 셀별 FD 값은 실행 config 전체31셀과 별도로 대조해 실제 반영을 확인했다.

## 미래 source를 알려준 두 진단은 별도

seed43에서 새 계수를 고정하고 실제 미래30초 본선 유입만 제공한2회를 수행했다. 자율 예측의 본선 ΔTTT −2.5561이 조건부 +1.1616으로 바뀌었지만, 실측 +3.7042에는 미치지 못했다. 이2회는 원인 분리용이며 예측 성공·제어 검증·학습 결과에 넣지 않는다.

입력을 알려줘도 셀19의 VSL 통과량 변화는 약+59.92대(실측+6대)로 과대예측된다. 이전 계수의 같은 조건부 값+58.04대에서 개선되지 않았다. 셀24의 변화도+60.54대로, 이전+46.59대보다 커졌다(실측+41대). 따라서 개선된 절대 회복과 과도한 VSL 방출 이득을 구분해야 한다. 경계 입력 차이만 해결하면 끝난다는 결론도 나오지 않는다.
