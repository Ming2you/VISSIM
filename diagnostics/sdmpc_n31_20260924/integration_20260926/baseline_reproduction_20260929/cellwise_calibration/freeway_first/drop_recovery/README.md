# 차로 감소 감속계수의 제한된 회복 보정 — 2026-09-30

**두 후보 모두 기각.** 무제어 회복을 개선하지 못해 제어 후보 검증으로 확대하지 않았다. 정본 계수와 SDMPC 설정은 바꾸지 않았다.

## 조건과 예산

현재 expanded036 + 경로 재고·저장 모델을 동결하고 FW_E의 기존 lane_drop_phi만 3→1.5 또는 1.0으로 변경했다. 셀18만의 계수가 아니라 동측에서 해당 항이 작동하는 모든 셀에 적용된다. 물리 차로 수, 동적 off-ramp 저장, 실제 합류·수용 계산, VSL 계수는 고정했다.

seed29 무제어, 같은 2220.1초 초기 상태에서 750초를 예측했다. 셀15–20의 N·v·30초 방출 오차를 각각 10대·20km/h·1000대/h로 정규화한 평균 제곱오차로 평가했다. 마지막 300초 오차를 10% 이상 줄이되 앞선 450초 오차 증가는 10% 이내, 전체 속도 RMSE 증가는 2km/h 이내라는 기준을 먼저 정했다.

최대 14회 예산 중 기준 동일성 1회와 두 후보 2회, 총 3회에서 종료했다. 후보가 학습 조건을 통과하지 못했으므로 다른 seed·RM/VSL 검증은 실행하지 않았다. 기각 결과를 독립 검증 완료로 표현하지 않는다.

## 검증과 해석

- 명시적 phi=3 기준의 cells/flows/ports/ramps 네 배열이 기존 결과와 정확히 같다.
- 세 예측 모두 invalid=false. 차량 보존 최대 잔차는 기준 2.98e−13, phi1.5 2.42e−13, phi1.0 2.13e−13대다.
- 실제 회복을 놓치는 문제가 lane-drop 항 하나의 크기로 해결되지는 않았다. 모든 lane-drop 모델이 무효이거나 국소 보정이 불가능하다는 결론은 아니다.
- 셀19의 기존 seed29 무제어 끝 속도는 실측 82.6, 모델 26.2km/h였다. 이 편향을 도시부 보정이나 제어 보상으로 상쇄하지 않는다.
- 750초는 회복을 관찰하기 위한 오프라인 진단 길이다. 운영 MPC 지평 450초·내부 적분 1초는 변경하지 않았다.
