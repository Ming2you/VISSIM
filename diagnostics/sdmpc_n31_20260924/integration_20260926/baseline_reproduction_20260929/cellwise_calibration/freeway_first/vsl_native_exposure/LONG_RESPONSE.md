# VSL750초 예측과 경계 유입 진단 — 2026-09-30

판정: 현재 동적 경로·저장 후보는 seed29의750초 VSL 이득을 표현하지만, seed43의 손익 순위를 자율 예측으로 재현하지 못했다. 실제 미래 유입을 알려주면 오차 일부가 줄지만, 셀16–19 방출 이득의 과대예측은 남는다. 제어 지평을 바꾸거나 물리계수 보정을 완료했다고 선언하지 않는다.

## 이번에 바꾼 것과 검증

- 기존 canonical_harness.rollout의 오프라인 검사용 최대 지평만450→750초로 늘렸다. 기본450초·제어 주기·MPC 목적함수·1초 물리 적분과 물리식·계수는 유지했다. AST 비교로 harness의 차이가 지평 검증 한계와 오류 문구뿐임을 확인했다.
- 기존 scoring과 _cellwise_measure에 horizon_sec 기본450인 선택 인자를 추가했다. 기존 helper에 유한 비교 함수를 추가했으며 adapter/runner 복제는 없다.
-2220.1초에 저장한 경계 입력450개를 확인했다. 유량·배수·도착 예측은 cutoff 이전 관측에서 만든 일정 값이고, 지정VSL은2250초 이후 유지 명령이었다. 같은 예측을300초 연장했으며 미래 실측 상태로 재초기화하지 않았다.
- 자율 예측4회: seed29 무제어/VSL, 계수 학습에 쓰지 않은 seed43 무제어/VSL. seed43 결과는 이전에 이미 살펴봤으므로 완전한 블라인드 검증이라고 부르지 않는다.
- 네 예측의 첫450초 cells/flows/ports/ramps는 각각 기존 저장 결과와 정확히 같고, 기본450초 score도 정확히 같다.750초는 연속된 같은 상태의 예측이며450초마다 상태를 실측으로 갈아 끼운 결과가 아니다.
- 이어 seed43에만 미래의 실제30초 본선 입력을 알려준 조건부 진단2회를 별도 실행했다. 이2회는 예측 성능이나 이득 보정 통과에 포함하지 않는다. 총6회 계산·새 native0회·새 FZP 추출0회·계수학습0회다.

첫 원문 보존 단계에서 Windows 긴 경로로 helper 사본 쓰기가 실패했다. 모델 변경·계산 전에 발생했고, 저장된 harness 사본을 유지한 채 짧은 helper_before.txt 이름으로 보존했다. input_check.json에 기록했다.
