# VSL 실제 적용과 평균 희망속도 비율 진단 — 2026-09-30

판정: native VSL은 지정 위치에서 차량의 희망속도를 바꾸고 있었다. 평균 희망속도 비율만 Carlson FD 입력에 반영한 후보는 비용·방출 반응을 일관되게 개선하지 못해 채택하지 않았다. 본선 동역학 검증을 먼저 진행하며 도시부 보정으로 오차를 흡수하지 않는다.

## 완료된 근거

- seed29 초기2220.1초 및 후기2670.1초의 기존 무VSL/VSL 기록4개에서 각각450초·5초 간격을 추출했다. 상세 차량 자료는 동측 셀14–26만 보관했다. 각 자료의16시점×31셀 재고·평균속도가 기존 truth와 일치한다.
- 초기 공통 전체 차량 ID만 짝지었다. 분기 후 생성된 같은 번호의 차량은 짝으로 취급하지 않았다. 같은 시각·영역에 남아 있는 표본의 조건부 차이이며, 개별 역학의 인과 계수로 사용하지 않았다.
- 활성 DSD 상류에서는 초기2587표본, 후기3708표본 모두 두 조건의 희망속도가 같았다. 활성 sign 이전의 희망속도 변경은 관측되지 않았다.
- 제어 영역의 희망속도 차이는 초기−15.05km/h, 후기−14.07km/h였다. 같은 표본의 실제 속도 차이는 각각+2.32,−1.25km/h로 상태에 따라 달랐다. 이 차이만으로 분산·차로변경·용량 효과를 분리했다고 주장하지 않는다.
- native 복원 sign은8090.751m(셀25), 현재 모델 복원은 다음 경계인 셀26이다. 기존 명시적 근사이며 새로 발견한 매핑 오류로 확정하지 않았다. 기록간격5초의 변경 구간은 정확한 이벤트 시각이 아니다.

첫 추출은 말단 차량 앞부분이 링크 끝을1.599m 넘는 사례에서 중단됐다. 기존 Observer와 같은 말단 셀 귀속을 적용한 뒤 재실행했다. 실패 원문과 로그는 failed_*로 보존했다. 상세 VSL 영역은 말단 셀과 겹치지 않는다.

## 단일 평균 비율 후보

DSD110의 분포 평균112.275km/h·표준편차12.254, DSD90은97.125·6.428이다. 분포 번호90/110 대신 이 평균의 비율을 Carlson b에 넣어 보았다. 이는 희망속도의 평균을 자유류 실측속도라고 단정한 것이 아니라 액추에이터 근사의 제한된 시험이다. 계수 A/E와 다른 물리항은 고정했다.

새450초 예측6회: 최대속도 조건 정확 재현2회 + 변경 조건4회. 나머지 무VSL2회는 재사용했다. 미래 실측 입력·계수 학습·core 변경은 없다. no-VSL의 cells/flows/ports/ramps 전체가 동일했고, 본선 보존잔차2.14e−14대·connector8.82e−13대 이내, 음수 재고·밀도 projection·jam 초과는 없었다.

## 이어지는 원인 분리

`../../../native_distribution_split/attempt2/protocol.json`에 동결한 두3000초 진단 런으로 평균만 낮춘 분포와 평균을 유지하고 모양을 바꾼 분포를 분리한다. 현재 실행 상태와 최종 결과는 그 폴더의 launch_status.json 및 analysis/를 기준으로 확인한다.
