# 합류 차량 구성과 본선 잔류 차량의 속도 변화 분리

2026-09-30. **셀21의 과도한 감속과 셀23의 가속 편향이 공존하며, 셀24·25에는 합류가 없어도 감속 편향이 남는다.** 하나의 merge 계수를 일괄 낮춰 해결할 문제로 보지 않는다. seed67 RM 완화±VSL의 기존5초 프레임과 앞서 확인한 램프 방출 기록만 사용했다. 새 VISSIM·FZP 읽기·자율 예측·보정·push는 없다.

## 이번에 새로 구분한 것

전체 속도 모멘트 또는 잔류/진입/이탈 합만 다시 계산한 것이 아니다. 진입 차량을 **그 셀에 직접 합류한 램프 차량**과 **다른 본선 유입**으로 구분하고, 각각 이전 표본속도에 따른 구성 변화와 다음 표본까지의 속도 변화를 나눴다. 상류 램프에서 들어와 해당 셀까지 통과한 차량은 직접 합류와 구분했다.

`(v_after−v_before)/5`는 아래 여섯 항의 합과 정확히 같다. 모든 분모는 `5*N_after`다.

- 양끝 모두 셀에 남은 차량의 속도 변화 합
- 직접 합류 차량의 `(마지막 램프 속도−기존 셀 평균)` 합
- 그 차량의 `(첫 본선 속도−마지막 램프 속도)` 합
- 다른 진입 차량의 `(이전 속도−기존 셀 평균)` 합
- 그 차량의 표본 사이 속도 변화 합
- 이탈 차량의 `(이전 속도−기존 셀 평균)` 합의 음수

셀10·12·21–25, 두 조건,90개5초 구간의1,260개 항등식 최대오차는4.78e−15km/h/초 미만이었다. 진입 차량의 이전 출처를 찾지 못한 사례를 삭제하거나 속도를 가정하지 않았다.

이것은 관측 장부다. 속도 변화가 셀 경계의 어느 쪽에서 일어났는지, 같은5초 안에 어떤 차로변경·상호작용이 있었는지는 완전히 식별하지 못한다. 잔류 차량의 변화 전체가 합류 마찰의 인과 효과인 것도 아니다.

## 셀21과23은 같은 오류가 아니다

반대로 셀23은 현재 실측 상태에서 가속을 과하게 예측한다. 셀23의 자율 예측이 느리다는 이유로 그 셀의 이완을 더 빠르게 하면 올바른 수정이 아닐 수 있다. 자율 상태의 밀도·인접 상태가 실제와 달라진 영향과 구분해야 한다.

## 표본 사이에 셀을 통과한 차량

같은5초 안에 합류 셀을 완전히 지나간 차량은 해당 셀의 양끝 재고에 남지 않는다. RM 완화에서10639는86대 중17대,10681은141대 중8대,10490과10484는 각각98대 중1대·82대 중1대다. 이들을 합류량에서 제외하지 않았고, 관측 셀 평균의 구성 항에는 가상의 재고를 추가하지 않았다. 출구까지 남은 거리 차이도 있어 이 수를 곧바로 누락 모델 비용이나 capacity 손실로 환산하면 안 된다.

## 판단과 다음 범위

- 현재 실제 합류량을 넣어도 셀21/23/24의 식 오차 방향이 다르다. 합류 속도 하나 또는 공통δ 배율 하나만 조절하는 작업을 반복하지 않는다.
- 유지할 것: 실제 허용 합류, 차량 수 보존, 램프 대기, 목적 경로 재고·동적 off-ramp 저장/배수, 과거VSL 노출.
- 남은 구조 문제는 공간 평균 상태가 실제 진입·이탈 차량과 회복부의 속도 반응을 대표하는 방법이다. 현재 캐시와 기존 상태 의존 차로그룹 구현을 재사용하는 제한된 후보를 검토하되, 고정 차로 비율이나 미래 실측을 넣지 않는다.
- 기존 PhysicalLaneGroups는 목적 경로 재고와 동시 사용을 명시적으로 금지한다. 이 제약을 삭제하고 바로 실행하면 경로별 보존을 잃을 수 있으므로 전역 차로그룹으로 전환하지 않았다. 필요한 연결 범위와 이미 검증한 차로/모멘트 후보를 먼저 대조한다.
- 작은 속도 편향을 전부 없애는 것이 목표는 아니다. 수정 후보는 본선의 큰 손익과 누적 방출·제어 순위를 유지하거나 개선해야 하며, 현재 결과는 그 통과를 의미하지 않는다.
