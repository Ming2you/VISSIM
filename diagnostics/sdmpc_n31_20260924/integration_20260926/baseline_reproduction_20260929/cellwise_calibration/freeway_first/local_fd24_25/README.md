## 조건부 항별 진단

셀24 RM유지에서:
- 예측상태:현재속도56.03, FD 목표속도37.43km/h. 이완−1.190, convection−0.018, anticipation+1.196km/h/s로 서로 상쇄된다.
- 실측 본인·상류·하류 상태를 넣은 조건:현재79.85,목표53.20km/h. 이완−1.705,convection−0.232,anticipation+0.320으로 순−1.617km/h/s다.
- 본인의 예측 상태를 유지하고 상류속도만 실측으로 바꾸면 순변화는−0.012→+2.214km/h/s로 바뀐다.

따라서 상류 오차의 전달도 있으나, 이 셀 자체의 낮은FD 목표속도 역시 회복을 억제하는 계산상 원인이다. 단순한 회복시간 τ 단축은 목표속도가 현재보다 낮으면 감속을 더 빠르게 만들 수 있다. 이 진단만으로 특정 항이 실제 VISSIM 회복의 인과 원인이라고 단정하지 않는다.
