# 본선 회복 오차 분리 — 2026-09-30

전체 망 보정에 앞서 본선 동역학을 검증한다. 기존 ALINEA·병목 VSL의 VISSIM 효과는 재사용하며, 이 진단은 그 효과의 존재를 다시 입증하는 실험이 아니다. 현재 모델의 회복 오차와 제어 반응 오차를 분리하는 단계다.

## 완료한 진단

- 동결된 expanded036 + 현재 경로 재고·저장 모델의 seed29/43 무제어 750초 예측을 재사용했다.
- 2670.1–2940.1초, 셀15–20에서 현재 자기 N/v, 상류 속도, 하류 밀도를 각각 예측값/실측값으로 교체한 8조합을 평가했다. 960회 스칼라 1초 속도 갱신이며 새 전체 롤아웃은 없다.
- 예측값만 사용한 120개 식은 저장된 실행을 오차 0으로 재구성했다.
- 차로 수·차로 감소 상태는 같은 예측 기준을 유지했다. 실측 상태 교체는 원인 분리용이며 자율 예측·차량 보존 검증·제어 이득 검증으로 간주하지 않는다.
- 비교한 실측 추세는 다음 30초의 공간 평균속도 변화다. 모델의 1초 갱신과 시간 연산자가 다르므로 이를 차량 가속도의 직접 오차로 해석하지 않는다.

## 확인한 점

잘못 전달된 하류 밀도와 현재 상태에서의 식 균형이 모두 원인 후보다. 셀18에서 하류 밀도만 실측으로 바꾸면 평균 1초 속도 변화가 seed29 −0.009→+2.849, seed43 −0.021→+2.009km/h로 바뀐다. 그러나 자기·상류·하류를 모두 실측으로 바꿔도 평균 변화는 각각 −2.779, −3.777km/h다. 특정 경계 하나만 바로잡으면 해결된다는 결론은 나오지 않았다.

기존 [거리 감사](../../../observed_state_pressure/five_second/geometry_distance_audit.json)는 경사 계산의 거리 검토를 이미 수행했다. 셀 중심 간 거리로 바꾸는 방안은 아직 실행·검증하지 않았다. 거리 차이만으로 모델 오류나 해결책을 확정하지 않는다.
