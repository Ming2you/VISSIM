# 차로 감소 구간의 VSL FD 계수: 제한된 재보정 결과

2026-10-01. 두 후보 모두 학습 단계에서 기각했다. 운영 모델·목적함수·망·명령·STOP은 변경하지 않았다. 새 VISSIM과 FZP 재스캔은 없다.

## 가설과 범위

동측 전체에 같은 Carlson E를 적용하는 대신, VSL 표지와 물리적 4→3차로 감소 전후인 **0기준 셀16–20**만 E=1 또는4로 바꿨다. 기존 E=2, A=0.5, alpha=0이며, 셀21 합류부와24·25 회복부는 그대로 두었다. nominal110 및 나머지 물리계수, 목적지 재고, 실제 수용 합류, 대기, 동적 off-ramp 저장·배수는 유지했다.

기존 진단 helper에 함수 하나를 추가하고 해당 프로세스 안에서만 FD 함수를 임시 연결했다. 새로운 adapter나 운영 설정은 만들지 않았다. 따라서 이 시험은 float 기반 동측31셀+진입/진출 connector 예측이며 **전체 Ω·AD·SDMPC 연결 검증이 아니다.**

## 사전 고정한 계산 예산

`protocol.json`을 먼저 저장했다. seed29 초기750초 VSL−NC, 후기450초 RM유지 시 VSL 추가, 후기450초 RM완화 시 VSL 추가의 세 반응을 비교했다. 750초는 저장된450초 예측 입력의 마지막 알려진 값을 연장했다. 미래 실측을 예측 입력으로 쓰지 않았다. 실측은 사후 점수 계산에만 사용했다.

무제어 parity1회+두 후보×세 상태=**7회**를 완료했다. 두 후보 모두 사전 기준을 통과하지 못해 예정했던 seed43/67 확인4회는 실행하지 않았다. 이 seed들의 기존 기준 결과를 읽어 둔 것과 새 후보를 검증한 것을 구분한다. 이미 읽은 seed이므로 설령 실행해도 blind holdout은 아니다.

150초별 셀15–20 유량 차이와 말단 재고 차이의 정규화 반응 손실은 기존 **1.36242**, E1 **2.59177(+90.23%)**, E4 **1.37546(+0.96%)**였다. 통과 조건은 기존 대비10% 이상 감소였으며 둘 다 실패했다.

E1은 초기 VSL 이득을 과장하고 후기 RM유지 상태의 손실 오차도 늘렸다. E4는 작은 후기 반응을 줄이는 대신 초기의 실제 VSL 이득을 손실로 뒤집었다. 속도 RMSE 악화 제한은 통과했지만, 그것만으로 제어 응답 보정 성공으로 판정하지 않았다. 작은 후기 부호 하나를 맞추기 위해 후보를 추가 탐색하지 않는다.

## 검증과 해석

- 저장된 소스·기준 결과·관측 95개 SHA256 일치. 원래 실패한 native prefix 판정도 그대로 보존했다.
- 기존 함수 100개의 AST가 수정 전과 같고, 실행 당시 helper 사본과 현재 파일도 같다.
- 무제어750초의 cells/flows/ports/ramps는 저장 기준과 정확히 같다. 후보 호출은 셀16–20의90km/h 집단에 한정됐다.
- 7회 모두 physical score invalid=false, 보존 잔차 최대 7.82e-13대. 상세 `verification.json`.
- 순수 rollout 시간 합 9.750초. 초기화·사후 점수·보고 시간을 포함한 전체 경과시간은 따로 측정하지 않았다.

국소 E 하나의 재보정으로 개선된다는 근거를 얻지 못했다. 이는 모든 METANET 수정이 불가능하다는 뜻이 아니다. 여러 seed에서 확인한 큰 RM 유지 이득과, 상태에 따라 나타나는 VSL 이득/손해는 보존한다. 다음 판단은 기존 방출·재고·회복 자료와 원래9000초 손실 원인 분리로 돌아가며, 같은 E/rho_crit/tau 그리드를 반복하지 않는다. 새 후보 채택·SDMPC9000 재시작·push는 하지 않았다.
