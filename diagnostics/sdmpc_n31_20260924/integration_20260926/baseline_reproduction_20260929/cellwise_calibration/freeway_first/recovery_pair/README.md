# 셀24·25 회복부 보정과 고정 후보 검증

2026-09-30. **최종 반응 검증 실패, 정본 반영하지 않음.** 기존보다 본선 회복과 일부 손익 방향은 좋아졌지만 제어 효과의 크기·초기 복합 제어를 충분히 설명하지 못했다. 이번 작업은 freeway 우선 검증이며 도시부 보정·SDMPC9000·push를 하지 않았다.

## 변경과 범위

기준은 동결된 connected-FD 후보다. 기존5초 차량 캐시를 이용한 [가속·평균속도 진단](../acceleration_balance/README.md)에서 실측 인접 상태를 줘도 셀24·25의 속도식에 감속 편향이 남았다. seed29 무제어의20개 셀×30초 구간만으로, 이 두 셀의 기존 회복 방향 anticipation 계수에 공통 배율2.859774049618318을 적합했다. 다른 셀·FD·합류 감속·물리 유량·램프 대기·동적 off-ramp 재고/배수는 그대로다.

실행 가능한 후보에서 회복 분기는 매 예측 단계의 현재/하류 밀도로 판별한다. 계수 적합에 쓴 실측 미래 상태는 자율 예측 입력으로 사용하지 않았다. 수요·경로·제어·목적함수 변경, VSL/RM 보상 또는 용량 보너스는 없다.

처음7회는 비활성 기준 재현1회와 후보6회였다. 무제어 게이트가 통과해 나머지 기존 조건을 검증했고, 두 계수만 바꾼 설정 파일로 저장한 뒤 동일 결과인지 확인했다. 추가11회는 설정 직렬화 정합1회와 다른 명령10회다. 첫6개 후보 예측을 재사용했다. 총18회 새 자율 예측,600회 조건부 단일 속도 갱신, 새VISSIM/FZP재읽기0회다.

## 좋아진 부분

seed29 NC750초의 셀21–25 N/v/유량 손실:

- 처음450초:0.51616→0.23012.
- 후반300초:1.09145→0.46970.

이는 **해당 상태의 회복 재현 개선**이며 제어 이득 검증 통과를 뜻하지 않는다. `selection.json`의 selected=true는 이 NC 게이트만 가리킨다.

## 검증·다음 판단

18회 예측의 invalid·차량보존 검사를 통과했고 최대 잔차는1.24e−12대다. 저장한 설정으로 재실행한 cells/flows/ports/ramps는 임시 후보와 정확히 같다. 네 core 파일과 기존9000 STOP은 바뀌지 않았다. 실행9352·32939 모두exit0. 첫 시도는Windows 출력경로 길이 때문에 최초 예측 전에 실패했고 `../connected_recovery24_25/failure.json`에 보존했다. 짧은 경로에서 다시 실행했으며 중복 시뮬레이션은 없다.

이번 결과는 **관측 상태에서의 국소 회복 오차를 줄이는 보정과, 자율 모델에서 제어 손익 차이를 유지하는 보정이 같지 않음**을 보여준다. 같은 배율을 촘촘히 다시 탐색하지 않는다. 다음에는 초기 RM/복합 조건의 실제 합류 차이가 본선 방출에 전달되는 과정과 셀21 합류 감속의 잔차를, 이번 회복 개선과 분리해 비교해야 한다. 기존 합류 감속 축소 단독 시험은 실패했으므로 그 시험을 그대로 반복하지 않는다. 도시부 계수로 본선 오차를 상쇄하지 않는다.
