2026-09-30. 이번 작업은 새 VISSIM 없이 완료 자료로30회 오프라인 예측을 실행했다(계수시험19 +조건부 경계2 +연결 영역9). 이전에 완료된 목적지/경계 진단4회도 별도 재검증했다. **정본 모델은 아직 채택 변경 없음.**

## 핵심 결과

목적지×차로 유입을 맞춰도 셀19의 재정체가 부족했다. 지역 차로 모델은19–21만 나누고, 셀21의 하류에는 셀22의 전체 평균 밀도를 받았다. 이를 원인 분리하기 위해 실제 셀22의 차로별 밀도를 기존 anticipation 입력에만 넣었다. source/목적지 유입 조건은 lane_joint67과 같고, 미래 속도나 셀 차량 수를 재설정하거나 receiving 유량을 강제로 맞추지 않았다.

## 자율예측으로 옮겨본 결과

계수/차로 이동률을 그대로 두고 현재 차로·목적지 재고만으로 영역을19–25까지 확장했다.10490·10484 합류와10483 진출을 같은 재고 장부로 처리하고, 두 번째 합류 뒤24·25의 회복을 포함했다. 선택망XML에서10484는24번link의1차로,10490은119번link의1차로에 합류함을 확인했다.

seed29·67의 RM 유지/완화×VSL110/90 8조건,450초 자율예측을 실행했다. 재정체 크기는 생겼지만 너무 일찍 발생하고 회복 구간이 느렸다. 예를 들어 seed67 무VSL2820.1초 셀19 1차로 실측N6·95.2km/h /모델N14.7·20.0km/h였다.2970.1초는 실측N31·1.9km/h /모델N26.8·6.6km/h였다. 셀24는 같은 두 시각 실측80.2·75.8km/h /모델44.5·44.5km/h였다.

VSL 추가의450초 본선 ΔTTT는 실측−1.492 차량·시간인데 연결 후보는+0.265였다. RM 유지의 유리한 방향은 표현하지만 전체 gain 검증은 실패했다. 조건부 진단의 성공을 그대로 정본으로 승격하지 않았고 core4개를 바이트 단위로 복원했다. 상세는 ../joint_lane_25/README.md와 local_comparison.json.
