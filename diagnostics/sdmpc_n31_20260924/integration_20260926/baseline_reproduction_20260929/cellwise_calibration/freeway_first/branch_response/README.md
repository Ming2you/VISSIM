# 진출 비중과 본선 방출 반응의 분리

2026-09-30. 기존 seed29의 혼잡 초기2220.1초와 혼잡2670.1초, 각4조건을 사용했다. 기존16개 예측을 재사용하고 **450초 계산10회(기존 결과 재현2회, 조건부 진단8회)**를 완료했다. 새 VISSIM·계수 보정·정본 승격·push는 없다. seed43/47/53/61은 이번 진단과 후보 선택에 사용하지 않았다. 기존9000초 STOP은 유지했다.

## 확인한 오차

혼잡 상태의 RM 완화에서10682 진출량은185→156대(−29)지만, 같은 분기 셀의 통과량은730→772대(+42)다. 총 방출은915→928대로 증가했고 진출 비중은20.22→16.81%로 감소했다. 따라서 이곳의 진출량 감소 전부를 본선 총 처리량 저하로 설명하면 틀린다. 모델의 비중은14.66→14.53%로 거의 고정되어 진출량 변화를+3.32대로 예측했다.

반면10483에서는 진출량150→128대(−22), 통과량769→682대(−87)로 둘 다 줄었다. 여기는 총 방출 감소가 주요한 차이이며, 기존 모델도 진출−18.36대·통과−96.95대로 같은 방향을 예측했다. 서로 다른 진출부를 하나의 감속 계수로 보정하지 않는다.

`summary.json`의 분해는 항등식이다. Q=진출+통과, β=진출/Q에 대해 Δ진출=평균β×ΔQ+평균Q×Δβ로 계산했다. 이는 인과 효과 분해가 아니다. β에는 목적지 구성뿐 아니라 도착 시각·차로 접근·하류 수용·기간 끝에서의 관측 절단이 함께 들어간다.

혼잡RM 완화의10682 진출 변화는storage 기준+5.44→조건부−22.77대로, 실측−29대에 가까워진다. 본선+8커넥터 ΔTTT도실측+4.704에 대해storage+2.436→조건부+4.088이다. 그러나 혼잡 초기의RM 방출 반응은 여전히 작고 VSL 이득 예측은 오히려 약해진다. 조건부 실측 비중을 주어도 본선 동역학 전체가 해결되지 않는다.

**미래 실측 β를 사용했으므로 자율 예측이나 제어 이득 검증으로 인정하지 않는다.** 실제 출구량 자체를 강제로 맞춘 것도 아니다. β만 바꾸고 기존 METANET 방출·수용 계산을 사용하므로 결과 출구량은 여전히 다르다.
