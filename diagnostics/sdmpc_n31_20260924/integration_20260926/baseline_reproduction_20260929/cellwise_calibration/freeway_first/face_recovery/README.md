# 본선 우선 검증: 회복 구간 경계 속도 근사와 동역학 연결

2026-09-30. 상태: **후보 기각·기존 코어 복원, 전체 이득 예측 미완료**.

현재 실측 상태에서 경계 통과 속도를 더 잘 추정하는 것과, 미래 상태를 자체적으로 갱신하며 제어 이득을 예측하는 것은 달랐다. 셀23–25의 경계 속도 보간은 자료상 오차를 줄였으나, 이를 상·하류에 같은 크기로 반영하는 동역학 후보는 방출·상태·제어 반응 예측을 악화시켰다. 이 후보는 채택하지 않았다. 도시부 계수를 함께 조정해 본선 오차를 상쇄하지 않는다.

## 범위와 순서

우선 31셀 동측 본선에서 실제 합류 변화 → 혼잡 발생·전파 → 회복·누적 방출을 검증한다. 이미 실측 이득이 있는 ALINEA와 VSL 조건을 재현할 수 있는지가 기준이다. 작은 속도 오차나 미미한 손익 부호까지 일치시키는 것이 목표는 아니다.

1. 기존 관측 경계·합류를 이용한 조건부 진단으로 본선 자체 오차와 입력 오차를 구분한다. 실측 미래 경계를 사용한 결과를 자율 예측 성능으로 보고하지 않는다.
2. 미래 실측 없이 동일 초기 상태의 NC/RM/VSL/병용 및 RM 유지·완화를 예측한다. 큰 손익 방향, 선택 순위, 누적 방출·잔여 재고를 함께 확인한다.
3. 본선 검증을 통과한 뒤 도시부 도착·신호·램프 접근과 연결하고 Ω 비용 및 SDMPC 선택을 확인한다. 램프 대기 비용, off-ramp 저장·배수·spillback은 본선 단계에서도 유지한다.

Ω TTT 목적함수 정의는 바꾸지 않는다. 아래 수치의 component TTT는 **FW_E 31셀 + on/off-ramp 8개 connector** 범위이며 Ω 전체 TTT가 아니다.

## 1. 현재 상태를 이용한 경계 속도 검사

`protocol.json`, `rows.json`, `summary.json`에 기록했다. 기존 seed29/43 NC·VSL, seed67 RM 완화·완화+VSL90의 여섯 캐시를 재사용했다. 추가 FZP 읽기·계수 적합·VISSIM 실행은 없었다.

셀 중심 사이에서 물리 경계의 속도를 다음과 같이 보간했다.

`v_face = (L_next*v_cell + L_cell*v_next)/(L_cell + L_next)`

입력은 해당 시각의 두 셀 실측 평균속도다. 비교 대상은 5초 사이 경계를 통과한 차량들의 직전 표본속도 평균이다. 경계의 정확한 통과 순간 속도는 아니며, 직후 표본속도에도 경계 이후 가속이 포함된다. 같은 5초 구간에 본선으로 진입해 직전 본선 표본이 없는 차량은 제외했다. 관측 통과량 대비 짝이 맞는 차량의 최소 비율은 99.48%였다.

| 경계 셀(0기준) | 기존 셀 평균속도 RMSE | 보간 RMSE | 감소율 |
|---|---:|---:|---:|
| 23 | 14.856 | 6.472 | 56.4% |
| 24 | 5.726 | 3.009 | 47.4% |
| 25 | 7.807 | 5.925 | 24.1% |

단위 km/h. 통과 차량 수로 가중한 경계별 표본 평균의 RMSE다. 세 경계 모두 사전 기준인 총 RMSE 5% 이상 개선 및 개별 사례 10% 초과 악화 없음에 통과했다. **이는 실측 현재 상태를 쓰는 국소 근사 검사이며, 자율 예측이나 미사용 자료 검증의 통과가 아니다.**

## 2. 자율 예측에 연결한 후보: 기각

후보 하나만 검사했다. 기존 실제 셀 간 유량으로 `dM = q*dt*(v_face-v_cell)`을 계산하고, 상류 셀에서 빼고 하류 셀에 더했다. 각 셀의 재고 갱신 후 차량 수로 나눈 속도 보정을 기존 convection 인자에 반영했다. 공유 경계 보정의 합은 0이지만, 전체 METANET 속도식의 물리적 정합성이 자동으로 보장되는 것은 아니다. 수용량 증가나 제어 명령별 보너스는 넣지 않았다.

seed29 초기 NC/VSL 750초, RM/병용 450초, 후기 RM 유지/완화 450초를 기존 모델과 비교했다. 총 **12개 자율 예측**이다. 비교 지평을 맞춰 초기 NC/VSL 450초는 750초 결과에서 잘랐다. 초기 상태·명령·수요·계수는 고정했고, 미래 관측은 평가에만 썼다.

| 사전 정의 손실 | 기존 | 후보 | 변화 |
|---|---:|---:|---:|
| 상태 손실 | 0.62710 | 1.08436 | +72.9% 악화 |
| 제어 반응 손실 | 0.15907 | 0.19350 | +21.6% 악화 |

허용 기준은 반응 손실 5% 이상 개선, 상태 손실 악화 10% 이하, 의미 있는 비용 차이의 새 부호 오류 없음이었다. 앞의 두 기준을 통과하지 못해 seed43/67 추가 자율 예측은 실행하지 않았다.

| 비교 | 실측 Δcomponent TTT | 기존 | 후보 |
|---|---:|---:|---:|
| 초기 450초 VSL−NC | −0.325 | −0.415 | −0.301 |
| 초기 450초 RM−NC | −0.825 | −0.065 | −0.055 |
| 초기 450초 병용−NC | −0.829 | −0.476 | −0.363 |
| 초기 750초 VSL−NC | −3.117 | −2.864 | −1.237 |
| 후기 450초 RM 완화−유지 | +4.704 | +2.657 | +4.653 |

단위 veh·h, 음수는 비용 감소다. 후기 RM 완화 비용은 실측에 가까워졌지만, 누적 방출 차이는 실측 −90대 대비 기존 −86.31대에서 후보 −154.49대로 악화했다. 초기 NC 750초 누적 방출도 실측 2,106대, 기존 1,902.21대, 후보 1,622.31대였다. 비용 하나가 가까워진 것을 성공으로 판정하지 않았다.

현재 상태에서 더 잘 맞는 경계 속도 근사만으로는 회복 동역학을 개선하지 못했다. 예측 상태·속도식과 결합할 때 오차가 커진 이유는 아직 확정하지 않았다. 같은 보간 후보의 배율을 반복 탐색하거나, 하류에만 가속 보너스를 넣지 않는다. 다음 원인 분리가 필요하면 저장된 예측에서 최초 상태·방출 차이가 생기는 구간을 먼저 확인한다.
