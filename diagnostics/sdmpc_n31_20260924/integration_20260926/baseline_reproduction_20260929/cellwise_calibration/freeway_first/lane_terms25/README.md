seed29 초기의90개30초 블록만으로 두 공통 배율을 한 번 적합했다. 이완항배율a와anticipation배율b에 각각[1/3,3] 제약,0.1의 기존값 정규화를 적용한2차식이다. 정확한2변수 box 최소값을 내부해·네 경계해로 구했다. 결과a=1/3,b=1.875900586. 기존 설정으로 직렬화하면 셀24·25의tau×3,nu×5.627701759이며nu/tau 비는×1.8759이다. FD·합류·다른 셀 계수는 그대로다. seed·시간·제어별 계수가 아니다.

이완배율이 하한에 걸렸으므로 잘 식별된 물리 계수라고 주장하지 않는다. 조건부 RMSE는29초기24에서4.120→3.278,25에서1.852→1.310으로 감소했지만29후기24는2.644→2.943으로 악화했다. 이계수의 자율 검증은 ../joint_lane_rec/README.md다. 조건부 적합을 이득 검증 완료로 취급하지 않는다.
