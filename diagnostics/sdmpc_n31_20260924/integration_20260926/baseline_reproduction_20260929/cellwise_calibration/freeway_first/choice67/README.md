# 독립 seed67: RM 손익은 구별하지만 VSL 방출 반응은 부족

2026-09-30. 네 조건의 VISSIM3300초 실행, 기존 명령/초기 궤적 검증, 사전 동결한 세 모델의450초 예측12회를 완료했다. 이 seed로 계수를 맞추거나 후보를 추가하지 않았다. 고속도로 반응을 먼저 검증하며, 전체 Ω·SDMPC 검증 및9000초 목표는 아직 미완료다.

## 비교 조건과 기록

- 선택80–90 DSD110 망에서 seed만67로 변경했다. 동일 수요·기하·도시 신호·초기 명령 이력을 사용했다.
- seed29 ALINEA 명령 이력을 재생한 뒤2700초부터 RM 유지/허용폭 내 완화, VSL110/90을 조합했다. 새 live ALINEA 또는 처음부터 무제어인 시험은 아니다.
- 공통 초기2670.1초에서3120.1초까지450초를 예측했다. 현재 전체 차량5391대의 경로·위치로 목적 경로 재고를 초기화했고, 예측에는 미래 실측을 쓰지 않았다.
- 네 native 런은exit0. 실제 LDP와 적용 readback 검증 통과, 기록 누락 SG 없음. 네 FZP의2700초 이전 데이터 prefix 및 초기31셀 N/v가 일치한다.
- 기본 동결 모델은 경로 재고를 사용하는 expanded036(`route036`), 연결FD 후보, 셀24·25 회복부 후보다. 모든 예측은 현재 목적 경로 재고+동적 off-ramp 저장/배수 조건이다.

## 본선 TTT 차이

단위veh·h. 음수는 표의 기준 명령 대비 감소다. 동측 본선31셀만 포함한다.

| 비교 | 실측 | route036 | 연결FD | 회복부 후보 |
|---|---:|---:|---:|---:|
| RM 유지→완화 | +8.6292 | +8.0869 | +7.7501 | +6.9426 |
| RM 유지에서 VSL 추가 | +0.1375 | +0.4984 | +0.6937 | +0.6789 |

실제 최선은RM 유지/VSL110이고 세 모델 모두 이를 골랐다. 네 명령 중 선택 손실은 본선 및 본선+동측8connector 영역에서 모두0이다. 그러나 선택 하나가 맞았다는 이유로 물리 반응 검증까지 통과한 것은 아니다. 의미 있는 본선 비용 차이(|Δ|≥0.5)5쌍 중 route036은5쌍, 나머지 두 후보는4쌍의 방향을 맞췄다. RM 유지에서VSL 추가의 작은 실측 차이는 의미 있는 효과 판정에서 제외했다.

## TTT가 가까워도 남은 유량 오차

RM 완화 시 실제 합류는72대 늘고, 본선에서 진출 connector·말단으로 빠진 차량은114대 줄었다. route036은101.24대 증가·74.02대 감소, 연결FD는101.18대 증가·61.54대 감소, 회복부 후보는101.10대 증가·33.09대 감소로 예측했다. **합류 증가를 크게 보고 방출 손실을 작게 보는 오차가 TTT에서 일부 상쇄된다.** 비용 근접만으로 고속도로 동역학 보정 완료를 선언하지 않는다.

RM 완화에서VSL 추가 시 실제 본선 입력은36대 감소, 합류는4대 증가, 진출 분기는10대 증가, 말단 유출은8대 증가했다. route036의 방출 증가 예측은5.16대, 연결FD는1.51대, 회복부 후보는2.56대 감소다.

같은30초 재고 적분의 보존식으로 VSL의 실측 본선 ΔTTT를 분해하면 다음과 같다.

| 항 | 실측 | route036 | 연결FD | 회복부 후보 |
|---|---:|---:|---:|---:|
| 본선 입력 시각·수량 | −0.8167 | 0 | 0 | 0 |
| 실제 합류 시각·수량 | +0.3667 | +0.0012 | +0.0016 | +0.0020 |
| 진출 분기 시각·수량 | −0.6083 | −0.0240 | +0.0165 | +0.0755 |
| 말단 유출 시각·수량 | −0.4333 | −0.0117 | +0.1001 | +0.1647 |
| 합계 | −1.4917 | −0.0345 | +0.1182 | +0.2422 |

이는 회계적 항등식이다. 입력 항을 빼고 남은 값을 독립적인 인과 효과로 부르면 안 된다. 다만 실제 입력 변화와 방출 변화가 모두 있는데, 현재 예측은 전자의 조건별 차이가 없고 후자의 반응도 약하다는 사실은 확인된다. 진출 분기는 본선→connector 사건이며 Ω TTD가 아니다.

## 위치: 회복부만 더 빠르게 만들면 안 된다

RM 완화 조건의VSL 추가로 셀18·19 하류 통과가 실제39·38대 증가했다. route036은10.45·10.92대, 연결FD는5.47·6.29대 증가로 보았고, 회복부 후보는3.13·2.34대 감소로 보았다. 셀15–19의 실제 재고 체류가 줄었지만 회복부 후보는 상당 부분 늘어나는 방향이다.

즉 이번 미설명 반응은 셀24·25만의 문제가 아니다. 현재 회복부 계수 후보를 더 강화하거나 전체 망에 채택하지 않는다. RM 완화 후 회복·방출 손실을 과소평가하는 문제와 VSL에 따른 상류·병목 방출 반응을 함께 유지해야 한다.

## 다음 작업
