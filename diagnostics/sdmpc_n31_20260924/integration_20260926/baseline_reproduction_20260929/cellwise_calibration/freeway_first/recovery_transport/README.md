# 회복 구간의 실제 차량 이동·평균속도 분해

2026-09-30. 기존4개 FZP에서2670.1–2970.1초를 한 번씩 추출하고 캐시 분석을 완료했다. 새 VISSIM·계수 적합 없음. 본선 동역학 검증 우선순위 유지, 이득 보정 미완료.

## 데이터 확인

seed29/43 NC/VSL의 기존 원본 크기·수정 시각을 확인하고,2670.1초까지의 기존 데이터 prefix SHA와 모두 일치함을 확인했다. 이후 회복 구간을 각61개5초 프레임으로 보존했다. 저장된30초 본선 관측과528개 셀·시각의 N/v가 일치했다. 상세2,640개 전이의 평균속도 항등식 최대오차2.82e−14km/h, 저장된 모델5초 전이2,640개의 식 합산 최대오차3.11e−15km/h다.

프레임 캐시에 vehicle ID,셀,위치,차로,속도,가속도를 보관했다. 이후 분석에서 FZP를 다시 읽지 않았다. 기존 초기 구간2220–2670초 결과와 구분한다. 소스·초기 및 확장 prefix 해시는 각 `s*_source.json`에 있다.

## 가속과 집단 구성이 함께 작용한다

5초 전후에 셀에 남은 차량, 들어온 차량, 나간 차량을 나눠 평균속도 변화를 정확히 분해했다. 이 항등식은 METANET의 개별 force 항을 식별한 것이 아니며, 표본 사이 가감속·차로 변경을 포함한다.

셀18·19에서 실제 평균속도가5초 동안3km/h 이상 오른 구간도 있지만, 저장된 자율모델은 낮은 상태 주변에서 거의 일정했다. 해당 구간의 시각·부호 일치를 제어 모델의 독립 통과 기준으로 요구하지 않는다. 목적은 장기 저속 편향과 단기 집단 변화를 구분하는 것이다.

## 간단한 경계 속도 근사는 충분하지 않았다

현재 상류 평균, 초기29NC에서 보정한 분산식, 현재 상류 셀의 하류 절반 평균, 인접 셀 평균의 minmod 기울기로 복원한 경계속도를 비교했다. 목표는 실제 다음 프레임으로 이동한 차량들의 **이동 전 표본속도**다. 정확한 경계 순간속도나 미래예측 결과가 아니다.

분산계수는 원본의0.7005458861158487을 그대로 사용했다. 최초 추출의 반올림0.70055 점수는 보존하고, `closure_summary.json`에 정확한 계수로 재계산했다. 재적합과 FZP 재읽기는 없다.

## 셀18 차로 연결과 별도 시험

선택 망에서2번 link의2·3·4차로가10613을 거쳐119의1·2·3차로로 이어진다.10481 진출 connector는2번 link의1·2차로에 연결된다. 본선에서 사라지는 차로는1차로다.

네 자료의 회복 구간에서 표본상 셀18→하류 본선으로 이동한2,268대 중 직전 프레임에서1차로였던 차량은1대였다. 이 구간1차로 차량 표본은 적고 평균속도도88–103km/h로, 여기의 평균 저속을 느린 진출차로 하나로 설명하지 못한다. 상류에서 이미 차로를 바꾼 차량이 있을 수 있으며,5초 표본이 모든 경계 통과를 포착한 것은 아니다. 다음 본선 프레임에서 사라진 차량은 별도 미확인 분류이며 TTD로 인증하지 않았다.

이 기하 때문에 일반적인 강제 합류형 lane-drop 감속을 구분할 필요가 있는지 [명목 진출 차로 제외 시험](../exit_lane_drop/README.md)을 실제로 수행했다. 단독 변경은 회복을 악화시켜 기각했다.

정본 물리·계수는 변경하지 않았다. 신규 함수는 기존 진단 helper에만 추가했다. 추출 세션25638은exit0, 이후 캐시 분석도exit0. 검증 기록은 `../exit_lane_drop/verification.json`에 함께 있다.
