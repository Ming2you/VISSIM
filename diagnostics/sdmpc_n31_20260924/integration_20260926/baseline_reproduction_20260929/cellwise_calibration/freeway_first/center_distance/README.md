# 비균일 셀의 중심 거리 시험 — 계수 고정 후보 기각

## 변경과 범위

기준은 route036, 현재 목적 경로 재고와 동적 off-ramp 진입·저장·배수다. 셀 길이가 다를 때 기존 속도식의 convection·anticipation이 모두 로컬 길이 Li를 사용하는 영향을 시험했다. 동측 내부 셀1–29에서 속도 경사 거리는 (Lprev+Li)/2, 밀도 경사 거리는 (Li+Lnext)/2로 바꿨다. 셀0·30의 가상 경계는 유지했다.

차량 보존, FD, 실제 합류, 합류 감속, lane-drop, 저장·수용 계산의 길이는 원래 Li다. 물리 상태 자체는 바꾸지 않았다. 진단 hook에서 동등한 상류속도·하류밀도 인자로 경사만 변환했고, 실제 anticipation 분기가 보존됨을21,750회 검사했다. recovery_relaxation은 기준 모델에 없어 절대 하류밀도 조건을 잘못 바꿀 위험이 없었다. 음수 동등인자는 clipping하지 않았으며 이번 런에서는 발생하지 않았다.

이는 비균일 격자의 한 후보이며 기존식의 버그를 확정한 것이 아니다. 기존 보정 계수가 로컬 길이 계산에 맞춰졌을 수 있어, 고정 계수 후보의 실패만으로 중심 거리 이산화가 일반적으로 잘못됐다고 할 수 없다.
