2026-09-29. 이전 설명 턴은 NO_PROGRESS. 이번에는 **새 자율450초 예측6회 완료**, 추가 계수 탐색0·VISSIM0·optimizer0·push0이다. 목표 ACTIVE / NOT_QUALIFIED. 최신 도시 경로/도착 수정본에 미리 선택해 둔159계수 후보를 연결했지만, 전체 이득 검증은 통과하지 못해 정본으로 채택하지 않았다.

## 변경과 확인

기준은 ../../sc1001_native_choices/candidate_config.json이다. 기존 manifest의 reference_config만 jacobian_step/trust_0.15/reference_config.json으로 교체했다. 이 파일은 이전 seed29 학습에서 이미 동결했으며 이번 seed43·47 결과로 다시 고르거나 보정하지 않았다.

새 reference와 기존 reference는 freeway.physical_cell_fd 및 freeway.state_response만 다르다. source-pinned 정본 로더를 실제 실행해 동측31셀의 FD/응답 계수 설치를 확인했다. 서측 FD/응답·기하·방향 기본계수·포트 프로필·도시 경로·수요·실행 명령은 유지했다. 기존 내부1초·동적off-ramp·VSL 이력·램프 대기/보존을 유지한다. 후보는 실험 설정이며 정본 runner를 복제하지 않았다.

두 예측 묶음은 seed47@2700 RM 유지/완화와 seed43@2250 NC/RM/VSL/결합이다. 이전과 초기 원시 파일 해시,10484 초기 재고,모든 실행 명령이 정확히 같다. 세150초 블록의 액추에이터/변경폭 검사를 통과했다. 8램프 최대 보존 잔차6.395e-13대,10개 실행 코어 파일 해시는 변하지 않았다. 실행 세션23724·21270은 모두exit0로 종료했다.

seed47 완화 손해의 오차는 줄었고 seed43 VSL 손해도 가까워졌다. 그러나 seed43 결합 이득의 부호는 계속 틀린다. 실제 순위는 RM→결합→NC→VSL이고 두 예측 모두 RM→NC→결합→VSL이다. 가장 좋은 후보 하나를 맞췄다고 다른 후보의 손익 오류까지 통과시키지 않는다. 한편 이 자료를 보고 또다시159개 계수 탐색을 반복할 근거도 없다.

Ω 밖 추적 재고의 비용은 별도로 기록했다. seed47 완화 Δ외부비용은 이전−0.002690/후보−0.0000945veh·h, seed43 각 제어는 절댓값4.1e-6veh·h 이하이다. 이는 **모델이 추적한 외부 비용**이며 실제 미삽입 대기까지 완전히 검증한 총비용이 아니다. seed43 동일450초의 native 미삽입 대기 기록 부족은 계속 남는다. 목적함수는 Ω TTT 그대로다.

## 기존 진단과 연결

ramp_entry_space/wave_audit.json의 기존 수용파 진단도 함께 검토했다. 도시부 파속3.2557m/s 또는 기존10484 서비스 상한1800대/h에서 얻은3.8533m/s를 그대로 적용하면 hold 실제72대 도착을 약67.85–68.98대로 제한한다. 도시 파속이 램프에도 맞는다는 근거는 없고, 서비스 상한도 도로의 자유 방출 용량을 뜻하지 않는다. 이 조건부 진단은 미래 head 통과/도착을 원인 분리용으로 썼으며 자율 예측·신규 보정으로 세지 않는다. 따라서 이 수용파나 임의 저장상한을 운용 모델에 넣지 않았다.

이미 완료된 RESPONSE2220_RESULT.md에서는 seed43 RM/결합의 상당 부분이 실제 미래 도착 차이를 알려주면 설명됐다. 그 실험은 더 이른2220초 구성요소 범위이므로 이번2250초 전체Ω와 숫자를 직접 차감하지 않는다. seed29에서는 미래 도착을 알려줘도 방출/회복 반응이 부족했다. 다음 물리 보정의 판별 상태는 이 seed29 반응을 우선 재사용하고, seed43의 삽입·도착 차이를 본선 계수로 무조건 흡수하지 않는다.
