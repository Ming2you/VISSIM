# Bounded-METANET 유한 보정 시험 — 미채택

기존 31셀 속도식의 큰 항 사이 상쇄가 제어 반응을 약하게 만드는지 검토하려고, [Zhao 등(2025)의 preprint](https://arxiv.org/html/2503.17680v1)의 가상 밀도 기반 이완식(Eq.13–17)을 제한적으로 적용하고 다시 보정했다. 논문의 SUMO·실측 검증은 우리 망의 RM+VSL MPC 성공을 보장하지 않는다. 이번 계산도 논문의 완전 재현이나 전역 최적화가 아니다.

완료 결과는 **기존보다 나빠 미채택**이다. 후보 50개에 대해 450초 예측 400개와 기본값 회귀 확인 2개를 실행했다. 보정·예측 경과시간은 약373초이며 VISSIM 시간이 아니다. optimizer는 nfev=5, njev=5에서 예산을 소진했고 수렴하지 않았다. 학습 기준 미통과이므로 계획한 seed43 확인은 실행하지 않았다.

## 변경 범위

기존 셀별 FD 차이와 실제 수용·합류·동적 off-ramp 저장/배수, 차량 보존 및 VSL 노출 이력을 유지했다. 실현된 합류량과 동적 차로 감소가 가상 밀도에 들어가고, 기존 명시적 convection/anticipation/merge/lane-drop 감속을 중복 적용하지 않았다. 고밀도/저밀도 하류 방향에 서로 다른 anticipation 계수를 허용했다. 원식과 달리 초기 관측 속도가 보정된 자유속도보다 클 수 있어 가상 밀도 내부의 속도 가중치만1에서 제한했다. 실제 재고·속도를 그 값으로 잘라 맞춘 것은 아니다.

공통 anticipation 두 계수, kappa, tau, 앞/뒤 합류 계수, lane-drop 계수, 기존 임계밀도/FD형상 배율의9변수를 보정했다. 초기값·범위·최대 예산은 protocol.json에 고정했다. 기존 31셀 개별159변수 보정과 다른 실험이며, 그 실험을 대신하는 결과로 해석하지 않는다.

학습은 seed29의2220.1초 네 조건 및2670.1초 RM 유지/완화±VSL 네 조건이다. 목적은 기존 상태 손실 + 제어쌍 반응 손실×2 + 계수 변화 제한이다. **controller의 Ω TTT 목적은 바꾸지 않았다.**

## 검증·보존

- 가상 밀도 식·범위 400개 검사, 효과0 동일성, 잘못된 합류 입력3개 거부를 확인했다. 전체 AD 검증은 하지 않았다.
- 기능 비활성 상태의 초기/후기 기본 예측은 cells/flows/ports/ramps 모두 기존과 정확히 일치했다.
- 두 production 파일을 시험 전 바이트로 복원하고 해시를 확인했다. 기존 다른 dirty 변경은 유지했다. 실행본은 executed_sources/, 이전본은 before_sources/에 보존했다.
- run.py는 당시 실행본과 함께한 기록이다. 복원된 production에서 그대로 재실행하면 동일 시험으로 간주할 수 없다. 자동으로 소스를 재변경하거나 재실행하지 않는다.
- 첫 SciPy 접근 실패는 rollout 전 발생했고 run.log에, 기존 설치 접근 허용 후 동일 실행은 run_retry1.log에 남았다.
- 새 VISSIM·push 없음. 기존9000 STOP 해시 유지. summary.json, selection.json, final_verification.json이 수치·복원 근거다.

다음에는 같은 두 초기 상태의 계수 탐색을 반복하기보다, 기존 동일 시나리오 자료의 시간대와 관측 상태 범위를 확장할 수 있는지 확인한다. 별도 상태·전체Ω·SDMPC 선택 검증은 여전히 미완료다.
