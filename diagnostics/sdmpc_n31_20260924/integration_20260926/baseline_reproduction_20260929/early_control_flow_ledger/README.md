# 셀별 공동 보정 이후: 입력 변화와 방출 반응 분리

완료한 기존 예측과 관측만 재사용했다. 새 rollout·VISSIM·계수 변경·push는 없다. `summary.json`은 실제/기존/공동 보정 후보의 공통 초기 상태 2220.1–2670.1초를 비교한다. `receiving_contract.json`은 같은 예측의 램프 수용 계산을 확인한다. 이 결과로 새 계수를 채택하지 않았다.

## 1. 현재까지 셀별 보정이 보여 준 것

31셀 각각의 임계밀도·FD 형상·이완시간·밀도차 부호별 anticipation, 합류 4셀의 감속계수까지 159변수를 공동으로 조정했다. 셀은 연결된 상태로 450초를 예측한다. 모든 물리 계수를 자유롭게 한 것은 아니다. 자유속도·kappa·lane-drop phi·VSL 법칙 A/E·램프 gap 계수는 이번 보정에서 고정했다.

상태 오차만 보정하면 학습 상태 손실은 17.1% 줄었지만 제어 반응 손실은 36.2% 증가했다. 반응을 포함한 보정과 직접 Jacobian 갱신은 학습 반응 손실을 기존 대비 17.9% 줄였고, 확인용 seed43에서는 1.8% 증가했다. 제한된 보정 결과이며 전역 최적점이나 셀별 보정의 불가능성을 뜻하지 않는다. seed43도 이미 열람한 확인 자료다.

따라서 셀별 계수 자체는 유지 가능한 방법이지만, 속도 적합 개선을 제어 이득 재현으로 대신할 수 없다. 아래에서는 보정에 사용한 비용 차이가 무엇으로 발생했는지 분리했다.

## 2. 본선 TTT 변화의 보존식 분해

초기 재고가 같고 셀별 보존이 성립하면, 동일한 30초 재고 사다리꼴 적분에서 다음 식이 정확하다.

`ΔTTT_main = Σ(유입 변화 + 합류 변화 − 진출 변화 − 말단 유출 변화) × (평가 종료 − 구간 종료 + 15초) / 3600`

각 항은 차량 수뿐 아니라 통과 시각을 포함한다. 이것은 **회계적 항등식**이며, 특정 항을 빼고 나머지를 독립적인 인과 효과로 해석하면 안 된다. 제어가 입력과 출구 통과를 함께 바꿀 수 있다. 단위는 veh·h, 음수는 NC 대비 본선 체류시간 감소다.

| 실측 | 본선 입력 항 | 램프 합류 항 | 진출 분기 항 | 말단 유출 항 | 본선 ΔTTT |
|---|---:|---:|---:|---:|---:|
| seed29 VSL | +0.0167 | +0.0917 | −0.2208 | −0.2625 | −0.3750 |
| seed29 RM | +0.0708 | −0.3875 | −0.4208 | −0.2625 | −1.0000 |
| seed29 both | +0.1625 | −0.6375 | −0.4042 | −0.2208 | −1.1000 |
| seed43 VSL | +0.5000 | +0.1083 | +0.0083 | +0.1458 | +0.7625 |
| seed43 RM | −1.5917 | +0.0667 | +0.0875 | +0.2375 | −1.2000 |
| seed43 both | −1.1875 | +0.1042 | +0.2333 | −0.2833 | −1.1333 |

**seed29 RM:** 최종 본선 입력은 7대 적지만, 시각까지 반영한 입력 항은 +0.0708이다. 따라서 ‘입력 7대 감소가 RM의 본선 TTT 이득을 설명한다’고 해석하면 틀린다. 진출 분기와 말단의 실제 통과는 합계 22대 증가했다. 공동 보정 모델은 1.504대 증가만 예측한다. 방출 관련 TTT 항은 실측 −0.6833, 모델 −0.0354로 반응이 작다. 합류 감소는 실측 3대, 모델 6.374대로 이미 모델에 나타난다.

방출 반응은 셀23만의 문제가 아니다. 실측 RM은 셀18의 하류 통과 +27대, 셀19 +25대, 셀20의 진출 분기 +9대, 셀22의 하류 통과 +13대였다. 셀11·18–22 주변에 체류 감소가 분포한다. 이 위치는 원인 후보를 좁히는 근거이며 특정 속도식 계수가 틀렸다는 증명은 아니다.

**seed43 RM:** 실제 합류는 2대 증가, 진출+말단 통과는 8대 감소, 본선 입력은 18대 감소했다. 본선 재고 감소에는 입력·시각 변화가 크게 기여한다. 이를 모두 ‘합류 억제로 방출능력이 개선됐다’는 목표로 학습시키면 물리 반응을 잘못 보정할 수 있다. 입력 차이가 제어에 따른 삽입 제한인지 확률적 차량 생성/진행의 차이인지는 이번 회계로 구분하지 않았다. seed43를 검증에서 제거하거나 실패한 반응 예측을 성공으로 재분류하지 않는다.

모델의 램프 대기 증가는 차량 보존에 따른 비용이다. seed29 RM 공동 보정의 합류 항 −0.1775와 램프 대기 +0.1775는 같은 예측 도착량에서 상쇄된다. 이 비용을 지우거나 임의 보상으로 처리하지 않는다.

## 3. 비용 영역을 혼동하지 않는다

위 표는 **동측 본선 31셀만** 포함한다. 진출 분기는 본선에서 connector로 들어간 사건이며 Ω TTD가 아니다. 램프·도시·외부 대기는 표에서 제외했다. 공동 보정 보고서의 ΔTTT는 동측31셀+8connector이므로 수치가 다르다.

기존 VISSIM 누적 기록의 whole-network/외부 대기 진단도 별도로 유지했다. seed29 RM은 도로망 TTT −0.8714, 외부 대기 +0.2870, 합계 −0.5844였다. seed43 RM은 도로망 TTT −1.1899, 외부 대기 +1.6798, 합계 +0.4899였다. 이것은 Ω 정의를 변경한 목적함수가 아니라 별도 진단이다. seed43의 낮은 내부 TTT만 보고 전체 대기까지 개선됐다고 해석하면 안 된다.

## 4. 셀별 임계밀도가 램프 수용 계산에 연결되는가

현재 비 two-branch 경로의 `effective_rho_crit`는 방향 스칼라 37.8을 반환한다. 속도식에 들어가는 합류셀10/12/21/23의 기존 국소 임계밀도는 42/21/47.04/39.2다. 즉 값의 전달은 같지 않다. 다만 이 차이가 이번 RM 반응 부족의 원인인지 실제 작동 제한을 먼저 검사했다.

각 seed·4조건·450초·4램프, 기존과 공동 보정 후보 각각 14,400개의 저장된 수용 질의를 확인했다. **28,800개 모두** 밀도 기반 상한보다 gap 수용 상한이 더 낮았다. 이것은 제시 가능한 수용 예산에 관한 결과이며, 실제 차량 방출이 항상 그 예산에 도달한다는 뜻은 아니다. head 서비스·현재 차량 가용량·이동시간도 남아 있다.

기존 식의 전역 임계밀도만 국소 nominal 값으로 치환한 경우를 저장된 min 피연산자로 경계 계산했다. 기존 모델 14,400개는 수용 예산이 그대로다. 공동 보정 후보는 14,396개가 그대로이며, 나머지는 seed43 셀21의 같은 1초가 4조건에 반복된 경우다. 그 1초의 최대 예산 감소도 조건당 0.000793대다. 이 값은 바뀐 전체 자율 예측의 상한이 아니라 **같은 상태에서의 질의 예산 차이 상한**이다. VSL에 따른 새 임계밀도 법칙까지 시험한 것은 아니다.

따라서 이 연결 차이는 명시해야 하지만, 이번 자료에서 이를 고치는 것만으로 큰 합류·방출 이득이 회복된다고 볼 근거는 없다. 작동하지 않는 수용 항을 더 세게 보정하는 대신, 실제 gap/head/재고 제한과 합류 이후 본선 방출 반응을 함께 봐야 한다.

## 검증과 다음 작업

셀·구간별 보존 11,160건을 확인했고 최대 잔차는 1.57e−13대다. 실제 미설명 유입·손실·삭제는 0, 공통 초기 재고는 일치한다. 관측 및 예측 해시는 저장된 프로토콜과 대조했다. 수용 감사는 기존 저장 결과를 읽었고 모델을 수정하거나 예측을 새로 실행하지 않았다.

다음 보정에서도 셀별 값은 허용하되, 입력 오차를 물리 계수가 대신 흡수하지 않도록 경계 유량과 제어 반응을 구분한다. 우선 seed29 초기 상태의 셀18–22 방출 반응과 기존 후기 RM 완화 손해를 함께 유지하는 수정 근거가 필요하다. gap 계수를 단순히 풀거나 밀도 상한을 낮춰 RM을 켜는 방식은 성공 기준이 아니다. 계수 추가 탐색 전에 실제 합류 시각·본선 누적 방출·대기 비용의 차이를 확인한다. 전체 Ω·독립 상태·SDMPC 선택 검증은 여전히 남아 있다. 목표 ACTIVE / 이득 보정 NOT_QUALIFIED.
