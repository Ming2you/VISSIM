2026-09-29. **목표 ACTIVE / NOT_QUALIFIED.** 새 VISSIM 런·FZP 스캔·계수 재적합·운용 설정 변경·push는 없다. 기존 runner의 입력 캡처와 예측 기능을 확장했다.

## 완료 범위

- seed29·43 공통2220.1초 상태에서 450초,2250초부터 VSL90 및 RM g8→6→4의 기존 네 명령을 재생했다. 이것은 완료된 고정 명령 분기 실험이며, 900초부터 시작한 ALINEA 정책 전체와 동일하지 않다.
- 최신 모델의 자율 예측8회, 실제 미래 본선·램프 도착량만 알려주는 조건부 진단8회, 기존 E4를 복원한 단일 반증 후보12회로 총28회 완료했다. 조건부 진단은 실제 예측 또는 제어 선택에 쓸 수 없다.
- 자율8회는 이후 확인한 과거 `local_merge_cell23/nu0.25_delta2/s{29,43}_early_*.json.gz`와 cells/flows/ports/ramps가 모두 정확히 같았다. 새 개선 결과로 세지 않는다. 이후 비교는 그 기존 캐시를 재사용했다.
- 모든 예측 유효, 최대 보존 잔차1.16e-12대 미만. 본선·램프 초기 상태와 과거 관측 제한 검사, 물리 소스/manifest 해시, 입력 해시를 확인했다. E4에서도 VSL 없는6조건의 물리 배열은 기존과 정확히 같았다.
- 최초 실행은 계수 JSON 포장 문서를 그대로 전달하여 예측 시작 전 동일성 검사에서 실패했다. 숫자는 바꾸지 않고 `parameters` 필드를 읽도록 고쳤다. 실패 기록과 입력은 보존했고, 올바른 입력·결과는 `_v2`에 저장했다.

## 이전 보정이 VSL 반응을 약하게 만든 경로

기존 `decision_response/train_d*_e*.json`의 완료된 요인별 비교를 재사용했다. E는 Carlson 기반 **plant FD 형상 계수**이며, 실제 VSL 제어 알고리즘이나 속도 명령 자체가 아니다.

같은 δ를 유지한 E4→E2 변경은 초기 이득 예측을 악화시키지만 늦은 손해 방향은 개선한다. 최신 모델은 여기에 셀23의 회복 방향 anticipation과 합류 감속 보정을 더해 초기−0.0029,늦은+0.2319가 됐다. 모든 차이를 셀23 변경 하나로 설명하면 안 된다.

## 전체 Ω 비용에서도 최적화 이전에 나타나는 오류

기존 `closedloop_recorded2250_lever450_trace10484_head10119_s43_v2`의 네 조건 예측을 재사용하고, 실제2250.1–2700.1초91개 Ω 재고 표본을 다시 적분했다. 명령표·재사용 관측 증빙의 해시를 확인했다. 예측은2250초에서 시작하므로0.1초 관측 위상 차이를 유지한다. 앞의2220초 component 시험과 구간·범위가 다르다.

도시 신호를 고정하고 실제 명령을 직접 넣은 계산이며 optimizer 반복은0이다. **RM 이득의 과소평가와 결합 손익 오류는 이미 후보 비용 계산 단계에 존재한다.** 이를 SDMPC 탐색 실패만으로 설명할 수 없다. 이 실험은 N_P/N_UF 예산 선택을 평가하지 않았으므로 모든 제약이 통과했다고도 말하지 않는다.

정확히 이 구간의 native 미삽입 대기는 기존 기록에 없으므로2220–2670초 비용을 가져와 더하지 않았다. 근거는 `fullomega_saved_response_link.json`이다. 이 전체 Ω 연결 확인에는 추가 예측·native 실행을 하지 않았다.
