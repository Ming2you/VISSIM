# RM+VSL 통합 MPC 문헌과 최소 보정 방향

2026-09-29. 사용자 요청에 따른 문헌·기존 결과 검토. **이득 보정 미완료 / 목표 ACTIVE / NOT_QUALIFIED.**
이번 검토 중 새 native 런, 새 계수 적합, SDMPC 최적화, 생산 모델·설정 변경, push는 하지 않았다.
준비하던 DSD 평균/분포형상 분리 실험은 보류했다. 준비 함수는 배경 그림 sidecar 누락으로 native 실행 전에 실패했으며, 일부 source 자산만 남아 있다. 완료·실행 중인 실험으로 취급하지 않는다.

**판단:** 작은 보조 항으로 충분할 가능성은 남아 있다. 다만 이미 시험한 FD·합류·anticipation 계수의 조합을 계속 늘리는 근거는 약하다. 알려진 정책의 제어 반응을 기준으로, 기존 METANET의 국소 속도/방출 오차를 제한적으로 보정하는 편을 우선한다. 문헌이 우리 망에서 통할 보조 항을 확정해 주지는 않는다.

## 3. 작은 보조 항에 더 직접적인 참고 문헌

**Frejo et al. 2018/2019 — 명령별 FD·준수율.** VSL에 따라 자유류 속도, 임계밀도, FD 형상, 준수율을 구분한다. A12 관측에서는120→90으로 제한할 때 용량이 감소하고 임계밀도가 증가했다. VSL 이득을 “속도를 낮추면 capacity 증가”로 넣으면 안 된다. 우리에는 이미 Carlson/Frejo 함수가 있으므로 새로운 항으로 중복 추가하지 않는다. 기존 코드의 `literature_vsl_parameters`와 문헌의 변환 구조가 대응한다. [2018 원문 식(3)–(4)](https://www.dcsc.tudelft.nl/~bdeschutter/pub/rep/18_008.pdf), [2019 논문](https://www.sciencedirect.com/science/article/pii/S0968090X18303310).

**Fang et al. 2019 — anticipation 반응의 상태 의존 보정.** VISSIM 기반 VSL-MPC에서 차량 간격·가속도를 이용해 anticipation의 반응 거리를 보정한다. RM+VSL 통합 검증은 아니지만 “거대한 모델 교체 없이 반응항을 고친다”는 질문에는 직접 관련된다. 단, 우리 과거 가속도/분산 진단도 자율 예측에 연결하면 개선이 유지되지 않은 사례가 있다. 미래 간격·가속도가 어떻게 예측되는지 확인하지 않은 채 측정값을 지평 전체에 주입해서는 안 된다. [원문 §3.1.2, 식(13)–(19)](https://onlinelibrary.wiley.com/doi/10.1155/2019/8151582).

Hegyi2005의 통합 METANET-MPC는 중요한 기초이지만 이 검토의 미시 검증 증거와 구분한다. [원 논문](https://www.sciencedirect.com/science/article/pii/S0968090X05000264).
Sun2023 학위논문의 SUMO 검증은 확인한 부분에서 도시 신호 PMPC 장이므로, 그 문구를 freeway RM+VSL의 SUMO 검증으로 인용하지 않았다. [학위논문 §3.5](https://www.dcsc.tudelft.nl/~bdeschutter/research/phd_theses/phd_sun_2023.pdf).

PDF 텍스트와 HTML 수식을 확인했다. 일부 PDF 화면 확인은 도구 cache miss로 실패했으므로 시각 검증을 완료했다고 하지 않는다. 위 제안식은 원문 식의 전사본이 아니다.

## 4. 권장 방향: 작은 '반응 보정' 한 가지, 제어 보너스는 아님

**아래는 문헌과 우리 결과를 연결한 제안이지, 해당 논문의 공식이나 검증 완료된 모델이 아니다.**

첫 후보는 기존 METANET 속도 갱신의 병목 영향 구간에 제한된 작은 상태 의존 잔차다.

```text
v_next = F_METANET(x, u) + Δt · r_theta(z)
z = 현재/하류 밀도·속도, 실제 예측 합류량,
    현재 예측 off-ramp 재고, 해당 차량군에 도달한 VSL 명령
```

- r_theta는 가감속 보정이며 양·음 방향을 허용한다. 초기에는 선택된 한 병목 영향 구간의 공통 계수2–3개 이하로 제한한다. 모든 셀·seed·시각별 계수를 만들지 않는다.
- 목적은 절대 속도를 완벽히 맞추는 것이 아니라 **같은 상태에서 RM/VSL을 바꿨을 때 달라지는 방출·재고·대기**를 맞추는 것이다.
- 기존 합류/anticipation/이완 항이 이미 설명한 효과는 중복 차감하지 않는다. 특정 항이 오류의 근원이라면 해당 항을 대체·보정하고 유사 항을 여러 겹 쌓지 않는다.
- 보정한 속도로 기존 유량·보존식을 계산한다. 보정 과정에서 제약·상한·속도/유량 정합·보존 검사를 유지한다. `VSL ON ⇒ +capacity`, `RM ON ⇒ -TTT` 같은 항을 넣지 않는다.
- 실제 합류는 요청 metering rate와 다르다. 램프 큐/도착/서비스/본선 수용을 통과한 실제 예측 합류를 사용하며 대기 비용과 동적 off-ramp는 유지한다.
- 현재 모델에서 q=Nv/L이 방출을 제한하고 있다면 용량 상한만 올려도 q는 늘지 않는다. 그러므로 속도 반응의 과도한 저하를 남겨 두고 capacity 보조 항만 붙이는 것은 우선순위가 낮다.
- 반대로 속도·재고를 맞춘 상태에서도 수용 상한이 잘못 걸린 근거가 있다면, 그때는 속도 잔차 대신 기존 sending/receiving 부분의 작은 보정을 택한다. 두 경로를 동시에 재적합하지 않는다.

단순한 공통 속도 bias는 일부 상태를 개선할 수 있어도 후보 간 이득 순위를 보장하지 않는다. 무조건적인 회복 가속도도 RM 완화로 실제 혼잡이 지속되는 경우까지 빨리 풀어버릴 수 있다. 작은 항이 충분한지는 아직 미확인이다.

## 5. 다음 검증은 제한된 예산으로 결정

이번에는 실행하지 않았다. 다음 작업의 범위를 아래처럼 제한하는 것이 적절하다.

1. 기존 기준·제어쌍에서 경계 방출 오차와 속도식 오차를 재사용해 잔차 후보 한 종류만 고른다. 차로 상태 전수 확장이나 새로운 native 분포 실험을 자동으로 재개하지 않는다.
2. 적합 목적에는 절대 상태 오차뿐 아니라 제어쌍의 누적 방출 차이와 ΔTTT 오차를 포함한다. 보상 함수는 Ω TTT 그대로이며, **학습 손실**과 **운용 목적함수**를 구분한다.
3. 초기 학습 예산은 계수 후보 최대6개×네 명령=24개 rollout. 선택한 한 후보만 고정하여 기존 세 상태×네 명령=12개로 반증한다. 기준 캐시는 재사용한다. 이 예산은 제안이며 아직 후보 적합을 시작하지 않았다.
4. seed29의 VSL 이득, seed43의 VSL 손해, 늦은 RM 완화의 손해를 함께 구별해야 한다. 미미한 차이의 정확한 부호나 완벽한 궤적 일치를 요구하지 않는다. 램프·도시 대기로 비용이 이동한 결과를 본선 이득으로 포장하지 않는다.
5. 이 자료들은 이미 여러 번 열어 본 확인 자료다. 후보가 통과해도 미사용 holdout으로 부르지 않으며, 정본 채택 전 새 상태/seed의 검증이 필요하다. 실패하면 같은 구조에서 더 촘촘한 계수 탐색을 반복하지 않고 실패 이유를 보고한다.
6. 물리 반응이 확인되면 ALINEA+고정90 기준 명령을 명시적 SDMPC 비교 후보로 넣는다. 모델이 기준 정책을 잘못 평가하는지, 제약에 막히는지, 더 좋은 후보를 놓치는지 따로 판정한 후에만 새9000초 평가로 진행한다.

**진행 방향:** 작은 보정으로 기준 정책의 손익을 재현할 수 있는지 먼저 판정한다. 문헌의 성공을 이유로 우리 simulator·수요·목적함수를 유리하게 바꾸거나, 큰 모델을 새로 만드는 방향은 이번 검토의 권고가 아니다.

## 6. 사용자 추가 요청: 특정 셀만 따로 calibration

2026-09-29 추가 검토. **국소 보정도 명시적인 비교 대상으로 포함한다.** 아래는 후속 설계이며 새 계수 적합이나 정본 승격 결과가 아니다. 이번 추가 검토에서는 기존 보고서·코드·원문만 읽었고 native 실행, FZP 재읽기, 생산 코드·설정 변경, push를 하지 않았다.

국소 보정 자체는 타당한 선택이다. 위 Hajiahmadi2016의 §V-B/Table II는 VISSIM으로부터 각 링크의 자유류 속도·혼잡파 속도·정체밀도·용량을 별도로 추정한다. 이는 LTM 사례로, METANET의 특정 셀 계수를 따로 바꾸면 우리 이득이 복원된다는 직접 증명은 아니다. Wang2019 식(3)–(4)도 구간별 수용·병목 제약을 사용한다. Fu2023 §4.1은 합류 영향 확인을 위해 225m 합류 구간을 따로 둔다. 우리에는 이미 짧은 물리 셀이 있으므로 세분화를 반복하기보다 그 구간의 반응 정합을 점검하는 근거로 사용한다.

### 구간과 계수를 함께 제한

셀 번호는 동측31개 물리 셀의 **0기준**이다. 모든 구간을 한꺼번에 맞추지 않고, 현재 상태를 넣어도 남는 오차와 실제 경계 방출 오차가 큰 구간 하나를 먼저 선택한다.

|검토 구간|검토 이유|제한적으로 검토할 대상|
|셀17–20, 특히18|10481 진출·차로 수 변화 부근의 과도 감속과 상류 전파|실행 중인 lane-drop/anticipation 및 방출 관계. 단순 차로 수 차이를 모두 강제 합류 손실로 간주하지 않는다.|
|셀21·23|10490·10484의 실제 합류에 대한 본선 손실|실제 예측 합류량에 반응하는 기존 merge 계수. 셀22는 우선 전달 오차의 확인 대상으로 두고 독립 계수를 만들지 않는다.|
|셀24·25|합류 직후 회복·방출 편향|두 셀이 공유하는 회복/이류 반응. 단순 회복시간 단축이 실패한 결과를 재사용하고, 상류에서 전달된 오차와 자체 반응을 구분한다.|

형태는 `theta_i = theta_current_i + mask_group(i) * delta_theta_group`로 제한할 수 있다. 기존 셀별 설정을 기준으로 선택 구간의 계수1–2개만 바꾸며, 비대상 계수는 고정한다. 다른 구간의 **예측 결과**는 전파 때문에 달라질 수 있으므로 전역 재고·방출도 확인한다. 기존 계수로 설명되지 않는 근거가 있을 때만 같은 구간에 작은 상태 의존 보조항 한 종류를 비교한다. 두 방식을 처음부터 동시에 넣지 않는다.

기존 `freeway_fd.py`의 `state_response.cell_overrides`가 이완·anticipation·합류 계수의 국소 설정을 지원한다. 새 adapter나 셀마다 다른 실행 경로를 만들 필요가 없다. lane-drop이나 수용식 변경은 해당 기존 계산 위치에서 별도로 검증해야 하며, 지원되지 않는 설정을 이미 연결되어 있다고 취급하지 않는다.

### 이미 실패한 국소 후보를 새 작업처럼 반복하지 않음

- [셀17–20 anticipation](local_anticipation_17_20/README.md): 학습150초 속도RMSE는34.40→15.49km/h로 줄었지만, 다른seed의450초는17.19→26.75로 악화했다. 이득이 있던seed29 VSL도 손해로 뒤집었다. 같은 배율을 더 촘촘히 탐색할 근거가 없다.
- [셀24·25 회복시간](../closedloop9000_d4e2_analysis/recovery_cells24_25/README.md): 일부 평균속도는 개선했지만 실제 RM 완화의 손해와 누적 방출 손실을 더 잘 설명하지 못했다. 기존/셀23만/회복만/양쪽 비교는 이미 완료했으므로 그 자체를 다시 제안하지 않는다.
- [실측 상태·이동 차량 속도](observed_state_pressure/README.md): 셀24로 다음5초에 이동하는 차량은 이동 전부터 상류 평균보다 약11–16km/h 빨랐다. 현재 관측 분산을 쓴 한 계수 관계가 이를 일부 설명했지만, 미래 분산의 자율 예측이나 제어 이득을 검증한 것은 아니다. 이류 보조항의 후보 근거일 뿐이며, 유출 차량이 상류 평균에 미치는 반작용까지 포함하지 않은 속도 가산을 바로 채택하지 않는다.

### 국소 보정의 채택 기준

적합 목적은 속도만이 아니라 **제어쌍의 누적 방출 차이와 ΔTTT**, 국소 재고·유량 오차를 포함한다. 이는 학습 손실의 변경이며 운용 Ω TTT 목적함수는 유지한다. 계수 변화에는 기준값에서 벗어나는 크기와 자유도를 제한한다. 모든 셀·항을 동시에 적합하여 서로의 오차를 상쇄하게 하지 않는다.

위 §5의 유한 예산을 확대하지 않는다. 새 근거를 가진 국소 후보를 최대6개 안에서 비교하고, 통과한 하나만 고정해 다른 상태에서 확인한다. 지금까지 실패한 후보를 그 예산에 넣어 재실행하지 않는다. seed29 VSL 이득·seed43 VSL 손해·RM 유지/완화의 큰 손익을 함께 구별해야 한다. 기존 자료는 여러 번 본 확인 자료이며 최종 채택에는 새 상태/seed가 필요하다. 작은 효과의 부호와 완벽한 속도 궤적은 성공 조건이 아니다.

**권고:** 전역 재보정보다 원인이 좁혀진 셀/구간의 소수 계수 보정을 우선 후보로 둔다. 그것으로 부족할 때 관측 근거가 있는 작은 보조항 하나를 비교한다. 국소 보정이나 보조항 모두 아직 성공이 보장되지 않으며, 전체 차량 보존·실제 합류·램프 대기·동적 진출 저장/배수는 유지한다.


## 7. 후속 실행 결과

위 검토 뒤 수행한 [국소 이류 보정](local_transport_response_24_25/README.md)은8개450초 예측에서 일부 회복 속도를 개선했지만 제어 반응 점수 개선은최대3.20%였고 전역 재고·유량 오차가 증가해 미채택했다. 실행 소스는 시험 전으로 복원했다. 기존 국소 anticipation·회복시간 시험과 다른, 실제 경계 유량을 이용한 양쪽 속도 모멘트 잔차였으며 미래 관측 입력은 사용하지 않았다. 이 실패를 모든 작은 보정의 불가능 판정으로 확대하지 않는다.
