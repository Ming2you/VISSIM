## 추가로 분리한 원인

기존 FZP 캐시만 읽어, 공통 초기 상태에 있던 차량10대를 양 조건에서 대조했다. 두 조건에서 **31번 도로의 첫 관측 시각·위치·차로·속도·경로가 동일**했다. 목적지도 모두1137:1이었다. 완화 시3115.1–3145.1초에10484로 진입했지만 유지 시3145.1초까지31번 도로에 남았다. 예:12355는 양쪽 모두3075.1초에31번에 도착했고, 완화에서는3115.1초에10484로 들어갔으나 유지에서는3145.1초에도31번396.61m,0.07km/h였다.

따라서 이10대의 차이는 SC1001 상류 도착이나 목적지 변경으로 설명되지 않는다. 램프 진입 전 대기·이동 반응이 확인된다. 다만 이 결과만으로 특정 wave speed·유효 저장공간·차로 변경식을 식별했다고 주장하지 않는다.

동시에 실제 미래1137 첫 관측 코호트는99대 중58대가 동측행이었다. 설정 확률0.5의 기대값49.5대와 다르다. 실현된58/99로 native 비율을 바꾸거나 미래 목적지를 예측 입력에 넣지 않는다. 모델의 유지 도착72.27이 실측72와 가까운 것에는 미반영 대기와 확률적 목적지 오차의 상쇄가 포함될 수 있다.
