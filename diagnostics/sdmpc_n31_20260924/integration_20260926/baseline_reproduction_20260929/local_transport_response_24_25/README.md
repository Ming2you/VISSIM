# 합류 후 국소 이류 보정: 일부 회복 개선, 이득 재현에는 불충분

2026-09-29. **8개450초 후보 예측 완료, 정본 미채택.** 기준 확인2회, 다른 상태의 자율 검증0회, 새 VISSIM0회다. 학습 단계의 사전 기준에 못 미쳐 추가 계수·상태 탐색으로 늘리지 않았다. 실행 코드는 보존하고 수정한3파일을 시험 전 바이트로 모두 복원했다. 목표는 ACTIVE / NOT_QUALIFIED다.

## 1. 국소 보정의 근거와 식

앞선 [차량 이동 진단](../observed_state_pressure/README.md)에서 셀24로 다음5초 동안 이동하는 차량의 **이동 전 표본속도**가 상류 셀23 평균보다11–16km/h 높았다. 관측 분산을 지평 전체에 주입하지 않고, 현재 두 셀의 속도차로 그 선택 편향을 근사할 수 있는지 먼저 확인했다.

`moving_before_speed - upstream_mean ≈ beta * max(downstream_mean - upstream_mean, 0)`

셀24·25로 들어가는 표본을 합쳐 seed29 NC만으로 가중 최소제곱을 적용했다. 절편·시각·명령별 보너스 없이 `beta=0.3421735677`을 얻었다. 이것은 새 문헌 공식을 전사한 것이 아니라 현재 상태로 계산 가능한 **경험적 근사**다. 실제 경계 순간속도라고 단정하지 않으며, 이동 차량의 미래 식별자는 학습 정답을 만드는 데만 사용한다.

|자료|보정 전 RMSE[km/h]|고정 beta 적용|
|---|---:|---:|
|학습 seed29 NC|10.09|4.46|
|확인 seed29 VSL|9.72|4.37|
|확인 seed43 NC|12.96|6.15|
|확인 seed43 VSL|11.29|5.14|

이 표는 관측 상태의 설명용 검사이며 자율 예측/제어 이득 검증이 아니다. 자료를 여러 번 검토했으므로 미사용 독립 검증으로 부르지 않는다. 탐색적 적합은 자율시험 프로토콜을 쓰기 전에 이루어졌고 그 순서를 `protocol.json`과 `explanatory_screen.json`에 명시했다. 기존 moment 캐시와 차량 이동 집계만 읽었으며 FZP는 다시 읽지 않았다.

자율 예측에는 같은 보정을 **실제 허용된 본선 경계 유량**에 적용했다. 출발 셀23·24, 도착 셀24·25에만 적용하며, 현재 예측 속도를 사용한다.

```text
epsilon_i = beta * max(v[i+1] - v[i], 0)
deltaP = accepted_flow[i] * dt_h * epsilon_i
N_after[i]   * delta_v[i]   = -deltaP
N_after[i+1] * delta_v[i+1] = +deltaP
```

빠른 차량이 상류에서 빠져나간 반작용을 함께 넣었다. 따라서 셀24·25에만 속도를 더하는 항이 아니며 셀23도 직접 영향을 받는다. 이 보정의 속도 모멘트 증감은 상쇄되지만, 전체 METANET이 물리 운동량 보존식을 따른다는 주장은 아니다. 출발 셀의 최저속도를 침범하지 않도록 양쪽에 동일한 전달량 제한을 적용했다. 실제8회에서는 이 제한이 한 번도 작동하지 않았다.

현재 step의 차량 유량·재고를 바꾸지 않고 다음 속도와 그에 따른 후속 유량이 달라진다. 실제 합류·램프 대기·동적 off-ramp·VSL 명령 이력·수요·Ω 목적함수는 유지했다. 전체 평균 이류 교체나 분산 상태 추가는 하지 않았다.

## 2. 제한된 재보정과 결과

국소 설명식의 beta와 그 절반 **두 값만** 비교했다. 각 값에 대해 seed29 공통2220.1초 초기상태에서 NC/VSL/RM/결합450초를 계산했다. 총8회다. 적합 평가에는 제어쌍의 ΔTTT, 진출+말단 누적 유출 차이, 실제 합류 차이를 사용했다. 각각0.5대·시간/50대/50대로 정규화한 제곱 오차의 합을 세 명령에 평균했다. 후보 결과를 보기 전에 최소20% 감소 및 전체 재고·유량RMSE 악화10% 이내를 정했다.

평가 범위는 **동측31셀+진입/진출 connector8개**, 동일30초 사다리꼴 적분이다. 전체Ω나9000초 정책 성능으로 확대하지 않는다.

|450초 ΔTTT[대·시간]|실측|기존|beta 절반|beta 전체|
|---|---:|---:|---:|---:|
|VSL|−0.3250|−0.00290|−0.01522|−0.00966|
|RM|−0.8250|−0.02978|−0.03451|−0.03517|
|결합|−0.8292|−0.03150|−0.05020|−0.04585|

반응 오차 점수는 기존2.1341 → 절반2.0658/전체2.0784로 **3.20%/2.61%만** 개선됐다. 실제 결합 제어의 진출+말단 유출 증가는30대인데 절반 후보는1.97대만 예측했다. 단순히 작은 이득의 부호가 다르거나 완벽한 궤적이 아니라는 이유로 기각한 것이 아니다. 큰 방출·비용 변화의 대부분이 여전히 빠져 있다.

전체 재고RMSE는10.70 →11.58/13.37대, 유량RMSE는1029.72 →1123.93/1297.27대/h로 악화했다. 전체 beta는10% 악화 제한도 넘었다. 후보 추가 세분화와 다른 상태의 자율검증은 실행하지 않았다.

## 3. 회복만 보면 개선으로 오인할 수 있다

|---|---:|---:|---:|---:|
|23|42.33|35.19|31.09|26.84|

24·25 회복 속도는 개선됐지만 이미 느리게 예측하던 상류23의 편향을 키웠다. 전역 재고가 늘고 제어에 따른 추가 방출은 거의 복원되지 않았다. 관측된 이동 차량 속도 관계가 좋다는 사실만으로 이 작은 동역학 보정을 채택할 수 없다.

이번 결과는 **현재 평균 속도식 위에 국소 이류 잔차만 얹는 방식으로 충분하지 않다**는 근거다. 모든 국소 보정이나 작은 보조항이 불가능하다는 증명은 아니다. 다음에는 회복 셀 속도를 더 올리는 것보다, 이미 감속이 과한 합류/병목 셀에서 어떤 반응을 유지·수정해야 실제 방출 차이가 살아나는지 기존 항 진단과 함께 판단해야 한다. 동일 beta를 더 촘촘히 탐색하지 않는다.

## 4. 검사·실패 기록·복원

- 보정의 속도 모멘트 상쇄·비대상 셀 불변·출발 셀 최저속도·beta0 무변화의250개 속성 검사 통과.
- 후보8회, 총7200번 경계 보정 적용. 전달량 제한0회, 최대 속도 변경1.349km/h/step. 보정 모멘트 최대잔차3.53e−13, 본선 차량 보존 최대잔차5.69e−14대. 램프·포트 보존 및 수치 검사도 통과했다.
- 첫 비활성 회귀 검사는 런타임tuple과 저장JSON의list 차이로 ramps 비교에서 실패했다. 후보 실행 전 실패이며 `first_default_failure.log`와 `default_failure_diff.json`을 보존했다. 추가 비활성1회로 원인을 분리해 저장했고, 같은 JSON 표현으로 비교하자 cells/flows/ports/ramps가 모두 정확히 일치했다. 기본 예측 총2회이며 추가 예측을 숨기지 않았다. 수정 재시도에서는 저장된 진단 예측을 재사용했다.
- `area_freeway_accounting.py`, `canonical_harness.py`, `replay_congested_component.py`의 실행 원문을 `executed_sources`에 보존한 뒤 모두 `source_before.json`의 SHA로 복원했다. 기존 dirty 변경은 유지했다. 후보 manifest는 실행 원문과 함께 사용해야 하며 현재 정본에는 시험용 설정 키가 없다.
- 실행 전 읽기 전용 프로세스 확인에서 Python/VISSIM/cscript 실행이 없었다. 어떤 프로세스도 종료하지 않았다. 실행61336은 종료코드0이며 남아 있는 이 시험 작업은 없다. 새 native와 push는 하지 않았다.
