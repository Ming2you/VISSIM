## 아직 통과하지 않은 부분과 다음 순서

1. 이번 상태에서는 VSL90 추가가 실제로도 손해다. 이를 맞췄다고 900초부터의 장시간 예방 이득을 재현했다고 하지 않는다. 다음은 **실제 VSL 이득이 있었던 공통 상태와 명령열**의 보존된 자료를 최신 모델에 재생하는 것이다.
2. 기존 네 정책의 혼잡 전·발생·회복 반응과 별도 seed를 비교한다. 정책별 실측 상태에서 재초기화한 예측은 반응 진단으로 쓰되 공통 상태의 인과 효과와 구분한다. 새 자료 재보정 없이 동결 검증을 먼저 한다.
3. 합류→방출/회복→램프·도시 대기→Ω ΔTTT를 통과한 뒤 ALINEA+병목 VSL90 명령을 SDMPC의 명시적 비교 후보로 평가한다. 명령이 불가능하면 물리/제약, 예측 비용이 잘못되면 모델, 낮은 비용인데 선택하지 않으면 탐색 문제로 분류한다.
4. 알려진 정책보다 나은 해의 장시간 검증은 그다음이다. 기존 9000초 SDMPC 실패는 보존하며, 재실행 성공 자체를 이득 검증으로 대체하지 않는다.

공통2670 상태는 기존 보정·진단에서 사용된 자료이므로 독립 holdout이 아니다. 이 결과만으로 전체 정책 재현 또는 목표 달성을 선언하지 않는다.
