## 실제 선택과 다음에 확인할 오류

- 실행에 영향을 준900–2850초14회 모두 동측 VSL을 선택했다.900초 S13=90, 이후 주로 S2/S5/S7/S13=100.2100초 이후 일부 해제,2550초부터 S13=90.
-8개 RM은14회 모두 녹색10초로 완전 개방이었다.
- PFO 최대2회, SDMPC 최대2회의 제한된 계산이다. 실제 반복·채택·수렴은 `sdmpc_decisions.json`에 각각 기록했다. 어떤 주기도 수렴했다고 주장하지 않는다.
-14개 결정의 동측 RM 국소 기울기324행 모두 비용·자원 기울기가 정확히0이다. 모두 자동미분의 현재 분기 기울기이며 실행 가능한 유한 이웃 비교는 수행되지 않았다.
- 이것은 ‘RM이 무효’라는 증거가 아니다. 실제로 허용된8/8/8초 및8/6/4초 예측에서 합류량·대기·비용이 달라지는지, 이어서 현재 제약에 들어오는지를 검사해야 한다. 도시부 및 VSL은 고정해 원인을 구분한다. 계수 전수 보정에 앞서 이 유한 변화와 선택 과정의 연결을 확인한다.
- 후속9개 고정 예측은 완료했다(`../closedloop3000_meter2700_sequence_v1/README.md`). 네 미터 모두 이 상태에서 유리한 비용 변화를 보이지 않았고,8/6/4초의 합류 감소도0.079–4.168대에 그쳤다. 국소 기울기0만으로 탐색 버그나 RM의 일반적 무효를 확정하지 않는다. 초기 보조 예측의 블록 적용 누락은 수정·격리했으며 실제 native SDMPC에는 해당하지 않는다.
- 같은 주기의 원래 held, PFO warm-start, 최종 selected 예측 비용을 분리했다. 서로 다른 초기 상태의 예측 감소량을 합산해 실측 이득으로 사용하지 않는다.
