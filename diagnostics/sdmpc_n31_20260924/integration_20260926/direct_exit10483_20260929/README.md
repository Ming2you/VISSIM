## 수정 범위

기존 `route_choice_corridor.py`에 **증명된 미래10483 유입분의 자유진출 목적지 표지**를 추가했다. 표지는 기존 공유 재고에 붙는 속성이고 별도 차량 재고가 아니다. 기존 `lane_offramp_runtime.py`에서 실제 수용된 배수량에만 붙이며, `urban_flow_accounting.py`의 기존 출구 용량·램프 수용 제약 뒤 실제 수락된 자유진출만큼만 줄인다. 목적지가 불명확한 초기 차량과 다른 도시부 유입은 기존 분기 규칙을 유지한다.

- 기존 저장 용량·이동시간·sending 비율·출구 서비스와 황색/미터/VSL 규약은 변경하지 않았다.
- 출구가 막히면 표지와 차량 모두 남는다. 자유진출 용량을 표지 차량에 우선 배정하지 않고 기존 자유진출 요청들과 비례해 공유한다.
- 네트워크 지문, 유일한 정적 경로, 연결 연속성, 하류 decision 부재를 검사한다. 공유 저장고에 Ω 외부 재고가 섞이면 조용히 비용을 혼합하지 않고 실패시킨다.
- `urban.preserve_direct_offramp_destinations=true`인 `candidate_config.json`에서만 사용한다. 이전 선택 설정과 실행 중/과거 결과를 덮어쓰지 않았다. FD·METANET 계수 적합은 하지 않았다.
- 기본 OFF에서 동일 네 명령450초 예측의 **모든 비시간 출력이 수정 전과 정확히 같았다**. `default_parity.json`.
