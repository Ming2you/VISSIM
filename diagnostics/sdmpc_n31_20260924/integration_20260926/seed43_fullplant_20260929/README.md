# seed43 네 조건 전체 플랜트 반응 검증

2026-09-29. 선택망64cf, seed43. 계수 추가 적합 없이 gate 결합 후보로 기존 NC/RM/VSL/both 명령을 각각450초 예측했다. **RM 단독 최선 선택은 맞았으나 이득 크기가 매우 작게 예측되고, 조합의 이득 부호는 틀렸다. 보정 완료나9000 실행 자격으로 판정하지 않는다.**

## 조건과 실행

- 보충 native는 무제어2700초 **1회**뿐이다. 도시·head·VSL의 과거 초기화 기록을 얻기 위한 실행이며 새로운 네 조건 런이 아니다. 기존 세 제어 런과NC 결과를 재사용했다.
- 네트워크64cf와 기존seed43 망의 XML 차이는 저장된randSeed뿐이다. 같은seed43/수요/기하/신호, SimRes10/FZP5초. 제어 전2250초까지 새NC와 기존NC의 **1,656,135행이 정확히 일치**했다. 기존 제어3조건의 공통 초기 원시 해시도 재검증했다.
- 소유 프로세스 모두 종료, 실행exit0, native LDP/VSL readback 통과. LSA COM 누락과 범용검사기의 별도 프로세스증빙 미포함 상태는 그대로 보존했다. 종료는 `analysis_v2/runtime_closure.json`으로 검증했다.

- RM은 동측4미터 g8→g6→g4, VSL은 실제DSD63–66의90km/h 명령이다. 기존 decoder/writer 주소·세 제어구간 변경한도를 검증했다. 과거 실행된 명령에 조건부인 반응 검사이며 ALINEA 정책을 자율 예측한 결과가 아니다. N_P/N_UF 타당성이나 SDMPC 실제 선택을 검사한 실험도 아니다.

## 전체 Ω 비용과 순위

Δ는 각 조건−무제어, 단위veh·h이며 음수가 이득이다. Ω 정의와 목적함수는 유지했다.

|---|---:|---:|---:|---:|
|무제어|471.890|0|0|0|
|RM|470.343|−1.547|−0.028|−1.237|
|VSL|472.667|+0.777|+0.085|+0.916|

실제 순위는 RM→조합→무제어→VSL, 예측은 RM→무제어→조합→VSL이다. 네 후보 중 예측 최선의 실제 선택손실은0이다. 하지만 예측한RM 이득0.028veh·h만으로 제어기가 강하게 움직일 것이라고 판단할 수 없고, 조합을 무제어보다 나쁘게 보는 오류가 남는다. seed43은 이전에도 검토했던 자료이며 처음 보는 blind holdout으로 부르지 않는다.

Ω 밖 삽입된 차량의 Δ체류는 RM+0.310, VSL+0.139, 조합+0.087veh·h이다. **같은450초 구간의 미삽입 대기 적분은 기존 기록에 없다.** 전체 도로의 삽입차량 TTT를 외부 대기까지 포함한 총비용으로 바꾸어 표현하지 않았다.
