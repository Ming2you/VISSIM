# 셀22·23 차로 수용식의 제한된 사전검사

**합류 차로 상태만 기존 gap 식에 넣는 수정과, 본선 우선으로 잔여 수용량을 배정하는 수정은 채택하지 않는다.** 전자는 막힌 차로에서 합류 기회를 오히려 크게 계산하고, 후자는 실제 허용된 합류까지 지나치게 제한한다. 이번 검사는 새 상태 동역학을 만들기 전에 이 두 단순 대안을 거르는 검사다.

완료된 seed53 공통 초기 상태 RM 유지/완화 자료의 91개 시점씩을 재사용했다. 기존 helper `audit_stopped_predictions.py --ramp10484-receiving-screen`에만 검사를 추가했다. FZP 재조회, 새 예측, 계수 탐색, VISSIM, 생산 설정 변경, push는 없다. STOP과 사용자가 열어 둔 창은 그대로다.

## 검사 정의

0기준 셀22가 상류, 23이 10484 합류 셀이다. 실제 각 시점의 차로 재고와 속도를 조건부 입력으로 사용했다. **2670.1초에서 출발한 자율 예측이 아니다.** 아래 값은 수용식이 제시하는 기회량의 적분이며, 램프 재고·도착·head 서비스까지 반영한 실제 합류 예측량이 아니다. 실현 합류를 처리용량의 정답으로 취급하지도 않는다.

기존 값은 도로 상한 C=6,937대/h, 램프 상한 R=1,800대/h, 임계/최대 밀도37.8/180대/km/차로, critical/follow-up gap2/1.5초다. `f(ρ)=clip((180−ρ)/(180−37.8),0,1)`과 기존 `gap_acceptance_supply_vph`를 그대로 썼다.

1. 기존 평균: `min(R, C f(ρ23평균), gap(q22평균))`.
2. 합류 차로 대입: `min(R, C f(ρ23차로1), gap(q22차로1))`.
3. 차로 상한: 위 식의 C를 C/3으로 대체.
4. 본선 우선 잔여: `min(R, max(0,C/3 f(ρ23차로1)−q22차로1), gap(q22차로1))`.

q는 해당 시점의 재고·속도로 계산한 밀도×속도이며 실제 경계 통과율이 아니다. 특히 C/3이 국소 병목 차로의 실제 용량이라는 보장은 없다. 네 번째 식은 본선 우선 배분을 가정하며 협조 양보와 측방 이동을 풀지 않는다. 따라서 이 검사의 수치를 그대로 새 capacity나 합류 우선순위로 입력하지 않는다.

## 결론과 다음 구현의 조건

- 기존 셀24·25 공통 회복계수 후보는 계속 미채택이다. 이번 검사도 회복만 가속해 합류 이득을 만들 근거를 추가하지 않는다.
- 차로1을 구분하는 것만으로 충분하지 않다. 국소 차로 재고, 본선·램프의 공동 수용 배분, 실제 측방 이동 및 posthead 대기가 같은 보존식에 연결돼야 한다.
- 이 연결을 시험한다면 기존 보존 계산 안에서 셀22·23만 제한적으로 다루고, 같은 상태의 유지·완화에서 정상 합류와 지속 대기를 모두 재현해야 한다. 고정 저속 보너스·70초 고정 지연·항상 유리한 RM 보상은 사용하지 않는다.
- 이번 seed53 자료는 구조 진단에 사용했으므로 새 후보의 미사용 검증 자료로 부를 수 없다. 다른 상태/seed와 Ω 비용·외부 비용·SDMPC 제약/선택 검증은 별도다.
- **새 수용 모델이나 이득 보정은 완료되지 않았다.** 전역 lane-group/v1 경로를 켜서 비교하거나, 이 조건부 검사를 자율450초 이득/SDMPC 성공으로 대체하지 않는다.
