# 10484 합류 차로와 회복 위치 — 완료된 seed53 재검증

**실제 RM 완화 손해는 합류 차로와 그 상류의 대기에 집중돼 있다. 셀25 전체의 회복을 일괄 가속하는 보정으로 설명할 문제가 아니다.** 신호 이후의 자유 주행시간을 늘리는 고정 계수도 적절하지 않다. RM 유지에서는 짧게 통과하지만 완화 후에는 같은 구간에서 긴 대기가 생긴다.

열린 VISSIM은 사용자가 창만 열어 둔 상태라고 확인했다. 해당 프로세스는 건드리지 않았다. 완료된 seed53 유지/완화 FZP를 각1회 읽고2670.1–3120.1초의 필요한 링크만 작은 캐시로 보존했다. 두 파일의 전체 SHA·행 수가 기존 완료 기록과 정확히 일치했다. 새 VISSIM·예측·보정·push는 없다. 기존 STOP과Ω TTT 목적함수를 유지한다.

## 다음 모델 수정의 범위

앞선 공통τ 보정은 계속 미채택이다. 이제 필요한 검증은 **셀22–23의 합류 접근 차로 상태와 신호 이후 합류 대기의 연동**이다. 현재 평균ρ·v만 사용하는 gap 식이 낮은 통과량을 높은 합류 기회로 해석하는 한계와 함께 검사해야 한다. 현재 자료는 국소 차로 정체와 대기 증가를 확인하지만, 수용식의 대체 계수나 차로변경 법칙을 유일하게 정하지는 못한다.

기존 차로 상태 구현도 읽어 확인했다. 현재 선택된31셀/v2 계약은 lane groups를 사용하지 않도록 검증하고 있고, 기존 전역 lane-group 경로에는 다른 목적지/유량 배분 계산이 포함돼 있다. 단순 스위치로 켜서 같은 모델의 개선이라고 비교하지 않는다. 기존 보존 계산 안에서 필요한 국소 상태·수용만 바꾸는 후보와, 나머지 식이 유지됨을 확인하는 대조가 먼저다. 고정 과거 차로비율 수용 보정의 앞선 기각 결과도 유지한다.

이 진단으로 seed53은 더 이상 미공개 검증 자료가 아니다. 새 후보를 만들면 별도 비학습 상태·seed에서 방향성 검사를 다시 해야 한다. 아직 새 수용식이나 SDMPC 강한 합류 상태의 이득 선택이 검증된 것은 아니다.
