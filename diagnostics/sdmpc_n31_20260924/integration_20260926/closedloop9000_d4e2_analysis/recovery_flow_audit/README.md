**seed53에서는 10484의 신호 이후 합류 대기를 지나치게 빨리 비우는 오차가 확인됐다.** 겉으로 합류 총량이 맞던 것은 도착량 과소예측과 합류 과대예측이 상쇄된 경우였다. seed47은 미래 도착량 과대예측의 비중이 크므로 두 경우를 같은 METANET 회복 계수로 맞추면 안 된다.

현재 정본·선택 config와 STOP은 그대로다. 앞선24·25 회복 후보는 계속 미채택이며, 이번 작업은 셀23만 보정한 동결 모델의 원인 진단이다. 새 계수 탐색·VISSIM·push·FZP 재스캔은 없다.

## 변경하지 않은 예측의 유량 계측

seed47/53 유지·완화450초4개를 그대로 재생했다. 계측 후 cells/flows/ports/ramps 배열이 이전 결과와 정확히 일치했고, 매초 계측한 유량을 적분하면 저장된30초 경계 통과량과1e−7대 이내에서 같았다. 셀18–30의 mainline receiving 제약 손실은 네 경우 모두0, off-entry cap 손실은 셀별450초 최대0.226대였다. 현재 계산에서 그 제약이 방출 감소를 만들어 주고 있지는 않다. Eq9 가상 합류속도 혼합은 이 모델에서 비활성이고 기존 merge 감속은 유지된다.

실측 재고·평균속도의 N·v/L을30초 표본으로 적분하면 두 seed의21–25셀에서 모두 완화 후 유량 감소 방향이 나온다. 그러나 이는 공간 평균 유량의 근사로서 정확한 하류 경계 통과량이 아니다. 이 값을 실제 순간 capacity나 추가 보정의 정답으로 사용하지 않았다.

동일 초기 재고의 보존식으로 셀23의 **완화−유지 유출 변화 오차**를 분해했다. 단위는 대, 양수는 모델의 유출 감소가 부족하다는 뜻이다.

이는 독립 인과 효과의 합이 아니라 정확한 차량 보존 항등식이다(최대잔차3.34e−13대). seed53은23셀 경계의 실제 통과 감소−66대가 말단에서−53대로 남지만, 모델은−50.60→−25.40대로 약하게 전달한다.24–30 종료 재고 변화는 실제−13대/모델−25.19대다. 따라서 합류·국소 상태와 하류 저장/방출 반응을 함께 봐야 한다.

## 미래 실측 도착량을 사용한 조건부 진단

추가4개 계산은10484의 도착 입력만 해당 native30초 구간의 실제 도착량으로 교체했다. 초기 상태·다른 경계·제어·물리 계수는 그대로이고, 요청/실제 수용 도착량과 재고 보존을 확인했다. **미래를 아는 원인 분리 실험이며 자율 예측 검증·실운용 예측·이득 보정 완료에 포함하지 않는다.** 도착 시각의30초 집계 한계도 남는다.
