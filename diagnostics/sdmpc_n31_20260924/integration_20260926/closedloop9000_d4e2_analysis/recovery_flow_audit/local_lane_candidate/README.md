# 셀22·23 국소 차로 모델 — 450초 실행 후 미채택

**국소 차로 상태를 실제 기존 예측에 연결해 실행했지만 채택하지 않았다.** RM 유지의 회복을 더 느리게 예측했고, RM 완화 손해의 과소평가도 충분히 개선하지 못했다. 큰 RM 유지/완화 순위는 기존 셀23 보정 모델부터 맞추고 있으므로, 작은 개선을 얻기 위해 다시 계수 grid를 반복하지 않는다.

## 실제로 바꿔 실행한 범위

기존 `physical_lane_groups.py`에 국소 상태를 추가하고, 정본 `area_freeway_accounting.py`와 기존 `canonical_harness.py`에 연결했다. 전역 lane-group/v1 경로를 켜지 않았다. 셀22·23만 합류 차로1/나머지2개 차로의 재고·속도를 나눴다. 인접 경계에서 실제 차량 공급·수용량을 배분하고,10484 실제 합류를 목표 차로에만 넣었다. 같은 METANET FD·이완·anticipation·합류 감속식을 그룹별로 계산했다.

직전 실제2670.1초 초기값과2520.1–2670.1초 관측만 사용했다. 두 셀에 공통인 양방향 차로 이동 기본률과, 현재 예측 속도차에 반응하는 민감도1개를 사용했다. 민감도는 과거 관측 endpoint 변경12건의 Poisson likelihood로 한 번 추정했다. β=7.6008645, 탐색 범위0–20의 내부값이다. 고정률 대조1개와 이 후보1개 외에 물리오차·TTT를 맞추는 재탐색은 없다. 적은 사건 수와5초 관측의 한계 때문에 식별이 충분하다는 뜻은 아니다.

모든 다른 셀, 동적 off-ramp 저장·배수·spillback,8개 램프의 대기·액추에이터,1초 적분, 경계 수요·명령·지평은 유지했다. 추가 capacity나 제어 보상은 없다. VSL 명령 코호트의 기존 비율과 수송을 유지하되, 각 국소 셀의 두 차로 집단에 같은 명령 비율을 가정했다. 외부의 단일 집단 셀과 연결할 때는1:2 차로 폭 비율을 가정했다. 이 두 가정도 후보의 한계다.

## 동일 초기 상태의450초 결과

seed53,2670.1–3120.1초. 실제 실행한 RM 유지, 점진 완화, 유지+VSL90, 완화+VSL90 명령을 조건으로 예측했다. 미래 차량 상태·도착·배수는 입력으로 넣지 않았다. 그러나 이 seed를 이전 구조 진단에 사용했으므로 미사용 독립 검증이라고 부르지 않는다.

비용은 **동측31셀+8개 진입/진출 커넥터**의 동일30초 재고 사다리꼴 적분이다. 전체Ω나 도시부·외부 대기를 포함한 SDMPC 목적값은 아니다. 각 값은 RM 유지 대비ΔTTT[대·시간]다.

큰 RM 완화 손해의 방향은 모두 맞지만, 후보가 손해 크기를 일부 늘린 것만으로 성공으로 판정하지 않았다. VSL의 작은 차이를 억지로 음수로 맞추는 추가 탐색도 하지 않는다.

RM 유지에서 전체31셀 재고 RMSE는10.83→11.15대,30초 경계 통과량 RMSE는7.84→8.16대로 악화했다(속도차 반응 후보). 셀24의450초 평균속도는 실측79.7, 기존62.5, 후보61.6km/h다. 셀25는72.6→73.4km/h로 조금 좋아졌지만 실측90.8km/h와 차이가 크고, 다른 회복 구간의 악화를 상쇄하지 못한다. 네 조건 모두 전체 재고·유량 RMSE가 악화했다.

합류·대기의 핵심도 해결되지 않았다. RM 완화의10484 합류 예측은92.885→92.933대로 사실상 같고, 최종 posthead 재고는1.33→1.28대다. 실측 최종 posthead는16대다. 자율 예측의 램프 도착 자체가 실측보다 작아 오차가 일부 상쇄된다는 앞선 진단도 그대로다. 이를 무시하고 합류 합계만 비슷하므로 성공이라고 할 수 없다.

후보의 목표 차로 여유공간 수용 상한은 최소45,008대/h인 반면, 실제 적용된 gap 예산은 최대1,689대/h였다. 물리 jam 공간만으로는 관측된 합류 대기를 제한하지 못했다. 이 수치를 새 보정 capacity로 쓰지 않는다. 국소 차로를 분리하고 기존 gap/공간 식을 유지하는 것만으로 문제가 해결된다는 가설은 이 비교에서 지지되지 않았다.

## 검증과 보존

- 본 비교는10회450초 계산: 두 기존 방식 확인과8개 후보 예측. 경과18.19초이며 controller 최적화 시간은 아니다. SDMPC/PFO outer iteration0, 선택·수렴 검사는 이번 실행에 포함하지 않았다.
- 이번 작업 전체로는 후보8회, 기본 방식 확인5회가 완료됐고, 첫1초 후 검증기에서 멈춘 후보1회가 있다. 초기 검증기는 셀당 desired-speed 호출1개만 예상해 두 실제 그룹 호출을 거부했다. 물리식·계수는 고정하고 관측 묶음만 수정해 재실행했다. 실패 기록과 양쪽 source SHA 모두 보존했다.
- 기능 비활성 상태의 유지/완화에서 `cells/flows/ports/ramps` 저장 기록이 기존 결과와 정확히 같았다. 첫 메모리 비교는 JSON에서 수치 사전 키가 문자열로 바뀌는 차이를 실패로 잡았다. 같은 저장 형식으로 정규화한 비교와 복원 후 재실행은 모두 통과했다.
- 후보8개의 국소 차량 보존 최대오차는8.14e−13대 이하다. 기존 전체 본선·각 램프/진출부 보존 검사와 VSL 코호트 수송 검사도 통과했다. 이런 회계 통과를 이득 예측 성공으로 대신하지 않았다.
- 시험했던3개 실제 사용 파일은 변경 전의 **기존 미커밋 작업까지 포함해 바이트 단위로 복원**했다. `restoration.json`, `rejected_candidate.patch`, `executed_sources`의 SHA 고정 source, 모든 예측·학습·실패 기록을 보존했다. 후보 코드를 기본 경로에 남기지 않았다.
- 기준 망·선택 설정·STOP은 같으며 새 VISSIM, 사용자 프로세스 조작, push는 없다.

## 다음 판단

이번 후보의 계수를 더 탐색하거나 전역 차로 모델로 넓히지 않는다. 현재 셀23 보정 모델이 이미 구별하는 **큰 RM 유지/완화 차이**를 실제 SDMPC가 같은 초기 상태·실제 이전 명령·허용 변경폭에서 선택할 수 있는지 확인하는 것이 다음 단계다. 물리 예측의 남은 정확도 문제와 관측 초기화·제약·탐색 문제를 분리한다.

강한 합류 변화가 확인된2670.1초 상태는 아직17개 도시부 관측 이력을 갖춘 SDMPC 입력으로 재구성하지 않았다. 기존4500초의 g10 상태와 섞거나 이전 명령을 임의로 g2로 바꾸지 않는다. 완전한 대응 상태를 확보하지 못하면 그 제한을 보고하고, 새 VISSIM으로 우회하지 않는다. 전체Ω 비용과 외부 비용은 그 후 같은 영역에서 검증해야 한다.

**현재 이득 보정 및 강한 합류 상태 SDMPC 검증은 미완료다.** 독립 seed 검사는 실패한 후보에 확대하지 않았다. 이 후보의 실패를 모든 차로 기반 모델의 불가능성으로 일반화하지도 않는다.
