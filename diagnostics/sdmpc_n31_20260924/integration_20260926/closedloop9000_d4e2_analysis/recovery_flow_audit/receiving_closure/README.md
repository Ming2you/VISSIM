# 10484 합류 수용식과 회복 보정의 한계

**회복τ를 더 줄이는 보정은 진행하지 않는다.** 기존24·25 공통 회복 후보는 제어 손익을 개선하지 못해 미채택이다. 이번에는 저장된 seed47/53 유지·완화 예측과 실측 위치를 대조했다. 새 예측0회, 최적화0회, VISSIM0회, FZP 재스캔0회이며 생산 모델·선택 config·Ω 목적함수·STOP을 변경하지 않았다.

## 확인한 합류 수용 계산

현재10484는 신호 통과 후 유한 저장/이동 버퍼를 거쳐, 다음 두 한계의 작은 값까지 합류한다.

- 밀도 기반 수용: `min(1800, 6937 × clip((180−ρ23)/(180−37.8), 0, 1))` [대/h].
- gap 기회: 셀22의 `q=ρ22×v22`를 사용하는 `q exp(−2q/3600)/(1−exp(−1.5q/3600))` [대/h].

이것은 실제 합류를 보장하는 유량이 아니다. 실제 예측 합류는 여기에 신호 이후 도달 재고를 교차 제한한 값이다. 기존 코드가 두 식을 이미 사용하고 있고, head 서비스·전후 재고 보존도 유지하고 있다. 식을 새로 추가한 것이 아니다.

4개 자율 예측과4개 기존 미래도착 조건부 예측의 모든450초에서 첫 밀도 한계는1800대/h였다. 즉 이 조건들에서는 밀도 한계가 추가 제한을 하지 못했다. 반면 gap 한계와 도달 재고는 번갈아 작동했다. 합류가 매초 `min(도달 재고, 수용 예산)`과 일치함을3,600개 저장된 step에서 확인했다. posthead 재고 변화 = head 통과 − 합류도120개30초 구간에서 확인했다.

이 식은 일부 자유류/정체 상태를 구분하지 못한다. 예를 들어 셀22·23을 각각ρ15,v100 또는ρ75,v20으로 둔 식 평가에서는 둘 다q1500이고, 밀도 제한도1800보다 높아 동일한 합류 기회를 준다. **식의 정보 한계를 보이는 합성 예시이며 실측 사례·보정 후보가 아니다.** 실제 합류 차로의 공간·차간격·상대속도는 현재 선택 모델의 이 식에 직접 들어가지 않는다.

## 실측 상태를 넣어도 남는 문제

seed53 완화의2970.1초 실측 셀22는ρ64.94대/km/차로, v24.52km/h이다. 이 값을 위 gap 식에 넣어도 약1356대/h를 준다. 당시 실제10484 head 뒤에는15대가 있었고9대가15km/h 미만이었다. 이후3120.1초에도16대 중9대가15km/h 미만이었다. 평균 본선 상태의 예측 오류만으로 모든 차이를 설명하기 어렵다는 단서다.

30초 구간 양 끝 모두 posthead 저속(<15km/h) 차량이3대 이상인 구간을 모았다. 이는 사후 위치 확인 기준이며, 구간 전체 내내 합류 대기열이 포화됐다는 증명이나 수용능력 추정은 아니다.

|완화 조건|구간 수|실제 합류|기존 자율 예측 합류|실측 도착 조건부 합류|조건부 예측 수용 예산|
|---|---:|---:|---:|---:|---:|
|seed47|7|51|65.08|49.55|71.95|
|seed53|8|55|52.53|67.45|89.74|

seed47은 도착 입력을 맞추면 이 구간 합류 총량은 근접한다. seed53은 반대로 기존 도착 과소예측이 과도한 posthead 방출을 가리고 있었다. 같은 계수로 도착 오차와 합류 오차를 함께 흡수하면 안 된다.

seed53의450초 전체에서 실제 head 통과106대/조건부107.55대인 반면, 실제 합류91대/조건부107.80대이고 종료 posthead 재고는16대/0.75대다. 앞선 진단과 정확히 이어진다. 조건부 모델은 끝에 도달 재고가 없어 합류가 줄어드는 것이며, 실제처럼 저속 대기가 유지되는 것이 아니다.

위 실측ρ·v 대입과 미래 도착 사용은 **원인 분리용 조건부 진단**이다. 자율 예측 개선이나 controller 성능으로 계상하지 않는다.30초 셀 평균 `ρv`는 순간 합류 차로의 경계유량·차간격을 측정한 값이 아니다. 따라서 이 결과로 새 receiving 계수나 capacity drop 크기를 바로 정하지 않았다.

## 보정 판단과 남은 범위

기존/셀23만/24·25만/양쪽 보정 결과는 [회복 비교](../../recovery_cells24_25/README.md)에 있다.24·25 가속τ12→6초는 일부 저속 편향을 줄였지만 seed53 RM 완화 ΔTTT를+1.246→+1.056대·시간으로 더 작게 예측했다(동일 동측 구성요소 실측+5.929). seed47 말단 유출 변화도 실측−33대에 대해−2.53→+0.77대로 악화했다. 따라서 이 후보를 정본에 올리지 않는다.

다음 수용식 수정에 앞서 필요한 증거는10484의 **신호 이후 이동시간/합류 대기와 목표 차로의 실제 수용 상태**다. 현재 자료만으로는 일정한 posthead 주행시간 가정, 차로별 공간 제약, 비포아송 gap/군집 도착, 본선 대표 상태 중 어느 하나로 원인을 확정할 수 없다. 과거10681의 고정 관측비율 수용 보정이 다른 seed에서 과대 합류를 만든 기각 결과도 유지한다. 임의의 고정 용량 감소나 seed 전용 보너스를 넣지 않는다.

이번 제한 보정은 **미채택으로 평가를 종료**한다. 새로운 계수 그리드는 예약하지 않았다. 강한 합류 차이가 있는 동일 전체 상태의 SDMPC 선택 검증은 아직 남아 있다. 현재 전체17도시 이력이 있는4500초 상태는 허용 RM 변화에 따른 합류 차이가 작으므로, 이를 강한 제어 이득 검증으로 대체하지 않는다. 목적함수는Ω TTT 그대로이며 외부 대기는 진단으로만 보고한다.
