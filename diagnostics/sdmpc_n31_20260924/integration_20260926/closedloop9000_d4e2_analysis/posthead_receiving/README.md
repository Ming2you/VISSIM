# 10681 수용 보정의 독립 검증과 RM/VSL 비용 오차 분해

2026-09-28 · **후보 기각 / 정본 채택 안 함 / 이득 보정 미완료**

목적함수는 Ω 내부 TTT로 유지했다. 새 VISSIM 런·SDMPC 최적화·git push는 하지 않았다. 중단된 8400초 런의 STOP을 유지한다. 아래 seed53 비용은 **동측 31셀+진입/진출 커넥터 8개**의 450초 비용이며, 전체 Ω나 외부 대기 포함 비용으로 읽으면 안 된다.

## 결론

1. 10681의 미터 이후 수용률과 차로별 충돌 유량 보정은 seed29의 6000초 상태를 개선했지만, 독립 seed53에서는 합류량 오차를 키웠다. 채택하지 않고 변경한 정본 파일 5개를 실험 전 바이트로 복원했다. 앞서 검증한 도시 전용 차량의 램프 오배정 방지 수정은 그대로 보존했다.
2. seed53에서 RM 제한 완화에 따른 **추가 합류량**은 기존 모델도 +95.8대로 실제 +94대와 가까웠다. 큰 비용 오차는 그 뒤의 **진출·말단 방출 저하**, 그리고 도시에서 램프로 추가 유입되는 차량을 고정한 부분에 있었다.
3. 합류량은 본선과 램프를 합친 영역의 내부 이동이다. 합류를 잘 맞추는 것만으로 전체 비용 이득이 자동으로 맞지 않는다. 다음 검증은 방출·배수·회복의 시간별 반응에 집중한다.

## 시험한 수정과 기각 근거

신호두 이후 146.8m 구간의 빈 공간이 즉시 모두 서비스 용량으로 바뀌지 않도록 `w(K-n)/L` 수용률을 추가했다. w=13.716759km/h는 seed29의 4500–4650초 한 창에서만 정했고 이후 고정했다. 이동 속도·여행시간·미터 신호·기존 gap 계수는 바꾸지 않았다.

별도로 직전 150초 차로별 본선 관측 유량을 초기 모델 유량으로 나눈 비율을 고정하고, 이후 모델 유량에 곱해 차로별 충돌 유량을 예측했다. 이는 차로 재고 보존 모형이 아니라 유효 충돌량의 관측 보정이다. 다른 상태에도 동일한 반응을 보장하지 않는다.

| 10681 시험 구간 | 실측 합류 | 기존 예측 | 새 후보 |
|---|---:|---:|---:|
| seed29 4500–4650초 | 48 | 47.16 | 46.36 |
| seed29 6000–6150초 | 37 | 26.53 | 38.41 |
| seed53 2670.1–3120.1초, 유지 | 148 | 140.63 | 170.29–175.46 |

앞의 두 행은 도시와 본선을 연결한 전체 플랜트 예측이다. 마지막 행은 독립 seed의 기존 동측 컴포넌트 실험이다. seed29 후보에는 앞선 도시 목적지 수정도 포함되지만 10681 도착량은 비교 전후 동일했다.

seed53 차로 관측은 완료된 FZP의 **2520.1–2670.1초만** 한 번 읽었다. 같은 링크의 내부 경계 통과 253대는 기존 집계와 일치했다. 5초 관측 사이 차로가 달라진 2대를 출발/도착 차로로 각각 처리한 두 경우 모두 실패했다. 이 둘은 관측 가능한 차로 불확실성의 민감도 검사이며, 미관측 중간 차로 변경까지 포괄하는 엄밀한 한계는 아니다. 예측 구간 실측은 입력에 사용하지 않았다.

분리 시험에서 수용률만 추가하면 seed53 합류·비용 결과는 기존과 동일했다. 차로 충돌량 보정만 넣으면 위 과대합류가 그대로 재현됐다. **직전 차로 유량 비율을 450초간 고정하는 수정이 다른 seed로 일반화되지 않았다.** 계수를 다시 맞춰 검증 자료에 적합시키지 않았다.

seed29의 동일 6000초 상태에서 10681 녹색을 10초 유지, 8초 유지, 8→6→4초로 제한한 450초 예측도 비교했다. 새 후보의 합류는 92.9677 / 92.9677 / 92.9667대였다. Ω TTT 차이는 최대 −0.00113대·시간으로, 의미 있는 RM 순이득 근거가 아니다. 물리·writer·주기간 변경 한도만 검증했고 N_P/N_UF 후보 타당성이나 SDMPC 선택은 검사하지 않았다.

## 실제 제어 반응의 비용 오차

기존 seed53 네 조건은 공통 초기 상태의 완료 자료다. RM 유지 조건의 동측 녹색은 10639/10681/10490/10484 순서로 2/9/5/2초이다. 완화 조건은 2700초부터 각 주기 최대 2초씩 늘렸다. VSL90 조건도 기존 실행 명령을 그대로 재현했다. LDP/readback·공통 궤적 검증은 기존 결과를 재사용했다.

아래는 **기존 δ4/E2 모델**과 실측 비교이며 기각한 후보의 숫자가 아니다.

| RM 완화 − 유지, 450초 | 실측 | 모델 |
|---|---:|---:|
| 합류량 변화 [대] | +94 | +95.78 |
| 본선→off-ramp 변화 [대] | −48 | −8.20 |
| 본선 말단 유출 변화 [대] | −53 | +0.12 |
| 본선 TTT 변화 [대·시간] | +8.77 | +6.62 |
| 8개 커넥터 TTT 변화 [대·시간] | −2.84 | −6.34 |
| 동측 컴포넌트 TTT 변화 [대·시간] | **+5.93** | **+0.28** |

추가 합류는 실측에서 주로 10639(+56대), 10484(+46대)에서 발생했다. 10681은 −6대, 10490은 −2대였다. 따라서 이 실험의 RM 이득 문제를 10681의 합류 상한 하나로 설명할 수 없다.

30초별 재고와 유량으로 전체 비용을 다시 구성했다. 두 모형과 네 조건 모두 보존식이 1e−7대·시간 이내로 일치하며, 본선의 설명되지 않은 생성·손실·삭제는 이 창에서 0이다. 합류와 off-ramp 진입은 내부 이동으로 정확히 상쇄된다. 남는 외부 경계 기여는 다음과 같다.

| RM 완화의 동측 컴포넌트 ΔTTT 기여 [대·시간] | 실측 | 모델 |
|---|---:|---:|
| 본선 입력 | +0.096 | 0 |
| 도시→램프 도착 | +1.517 | 0 |
| off-ramp→도시 배수 | +2.512 | +0.201 |
| 본선 말단 유출 | +1.804 | +0.075 |
| 합계 | **+5.929** | **+0.276** |

이는 보존에 따른 장부 분해다. 특정 감속항이 원인이라고 확정한 결과는 아니다. 도시→램프 도착은 전체 Ω에서는 내부 이동일 수 있으므로 +1.517을 전체 Ω의 손해로 곧바로 옮기면 안 된다. 컴포넌트의 고정 경계가 실제 제어로 달라진 도시 유입을 놓친다는 증거다.

VSL90 − 유지의 컴포넌트 ΔTTT는 실측 −0.150, 모델 +0.147대·시간이었다. 특히 말단 유출 시점의 비용 기여는 실측 −0.121, 모델 +0.144였다. 작은 한 seed 차이이므로 강건한 VSL 이득이나 일반적 무효로 단정하지 않는다. 종료 누적 유출량뿐 아니라 유출 시점이 중요하다.

## 유지 상태와 다음 순서

- 선택망·선택 config·목적함수·중단 STOP은 동일 SHA로 확인했다. 이번 후보의 정본 코드 5개는 복원했고, 실패 소스·patch·검증 결과는 보존했다. `candidate_config.json`은 **기각한 실험 기록**이므로 실행 정본으로 쓰지 않는다.
- 앞선 도시 목적지 오배정 방지 수정과 관련 유효 결과는 유지한다. 이번 후보 관련 검사 31개 통과, 비활성 상태의 seed53 네 조건 cells/flows/ports/ramps 전체 배열이 기존과 정확히 일치했다. 이전 legacy 검사 중 누락된 포트 fixture 실패는 성공으로 바꾸지 않았다.
- 오프라인 전진 예측 28회(전체150초 2회, 전체450초 6회, seed53 기본회귀4회+후보8회+분리8회). SDMPC optimizer iteration은 0회이고 새 native는 0회다. 소유 계산은 모두 종료했다.
- 다음에는 이미 저장된 seed53의 시간·위치별 방출을 이용해 10643 등 진출부와 말단의 **진입 부족 / 배수·수용 제한 / 속도·회복 오차**를 분리한다. 합류량을 더 맞추는 계수 탐색부터 반복하지 않는다.
- 그 근거가 나온 부분만 기존 동역학에서 수정한 뒤, 같은 네 조건의 비용 방향과 후보 순위를 다시 확인한다. 이어 도시부를 포함한 SDMPC 선택을 검증한다. 완벽한 속도 궤적 재현은 합격 조건이 아니다. 근거 없는 capacity 보너스나 레버 보상항은 넣지 않는다.
