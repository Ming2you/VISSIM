# 국소 보정 이후 남은 RM·VSL 조합 오차 — 2026-09-28

셀23의 국소 보정은 유지하되, 이 자료에 맞추기 위한 추가 계수 탐색은 하지 않는다. 초기 450초에서 RM에 VSL을 더한 실제 순이득은 작고, 경계 유입의 차이가 비용에 섞여 있다. 이 차이를 전부 병목 방출 개선으로 해석해 계수를 맞추면 잘못된 물리 반응을 학습할 수 있다.

## 자료와 검증 범위

기존 seed29·43의 동일 2220.1초 상태에서 2670.1초까지 무제어/RM/VSL/둘 다를 비교했다. 이번 작업은 저장된 실측 표와 동결된 `nu0.25_delta2` 예측을 읽은 사후 계산이다. 새로운 예측·VISSIM·FZP 재스캔·계수 재학습은 없다. SDMPC 선택 검사는 별도 단계다.

- 초기 동측31셀의 재고·속도와 진입/진출 커넥터8개 재고가 조건 간 정확히 같다.
- 각 30초 구간의 재고 변화와 경계 유량을 대조했다. 이번 8개 조건에는 미해명 본선 유입·소실·삭제가 없다.
- 아래 비용은 **동측31셀+동측8개 커넥터**의 30초 재고 적분이다. 전체 Ω 목적함수나 외부 미삽입 대기를 대신하지 않는다.
- 내부 합류/진출 이동은 합계에서 상쇄된다. 남는 항은 본선 외부 유입, 도시→램프 유입, 진출램프→도시 배수, 본선 말단 유출이다. 각 유량에 종료까지 남은 시간을 가중한 값과 재고 적분이 1e−7대·시간 이내로 일치한다.
- seed43 무제어의 과거 manifest는 원시 FZP만 고정하고 CSV 해시를 저장하지 않았다. 이번 CSV 해시는 보존했지만 과거 CSV 바이트 동일성까지 주장하지 않는다.

## seed43: RM 이득의 큰 부분은 본선 유입 시점 차이

무제어 대비 실제 ΔTTT, 단위 대·시간. 음수는 비용 감소다.

| 경계 항 | VSL | RM | RM+VSL |

| 본선 유입 |+0.5000|−1.5917|−1.1875|
| 도시→램프 유입 |+0.0667|+0.2958|+0.2500|
| 진출 배수 |+0.0792|−0.1125|−0.0542|

RM의 합계 −1.1708을 모두 본선 방출 증가로 해석할 수 없다. 말단 항은 오히려 +0.2375다. 실제 본선 유입 차량은 무제어913대, RM895대, RM+VSL902대, VSL945대이다. 현재 예측은 조건별 외부 경계 유입을 같게 두므로 이 차이의 비용 기여는 0이다.

첫 유입 차이는 RM/둘 다에서 2370.1초에 끝나는 구간, VSL은 2520.1초에 끝나는 구간이다. 입력 셀의 평균 속도는 대략49–53km/h, 밀도33–40대/km/차로라 자유류라고 단정하기도 어렵다. 기존 native 검증은 2250초 이전 원시 궤적의 조건 간 정확 일치를 확인했다. 이후 차이가 수용량·유입 대기·확률열 변화 중 무엇에서 왔는지는 이 집계만으로 확정하지 않는다. 미래 실측 유입을 예측 입력에 넣지 않았다.

RM에서 RM+VSL로 바꾸면 실제 말단 항은 −0.5208 개선되지만, 본선 유입 +0.4042 등과 상쇄되어 총 −0.1042다. 국소 보정 모델은 +0.2317로 이 작은 추가 효과를 놓친다.
