# 10484 합류 셀 하나의 재보정 — 부분 개선, 정본 미채택

후속 완료: [셀24·25 회복 구간의 네 모델 비교](../recovery_cells24_25/README.md).48개 추가 예측과 저장4500초 SDMPC/실행모델 검증을 마쳤다. 회복 속도 편향은 조금 줄었지만 방출 손실·제어 순위가 개선되지 않아 회복 후보도 미채택이다. 기존 STOP 유지, 새native/push 없음. 아래는 앞선 셀23 보정 기록이다.

2026-09-28. 사용자가 제안한 ‘오차가 반복되는 특정 셀만 재보정’을 기존 모델로 시험했다. **10484 합류부인 동측 물리 셀23만 변경했고, 큰 RM 손해의 부호 오판을 한 사례에서 바로잡았다.** VSL·RM 전체 이득 예측의 완료는 아니다.

## 이 셀을 고른 근거

기존 예측은 seed29·47·53 모두에서 미터 완화 후 셀23의 속도를 높게 예측했다. 450초의30초 스냅샷 평균은 다음과 같다.

| 후기 상태 | 실제 속도 | 기존 예측 |
|---|---:|---:|
| seed29, RM 유지 |59.14|58.00|
| seed29, RM 완화 |38.17|49.32|
| seed47, RM 유지 |89.31|61.06|
| seed47,10484 완화 |39.79|49.70|
| seed53, RM 유지 |78.90|55.40|
| seed53, RM 완화 |40.27|47.49|

단위km/h. 유지 시 회복과 완화 시 혼잡을 충분히 구별하지 못했다. 셀23은 공개 제어구간 번호가 아니라 **31셀 물리 격자의0기준 번호**이다.

정본 속도함수를560번 조건부 평가해 이완·대류·anticipation·합류 감속 합과 실제 함수 반환값을1e−10km/h 이내로 대조했다. 실측 혼잡 상태에서 하류 밀도가 낮다는 이유로 anticipation 가속이 강하게 발생했고, 유지 상태에서는 감속이 과했다. 예를 들어 seed47 셀23의 조건부 총 변화 평균은 유지−6.58, 완화+2.62km/h/s였다. 실제 다음30초의 셀 평균 속도 추세는 각각+0.054/−0.084였다.

이는 **순간 관측값과 직전30초 합류율을 넣은 모델 벡터장의 진단**이다. 서로 다른 차량이 셀에 드나드는30초 평균 추세를 실제 차량의1초 가속도로 취급하거나 이 값에 직접 계수를 맞추지 않았다. [항별 자료와 재현 실패 기록](../recovery_response/seed47_audit/speed_balance/summary.json).

## 변경과 선택

- 기존 δ4/E2 설정을 기준으로 셀23의 `delta_merge`와 `anticipation.downstream_lt_local`만12개 조합으로 비교했다. 하류가 더 조밀한 경우의 anticipation, 다른 셀, FD, 임계밀도, 회복시간, 차로·수용·보존·수요·명령은 고정했다.
- 학습은 seed29의2670.1초 공통 상태에서 RM 유지/점진 완화450초 두 경우이다. 국소 셀21–25의 재고·속도와 통과량, 말단 통과량의 정규화 RMSE로 선택했다. ΔTTT나 후보 순위를 학습 목적값으로 쓰지 않았다.
- 동측31셀 전체 재고·통과량 RMSE가 어느 학습 상태에서도 기준보다5% 넘게 나빠지면 제외했다. 이는 이 시험의 후보 배제 규칙이며 일반적인 완성도 정의가 아니다.
- 평균 점수0.57613→0.53868(**6.50% 감소**)인 조합을 선택해 고정한 뒤 나머지 상태·seed를 검사했다. 새 값은 셀23의 **δmerge4→2**, 하류가 덜 조밀할 때 **ν18.375→4.59375**이다. 반대 밀도 구배의ν18.375는 유지했다. 앞선 광역τ4 후보와 합치지 않았다.
- [프로토콜](protocol.json), [동결 선택](frozen_selection.json), [후보 설정](candidate_reference_config.json). 모델식을 추가하거나 제어에 보상항·capacity bonus를 넣지 않았다.

작은 후보표의 선택은 seed29 초기 무제어→RM+VSL, seed43 초기 무제어→RM으로 바뀌었다. seed47 후기에는 잘못된10484 완화를 피하지만10490 완화를 선택하는 오류가 남았다. 실제 최선 대비 선택 손실은 각각0.8292→0,1.2750→0.1042,1.6792→0.2500대·시간이었다. 이는 **전진 예측 후보표의 선택**이며 SDMPC optimizer 실행 결과가 아니다.

독립 후기 상태에서 전체31셀 재고·유량 RMSE는 유지/완화별로 약0–4.5% 악화한 항도 있었다. 이득 방향이 좋아졌다고 전체 궤적 정확도까지 개선됐다고 하지 않는다. 이득 크기는 여전히 작게 예측하며, RM+VSL 상호작용과 작은 VSL 이득은 미해결이다.

## 결합 플랜트 연결과 보존 확인
