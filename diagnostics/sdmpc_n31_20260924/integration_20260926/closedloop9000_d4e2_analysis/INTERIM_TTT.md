# 7800초 잠정 TTT 비교

사용자의 중간 비교 요청에 따라 완료된 실제 차량 관측만 읽었다. 실행 중인
VISSIM/제어기/설정은 변경하지 않았고 FZP를 스캔하지 않았다.

근거: `interim_ttt_007800.json` (원본 관측 경로·SHA256·시각별 차량 수 포함).
동일 seed29, 네트워크·수요 프로필·생성 VBS 설정 SHA256 일치를 확인했다.
각 관측의 완전성, 차량 ID 중복 없음, 링크의 Ω 안/밖 분류 누락 없음을 확인했다.
0초 빈 망, 1초, 이후150초 간격 관측을 7800초까지 동일하게 사다리꼴 적분했다.
제어 전900초까지 두 런의 안/밖 차량 수가 일치했다.

| 체류시간 [대·시간] | 무제어 | 현재 SDMPC | SDMPC−무제어 |
|---|---:|---:|---:|
| Ω 내부 | 6520.0608 | 6630.5817 | +110.5208 (+1.6951%) |
| Ω 외부의 이미 삽입된 차량 | 2263.6436 | 2458.2894 | +194.6458 |
| 두 영역 합계 | 8783.7044 | 9088.8711 | +305.1667 (+3.4742%) |

Ω 누적 차이는 3000초 +4.6667, 4500초 +32.5625, 6000초 +58.4583,
7800초 +110.5208대·시간이다. 7800초 Ω 잔여 차량은 무제어2156대,
SDMPC2267대다. 현재까지 개선을 보인다는 근거는 없다.

이 값은 모델 예측이나 최종9000초 결과가 아니다.150초 관측 사이 변화는
근사했으며 미삽입 대기를 포함하지 않았다. 차량 삭제·미삽입 및 정상 유출은
아직 최종 대조 전이다. 따라서 최종 성능이나 특정 레버의 인과 효과로 해석하지 않는다.

기존 `finish_after_native.ps1 -RecoverAfterSupervisorExit`가 원래 native
프로세스 종료 후 실행 검증과5초 FZP 비교를 한 번 수행하도록 대기 중이다.
이 잠정 파일은 자동 최종 `summary.json`과 별개다. 종료 뒤 공간별 비용과
실제 명령을 대조하고, 선택 당시의 예측 이득과 실측 손실의 원인을 좁힌다.
계수·목적함수 변경이나 추가 native 런은 이 중간 집계에서 수행하지 않았다.
