4500초 도시행41대,6000초 도시행15대를 보존한다. 그중6000초10695의1대는 물리적으로 Ω 밖이며 기존 소유/영역 배정을 그대로 유지한다. 과거900초의0.5대 fractional 소유도 처리한다. 상류32·129의 미확정 목적지는 여전히 기존 분할을 쓰며, 이번 수정으로 전체 목적지를 복원했다고 주장하지 않는다. 10695의 이미 완료된 도시 회전·추가 신호 통과까지 재모델링한 것도 아니다.
