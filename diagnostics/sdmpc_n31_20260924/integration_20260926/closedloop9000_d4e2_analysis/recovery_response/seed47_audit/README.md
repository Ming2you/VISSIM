이번에는 계수를 다시 맞추거나 VISSIM을 실행하지 않았다. 기존 네이티브 캐시와 동결된 δ4/E2 및 회복 τ4 후보의 예측만 사용했다. Ω TTT 목적함수·선택망·선택 설정·STOP은 그대로이다.

## 비교 조건과 신뢰 범위

- Seed47, 공통 초기 상태2670.1초에서3120.1초까지450초. 같은 사전 미터 명령 이력을 재생한 상태이며, 무제어와의 비교가 아니다.
- 기준은10484 녹색2초 유지, 비교는2700/2850/3000초에4/6/8초로 점진 완화이다. 다른 미터와 VSL은 같다. 명령의 원본 SHA와 capture의 정렬 JSON SHA를 각각 검증했다.
- 비용 범위는 **동측31셀+동측 진입/진출 커넥터8개**이다. 전체 Ω·도시부·외부 대기 비용으로 부르지 않는다.
- 두 실제 상태의 초기31셀 재고·속도와8커넥터 재고가 같다. 관측 CSV4종/조건의 SHA를 확인했고, 30초 재고 적분과 시간 가중 경계유량으로 계산한 비용이1e−7대·시간 이내에서 일치했다. 해당 두 조건에 비정상 삭제·미해명 소실은 없다.

## 혼잡 전파와 분기 비율의 영향

실제10484 합류 셀23의 속도는 제한 유지 시 회복하지만, 완화 시2730.1초부터 감소해 이후 대체로30–40km/h에 머문다. 감소가 셀22→21→20→18로 전파된다. 마지막150초에 셀23 속도는 유지89.7/완화33.8km/h, τ4는67.4/45.8km/h였다. 이는 차량 수 가중30초 스냅샷 평균이며 연속 측정 평균은 아니다.

셀23의450초 통과량은 실제880→828대(−52), 모델788.46→831.56대(+43.10)이다. 모델도 감속과 재고 증가를 만들지만 추가 재고의 유량 증가 효과가 우세하여 방출 방향이 반대이다. 상류 셀22 통과는 실제−81대, 모델−13.92대, 셀20 전체 방출은 실제−80대, 모델−0.97대에 그친다.

10483 진출부의 실제 진출 감소21대는 사후 집계상 다음처럼 나뉜다. 기준 실현 진출 비중18%를 먼저 고정하면 전체 방출900→820대 감소가−14.4대, 실현 비중18%→17.20% 변화가 나머지−6.6대이다. 분해 순서에 의존하는 회계 분해이며 차량별 인과 기작이나 설정된 경로 비율 변경을 뜻하지 않는다. 미래 비율을 예측 입력으로 사용하지 않았다. 목적지 구성이 일부 영향을 주지만 본선 흐름 감소를 놓친 문제가 더 크다.

## 새 용량 상한을 바로 넣지 않은 이유

실측 N·v를 기존 `q=Nv/L` 관계에 넣고30초 사다리꼴로 적분하면 셀20–25에서 모두 방출 감소 방향이 나온다. 예를 들어 셀23은−24.53대(실제 경계 통과−52대), 셀22는−86.52대(실제−81대)이다. 따라서 **현재 자료에서는 속도·재고 반응을 맞추면 기존 유량식도 올바른 방향을 낼 가능성**이 있다.

다만 공간 평균 속도·30초 표본으로 경계 통과를 완전히 복원할 수 없다. 이 근사는 수용 상한이 필요 없다는 증명도 아니다. 이전 `receiving_audit/summary.json`에서는 실측 유량 자체가 평형 FD 최대값을 넘은 창도 있어, 그 최대값을 그대로 과도상태의 절대 상한으로 쓰면 안 된다.

다음 최소 검사는 같은 실측 상태에서 정본 METANET의 이완·대류·anticipation·실제 합류 감속 기여를 분리하는 것이다. 현재 상태를 주어도 반응이 틀리는지, 자율 예측에서 상태가 빗나가며 반응이 틀리는지 구분한 뒤 수정한다. 단순히 합류 계수를 더 크게 하거나 새 capacity drop을 덧붙이는 탐색은 아직 하지 않는다.
