# 회복 시간의 제한적 재보정과 제어 반응 검증

2026-09-28 · **초기 RM 방향 일부 개선 / 후기 오판 지속 / 정본 미채택**

이번 단계는 기존 `recovery_relaxation`만 재보정했다. 새 동역학 식·capacity 보너스·제어 보상항을 만들지 않았다. 목적함수는 Ω TTT로 유지했고, STOP을 유지했으며 새 VISSIM 런·SDMPC 최적화·push는 하지 않았다.

## 확인된 위치별 문제

완료된 seed53 자료와 δ4/E2 예측을 다시 비교했다. RM 제한 완화 시 450초간 off-ramp별 변화는 다음과 같다.

| 진출 커넥터 | 실제 진입 변화 | 예측 진입 변화 | 실제 배수 변화 | 예측 배수 변화 |
|---|---:|---:|---:|---:|
| 10643 | −2 | −2.43 | −6 | 0 |
| 10682 | −23 | +0.01 | −20 | +0.01 |
| 10481 | −4 | −1.90 | −2 | 0 |
| 10483 | −19 | −3.87 | −23 | −3.82 |

단위는 대이다. 10682·10483은 배수 능력만의 문제가 아니라 **상류에서 도착하는 진출 차량 감소**를 놓쳤다. 고정한 도착 비율과 본선 흐름 변화가 함께 영향을 주므로 이를 바로 capacity drop으로 해석하지 않는다.

RM 유지 상태부터 모델은 두 램프군 사이의 회복을 놓쳤다. 예를 들어 seed53 3120.1초 셀17/18의 실제 속도는60.9/82.0km/h인데 예측은28.1/27.8이었다. 같은 시각 RM 완화 상태에서는 실제17.0/32.1, 예측25.6/25.7이었다. 기준 상태를 이미 혼잡하게 예측하면서 추가 개입의 손실을 작게 보는 문제가 있다. 한 시각 속도만으로 기작을 확정하지 않고 시간별 흐름·재고 오차로 다음 후보를 평가했다.

48개 진출부150초 창과 원본 캐시 SHA는 [offramp_spatial_audit.json](offramp_spatial_audit.json)에 보존했다. FZP를 다시 읽지 않았다.

## 재보정 방법

- 기존 모델의 가속 조건 `desired > speed`, `downstream ≤ local density`, `downstream < rho_crit`를 그대로 사용했다. 조건이 성립할 때만 회복 시간 τ를8/6/4초로 시험했다. 기존 nu/tau 비를 보존해 압력항 자체를 증폭시키지 않았다.
- 두 램프군과 그 사이의 연속 영역인 동측 물리 셀9–25에 **같은 값 하나**를 적용했다. FD·임계밀도·합류 감속·차로 감소·유입량·분기·명령·적분 간격은 그대로이다.
- seed29 초기2220.1초 무제어와 후기2670.1초 RM 유지 두 상태만으로 값을 선택했다. 제어 이득이나 후보 순위에 맞춰 고르지 않았다.
- 점수는 구간 재고 RMSE/평균 관측 재고 + 경계 통과량 RMSE/평균 관측 통과량이다. 각 학습 상태의 두 RMSE 중 어느 것도 기준보다5% 넘게 악화하면 제외하도록 사전에 정했다. 이는 시험의 선택 규칙이며 일반적인 완성도 기준이 아니다.
- 평균 점수0.50063→0.49192로 약1.74% 낮아진 τ4초를 동결했다. 그 뒤 기존 seed43·47·53과 나머지 제어 명령을 평가했다. 이 자료들은 이전 진단에서 이미 살펴본 자료이므로 엄밀한 미공개 검증 세트로 부르지 않는다. 이번 τ 선택에는 사용하지 않았다.

## 실제 제어 손익과 비교

아래는 같은 초기 상태에서 기준 명령에 대한 **동측31셀+진입/진출 커넥터8개**의450초 ΔTTT이다. 음수가 이득이다. 전체 Ω나 외부 대기까지 포함한 비용과 혼동하지 않는다.

| 상태·명령 | 실제 | 기존 예측 | τ4 예측 |
|---|---:|---:|---:|
| seed29 초기, RM | −0.8250 | +0.0015 | **−0.0195** |
| seed43 초기, RM | −1.1708 | +0.0228 | **−0.0141** |
| seed29 초기, VSL | −0.3250 | +0.1447 | +0.1862 |
| seed43 초기, RM+VSL | −1.2750 | +0.4382 | +0.2464 |
| seed47 후기,10484 RM 완화 | +1.6792 | −0.2159 | **−0.2397** |
| seed53 후기, RM 완화 | +5.9292 | +0.2758 | +0.3463 |
| seed53 후기, VSL90 | −0.1500 | +0.1469 | +0.1818 |

단위는 대·시간이다. 초기 RM 두 상태의 방향은 개선됐지만 예측 이득의 크기는 여전히 매우 작다. 후기10484 완화의 부호는 여전히 반대이며 조금 악화했다. VSL의 이득 방향을 해결하지 못했다. **전체 이득 보정 성공이나 안전한 제어 선택으로 판정하지 않는다.**

작은 후보표에서 초기 seed29/43의 예측 최선은 무제어→RM으로 바뀌었다. 실제 최선은 두 경우 모두 RM+VSL이며, RM을 골랐을 때 실제 최선 대비 손실은 각각0.0042/0.1042대·시간이었다. 후기 seed47의 잘못된10484 완화 선택은 그대로이다. 이것은 후보 전진 예측의 순위 비교이며 SDMPC optimizer가 실제 선택했다는 뜻이 아니다.

## 전체 플랜트 연결 확인

후보를 별도 `candidate_reference_config.json`과 `candidate_manifest.json`으로 저장하고 기존 full config에서 그 manifest만 바꾼 `candidate_full_config.json`을 만들었다. 선택된 정본 config는 바꾸지 않았다. 파라미터 검사는 PASS이다.

완료된 SDMPC seed29의6000초 상태를 기존 runner 입력·head 이력·VSL 이력으로 초기화하여150초 전진 예측을 한 번 수행했다. 31셀·8램프·도시부 결합 예측은 완료했고 램프 보존 오차는1.1e−13대 이하였다. [전체 연결 결과](../../closedloop_recorded6000_trace_recovery_tau4_v1/summary.json)를 보존했다.

Ω TTT 예측120.2417대·시간은 동일 명령의 **모델 값**이다. 이를 실제 제어 개선으로 보고하지 않는다.10681 합류 예측은25.84대(실측37)로 개선되지 않았고,10490 도착 오차도 남았다. 이것은 연결·보존 확인이며 계수 채택 검증은 아니다.

## 보존 및 다음 작업

- 기존 `replay_congested_component.py`에 유한 `recovery-response` 실험만 추가했다. 새 adapter나 실행 controller를 만들지 않았고 정본 물리 소스는 수정하지 않았다.
- 오프라인450초 예측44회와 전체150초 예측1회, optimizer iteration0, native0. 모든 소유 계산 종료. 기본 모델의 seed53 네 조건 cells/flows/ports/ramps 배열은 기존 결과와 정확히 같다.
- 선택망·선택 config·도시 목적지 수정·중단 STOP 유지. 결과와 후보는 보존하되 정본 채택하지 않는다. 다음 단계에서 후보를 비교할 수 있도록 별도 설정으로 남겼다.
- 다음 우선순위는10484 완화의 손해를 놓치는 이유이다. 해당 경우의 **램프 실제 추가 합류→셀22–24 통과→하류 유출**을 분해하고, 진출 목적지 구성과 셀 평균 흐름의 가정을 구분한다. 회복 시간을 더 작게 하는 탐색부터 반복하지 않는다.
- 이 오류와 VSL 순위 문제가 남았으므로 새9000초 실행으로 검증을 대신하지 않는다. 목표는 ACTIVE이며 완료되지 않았다.
