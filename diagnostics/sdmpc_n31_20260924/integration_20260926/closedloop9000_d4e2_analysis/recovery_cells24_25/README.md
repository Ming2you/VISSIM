## 결합 플랜트와 SDMPC

동결 설정을 파일로 다시 로드한 seed47 완화 예측은 cells/flows/ports/ramps 전체 배열이 정확히 일치했다(추가 연결 확인1회). 회복 조건과ν/τ 보존을 직접 검사했다.80개 비교의 본선 보존 최대잔차1.85e−13대이며 동적 off-ramp 저장·배수·spillback 및 램프 재고를 유지했다.

실제 저장4500초의 도시·램프·VSL 이력을 유지하고 Ω 목적함수로10490을 비교했다. g10 유지→g8/6/4의 합류는107.826→107.541대, Ω ΔTTT−0.00926대·시간이다. g8고정은 합류량이 사실상 같았다. 이 상태는 **허용 명령에서 물리 효과가 작은 경우**이며 큰 이득 선택의 대표 상태로 사용하지 않는다. 기존10484 선택후 비교는 작은 이득 후보가 제약을 통과해도 제한된2회 탐색에서 선택되지 않았음을 이미 확인했다. 이를 큰 이득 탐색 실패로 확대하지 않는다.

저장4500초의 정본 SDMPC 한 회차와 선택 후 실행모델 검증도 **완료**했다. PFO 상한2/실행2/수락2, SDMPC 상한2/실행2/수락2, 둘 다 미수렴이다. 제어계산313.82초, 선택 근사모델450초29회(스칼라25+접선4), 선택 후 정본 실행모델2회49.77초이다. 별도10490 고정명령 실행모델3회는 optimizer iteration에 포함하지 않는다. 독립 수치미분 witness는 이번에 수행하지 않았다.
