# 실제 관측 이력이 있는 상태의 RM 효과 검사

2026-09-28. 새 VISSIM 실행 없이, 중단된 seed29 SDMPC 런의 실제 3600초·6000초 상태에서 각각 450초 예측을 3회 수행했다. **이번 두 상태에서는 허용된 RM 변경의 합류 효과가 작았다. 큰 물리적 이득을 SDMPC가 놓친다는 추가 증거는 얻지 못했다.**

## 고정한 조건

- 기존 셀23 보정 후보와 도시 목적지 보존 수정을 사용했다. 회복24·25 후보와 국소 차로 후보는 앞선 비교에서 기각된 상태를 유지했다. 계수·물리식·원본 선택 설정을 수정하지 않았다.
- 같은 런의 직전 실제 명령, 17개 도시부 상태, 과거 head 관측, VSL 명령 이력을 사용했다. head 이력 23개/39개 창의 원본 SHA를 확인했고, VSL 이력의 원본 파일 불변 검사도 통과했다.
- 도시 신호·VSL은 직전 실제 명령으로 고정하고 10484만 비교했다. 실제 직전 RM은 g10이며, 150초마다 최대 2초 변경을 지켰다. 다른 시점의 도시 상태나 가상의 g2 이전 명령을 섞지 않았다.
- Ω TTT 목적은 유지했다. 추적 가능한 외부 체류는 별도 진단이며 미삽입 차량 대기 전부를 의미하지 않는다.

사전에 두 상태·6회 예측으로 제한했다. 추가 최적화는 합류 차이 10대 이상이고 Ω 비용 차이 절댓값 0.1대·시간 이상인 후보가 있을 때만 1회 하기로 했다. 이것은 이번 계산을 제한하는 작업 기준이며 통계적 유의성이나 일반적인 제어 가능성의 경계가 아니다. 두 상태 모두 해당하지 않아 추가 SDMPC 최적화를 실행하지 않았다. 새로운 N_P/N_UF cap 검사는 하지 않았으며, 물리·writer·블록 간 명령 제한 검사를 공동 제약 검증으로 표현하지 않는다.

예측 6회의 전진 계산 합계는 156.82초다. 관측 이력 재구성·초기화 시간은 이 합계 밖이다. PFO/SDMPC outer iteration은 0회이며 수렴 여부는 해당 없다. 모든 예측의 3개 명령 블록 실행, 명령 제한, 램프 차량 보존을 확인했고 최대 잔차는 1.48e−13대다. 원본 망·설정·STOP·실제 상태·이전 명령 SHA는 전후 동일하다.

## 해석과 남은 한계

g10에서 시작하면 450초 안에 사용할 수 있는 가장 강한 점진 계획은 g8→g6→g4다. g2는 다음 150초 블록부터 가능하다. 반면 큰 RM 유지/완화 손익이 확인된 seed47·53 실험은 이미 강한 RM이 적용된 상태에서 출발했다. **두 실험의 출발 명령과 허용 제어 영역이 다르므로, 그 이득을 현재 g10 상태의 한 번의 450초 선택에서도 당연히 얻어야 한다고 볼 수 없다.** 이번 검사만으로 지평이 유일한 원인이라고 확정하지 않는다. 수요·하류 수용·posthead 재고도 실제 합류를 함께 제한한다.

기존 셀23 모델은 큰 RM 완화 손해의 방향을 구별하지만 크기를 과소평가하고, 셀24·25의 회복 오차도 남아 있다. 기존 [4500초 검사](../local_merge_cell23/CONTROLLER_CHECK.md)는 작지만 실행 가능한 RM 개선을 제한된 2회 탐색이 선택하지 않은 사례다. 이를 큰 이득을 놓친 사례로 확대 해석하지 않는다. 이번 3600·6000초 결과도 RM의 일반적 무효를 뜻하지 않는다.

강한 반응이 확인된 seed53 2670.1초 런에는 FZP와 50개 native LDP가 있지만, 현재 어댑터가 요구하는 전체 state/obs150 파생 기록·실제 action JSON·head 이력 묶음이 없다. FZP에는 경로 필드가 있으므로 구성 요소 분석은 가능하지만, 그것을 검증 없이 기존 온라인 입력과 동등하다고 선언할 수 없다. 이번에 새 재구성 프레임워크를 만들거나 다른 런의 도시 상태를 빌리지 않았다. `strong_state_input_audit.json`에 확인한 파일 목록과 한계를 남겼다.

## 다음 작업의 경계

이번 제한된 계수·회복·국소 차로·추가 상태 검사를 종료한다. 같은 작은 이득의 부호를 맞추려고 다시 계수를 늘리지 않는다. 강한 합류 반응에서 전체 SDMPC 선택을 검증하려면 **그 상태의 실제 직전 명령과 17개 도시부/관측 이력이 함께 있는 입력**이 먼저 필요하다. 지평이나 명령 변경 한도 변경은 별도의 제어 설계 비교이며 이번 작업에서는 바꾸지 않았다.

기존 결과·기각 후보·로그를 모두 보존했다. 기존 STOP 유지, 새 VISSIM 0회, push 없음. 사용자가 열어 둔 PID38088 창에는 접근하지 않았다. 전체 이득 보정과 강한 상태 SDMPC 검증은 여전히 미완료다.
