## 실제 선택 과정에서 확인한 연결 문제

1. 최신 SDMPC 트리에는 이전 트리의 셀별 delta_merge가 빠져 있었다. 기존 속도 감속식의 계수 조회만 복원했다. 물리량 보존·용량·cost 식은 바꾸지 않았다. 명시적 delta1은 기존 배열과 같다. 관련 44검사+31subtest 통과. delta2 계수는 기본 설정에 넣지 않았다.
2. 실제 SDMPC 선택을 처음 실행하자 저장 가격 정책 불일치로 중단됐다. 진단 결과 적용시각 1050·CSV 경로/크기·schema는 일치했고, 정책 차이는 선택 설정의 `sdmpc_vsl_activation_secant=true`가 현재 코드에서 무시된 것뿐이었다. 기존 기능을 복원했다. 최대 VSL에서 비용/자원 미분이 0일 때만 실행 가능한 낮은 속도 후보의 비용을 계산하며, 실행 범위와 비선형 채택 검사를 유지한다. 강제 VSL 보상은 없다. 관련 23검사+24subtest 통과.

3. 두 번째 실제 선택에서는 예측·미분 계산과 PFO 초기화 2회 수락까지 통과했다. 이후 N_P 후보를 읽기 위해 호출한 기존 joint-game의 미터 서비스율 역변환이, 녹색 9초와 10초의 서비스율이 같은 구간에서 실패했다. SDMPC는 녹색 시간을 직접 탐색하므로 이 역변환은 불필요하다. 기존 함수에 N_P만 읽는 경로를 추가해 두 호출에 연결했다. 원래 N_P 후보·미터 제약·full joint-game 기본 경로는 유지했다. 분리 회귀검사와 SDMPC 제약·VSL 검사 총 24개 및 subtest 24개 통과.

가격은 초기화하지 않았고 기존 적용 영수증·정책 일치 검사를 유지했다. 이전 설정·명령 파일을 고쳐 검사를 통과시키지도 않았다. 실패는 `select1200/`, `select1200v2/`에 보존했고 수정 후 실제 선택은 `select1200v3/`에서 실행한다. 두 번째 실행은 약 147초의 PFO 2회 수락까지 완료했으며 수렴하지 않았다. 이 시간을 최종 SDMPC 수렴 시간으로 보고하지 않는다. 실제 진행은 `status.json`과 해당 세션/프로세스로 확인한다.

### 숫자 오차 대신 실제 선택 손실로 기존15후보 재평가

새 학습 예측 없이 기존15후보를 재평가했다. 두 학습 상태에서 모델이 고른 후보의 실측 비용과 관측 후보 중 최저 실측 비용의 차이를 합산했다. 같은 선택 손실이면 더 작은 merge delta, 그다음 기존 E=4에 가까운 E를 택했다. 계수 δ4/E2를 먼저 고정한 뒤 기존 seed43/47 두 상태의8개 명령을 예측했다. 이 상태들은 과거에 열람한 개발 자료이며 신규 독립 seed 검증이라고 부르지 않는다.

| 개발 상태 | 기존 δ1/E4 선택 / 선택 손실 | δ4/E2 선택 / 선택 손실 |
|---|---|---|
| seed29 초기(학습) | VSL /0.5042 | 무제어 /0.8292 |
| seed29 후기(학습) | 미터 해제+VSL /4.7500 | 기존 미터 유지 /0 |
| seed43 초기(점검) | VSL /2.0667 | 무제어 /1.2750 |
| seed47 후기(점검) |10484 미터 해제 /1.6792 |10484 미터 해제 /1.6792 |

손실 단위는 동측31셀+8개 램프 connector의 차량·시간이다. 학습 합계5.2542→0.8292, 점검 합계3.7458→2.9542로 감소했다. 그러나 초기 RM 이득을 여전히 놓치고 seed47에서는 불리한 해제를 선택한다. 해당 후보는 **부분 개선된 진단 후보**로 보존하며 기본 설정·전체 순이득 검증에 승격하지 않았다. `decision_regret_check/selection.json`은 예측 전에 고정한 선택과 기존15후보 전체 순위를, `summary.json`은 점검 결과를 담는다. 차량 보존·수치 유효성 검사는8개 모두 통과했다.

이는 예측값의 세밀한 오차만 최소화할 필요가 없다는 사용자 지적을 뒷받침한다. 앞으로 선택 손실을 중심에 두되, 유리한 제어를 전부 피하는 것만으로 통과시키지도 않는다. 아주 작은 예측 차이를 확실한 우열로 보고하지 않는다(δ4/E2의 seed43 첫·둘째 비용 차이는0.0228대·시간).

원인 범위도 좁혔다. 실제 미터 해제 후 방출 감소는 특히22번 셀 하류 경계에서−118대인데 기존 모델은−10.83대다. 현재 집계형 본선 수용량은 기본적으로 다음 셀의 남은 저장공간/시간이며, 램프 합류를 뺀 뒤 본선에 배분한다. 이 상태에서 실제 합류 병목의 공통 처리 용량을 충분히 나타내는지는 아직 미확인이다. 다음은 저장 여유와 지속 가능한 처리 유량을 구분하는 기존 합류·수용 계산의 계측이다. 임의 capacity drop이나 새 보상항을 넣지 않는다.

전체 비용과 구간 비용은 계속 구분한다. 기존 후기 native 자료에서 미터 해제의 동측 component 증가4.7042와 달리, 전 망 체류+기존 외부 대기 추정의 증가는2.6438대·시간이었다. 어느 값도 다른 평가 영역의 예측과 직접 맞춰 보정하지 않는다. 3000초 폐루프의 미삽입 대기시간 적분은 여전히 미측정이다.
