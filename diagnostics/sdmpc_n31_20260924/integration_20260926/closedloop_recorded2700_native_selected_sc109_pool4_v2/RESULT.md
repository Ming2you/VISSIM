# SC109 관측 연결 후 선택 명령의 실제 반응

seed47, 공통2700초 상태에서 선택된 도시 신호·RM 명령을3150초까지 실행했다. **Ω TTT는465.537→458.844대·시간(−6.693,−1.438%)으로 감소했다.** 모델은−10.537로 방향은 맞췄지만3.844대·시간 과대예측했다. 이 비교 기준은 완료된 RM 유지 런이며 무제어가 아니다.

## 실제 실행과 비용

- 제어 전 FZP2,141,219행과2700초 차량 상태가 정확히 같다.22개 실행 명령 및 native LDP/readback을 통과했다. LSA COM 커버리지 실패는 보존하고, 사용자 승인된 LDP 기준으로 판정했다.
- 새 native1회, 재시도0회, watchdog1021초. 사후 분석·8램프 검증 완료 및 소유 job/runner/VISSIM15656/42920/26416 종료를 확인했다. 기존9000 STOP은 그대로다.
- Ω 밖 도로 체류는+9.364, native 전체 도로 체류는+2.695, 미삽입 대기는−2.115대·시간이다. **native 도로+미삽입 합계는+0.580대·시간으로 손해**다. 모델의 추적 외부 포함−1.864는 전체 native 비용과 범위가 다르며 전체 순이득 검증으로 쓰지 않는다.
- Ω 정상유출 사건21340→21401(+61), 마지막 Ω 재고3672→3616(−56). 명시적 차량 삭제83→73, 미삽입 잔여8152→8120. 미해명 Ω 소실277→272는 정상 TTD에 넣지 않았다.5초 표본과 마지막4.9초 재고 유지 추정의 한계가 남는다.
