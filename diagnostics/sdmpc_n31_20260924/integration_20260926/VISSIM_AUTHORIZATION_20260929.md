# VISSIM 실행 승인 갱신 — 2026-09-29

사용자 지시: “앞으로, 비씸 실행 필요하면 알아서 돌려줘. 허락 받지 말구”

진행 중인 plant 보정·SDMPC 검증 목표에 필요한 VISSIM 실행은 추가 허락 없이 준비하고 실행한다. 이전의 ‘준비한 1회만’, ‘새 VISSIM 런 금지’ 제한은 후속 실행의 승인 조건으로 적용하지 않는다.

기존 STOP 파일과 중단된 큐는 보존하며 자동으로 재개하지 않는다. 필요한 후속 실험은 범위를 정해 별도로 실행한다. 사용자가 열어 둔 창과 다른 작업은 보호하고, 중복 실행 전에 소유 PID·생성 시각과 현재 상태를 확인한다. 최초 실제 simulation 진행이 300초 동안 없으면 해당 런의 소유 프로세스만 정리한다.

기존 평가 영역·목적함수·실행 검증 원칙과 push 제한은 유지한다. 이 승인 기록 자체는 새 런의 시작이나 완료를 뜻하지 않는다.
