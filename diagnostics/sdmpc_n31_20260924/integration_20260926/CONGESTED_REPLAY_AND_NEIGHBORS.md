## 6구역 후보와 가격 검사 수정

선택망의21개 명령 주소는6개 구역 머리 `[0,2,5,10,13,15]`를 사용한다.
자유 머리는 `[2,5,10,13]`,입구0과회복15는 고정이다. 실제 동역학31셀과 구별한다.

- `joint_owner_game.installed_vsl_layout`이 legacy4구역과 선택6구역의 명시적인 주소를 검사한다.
- `joint_owner_neighbors`의 현재 후보 추출·단일 구역 후보·가격 벡터를 설정된 자유 머리에서 만든다.
- 모든 fixed 구역의 실제 DSD 행을 보존하며,입구를 변경하는 후보는 실패 처리한다.
- 가격 계산 후보의 조기 종료 차원이 `3+미터 수`로 남아 있었다. 실제 callback/writer 시험에서
  자유 구역4개 중3개까지만 남는 오류를 동·서 양쪽에서 재현했다. 이를
  `len(domain.head_values)+움직일 수 있는 미터 수`로 수정했다.

검사는 **76개 테스트+57개 subtest 통과**(`six_zone_callbacks_final.log`).
기존4구역·writer·고정 trust region·미터 가격 검사를 포함한다. 새 가격 회귀 시험은 합성 관측·후보
함수와 실제 canonical callback/writer를 사용한다. 실제 SDMPC 최적화나 교통 이득 검증은 아니다.
최초 시험용 함수의 bound-method 계약 오류와 실제 후보 누락 실패 로그도 각각 보존했다.

현재 SDMPC `Coordinates`와 가격 적합의 도메인 수는 설정된 자유 구역을 순회한다.
이번 확인만으로 전체 SDMPC의 수렴·미분·최종 명령 선택이 검증됐다고 표시하지 않는다.
