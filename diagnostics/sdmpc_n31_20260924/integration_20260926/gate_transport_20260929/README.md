# 램프 도착 경로·이동시간 수정 — 2026-09-29

두 가지를 구분해 수정·검증했다. **이미 지난 분기로 되돌아 배정하는 오류는 수정했다. 실제 경로의 이동시간을 사용하는 기능은 연결을 보완하고 후보 설정에서만 시험했다.** RM/VSL 전체 이득 보정과 최종9000초 목표는 아직 완료되지 않았다. 추가 native·FZP 재스캔·계수 보정·push는0회이고 기존9000 STOP을 유지했다.

## 1. 현재 재고의 도달 가능한 목적지

기존 정본 `physical_ramp_branches.py`의 `initial_gate_city_lock` 초기화를 수정했다.10778·129는10482 분기를 지난 위치이므로 그 차량을10482로 다시 배분하지 않는다. 기존 비율을 남은10490·도시 목적지에 조건부 정규화한다. 이는 관측되지 않은 실제 개인별 경로를 복원한 것이 아니라, 물리적으로 가능한 목적지에 대한 기대 배정이다. 도시행 확정 재고·차량 수·대기·기존 준비 시각·미래 생성은 유지한다. 어댑터나 실행 경로를 복제하지 않았다.

수정 전에는10778/129에 있는10대 중5.114대를10482로 보내는 테스트가 각각 실패했다. 수정 후 관련19개 검사가 통과했다. 같은 명령으로450초 예측4회를 수행했다.

|seed47,2700초|−8.082932|−8.082933|

단위 대·시간. 두 상태 모두 후보 순위가 유지되고8램프 보존을 통과했다. seed47의 잘못된10482 방향 기대 배정6.487대를 제거했지만10490 진입은106.766→110.483으로 늘어 도착 과대예측 자체는 해결되지 않았다. **경로의 물리적 일관성을 고친 결과이지 이득에 맞춘 보정이 아니다.**

## 2. 새 차량에 적용된34초 이동시간

수정 전 seed47의10490 예측은 다음처럼 정확히 분해된다.

- 초기 미확정156대×실효10490 비율0.201293=31.4017대.
- 미래 입력3240대/h×같은 비율=초당0.181164대.
- 공통34초 이동 후450초 지평에 도착하는 미래 차량416초×0.181164=75.3642대.
- 첫150초 예측은31.4017+116초×0.181164=52.4167대. 실제 첫150초31대는 모두 초기 망에 있던 차량이며 신규 생성 차량 도착은0대였다.

따라서 첫 구간의 과다 도착을 미터 출발지연만으로 보정하면 원인을 놓친다. 미래 도착을 실제 경로 길이와 현재 접근 상태에 연결해야 한다.

이미 구현된 `native_gate_travel`은 정확한 현재 route COM 관측을 전제로 한 초기화에만 연결되어 있었다. **아직 생성되지 않은 미래 차량의 native 선택 분포와 경로 길이는 현재 차량의 과거 선택 관측과 독립적**이므로, 검증된 topology 초기화에도 연결했다. 기존 기능의 경로·현재 링크 속도·외부 대기·수용·보존식을 재사용하고, 오래된 route 관측을 만들어 넣지 않았다.

기존 strict route 모드의 전체 초기 상태·미래 기하·반환 진단은 수정 전 소스와 정확히 같다. 새 경로 연결 및 실패 시 초기 상태 무변경을 포함해21개 검사가 통과했다. 원래 full config는 변경하지 않았다. 이 폴더 후보는 기존 full config와 비교해 `urban.ramp.native_gate_travel=true` 한 항목만 다르며 parameters 검사도 통과했다.

## 3. 한 후보의 제한된 자율 예측4회

현재·과거 관측만 사용했다. 미래 실측 차량·속도·도착은 예측 입력에 넣지 않았다. seed47의 실제10484 RM 유지/완화 두 명령을450초 예측하고, seed29의4500·6000초에서는 직전 실제 명령 유지 예측을 각각1회 수행했다. 이4회 후 추가 계수나 이동시간 후보를 탐색하지 않았다.

seed47에서 새1102 차량의 이동시간은10482까지149초,10490까지178초,도시 정지선까지290초다. seed29의4500초에는128/155/267초,6000초에는94/115/158초다. 계수를 따로 맞춘 값이 아니라 현재 링크 평균속도와 실제 경로 길이로 계산한 값이며 지평 내 고정하는 근사의 한계가 있다.

|seed47·10490|실제 유지|기존 예측|미래 이동 후보|
|---|---:|---:|---:|
|450초 진입|101|106.766|89.519|

10490 합류 오차는 줄었지만 진입 총량은 과소예측하고 종료 재고도 부족하다. 원래 망의10484 완화 조건에서도10490 합류는 실측91,기존107.854,후보89.881이었다. 이것은10490 미터를 직접 변경한 반응 검증은 아니다.

유지·완화×8램프16개 관측의 평균 절대 오차는 합류12.394→10.650대, 도착16.398→16.630대, 종료 재고8.883→8.819대다. 한 램프의 개선만으로 전체 보정 완료를 선언하지 않는다.

10484 RM 완화의 실제 Ω 손해는+2.0538대·시간이다. 기존 예측+0.4889,후보+0.4848로 **방향은 유지되지만 손해 크기를 여전히 작게 예측**한다. Ω 밖 체류도 별도 진단했으며 목적함수는 변경하지 않았다. 이 시험의 VSL은 고정이므로 VSL 이득 검증이라고 하지 않는다.

모든8램프·게이트의 보존과 명령 한도 검사를 통과했다. gate 입력405대 중251대가 목적지 큐에 도착하고154대가 이동 중으로 남는 등 지연된 차량을 삭제하지 않는다. seed29 두 예측은 다른 상태의 실행·보존 확인이며 동일 명령의 실제 미래를 검증한 것은 아니다.

## 판단과 다음 범위

1. 지나간 분기로 돌아가는 초기 배정 오류 수정은 유지한다. 미확정 경로의 기대 배정이라는 한계를 명시한다.
2. 미래 이동 기능은 **후보로 보존하고 기본 설정에 채택하지 않았다.** 이미 완료된 선택 도시+10490 RM 명령과, 정확히 맞춘 독립 상태의 실제 명령에 대한 반응 검증이 남는다.
3.10482는 실제2차로 접근 movement의 실효 상한이 아직 총1800대/h라 예측 진입217.5대에 계속 걸린다. 이는 본선 합류 상한·미터 서비스율과 별개다. 기존 차로 수 반영 기능을 같은 관측 방식에 연결할 수 있는지 다음에 확인한다. 실제 방출에 맞춘 임의 상한을 넣지 않는다.
4. 초기 재고의15초/105초 집계 준비 시각, 이동 중 회복, off10491에서 오는 도착 흐름과 목적지 불확실성은 남아 있다. 합류 감속·anticipation·서비스표를 동시에 다시 맞추지 않는다.
5. SDMPC 재선택·AD 연결·VSL 반응·장기 폐루프 검증을 통과했다고 하지 않는다. 기존9000 STOP 및 사용자 프로세스를 유지했다.
