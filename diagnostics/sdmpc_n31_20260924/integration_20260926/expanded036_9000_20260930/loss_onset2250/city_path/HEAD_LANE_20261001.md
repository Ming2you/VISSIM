# 이전9000 손실 시작 구간: 초기 큐의 차로 배정과 녹색 도착

완료된 seed29 SDMPC의2250·3600초 관측만 사용했다. 현재 CTG는 조회·변경하지 않았고 새 VISSIM·FZP 스캔·계수 탐색·push는 없다. 이 문서는 전체9000 손실 보고서 `../../loss_diagnosis/README.md`의 후속 원인 진단이다. 목표는 **ACTIVE / NOT_QUALIFIED**다.

## 확인한 원인

기존 초기화는 도로329의 정지30대를 세 movement에10대씩 배정했다. 실제 head 관측에서 직진 연결 차로2·3의 정지 차량은25대, 좌회전 차로4는5대다. 기존 `head_phase` 옵션만 켜도 직진·우회전이 같은 현시라25대를12.5대씩 나누는 문제가 남았다.

선택 네트워크의 실제 connector source lane과 기존 정본 movement→physical turn 매핑을 검증해, **29·329 두 도로의 초기 큐만** 차로에 맞춰 배정하는 선택적 후보를 구현했다. 예:329→10691은2·3차로 직진,10692는1차로 우회전,10693은4차로 좌회전이다. 움직이는 차량의 목적지나 미래 통과 정보를 초기화에 넣지 않았다. 이는 현재 head 접근 차로를 사용하는 근사이며, 차량의 이후 차로변경·목적지를 완벽히 아는 모델은 아니다.

## 상류 방출이 늘어도 하류 녹색을 놓쳤다

2250초 기준 모델329 직진 서비스율은1818.18대/h,3600초는2142.86대/h다. 상태별 초기화 값이며 새로 보정한 상수는 아니다.2250초 모델은 녹색 시작 후 약0.505대/s로 방출한다.

|2250 이후30초 구간|실제329 방출|차로 큐 후보|
|---|---:|---:|
|2250–2280|14|6.566|
|2280–2310|21|15.152|
|2310–2340|0|7.343|

모델 상류 방출이 실제보다 늦게 분산된다. 늘어난 상류15대 중 기존 다음 movement 비율0.625에 해당하는9.375대가 하류 직진 큐에 **2356–2384초**에 추가 도착한다. 하류 녹색은2296–2351초라 모두 녹색을 놓친다. 따라서29 방출 증가1.333대는 초기29 직진 큐의0.667→2대 수정분뿐이며, 추가 상류 방출의 효과는 첫150초 내 나타나지 않는다.2400초29 직진 잔여 큐는1.212→10.587대다.

다음에는 **현재 head/차로별 서비스율 추정이 초기 platoon 방출을 과소평가하는지**, 이동 중 재고의 목적지 분할과 도착 시각을 함께 확인해야 한다. 이 자료만으로 용량을 두 배로 올리거나 이동시간을 일률적으로 줄이지 않는다. 모델의 실제 합류 과대(2250초46.43 vs36)는 별도의 램프 통과·수용 문제로 남는다.

## 채택·검증 범위

- 생산 기본 설정은 변경하지 않았다. 선택적 코드만 추가했고 `head_lane_config.json`에서만 사용한다. 활성 CTG는 동결 실행본을 사용하므로 이번 코드와 무관하다.
- 초기화3회: phase-only, 전역 head-phase+국소 connector support, 최종 **29·329만 적용**. 앞의 두 개발 결과를 보존하고 최종 국소 후보로만450초 예측2회 수행했다. 세 초기화와 예측2회 모두 정상 종료했다.
- 두 상태에서 물리 링크별 재고 배정 변화는29·329뿐이다. 링크별 합계, 전체 큐 합계, 다른 링크 배정, 저장·이동 예약·속도·본선 초기 배열과 명령은 동일하다.8개 램프의 예측 보존 잔차는 모두1e-8 미만이다.
- 기존 전체 투영 진단 잔차 **−43대(2250),−59대(3600)**는 수정 전후 동일하다. 이번 후보가 차량을 추가·삭제하지 않았다는 차분 검증과, 기존 전체 투영이 완전히 정합하다는 주장은 구분한다. 후자는 이번에 통과했다고 주장하지 않는다.
- 차로 공유/분리·미확인 head 폴백·큐 보존, 네트워크 해시 변경·다른 관측 망·movement 재연결·틀린 connector 차로 거부, 미설정 경로 보존 등 **17개 테스트 통과**. `git diff --check` 통과.
- 기본 튜닝 c4ab, 기존 램프 속도 연결 수정, RM 물리·routing·SDMPC·STOP 해시 유지. 미래 관측 입력, 목적함수·N_P/N_UF·METANET 계수 변경 없음.
-450초 Ω 예측TTT는2250상태485.218→486.359,3600상태516.986→517.814다. 같은 명령의 **모델 변경**이며 실제 정책 손익이 아니다. native 다음 명령이 달라지므로 전체450초를 동일 실행 검증으로 보지 않는다. 후보 순위·미분·제약·SDMPC 선택·실제 제어 이득은 미검증이다.
