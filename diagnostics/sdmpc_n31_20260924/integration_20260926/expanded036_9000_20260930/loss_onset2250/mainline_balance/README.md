# 본선 방출·재고 보존과 24·25셀 속도항 진단

2026-10-01. **24·25셀의 과소 방출은 상류 오차가 그대로 전달된 것만은 아니다. 이 구간 안에서 추가 재고 오차가 생긴다. 모델 내부에서는 낮은 목표속도로의 이완과 상류 속도의 대류 영향이 직접 감속을 만들고 있었다.** 새로운 물리 계수나 모델은 채택하지 않았다.

## 범위와 독립 검증

완료된 expanded036 seed29 런의 2250–2400초 및 3600–3750초만 실제 명령과 대조했다. 기존 자율 후보의 450초 예측에서 첫150초를 사용했다. 이후 실제 명령이 바뀌므로 나머지300초를 native와 같은 실험으로 취급하지 않는다. 현재 CTG 런을 읽거나 건드리지 않았다.

native source/off-entry/terminal은 기존 obs150의 검지 위치와 양끝 재고 보정을 적용한 경계 통과 수를 사용했다. 합류는 미터 head 통과와 신호등 이후 초기·종료 재고로 복원했다. 두 창 모두 native 삭제는0이다. 각 셀의 누적 하류 통과량은 차량 보존식으로 복원했다.

F_out = F_in + 실제 합류 − 진출 − (종료 재고 − 초기 재고)

각 창의 전체 본선 보존·말단 통과가 일치했다. 별도 본선 through 검지기 네 지점씩, 총8건에서도 **복원값과 검지 통과가 정확히 일치**했다. 검지기 위치가 셀 경계와 다르면 실제 차량 위치로 부분 구간 재고를 계산했으며 균일밀도로 나누지 않았다. 31셀×2모델×2창의124개 행을 보존했다.

## 24·25셀: 구간 내부에 생기는 추가 재고

아래 오차는 모델−실측, 단위는 차량이다. 두 셀에는 합류나 진출 포트가 없다.

|---|---:|---:|---:|
|2250초|−13.35|−25.84|+12.49|

2250초에는 이미 유입을 적게 받는데도 더 많이 쌓는다. 3600초에는 추가 유입5.61대보다 추가 재고25.09대가 크다. 따라서 상류 합류량만 고치면 하류 재고 오류가 자동으로 해결된다고 볼 수 없다. 이는 **정확한 보존 항등식의 분해이며 독립적인 인과 기여율은 아니다.**

두 창의 본선 source 예측은 각각305/290대, 실측303/341대다. 특히3600초 전체 본선의 재고 부족을 전부 병목 동역학 탓으로 보정하면 안 된다. 원점 예측 오차와 국소 방출 오류가 동시에 존재한다.

같은 예측을 두 번 재계산하며 기존 속도 갱신의 입력·항·출력만 계측했다. 셀18–26의 매초2700개 호출에서 항의 합, 다음 초 속도 연결,150초 말단 속도를 확인했다. 24·25의 매초 유출 적분도 앞서 독립적으로 복원한 유출량과 일치했다. 계측 전후450초 상태·명령·유량·재고·비용은 정확히 동일했다.

- **24셀의 이완항은 거의 계속 감속이다.** 목표속도가 현재속도 이상인 초는2250창0/150,3600창6/150이다. 모델 내부 평균 목표속도는39.95/36.46km/h다. 현재 구현처럼 목표속도가 높아야 발화하는 회복 가속 계수만 줄이면 거의 작동하지 않는다.
- **상류 대류항도 크다.** 동일한 실측 초기 상태에서2250초24셀은 이완−1.55,대류−6.16,anticipation+0.50km/h의 첫1초 갱신을 받는다.3600초는−0.49/−4.01/−0.83이다. 이후 저속·추가 재고·낮은 목표속도가 연결된다.
- **24·25에는 직접 합류 감속·lane-drop 감속·수용 제한에 의한 속도 상한 적용이 없었다.** 이 말은 상류 합류/진출의 간접 영향이 없다는 뜻이 아니다. 현재 두 예측 안에서 직접 속도를 깎는 항을 구분한 것이다.
- **25셀의 상태는 창마다 다르다.** 2250창은 이완 가속136/150초,3600창은0/150초다. 하나의 ‘회복 가속’ 규칙을 두 창에 같은 의미로 적용할 수 없다.
- **23셀까지 일괄 가속하면 위험하다.** 3600창 종료에서 실측31.45인데 모델43.58km/h로 이미 빠르게 예측한다.24·25의 저속 편향과 같은 방향의 오류가 아니다.

이 항 계측은 모델 내부의 직접 계산 경로를 설명한다. actual 차량 가속도나 파라미터 변경의 인과 효과를 측정한 것은 아니다. 후반 목표속도 저하는 예측 밀도 오류의 결과이기도 하므로 FD 단독 오류로 확정하지 않는다. 다만 초기 실측 상태에서 이미 발생한 큰 감속은 다음 비교 대상을 좁혀준다.
