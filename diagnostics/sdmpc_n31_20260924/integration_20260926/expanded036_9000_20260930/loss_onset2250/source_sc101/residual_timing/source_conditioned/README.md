# 동측 유입량 차이의 조건부 원인 진단

2026-10-01. 완료. 새 VISSIM·최적화·계수 보정은 없고, 기존 두 명령의 450초 예측만 각각 한 번 계산했다. 순 계산 시간은 81.359초였다.

**미래 실측 유입량을 사용한 조건부 진단이다. 자율 예측, 이득 검증 통과, 보정 완료의 근거로 사용하지 않는다.**

2700초 같은 초기 상태에서 RM 유지와 기존 SDMPC 선택 명령을 재생했다. 선택 명령은 도시 신호도 변경하므로 RM 단독 비교가 아니다. VSL은 두 조건 모두 110이다. 계수·초기 상태·명령·서측 및 도시 수요는 유지했고, 동측 원점의 150초 평균 입력만 실제 수용된 차량 수로 대체했다. 이는 발생 수요를 식별한 결과가 아니다.

동측 조건부 입력은 유지 307/303/306대, 선택 308/316/316대다. 모델의 실제 수용량이 입력과 일치하고 종료 원점 대기가 0임을 확인했다. 재고나 방출량을 강제로 덮어쓰지 않았다.

Δ는 선택−유지다. TTT는 해당 150초 구간의 대·시간, ΔN은 구간 끝 차량 수 차이다. 음의 ΔTTT가 개선이다.

450초 Ω ΔTTT는 기존 자율 −7.3853, 조건부 −6.2585, 실측 −1.0883대·시간이다. 동측 본선만 보면 각각 +0.1751/+1.3000/+2.5376대·시간이다. 입력 차이의 반영으로 일부 오차가 줄지만, 큰 도시부 개선을 과대예측하고 뒤쪽 구간의 손실을 놓치는 문제는 남았다.

본선 말단의 선택−유지 누적 유출은 조건부 0.7875대, 실측 −44대다. 조건부 종료 동측 ΔN도 +22.53대로 실측 +71대에 못 미친다. 실제 원점 유입 차이 +24대만으로 현재 모델의 방출 반응이 복원되지 않는다. 이 숫자들을 인과적 기여율로 환산하지 않는다.

3150초 선택 조건에서 셀19/20 속도는 조건부 예측 76.01/71.77, 실측 38.31/30.57km/h다. 반면 셀21–25에는 여전히 저속 편향이 있다. 따라서 전구간 회복을 빨리 하거나 셀23 계수만 강하게 바꾸는 근거는 아니다. 본선 내 혼잡 위치·전파·출구 선택·방출의 연결을 구분해야 한다.

원래 ALINEA·고정 VSL90 네 조건은 계속 기본 물리 반응 기준이다. 이번 SDMPC 손실 진단은 이를 대체하지 않는다. 이미 실패한 route-inventory 옵션, 회복24·25 FD/이완계수 그리드를 반복하지 않는다. 원래 큰 RM 이득/손실 및 VSL 조건의 공통 초기 상태 비교를 깨뜨리지 않는 개선이 필요하다.

검증: 원본 명령 동일, 두 도로 각 150초 차량 보존 잔차 1e−7 이하, 기존 None/네 조건 진단의 출력 동등성, 12개 잘못된 계약 거부, 원본 출처 해시 유지. 기존 실행 자료와 STOP은 변경하지 않았다. 바뀐 파일은 진단 helper 및 wrapper뿐이며 과거 실행 원문을 먼저 보존했다.
