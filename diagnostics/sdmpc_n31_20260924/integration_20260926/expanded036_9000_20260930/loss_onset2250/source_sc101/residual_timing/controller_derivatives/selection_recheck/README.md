# 비활성 VSL 미분 수정 후 실제 SDMPC 선택 확인

2026-10-01 완료. seed47의 저장된 2700초 상태에서 기존 SDMPC를 한 주기 실행했다. 이전 목표 턴은 기존 보정 범위를 재확인한 NO_PROGRESS였고, 이번 턴은 실제 선택 계산과 실행 명령 동등성을 확인한 PROGRESS다. 전체 목표는 ACTIVE / NOT_QUALIFIED다.

## 바뀐 탐색과 실제 선택

앞서 수정한 freeway_fd의 비활성 VSL 미분만 사용했다. 물리식의 스칼라 값, 보정 계수, 목적함수, 정책, 탐색 범위, 두 번의 반복 한도, PFO 기반 N_P/N_UF 상한은 이전 res47v2와 같다. 과거 head·VSL 이력과 실제 2550초 명령의 출처 검증을 통과했다.

- 수정 전에는 동측 VSL 24개 항목을 AD로 처리했다. 수정 후에는 동측 4개 제어 구역 × 3개 시간 블록 × 2회 반복을 모두 110→100km/h의 실제 허용 단계로 평가했다. 서측 24개 항목은 수정 전에도 같은 검사를 했다.
- 추가된 동측 24개 비교는 Ω 비용이 각각 +0.000102~+0.152053veh·h 증가했다. 작은 차이를 실제 손해로 확정하는 것이 아니라, 현재 모델에서 이 후보들이 선택되지 않는 이유를 확인한 결과다.
- 총 48개 VSL 비교는 모두 N_P/N_UF 상한을 통과했다. 이 수치는 저장된 실제 secant 비용·자원 차이에서 복원했다. 자원 상한 통과를 각 후보의 모든 비선형 물리 제약 검증으로 확대하지 않는다.
- 최종 명령은 이전과 같다. VSL은 모두110, 10484 녹색2초 유지, 10490은 첫 블록5→6초와 이후5/5초, 나머지 RM과 선택 도시 신호도 이전 선택과 정확히 같다.

최종 선택 명령을 기준으로 한 첫150초 구역별 110→100 변경의 예측 Ω 비용 증가는 다음과 같다. 나머지 명령과 초기 상태는 고정했다.

|동측 VSL 구역|예측 ΔΩ TTT [veh·h]|
|---|---:|
|seg2|+0.006378|
|seg5|+0.046100|
|seg10|+0.020713|
|seg13|+0.138926|

이는 한 저장 상태에서 한 구역·한 블록씩100을 적용한 확인이다. 50~110의 모든 조합, 더 이른 예방 시점, VSL90의 장기 이득을 배제하는 결과가 아니다. 허용 전체 집합50/60/70/80/90/100/110은 유지했다. 현재110에서의 변경 한도 때문에 좌표의 국소 허용 범위는70~110이다.

## 실행 검증 재사용

이전 선택과 새 선택의 7개 물리 action 필드, 세 블록 명령, 실제 CSV 바이트, 직전 실제 명령 JSON·CSV가 모두 동일하다. 선택 비용487.084351→479.584199와 자원 계산도 정확히 같다. control sequence에서 달라진 것은 출처 문맥을 포함하는 plan_action_token뿐이다.

따라서 계획했던 실행용 모델 두 번의 중복 예측은 수행하지 않고, closedloop_recorded2700_select_check_res47v2_resv3의 기존 held/selected 검증을 재사용했다. 앞선 독립 검사에서 AD 수정 전후13개 스칼라 예측이 정확히 같았고, 당시103개 source pin 중102개가 그대로다. 나머지 helper의 이전 바이트를 확인했고 probe_levers의 AST가 같음을 검증했다. helper의 변경은 진단 guard와 선택 검사 진입점이며 물리 예측 함수는 같다.

재사용한 실행 모델의 선택−기존 명령 Ω 차이는−7.385319veh·h, 추적 외부 체류 차이는+6.943106veh·h다. 8램프 보존·17도시 owner 자원 검사는 기존 검증으로 유지된다. 새 VISSIM 실측이나 추가 이득으로 보고하지 않는다. 앞서 동일 명령의 native 반응에서 확인한 Ω 이득 과대예측과 본선 방출·회복 오차도 그대로 남는다.

새 label을 받도록 기존 실행 검사 wrapper를 잠시 확장했으나, 최종 명령이 같아 사용하지 않았다. 원본 hash를 대조한 뒤 wrapper를 정확히 복원했고 제안본과 편집 기록만 보존했다. 새 adapter나 운영 실행 경로는 추가하지 않았다. 첫 후처리에서 executed_control_blocks 리스트를 정수3과 비교한 진단 assertion 실패는 보존했으며, 실제 리스트 길이3을 확인하도록 수정했다. 이 수정에 따른 재예측은 없다.

## 계산과 판정

실제 SDMPC 한 결정399.774초, 반복2회 중 개선1회 수락, 한 leader 후보, no_executable_step 종료, converged=false다. 근사 스칼라48회+AD8회=56회이며 이전24+8회보다 스칼라24회가 추가됐다. 계산시간은 실행 환경의 영향을 받으므로 이번 결과로 속도 개선을 주장하지 않는다. 세션14323은 exit0다. 새 계수 보정0, 새 native0, FZP 재스캔0, push0다.

결론: 비활성 VSL의 잘못된 미분이 합법적인 후보 검사를 막던 연결 문제는 실제 SDMPC 경로에서도 수정됐다. 다만 이 상태의 최종 선택은 바뀌지 않았다. 현재 근방에서 VSL을 쓰지 않는 것을 자원 제약이나 해당 후보의 탐색 누락으로 설명할 근거는 없어졌다. 10490 미분 크기 불일치와 실제 VSL 방출·회복 반응의 오차는 미완료다.

같은 상태의 선택을 반복하거나 작은 비용 차이를 억지로 맞추지 않는다. 다음 물리 보정·검증은 기존 ALINEA/VSL 공통 초기 상태 자료에서 유의미한 실제 합류·병목 방출·회복 차이를 기준으로 한다. 기존 기각된 FD/회복/공간 합류 계수 탐색은 반복하지 않으며, 이 선택 확인을 전체 이득 검증이나9000초 실행 자격으로 대신하지 않는다.
