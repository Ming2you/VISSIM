# 비활성 VSL 자동미분 정합 수정

2026-10-01. 선택망 seed47의 저장2700초 상태와 현재 readiness_candidate/res47v2 이력을 사용했다. 새로운 계수 보정·VISSIM·push는 없다. 목표는 ACTIVE / NOT_QUALIFIED다.

일반 예측은 명령110 부근의 비활성 구간에서 문헌 VSL식을 적용하지 않는데, 자동미분만 그 식의 명령 기울기를 더하고 있었다. 일반 예측의 국소 미분과 달랐고, 기존 vsl_activation_secant가 요구하는 영 기울기 조건을 막았다.

freeway_fd.literature_desired_speed의 비활성 분기에서 그 추가 기울기를 제거했다. target의 밀도 등 상태 미분은 유지한다. 활성 VSL식·계수·차량 보존·램프 서비스·목적함수·실행 명령은 바꾸지 않았다. 기존 FD 법칙의 실제 제어 이득을 검증했다는 뜻은 아니다.

## 독립 미분 대조

실제 직전 명령을 유지한 anchor에서450초, AD1회와 별도 query의 scalar13회를 수정 전후 각각 실행했다. RM은 녹색0.001/0.0005초, VSL은0.01/0.005km/h 차이를 사용했다. 작은 perturbation은 native 명령이나 실행 가능한 후보로 취급하지 않았다.

전후 scalar13개의 목적값·주체별 비용·NP/NUF·영역·자원 summary는 정확히 같았다. 기존 선택의 held objective487.084351104582도 재현했다. 두 AD의 독립 primal 대조, 17개 관련 unit tests 및240개 scalar FD 함수 대조가 통과했다. 활성 VSL의 AD 차분 일치와 비활성 target의 기존 상태 미분 유지도 시험했다.

실제 VSL 열을 sdmpc.vsl_activation_axes에 넣으면 수정 전에는 대상이 없었고 수정 후에는 기존 legal-step 검사 대상으로 선택된다. 검사 경로 연결 확인이며 SDMPC가 VSL을 최종 채택했다는 주장은 아니다. 새 최적화는 실행하지 않았다.
