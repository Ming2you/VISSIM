# 준비 큐를 제외한 잔여 정지 재고의 분류 수정

기존 어댑터 한 함수의 오류를 수정했다. 관측 정지 차량에서 이미 준비 큐로 배정한 차량을 빼지 않고, 원래 링크의 정지 비율을 잔여 저류에 다시 적용하고 있었다. 차량 총수가 중복된 것이 아니라, 남은 이동 차량 일부를 정지 차량으로 잘못 분류하여 늦은 도착으로 예약한 문제다.

관측된 정지/연속 큐를 사용할 때 잔여 정지량을 **관측 정지량 − 준비 큐**로 계산한다. 고정 비율로 추정한 큐에는 이 차감을 적용하지 않는다. 중간 native 신호 앞 차량처럼 준비 큐가 0인 저류는 기존 정지량을 유지한다. 관측 큐가 관측 정지량보다 크면 실패 처리한다. METANET 계수·서비스율·명령·경로 비율은 바꾸지 않았다.

3600초 SC101 접근도로1220011503은 총43대 중 정지5대가 모두 준비 큐에 들어간 상태였다. 남은38대는 이동 차량인데 기존 계산은4.419대를 정지 저류로 다시 분류했다. 수정 후 SC1_to_SC101 전체70대의 초기 예약은 3615초50.581/3705초19.419대에서55/15대로 바뀐다. 15대는 실제 SC15 앞 정지 차량이다. **15초/105초의 기존 예약 규칙 자체는 아직 물리적 이동시간 모형으로 교체하지 않았다.**
