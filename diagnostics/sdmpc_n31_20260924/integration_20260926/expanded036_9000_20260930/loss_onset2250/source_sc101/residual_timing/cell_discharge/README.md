# 셀19·20 방출 손실의 위치 확인

2026-10-01. 기존 완료 자료만 사용했다. 186개 셀·구간 보존식, 146개 차로 snapshot과 12개 native 검지기 대조를 완료했다. 새 예측·보정·VISSIM·FZP 재스캔은 없다. 전 목표는 ACTIVE / NOT_QUALIFIED다.

기존 원점 유입 조건부 진단 다음 단계로, 2700–3150초의 본선 유량을 셀별로 분해했다. 내부 셀 유량은 초기·종료 재고와 실제 진출·합류를 이용한 보존식 역산이다. 셀18/20은 별도의 through:10481/10483 native 검지기와 6개 구간씩 정확히 일치했다. 다른 셀의 역산 유량을 독립 검지기 측정으로 표현하지 않는다.

Δ는 선택 명령−기존 RM 유지, 단위는 대다. 선택 조건은 도시 신호도 바뀌므로 RM 단독 효과가 아니다. 모델 열은 앞서 완료한 자율 예측을 사용했으며, 이번 분석에서 미래 관측을 모델에 공급하지 않았다.

450초 동안 셀18 통과량 차이는 −2대에 불과하지만 셀20에서는 −38대가 된다. 두 셀의 실제 종료 재고 차이가 +40대로 커졌다. 본선 말단 −44대만 보고 전체 고속도로의 균일한 수요 문제라고 판단할 수 없다. 말단과 중간 구간의 차이에는 이동시간·진출·합류·구간 재고가 포함된다.

2850초 선택 조건의 셀20 1차로 정지(<5km/h) 차량은 4대다. 현재 route 관측상 1대는 본선 통과(1131/1), 3대는10483 진출(1131/3)이다. 이 시각10483 connector 재고는 0대이고, 합류하는 도시 링크124에도 정지 차량이 없다. 따라서 이 시각 본선 정체를 off-ramp가 가득 찬 결과로 설명할 수 없다. Snapshot 사이의 정지·혼잡을 배제하는 결과는 아니다.

10483 진출 위치와10490 합류 위치 간격은 기존 기하 감사에서2.81425m로 확인됐다. 이번 증거는 공유 차로의 혼합 교통 반응을 다시 뒷받침하지만, 특정 conflict rule 또는 RM 명령이 이 손실을 일으켰다는 단독 인과 증명은 아니다. 새 기하/차로 모델이 필요한지 여부와 채택 성공도 증명하지 않는다.

3150초 선택 조건의 셀19/20 속도는38.31/30.57km/h인데, 바로 하류 셀21은66.59km/h다. 플랜트는19/20을76.01/71.77로 빠르게,21을46.29로 느리게 예측했다(직전 조건부 결과; 자율 결과도 같은 편향). 혼잡 위치가 반대로 퍼진 단서이므로, 셀21 합류 감속만 키우거나24/25 회복만 키워 이 사례에 맞추지 않는다.

다음 판단은 기존 지역 차로·목적지 모델19–25가 실패했던 조기 혼잡/느린 회복과 함께 해야 한다. 이미 구현·기각한 lane_dn67/joint_lane_25 후보를 새 아이디어로 반복하거나 단순 route-inventory 옵션을 다시 켜지 않는다. 현재 공통 재고 모델의 저밀도 합류 수용은 주로 남은 jam 공간이고, 실제 mainline–ramp 경쟁은 gap 공급과 합류 감속에 나뉘어 있다. 공유 합류 지점에서 유량과 속도 반응을 함께 표현하는지 확인할 근거는 강화됐지만, 임의 상수 용량 감소를 도입할 근거는 아직 없다.

원래 ALINEA+병목 VSL90 네 조건을 기본 기준으로 유지하고 큰 RM 손익을 이미 맞춘 결과는 보존한다. 새 동역학 후보는 이득/손해 양쪽의 자율 유량·재고·대기·Ω 비용을 통과해야 한다. 계수·운영 코드·기존 STOP·프로세스·git 원격 상태를 변경하지 않았다.

## 기존 FD를 수용 용량으로 바로 쓰는 후보의 사전 배제

현재 결합 모델이 참조하는 expanded036의 평형 희망속도식에서 최대 유량을 계산했다. q_max = 차로 수 × v_free × rho_crit × exp(−1/a)다. 이는 현재 동적 수용식이나 실측 capacity가 아니다.

셀21의 기존 FD 최대는 4663.5대/h인데, 실제 본선 유입+10490 합류는150초 평균 6360–6936대/h였다. 이 FD 최대를 새로운 hard receiving cap으로 바로 넣으면 실제로 받아들였던 교통을 매150초 70.7–94.7대씩 배제한다.

따라서 이 특정 수정은 추가 rollout 없이 배제한다. 모든 CTM·수용 모델이 부적합하다는 결론은 아니다. 비평형 METANET의 순간 유량이 평형 FD 최대를 넘는 것 자체를 코드 오류로 취급하지 않으며, 관측 최대150초 유량을 진짜 capacity로 확정하지 않는다. 미래에 수용식을 검토하면 현재 FD의 rho_crit을 그대로 capacity로 읽는 가정부터 분리해야 한다. 기존 실제 합류/방출·램프 대기 보존과 물리적 용량 근거가 필요하다.

추가 근거: fd_capacity_countercheck.json. 후보 fitting·운영 모델 변경은 없고, verification.json에서 기존15개 진단 함수 AST 불변과 출처 핀을 확인했다.
