# 중간 native 신호 앞 재고의 준비 큐 배정 수정

**기존 코드 두 함수에 범위를 제한한 수정을 적용하고450초 예측4회·검사28개를 마쳤다.** SC15 앞 차량을 SC101 녹색으로 즉시 방출할 수 있는 큐에서 제외하고 같은 SC1_to_SC101 저류로 보존한다. 운영 설정에는 아직 채택하지 않았고 전체 목표는 ACTIVE / NOT_QUALIFIED다.

## 수정 범위

기존 `head_lane_contract`에1210008501 한 도로의 upstream stopline 증거를 추가했다. 선택망 해시, 실제 SC15 SG3/SG8 head 전체, active FIXEDTIME 신호, SC101 canonical 접근1220011503의 movement와 origin을 확인한다. 같은 신호의 실제 정지선을 upstream으로 주장하거나 기존 origin을 다른 저류로 바꾸면 실패한다.

`observation_projection.configure_head_queue_lanes`에서 증거를 설치하고, 기존 어댑터의 `build_local_observation_summary`가 이를 소비한다. 등록된 도로는 차량 전량을 기존 저류에 배정한다. 동일 차량을 준비 큐에도 중복 배정하지 않으며 수용공간이 부족해 관측 차량이 잘릴 경우 실패한다. 새 제어주체·서비스율·FD·목적지 비율·신호·수요는 만들거나 바꾸지 않았다. 별도 어댑터 복제도 없다. 미설정 상태와 기존 canonical head 지원은 유지된다.

**숫자가 가까워진 것만으로 도착 모형이 맞아졌다고 판정하지 않는다.** 새로 저류에 옮긴15대는 여전히 기존 정지 잔차105초 지연에 따라3705초에 예약된다. 실제 upstream3대의 좌회전 통과는3660.81/3663.21/3665.19초였다. 따라서 이번 감소3대는 잔여 이동/목적지 오차와 일부 상쇄될 수 있다. 모델의 즉시 서비스 가능성은 바로잡았지만 native 중간 신호와 물리 이동 시간을 반영하는 도착 예약은 아직 미완료다. 그 시간을 미래 MER로 강제하지 않는다. 상세는 `timing_limit.json`이다.

같은 명령450초 모델 Ω TTT는2250초486.730749로 동일,3600초517.730137→517.944434대·시간이다. 이는 **모델 변경에 따른 비용 차이**이며 제어 손익이나 실제450초 오차라고 해석하지 않는다.

## 독립 RM 반응

이미 검토한 seed47 공통2700초 상태에서10484 녹색2초 유지와4→6→8초 완화를 기존 명령표대로 각각450초 예측했다. 도시 신호·VSL은 고정이다. 새로운 blind holdout이라고 부르지 않는다.

- 완화−유지 Ω ΔTTT: 실제+2.053833,수정 전/후 모두+1.644970대·시간.
- 동측 본선 ΔTTT: 실제+4.869944,전/후 모두+4.807361. 램프 대기 감소를 포함한 기존 성분도 같다.
- 두 조건 각각의8개 램프 결과가 수정 전과 정확히 같다. 큰 RM 유지 이득의 방향은 보존했으나 더 정확해진 것은 아니다.
- native 외부 체류 Δ−0.498611/모델−0.000434의 기존 차이도 남아 있다.

이 네 예측은 새로운 SDMPC 선택·미분·N_P/N_UF·VSL 효과의 검증이 아니다. 아직 원래 네 정책의 전체9000초 반응을 재현했다고 선언하지 않는다.

## 검사·실행 기록

새 회귀검사8개,기존 head queue17개,origin projection3개로28개 통과. 수정 전에는7개 중5실패·1오류·1통과로 결함을 재현했다. 중간에는 진단 키를 잘못된 하위dict에 기록한 테스트 오류를 고쳐 재검사했다. 최종 보호검사 첫 시도에서는 뺄셈 순서에 따른7.1e−15대 차이를 exact equality로 검사해 실패했다.1e−10대 절대허용오차로 검사만 고쳤으며 예측 재실행은 없었다. 실패 사유를 `protocol.json`, `final_guard_failure_v1.json`에 보존했다.

기존 core 두 파일에서 변경 함수는각1개이고 다른280함수 AST는 같았다.105개 보호 파일에서 의도한 두 파일 외 망·설정·기존STOP·소스는 그대로다. 파라미터 검사 PASS(기존 calibration override 경고 유지). 네 예측 계산 합146.474초이며 초기화·I/O·전체 작업시간을 포함하지 않는다. 최적화0·계수fit0·새VISSIM0·FZP0·현재런조회0·push0. 세션37211/93909/10846은 모두exit0으로 종료했다.

다음에는 이 upstream 재고의 도착 예약을 native 고정신호와 기존 물리 경로로 제한하되, 분기 목적지 불확실성을 유지해야 한다. 동시에 **이번 수정만으로10484 합류나 RM 이득 예측이 개선된 것은 아니라는 결과**를 유지한다. 실제 합류가 크게 달라지는 단순 정책 자료의 방출·회복·전체 비용 검증을 도시 큐 오차 감소로 대신하지 않는다.
