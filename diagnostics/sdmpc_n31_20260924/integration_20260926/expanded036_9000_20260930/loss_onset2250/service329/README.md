# 329 직진 head 방출률의 movement 귀속 진단

이전 목표 턴은 차로 큐 귀속 후보 검증으로 progress였다. 이번에도 완료 자료와 정본 코드에서 원인을 확인하고 기존 head-resource 경로의 선택적 후보를 검증했다. **Goal ACTIVE / NOT_QUALIFIED.** 현재 CTG를 조회·변경하지 않았고, 새 VISSIM/FZP 스캔/계수 탐색/push는 없다.

## 확인된 배정 오류

329번 SC1002 SG6에는2·3차로 head만 있다. 직진 connector10691도2·3차로다. 우회전10692는 신호 head가 없는 별도1차로다. 그런데 기존 lane-group 분배는 같은p3에 속한 두 movement의 beta5:1로 SG6의 관측 방출률을 나눴다.

-2250초 이전2100–2250 창: 직진 두 head의 통과19+21대, 녹색66초. 관측 방출률 합은2181.818대/h. 직전 창2193.75와의 최소값 및 과거 하한을 사용하는 기존 규칙으로2181.818이 지지된다.
-기존 직진 배정은2181.818×5/6=1818.182대/h. 별도 우회전이 나머지363.636을 가져갔다.
-3600초에는 과거 지지 하한2571.429 중 직진2142.857만 배정됐다.

이 값들은 관측된 **녹색 평균 방출 하한**이다. 포화 방출능력이 식별됐다는 뜻이 아니다. 해당 코드도 lower bound로 명시한다.

## 기존 정본 경로의 제한적 수정

`head_service_resources.configure`에 검증된10691을v7 계약으로 추가했다. 새 adapter/실행 경로를 만들지 않았다. 기존 observer·2개 과거 창 지지 규칙·finalize·공유 수용 계산은 그대로다. native head/차로/connector/목적 storage, 검증된 canonical movement 및 정적 경로1113:1/2, 다른 차로의 우회전을 고정 자료로 대조한다. 우회전 경로는 상류321부터 이어지므로 기존 validator가 선언된 전체 경로와 마지막 물리 triplet을 모두 확인하도록 보완했다. 기존v6의 짧은 경로 검증은 그대로 유지했다.

관측2181.818/2571.429를 직진에 연결한다. 우회전은 더 이상 직진 관측을 받지 않고 기존 독립 사전값206.531대/h로 돌아간다. 따라서 **직진·우회전 두 서비스값이 바뀐다**. 우회전의 실제 서비스 자체가 이번에 보정/검증됐다는 뜻은 아니다.

기본 튜닝c4ab는 그대로다. `candidate_config.json`만 직전 차로 큐 후보에서 head 계약 경로 하나를 바꿨다. production에는 채택하지 않았다.

## 녹색 전체 평균과 대기 차량의 방출 간격은 다르다

저장된 MER와150초 시작 차량 관측으로, 시작 때329의 같은 차로에 정지해 있던 차량들이 같은 녹색에서 연속 통과한 쌍만 추렸다. 다른 차량이 사이에 있거나 녹색이 끊기면 그 쌍은 제외했다. 추가 FZP는 읽지 않았다.
