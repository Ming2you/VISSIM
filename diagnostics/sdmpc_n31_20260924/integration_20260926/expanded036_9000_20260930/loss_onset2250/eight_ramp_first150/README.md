## 수용 차로를 확인해야 하는 이유

정본 INPX(64cf…)의10490은 **119번 링크1차로**로 합류한다.2250초 바로 상류 셀20의 전체 평균은 밀도63.34대/km/차로·속도26.35km/h지만,1차로는115.02대/km·8.70km/h이고13대가5km/h 미만이다.2·3차로 속도는52.71·54.47이다. 셀21·22도 차로별 차이가 있다. 자료는 `merge_lane_10490.csv/json`에 보존했다.

현 gap 계산은 명시적 차로 plant가 없으면 상류 셀 평균 밀도×속도로 충돌유량을 계산한다. **혼잡으로 충돌유량이 낮아지면 gap 기회는 오히려 늘 수 있다.** 따라서1차로 유량만 대입하는 것도 충분한 해결책이 아니며, 현재 수용 차로의 재고·유출과 결합된 수용 제약을 검토해야 한다. 단면 스냅샷만으로 그 식·계수가 식별됐다고 주장하지 않는다.
