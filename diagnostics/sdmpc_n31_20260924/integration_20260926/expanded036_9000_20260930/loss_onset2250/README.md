# 손실 확대 직전 2250초: 10484 RM 반응과 도착·합류 오차

완료된 expanded036 seed29 9000초 런을 사용했다. 현재 CTG 런은 조회하거나 변경하지 않았다. [앞선 시간·공간 손실 진단](../loss_diagnosis/README.md)의 후속으로, 10484의 물리 반응만 3회·450초 예측했다. 계수·목적함수·제약은 바꾸지 않았다.

**주요 발견: RM을 줄여도 모델의 합류량이 거의 달라지지 않는 동시에, 같은 명령의 첫 150초에서도 모델이 램프를 실제보다 빨리 비웠다.** 따라서 이번 결과만으로 실제 RM이 효과 없다고 판단하면 안 된다. 도시에서 램프까지의 도착 시각과 램프 내부 통행·합류를 먼저 분리해야 한다.

## 1. 왜 2250초인가

이전 런은 Ω 누적 이득이 2265.1초에 최대 -21.37대·시간이고 3325.1초에 누적 손해로 전환했다. 동측 본선 추가 재고는 이미 1800초 +53대, 2100초 +85대로 먼저 나타났다. 최종 동측 +401.89대·시간이 다른 Ω 영역의 이득을 상쇄해 전체 +326.71대·시간(+4.498%) 손실이 됐다.

2250–3300초에는 10484 합류 재구성값이 NC 161→제어 236대로 늘고, 10481 분기 이후 본선 통과는1907→1630대로 줄었다. 도시 신호·VSL·상태 이력이 함께 달라진 관측이므로 +75대 합류가 방출 감소 전부의 원인이라고 단정하지 않는다.

## 2. 물리 RM 후보 3개만 비교

2250초 관측과 그 이전 head·VSL 이력으로 초기화했다. 도시 신호·VSL·다른 미터는 실제 보유 명령으로 고정했다. 녹색은 10초 주기이며 각 150초 구간 간 변경은 최대 2초다.

| 10484 녹색 [초] | 450초 합류 [대] | 종료 램프 재고 [대] | 동측 본선 ΔTTT | 10484 ΔTTT | Ω ΔTTT [대·시간] |
|---|---:|---:|---:|---:|---:|
| 10 / 10 / 10 | 83.2038 | 3.0840 | 0 | 0 | 0 |
| 8 / 8 / 8 | 83.2038 | 3.0840 | -0.01814 | +0.00888 | -0.00815 |
| 8 / 6 / 4 | 81.8801 | 4.4078 | -0.09737 | +0.06483 | **-0.02731** |

Δ=후보−10초 유지. 음수 TTT가 이득이다. Ω 기준 TTT는485.1720대·시간이라 가장 큰 개선도 약0.0056%다. 외부 체류 차이는 최대+0.0000012대·시간이다. 전체 합류량이 같아도 시간별 방출은 달라질 수 있으므로 flat8의 작은 TTT 차이는 모순이 아니다.

후보는 기존 물리 실행 모델과 액추에이터·주기간 변경 검사를 통과했다. **N_P/N_UF 제약과 SDMPC 선택은 이번에 평가하지 않았다.** 최적해·전체 제약 만족·실제 VISSIM 이득의 증거가 아니다.

모델상 g10/g9는1512, g8은1440, g6은1080, g4는720대/h의 주기 평균 서비스다. g4도150초에30대를 서비스할 수 있는데, 마지막150초의 예측 도착은20.04대다. 초기 재고가 이미 거의 배수되어 후반 제한의 합류 영향이 작아진다. 이는 이번 상태와 모델의 설명이며 실제 수요가 적다는 일반 결론이 아니다.

## 3. 같은 초기 상태·실제 명령의 첫150초 검증

2250초 action JSON의 모든 green·offset·VSL이 보유 명령과 정확히 일치했다. writer CSV의17개 신호, 66개 DSD, 8개 RM 녹색도 일치했다. 실제 실행은 앞선 전체 런의 native LDP/VSL readback 검증을 재사용했다. 첫150초만 동일 명령의 검증으로 취급한다. 이후2400·2550초 실제 도시 명령은 바뀌므로 고정 명령450초 예측과 전체450초 실측을 직접 비교하지 않는다.

| 2250–2400초 10484 | 모델 | 실제 |
|---|---:|---:|
| 시작 커넥터 재고 [대] | 22 | 22 |
| 램프 입구 도착 [대] | 23.9042 | 27 |
| 미터 신호등 통과 [대] | 34.9516 | 29 |
| 본선 합류 [대] | 43.2458 | 36 |
| 종료 커넥터 재고 [대] | **2.6584** | **13** |

커넥터 재고에는 주행 중 차량도 포함하므로 전부 정지 대기열은 아니다. 실제 합류는 ‘시작 총재고+도착−종료 총재고’와 ‘head 통과+시작 post-head 재고−종료 post-head 재고’ 두 보존 재구성이36대로 일치했다. 앞선 진단에서 해당 커넥터 삭제 없음도 확인했다. 직접 합류 단면의 차량별 계측이라고 표현하지 않는다.

종료 재고 오차 -10.3416대 = 도착 오차 -3.0958대 − 합류 오차 +7.2458대다. 차량 보존 자체는 맞지만 실제보다 이른 도착·방출 예측으로 재고가 잘못 배치된다.

## 4. 총 도착량 외에 도착 시각도 어긋난다

완료 런의 기존 `obs150/mer_002400.jsonl` 573KB만 읽었다. state에 저장된 SHA256과 일치하고, entry 행만 센27대 도착/29대 head 통과가 기존150초 누적 검지 집계와 일치한다. 새 FZP 스캔은 없다.

모델 흐름은1초 적분 구간 시작시각으로, 실제는 검지 entry 시각으로30초 묶었다. 해당 창에서는 모델이 도착을 앞쪽에 집중시키고 뒤쪽 도착을 적게 예측한다. 다만 이 패턴만으로 모든 도착 차량의 이동시간이 동일하게 짧다고 결론 내릴 수는 없다. 상류 신호 방출·목적지 배분·초기 이동 차량의 도착시각을 분리해야 한다.

램프 모델은 초기 실제 위치를 사용하지만 초기 속도를 이후 이동시간에 직접 외삽하지 않고 공급된 평균속도48.77km/h로 이동한다. 초기 post-head9대 중 합류부 근처에는2.6–19.7km/h 차량도 있다. 이는 내부 체류를 짧게 예측할 후보 원인이지, 계수를 바꿔 원인이 입증된 상태가 아니다. 실제 수용 제약도 함께 작동하므로 평균속도만 수정하는 처방을 채택하지 않았다.

## 5. 다음 수정 전에 확인할 좁은 범위

1. SC1001에서 링크31을 거쳐10484로 들어오는 흐름의 **상류 방출·이동시간·목적지 배분** 중 도착 시각 오차가 생기는 위치를 기존 기록으로 확인한다.
2. 동일한 도착 조건에서 **신호등 이후 이동·합류 수용**이 재고를 너무 빨리 배수하는지 분리한다. 실측 미래 도착을 입력하는 시험은 조건부 원인 진단으로만 표시하고 자율 예측 검증에 합치지 않는다.
3. 근거가 생긴 한 부분만 수정하고, 같은 첫150초와 다른 상태의 RM 유지/완화 비교를 재검증한다. 이 약한0.027대·시간 이득을 키우기 위한 계수 탐색은 하지 않는다.

이번3개 모델 후보로 이전9000초 손실의 RM·VSL·도시 신호 인과 기여를 분리한 것은 아니다. 다만 ‘미터 후보를 더 찾으면 된다’에 앞서 **모델이 실제 램프 축적을 놓치는 지점**을 확인했다.
