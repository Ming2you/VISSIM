# 24·25셀 제한 보정 — 두 후보 모두 정본 미채택

2026-10-01. **FD 후보는 회복 구간의 재고·유출 오차를 줄였지만, 이미 과속 예측하던23셀을 더 빠르게 만들었다. 독립 RM 비교에서도 손해 크기를 더 과소예측해 정본에 채택하지 않는다.** 두 후보의 물리 선별 탈락은 유지했다. 이후 작은 속도 오차만으로 제어 후보를 버리지 않는다는 사용자 기준에 따라, FD 후보만 고정한 별도 제어 반응 진단2회를 명시적으로 추가했다. 선별 기준을 소급 변경한 것은 아니다.

## 변경과 예산

기준은 posthead_clock10490 후보이며 생산 expanded036 설정을 덮어쓰지 않았다. 두 후보 모두 물리 셀24·25(0기준)에만 같은 배율을 적용했다.

- fd125: 기존 FD의 rho_crit만1.25배. a, 자유속도, 합류항, 도시·수요·명령은 유지.
- relax200: 기존 가속/감속 이완시간을2배, 두 anticipation 계수도2배로 두어 nu/tau를 유지. 목표속도와 대류식은 유지하고 이완항만 약하게 만든다. 과거 tau24 후보는 압력항까지 변했으므로 같은 비교가 아니다.

각 후보를2250초와3600초 상태에서450초씩, 총4회 실행했다. 실제 명령과 비교하는 범위는 첫150초다. 추가 그리드나 합성 후보는 없다. 속도 일치나 제어 순이득 부호로 계수를 연속 최적화하지 않았다.

실효 임계밀도에는 기존 동측 component multiplier1.4도 적용된다. 실제 식에서24셀31.079→38.849,25셀47.807→59.759대/km/차로를 확인했다. JSON 값만 보고 적용됐다고 판단하지 않았다. relax200의 첫 상태에서 목표속도 동일, tau2배, nu/tau 동일도 확인했다.

재고 오차는24·25 두 셀의 종료 절대오차 합, 유출 오차는25셀 하류의 누적 통과 절대오차다. 단위는 차량이다.

하지만3750초23셀 속도는 실측31.45km/h에 대해 기준43.58,FD47.08,이완46.05다. 이미 존재하던 과도한 회복을3.49/2.46km/h 더 키웠다. FD의24셀 속도는48.70→55.80으로 좋아졌지만 실측72.62까지는 여전히 차이가 크다.

사전에 정한 조건은 두 상태의 재고·유출이 각각 악화하지 않을 것,전체31셀 재고 L1 악화5% 이내,23셀 속도 절대오차 증가2km/h 이내,평균 점수20% 이상 감소였다. FD는23셀 조건에서,이완은 복수 조건에서 탈락했다. 결과를 본 뒤 허용오차를 늘리지 않았다. 이들은 **이번 물리 선별 기준**이며,2km/h 차이가 실제 제어 손익의 실패를 증명한다는 의미는 아니다.

## 해석과 다음 판단

24·25를 더 잘 비우면 하류 상태와 수용 공간이 바뀌며23셀도 달라진다. 셀별 계수를 분리해도 반응이 독립적이지 않다. 동시에 본선 원점 입력 예측 오차가 따로 존재하므로 모든 재고 오류를 FD 계수로 흡수하지 않는다.

현재 결과는 ‘METANET으로 불가능하다’는 증거가 아니다. 다만 단순 회복 가속 또는 한정된 FD 상향만으로 제어 이득까지 해결됐다고 주장할 근거는 없다. 추가 배율 탐색은 여기서 종료한다. 독립 RM/VSL의 큰 손익 방향이 더 중요한 최종 기준이라는 원칙은 유지한다. 향후 이 기각 후보의 제어 반응을 원인 진단으로 시험한다면, 이번 물리 기준 통과나 정본 채택으로 바꾸어 부르지 않아야 한다.

## 추가 독립 RM 반응 진단

물리 선별 판정과 별도로 response_diagnostic_protocol.json을 먼저 기록한 뒤 seed47의 공통2700초 상태에서10484 녹색2/2/2초 유지와4/6/8초 완화를450초씩 예측했다. 계수는 추가 조정하지 않았다. 실제 실행 명령을 조건으로 삼았고 미래 교통 관측은 입력하지 않았다.

RM을 완화하면 램프 대기는 줄지만 전체 손해가 커져 유지가 낫다는 **큰 순위는 유지**한다. 그러나 Ω 비용차 오차는0.67029→1.03484로 늘었다. 회복 구간 절대 오차가 나아진 것과 제어 이득 예측 개선은 별개라는 실제 비교다. 작은 속도 오차나 단일 실패 항목만으로 후보의 일반적 무효를 주장하지 않지만, 이번 보정을 정본으로 바꿀 추가 근거는 없다.

원본 native 실행 receipt는 출력 폴더와 바뀐 config pin을 제외한 모든 내용이 정확히 같았다. 제외한 두 값도 각각 폴더 소유 범위와 파일 hash를 확인했다. 최초 전체 receipt 동일성 검사 실패와 수정 근거를 보존했다. 공통 상태·명령·writer·8램프 보존 통과. VSL 반응이나 SDMPC 최적화 선택 검증은 아니다.

## 검증과 실행

- 공통 초기31셀 상태·명령·writer 제약·8램프 보존 통과. 재구성한 본선 말단 유출과 모델 기록도 일치. 원점 유입은 기준과 동일.
