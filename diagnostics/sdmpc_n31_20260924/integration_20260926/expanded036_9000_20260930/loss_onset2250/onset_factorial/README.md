## 6. 원래 9000초 실행의 RM 미분 경로 확인

2026-10-01 추가 확인. 위 네 조건의 native 큐가 실행되는 동안 **원래2250초 결정과 동결 코드·설정만 읽었다.** 새 예측·보정·최적화·native 실행은 없다. 추출과 SHA256은 `rm_gradient_path2250.json`에 보존했다.

**정정:** 최초 작성과 채팅에서 외부 actuation 설정표를 최종 적용값으로 잘못 판단했다. 그 표의10484는 g10=1512.0, g9=1328.4, g8=1166.4대/h지만, 실제로는 `lane_plant_runtime.configure_runtime`이 manifest에 고정된 reference config의 보정곡선으로 덮어쓴다. 원래 동결 실행본의 manifest→`expanded_joint/eval_036/reference_config.json`(SHA7f6df2d…)→`CanonicalFreewayModel`→runtime override를 확인했다. **최종10484 값은 g10=g9=1512.0, g8=1440.0대/h다.** 다른 동측3램프도 g9=g10이다. 최초 오류는 `rm_gradient_path2250.retracted.json`에 철회 표시와 함께 보존했고, 현재 `rm_gradient_path2250.json`은 선언값·실효값을 구분한다.

저장된2250초 AD 결과에서는 동측4램프×3블록의 **12개 축 모두 비용·N_P/N_UF 및5,106개 저장 물리 제약값에 대한 미분이 전부0**이다. 서측 일부 RM 축은0이 아니므로 모든 RM의 미분이 통째로 끊어진 결과는 아니다. 최종 보정표를 보간하는 `sdmpc_continuous.meter_rate`의 g10 왼쪽 기울기부터0이다. 따라서 이 국소 미분에서는 하류 수용 제약에 도달하기 전부터 RM 민감도가 사라질 수 있다. 이것은 실제 RED/GREEN 유한 명령 변경도 무효라는 뜻이 아니다. 기울기를 만들 목적으로 보정표를 임의 변경하는 처방은 하지 않는다.

동결 코드에는 `meter_activation_axes`가 이미 있었지만 당시 정책에는 `meter_activation_secant`가 지정되지 않아 호출되지 않았다. 세 블록의10484 허용 녹색은 각각[8,9,10], [6…10], [4…10]이었고 `stencil=None`으로 기록됐다. 따라서 이미 존재하는 보완을 다시 만드는 대신, native 비교 후 효과가 충분한 상태에서 이 경로의 유한 명령 검사와 실제 실행 모델 검증을 확인하는 것이 다음 단계다. 옵션을 켜는 것만으로 물리 예측 오차가 해결되거나 native 이득이 입증되는 것은 아니다.

이 기록은 **원래9000초 당시 연속 대리모델**의 근거다. 앞 절의 수정 후 물리 모델450초 값과 같은 모델이라고 취급하지 않는다. 현재 진행 중인 네 조건 native 결과가 나오기 전에는 RM 무효·보정 성공·탐색만의 문제를 결론 내리지 않는다.

## 7. 저장된 물리 예측에서 유한 RM 효과가 작은 이유

현재 수정 후 모델의 유지/RM 두450초 추적파일(각약90KB)을 읽었다.900개1초 기록 모두 합류량이 저장된 재고·준비 차량·정본 수용·물리 수용 상한의 최소값과 일치했다. 새 rollout이나 FZP 읽기는 없다. `rm_gate_trace2250.json`에 합계·활성 제한·출처를 보존했다.
