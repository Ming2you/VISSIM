목적식은 `J = TTT_Ω − β D_Ω`다. 도시부 초기 고정ETA 이동 일부는 실제 링크와 집계 storage의 연결이 불완전하다. 이를 임의 경로로 메우지 않고 현재 수송법에서 후보 명령과 무관한 초기 이동분 `C(x0)`만 공통 상수로 분리한다. 구현 점수는 `J_shifted = TTT_Ω − β(D_Ω − C) = J + βC`이므로 **동일 초기 상태 후보 간 비용 차이·순위·기울기는 같다**. 서로 다른 상태의 shifted 거리를 절대 주행거리처럼 비교할 수 없다.
