# 혼잡 후 첫 램프군의 150초 응답 — 2026-09-30

현재 동결된 expanded036이 **첫 램프군에서는 너무 빨리 회복하고, 뒤쪽 회복 셀24·25에서는 너무 느리게 회복하는 오차**를 동시에 보인다. 전 구간 anticipation/회복을 한 방향으로 조정할 근거가 아니다. 첫 램프군의 회복 방향 anticipation을 낮춘 한 후보도 병목 셀9·10을 악화시켜 미채택했다.

## 완료 범위

- 먼저 저장된 2100→3900초의 12개 150초 예측을 실제31셀 프레임과 대조했다. 원래 `state.freeway_segments`의21셀 집계는 사용하지 않았다. 근거: [12개 기존 예측](one_step_physical_3900.json).
- 3600→3750, 3750→3900 두 구간을 현재 상태·이미 작성된 실제 명령·과거 head/VSL 이력으로 재생했다. **두 기준 예측의 저장 raw state_summary 전체가 정확히 일치(max error0)** 했다.
- 기준2회 + 단일 계수 후보2회 = 새150초 예측4회. 각 예측의 동측31셀×150개 속도 갱신과 실제 받아들인 유량을 기록했다. 450초 이득/순위 검증이나 독립seed 검증을 대신하지 않는다.
- 모델·native 입력과 기존 STOP 해시 유지. 기준 핵심 코드5개는 실행 중인 frozen 파일과 일치했다. 새 VISSIM 런·FZP 스캔·추가push 없음.
- native R2는 별도로 계속 실행 중이며, 이 오프라인 후보를 적용하지 않았다.

기준 예측에서 셀9의 평균 1초 속도 갱신 기여는:
- 3600 시작: relaxation −0.805, convection −0.044, anticipation +0.926km/h.
- 3750 시작: relaxation −0.829, convection −0.051, anticipation +0.972km/h.

## 4. 한 후보의 결과와 판정

가설 검사용으로 셀6·7·8·9의 `downstream_lt_local` anticipation만 공통0.5배로 조정했다. 각 시점의 예측 밀도 관계로 해당 항을 선택하며 seed·시각·제어별 보너스가 아니다. 계수 재최적화·추가 후보 sweep은 하지 않았다.
