# 10484: 저속 합류 공간의 해소 시간 보정 시험

2026-10-01. **초기 정체의 과대 합류는 크게 줄었으나, 독립seed47의 RM 손익 오차가 커져 정본에 채택하지 않았다.** 새로운 계수 fitting이나 native 런 없이4회450초 자율 예측을 완료했다. 기존4개 기준 예측을 재사용했다. 현재 실행 중인 런은 조회하지 않았다.

## 출발 가속만 빠진 것인가

아니다. 기존 모델의 국소1초 루프에는 실제 녹색·적색 구간이 이미 들어 있다. 신호등 뒤164.800m를 명목67.97km/h로 이동시키는 기본 가정은 있으나, 신호 pulse를 통째로 누락한 것은 아니다.

통과속도에서0.1km/h를 빼고, 그 속도를 유지했을 때의 이동시간에 추가1초를 허용해도, 완료 차량35대 중25대의 실제 이동시간 하한이 더 길었다. 이후 비교 창은23대 중5대였다. 완료하지 않은10대는 이 비율에서 제외했다. head부터 합류까지의 실제 시간은5초 FZP로 구간을 잡았으며, 정확한 단일 시각으로 보간하지 않았다.

실제 head 시각·속도까지 준 조건부 buffer 재생에서도 초기 합류는 명목속도43.899→head 속도 유지41.343대였고 실측34대와 차이가 남았다. 따라서 출발 가속 보정만으로 지연 전체를 설명할 근거는 없다. 다음 창은 둘 다23대로 실측과 같았다. 이 재생은 미래 실측과 고정된 모델 수용 예산을 사용하는 원인 분리이며 자율 예측이나 TTT 검증이 아니다.

MER의 front 통과시각·차량번호·속도 필드 해석은 [PTV Vissim2020 공식 설명](https://cgi.ptvgroup.com/vision-help/VISSIM_2020_ENG/Content/11_Auswertungen/AuswertungQuerschnittsmessungen.htm)을 확인했다. 결과·출처는 `../local10484/head_speed_diagnostic.json`에 있다.

## 시험한 가설 하나

현재 gap 식은 본선의 `rho*v`가 작아지면 기회를 크게 계산할 수 있지만, 저속 차량이 접속 공간을 비우는 시간은 고정돼 있다. 다음은 이 시간의 증가만 반영한 **가설**이며 검증된 합류 법칙이나 문헌의 정확한 식이라고 주장하지 않는다.

```
v_lane(t) = 현재 관측의 lane1/셀23 속도 비율 × 예측 셀23 속도
추가시간 = max(0, 6m × 3.6 × (1/v_lane − 1/67.97km/h))
수용 후보 = 기존 gap(q, critical=2초+추가시간, followup=1.5초+추가시간)
v_lane=0이면 수용 후보=0
```

6m는 기존 저장 간격,67.97km/h는 기존 posthead 명목속도다. 새 계수는 맞추지 않았다. 초기 속도 비율은1500초0.4636,3600초0.9166,seed47의2700초0.7542다. 이 비율을450초 유지한다는 가정도 검증 대상이다.10484에만 적용했고 posthead 이동식·METANET 계수·도시 도착식·공유 수용량·목적함수·명령·제약은 바꾸지 않았다. 실제 미래 속도나 특정 RM/VSL 명령의 보너스는 없다.

## 후속 원인 분리: 충돌 유량이 접속 차로를 대표하는가

이전 절은 속도만 실측으로 바꾸고 충돌 유량은 모델 값에 둔 검사였다. 새 검사에서는 **접속1차로와 본선3차로 평균을 혼동한 입력의 영향**이 확인됐다. 이것은 기존 후보의 자율 예측 실패를 면제하거나 정본으로 승격한 결과가 아니다.

기존 캐시의4개 창만 다시 읽었다. 접속점은 INPX10484→24의165.698395m이며, 실제 차량번호를 연속5초 프레임 사이에서 따라갔다. 원래1500.1–1650.1초의 램프→본선 전환34대,3600.1–3750.1초23대가 기존 경계 원장과 일치했다. seed47에서는2700.1–3145.1초에 유지45대/완화96대를 확인했다. 마지막5초가 없는 이 캐시의96대를 기존450초97대와 모순이라고 해석하지 않는다. 총238개5초 간격에서 램프 재고 원장이 닫히고, 사라진 램프 차량이 어디로 갔는지 미확인인 사례는0개였다.

접속점 상류/뒤6m/그 뒤 셀23/다음75m의1차로 속도 표본 중앙값은 원래 초기 상태에서12.02/11.75/37.13/64.99km/h,독립 RM 완화 상태에서15.48/14.41/38.48/62.72km/h였다. 따라서 직후6m 자체도 느리다. 단지 '접속부는 빠른데 상류를 평균해서 낮아졌다'만으로 설명할 수 없다. 공간별 표본 중앙값이며 동일 차량의 가속 궤적으로 해석하지 않는다.

순간 점유도 통과 불능과 같지 않다. 초기 창에서 접속점을 차체가 덮고 램프 posthead가 있던22개 표본 중19개는 다음5초에 램프 합류가 있었다. 독립 완화에서는40개 중30개였다. 같은 시각의 차체 중첩을 뜻하지 않으며,5초 사이 공간이 비고 다시 채워질 수 있다는 관측이다. 램프 맨 앞 차량의5초 실제 이동거리도 정지에 가까운 표본에서 초기 중앙값12.75m/독립 완화16.39m였다. 순간 저속이나 점유율만으로 긴 수용 중단을 강제할 근거는 부족하다.

본선 차량의 접속점 통과를 따로 세면, 독립 완화의1차로 양끝 일치 차량은143대/445초(약1157대/h),1차로 관련 차로 변경은21대였다. 같은 지점의 본선 전체 통과718대를3차로로 평균하면약1936대/h다. 모델 충돌 유량 평균약1959대/h와는 전체 평균 쪽이 가깝다. 현재 gap 계산은 본선 평균을 사용하는데 실제 접속은1차로에 있다.5초 사이 정확한 차로 변경 시각은 모르므로, 양끝1차로와 변경 차량 포함의 두 분류는 엄밀한 상·하한이라고 주장하지 않는다.

## 후속 자율 예측: 합류량에 반응하는 최소 유량 분배 후보

미래 실측을 입력하지 않는 다음 후보를 기존 진단 runner의 `--allocation84` 모드로 실행했다. 새 계수 fitting은 없으며, **초기 오차 검사·저대기 검사·독립 RM 손익 검사까지 통과했다.** VSL/병행 제어·SDMPC·전체 목표는 아직 미검증이라 생산 설정에 채택하지 않았다. 자료는 형제 `../allocation84/`에 보존했다.

```
q1 = max(0, q_mean − (1−1/λ) × r_previous)
q_other = (λ × q_mean − q1)/(λ−1)
```

q_mean은 기존 상류 셀의 차로당 rho×v,λ는 실제3차로다. r_previous는 첫 step에서는 직전150초 실제 head 통과와 posthead 재고 차이로 복원한 합류율, 이후에는 직전1초 **모델의 실제 수락 합류량**이다. 따라서 합류를 시도했다는 이유만으로 유량을 빼지 않는다. 첫 step에 예측 미래를 쓰지 않았고 이후에는 예측 상태만 사용했다. 이 q1을 기존 추가 gap 후보의 충돌 유량으로 사용했다. 현재 관측 차로속도 비율과 예측 셀 속도를 결합한 기존 clearance 부분은 그대로다.

이 식은 합류 후 차로별 총 방출이 같다는 **근사 가정**에서 얻은 유량 proxy 분배다. 차로 재고를 새로 보존·예측하는 모델이라고 주장하지 않는다. 합산한 본선 유량 proxy는 기존값과 같고 실제 본선 sending·METANET 속도식·FD·off-ramp 저장·도시 도착식·posthead 이동·액추에이터·목적함수는 변경하지 않았다. 모델이 허용하는 합류는 여전히 차량 수·head 서비스·수용 한계의 제약을 받고 기존 소유 재고에서 차감된다. 이 근사가 다른 VSL/수요 조건에 일반화되는지는 별도 검사 대상이다.
