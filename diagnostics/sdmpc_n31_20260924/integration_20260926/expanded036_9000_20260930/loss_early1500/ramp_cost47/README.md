# 10484 램프 체류 비용 오차: 합류 합계보다 합류 시점

2026-10-01. 완료된 seed47 2700–3150초 RM 유지/완화 자료와 저장된 예측만 사용했다. 이전 seed29 9000초의 손실 원인을 이해하기 위한 독립 반응 진단이며, 이 결과를 9000초 손실의 인과 기여로 환산하지 않는다. Δ는 완화−유지, 시간 비용 단위는 대·시간이다.

**10484 비용 오차의 주된 부분은 신호등 뒤에서 본선 합류까지 기다리는 시간을 모델이 적게 계산하는 데 있었다.** 실제 도착량 차이도 있지만, 그 차이만으로 설명되지 않는다. 실제 접속 차로 상태를 넣은 조건부 검사는 합류 대수와 대기 비용을 함께 개선했다. 미래 실측을 사용했으므로 정본에는 채택하지 않았다.

## 2. 10484의 시간 회계를 분해했다

보존식에서 체류시간은 초기 재고의 체류 + 도착의 남은 시간 가중합 − 합류의 남은 시간 가중합이다. 신호등 통과는 커넥터 전체 체류에서는 내부 이동이지만, 전후 체류를 나누는 데 사용된다.

|---|---:|---:|---:|

회복 후보의 커넥터 전체 오차 −0.525071은 도착 항 −0.094111과 합류 시점 항 −0.430960의 합이다. 같은 오차를 신호등 전후로 나누면 −0.121103과 −0.403968이다. 두 분해는 같은 오차를 다른 기준으로 나눈 것이므로 서로 더하지 않는다. 이는 정확한 부호 있는 회계 분해이며, 각 입력을 독립적으로 바꾼 인과 기여 추정은 아니다.

실제 450초 합류는 유지45대/완화97대다. 기존 모델은 약45.33/95.00대로 합계가 가까워도, 통과 시점 차이 때문에 체류 비용을 틀릴 수 있다.

## 3. 기록 간격으로 설명되는 차이인가

기존 FZP는 2700.1–3145.1초의 90개 표본이고 마지막 4.9초 재고를 유지하여 체류를 계산했다. 표본 구간에서 유지/완화 도착은71/83대, 합류45/96대, 신호등 통과45/100대다. 3150초까지의 전체 계수는 도착72/83대, 합류45/97대, 신호등 통과45/102대다. 서로 다른 범위의 계수를 섞지 않았다.

native MER의 실제 신호등 통과 시각, 5초 FZP의 합류 시각 구간, 3150초 최종 posthead 재고 1/6대를 이용해 체류 가능 범위를 계산했다. 10484에 native 삭제가 없음을 확인하고 초기·최종 재고 보존을 검사했다.

| 신호등 뒤 체류 | 가능한 범위 | 5초 표본 기반 값 |
|---|---:|---:|
| 유지 | 0.107392–0.169892 | 0.133306 |
| 완화 | 0.611225–0.745919 | 0.687361 |

기존 모델 0.145661과 회복 후보 0.150088은 이 범위보다 작다. 따라서 5초 합류 시각 불확실성만으로 오차가 사라지지 않는다. 이 범위는 관측 사건 시각의 정합 범위이며 통계적 신뢰구간은 아니다. 첫 0.1초 모델/관측 시각 차이도 이 크기의 격차를 설명하지 못한다.

## 4. 같은 posthead 계산에 어떤 관측이 필요한가

기존 pure buffer helper로 두 조건×네 방법, 총8회만 재생했다. 새 전망 계산·최적화·계수 탐색은 없다. 모델 입력 재생의 900개 1초 merge/재고 값과 체류 합이 저장 예측에 정확히 일치했다.

| 조건부 입력 | 유지 합류 | 완화 합류 | Δposthead TTT | 실제 대비 오차 |
|---|---:|---:|---:|---:|
| 기존 head·기존 수용 | 45.329 | 95.001 | +0.145661 | −0.408394 |
| 실제 head·기존 수용 | 45.000 | 99.000 | +0.190968 | −0.363088 |
| 실제 head·속도 + 전 차로 평균 유량·공간 해소 시간식 | 45.000 | 75.661 | +1.394230 | +0.840174 |
| 실제 head·속도 + 접속 차로 유량·공간 해소 시간식 | 45.000 | 97.965 | **+0.497232** | **−0.056823** |

실제 head만 넣어도 오차 대부분이 남았다. 마지막 두 방법은 같은 기존 공간 해소 시간식에 충돌 유량만 바꾸므로, 이 비교에서는 전체 차로 평균을 접속 차로 유량으로 쓰는 오류를 분리할 수 있다. 마지막 방법은 합류 대수와 체류 범위 양쪽에 가까웠다.

단, 기존 수용과 마지막 두 방법을 비교하면 식과 상태 입력이 함께 달라진다. 개선 전부를 차로 유량 하나의 효과라고 해석하지 않는다. 접속 차로 계수에는 모호한 차로 변경 사건을 포함했고 이를 수용량 상한으로 주장하지 않는다. 미래 속도·유량·head와 고정된 본선 수용 예산을 사용하여 도시/본선 피드백은 재계산하지 않았다.
