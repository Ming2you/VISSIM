# 이전9000 손해 구간: 셀21–25 속도식 항별 진단

2026-10-01. 진행 중 CTG/VISSIM을 조회하지 않았다. 새 VISSIM 실행, FZP 본문 재스캔, 계수 보정, 운영 설정 변경, push는 없다.

## 어디서 손해가 시작됐는가

기존 `../../loss_diagnosis/README.md`의 결론을 유지한다. 9000초 Ω TTT는 무제어7263.267 → SDMPC7589.973차량·시간으로 **+326.706(+4.498%)**였다. 동측 본선 증가분은+401.888이고, 서측+10.194·나머지Ω−85.375와 합쳐진 값이다.

실측 경로가 먼저 벌어진 구간은 **1500–1650초, 동측 셀21–23**이다. 이150초에 동측 재고 차이는−25→+21대로, 그중 셀21–23의 변화가+41대였다. VSL 최초 하향은1650초다. 따라서 초기 차이를 VSL 단독 효과로 부를 수 없다. 당시 도시 신호와 도착·방출의 차이를 포함한다. 누적 TTT는2265.1초에 최대이득−21.369차량·시간이었다가3325.1초에 손해로 넘어갔다. 공간적 분기 시작과 누적 비용의 부호 전환은 다르다.

이번에는 이 초기 구간의 모델 오차를 확인했다. **정본의1500초 초기 상태·명령을 유지한450초 예측1회**에만 항 기록을 추가했다. 모든 저장된 예측값은 기존 기준과 정확히 같았다(wall time 제외). 첫150초만 실제 향후 명령과 같으므로, 실측 비교도 이 구간에 한정했다.

## 실측 국소 상태를 넣어도 한 가지 계수로 설명되지 않는다

원인을 분리하려고 추가 자율 예측 대신 기존 실측 발췌를 재사용했다. 셀23의 현재 속도·밀도, 상류22의 속도, 하류24의 밀도를 넣고 동일한 계수로 순간 속도 변화율을 계산했다. 실제 다음5초 합류 수도 사용하는 **조건부 진단**이다. 이는 미래 입력 없는 예측 검증이나 인과효과 추정이 아니다.

|상태|실측 평균속도 변화율|식의 순간 변화율|잔차|
|---|---:|---:|---:|
|seed29,1500–1650 혼잡 시작|−0.127|+1.987|+2.115|
|seed47,RM 유지|−0.045|−2.710|−2.664|
|seed47,RM 완화|−0.064|+1.078|+1.142|

단위는km/h/s, 다음 프레임 재고 가중 평균이다. 실측은5초 유한 차분이고 모델은 현재 상태를 고정한 Euler 변화율이다. 차이의 크기를 그대로 계수 보정 목표로 쓰지 않는다. 이 자료는 프로젝트에서 이전에 살펴본 상태이므로 새로운 미사용 검증 표본으로 주장하지 않는다.

혼잡 시작과 RM 완화에서는 가속 편향, RM 유지에서는 감속 편향이다. 특히 현재 merge 식은 다른 조건이 같으면 `q_merge × v/(rho+kappa)`에 비례한다. 이번 조건부 평균 감속은 RM 유지−1.445, RM 완화−0.670으로, 적게 합류하는 유지 상태에서 오히려 크다. 이것만으로 그 식이 틀렸다고 단정할 수 없지만, **merge 계수의 일괄 상향은 원활한 RM 유지 상태를 더 망가뜨릴 수 있다.**

실측 차량ID로 닫은 속도 모멘트 회계도 재사용했다. 혼잡 시작의 잔차+2.115 중 대류 비교 차이는+0.848, 나머지 이완·anticipation·합류 반응 비교 차이는+1.267이었다. 두 항군 모두 관련된다. 기존 상류 경계속도만 교체한 진단이 다른 상태에서 악화했다는 결과도 유지한다. 평균속도 한 값을 보너스로 올리거나 내리는 근거가 아니다.

3600초 자료도 처음 계산했으나, 그때는 해당 VSL이90으로 내려가 있었다. 명령 노출 이력을 제외한 식을 같은 조건의 진단으로 사용할 수 없어 **최종 비교에서 제외**했다. 초기 계산과 소스는 `cross_state_uncapped_late.*`, `cross_assess_uncapped_late.py.txt`에 보존했다. 운영 예측을 재실행하거나 보정하지 않았다.

## 다음 수정의 범위

이번 결과로 받침 없이 gap 계수·merge 계수를 더 키우거나 전체 FD를 다시 맞추지 않는다. 셀23의 지속 저속과 셀24 회복을 함께 설명하는 최소 상태 의존 반응을 검토할 근거가 생겼다. 우선 현재의 순간 합류량에만 비례하는 손실이 원활한 상태에서 과하고, 합류 후에도 남는 국소 제약을 평균 밀도가 놓치는지 분리해야 한다. 속도 모멘트의 양쪽 경계 선택도 함께 고려해야 한다.
