# 10484 합류 전·후 공간 평균의 조건부 반응 검사

2026-10-01. 기존 9000초 손실의 초기 구간과 독립 RM 유지·완화 자료를 재사용했다. **합류부 주변의 속도를 하나 골라 기존 수용식에 넣는 변경은 채택하지 않는다.** 초기 혼잡에서 나아지는 선택이 다른 상태의 실제 합류를 과도하게 막았다.

## 방법과 범위

기존 `loss_early1500/assess.py`의 `local_conflict_flow84`에 선택적 공간 범위 비교만 추가했다. 이미 추출된 5초 차로 자료, 실제 미터 head 통과 시각, 초기 posthead 재고와 기존 수용량으로 신호등 뒤 대기를 재생했다. 원래 164m 셀의 접속 차로, 합류 전 약105m, 합류 직후6m, 그 뒤 셀 끝까지 약53m를 비교했다. 실제 합류점은 셀 끝보다59.3m 상류다.

4개 상태 × 4개 공간 범위 × 2개 유량 집계 = 32회 버퍼 재생이다. 이 중8회는 기존 전체 접속 차로 결과의 재현,24회가 새 공간 민감도다. 계수·경계 최적화는 하지 않았다. 기존 차량 간격6m와 명목 posthead 속도67.97km/h로 속도에 따른 추가 통과 시간을 계산하고, 기존 gap 수용식과 물리적 서비스 상한을 유지했다.

**미래 실측 속도·유량·head 사건을 사용하는 원인 분리용 조건부 계산이다. 자율 plant 예측이나 제어 이득 검증이 아니다.** 두 유량 집계의 범위도 엄밀한 상하한이 아니다. 비어 있는 짧은 공간 표본은 추가 지연0으로 처리한 민감도 조건이며, 자유류 관측값으로 해석하지 않는다.

합류 전 저속으로 전체 속도를 대체하면 초기 합류를 작게 만들지만, 독립 RM 완화에서는 실제97대를84–88대로 과도하게 제한한다. 합류 뒤 회복 속도는 초기 합류를44–45대로 과대 예측한다. 직후6m는 초기와 완화에서 비교적 가깝지만 대기가 적은 상태의23대를18대 안팎으로 막는다. 또한 이6m 공간의 빈 표본 비율은 상태별23.3%,36.7%,83.3%,45.6%여서, 5초 순간 관측의 작은 공간 속도 하나로 처리 능력을 판단하기 어렵다.

이 결과는 공간을 더 잘 나눈 모든 모델이 불가능하다는 증거가 아니다. **기존 gap 수용식에서 속도 입력의 공간 범위만 바꾸는 방법이 여러 상태를 일관되게 개선하지 못했다는 제한된 결론**이다. 기존 전체 접속 차로의 조건부 결과가 가깝다고 이를 자율 예측으로 간주하지 않는다. 정본은 그 차로의 미래 속도·유량을 알지 못한다.
