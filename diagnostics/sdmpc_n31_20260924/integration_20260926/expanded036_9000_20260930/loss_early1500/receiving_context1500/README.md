# 10484 합류 수용: 실제 소비하는 상태와 혼잡 차로를 구분

2026-10-01. 이전 목표 턴은 실제 head 시각 대입으로 남는 posthead 오차를 확인한 PROGRESS였다. 이번에는 원래1500초 상태·명령·모형을 그대로450초 예측 **1회** 재생하면서 실제 합류 수용 계산 경로를 기록했다. 초기화·과거head/VSL 이력은 기존 helper를 사용했고, 현재 별도 CTG 런은 조회하지 않았다. 계수 변경·새 VISSIM·FZP 재스캔·optimizer·push는 없다.

## 실제로 쓰인 수용식

실행 중450개 호출에서 모두 확인했다.

- 31셀 v2 component는 본선 lane-group 동역학을 사용하지 않는다. 바깥 tuning의 옛 선언을 실제 실행으로 오인하지 않았다. 이것은 기존 v2 계약이지 이번에 새로 생긴 설정 오류가 아니다.
- RM_C10484는 본선 셀23으로 들어오지만, gap 식은 **상류 셀22의 전체 차로 평균 `rho×v`**를 conflicting flow로 사용한다. 해당 상류셀의 off-ramp 차감은0이다.
- critical gap2초, followup1.5초인 기존 Poisson 식을 그대로 사용한다. canonical 공급은 이 예측450초 동안1800대/h이며,450초 모두 gap 상한이 더 작다.
- 매초 실제 물리 수용 budget은 `min(canonical 공급,gap 공급)/3600`과1e-8대 이내에서 일치했다. 램프에 도착하는 차량과 merge-eligible 재고는 이후 실제 합류량을 추가 제한한다. 수용 예산을 실제 방출량으로 해석하면 안 된다.

첫150초 gap 수용 예산 합은51.8287대, 실제 모델 합류는45.7592대다. 이미 완료한 [head 시각 조건부 검사](../posthead10484_timing/README.md)에서는 실제45대의 통과 시각을 넣어도43.8987대가 합류해 실측34대를 초과했다.

## 모델 입력 위치와 실제 접속 차로의 차이

아래는 같은 native 순간 관측이다. 밀도는 물리 셀 길이와 차로 수로 계산했다. 셀 번호는0기준이다. native10484의 접속 주소는 `link24 lane1 position165.698395m`다.

| 상태 | 셀·차로 | 차량 수 | 밀도[대/km/차로] | 평균속도[km/h] |
|---|---|---:|---:|---:|
|1500초|상류22·전체|10|20.29|88.70|
|1500초|합류23·전체|19|38.56|50.74|
|1500초|합류23·1차로|9|54.79|23.52|
|1650초|상류22·전체|22|44.64|38.45|
|1650초|합류23·전체|29|58.85|33.04|
|1650초|합류23·1차로|14|85.23|13.10|

1500초 실제 상류22의 평균 밀도·속도는 instrumented 모델이 최초로 소비한 값과 정확히 일치한다. 따라서 최초 입력 전달 오류가 아니라, **어느 공간 상태를 어떤 식으로 수용 가능량으로 바꾸는가**의 문제를 따로 봐야 한다.

같은 gap 식에 native 상류22의 `rho×v`를 넣으면 가상 기회량은1500초1255→1650초1295대/h로 오히려 커진다. 접속1차로 값으로 주소만 바꿔도1516→1614대/h로 증가한다. 정체로 밀도가 커져도 속도가 더 낮아지면 `rho×v`는 줄고, Poisson gap 식은 더 많은 틈을 계산할 수 있기 때문이다.

이는 **수식의 현재 상태 조건부 검사**다. 공간 `rho×v`는 실제 합류 충돌 단면의 시간 유량이 아니며, 여기서 계산한 숫자는 native 용량 추정·물리적 상한·변경된 자율 예측이 아니다. 실제 VISSIM 수용이 반드시 이만큼 감소해야 한다는 수치까지 식별한 것은 아니다.

## 이번 결과가 바꾸는 다음 작업

1. 단순히 critical gap을2.5/3초로 늘리는 기존 실패 후보를 반복하지 않는다. 평균 유량 입력을1차로 유량으로 교체하는 것만으로도 저속 점유 문제는 해결되지 않는다.
2. 현재31셀 모델의 gap 기회와 **합류 지점의 저속 점유·잔여 수용**을 구분해야 한다. 현 관측에서 혼잡 차로와 전체 평균이 얼마나 다른지 먼저 보존하고, 미래 실측을 공급하지 않는 상태 표현과 기존 합류/수용 계산의 제한적 수정으로 이어간다. 단순 관측34대/150초를 cap으로 적합하지 않는다.
3. 모델이 본선 혼잡을 잘못 예측해 canonical density 제약이 비구속인 영향도 남아 있다. gap 식만을 전체9000 손실의 유일한 원인이라고 하지 않는다. posthead 이동시간 오차도 아직 분리되지 않았다.
4. 회복·낮은 수요에서 새 제한을 만들지 않고, 실제 합류가 크게 달라지는 독립 RM 유지/완화 상태의 본선 방출·램프 대기·ΔTTT 순위를 유지해야 채택할 수 있다. 기존 강한 RM 손해 방향 예측이 맞았던 증거를 버리지 않는다.
