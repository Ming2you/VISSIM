# 과거450초 차로 비율 후보의 반응 검증

2026-10-01. 이전 턴과 이번 턴 모두 PROGRESS다. 이번에는 과거 관측만 쓰는 단일 후보를5개 상태/정책 사례에서 검사하고, seed43 네 명령의450초 자율 예측으로 영향까지 확인했다. **정본 미채택, 이득 검증 미완료**다. 새VISSIM·실시간 런 조회·FZP 스캔·push는 하지 않았다.

## 후보와 사전 검사

10681의 미래 도착 차로 비율만 직전150초 계수에서 직전450초 누적 계수로 바꾸었다. 초기 차량의 차로·위치, 도착 총량 모델, head 서비스, 이동시간, 합류 수용, 본선 속도식, 도시 신호, off-ramp 저장/배수는 그대로다. 미래 실측을 예측에 넣지 않았다. 기존v2 초기화는`obs150_lane.ramp_arrival_shares`의 현재 닫힌 관측창을 읽으므로 설정 파일의`lane_arrival_history_sec`만 바꾸고 작동했다고 판정하지 않았다. 기존진단 runner에서 실제10681 buffer의 미래 도착 비율 한 항목을 변경하고 나머지 state의 동일성을 확인했다.

전체450초 안의 각150초 창마다1차로 차량 수 오차의 절댓값을 더했다. 이것은 실제 총 도착량을 공통 분모로 두어 차로 비율만 평가하는 통계 검사이며, 자율 교통 예측의 오차가 아니다.

전체 오차는14.67% 감소했으나, 사전에 정한15% 감소와 각 사례 악화2대 이하 기준을 근소하게 통과하지 못했다. 이 통계 검사를 통과로 바꾸지 않았다. seed47 유지/완화는 동일 과거 상태를 공유하므로 서로 독립 표본2개로 세지 않는다. 기존에 관측했던 자료이며 blind 검증이 아니다.

차로 비율 오차와 제어 판단의 관계를 확인하기 위해 한 후보의 네 조건 물리 예측만 추가했다. 이는 통계 gate 면제나 채택이 아니라, 국소 절대량이 좋아져도 제어 이득이 개선되는지 확인하는 제한된 민감도 검사다. 다른 관측 기간을 탐색하지 않았다.

## 다음 진단의 초점

RM에서8램프 대기 비용 변화는 후보+0.2442/실제+0.2458대·시간으로 가깝다. 반면 동측 본선은 후보−0.3426/실제−1.2792다. VSL 동측 효과는 후보−0.0201/실제+1.0958로 방향도 다르다. 램프 대기 비용을 임의로 낮추거나10681 차로 비율만 계속 맞추는 방향은 근거가 없다. 원래9000 손실의 주요 원인 후보인 **본선 병목 방출·상류 축적·회복 반응**을 다음 우선 진단으로 한다. 다른 명령별 실현 입력 차이를 물리 계수로 흡수하지 않는다.

현재 상류 연결도 확인했다.10681의2개 차로는68의1·2차로에서 연결된다.2250초68에 있는11대는 모두2차로이고,2400초에는 같은11대가10681의2차로에 있었다. 초기 상류 재고의 차로와 미래 미선택 차량의 차로 비율은 다른 정보다. 현재`known_legsplit`는 목적지 태그를 보존하지만 이 태그 자체에는 차로가 없어, 차로 비율 평균을 늘리는 것만으로 이를 표현했다고 볼 수 없다. 이 관측은 구조 검토 근거이며 새 lane-change 모형을 채택했다는 뜻은 아니다.
