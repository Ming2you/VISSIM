## 검증과 보존

- 앞서 완료된NC/RM 두450초 예측은 기존10484 추적 기준 결과와 `wall_sec`를 제외한 전체JSON이 정확히 같다. 추적기능만 바뀌었다.

- 실제 입구/head의12개 창·검지기 계수를 원시MER, 창 집계, 누적 계수 차이로 대조했다. 세150초 실제 램프 재고 원장의 잔차는0이다.
- 기존 실행의115개 고정 파일을 재확인했다. 새 모델 계수·운영 코드·망·수요·STOP·실행 중 런은 바꾸지 않았다. 새VISSIM·전체plant rollout·FZP 스캔·현재 런 조회·push는0이다.
