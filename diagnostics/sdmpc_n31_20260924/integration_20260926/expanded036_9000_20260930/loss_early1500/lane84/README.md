# 합류 차로 관측을 반영한 posthead 이동 후보: 제한된 검증 결과

2026-10-01. 새 native/실행 중 런 조회/계수 적합/push 없이, 기존 자료로6회450초 자율 예측을 완료했다. **기존 모델과 후보 모두 독립seed47의 큰 RM 손익 방향을 맞췄지만, 후보는 반응 오차를 개선하지 못해 정본에 채택하지 않았다.** 전체 이득 보정 목표는 미완료다.

## 무엇을 바꿨나

[차량별 근거](../local10484/README.md)에서10484 선두의 상호작용 대상은 합류 직후 본선24의1차로였다. 기존 셀 평균속도 제한은 초기 오차를 거의 줄이지 못했다. 이번에는 현재 관측의 셀23 전체 평균속도 대비1차로 속도 비율을 구해,450초 동안 예측된 셀23 속도에 곱했다. posthead 이동속도만 min(명목속도, 비율×예측 셀 속도)로 제한한다.

비율은1500초0.4636,3600초0.9166,독립seed47의2700초0.7542였다. 현재 raw 관측만 사용하며 후보 명령마다 같은 초기값이다. 미래 궤적이나 명령별 보너스는 없다. 비율이450초 유지된다는 것은 검증할 가정이다. 수용량·본선 우선배분·METANET 계수·도시 도착식은 바꾸지 않았다.

## 독립seed47: 큰 RM 이득 방향은 기존 모델도 본다

같은2700초 초기 상태에서10484 g2 유지와g4→6→8 완화를 비교했다. 나머지 제어는 기존 native 명령을 그대로 재생했다. native 두 런의 공통 prefix와 실행 검증은 기존 통과 결과를 재사용했고, 모델 입력은2700초 이전 이력으로 제한했다. 아래 Δ는 완화−유지다. 양수 Ω/East는 RM 유지가 유리함을 뜻한다.

**선택 방향은 둘 다 맞다.** 후보는 본선·램프 각각의 차이를 일부 가깝게 했지만 Ω 순이득 오차는 커졌다. 세 비용 오차를 각 실측 차이의 절댓값(최소1)으로 나눈 합은0.40893→0.45801로12.0% 증가해, 예측값을 읽기 전에 정한10% 악화 허용 기준을 넘었다. 따라서 이 후보를 기본값으로 승격하지 않았다. 작은 부호를 맞추는 추가 계수 탐색은 하지 않는다.

이 결과를 RM 이득을 전혀 못 잡는다는 주장으로 해석하면 안 된다. 기존 모델은 이 강한 RM 비교의 합류차이와 큰 손익 방향을 잡는다. 완전 개방g10에서 제한을 시작하는 판단, VSL·동시 제어, 실제 SDMPC 선택과 수렴은 이 시험으로 검증되지 않았다. 고정 명령 반응 비교이며 N_P/N_UF leader 목표의 실행 가능성은 주장하지 않는다.

## 다음에 확인할 도착·저장 연결

실제10484 도착은 유지72대/완화83대였으나 모델은두조건 모두72.274대였다.3150초 실측에서는:

- 유지: 전체57대 중 신호등 앞56대,49대가5km/h 미만. 가장 뒤 차량의 앞 위치는 커넥터 시작에서1.314m여서 대기가 입구까지 닿았다.
- 완화: 신호등 앞10대,5km/h 미만0대. 가장 뒤 차량은74.342m였다.

현재 `PhysicalRampBoundary.current_admission_space`는 커넥터 전체 잔여 공간을 사용한다. 신호등 이후의 저장은 head 방출 때 따로 제한하지만, 신호등 전방 입장에서는 전체 빈 공간이 사용된다. 같은 명목6m/대 간격으로 유지 상태를 계산하면 전체 여유33.318대, 신호등 앞만 계산해도6.852대다. 따라서 단순히 prehead 재고 상한만 추가하면 이번 도착 오차가 해결된다고 주장하지 않는다. **입구까지 닿는 대기와 공간이 상류로 전달되는 시간**, 도시 도착 예측을 분리해야 한다. 이 단계에서는 수용량이나 spacing을 조정하지 않았다.
