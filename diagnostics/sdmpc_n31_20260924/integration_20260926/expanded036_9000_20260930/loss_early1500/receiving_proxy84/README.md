# 본선 동역학을 유지한10484 수용 차로 추정 — 자율 예측 기준 실패

2026-10-01. 직전 국소 차로 METANET은 RM 유지 때 회복을 악화했다. 이번에는 기존 본선 속도식·차량 보존·동적 진출부·도시부를 유지하고,10484 합류 수용 계산에서 쓰는 차로 속도 추정만 작게 바꿨다. 관측 상태 대입에서는 개선됐지만, 자율 예측에서는 초기 합류 오차를 충분히 줄이지 못했다. 정본에 채택하지 않았다.

## 계수 하나를 동결한 뒤 검사

수용 차로의 저속 정도를 다음 경험식으로 시험했다.

```
x = r10 / (q22_total + r10) × max(0, 1 − v23/110)
v_lane = v23 × exp(−a × x)
```

q22_total은 현재 상류22셀의 전체 rho×v 유량 proxy, r10은 직전10초 실제 합류율, v23은 현재 합류23셀 평균속도다. a만 seed29의1500–1650초·3600–3750초 기록으로 로그 속도비의 비음수 가중 최소제곱으로 한 번 추정했다. 가중치는 관측 접속 차로 차량 수다. **a=7.1503761553**을47/53 자료를 읽기 전에 저장했다. 비용·이득을 학습 목표로 쓰지 않았다.

110은 이번 가설의 고정 자유속도 기준이다. VSL 때문에 낮아진 자유류 속도와 혼잡 감속을 혼동할 수 있다는 한계를 사전에 명시했다. 따라서 이 식을 METANET의 검증된 물리 법칙이나 VSL 반응 모델로 주장하지 않는다.

계수 학습62개5초 표본, 별도47·53 검증356개 표본을 사용했다. 이 두 seed는 이번 계수 학습에서 제외됐지만, 전체 프로젝트의 이전 구조 진단에는 사용됐으므로 전혀 보지 않은 독립 연구 검증이라고 부르지 않는다.
