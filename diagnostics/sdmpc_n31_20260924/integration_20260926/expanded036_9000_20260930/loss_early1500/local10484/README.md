# 10484 신호등 뒤 지연: 실제 합류 차로와 차량 상호작용

완료된 seed29 원래9000초 런에서1470.1–1665.1초와3570.1–3765.1초만 읽었다. 파일은1.247GB지만 시간순 FZP의 바이트 위치를 찾아68.60MB만 읽었고, 추출은0.955초 걸렸다. 전체 파일을 재스캔·재해시하지 않았다. 각 창40개5초 프레임의 시각·중복 ID·열 수, 읽기 전후 파일 크기/수정시각, 각 바이트 범위와 선택 행 해시를 확인했다. 새 VISSIM·현재 런 조회·보정은 없다.

초기 창에서 선두가 보는 대상은 전체3차로 평균이 아니라 합류 직후1차로의 실제 차량이었다. 대상 중20개는 선택한 FZP 구간에서 앞서10484에 있던 차량으로 확인됐다. 나머지의 출처를 본선 차량이라고 단정하지 않는다. 이 사실은 선행 합류 차량의 이동·추종도 중요할 수 있다는 근거이며, 특정 차량 하나가 지연의 유일한 원인이라는 증명은 아니다.

head 통과 시각은 native MER, 합류 시각은 마지막10484 표본과 첫24 표본 사이의5초 구간으로 구했다. 초기 창의45대 중35대에서 전이를 확인했고10대는 추출 종료 시점까지 확인되지 않아 제외했다. 이 완료 표본의 posthead 이동시간 중앙값 범위는 **20.81–25.81초**다. 둘째 창23대는 모두 전이를 확인했으며 **10.90–15.90초**다. 현재 모델의 고정 명목 이동시간은8.73초다. 미완료 차량을 제외한 중앙값이므로 전체 차량의 비편향 평균 지연 또는 정확한 합류 시각으로 해석하지 않는다.

램프 내 기록된 차로 변경은 모든 표본에서None이었다.5초 사이의 짧은 움직임이나 본선 차량의 양보·차로 변경이 없었다는 의미는 아니다. FZP의 `Free`, `Brake AX/BX`, `Follow` 등 문자열은 그대로 보존하며 단어만으로 내부 운전 로직의 원인을 확정하지 않았다.

3600초의 셀23은 본선 회복 상태로 확인되지 않았다. 램프가 지속 정체하지 않고 실제23대가 합류한 비교 상태다. 이 창을 자유류라고 쓰거나 합류34/23대를 각각 용량으로 고정하지 않는다.

이 근거로 [현재 합류 차로 속도 비율을 반영하는 이동 후보](../lane84/protocol.json)를 제한적으로 검토한다. 현재1500초 관측에서1차로 평균23.52/셀 전체50.74km/h의 비율0.4636을 얻고, 예측 중에는 METANET 셀 속도에 그 비율을 적용한다. 고정된450초 차로 속도 비율은 아직 검증할 가정이며, 미래 실측 궤적을 예측 입력으로 쓰지 않는다. 공유 수용량이나 본선 우선 배분을 바꾸지 않는다.

`extraction.json`, `analysis.json`, 선택 행 압축파일, 실행한 assessor 소스를 보존했다. FZP0.1초 위상과 COM 정수초 관측을 동일 시각이라고 취급하지 않았다. 본 문서의 속도·표본은 FZP 위상, 후보 초기값은 정수초 현재 COM 관측을 사용한다. 정본 채택·제어 이득 검증은 별도이며 전체 목표는 미완료다.

후속(2026-10-01): `head_speed_diagnostic.json`에서 head 통과속도는 두 창41.7/42.2km/h로 비슷했지만, 초기 창은 posthead 중간·말단에서 다시 감속·대기함을 확인했다. 완료35대 중25대는 통과속도를 유지했을 때보다도 이동이 늦었다(속도0.1km/h·시간1초 여유 포함). [저속 공간 해소 보정 후보](../clearance84/README.md)는 초기 과대 합류를 줄였으나 독립 RM 손익 오차가 커져 채택하지 않았다. 새 FZP 스캔·native 런 없음.
