# 셀23 밀도별 합류 감속: 제한된 민감도 시험, 채택하지 않음

2026-10-01. 기존9000 손해 분석의 후속 작업이다. 진행 중 VISSIM/CTG 조회·중단, 새 VISSIM 실행, FZP 재스캔, push는 하지 않았다. 원래 expanded036 운영 설정도 그대로다.

## 시험한 변경

앞선 항별 진단에서 셀23은 혼잡 상태에 가속 편향, 원활한 RM 유지 상태에는 감속 편향이 있었다. 이를 근거로 **현재 예측 밀도에 따라 기존 합류 감속 계수만 바꾸는 후보1개**를 시험했다.

```
w = clip(rho / rho_critical - 0.5, 0, 1)
delta23 = 기존 delta23 × (0.5 + 1.5 w)
```

임계밀도의0.5배 이하에서는0.5배,1.5배 이상에서는2배의 합류 감속이다. 중간은 연속 선형이다. 이 숫자들은 적합으로 얻은 정본이 아니라 **사전에 고정한 민감도 후보**다. 새 용량·유입 보너스, 목적함수 보상, 미래 실측 입력은 없다. 합류량·차량 보존·램프 이동과 대기·도시 신호·동적 off-ramp 저장·배수는 기존 계산을 그대로 사용했다.

기존 `onset_factorial/run.py --merge-state23=onset/ind47`의 명시적 진단 모드에서만 계수를 적용했다. 현재 셀의 예측 밀도를 읽고 복사한 응답 설정을 반환한다. 운영 물리 코드나 설정 파일을 수정하지 않았다. 각 실제 속도 업데이트 뒤 결과를 대조해 셀23의 계수만 변경됐음을 확인했다.

실행 전 `protocol.json`에 후보1개·450초 예측3회·계수 적합0회의 예산과 판단 기준을 고정했다. 실제로3회 모두 완료했다: seed29의1500초 시작1회, 공통 초기 상태 seed47의 RM 유지·완화2회. 계산77.691초, 전체113.144초였다.

## RM 손익은 과하게 예측

동일 초기 상태·실행 명령을 사용한 seed47의450초 결과다. 아래는 **RM 완화 − RM 유지**이고, 양수이면 유지하는 쪽이 유리하다. 단위는차량·시간이다.

|동측 본선|+4.870|+5.236|+7.077|

RM 유지가 낫다는 큰 순위는 유지했지만, 본선 차이를 과장했다. 본선+램프 차이의 절대오차는0.254→1.580으로 커져 사전 기준을 통과하지 못했다. 실제10484 합류 예측은 유지45.329→45.328, 완화95.001→95.031대로 거의 같았다. 주된 변화는 합류량 자체보다 본선의 상태 반응이다.

램프 비용의 오차가 약−0.62로 그대로인 상태에서 본선 오차는+0.37→+2.21로 커졌다. 이 두 끝점을 보간해 전체ΔTTT만 맞추는 재보정은 하지 않는다. 서로 다른 비용 오차를 상쇄시키는 방식으로 맞출 수 있기 때문이다. 외부 대기 비용은 목적함수에 넣지 않고 진단으로 기록했다.

## 상태별 계수가 의도한 상태에서 작동하지 않는다

후보가 실패한 이유를 기존 실측과 모델의 밀도로 대조했다. 미래 실측은 평가에만 사용했다. 아래는2700.1–3140.1초의89개 프레임 평균이다.

|RM 상태|실측 셀23 밀도|모델 밀도|실측 상태라면 적용될 배율|실제 예측에서 적용된 배율|
|---|---:|---:|---:|---:|
|유지|25.72|37.75|0.722|1.134|
|완화|53.49|62.76|1.690|1.753|

밀도 단위는대/km/차로다. 유지 상태에서89개 중71개 프레임은 감속을 약하게/강하게 하는 방향 자체가 실측 상태 기준과 달랐다. 실측 속도는88.84, 모델은61.19km/h다. **실측 상태에 대입하면 좋아 보이는 밀도별 계수도, 자율 모델이 밀도·속도를 잘못 예측하면 반대로 작동한다.**

모델의 첫30초를 보면, 셀21은71.38→49.76km/h로 내려가며 밀도가28.72→40.34로 올라갔다. 셀21의 평균 합류 감속−4.838km/h/1초는 이번 시험에서 바꾸지 않은 기존 항이다. 셀22에는 대류와 anticipation 감속이 이어지고, 셀24에는 낮은 FD 목표속도에 따른 이완 감속이 남는다. 이는 **모델 내부의 전파 경로**를 확인한 것이며, 실측 혼잡 원인을 이 항 하나로 확정한 것은 아니다.

## 결론과 다음 범위

후보는 미채택이다. 첫 혼잡 셀23의 국소 오차와 큰 RM 손익 순위는 개선 또는 유지했으나, 주변 저속과 RM 본선 손익 오차를 해결하지 못했다. 계수·문턱을 여러 개 더 탐색하지 않았다.

다음에는 셀23만 반복 보정하는 대신 **상류10490 합류 셀21의 감속이 셀22·23의 잘못된 상태를 만드는 정도**, 그리고 셀24 회복 이완의 영향을 분리해야 한다. 현재 모델의 잘못된 밀도를 전제로 상태별 계수를 더 적합하지 않는다. 초기 상태의 단기 반응과 방출·재고 전파를 확인한 후 필요한 지역 계수만 제한적으로 검토한다. 원활한 RM 유지와 혼잡한 완화를 함께 유지하고, VSL 조건·별도 seed의 전체 비용 검증도 아직 필요하다.

`assessment.json`에는 사전 기준5개 중 RM 비용 크기 기준 실패가 기록돼 있다. 이는 전체 목표 완료나 SDMPC 연결 검증이 아니다. 새 VISSIM이나9000 재실행으로 대체하지 않았다.
