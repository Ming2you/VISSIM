Apply this one patch after `area_phase_finalization.patch`. It adds `evaluation/controllers/area_meter_finalization.py` and five small hooks:

1. Shared runtime initialization freezes the actual merged actuation settings, physical meter mapping, current snapshot flow hints, previous observed demand/green hints, and current observed ramp spillback into serializable cfg context. Worker cfg carries the same context without reading future data. The spillback hint is the initial decision's observed tail, not a forecast of future microscopic tails.
2. The canonical area endpoint builds a private action, overlays the requested price move, finalizes it, and calls the existing endpoint with that action. Empty/base price probes also preserve the original input object.
3. Follower final scoring finalizes the actual candidate after phase refinement and before its on/off/final endpoint evaluations. Thus selected Nash controls retain the scored first physical meter command. PFO uses the same follower solve path at vendor `stackelberg_wu_metered.py:2170`; its ordinary severe fallback comparisons are unchanged.
4. The already-accounted coupled interval finalizes its current action before advancing. Actual n7 has both leader box-walk flags True and meter box300veh/h, so subsequent horizon intervals can change rates. Those changed rates are reallocated using the same current-decision context. Allocation diagnostics use copy-on-write because canonical box-walk starts from a shallow action copy; the original candidate's first command and marker remain unchanged.
5. Main's late writer block asserts that rates, calibrated context and physical schedule match the finalized candidate, rather than running the guard again after scoring. Only explicit no-control warmup may initialize an unscored action there. CSV consumes the already-cached exact schedule.

The separate marker hashes context, physical mapping, actuation/table settings and model group capacities, and records original requested rates, written rates, physical greens and demand hints. Unchanged copies remain idempotent. Changed rates, table, map, observed spill or demand invalidate the allocation; stale legacy `rw_meter_*` keys are then removed before reallocation. Modifying a scored command at the late writer raises. Missing shared context also raises explicitly.

Current final β0/60/150/300 configs do not enable `adapter.post_guard_safety`, `actuation.ramp_release_guard`, the active actuator mask, or the invalid-F override. Enabling those separate late selectors/overrides is explicitly unsupported by this patch and fails at configure; it does not silently treat a native-fixed fallback as scored. Other controller families have not been promoted by this n7-specific review. Diagnostic fixtures that manually enable Ω without the shared runtime need an explicit `configure(adapter,cfg,tuning,mapping,raw,previous_path,state,calibration)` call; actual main/worker already use the common initializer.

The global endpoint and each coupled horizon interval see the physical allocation. The local follower predictor still optimizes a continuous grouped-rate surrogate before the final coupled comparison; this patch does not rewrite that local solver.
