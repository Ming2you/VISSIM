# FW80 / urban90 — completed four-condition comparison

후속 공간·시간 분해는 `vsl_decomposition/README.md`를 참고한다. VSL 단독의 동측 중간 구간은−44.48veh·h지만 동측 입구가+215.38veh·h여서 전체 손해로 합쳐진다. 5.3–6.6km 관측 진입군은 모두 출구를 확인했고, 평균 통과시간62.08→52.28초/대수13634→13641이다. 입구40m 검지와 장시간60 명령은 후속 대조 실험 대상이며, 아직 특정 구역만 켠 인과효과나 개선 정책을 확정하지 않았다.

네 조건 모두 seed23, 0–9000초 완료. 무제어는 기존 정본을 재사용했다. RM은 ALINEA, VSL은 규칙 제어이며, plant/MPC가 선택한 제어가 아니다. 제어 시작900초 전 FZP 데이터 행 SHA-256은 네 조건이 정확히 같다. 제어3조건의 기존 native LDP/적용 readback 검증은 모두 PASS이며 기록 대상 누락은 없다. 새로운 VISSIM 런이나 calibration은 수행하지 않았다.

## TTT·유출

TTT는 Ω=고속도로+도시 protected network 내부 재고의 시간 적분이다. 램프와 Ω 내 도시 대기는 포함하고, 망에 삽입되지 않은 외부 대기는 포함하지 않는다. 동일한 기존 물리 영역 함수를 실제 네트워크에 다시 검증했고, 링크별 TTT 합계와 재고 장부가 일치한다.

| 조건 | Ω TTT [veh·h] | 무제어 대비 | Ω 유출 TTD [사건] | 살아서 비제어 영역으로 | Ω 내 말단에서 정상종료 추정 |
|---|---:|---:|---:|---:|---:|
| No control | 7,073.21 | 기준 | 58,231 | 35,292 | 22,939 |
| ALINEA RM | 7,012.48 | −0.86% | 58,323 | 35,368 | 22,955 |
| Rule VSL | 7,253.82 | +2.55% | 58,056 | 35,211 | 22,845 |
| RM + VSL | 7,326.03 | +3.57% | 57,561 | 34,888 | 22,673 |

TTD는 차량의 유출 사건이며 고유 차량 수와 동일하다고 가정하지 않는다. Ω 내부 이동·비정상 삭제·미확인 소실·마지막 잔여 차량은 유출로 세지 않았다. 5초 기록 사이에 짧은 비제어 구간/말단 링크를 지나면 경계 사건이 빠질 수 있어 정확한 native 전수 카운터는 아니다. 마지막8995.1초 이후4.9초는 마지막 재고를 유지하여 TTT만 추정했으며 유출을 추가하지 않았다(조건별2.69–2.77veh·h).

## 망 전체 termination을 별도로 볼 때

| 조건 | 확인 가능한 말단 정상종료 추정 [대] | 판정하지 못한 망 소실 [대] | native 삭제 [대] | 마지막 관측 망 잔여 [대] | 종료 시 미삽입 [대] |
|---|---:|---:|---:|---:|---:|
| No control | 54,712 | 9,810 | 250 | 2,650 | 10,725 |
| ALINEA RM | 54,746 | 9,880 | 235 | 2,629 | 10,658 |
| Rule VSL | 54,612 | 9,721 | 230 | 2,676 | 10,909 |
| RM + VSL | 54,258 | 9,620 | 229 | 2,603 | 11,440 |

첫 열은 **전체 정상 종료 대수의 확정값이 아니다.** 마지막 관측 위치가 실제 망 말단이고, 다음 표본에서 사라지며, 이동 가능 거리가 맞고, native 삭제가 아닌 경우만 추정했다. 판정하지 못한 망 소실은 정상종료로 더하지 않았다. 5초 기록으로 생애 전체가 누락된 짧은 통행도 있을 수 있다. 이 표의 종료 추정치로 작은 처리량 차이를 단정하지 않는다. native 삭제는 ERR 차량ID와 FZP 소실을 대조했으며 말단 정상종료 판정과 충돌한 삭제는 없다. 종료 잔여는8995.1초 관측치다.

미삽입은 네 조건 모두 vehicle input1099에 기록된 **차량 수**이며 경고 건수가 아니다. 같은 설정 수요라도 실제 삽입량은 달라졌다. 따라서 ΩTTT만으로 동일 총수요를 모두 처리한 네트워크 총비용 개선을 주장할 수 없다. 이 입력의 전체 대기시간은 이번 자료에서 적분하지 않았다.

## 고속도로 히트맵

- `FW_E_four_conditions.png`: 동측 네 조건, 30초×100m.
- `FW_W_four_conditions.png`: 서측 네 조건, 같은 집계·색 범위.
- 빨강은 저속, 파랑은 고속, 회색은 차량 표본 없음. 가로선은 실제 램프 접속 위치, 세로선은900초 제어 시작이다.
- VSL로 명령한 제한속도 때문에 생긴 넓은 저속 띠를 모두 대기열로 해석하지 않는다.

RM은 동측7.2–7.6km 부근에서 상류로 전파되는 혼잡을 줄였다. 동측 본선 TTT는132.64veh·h(6.49%) 감소하지만 서측16.66veh·h와 도시·램프 등55.24veh·h 증가로 Ω 순감소는60.74veh·h(0.86%)다. VSL 단독 및 병용은 이번 규칙과 seed에서 Ω TTT가 증가했다. 병용의 서측 본선 TTT는13.18% 증가한다. 이는 이 제어 규칙의 관측 결과이며, VSL/RM의 모든 설정이나 MPC의 한계를 뜻하지 않는다.
