# VSL은 항상 손해인가, 국소 이득이 상쇄됐는가?

이번 FW80·urban90 / seed23 / 9000초 자료에서는 **국소적인 개선과 손해가 섞였고, 손해가 더 컸다.** 모든 상태·정책에서 VSL이 무효라는 증거가 아니다. 새 런이나 controller/plant 수정 없이 완료된 네 조건을 추가 집계했다.

## 1. 실제 비용의 공간 분해

VSL 단독−무제어, 0–9000초. 음수는 해당 공간의 TTT 감소다. 영역별 재고를 원래5초 시각에서 사다리꼴 적분했으며 합계는 기존 Ω TTT 차이와 일치한다.

| 구간 | 위치 | ΔTTT [veh·h] |
|---|---|---:|
| 동측 입구 VSL 구간 | 0–2.735km | +215.38 |
| 동측 두 램프군 사이 | 5.042–6.827km | **−44.48** |
| 동측 뒤 램프군 | 6.827–7.604km | **−16.55** |
| 서측 입구 VSL 구간 | 0–2.694km | +59.22 |
| 나머지 본선·도시·램프 | 위 구간 제외 | −32.98 |
| Ω 전체 | 고속도로+도시 protected network | **+180.60 (+2.55%)** |

동측 두 램프군 사이에서는30km/h 미만 체류도27.03veh·h 감소했다. 반면 동측 입구의 비용 증가는30–80km/h 체류 증가가 중심이며, 단순히 모든 공간의 정체가 악화된 것은 아니다. 속도 구간별 체류는 기술적 분류이지 인과적인 손실 원인 분리는 아니다.

12개 공간×150초로 나누면 감소분 합계206.22veh·h, 증가분 합계386.82veh·h, 순증가180.60veh·h다. 이 증가/감소 합계는 분할 방식에 따라 달라지고, 감소한 조각만 독립적으로 실행해 얻을 수 있는 편익은 아니다.

## 2. 차량이 덜 들어와서 좋아 보인 것인지 교차 확인

900–8100초에 아래 구간으로 진입한 관측 통과군의 여행시간을9000초까지 추적했다. 같은 물리적 절단면을5초 위치 기록 사이에서 선형 보간했다. 동일 차량ID를 정책 간 대응시킨 분석은 아니다.

| 구간 | 무제어 평균 | VSL 평균 | 무제어/VSL 통과 대수 |
|---|---:|---:|---:|
| 동측 입구 내부 0.3–2.5km | 80.69초 | **128.39초** | 14,300 / 14,295 |
| 동측 두 램프군 사이 5.3–6.6km | 62.08초 | **52.28초** | 13,634 / 13,641 |
| 서측 입구 내부 0.3–2.5km | 212.06초 | **235.33초** | 8,555 / 8,418 |

위 세 구간의 관측 진입군은 네 조건 모두100% 대응 출구를 확인했다(`cohort_coverage.json`). 따라서 동측 중간 구간 개선을 통과 차량이 크게 줄었거나 느린 차량을 완료 표본에서 빠뜨린 결과로 설명하기는 어렵다. 다른 시각에 도착한 차량 구성과 정책 간 수요 실현 차이는 남는다. 추가 집계한6.9–7.7km는 중간 진출로 때문에 미대응 약2,330대가 있어, 그 완료차량 평균만으로 전체 편익을 판단하지 않았다.

## 3. 이득이 나타나는 시간도 있다

VSL−무제어의 Ω 전체150초 구간54개 중10개는 TTT 감소였다. 900초 집계에서는4500–5400초에6.51veh·h 감소했으나, 다른 시간대의 증가를 상쇄하지 못했다. 최종 누적 비용이 기준보다 좋아졌다는 뜻이 아니다. 해당900초의 동측 본선은+1.94이고 도시·램프 등의 감소가 전체 음수에 기여했다.

## 4. 우선 확인할 제한 위치·판단 방식

실제 저장된 rule_policy/decision/실행 검증에서 다음을 확인했다.

- 동측·서측 첫 VSL 검지는 본선 입구40m에 있다. 이 관측값으로 여러 DSD가 묶인 첫 구역 명령을 결정한다.
- 동측은900초 관측에서48.55km/h를 보고60 명령을 내렸고, 전체 제어 기간 중6150초를60으로 유지했다. 서측 첫 구역은8100초 내내60 명령이었다.
- 제어 전750–900초 무제어 공간 평균속도는 동측0–100m에서46.59,100–300m62.79,300–500m82.44,500–2500m103.88km/h였다. 같은 시각 하류 대부분은 원활했지만 입구 관측은 저속이었다.

따라서 **입구의 가속 구간/국소 저속을 넓은 구역 혼잡으로 취급해 긴 제한을 유지했을 가능성**이 유력한 확인 대상이다. 관측된 속도 분포와 정책 동작은 확인됐지만, 입력 가속과 대기열의 기여를 완전히 분리하거나 검지 위치 변경의 순이득을 검증한 것은 아니다. 원하는 효과를 얻기 위해 임의 capacity drop이나 보상항을 추가하지 않았다.

## 5. 병용−RM은 다른 결과

병용−RM의 ΩTTT는+313.55veh·h다. 동측 중간 구간도+20.07veh·h로, RM 단독에 비해 추가 이득은 보이지 않는다. 동일5.3–6.6km 통과시간은 RM47.30초, 병용51.14초다. 두 정책 간8미터×54회 중86개 명령이 달랐으므로, 이 차이를 'RM을 고정하고 VSL만 추가한 순수 효과'로 해석하지 않는다.

미삽입 입력1099는 무제어10725→VSL10909, RM10658→병용11440대다. 이 외부 대기시간은 Ω 비용에 포함되지 않는다. 특히 도시·램프 비용 감소를 그 자체로 효율 개선이라 단정하면 안 된다.

## 최소 후속 검증

첫 후보는 **동측 입구 VSL 구역만 기준120으로 유지하고 나머지 VSL 규칙·수요·기하·seed·RM OFF를 그대로 둔 대조 런**이다. 기존 무제어·전체VSL과 비교해 입구 비용을 줄이면서 중간·뒤 램프군의 개선이 유지되는지 본다. 반응이 달라지므로 기존+215.38을 단순히 총비용에서 빼서 예상 순이득으로 제시할 수 없다. 그 다음에 검지 위치 또는 혼잡 확인 조건을 하나씩 바꾸는 것이 적절하다. 새 대조 런은 아직 실행하지 않았다.
