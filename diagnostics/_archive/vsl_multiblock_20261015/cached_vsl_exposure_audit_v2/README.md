# 저장된 VSL 전달·목표속도 검사

2026-10-15. 완료된 matched_off2250_v3의 세 예측만 재사용했다. 새 교통 예측·최적화·VISSIM·FZP 스캔·계수 적합·생산 코드 변경은 각각 0회다.

## 확인한 설정

상위 `network.json`에는 `freeway_vsl_fd_response`가 없지만, 실제 예측 커널은 하위 고속도로 참조 설정을 사용한다. `LaneFreewayRuntime`이 `CanonicalFreewayModel._config()`에서 복사하는 동측 설정에는 **Carlson A=0.5, E=2, alpha=0**와 수동 코호트 전달이 활성화돼 있다. 상위 옵션의 부재를 실제 플랜트의 VSL 반응식 비활성으로 해석하면 안 된다. 이 검사에서 새 FD 식을 추가하거나 켜지 않았다.

현재 실제 커널의 31개 FD 파라미터가 저장된 예측 파라미터와 정확히 같은지 검사했다. 초기 2250초 코호트는 관측 이력상 전부 110이다. 단일 구역은 물리 셀16–25, 두 구역은14–25에90을 전달하며,26의 다음 표지판에서110으로 돌아간다. 램프 합류 차량은 다음 표지판까지110을 유지한다.

## 기존 예측의 명령 전달

병목 셀19–23의 차량·시간 가중90 노출 비중이다. 차량 고유 대수 비율이나 실측 순응률이 아니다.

|조건|첫150초|다음150초|마지막150초|
|---|---:|---:|---:|
|단일 구역90|49.6%|92.0%|92.1%|
|두 구역90|49.1%|91.9%|92.1%|

따라서 이 예측에서 여러 블록의90 명령이 누락되거나 플랜트에 전달되지 않은 현상은 확인되지 않았다. 합류110 코호트가 남으므로 병목 전체가 즉시90이 되는 모델도 아니다.

같은 저장 밀도에서 코호트가 FD 목표속도에 주는 직접 변화(대·초 가중 평균)는 다음과 같다. **실제 평균속도 변화나 용량/TTT 인과효과가 아니다.**

|조건/구간|첫150초|다음150초|마지막150초|
|---|---:|---:|---:|
|단일90,접근16–18|−6.89|−7.26|−6.13|
|단일90,병목19–23|−1.49|−3.14|−2.76|
|두 구역90,접근16–18|−7.25|−7.66|−6.37|
|두 구역90,병목19–23|−1.58|−3.40|−2.93|

단위는 km/h다. 병목의90 노출 차량·시간 중 약6–9%에서는90의 FD 목표가110보다 높다. 현재 식이 이득 방향을 수학적으로 금지하지는 않지만, 이 상태에서는 감속 방향의 직접 항이 우세하다. 이것만으로 그 반응식의 실제 정확도나 필요한 계수를 결정하지 않는다. 기존 전체 모델 예측 ΔΩTTT는 단일90 +0.921683, 두 구역90 +1.111329대·시간으로 유지된다.

## 검산과 한계

- 저장된 실제 채택 유량에만 코호트를 통과시켰다. 다시 계산한 코호트나 FD 목표는 교통 유량에 되먹임하지 않았다.
- 명목5초 내부에도 RM 사건에 따라 하위 시간간격이 있다. hold/single은208개, 두 구역은207개 하위 구간을 그대로 사용했다. 이를1초나새시간간격으로 바꾸지 않았다.
- 재고 복원 오차 최대1.28e−13대, 밀도 복원 오차4.97e−13, 코호트 보존 오차1.35e−12대, 정본 함수와 독립 FD 계산의 차이3.79e−13km/h 이내다.
- 첫 검사v1은 저장5초 프레임과 내부 사건 구간이 항상 같다는 가정 때문에 중단됐다. 스크립트·로그·부분 출력은 보존했고, v2에서 기존 유량 장부의 실제 사건 구간을 사용했다. 새 예측은 없었다.
- 단일90의 기존 실측 대조는 전체450초 Ω 차이가 거의0인 반면, 모델은 마지막150초 방출을 적게 예측한다. 다른seed에서는 오차 방향이 반대다. 여기서 공통 VSL 이득계수나 회복 가속을 채택할 근거는 없다.
- 새 두 구역 native는2250의 명령 메타데이터 오류로 실패했으므로 이 검사는 그 실제 반응을 대신하지 않는다. 수정된 명령639행의 검증은 완료됐으며, 별도1회 실행 승인 응답은 아직 없다.

근거와 입력 해시는 summary.json 및 active_component_config.json에 저장했다. 보정 목표는 ACTIVE·미완료이며, 실패한 native와 동결본은 그대로 보존한다.
