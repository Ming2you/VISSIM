# 접근부 VSL 반응의 후속 진단 — 2026-10-19

보정 목표는 ACTIVE·미완료다. 승인된 두 구역 native와 분석은 정상 완료했으며 새 native 예산은 0이다. 이번 후속은 완료된 예측 장부, 저장 상태와 검지기 관측만 사용했다. 새 예측·최적화·FZP 스캔·생산 변경·계수 적합·push는 모두 0이다.

## 새로 확인한 반응

2250–2700초 동측 두 구역90과110의 비교에서, 접근부 물리 셀14–18 끝의 검지기 통과량은 실제 **+31대**, 모델은 **−28.868대**다. 접근부 종료 재고는 실제 **−30대**, 모델 **+26.052대**다. 전체 ΩTTT는 약−0.009%로 거의 중립이며 이 내부 반응을 전체망의 유의미한 개선으로 바꾸어 해석하지 않는다.

through:10481 검지기는 본선 연결로10613 진입 후1m에 있다. 모델 셀 경계와 동일한 측정 위치라고 가정하지 않는다. 저장된1m 구간 재고의 조건별 차이는450초에서0이며, 관측되지 않은 소실/유입은 단정하지 않는다. 31대는 정상 네트워크 말단 유출이 아니다.

이전 보고서의 '실제 내부 유량은 현재 캐시에 없음'은 당시 집계 캐시의 한계다. 이번에는 원래 저장 상태의 obs150 검지기 기록을 추가로 읽어 위 경계의 관측을 확보했다. 다른 모든 셀 경계나 실제 합류 유량까지 확인한 것은 아니다. 과거 완료 보고서와 해시는 보존했다.

## 속도식과 실제 차로 연결

완료된 hold/single90/twozone90 예측의 내부 사건구간208/208/207개에서 접근부14–18의 속도 갱신 **3,115개**를 복원했다. 다음 기록 속도와의 최대 차이7.15e−12km/h, 직접 식과 호출 함수의 차이2.14e−14km/h, 재고 복원 오차1.28e−13대다. 기존 코호트별 VSL 목표속도 캐시를 재사용했다.

셀18의4→3차로 감속항은 첫150초 평균으로110 유지에서 약−3.03km/h/s, 두 구역90에서−2.72km/h/s이다. 이완·대류·하류 밀도항이 동시에 작용하므로 이 숫자는 관측 차량 가속이나 독립 인과효과가 아니다. VSL은 이 감속항을 더 크게 만들지 않았다. 반대로 희망속도 이완 가속이 줄고, 재고·밀도가 달라지는 연쇄가 함께 나타났다. 따라서 'VSL의 손해는 차로 감소항이 증가해서 발생'한다고 결론 내리지 않는다.

정본 INPX에서 연결로10613의3개 차로는 상류 링크2의2–4차로에서 본선119의1–3차로로 연결된다. 진출10481은 상류1–2차로에서 갈라진다. 이것은 단순한 전체 교통의 차로 소멸과 다른 분기 구조지만, 이 사실만으로 집계 METANET 차로 감소항을 오류라 하거나0으로 설정할 수는 없다.

12개 저장 시각·조건의240개 셀/차로 단면을 확인했다. 예를 들어2700초 셀18에서110 조건의2차로 평균속도는20.14km/h(15대),4차로는42.57km/h(9대)였고, 두 구역90에서는각36.99km/h(11대),56.99km/h(7대)였다. 이는 차로별 불균형의 관측이며,150초 사이 실제 차로변경 횟수나 차량의 진출 의도를 직접 관측한 자료는 아니다.

## 채택 결정과 다음 범위

새 생산 수정은 아직 채택하지 않았다. 차로 감소항을 일괄 약화하거나, 희망속도를 낮추면 용량이 늘도록 보너스를 넣을 근거가 없다. 셀 중심 거리 보정은 과거freeway_first/center_distance 실험이 있으므로 새 후보로 중복 실행하지 않았다. 기존19–20 미세 재고 교환,1초 내부 시간간격,임계밀도 압력 환산 실험도 재사용하며 반복하지 않는다.

다음 후보를 구현하기 전, 접근부14–18의 분기 차로 불균형과 공간 내 정체 위치를 현재 집계 상태가 구분하는지 확인한다. 기존183/195/212/213/247 및physical_lane_groups 진단과 동일한 가설이면 다시 실행하지 않는다. 후보가 정당화되면 차량·진출 의도·VSL 코호트를 보존하고, 미래 관측을 입력하지 않는 하나의 작은 수정으로 제한한다. seed29의150/300/450 단일/두 구역 반응과 seed67 이득·seed71 손해 및 기존RM 검증, 절대 재고/유량 오차, 물리·NP/NUF·액추에이터·계산시간을 함께 통과해야 한다. 이 요건을 새로 통과했다는 증거는 아직 없다.
