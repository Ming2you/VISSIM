# 175m 재보정을 위한 시간 적분·무제어 식별 검사

기존526m 셀의 보정 계수를175m 세 구간에 그대로 옮긴 후보의 실패만으로 공간 분할 자체를 기각할 수 없다는 사용자 지적에 따른 후속이다. 보정 목표는 ACTIVE·미완료이며 생산 변경·추가native는 없다.

## 시간 적분의 영향

같은 분할 상태·계수·도시/RM 명령으로 내부 적분 상한1.25초와0.625초의hold110/두 구역90를 각1회 계산했다. 외부 교환은FW5/U10, 지평450초, 목적함수·수요는 그대로다. 원래 분할2예측은 재사용했고 새예측은4회다.

## 새 관측과 분리된 보정/검증

정상2700초 완료·소유종료가 확인된 기존hold110 FZP에서만 새 공간 집계를 추출했다. 900.1–2695.1초의5초 간격360프레임, 접근부14/분할15/16의34,842개 차량·시점 표본이다. 기존TTT/히트맵/전체Ω캐시는 재분석하지 않았다. FZP기록은0.1mod5여서 정수 시각 원본 상태와 섞거나 동일 시각이라 하지 않는다.

첫 추출은 관심구간 밖 종단 링크24의종점 초과 기록(1.819m)까지 정본 위치 검사를 적용하여 중단됐다. 관심구간을5262.879–6490.884m로 먼저 한정한 뒤 그 안에서만 엄격한 정본 위치 검사를 적용했다. 종점 기록을 잘라서 다른 셀에 넣지 않았다. 최초스크립트·실패 원인을 보존했고 성공한 새공간 집계1회다.

보정은900.1–2100.1초, 완충구간2100.1–2250.1초, 검증은2250.1–2695.1초로 먼저 지정했다. 세분화3구간에 공유하는완화1/τ, 하류 고밀도/저밀도 반응ν/τ의3개계수만 비음수 최소제곱으로 한 번 식별하고, 부모해상도에서도 비교용으로 한 번 식별했다. FD·대류·기하·수요는 고정했다. VSL90 표본이나 실제 미래 경계를 예측 입력으로 쓰지 않았으며 계수 격자를 수행하지 않았다.

두 설계행렬은rank3이고 정규화조건수1.74/1.82다. 그러나 두 해상도 모두 최적해가1/τ=0, 고밀도 방향ν/τ=0의 경계로 갔다. 유한한완화시간을 가진물리적 파라미터 세트로 환산할 수 없어 후속 자율450초2예측 진입 조건을 충족하지 못했다. 낮은오차만으로 이퇴화해를 채택하거나τ상한을 임의로 지정하지 않았다.

세분화모델의검증 한단계속도RMSE는기존33.60→퇴화해10.98km/h였지만, 이는매5초관측으로재초기화한식별평가이지450초자율예측이 아니다. 기존관측을 이미부분적으로봤으므로완전히새로운blind test라고표현하지 않는다. 보정완료나VSL성능개선으로표현할수없다.

## 다음 식별 문제

실제 가운데구간은2250.1/2255.1/2260.1초에86.69/84.94/85.04km/h다. 작은시간간격의모델도첫10초에6.24km/h까지떨어지므로현재급감은수치하한처리만의문제로설명되지않는다. 원본과관측의0.1초시각차는유지한다.
