# 공간 분할 후 계수 보정과 독립 자료 평가

기존 공간 분할 시험은 부모 구간의 계수를 그대로 사용했다. 그 결과는 미보정 후보의 채택 근거가 부족하다는 뜻이며, 보정된 공간 모델 자체를 기각하는 근거가 아니다. 사용자의 지적에 따라 이 판정 범위를 정정했다.

이번에는 동측 15번 모델 구간을 세 부분으로 나눈 상태에서 임계밀도, FD 곡률, 속도 반응시간, 두 방향 밀도차 반응계수의 다섯 값을 함께 조정했다. 현재 후보는 독립 자료에서 일관된 개선을 보이지 않아 생산에 채택하지 않았다. 계수 보정이 불가능하다고 결론 내린 것도 아니다.

## 보정 범위와 결과

완료된 seed29의 110km/h 기준 자료에서 자유류(1650–2100초), 정체(2250–2700초), 회복(2850–3300초)의 450초 궤적을 사용했다. 150/300/450초의 차량 수와 속도를 맞췄으며 VSL90 손익을 보정 목표로 사용하지 않았다. 2250초 자료는 이제 학습·개발 자료이며 독립 검증 자료로 부르지 않는다. 기존 기록 명령은 조건으로 사용하지만 미래 실측 경계 유입이나 상태를 예측에 넣지 않았다.

과거 물리 범위 안에서 제한된 Gauss–Newton 갱신 두 번만 수행했다. 이번 단계 시작점은 앞선 자유류 중심 보정 값이다. 나머지 구간, 수요, 도시/RM 동역학, VSL 법칙은 고정했다.

| 지표 | 이번 재보정 전 | 재보정 후 |
|---|---:|---:|
| 정규화 학습 오차 | 1.156383 | 1.126679 |
| 차량 수 RMSE [대] | 6.6301 | 6.5425 |
| 속도 RMSE [km/h] | 16.9328 | 16.7169 |
| 정체 사례 속도 RMSE [km/h] | 22.2667 | 21.4368 |

학습 오차 감소는 2.57%다. 최종 값은 임계밀도 35.3192, FD 곡률 2.02806, 반응시간 6.71344초, 밀도차 반응계수 48.2384/43.7346이다. 반응시간은 이번 단계의 상대 변화 하한에 닿았다. 비선형 보정 수렴을 확인한 결과가 아니며 완결된 최적 계수라고 주장하지 않는다.

FW5/U10은 유지했고, 세분화 예측의 내부 계산 간격 상한은 0.625초로 고정했다. 이 수치 설정과 보정 계수는 생산에 적용하지 않았다. 새로운 계수를 채택하려면 해당 계수에서의 수치 민감도와 AD/NP·NUF/액추에이터/계산시간 검증도 필요하다.

## 계수를 고정한 뒤의 VSL 반응

아래는 각 사례 안에서 VSL90 조건에서 기준 조건을 뺀 450초 접근부 통과량 변화다. 보정 전·후는 같은 세분화와 내부 시간간격을 사용한다. seed마다 적용 구역·도시/RM 조건이 다르므로 사례 간 통과량을 직접 비교하지 않는다.

| 사례 | 실제 변화 [대] | 기존 계수 예측 [대] | 보정 계수 예측 [대] |
|---|---:|---:|---:|
| seed29 두 구역90, 개발 자료 | +31 | −28.88 | −31.49 |
| seed67, 보정에 쓰지 않은 자료 | +33 | +7.46 | +7.94 |
| seed71, 보정에 쓰지 않은 자료 | −24 | −11.60 | −4.34 |

seed67의 통과량 반응은 소폭 나아졌지만 절대 차량 수·속도 오차는 두 조건 모두 커졌다. seed71의 절대 궤적 오차는 줄었지만 VSL의 통과량 영향은 더 과소예측했다. 기본 궤적을 조금 더 잘 맞춘다는 사실이 제어에 따른 차이도 잘 맞춘다는 뜻은 아니다.

전체 Ω TTT 변화도 아직 일치하지 않는다. seed67은 실제 −2.065대·시간에 대해 보정 예측 +0.03714, seed71은 실제 +1.45533에 대해 −0.17554다. seed29 실제 −0.045833은 매우 작은 차이이며 그 부호를 억지로 맞추는 목표로 사용하지 않았다.

seed67/71은 이번 계수 추정에 사용하지 않았다. 다만 과거 모델 개발 과정에서 결과를 이미 본 자료이므로 맹검 검증이라고 부르지 않는다. 실제 관측 단면은 연결로 안쪽, 모델 유량은 경계면이라는 기존 비교 한계도 유지한다.

## 완료·보존 및 다음 단계

이번 단계의 새 오프라인 예측은 보정·개발 38개와 독립 비교 8개다. 기존 예측 두 개는 재사용했다. 모든 작업은 exit0으로 종료했고 자료를 보존했다. 새 native 실행, FZP 재스캔, 전체 S-DMPC 최적화, 생산 수정은 모두 0이다. 차량 경로·VSL 이력의 보존 잔차는 수치 오차 수준이었다. 이 사실만으로 행동 모델의 정확성을 주장하지 않는다.

준비 단계의 NP/NUF 메타데이터 혼동, 고정 replay에 온라인 sentinel을 요구한 오류, 독립 평가 출력의 상대 경로 오류는 예측 시작 전에 멈췄고 기록을 보존했다. 해당 준비 실패를 native 실패나 완료 예측으로 세지 않는다.

다음에는 저장된 궤적과 이번 유한차분 자료로 구간별 오차와 계수 민감도를 분리한다. 15번 구간의 국소 계수만으로 식별 가능한 오차인지, 인접 구간 또는 평균화된 속도 전달에서 오는 오차인지 먼저 확인한다. 이를 보기 전에 계수 범위를 무작정 넓히거나 독립 사례의 손익에 맞춰 재보정하지 않는다. 공간 분할의 적합성은 미결이며, 전체 보정 목표는 ACTIVE·미완료다. 유한 native 자동 확인은 PAUSED를 유지한다.
