# Native 진출 비율 민감도: 본선 재고 오차는 줄지만 E8 속도 오차는 남는다

실제 `codex_area_sources_beta0_s13_20260910`의 1200초 상태와 실행 명령을 유지한
150초 예측에서, 합성 기본 진출 비율을 native 경로의 조건부 비율로 바꾸면
본선 종료 재고가 관측에 가까워진다. 그러나 E8은 계속 너무 빨리 회복한다.
따라서 이 치환을 검증된 물리 모형이나 실제 제어 성능 개선으로 채택하지 않는다.

| 1200→1350초 | 현재 모형 | native 총 진출 비율 | 총 비율 + 조건부 direct 비율 | 실제 관측 |
|---|---:|---:|---:|---:|
| Ω TTT, veh·h | 111.600511 | 110.623970 | 110.282829 | 106.012500 |
| Ω TTD, veh | 484.779891 | 511.974283 | 529.728721 | 818 |
| 본선 종료 재고, veh | 1285.088157 | 1143.868534 | 1142.101650 | 1115 |
| 본선→8개 진출 가지 이동, veh | 157.218200 | 301.002046 | 302.768641 | 286 |
| E8 종료 속도, km/h | 96.1159 | 94.8488 | 98.8661 | 40.485 |
| E9 종료 속도, km/h | 84.7905 | 89.3607 | 90.9597 | 43.168 |

본선 재고 관측은 FZP 끝 프레임이며 같은 시각 COM은 1114대다. Ω 유출 818대는
직접 경계 통과 575대와 종단 추론 243대의 합이며 내부 소실 1대는 제외했다.
본선→진출 가지 이동은 Ω 내부 이동이므로 위 TTD에 다시 더하지 않는다.

native 총 진출 비율은 FE=5.6/13.6, DE=7/15, DW=6/16, FW=4/12이고,
진출 조건부 direct 비율은 각각 4/5.6, 3/7, 3/6, 3/4다. 실제 INPX와
`total_offramp_ratio_audit.json`의 해시·경로 근거를 확인했다. 하지만 중간 합류
차량의 경로와 두 출구의 물리적 순서가 현재 집계 셀에서 구분되지 않으므로,
이 값을 모든 차량의 무조건적 진출 확률로 읽으면 안 된다.

총 비율과 direct 비율을 함께 바꾼 모형의 그룹별 방출은 FE 112.333/관측80,
DE 68.752/68, DW 74.560/74, FW 47.124/64대다. 전체 302.769/286대라는
작은 차이는 FE 과대와 FW 과소의 상쇄를 포함한다. E8의 과도한 속도 회복은
이 비교에서 개선되지 않았다. 실제 차량의 경로 표식과 순서가 있는 합류·분류
흐름을 보존하는 수정이 별도로 필요하다.

각 arm은 실제 raw 상태, 이전 명령, 현재 명령, 수요 예측의 독립 사본에서
동일한 15개 하위 스텝을 실행했다. 현재 모형 arm은 독립 실제 구간 재생의
TTT·TTD·진입량과 정확히 같고, 세 arm 모두 재고 보존과 입력·소스 불변 검사를
통과했다. 새 optimizer 검색이나 VISSIM 실행은 없었다. 실행시간은 3.219초다.

재현기는 `probe_total_offratio_sensitivity.py`, 수치·해시는 동명 JSON이다.
과거 기본 run 결과는 덮어쓰지 않았다.

```powershell
python -X utf8 -m diagnostics.probe_total_offratio_sensitivity --run codex_area_sources_beta0_s13_20260910 --start 1200 --reference diagnostics/source_interval_1200_1350.json --include-native-direct --out diagnostics/source_native_offratio_sensitivity_1200.json
```
