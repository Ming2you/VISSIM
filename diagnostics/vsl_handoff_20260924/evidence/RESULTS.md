VSL 이득 재현의 확인 범위

VSL 이득은 seed29의 450초 학습 구간에서 모델로 재현했다. 독립 혼잡 개입과 외부대기를 포함한 전체 비용까지 일반화됐다고 말할 근거는 없다. 아래 Δ는 같은 seed의 제어 − 무제어이며, 단위는 veh·h(차량·시간)다. 음수가 비용 감소다.

|검사|실제 VSL ΔTTT/비용|예측 또는 해석|
|---|---:|---|
|Seed29, 2220.1–2670.1초 학습|−0.325000|A0.5_E4 예측 −0.269119. 450초 전부 학습 자료|
|Seed43, 870.1–1320.1초 초기 개입|+0.400000|A0.5_E4 예측 +0.052273. 혼잡 전 손해 방향 검사|
|Seed43, 2220.1–2670.1초 새 혼잡 개입|+0.791667|후속 동결 prior −0.147650 / local_fd −0.138854. 방향 불일치|
|Seed29, 0–9000초 native 전체 비용|−78.763697 (−0.272117%)|외부대기를 포함해도 이 seed에서 순감소|
|Seed43, 0–9000초 native 전체 비용|+67.635667 (+0.235803%)|전체 비용 감소는 재현되지 않음|

대표 재현 후보는 원본 `diagnostics/dsd110_20260923/response_recalibration_20260924/gain_response/full_response_fit/A0.5_E4.json`이다. `training450_seed29/selection.json`의 공통 parameters와 원본 `gain_response/recovery_fit/segment_params.json`을 함께 쓴 결과다. `training450_seed29/check_summary.json`의 actual/predicted에서 동일 cutoff 무제어를 빼면 첫 행을 재계산할 수 있다. 새 혼잡 heldout의 prior/local_fd는 후속 램프·head·진출부 보정을 포함한 다른 후보이므로, A0.5_E4 그대로의 독립 검증 결과라고 부르지 않는다.

TTT의 범위를 구분해야 한다.

- **450초 actual/predicted:** 동측 본선 31셀과 진입 4개·진출 4개 커넥터의 차량 재고를 공통 30초 간격 사다리꼴로 적분한다. 직접 도시 접근부, 기존 상류 대기, 망 외부 삽입 대기는 이 비용에 포함되지 않는다. `objective`/`with_wait`는 모델 내부의 세부 시간 적분 및 추가 대기 비용이며 native 전체 비용과 동등하지 않다.
- **9000초 east_local_TTT_veh_h:** 동측 본선 물리 링크 10613/10699/10702/119/2/24/74, 진입 커넥터 10484/10490/10639/10681, 진출 커넥터 10481/10483/10643/10682, 직접 진입접근 링크 129/31/68/70이다. 공유 진출수용 링크 121/124/126/127은 제외된다. 5초 FZP 재고의 실제 시각 사다리꼴 적분과 마지막 4.9초 재고 유지 추정을 사용한다.
- **9000초 TTT_veh_h:** 정본 Ω 전체 링크 영역 안의 체류시간이다. 전체 VISSIM 망이나 외부대기 비용과 다르다. `accounting/east_link_sets_source.json`은 동측 링크 범위의 원본이며, Ω 범위는 저장소 정본 `diagnostics/control_area_membership.json`을 따른다.
- **9000초 network_TTS_including_external_veh_h:** native 누적 `(TravTmTot + DelayLatent) / 3600`이다. `external_wait_veh_h = DelayLatent / 3600`. 종료 시 미삽입 차량 수를 시간 비용으로 대신 빼거나 더하지 않는다.
- **새 heldout의 native_5s_ttt_veh_h:** 2220.1–2670.1초 전체 망/Ω 재고의 5초 사다리꼴 적분이다. 망 외부 latent delay를 포함하지 않으므로 이 배열로 전체 순이득을 주장하지 않는다. 별도 native checkpoint 비용 재측정의 완료 결과는 이 증거 묶음에 없다.

9000초에서 seed29 동측 local TTT는 2483.238667→2330.441278(−6.153%), Ω는 7263.267194→7094.754306이다. 외부대기 +79.279000을 포함한 전체 비용은 28944.770090→28866.006393이다. Seed43 동측 local은 2457.684931→2444.659542(−0.529986%), Ω는 7362.242028→7338.700861이지만, 외부대기 +76.484500 때문에 전체 비용은 28683.158176→28750.793842로 증가했다. Seed43 동측 종료재고 598→612, 동측 비정상 삭제 0→1, 전체 삭제 250→263도 함께 보고한다.

RM은 seed29 학습 실제 −0.825000/예측 +0.000013, 새 seed43 실제 −1.170833/예측 +0.009483(prior) 또는 +0.011024(local_fd)로 이득 예측이 미해결이다. 동시 제어 결과의 음수만으로 RM이나 VSL의 개별 원인을 검증했다고 할 수 없다.

원본 보고서의 당시 “heldout 대기” 문구와 상대 링크는 그대로 보존했다. 최신 판정은 이 문서와 `heldout450_seed43/summary.json`, `native9000_seed43/summary.json`을 함께 본다. 원본별 상대경로·SHA256·복사 크기·범위는 `index.json`에 있다. 두 heatmap은 동측 시각 자료이며 전체 비용 판단은 JSON 수치를 따른다. 모든 원본은 바이트 그대로 복사했고 새 시뮬레이션·재보정·raw FZP 분석을 하지 않았다.
