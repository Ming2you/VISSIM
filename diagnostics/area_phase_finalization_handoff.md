# Actual phase vector / score mismatch and scoped repair

The completed t3300 beta300 production preflight has four paired base/Link follower returns. All four change greens after the base endpoint score; the largest phase change is 42 seconds. The first pair changes 33 phase values while retaining objective 527.308324117237. This is an actual mismatch, not an inference from class structure.

Evidence: `area_production_preflight/wu-link_t3300_beta300_20260909T183707416734Z/phase_trace/phase_commit_36844.json`. The read-only profiler records return frames only and does not replace model/controller functions. The original adapter command exits 0, but arithmetic self-consistency alone does not establish score/vector alignment.

The observed cause is **post-solve phase refinement**. `before.phase_price_in_gne=false` and `stored_phase_overrides=0`. The resolved n7 configuration has `phase_price.refine_rounds=12` and no `in_gne` declaration. Thus `LinkAgentWuFollower.solve` executes its `apply_phase_price_refinement` branch after `WuFaithfulFollower.solve` has scored and guarded offsets. This is not the pending GNE-vector branch. The leader endpoint separately reevaluates the returned vector, so the demonstrated defect is the follower's objective/diagnostics and the offset retention comparison; it does not prove that every final leader objective is stale.

`area_phase_finalization.patch` changes only `evaluation/controllers/area_follower_objective.py`. The canonical builder calls this helper after installing the existing phased/joint/two-stage refinement methods. In area mode it scopes the whole Link solve, invokes that installed refinement chain once before the first follower endpoint, and keeps identical greens for offset-on, copied offset-zero, and final score. The original outer refinement call is skipped only for the action finalized in this solve. A separate branch commits pending GNE vectors before scoring when that flag is actually enabled. It does not enable the flag or change refinement settings.

`ControlAction.copy()` copies declared dictionaries and drops arbitrary object attributes. Therefore the solve token uses a temporary diagnostics entry, which the zero-offset copy preserves. The helper removes the entry before returning. Fresh solve tokens, exception restoration, and an exact final-vector assertion prevent stale markers or an unnoticed later phase mutation. Physical signal contract validation follows finalization. OFF delegates to the original methods and retains the original ordering.

The parent applied the patch. Validation against actual production imports: `python -m unittest diagnostics.test_area_phase_finalization diagnostics.test_area_follower_objective -v` passes ten tests (0.560 seconds). These invoke the actual base solve, actual Link solve, actual canonical phase refinement and exchange candidates; only the expensive inner search/local cost and endpoint are bounded fixtures. They cover a guard-choice reversal under the finalized greens, equality of the three scored vectors and returned vector, GNE commit without refinement, a no-guard path without invented guard diagnostics, second solve, exception restoration, and OFF legacy behavior. The next full t3300 preflight can check `control_area_phase_outer_matches_scored=1` without expensive profiling; this field is emitted only after exact green-dictionary equality, and every scored copied arm also asserts equality. That full run waits for the separate meter-finalization repair.
