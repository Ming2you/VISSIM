## A안 검정 — capacity drop 은 답이 아니다

혼잡에서 VSL 80(J +154)이 VSL 100(J −73)보다 나쁘게 관측되는 비단조성을 보고,
현행 모델에 꺼져 있는 capacity drop 두 메커니즘이 원인이라고 보았다. 관측 궤적은 고정한 채
모델만 바꿔 5 개 구성으로 재채점했다(VISSIM 재실행 없음).

**pairwise 가 다섯 구성 모두 소수점 17 자리까지 같다.** 모델 파라미터로는 이 지표가 움직이지 않는다.
phi=0.6 은 셀 대수 MAE 를 43 % 악화시키고, phi=0.6+ant 는 유일하게 통과하던 링크 속도까지 깨뜨린다.
**가설 기각.**

## 왜 움직이지 않는가 — 관측이 후보를 구분하지 못한다

그리고 다음 두 쌍은 전 지평에서 정확히 0 이다.


관측 차이가 0.1 % 미만인 쌍이 **16/91 (17.6 %)** 이다. 이 쌍들에서 참 순위는 정의되지 않는다.
어떤 모델도 정의되지 않은 순위를 맞출 수 없다. **G6 실패는 모델 능력의 문제가 아니라
후보집합 설계의 문제다.**

액션은 정상 집행된다. 액션 CSV 에서 `major_green 57→75`, `minor_green 57→25`,
`offset 0→30`, `rate_vph 900→682`, `speed_kph 120→80` 이 모두 기록되고 되읽기까지 확인된다.
다만 개입 규모가 다르다 — VSL 은 426 셀, ramp 24 셀, green 12 셀, offset 6 셀을 바꾼다.
green 은 VSL 의 1/35 다.

## G5 — 셀 기준은 구조적으로 8 배 엄격하다

임계값이 정확히 8 배다. 두 측정 모두에서 검증했다.

```
mixed t2700 :  cell 10.306048   link 82.448387   비 = 8.000000000000
lowurban    :  cell  9.732639   link 77.861111   비 = 8.000000000000
```

세그먼트가 8 개이므로 계약이 링크 예산을 세그먼트 수로 균등 배분한 값이다.
그런데 셀 오차의 대부분은 **링크 총량을 보존하는 재배치**라 링크 합산에서 상쇄된다.
플랜트 잡음은 세그먼트별로 독립적이지 않으므로 잡음/임계 비가 링크→셀에서 8 배 나빠진다.

병렬 조사(13 에이전트, 반박 통과 3/4)의 정량 결론.

- `cell_speed_mape` — 편향을 완전히 제거한 오라클이 **0.0604** 다. 임계 0.10 대비 40 % 여유.
  **모델 작업으로 통과 가능하다.**
- `cell_count_mae` — 편향 완전제거 오라클이 **10.10~10.21** 이다. 임계 9.733 을 넘는다.
  **어떤 편향형 보정으로도 통과 불가다.** 두 번째 VISSIM 시드를 예측으로 써도 11.13~13.89 로
  임계의 114~143 % 다. 즉 플랜트 자체의 시드간 재현성이 임계보다 나쁘다.

기각된 가설 하나 — 방향별 FD 분리(FW_E `a`=1.23 / FW_W `a`=1.65)는 실측 이득 +0.13 % 다.
필요 감소폭 −47.1 % 대비 363 배 부족하다. 세그먼트별 `v_free` 는 정적 FD 에서 −31 % 개선이지만
rollout 반사실에서는 **+8.9 % 악화**다. FD 처방은 반드시 rollout 으로 검증해야 한다.

## 다음에 해야 할 것

1. **후보집합 재설계.** `c01_vsl110`/`c02_vsl100` 과 `c22_major62`/`c23_minor62` 는 플랜트 결과가
   완전히 같다. 중복 후보를 제거하고, green/offset 진폭을 관측 가능한 수준까지 키우거나
   목적함수에 도시부 항을 넣어야 한다. 후자는 계약 변경이다.
2. **시드복제로 잡음 하한 확정.** 현행 추정은 3 점 detrend 라 하한일 가능성이 있다.
   시드 3 개 이상으로 sigma 를 확정해야 `cell_count_mae` 임계 논의가 성립한다.
3. **셀 임계 재정의 검토.** 링크 예산의 균등 8 분할은 오차가 세그먼트 간 독립일 때만 타당하다.
   실측은 그렇지 않다. 잡음직교 임계 / 셀 공간 재정의 / H=1 한정 채점 중 하나가 필요하며
   모두 계약 문언 변경을 수반한다.
