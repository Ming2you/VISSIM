차량삭제를 대조했다. 편집 범위는 VRD 1135 하나뿐이다 — 링크 1218 개 동일, 추가·삭제·변경 0 건.
따라서 단일 변수 대조다.

조건. SimPeriod 4500 s, RandSeed 13, SimRes 1, 무제어(제어기 미부착), NumRuns 20.
라우팅 결함은 제어층과 무관하므로 제어기를 빼서 변수를 하나로 묶었다.

## 메커니즘 — 확정

원래 모순은 이랬다. 수정 전 VRD 는 link 68 @98.802 이고 10681(→link 2)은 @76.589 로 **상류**다.
그러면 10681 로 빠진 차량은 VRD 에 닿지 못하니 route 1135-2 를 지닐 수 없어야 한다.
위치제약 도달성 탐색으로도 확인했다 — 98.802 에서 10646 을 쓰지 않고 link 2 에 가는 길은 없다.

해소는 **유효 배정 지점이 VRD 표식 위치가 아니라는 것**이다.

link 68 상류 경로결정들의 목적지가 link 68 **안쪽 pos 22.7 ~ 57.4 m** 에 있다
(1123-2 / 1124-1 / 1125-1). `combineStaRoutDec="true"` 이므로 앞 경로가 거기서 끝나는 순간
VISSIM 이 다음 경로결정(1135)을 이어 붙인다. 즉 차량은 **pos 22 ~ 57 m 에서 이미 route 1135-x 를
지닌 채** 76.589 의 분기를 만난다. 표식이 98.802 에 있어도 그렇다.

여기에 `lnChgDist = 200 m` 가 겹친다. 차량은 목표 커넥터 200 m 전부터 차로를 잡기 시작한다.
route 2 의 목표는 10646 @352.004 이므로 조준 시작점은 pos 152.0 인데, 분기 10681 은 76.589 —
**조준을 시작하기도 전에 분기를 만난다.** 이미 1~2 차로에 있던 차량이 10681 로 쓸려 나가
link 2 에 올라가고, 자기 경로의 10646 을 영영 못 만난 채 link 2 끝(4691.599)에서 삭제된다.

### 수정 후 잔여 310 건은 같은 결함의 거울상이다

route 4 의 목표는 10681 @76.589 인데 VRD 는 @59.792 — 도움닫기가 **16.8 m** 뿐이고
lnChgDist 는 200 m 다. 1~2 차로에 있지 않던 차량은 10681 을 못 타고 그대로 흘러
10646 @352.004 → link 26 → link 70 → link 2 로 돌아 나온 뒤 link 2 끝에서 10681 을 못 찾고 삭제된다.
경로는 위치제약 탐색으로 확인했다.

즉 잔여 결함은 **link 68 의 기하 자체**에서 온다. 첫 분기까지 76.589 m 뿐인데 lnChgDist 는 200 m 이고,
link 66 에서 오는 차량은 커넥터 10633 으로 **4 차로**에 떨어져 3 개 차로를 건너야 한다.
link 68 위에 결정을 두는 한 이 간격은 메울 수 없다.

## 처방

**동/서 분기 결정을 상류 링크로 옮긴다.** 이미 그 자리에 경로결정이 있고 도움닫기도 충분하다.

| VRD | 위치 | 진입 커넥터 | 도움닫기 |
|---|---|---|---:|
| 1123 | link 52 @ 11.1 | 10629 → link 68 @2.067 | 454 m |
| 1125 | link 46 @ 16.5 | 10625 → link 68 @2.120 | 933 m |
| 1124 | link 66 @ 1394.1 | 10633 → link 68 @2.361 | 1266 m |

각 VRD 에 `진입커넥터 → link 68 → 10681`(FW_E) 과 `진입커넥터 → link 68 → 10646`(FW_W) 두 경로를
명시하면 link 68 위에는 결정을 둘 필요가 없어진다.

## 남은 결함 — 이제 이쪽이 더 크다

`LANECHANGE_KILL` 은 수정 전후가 사실상 같다 (462.1 → 466.9, +1.0 %). VRD 1135 와 무관한
독립 결함임이 확인됐고, 수정 후에는 **전체 삭제의 87 %** 를 차지한다.

| VRD | 링크 | 20 런 합계 (전 → 후) |
|---|---|---|
| 1113 route 3 | 329 | 2028 → 2119 |
| 1124 route 1 | 66 | 1729 → 1748 |
| 1119 route 1 | 40 | 1427 → 1507 |
| 1126 route 1 | 71 | 1105 → 1085 |
| 1127 route 1 | 403 | 668 → 677 |

전부 4~5 차로 링크에서 가장자리 차로의 1 차로 커넥터로 붙어야 하는 이동류이고,
해당 링크의 `lnChgDist` 는 모두 기본값 200 m 다. 손대면 플랜트 거동이 바뀌므로
기준선 재측정이 따라야 한다.

## 방법상 주의 — .err 인코딩

VISSIM 이 쓰는 `.err` 는 BOM 없는 **CP949/ANSI** 다. UTF-16 으로 먼저 시도하면 바이트 길이가
짝수인 파일에서 예외 없이 디코딩에 "성공" 하면서 CJK 모지바케가 되고, 집계가 조용히 0 이 된다.
첫 집계에서 pre 20 번 런이 그렇게 0 으로 나왔다(414376 바이트 = 짝수). BOM 을 검사해
없으면 CP949 로 확정해야 한다.
